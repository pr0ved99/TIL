# 103JT-025 모터 케이스 온도 2채널 입력 설계

기준일: **2026-10-22**. 상태: **계산한 초기 설계안 / 실물 미연결 / ADC 미구현**.

구매한 SEMITEC 103JT-025 두 개를 STM32 내장 ADC로 읽는 최소 회로다. [전체 모니터링 준비](2026-10-22_Motor_Current_Temperature_Monitoring_and_Procurement_ko.md)의 온도 입력을 구체화한다. 센서·측정기는 모두 배송 대기다. 전류 입력 필터, 전체 전원 여유, 실제 모터 허용 온도와 자동 정지 정책은 이 문서의 확정 범위가 아니다.

## 2026-10-23 별도 전원안 적용 경계

후속 확장안은 XL4015 #2→별도 LDO 공급을 검토한다. [ADC6채널 계약](../../09_Electrical_Design/20_Analog_6Ch_Contract_and_Stage2_Review_2026-10-23_ko.md)을 우선한다. 아래 동일 STM 여기 전원·g=1·rail 코드4079/16·STM과 동시 OFF는 당시 계산 조건이며 새 별도 전원에서 자동 성립하지 않는다. NTC 단선 시 노드는VEXC로 올라가므로 VDDA 초과/무전원 보호와 환산 비율을 다시 결정한다. 원본 계산/CSV는 명목 조건 이력으로 보존한다.

## 채널별 회로와 부품

왼쪽과 오른쪽에 아래 회로를 각각 하나씩 사용한다. 저항·커패시터는 STM 보드 가까이의 별도 확장 기판에 배치하는 방향으로 검토하고, 모터까지 가는 두 선에는 NTC만 연결한다. 기존 만능기판의 빈자리가 확보됐다는 전제는 두지 않는다.

**실장 공간 정정:** 사용자가 현재 만능기판의 여유 공간 문제를 지적했다. [9/30 공간 검토](../../09_Electrical_Design/12_Dual_Rail_ADC_Space_Review_2026-09-30_ko.md)에서도 기존 배선/모듈 몸체·커넥터까지 보존한 연속 실장 공간은 확인되지 않았다.8/14 사진의 빈 홀을 현재 사용 가능 면적으로 간주하지 않는다. 앞서 제시한 리드형 부속은 부품 형식 예시이며 기존 기판에 바로 납땜하라는 지시가 아니다.

현재는 전류2·온도2채널의 신호 회로/커넥터·STM 인출을 별도 확장 기판 또는 후속 PCB로 설계한다. 기존 [하층 확장 검토](../../09_Electrical_Design/13_Two_Deck_Perfboard_Expansion_Feasibility_2026-09-30_ko.md)는 가능성 제안이며 새 기판 크기·적층/고정 위치·실물 인출은 미확정이다. 모터 주전류 경로의#5241 두 모듈은 별도 전력 배선/기계 지지를 검토하며 신호 확장 기판에 주전류를 흘리지 않는다. 최종 기판 방식/패키지를 정하기 전 리드형 부속이나 새 만능기판 구매를 확정하지 않는다. 기존 외부 GM-1312/UT210E 관측에는 이 확장이 선행 조건이 아니다.

```text
STM 측 3.3V 여기 전원 VEXC
        |
    R_FIXED 10kΩ 0.1%
        |
        +---- TEMP_NODE ---- R_SERIES 1kΩ ---- TEMP_ADC
        |                                      |
    103JT-025                              C_FILTER 100nF
        |                                      |
STM 신호 GND ------------------------------- 신호 GND

왼쪽 TEMP_ADC → PC2 / ADC1_IN12 후보
오른쪽 TEMP_ADC → PC3 / ADC1_IN13 후보
```

| 부속 | 채널당 | 2채널 합계 | 초기 선정 조건 |
| --- | ---: | ---: | --- |
| 103JT-025 | 1 | 2 | 구매 완료, 배송 대기 |
| R_FIXED 10kΩ | 1 | 2 | ±0.1%, 온도계수 ≤25ppm/°C 권장, 1/8W 이상 |
| R_SERIES 1kΩ | 1 | 2 | ±1%, 1/8W 이상 |
| C_FILTER 100nF | 1 | 2 | 세라믹 X7R, 정격16V 이상 권장. 허용오차·DC bias·사용 온도를 포함해 유효 용량80~120nF를 만족하는 부품 선정 |
| 센서별 2선 배선·커넥터·절연/고정재 | 1쌍 | 2쌍 | 신호용, 모터 진동·리드 응력 관리. 실물 연결 방식에 맞춰 선택 |

부속의 **필요 수량**이며 추가 구매 확정 목록은 아니다. 보유 수량과 실제 허용오차를 확인하고 부족분만 구매한다. 기존 E-stop 회로에서 사용하는 저항을 여분으로 계산하지 않는다. 1% 기준 저항도 사용할 수 있지만 환산 시 실제 저항값/오차를 반영해야 한다. 0.1%는 필수 센서 사양이 아니라 기준 저항이 추가하는 오차를 줄이기 위한 선택이다.

**최신 구매 상태:** Vishay `K104K15X7RF53H5` 10개 구매 완료(2026-10-22 사용자 보고). 규격은100nF(0.1µF)·50V·X7R·±10%·리드형·피치5mm다. 수령 여부·실제 판매처/결제액·도착일은 미확인이다. 10kΩ·1kΩ·12kΩ 저항은 보유로 확인됐으나 수량/허용오차는 미확인이다. 아래 부족분/미보유 표기는 구매 전 검토 이력이며 현재 구매 안내로 사용하지 않는다.

**구매 전 보유 상태와 대체 조건:** 사용자는10kΩ±0.1% 저항 보유 여부를 모르며100nF는 없다고 보고했다. 0.1% 제품만을 추가 구매할 필요는 없다. 초기 구성에는10kΩ±1% 금속피막을 대안으로 두고, 보유 저항의 허용오차를 확인한다. 명목10kΩ으로 환산했을 때 기준 저항±1%만의 온도 오차는 제조사 표 보간 기준25°C 약−0.262~+0.267°C,80°C 약−0.349~+0.357°C다. 센서/ADC/부착 오차는 별도다. 측정한 저항값을 반영해 초기 오차를 줄일 수 있지만 멀티미터 정확도·온도에 따른 저항 변화까지 없어지는 것은 아니다.

아래 계산 산출물의 기준은 계속±0.1%다. ±1% 대체 시 R_SOURCE 상한11.11kΩ·C최대120nF에서0.5LSB 정착 약12.01ms로 계산되므로20ms 초기 대기 후보는 유지할 수 있다. 실제 사용 부품 확정 시 계산 입력도 갱신한다. 100nF는 온도용 최소2개가 부족하며, 만능기판 조립에는 리드형 X7R·±10%·50V 제품을 검토한다. [Murata 리드형 제조사 사양 예시](https://search.murata.co.jp/Ceramy/image/img/A01X/G101/ENG/RDE_X7R_X7S_25V-100V_E.pdf)의 `RDER71H104K0K1H03B`는0.10µF/50V/X7R/±10%다. 이는 규격 예시이며 주문/실물 적합성 확정이 아니다. 전류 입력 부속까지 검토한 뒤 부족분을 함께 정리한다.

이 문서의 RC 값은 수동 NTC 전용이다. #5241의 능동 VIOUT에 그대로 적용하는 회로가 아니다. 전류센서 출력의 용량 부하 조건은 별도로 검토한다.

## 10kΩ을 선택한 이유와 명목값

103JT는 R25=10kΩ±1%, B25/85=3435K±1%다. [SEMITEC 제조사 표](https://www.semitec-global.com/uploads/2022/01/P9-JT-Thermistor.pdf)의 저항값과 VEXC=3.3V로 계산했다. 센서 온도가 오르면 저항과 ADC 전압이 내려간다.

```text
V_NODE = VEXC × R_NTC / (R_FIXED + R_NTC)
P_NTC  = VEXC² × R_NTC / (R_FIXED + R_NTC)²
```

| 센서 온도 | 제조사 명목 저항 | 노드 전압 | 이상적인 12bit 코드 좌표* | NTC 전력 |
| ---: | ---: | ---: | ---: | ---: |
| 0°C | 27.70kΩ | 2.425V | 3009.5 | 0.212mW |
| 25°C | 10.00kΩ | 1.650V | 2048.0 | 0.272mW |
| 50°C | 4.147kΩ | 0.967V | 1200.7 | 0.226mW |
| 80°C | 1.668kΩ | 0.472V | 585.5 | 0.133mW |
| 100°C | 0.9753kΩ | 0.293V | 364.0 | 0.088mW |

* `4096 × V_NODE/VREF`의 실수 좌표다. 실제 코드는 정수0~4095이고 양자화·ADC 오차가 있다. 표의 온도는 회로 계산점이며 **모터 운전 허용값이나 중단 기준이 아니다**.

10kΩ은25°C에서 ADC 중간 범위를 사용하고, 저항을 더 작게 했을 때의 자가발열과 더 크게 했을 때의 높은 소스 임피던스 사이에서 초기 구성에 적절하다. 전 온도에서 최고 분해능인 유일한 값이라는 뜻은 아니다.

전력은 `R_NTC=R_FIXED`일 때 최대0.27225mW다. 제조사 정지 공기 중 방열계수 약0.7mW/°C를 적용하면 자가발열은 약0.389°C로 추정된다. 부착 후 방열 조건은 달라지므로 이 수치를 보정 상수로 빼지 않는다. 센서 시간상수 약5초도 공기 중 값이며 실제 모터 표면 추종 시간을 보증하지 않는다.

두 분압의 전류는25°C에서 합계 약0.33mA, NTC가 단락된 최악의 저항 허용오차 조건에서도 합계 약0.661mA다. 이때 기준 저항 한 개의 전력은 약1.09mW다. 이는 온도 분압 부하 계산이며 전체3.3V 전원 여유 검증은 아니다.

## ADC 기준 전압과 온도 환산

가능하면 VEXC를 ADC의 VREF+/VDDA와 같은 아날로그 전원 기준으로 설계한다. 기존 NUCLEO의3.3V 헤더와 VDDA 사이 필터/전압 차이를 실제 보드 회로와 나중 측정으로 확인해야 한다. AREF를 별도 전원 출력으로 간주하거나 외부 전압을 강제로 인가하지 않는다.

비율 `q=V_NODE/VREF`, `g=VEXC/VREF`라면 다음과 같다.

```text
R_NTC = R_FIXED × q / (g − q)
같은 기준 전압이면 g=1 → R_NTC = R_FIXED × q / (1 − q)
```

동일 기준에서 공급 전압이 함께 변할 때 비율로 상쇄되는 구조다. VEXC가 다른 전원이라면 `g=1`로 가정하지 않는다. 12bit의 `q≈raw/4096`는 기본 근사이며 ADC offset/gain·기준 전압 차이·누설을 따로 다룬다. R_SERIES는 이상적인 무부하 DC 분압비에는 들어가지 않지만 ADC 누설/획득 오차에는 영향을 준다.

환산은 제조사의 **103JT R-T 표와 log(R) 구간 보간**을 우선한다. 계산 산출물에−50~125°C의 제조사 표21점을 보존했다. 양 끝을 넘는 저항은 외삽하거나 정상 온도로 고정하지 않고 범위 밖으로 표시한다. 표 사이 보간의 오차 보증 자료는 없으므로 계산값을 교정 정확도로 표현하지 않는다.

고정 B=3435 식은 비교용 근사다. 명목 제조사 표0~100°C의 기재점만 비교해도 최대 약0.776°C 차이가 나므로 B 식만으로 정밀도를 주장하지 않는다. 기준 저항±0.1%만의 영향은25°C에서 약0.027°C,80°C에서 약0.036°C지만 센서 자체 R25/B 허용오차, ADC 오차, 부착 오차와 자가발열이 별도로 남는다. 소수점 표시 자릿수는 실제 정확도가 아니다.

## 필터와 ADC 시간 조건

필터는 `1kΩ × 100nF`만으로 계산하지 않는다. 커패시터가 보는 소스 저항은 다음과 같다.

```text
R_SOURCE = R_SERIES + (R_FIXED || R_NTC)
τ = R_SOURCE × C_FILTER
fC = 1 / (2π × τ)
```

25°C에서 R_SOURCE=6kΩ, τ=0.600ms, fC≈265Hz다. 0°C에서는 약191Hz,80°C에서는 약655Hz다. 온도에 따라 바뀌는 1차 입력 필터이며, 모터 PWM 잡음의 일부를 줄이는 목적이다. 이 필터만으로 모든 에일리어싱/EMI를 제거했다고 판단하지 않는다.

기준 저항·직렬 저항 상한과 센서 단선까지 포함하면 R_SOURCE≤11.02kΩ다. C≤120nF에서 τ≤1.3224ms, 전체 스케일 변화가0.5LSB 이내로 정착하는 이상적 RC 시간은 약11.92ms다. **전원/ADC 시작·여기 전원 변경 후 최소20ms 정착 대기**를 초기 조건으로 두고 그 전에는 온도 유효값을 내지 않는다.

현재 [main.c](../../03_Firmware/stm32_uart_mvp/Core/Src/main.c)의 PCLK2와 `.ioc`는84MHz다. 다음은 아직 적용하지 않은 초기 설정안이다.

| 항목 | 온도 채널 초기 설정안 | 근거/경계 |
| --- | --- | --- |
| ADC 클록 | PCLK2/6=14MHz | 현재84MHz 기준; 클록 변경 시 재계산 |
| 해상도·샘플 시간 | 12bit·480cycles | 획득 시간 약34.29µs |
| 변환 시간 | 채널당 약35.14µs | 480+12cycles, 온도 두 채널 약70.29µs |
| 온도 수집 | 채널당100sample/s 후보 | 연속 최대 속도 변환은 피하고 주기를 둔다 |
| 온도 표시/저장 | 약10Hz 후보 | 원시값/유효성을 보존하고 필터 지연을 기록 |

[ST DS10693](https://www.st.com/resource/en/datasheet/stm32f446vc.pdf)의 ADC 조건과 [AN2834](https://www.st.com/resource/en/application_note/an2834-how-to-get-the-best-adc-accuracy-in-stm32-microcontrollers-stmicroelectronics.pdf)에 따라 소스 임피던스·획득 시간·외부 커패시터의 반복 충전을 함께 검토했다. 상세 수치 계산은 저장된 [DS10693 Rev10](../../assets/stm32f446mc.pdf)의 ADC 표74/식1을 사용했다. 웹의 최신 문서 표지는 Rev11이며 상세 페이지 재조회는 timeout이 나므로 Rev11과 모든 전기 항목이 동일하다고 주장하지 않는다. 실제 설정 단계에서 최신 ADC 전기 표의 개정 차이를 재확인한다.

R_ADC 최대6kΩ·C_ADC 최대7pF와 위 소스 상한을 적용한 커패시터 없는 획득 모델의0.25LSB 조건은 약1.19µs다. 외부 C≥80nF라면 다른 채널의 전체 스케일 전하가 한 번 공유되는 순간의 단순 상한은 약0.358LSB다. 반복 획득 간 충분한 회복 시간이 필요하며, 두 계산은 다른 단순 모델이다. 누설·ADC 전체 오차·기판 기생성분을 포함한 최종 정확도 보증으로 합치지 않는다.

온도 채널 간격10ms는 위 RC 시간상수의7.5배 이상이다. 실제 ADC scan/DMA 구현 시 전류 채널의 더 빠른 수집과 분리/배치해 이 간격을 유지하고, 다른 입력 전압을 바꿨을 때 온도 채널이 끌려가는지 확인한다. **전류 샘플링을100Hz로 확정한 것이 아니다.**

| --- | --- |
| NTC 또는 센서선 단선 | VREF 부근으로 상승. `raw≥4079`를 초기 rail 오류 후보로 두고 정상 온도와 분리 |
| 센서선 간 단락 | 0V 부근으로 하강. `raw≤16`을 초기 rail 오류 후보로 두고 정상 고온과 분리 |
| 제조사 표 밖 | `OUT_OF_RANGE`, 외삽/정상값 고정 없음 |
| 초기 정착 전·ADC 미수신/갱신 중단 | `NOT_READY`/`STALE`, 이전 값을 현재 정상값으로 쓰지 않음 |

rail 임계값은 측정/진단용 후보이며 자동 정지 임계값이 아니다. 센서 허용 범위 명목 코드는 약207~3988이라 위 rail 후보와 구별된다. 다만 중간값을 만드는 누설·접촉 불량·ADC 쪽 선 단절·센서의 케이스 이탈은 이 방법만으로 검출할 수 없다. 온도 변환/평균 전에 원시값과 유효성을 점검하는 흐름으로 설계한다. 여러 값으로 평균해 오류를 정상값으로 숨기지 않는다.

NTC 선은 모터 전력선과 분리해 배치하고 신호와 귀환선을 함께 꼰다. 귀환선에 모터 전류가 흐르지 않게 한다. 커패시터는 ADC 핀/신호 GND 가까이 둔다. 기준 저항의3.3V는 STM과 함께 꺼지게 하여 무전원 ADC에 외부 전원을 공급하지 않는다.

직렬1kΩ은 필터/소량의 과도 전류 제한 역할이며 **배터리12V 오접속·ESD·지속 과전압 보호 회로가 아니다**. 현재안은 같은 STM 전원으로 동작하는 수동 NTC를 대상으로 한다. 최종 PCB/외부 커넥터 보호는 허용 고장 전압·클램프 누설·역급전·GND 구조를 정해 추가 검토한다. 보호 소자를 근거 없이 구매 목록에 더하지 않는다.

## 수령 후 확인할 순서

1. 실물 모델/리드·연결 부속 및 PC2/PC3 인출·VEXC/ADC 기준 전원 경로 확인.
2. 부품값과 허용오차 확인 후 무전원 조립 검사. firmware 입력은 사용자 학습 절차로 별도 진행.
3. 모터 무구동 상태에서 노드 전압/ADC·단선/단락·정착/채널 간 간섭을 확인. 먼저 센서 대신 정밀 저항으로 전기 환산 경로를 구분해 확인할 수 있다.
4. GM-1312와 대응 위치의 평형 표면 온도를 비교하고 주위 온도·부착 조건을 기록. 센서가 다른 위치/시간을 읽는 차이를 교정 오차와 섞지 않는다.

오늘 물리 조작·MCU 코드/설정 변경·빌드/플래시·온도 실측은 없다. 다음 설계 작업은 **#5241 전류2채널의 출력 부하 조건을 만족하는 필터/ADC·영점 보정 검토**다. 전체3.3V 부하와 실제 보호 부속은 그 결과를 합쳐 결정한다.
