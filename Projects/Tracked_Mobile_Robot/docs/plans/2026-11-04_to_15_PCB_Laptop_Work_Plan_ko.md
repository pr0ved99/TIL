# 11/4~15 PCB 후속 작업 계획 — 11/9·10 휴무 반영

**2026-11-05 실적·재개점 갱신:** 자료는37-3까지 작성했고 사용자 필기는36-19까지 확인됐다. 사용자 추가 요청으로 짧은 공중 전진/후진 외부 관측4건을 진행한 뒤 전원 분리했다. 마감 후 NotebookLM01단원을 안내한다.11/6은37-4 잡음/평균·10Hz 처리부터 이어가고38 기준 계기·39 전체 판정으로 연결한다. 아래11/5의36절 시작은 최초 계획이며 실제 진도는 이 갱신을 우선한다.11/9·10 휴무와 전체 제작 전 검토 순서는 유지한다. [실적](../progress/2026-11-05_progress.md).

2026-11-04 사용자 요청으로 조정했다. **11월9일(월)·10일(화)은 프로젝트 작업을 배정하지 않는다.** 이전 진도를 압축해서 두 날짜 전후에 몰아넣지 않고 여유일에서 조정한다. 날짜별 목표이며 작업 시작/종료 시각이나 완료 약속은 아니다.

현재는 필기30~35를 마감하고 TPS3840PL30–TMUX1511을 후속 계산 후보로 유지한 상태다. 다음 첫 작업은36절 전체 전압 오차 예산이다. 회로 계산/부품 검토→회로도/ERC→기구/footprint→배치/배선→제작 검토 순서를 유지한다.

**Calendar 실제 반영 — 11/4 후속:** 날짜별 작업10개를 primary에 종일·한가함·알림 없음으로 등록하고 각각 재조회했다.11/9·10은 프로젝트 일정이 없다. [일정 링크/ID·등록 근거](../../assets/logs/pcb_design/2026-11-04_calendar_plan_sync/README.md). 작업 시각은 미정이며 종일 표시를 실제 하루 작업시간으로 해석하지 않는다.

## 11/4~8 — 전압 측정 오차 예산과 설계 판단

**기간 목표:** 무엇이 측정 오차를 만들고, 보정 후 무엇이 남으며, ±0.10V 목표를 판단하려면 어떤 근거가 더 필요한지 한 표로 정리한다. 노트북 문서/계산 작업이며 새 측정/장비 확보를 완료 조건으로 강제하지 않는다.

| 날짜 | 작업 | 남길 결과 |
| --- | --- | --- |
| 11/4 수 | 필기30~35 마감·문서/파일 관리 점검, 이번 계획 조정 | 학습/문서 마감 완료. 이후 작업은 아래 일정 |
| 11/5 목 | 36절 시작: 보호 부하를 포함한 저항비·RON·누설의 입력 환산 오차 | 기존 계산을 활용한 회로 기여량 표. 다른 일정이 있어 작업량을 가볍게 잡음 |
| 11/6 금 | ADC·VREFINT/VDDA 추정·보정 후 잔차·온도/잡음/정착 항목 연결 | 조건/상관/중복 여부를 표시한 전체 표. 미확인 값은 미정으로 둠 |
| 11/7 토 | 목표와 예산 대조, 기준 계기로 입증 가능한 범위 구분 | 목표 유지/조정/보류 근거와 부족한 증거 목록. 짧은 검토 또는 보충일로 운영 |
| 11/8 일 | 밀린 항목 보완·추가 시뮬레이션 선정·1주차 마감 | 오차 예산 검토본, 필요한 필터/ADC취득/전원전환 해석과 회로 반영 후보/미결 목록 |

±0.1% 저항은 비교 조건이며 구매 지시가 아니다. 0~16V DC·보정 후±0.10V·20~30°C·결과10Hz는 검토 기준 제안이다. 보정 전 공차를 보정 후 잔차로 자동 합산하지 않으며, 기준 계기의 비교 경계는 DUT 물리 오차와 구분한다. 완료RC/공차/두 점 보정 실습을 반복하지 않는다.

## 11/9~10 — 프로젝트 작업 없음

필기·자료 읽기·시뮬레이션·마감 작업도 두 날짜에 숙제로 배정하지 않는다. 다음 프로젝트 작업은11/11 수요일로 잡는다. 최초 검색에는 해당 기간TMR일정이 없었으며, 후속으로 작업일10개를 실제 등록한 뒤에도11/9~10은 프로젝트 일정이 없음을 재조회했다. 다른 개인 일정은 변경하지 않았다.

## 진도 조정 기준

- 1주차에 부품/측정 요구의 핵심 미결로 회로 반영 범위를 정하지 못하면11/11~13을 그 판단에 먼저 사용한다. 배치/제작 단계로 건너뛰지 않는다.
- 11/15 목표는 회로 초안/ERC 검토본이다. 검출 지연·전원 하강·완전OFF·ADC 유효화의 실물 보호 PASS와 구분하며, 미정은 표로 계속 추적한다.
- KiCad 작업과 GUI 실습은 기존 학습 방식대로 사용자와 단계별로 진행한다. 계획 작성이 회로 변경/검사 실행 완료를 뜻하지 않는다.
- MCU 빌드/플래시·실물 시험·부품 구매·AI 구현은 이번 날짜별 기본 계획에 넣지 않는다. Calendar에는 날짜별 종일 일정으로 반영했으며 작업 시작/종료 시각은 지정하지 않았다.
