## 1. 이번에 끝낼 범위

**11/20 채택 완료:** [기록44 §10](../verification/44_EStop_Acceptance_Proposal_2026-11-19_ko.md)에 따라 T005A 정상 기능을 한정 PASS로 수용했다. 수치 잔류 전압/에너지 수용은 OPEN으로 분리한다. 기존 자료 대조·같은 진단을 반복하지 않는다. T007 다른 선행 수용과 정량 정지는 남으며 상위9 PASS·4 PARTIAL 유지. 다음 사용자 작업은 전원/모터 분리 상태의 카메라 구도 준비, Codex 작업은 남은 선행 수용 대조다.

[기록44 §8](../verification/44_EStop_Acceptance_Proposal_2026-11-19_ko.md). 이번 진단 자료 확보는 종료하며 같은 준비/측정을 반복하지 않는다. 해당 진단은11/20 T005A 정상 기능 한정 PASS 근거에 포함했다. 수치 잔류 수용은 OPEN이다.

**현재 완료 결정:** [기록44](../verification/44_EStop_Acceptance_Proposal_2026-11-19_ko.md)의 실제 속도≤0.10m/s·정지시간≤1.0초·잔여 이동≤0.10m를 사용자가 제한된 저속 시험의 성능 목표로 채택했다. 정본 요구사항24·시험 계획06에 반영했고 목표 미정을 해소했다. 전원 차단 수용과 실제 정지 계측은 남는다. 상위 판정 변경이나 새 통전 지시가 아니다.

**현재 로봇·기존 만능기판·기존 펌웨어로 수행한 무선 수동 주행, 정지/비상정지, 엔코더, 1m 거리 기록을 기존 MVP 요구사항에 대조해 마감한다.** 이미 충족한 항목을 닫고, 실제로 부족한 근거만 보완한다.

확장 PCB는 애초에 이 MVP에 포함되지 않는다. ADC/계측 쉴드·IMU 기능·CAN·STM RTOS·LL·Ubuntu·Nav2·RL도 이번 마무리의 선행 작업이 아니다. [11/18 전체 확장 계획](2026-11-18_Detailed_Design_to_Final_Completion_Plan_ko.md)은 후속 검토 문서로 보존한다.

전류계 UT210E와 GM1312는 준비된 외부 계측 장비다. 남은 시험이 해당 관측을 필요로 할 때 사용한다. 장비를 구매했다는 이유로 이미 후속으로 분리한 정량 전류/온도 시험을 MVP 필수로 복원하지 않는다. 반대로 외부 관측에 PCB/ADC 완성을 요구하지 않는다.

**목표일은 11/20이며, 하루5~7시간·사용자 실물 작업 가능을 계획 가정으로 둔다.** 실제 가용시간/현재 전원·배선 상태는 실행 전에 확인한다. 달력 일정이나 기존 약속을 이번 작성으로 변경하지 않는다.

전체 MVP 완료는 적용 MUST 충족이 확인될 때 선언한다. 부족한 필수 근거를 날짜 때문에 PASS로 바꾸지 않는다. 현재 확인된 T005A/T007 미결 때문에 **전체 완료 가능성은 조건부**이며, 아래 첫2시간의 산출물에서 가능/불가 사유를 결정한다.

## 4. 첫2시간에 끝낼 판단 — 제외한 조사를 다시 시키지 않는다

### 4.1 알려진 쟁점

- T005A에는 허용 rail-off 전압/판정 시점과 일부 전력 경로 수용 미결이 있다.
- T007은 선행 시험과 실제 정지 시간/거리의 정식 수용 기준·근거가 부족해 BLOCKED다. 기존 S0/PWM/엔코더 관측은 유효하지만 전체 T007 PASS는 아니다.
- 10/17에 이미 수행한 제조사/정격/도면 검토의 반복 재개는 사용자 결정으로 제외됐고, 보고서41도 재개 제안을 취소했다.
- 따라서 일반적인 “MVP 마무리 계획” 요청을 해당 조사 전체의 재개 허가로 해석하지 않는다. 동시에 조사를 제외했다는 사실을 기술적 PASS로 해석하지 않는다.

### 4.2 종료해야 할 결정

각 미결에 대해 **기존 요구 문장 → 이미 있는 증거 → 실제 부족한 사실 → 이전 제외 결정 → 가능한 처리**를 한 행으로 작성한다. 결과를 다음 네 가지로 분류한다.

| 분류 | 의미 | 처리 |
| --- | --- | --- |
| 기존 근거로 충족 | 요구한 관측/판정이 이미 있고 상태 반영만 부족 | 원본을 확인해 문서 판정 갱신. 실물 재시험 없음 |
| 현재 조건에서 보완 가능 | 필요한 기준·장비·허용 시험 범위가 갖춰짐 | 닫을 요구만 포함한 측정 묶음으로 오늘/내일 실행 |
| 기존 제외와 충돌 | 미결은 남지만 해당 조사 재개가 제외됨 | 충돌과 결과를 사용자에게 제시. 제외 유지 중에는 해당 조사·시험을 강행하지 않음 |
| 새 장비/설계/근거 필요 | 오늘·내일 확보할 수 없는 측정/수정이 필요 | 이틀 전체 완료 불가 항목으로 명시. 다른 항목 마감은 계속 진행 |

기존 요구를 충족하는 대체 근거/검증 방법이 있으면 적용성을 검토한다. **잔류전압0.58V를 봤다는 이유로1V를 합격선으로 만들거나, 기존 정지 영상에 맞춰 허용 시간을 정하지 않는다.** baseline을 보고 기준을 정하는 절차가 필요한 경우 기준 결정과 이후 독립 수용 시험을 구분한다.

사용자에게 범위 결정이 필요하면 “무엇을 빼야 완료라고 말할 수 있다”는 포괄적인 질문을 하지 않는다. 예를 들어 **제외 유지 시 T005A/T007과 전체 인수는 미완료로 남는다**는 결과, 대체 근거가 있는지, 재개한다면 필요한 최소 작업/장비/시간을 구체적으로 제시한다. 사용자가 범위를 변경하더라도 기존 시험의 미검증 상태와 변경 이력을 보존한다.

**2시간의 산출물:** 이틀 내 처리 가능한 항목 목록, 남는 장애 항목, 다음 실제 한 작업. 자료 읽기 시간을 자동 연장하지 않는다. 찾지 못한 근거는 “없음”과 “아직 못 찾음”을 구분한다. 이 판단표 작성으로 문제 자체가 해결된 것으로 기록하지 않는다.

## 5. 오늘·내일의 실행 배정

시간은 예상 작업량이며 실제 수행 시각이 아니다. 사용자의 실물 작업 가능 여부·원본/장비 준비를 확인한 뒤 실행한다. 대기 중에는 준비된 문서/로그 정합성을 처리하고 후속 PCB/ADC로 작업을 바꾸지 않는다.

## 6. 측정은 이렇게 묶는다

아래는 선택 가능한 묶음이며 전부 재실행할 목록이 아니다. §4에서 실제로 부족하다고 판정한 행만 활성화한다. 전원 인가/배선/빌드/플래시는 사용자 수행이며, 이 문서는 즉시 배선 지시가 아니다.

| 묶음 | 관측/기록 | 선택 조건 | 종료 기준 |
| --- | --- | --- | --- |
| 구성/무전원 기록 | 현재 보드/앱·출력 설정·배선 변경 여부·장착/식별 사진·전원 연결 방식 | 기록 미비 또는 실제 변경이 있을 때 | 해당 요구를 확인할 수 있는 식별/사진/기록 확보 |
| UART/출력 | 원래 요구 중 빠진 owner/명령 거부/timeout/reset 등의 로그·관련 PWM 핀 | 필요한 기존 근거가 없고 모터 분리 벤치 조건이 준비될 때 | 기존 상태/시간/출력 기준 만족. 정상 시험 전체 반복 금지 |

보유 전류계로 확인할 수 있는 것은 검토된 조건의 DC 표시다. 정지 지연·아날로그 엔코더 신호·배터리 과도 에너지를 이 장비 하나로 검증하지 않는다. 적합한 아날로그 계측 경로가 미확보이면 해당 시험은 준비 부족으로 남긴다. 신규 장비 구매는 이번 계획의 자동 실행 항목이 아니다.

새 코드를 꼭 고쳐야 할 결함이 발견되지 않으면 MCU 빌드/플래시를 마감 의식처럼 반복하지 않는다. 현재 보드 이미지와 저장 파일의 동일성이 필요한 경우 기존 사용자 적용 보고/실행 로그/이미지 식별 근거를 먼저 확인한다. 로컬 hash를 보드 readback으로 표현하지 않는다.

각 활성 시험은 시작 전에 **시험 목적·연결된 Requirement/Test ID·현재 구성·측정점·입력/시간·기존 PASS 기준·중단 조건·저장 파일**을 한 장에 적는다. 현재 배선/전원을 확인하지 않고 과거 세션의 전원 상태를 그대로 적용하지 않는다. 준비된 순서를 한 동작씩 안내하고 결과를 확인하며 진행한다.

## 7. 최종 결과물과 완료 판정

한 폴더/보고서에서 다음을 찾을 수 있게 한다. 이번 계획 작성 시 이 결과물이 이미 생성/검증됐다고 주장하지 않는다.

1. **MVP 인수표:** MVP-001~013과 적용 하위 요구의 판정·원본·미결. MVP-014/015는 기존 후속 범위를 유지.
2. **실행 구성:** 사용한 소스/설정/배선·실물 기준점, 확인하지 못한 board identity는 명시.
3. **추가 시험 근거:** 실제 실행한 것만 로그/사진/영상·계기 범위·결과 기록. 새 시험이 불필요하면 기존 원본 연결.
4. **운용·복구 절차:** 현재 전원 정책, 정지·복구·수동 ARM, 셀 알람/작업자 감독과 검증된 사용 범위.
5. **최종 현재 안내:** README·진행·검증표·인수인계·메모리와 게시 상태 일치. CAD가 안 바뀌면 기본 PDF 재생성 대신 동일성 확인.

최종 결과는 다음 중 실제 근거에 맞는 것으로 정한다.

- **전체 MVP 완료:** 적용 MUST의 충족과 인수 근거를 확인했고, 미해결 필수 사항이 없다.
- **일부 마감/전체 미완료:** 완료한 부분을 닫고, 남은 항목을 요구·부족한 근거·해결 방법·장비/시간으로 특정한다. “추가 검증 필요” 한 줄로 다시 넘기지 않는다.
- **사용자에 의한 종료 범위 변경:** 변경 전후 범위와 제외 이유를 남긴다. 기존 시험의 PARTIAL/BLOCKED를 기술적 PASS로 덮어쓰지 않는다.

이틀 동안 확실히 줄일 대상은 **근거 없이 남은 PARTIAL, 중복 시험 요구, 완료/후속의 혼동**이다. 실제 미해결 위험을 문서만으로 없애는 작업은 아니다.

**B. 모터 동력선 분리 상태에서 전원/입력 보완 (기준 확정 후 사용자 계측)**

- 기존 T005A nominal cases에서 실제 누락된 연결/전원 조건만 선택한다. 모터를 구동하지 않고 K1 전원 차단·전원 복귀/수동 S2 전 무재인가를 확인한다. 원래 충분한 근거가 있는 사례는 반복하지 않는다.
- 엔코더 출력형식은 기존 사진·부품 식별/공식 회로 근거부터 확인한다. 필요하면 안전하게 설계한 부하별 DC 측정으로 특성을 보완하되, 그 결과만으로 미확인 과도전압까지 입증하지 않는다. STM 입력을 보호하는 시험 연결은 별도 지시 전에 확정한다.
- DMM은 정지 HIGH/LOW·공급·접점 확인, LA는 디지털 전이·UART/PWM·count 대조에 사용한다. 현재 장비만으로 analog overshoot·rise/fall 파형까지 확인했다고 주장하지 않는다. 추가 파형이 수용에 실제로 필요하고 대체 근거도 없으면 MVP-007은 장비 접근 또는 입력 회로 보완 결정 전까지 미완료다. 오실로스코프 구매 자체를 이번 첫 과제로 지정하지 않는다.

**C. 부족한 단일 구동·정지 관측을 한 묶음으로 수집 (A/B 선행 PASS 후)**

- 기존 낮은 duty/공중 단일 모터 조건에서 남은 소음 관측, encoder 로그, S0 전원·PWM·실제 정지/재시작 방지를 필요한 사례에만 연결한다. 기존 양방향/timeout 시험 전체를 반복하지 않는다.
- 실제 정지 시간·거리 기록에는 보이는 기준점·영상 시간축과 신호의 대응, 측정 불확도를 명시한다. PWM0 시각이나 마지막 encoder tick을 실제 정지와 동일시하지 않는다.
- 새 데이터를 합격선 결정에 사용하면 그 회차는 baseline이며, 채택 기준에 대한 독립 확인과 구분한다. 안전 기준과 장비가 준비되기 전에 구동을 시작하지 않는다.
- 최종적으로 적용 하위 MUST와 원래 상위4항목을 대조해 충족한 행만 PASS로 갱신한다. 문서 작성/계획 합의만으로 판정을 변경하지 않는다.

### 9.3 지금의 첫 행동

사용자는 기존 전원 분리 상태를 유지한다. A의 **전력 접속부 미결 + 차단/정지 판정안** 재검토는 승인됐다. 첫 작업은 K1 주전력선 두 접속부의 적합성 해소안이다. 엔코더 기존 사진/출력 자료 대조와 시험 카드 준비는 독립적으로 가능하다.

오실로스코프 이용 불가와 기존 수용 기준 미결이 있으므로 **현재 장비로 오늘4개 전부 PASS를 약속하지 않는다.** 장애를 장비 문제 하나로 축약하거나, DMM/LA가 있으니 모든 아날로그 조건도 충족한다고 하지 않는다. 이 계획은 작업 순서이며 전원 인가·배선·구매·빌드/플래시 지시가 아니다.

도체 단면적과 피복 포함 외경은 서로 다른 치수다. 1.78mm가 도체 지름이면 피복 외경은 아직 모르며, 피복 포함 외경이라면 후보962835-3의2.4mm 하한보다 작다. 현재 정보만으로 어느 쪽인지 단정하지 않는다.55.6A와 온도 표기를 실제 하네스·단자의 허용 정격으로 그대로 채택하지 않는다.

후속으로 [사용자 구매 링크](https://smartstore.naver.com/openhw/products/8872903167)를 받았다. 웹 도구는 접근 불가, 직접 HTTP 요청은429를 반환했고 상품번호/판매자+직경 표적 검색에서도 자료를 확보하지 못했다. 상세 이미지·외경 항목은 미열람이다. 링크를 다시 요구하거나 접근 제한을 우회하지 않는다. 당시 규격표 캡처를 요청했으나 아래 사용자 외경 추정 지시로 다음 행동을 변경했다.

**현재 외경 가정과 판단:** 사용자가 “3.1~2mm되는 것 같아. 이걸로 유추해”라고 답했다. 이를 피복 포함 **약3.1~3.2mm**로 해석해 사용하며 정밀 측정/제조사 확정값이라고 하지 않는다. 기존1.78mm는 구리 도체 묶음의 직경일 가능성이 있으나 원문 정의를 확인한 것은 아니다. 이 가정에서는962835-3의 도체/피복 범위에 모두 들어가고,280756-4는 도체뿐 아니라 피복 하한3.4mm도 벗어난다. **14AWG 유지+적합 단자 교체안을 우선**하며 외경 캡처를 계속 필수로 요구하지 않는다.

소켓 호환의 추가 대조: TE의 [962835-3 제품 요약 PDF](https://www.te.com.cn/chn-zh/product-962835-3.datasheet.pdf)는 출력일2026-01-19, p2 `Dimensions`에 피복2.4~3.7mm/도체1.03~2.62mm²가 있다(별도 Rev 표기 없음). p3~4의 `Customers Also Bought`에1393310-4가 보이지만 이는 호환 승인표가 아니다. 소켓 제품 페이지는 접근 불가였으며 이번 대조에서 삽입·잠금 적합성은 입증하지 못했다. 다음 검토를 이 기계적 조합과 압착·전류 조건으로 한정한다.

**현재14AWG의 허용 전류가 부족하다고 판정한 것이 아니라 단자와의 압착 조합 문제**다. 전선을 접거나 납땜으로 채워 규격 편차를 감추는 방식을 대안으로 삼지 않는다.

두 번째 묶음의 현재 결정: 접점의 공급 차단, 잔류 rail 전압, PWM0, 실제 정지를 각각 입증한다. 기존 요구는 직접 rail 수용도 포함하므로 접점 개방만으로 자동 대체하지 않는다. DMM/LA/영상으로 확보 가능한 관측을 시험 카드로 만들되, rail 허용값/정지 허용값은 아직 채택하지 않았다. 장비 한계 때문에 얻지 못한 근거를 PASS로 만들지 않는다.

### 9.5 후속 사용자 정정 — 단자 추가 검토 중단

사용자는 넘어가자는 뜻을 반복했는데도 단자 교체 검토를 계속한 안내를 지적했다. 이 지시를 앞선 제한적 재검토 승인보다 우선한다. K1 단자 자료 수집/소켓 조사/교체 제안은 중단하고 기존 배선을 유지한다. 미결 적합성을 PASS로 처리하지 않으며 자동으로 재개하지 않는다.

지금 가능한 보완은 기존 A/B 단일 모터 정상 회전에서 비정상 소음이 있었는지 당시 사용자 관측 보고를 받는 것이다. 기존 기록에서 명시적 관측을 찾지 못한 항목만 묻고, 새 통전/반복 구동은 요구하지 않는다. 기억이 없으면 미확인으로 남긴다. 보고를 받더라도 이는 소음 관측의 후속 진술이며 T005A 선행이나 전체 MVP-005 PASS를 대신하지 않는다.

전원 차단/정지 검토에서는 기존 S0→rail 하강·S2 전 무재인가·PWM0·정지 관측을 재사용한다. 현재 rail 수용값/실제 정지 기준은 미결이며, 과거 결과에 맞춘 임의 합격선이나 새 구동 지시를 만들지 않는다.

**§9.5 후속 답변:** 사용자는 기존 정상 구동에 “비정상 소음 없었음”이라고 확인했다. 해당 질의는 종료하고 같은 소음 확인을 반복하지 않는다. REQ-MOTOR-005 기능·소음 범위 PASS, 상위 MVP-005/T-MOTOR-003의 T005A 선행 미결은 유지한다. 엔코더 기존 전압·디지털 근거를 대조했으며 출력형식·아날로그 파형을 확인한 것으로 확대하지 않는다. 다음은 공통 차단·정지 수용 기준 대조다.

### 9.8 사용자 정정 — B+ 연결선은 이미 12AWG

사용자는 “B+를 연결하는 전선은 12AWG인거 알고있어?”라고 지적했다. **MDD10A B+에 연결된 전선은 이미 12AWG라는 사용자 보고**를 현재 구성으로 반영한다. 새로 교체했다는 보고가 아니다.

9/23 보고서27 §1에는 B+를 K1 87에 연결했고 K1 주접점 배선은 14AWG라고 적혀 있었다. Codex가 이 문장을 두 주전력 구간 전체가 모두 14AWG라는 뜻으로 확대해 해석했다. 이번 사용자 진술보다 앞선 기록을 우선하거나 B+ 전선을 새로 12AWG로 바꿔야 한다고 안내하지 않는다. 다만 B+ 연결선의 굵기만으로 K1 단자 바로 옆 선재, 중간 접속 유무와 전체 구간의 동일 굵기를 새로 추정하지 않는다.

- §9.6의 두 구간 일괄 교체안과 새 단자 설치2개/총4개 수량 초안을 현재 구매안에서 철회한다. 일부 교체가 필요하다면 실제 대상이 특정된 범위에서 다시 산출해야 하며 여기서 새 수량을 확정하지 않는다.
- §9.7의 KF127 CAD 모델명은 자료 확인 사실로 보존한다. 같은 이름의 타 제조사 사양으로 현재 장착 단자가 12AWG를 수용하지 못한다거나 기존 B+ 연결이 불량이라고 단정하지 않는다. 기존 연결 사실을 제조사 승인으로 확대하지도 않는다.
- 기존 14AWG 압착부 손당김 미분리 보고는 보존하며 이번 정정을 전체 주전력 단자의 개별 검사 완료로 확대하지 않는다.
- 현재 구성 정정과 근거 범위만 갱신한다. 사진 재요청·분해·재압착·새 구매·통전·빌드/플래시는 지시하지 않으며 상위9 PASS·4 PARTIAL 유지.

### 9.9 최종 구성 확인 — K1 양쪽 12AWG

**+버스바→K1 30번은12AWG, K1 87번→MDD10A B+도 중간 접속 없는12AWG**로 사용자 확인됐다. 새 배선 변경이 아니다.280756-4 지정 도체 범위12–10AWG에 포함되므로14AWG 불일치 지적과 이에 따른 선재/단자/압착기 추가 구매·교체 요구를 철회한다. 기존 손당김 미분리 보고는 보존하고 반복하지 않는다.

- +버스바→K1 30번:12AWG.
- K1 87번→MDD10A B+:12AWG, 중간 접속 없음.
- 앞서 받은14AWG 상품 정보와 외경3.1~3.2mm를 이12AWG 선재에 대입하지 않는다. 새 도체 치수 측정이나 전체 압착 인증 완료라는 뜻은 아니다.
- 중간 접속 질문의 목적은 K1 단자에 직접 물린 선재를 특정하는 것이었다. 중간 접속 자체로 부적합/교체 필요를 판단할 수 없으며, 실제로 없는 접속부를 새 검증 과제로 만들지 않는다.
- 앞선 두 구간 교체안·설치2개/총4개 단자 구매안과14AWG 불일치에 근거한 압착기 구매 필요 주장을 철회한다. 소켓/단자 품번과 기존 손당김 관측은 유지한다.

현재 안내·메모리·전원 구성·부품 목록을 정정한다. 과거 시험 원문은 보존하고 현재 구성과 구분한다. 다음은 이미 승인된 전원 차단·실제 정지 수용 검토다. 상위9 PASS·4 PARTIAL, T005A PARTIAL/T007 BLOCKED 유지; 새 구매·배선·통전·빌드/플래시·외부 게시 없음.

### 9.10 다음 작업 — 잔류전압의 작은 부하 진단 준비

**후속 정정: 아래는 제안 이력이며 현재 실행 지시가 아니다.** 사용자 질문 후9/27·10/2의1kΩ 방전 기록을 찾아 §9.11에 반영했다. 저항 준비/추가 시험을 자동 진행하지 않는다.

목적은 **S0 후 남는 MDD 입력 전압이 알려진 작은 부하에서도 유지되는지** 확인하는 것이다. 단자 구매 검토, 같은 무부하 전압 관측 반복, 새 모터 구동과 구분한다. 아래는 진단 설계이며 기존 T005A 수용 기준을 변경한 것이 아니다.

**기존 근거 대조:** 보고서27 §5에는 제어 하네스 연결 상태의 부팅/복구 및 S0 후 전압 관측도 있다. 따라서 로직 연결 상태를 전혀 시험하지 않았다고 안내하지 않는다. 10/17에는 모터4선·제어5핀 분리 조건에서 S2 후12.03V, S0 후5초1.43V/30초0.58V를 관측했다. 같은 무부하 측정을 다시 하는 대신 알려진 부하에 대한 반응을 추가 관측한다. 서로 다른 날짜/배터리 전압의 결과를 완전히 통제된 비교로 쓰지 않는다.

**시험 부하 제안:** 보드 본체 B+↔B−에10kΩ, 정격0.25W 이상 저항 하나를 임시 병렬 연결한다. 보유 목록에는10kΩ이 확인되지만 시험에 쓸 개별 저항의 실제 값·정격은 아직 확인 전이다. 새 구매를 요구하지 않는다.3S 최대12.6V 가정에서 `I=12.6/10000=1.26mA`, `P=12.6²/10000=15.876mW`. 이는 모터 부하를 흉내 내는 저항이 아니다.

**현재 사용자 첫 행동:** 회로에서 분리된 여유10kΩ·0.25W 이상 저항을 준비하고 DMM 저항 모드로 실제 값을 읽는다. 로봇에 연결하거나 통전하지 않는다. 이 준비의 종료 조건은 해당 저항의 식별과 측정값 확보이며 T005A PASS가 아니다.

**후속 진단 카드 — 준비 확인 후 별도 안내:**

1. 배터리·USB를 분리하고 잔류 전압을 확인한 뒤 준비한다. 모터 전력4선과 MDD 제어5핀을 분리·절연하고, K1→B+와 B− 귀환은 유지한다. 기존10/17과 같은 보드/USB 분리 조건을 적용한다. 저항/절연된 측정 리드는 무전원에서 고정하며 통전 중 배선을 바꾸지 않는다.
2. 사용자 DC 전압 측정으로 S0 잠금·S2 미조작 초기값, S2 재인가 후값, S0 후5초/30초값을 한 표에 기록한다. 모터 명령은 보내지 않는다. 첫 회차는 여기서 종료하고 전원을 분리한다. 전압이 차단 후에도 공급 수준을 유지하거나 발열·연기·이상 동작이 있으면 즉시 S1 OFF/배터리 분리하고 다음 단계로 진행하지 않는다.
3. 측정값으로 저항 전류 `I_R=V/R`와 소비전력 `P_R=V²/R`를 계산한다. 부하를 걸었을 때 낮아지면 해당 조건에서 그 부하를 유지할 공급 능력이 작다는 근거다. 전압이 유지되면 누설/우회 공급 등을 추가 구분해야 한다. 커패시터·역급전 중 하나로 바로 단정하지 않으며, 이 전류가 모든 순간/부하 조건의 공급 가능 전류 상한인 것도 아니다.
4. 임시 저항은 회로의 방전 조건을 바꾼다. 저항 부착 결과를 원래 회로의 V_RAIL_OFF_MAX 충족이나 모터 정지 PASS로 소급하지 않는다. 영구 방전저항 채택은 별도 설계 결정이다. 임의1V/30초 기준은 만들지 않는다. 결과와 기존 근거로 수용 가능한 범위/필요한 변경을 판단한다.

실제 정지 시간·거리는 기존 S0 후 엔코더 마지막 전이127.32ms와 별개다. T007의 motion/time/distance 기록과 수용은 남기고, 현재 진단 전에 새 구동을 하지 않는다. 정밀 과도파형 T006은 post-MVP 유지다.

### 9.11 기존 저항 방전 관측 확인과 추가 시험 안내 정정

사용자가 “이 검증을 내가 안했던거야?”라고 물어 관련 기록을 다시 대조했다. **저항을 이용한 잔류전압 방전 확인은 이미 수행했다.**

- [보고서30 §추가 전력 관측](../verification/30_Actual_Encoder_and_Power_Bench_Closeout_2026-09-27_ko.md): 전원 분리 후0.12V, 임시1kΩ 방전 후0V. 저항은 재통전 전에 제거했다. 통전 중 다시 연결하자는 당시 안내는 사용자 지적 후 철회했으며 실행 기록이 아니다.
- [10/2 무전원 점검](../progress/2026-10-02_progress.md#무전원-점검): LiPo·USB·LA 분리 조건. MDD B+↔B−에0.27V가 남아 별도로1kΩ을 적용한 뒤0V 확인. Bar/두 buck도 방전 관측을 기록했다.

새10kΩ 제안은 배터리 연결·K1 OFF 조건의 부하 진단이므로 동일한 시험은 아니다. 그러나 기존 무전원 방전 관측을 누락한 채 새 진단을 당연한 다음 필수 작업으로 지정한 것은 잘못이다.10kΩ 준비 지시는 철회하고, 기존 완료 범위는 그대로 인정한다. 이전 방전 결과를 통전 중 모든 우회 공급 부재나 전체 T005A PASS로 확대하지 않는다. 새로운 시험의 필요성을 주장하려면 이 기존 근거로 닫히지 않는 요구와 결과에 따른 결정부터 제시해야 한다. 새 시험·구매·배선·통전 없음.
