# 모터 전류·온도 모니터링과 계측 장비 구매 마감

기준일: **2026-10-22**. [구매 완료 보고와 판단 근거](../progress/2026-10-22_progress.md), [부품/장비 대장](../../00_Project_Charter/02_Component_Inventory.md).

## 현재 확정 범위

사용자가 온도센서 2개·전류센서 2개·GM-1312·UT210E 구매 완료를 보고했다. 수령·실제 SKU·주문 구성·결제액·납기는 미확인이다. 대화 선정 후보는 온도 SEMITEC `103JT-025`, 전류 Pololu `#5241 / ACS71240KEXBLT-030B3`이며 주문품의 모델로 확정해서 회로를 만들지 않는다.

모터별 전류와 케이스 온도 각 2채널을 우선한다. GM-1312와 UT210E로 한정된 운전 조건을 관측하고, 후속 센서 ADC 로그를 비교한다. 배터리 셀별 측정, 보드별 전류 상시 채널, 추가 ADC, PSU·탑재 컴퓨터는 이번 최소 구매 범위에 넣지 않는다. 향후 PCB에는 신호 수집/보호·커넥터·시험점을 검토하되 실제 전류·부품 정격·배선과 센서 모델이 확정되기 전 전력 경로를 설계 완료로 표시하지 않는다.

## 수령 후 준비 순서

| 단계 | 준비 내용 | 완료 기준 |
| --- | --- | --- |
| 구성 확인 | 실제 센서 SKU/핀/전원/출력·GM 프로브·UT 구성 대조 | 주문품과 설명서·실물 식별 일치, 부족 부속 목록 확정 |
| 계측 계획 | 모터 한 도선의 클램프 접근, 표면 부착·절연, 주위 온도·출력/구동/휴지 기록 | 현재 배선에 적용 가능한 위치·범위·수치 중단 기준 확정 |
| 외부 관측 | [외부 온도 계획](2026-10-20_External_Temperature_Test_Plan_ko.md)에 따른 한정 관측과 기본 DC 전류 기록 | 회차별 관측값·운전 조건·한계 보존; 새 실측 전 PASS 없음 |
| 센서 연결 설계 | 실제 구매 모듈의 정격·신호 범위·STM ADC 입력/RC/보호, NTC 분압·특성 계산 | 회로·핀 배정·오차/샘플링 검토 후 사용자 구현 단계로 이동 |

클램프는 개별 모터의 한 도선만 감싸는 방법을 계획한다. MDD10A 공통 입력 전류와 모터 전류를 혼용하지 않는다. DC 표시와 순간 피크/고주파 RMS, 표면 온도와 내부 권선/접합 온도는 관측 범위를 나눠 기록한다. 외부 측정기 비교는 기본 교차 확인이며 교정 인증을 대체하지 않는다.

## 다음 세션

수령한 품목이 없으면 기존 source/증거 대조와 기록·연결 설계 준비만 한다. 수령했다면 실제 모델/구성부터 대조한다. 배선·통전·구동·빌드/플래시는 사용자 수행이고, 센서 연속 모니터링을 완료해야 기존 외부 온도 관측을 할 수 있는 것은 아니다. 지상1m는 기존 온도/정지 등 선행 조건 충족 후다. 오늘 추가 물리 시험은 없다.
