## 이미 끝난 범위

- A/M1 양수·음수10%/300ms 회전·CPS 부호·timeout 후0 복귀.
  양수 시험의 실제 전진 방향은 미확인이다.
- B/M2는 오른쪽 DIR 보정 후 실제 전진/역회전·CPS 부호·A 무동작·timeout 후0 복귀까지 확인했다.
- 원래 연결은 A/M1/JENC_1, B/M2/JENC_2다.
- 저항·도통·손회전·1560 counts/rev 보정을 다시 시작하지 않는다.

## 재개 순서

- [ ] 실제 전원 상태 확인. 마감 전원 분리 완료가 문서에 없다면 꺼졌다고 가정하지 않는다.
- [ ] 현재 ESP가 M2 역방향10%/300ms 시험 이미지인지 소스와 HELP로 확인한다.
  M2_PULSE를 입력하면 B가 역회전한다. 다음 M1 시험 명령으로 오인하지 않는다.
- [ ] 기존 USB 공급 구성(#1 보드용2P 두 개 분리·절연, STM U5V/JP1 OPEN)을 유지한다.
  ESP는 기판 밖, GPIO17/18/GND 연장과 UART 표기 USB 콘솔을 사용한다.
- [ ] 다음 준비에서 STM/ESP 부팅부터 READY·안정 TEL까지 로그를 남겨err 기준과 증가 여부를 확인한다.
  마지막 두 첨부의err=0→1439 증가 위치는 없다. 같은 run에서 계속 증가하면 원인을 먼저 확인한다.
  누적값이0이 아니라는 사실만으로 이전 시험을 실패로 바꾸지는 않는다.
- [ ] 사용자가 ESP를 M1 양수10%/300ms 단발 설정으로 변경한다.
  CMD(50,-250,300), 기대PWM100/0, M1_PULSE와 HELP/검사/로그를 함께 맞춘다.
  Codex가 당시 실제 파일의 위치와 완전한 연결 블록을 제공하고 저장 파일을 검토한다.
- [ ] 사용자가 ESP 빌드·플래시·HELP 확인. 새로운 STM 기능 변경이 없으면 STM 재빌드는 요구하지 않는다.
- [ ] 모터 몸체 고정·축 간섭 제거 상태에서 S0 잠금→전원→latch/reset→S2를 한 묶음씩 확인한다.
- [ ] M1 한 번 구동: **A가 차량 전진 방향으로 돌고 left_cps 양수**, B 무동작,
  timeout 뒤PWM0·CPS0 복귀를 로그와 육안으로 함께 확인한다.
  방향 불일치가 나오면 동력 DIR와 실제 장착 기준을 대조하고, 손회전으로 확인한 엔코더 부호를 임의로 바꾸지 않는다.

M1 확인 후에만 다음 물리 E-stop/전력단 잔여 시험의 목표와 조건을 정한다.
아직 구동 중 S0 차단·직접 rail 수용 기준·부하·주행까지 완료한 것이 아니다.
필요한 로그가 없다는 이유로 B 양방향 회전 전체를 재시험하지 않는다.

## 마감할 때

- 현재 수동 시험1U는 자동 구동이 없더라도 default-off 복구와 다르다.
  시험 코드 비활성화가 필요하면 사용자가0U 변경·빌드·플래시를 하고 무구동 복구를 확인한다.
- 펌웨어 학습 코드는 사용자 입력, 두 보드 빌드·플래시와 물리 작업도 사용자 수행이다.
- 결과는 마감 때 모아서 문서화한다. Git 커밋·푸시는 해당 작업 블록에서 요청받았을 때만 한다.
