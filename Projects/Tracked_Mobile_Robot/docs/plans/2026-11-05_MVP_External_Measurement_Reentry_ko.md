# MVP 후속 외부 계측 재개 — 2026-11-05

사용자가 오늘 PCB 학습을37-3까지로 멈추고 보유 온도계·전류계를 이용해 MVP 검증을 이어가도록 요청했다. 기존 온도/전류 후속 분리 항목의 **외부 관측 준비를 재개**한다. 전체 MVP 필수 조건으로 자동 복원하거나 T005A PARTIAL/T007 BLOCKED를 변경하지 않는다.

## 목적과 범위

현재 로봇의 전류·표면 온도를 외부 계기로 관측할 준비를 한다. 내장 ACS71240/NTC·ADC 정확도 시험은 별도이며 PCB 조립/펌웨어 구현을 선행 조건으로 요구하지 않는다. 완료한 기본 주행/1m/S0를 처음부터 재시험하지 않는다. 제외된 rail-off·제조사 문의·단일고장 시험을 재개하는 요청으로 확대하지 않는다.

연결 근거: [T-LOAD-001 기존 계획](2026-10-20_External_Temperature_Test_Plan_ko.md) · [MVP 판정41](../verification/41_MVP_Acceptance_Disposition_2026-10-24_ko.md). 기존 구동 프로파일은 후보이며 이번 장비 확인으로 승인되지 않는다. 모터/부품 표면 허용 온도·구동 시험의 수치 중단 기준은 여전히 미확정이다.

## 현재 단계 — 제한된 공중 관측 후 회차 종료

GM1312 T1=A/T2=B·UT210E20A DC를 사용해 M1B/M2B 각각 전진·후진을 짧게 관측했다. 최종 사용자 전원 분리 완료. [보고 전사·JSON/CSV·정정/한계](../../assets/logs/mvp_measurements/2026-11-05_external_current_temperature_air_run01/README.md)가 실제 실행 근거다.

| 관측 | 전진 / 후진 전류 표시 | 온도/상태 |
| --- | --- | --- |
| M1B | −0.18 / +0.18A | 전진 후26.7/26.7°C. 후진은 T1 26.6→26.7°C, T2 별도 미보고 |
| M2B | +0.20 / −0.23A | 정정 반영한 전진 후 및 후진 후 T1 26.9/T2 27.0°C, 정지/DISARM 정상·이상 없음 |

동작당1초 이내를 안내했으며 실제 시간을 계측하지 않았다. 두 설치의 무구동 표시−0.01A는 그대로 남긴다. 60초 정지 대기는 M1B에서만 보고됐다. 표면 접점/테이프 고정은 사용자 확인이며 정격 절연·열 접촉 정확도는 미검증이다.

정식 T-LOAD-001의 구동/휴지·정량 중단/수용 기준은 여전히 미확정이다. 위 관측을 장시간 발열/정격 하중/PWM 피크·RMS/내장 센서 정확도 PASS로 기록하지 않는다.

UT210E 근거는 보유 **UNI-T UT210E Operation Manual, P/N110401104880X, MAY2018 REV2, PDF1쪽 오른쪽 VIII.3의2)DC**, ZERO·SELECT·빈 집게/측정 방향 설명이다. [설명서](../../assets/datasheets/UNI-T_UT210E_User_Manual.pdf). 도구로 원문 이미지를 확인했다. 계기 리드를 빼고 집게를 완전히 닫아 무전류 상태에서 영점을 맞춘다. 모터/자석에서 떨어져 같은 방향으로 유지하고 값과 변동을 기록한다.10초는 이번 표시 관찰 구간이며 제조사 정확도 보장 시험 시간이 아니다.

## 이후 순서

1. 오늘 실물 작업은 종료하고 전원 분리 상태를 유지한다. 자동으로 구동 시간/출력을 늘리지 않는다.
2. 사용자 요청대로 마감 후 NotebookLM01단원 자료 업로드·프로듀서 메모 검토를 안내한다. PCB 학습은37-4부터 재개한다.
3. 다음 실물 회차를 요청하면 주위 온도·표면 접촉·구동/휴지/출력·근거 있는 중단/판정 기준을 먼저 정한다. 오늘의 낮은 표시 온도를 열적합 근거로 쓰지 않는다.
4. ACS71240/103JT-025 센서 포함 시험과 이번 외부 계기 관측을 분리한다. 기존 MVP 미결/제외 범위를 변경하지 않는다.
