## 실제 구현 시 구분할 교차와 겹침

아래는 모두 부품면 좌표다. Wire 중간은 절연된 선이며, 같은 좌표에 그려져도 다른 Net과
접속하지 않는다. 접속점의 노출 도체를 납땜한 다음 통과하는 선을 약간 띄우거나 옆으로 피한다.
같은 홀에 다른 Net의 벗긴 선 두 개를 넣지 않는다. 부품/모듈 아래에서는 억지로 여러 층을 눌러 넣지 않는다.

| 위치 | 겹치는 신호 | 제작 시 처리 |
| --- | --- | --- |
| C30/R3 | INT 접속점 ↔ RST 점퍼 몸체 | INT 접속부를 먼저 마감하고 RST 피복을 유지 |
| C30/R7 | SDA 접속점 ↔ INT 점퍼 몸체 | SDA 접속부 접근을 먼저 확보하고 INT 피복을 유지 |
| R14, C30~37 | IMU INT ↔ 기존 DIR1 | 접속점이 아닌 겹침 구간. 새 점퍼를 기존 선에서 분리해 배치 |
| R15, C29~37 및 C39~40 | IMU RST ↔ 기존 PWM1 | 길게 겹친 선과 각 끝점에서 피복 손상·납땜 접촉 방지 |
| C4, R26~33 | ENC1_B ↔ ENC2_B | 서로 다른 절연선. 한쪽을 옆으로 비켜 서로의 끝점을 가리지 않게 배치 |
| C43~46/R4, C40~43/R3 | CTRL 분기 ↔ 기존 DIR/PWM | 기존 선을 벗기거나 교차 위치에 공통 납땜점을 만들지 않음 |
| C29/R35 | UART GND 끝점 ↔ ESP 5 V 점퍼 몸체 | GND 접속부를 먼저 마감하고 5 V 피복 유지, 새 단락 검사 |

위 표는 이번 작업에서 특히 접근이 어려운 위치다. 그 외 서로 다른 Net의 Wire 교차도 같은
절연 원칙을 적용한다. 납땜 인두로 기존 선의 피복을 누르거나 교차점을 납으로 이어 붙이지 않는다.

### 9/18 수정본 대조 — CTRL/ENC 3핀 두 개

- 이전 이름으로 다시 저장된 사용자 지정 CTRL수정본이 9/16 IMU_WIP보다 최신이다.
  두 파일을 합치거나 덮어쓰지 않았으며, 앞으로 실제 작업 기준은 사용자 지정 CTRL수정본이다.
- JDBG_CTRL_1은 C35/R1~3, JDBG_CTRL_2는 C35/R5~7이다. 두 부품 사이 C35/R4는 빈 홀이다.
  CTRL_2 Pin2(C35/R6)는 PC7이며 GND가 아니다. GND는 CTRL_2 Pin3(C35/R7)다.
- JDBG_ENC_1은 C9→C7/R37, JDBG_ENC_2는 C5→C3/R37이다. 두 부품 사이 C6/R37은 빈 홀이다.
- UART와 IMU 헤더 좌표·배정은 유지된다. CTRL/ENC의 모든 신호는 지정 MCU에 연결되며,
  다섯 디버그 GND 점도 공통 GND에 연결된다. 기존 Wire 132개 중 7개의 끝점이 변경됐고 추가/삭제는 없다.
- 이 대조는 도면 검토 결과다. 이후 CTRL의 사용자 무전원 검사 결과는 아래에 기록한다. ENC 실물 검사는 미보고다.

  JDBG_IMU는 6핀 한 개이며 Pin1이 아래, Pin6이 위다. Pin5(C45/R11)는 미사용이고 Pin6 GND는 완료 상태다.
- 안내한 검사 범위 PASS: 각 JDBG 신호 핀↔해당 STM/BNO 소켓 도통; 네 신호 상호,
  각 신호↔GND 및 미사용 Pin5 비도통. IMU Pin2(INT)↔CTRL_1 Pin1(DIR1) 및
  IMU Pin1(RST)↔CTRL_1 Pin2(PWM1) 비도통도 포함한다. 개별 저항 수치는 미보고다.
- BNO VCC·모드·풀업은 별도 미완료다. 이번에는 센서 모듈을 꽂거나 전원을 인가하지 않는다.
  위 결과는 배선의 무전원 검사이며 센서 동작·전원 인가·T004 PASS가 아니다.

## 헤더 방향과 도통 검사 지점

좌표는 모두 현재 VRT의 부품면 기준이다. STM/ESP/BNO는 제거한 상태에서 **소켓 접점**을 잰다.
멀티미터 리드를 먼저 서로 접촉해 기준 저항을 확인하고, 직접 배선 경로는 그 값에 가까운 안정된 저항과 도통을 기대한다.

| 헤더 | 현재 방향 | 핀별 기능과 확인할 소켓 |
| --- | --- | --- |
| JDBG_UART | C26→C28/R37, 왼쪽이 Pin1 | 1=STM PA9(C16/R5)↔ESP GPIO18(C42/R26); 2=STM PA10(C22/R5)↔ESP GPIO17(C43/R26); 3=GND |
| JDBG_CTRL_1 | C35/R1→R3, 위가 Pin1 | 1=DIR1/PC8(C6/R4); 2=PWM1/PB6(C14/R5); 3=DIR2/PC9(C6/R5) |
| JDBG_CTRL_2 | C35/R5→R7, 위가 Pin1 | 1=PWM2/PB7(C16/R29); 2=PC7(C15/R5); 3=GND |
| JDBG_ENC_1 | C9→C7/R37, 오른쪽이 Pin1 | 1=ENC1_A/PB4(C19/R5); 2=ENC1_B/PB5(C20/R5); 3=GND |
| JDBG_ENC_2 | C5→C3/R37, 오른쪽이 Pin1 | 1=ENC2_A/PA0(C19/R28); 2=ENC2_B/PA1(C20/R28); 3=GND |
| JDBG_IMU | C45/R15→R10, 아래가 Pin1 | 1=RST/PC4(C22/R4)↔BNO C33/R3; 2=INT/PB1(C17/R4)↔BNO C33/R4; 3=SDA/PB9(C8/R5)↔BNO C33/R7; 4=SCL/PB8(C7/R5)↔BNO C33/R8; 5=NC; 6=GND |

- GND 기준은 STM 소켓 C15/R4다. JDBG_IMU Pin6은 BNO 소켓 C33/R9와도 이어져야 한다.
- JDBG_IMU Pin5(C45/R11)는 미사용으로 유지한다.
- 각 기능을 마친 뒤 해당 신호끼리, 신호↔GND, 새 배선과 인접 전원 사이에 예상치 못한
  저저항 단락이 없는지 검사한다. 기존 CTRL의 풀다운/PC7 풀업 등 정상 저항 경로를 고려하며
  모든 신호가 GND에 무조건 OL이어야 한다고 판단하지 않는다.
- 잘못된 핀 도통, 설계에 없는 저저항 접속, 패드 들뜸, 피복 녹음, 모듈/커넥터 간섭이 있으면
  해당 구간에서 멈추고 바로 수정한다. 정상인 다른 기능 전체를 다시 검사하는 절차로 확대하지 않는다.

## 납땜 이후의 경계

- BNO 전원·풀업·모드 설정을 확인하기 전에는 BNO 모듈을 빼 둔다. 향후 STM32를 켤 때도 같다.
  BNO08x IC의 로직 핀 최대 전압은 VDDIO+0.3 V다. 실제 GY 모듈의 입력 격리 회로는 확인되지 않아
  미전원 모듈에 MCU 신호를 인가해도 안전하다고 전제하지 않는다.
  근거: [BNO08x 데이터시트 §6.1](https://www.ceva-ip.com/wp-content/uploads/BNO080_085-Datasheet.pdf).
- I2C 배선과 측정 분기의 전기적 연결은 확인했지만 통신 품질은 별도다. 불필요한 여분 선을 감아 두지 않고,
  사용하지 않는 분석기 케이블은 제거한다. 향후 실제 모듈 풀업과 SCL/SDA 파형을 확인한다.
  배선·접속·핀의 총 정전용량이 풀업과 상승시간에 영향을 준다는 근거는
  [NXP UM10204 §7.1](https://www.nxp.com/docs/en/user-guide/UM10204.pdf)다.
- JDBG_ENC는 MCU 측 측정점이다. 원시 엔코더 입력용 커넥터를 대신하지 않는다.
  기존 입력 계약의 1 kΩ 직렬 및 MCU 노드의 15 kΩ GND 경로와 실제 입력 커넥터는 별도 설계·구현한다.
- 이번 무전원 제작 완료는 IMU 동작, 센서 입력 회로, 모터 구동 또는 T004 PASS를 의미하지 않는다.
  다음 전원 인가/빌드/플래시는 기존 T004 절차와 사용자 수행 원칙을 따른다.
