# 외부 온도 관측 계획 — T-LOAD-001

**2026-10-23 최신 상태: DEFERRED / NOT_RUN.** 사용자 결정으로 온도 검증을 이번 MVP 필수에서 후속으로 분리했다. 기존 MG540 모터를 유지하며 본 계획의 장비·온도 기준 대기를 지상1m/MVP 선행 조건으로 사용하지 않는다. 아래 준비 절차와 철회 이력은 재개 참고용이고 열적 적합 PASS 또는 구동 시간/출력 확대 근거가 아니다. [범위 결정](../progress/2026-10-23_progress.md#기존-모터-유지와-온도-검증-후속-분리).

작성: 2026-10-20. 연결: `ST-MVP-04`, `TK-MVP-04-01~04`, `REQ-THERM-001`, `MVP-015`.

**상태: 근거 없는 온도 수치 초안 철회 / 장비 수령·실물 부착·근거 기반 기준 확정 대기(10/22 갱신).** 이전 GM-1312 주문은 재고 취소됐고10/22 사용자가 온도센서2·전류센서2·GM-1312·UT210E 구매 완료를 보고했다. 실제 수령·열전대/건전지·부속 구성·최종 납기는 미확인이다. [구매 기록](../progress/2026-10-22_progress.md), [계측/센서 준비](2026-10-22_Motor_Current_Temperature_Monitoring_and_Procurement_ko.md). 아래 절차는 실행 전 후보이며 실제 수행은 준비 확인 후 한 단계씩 안내한다.

## 1. 확인할 것과 현재 기준

현재 저속 설정에서 대기·전진·후진·양방향 회전 중 **지정한 표면의 온도 변화와 이상 동작**을 기록한다. 전류/전압 ADC는 필요하지 않다. 전력 여유, 내부 권선/반도체 접합 온도, 장시간 연속 운전·정격 하중을 검증하는 시험은 아니다.

- STM/ESP 기준점: [source·이미지 대조](../../assets/logs/wifi_link/2026-10-20_acceptance_image_identity_review/manifest.json). 이후 변경이 있으면 영향 항목을 검토한다.
- 전진 PWM 좌/우 `144/150`, 후진 `-140/-150`, 좌회전 `-200/+200`, 우회전 `+200/-200`‰. 실제 TEL로 적용값을 확인한다. 요청 `vx=±100`, `w=±500`은 실측 속도가 아니다.
- 기존 LiPo 단독 전원·각 궤도 한 링크 단축 구성 유지. 모터는 왼쪽 M1/JENC1, 오른쪽 M2/JENC2로 식별한다.
- [공중 명령선 단절 정지](../../assets/logs/wifi_link/2026-10-20_uart_tx_disconnect_timeout_air_run01/observations.json)와 [재연결 무동작·수동 복구](../../assets/logs/wifi_link/2026-10-20_uart_tx_reconnect_recovery_air_run01/observations.json)는 완료했다. 온도 준비를 이유로 반복하지 않는다.
- 10/20 사용자 ESP 원래 장착 복원·배선 경로 확인과 알람·주전원 분리 완료를 보고했다. 외부 점퍼는 앞선 UART 단절 시험 때의 구성이다. 온도 시험 시 실제 배선·통풍·기판 배치를 사진으로 기록한다. 배치가 달라진 결과를 최종 장착 상태의 온도로 간주하지 않는다.

## 3. 측정 위치와 고정 후보

두 채널이므로 아래 쌍을 **별도 회차**로 측정한다. 사진에 실제 접촉점을 표시하고, 접촉 재료·위치·리드 경로를 기록한 뒤 고정한다.

| 쌍 | T1 / T2 지점 ID | 부착 후보 | 확정에 필요한 확인 |
| --- | --- | --- | --- |
| A 모터 | `MOTOR_L` / `MOTOR_R` | 두 모터의 고정된 원통형 케이스에서 서로 대응하는 위치 | 축·기어·단자와 간섭 없음, 케이스와 프로브 절연 상태, 두 위치 사진 |
| B 드라이버 | `MDD_M1` / `MDD_M2` | MDD10A 각 채널 전력 소자의 절연 몰딩 표면 | 실제 소자/채널 식별, 닿을 수 있는 면, 노출 금속/핀과 이격 및 프로브 절연 |
| C 전원부 | `BUCK_1` / `BUCK_2` | 각 XL4015 모듈의 대응하는 IC 절연 몰딩 표면 후보 | 실물에서 접근 가능한지, 방열판/부품 간섭, 실제 전기적 절연 |

이 위치들은 **최고 온도 지점으로 검증된 것이 아니다.** 접근할 수 없으면 무리하게 끼우지 않고 대체 지점을 정해 이름·사진·해석 범위를 바꾼다. 모터 케이스 온도는 권선 온도와 다르고, 모듈 한 점은 전체 모듈의 최고 온도를 대표하지 않는다.

고정은 전원 차단 상태에서 한다. 프로브 제조사가 허용하는 표면 접촉·절연 방법을 우선하며 얇은 내열 절연 테이프는 고정 후보일 뿐이다. 테이프 한 겹을 검증된 전기 절연으로 간주하지 않는다. 접촉면 사이 절연재는 열 전달 지연/오차를 만들 수 있으므로 재료와 층수를 기록한다. 금속 클립으로 노출 단자나 소자를 물리지 않는다.

**XL4015 금속 탭은 SW 노드다.** 노출 탭이나 연결된 방열판을 GND로 가정해 맨 열전대 접점을 붙이지 않는다. 전원부 측정은 실물 접촉점과 절연 사양 확인 후 확정한다. [XL4015 데이터시트, p.2](https://www.xlsemi.com/datasheet/XL4015-EN.pdf)

리드는 회전부·궤도에서 떨어뜨려 고정하고 프로브 접점에 당김이 걸리지 않게 한다. 지상 회전에서는 차체 밖 리드가 감기거나 차체를 당기지 않는 구성이 필요하다. 계측기/리드를 차체에 실으면 추가 질량·위치를 기록하고 전자회로/통풍구를 덮지 않는다. 조종자가 움직이는 차체 옆에서 프로브를 손으로 대는 방식은 사용하지 않는다.

주위 온도는 같은 장소의 열원·직사광선을 피한 공기에서 **각 회차 전후** 별도로 기록한다. T1/T2를 모두 부품에 붙인 동안의 주위 온도는 동시 측정값이 아니다. 프로브 이동 후 값이 안정된 시점과 소요 시간을 남긴다.

## 4. 짧은 주행 프로파일 후보

아래 시간/반복 수는 **프로젝트 시험 설계 초안**이다. 제조사 정격 시험이 아니며 장비 수령 후 응답 지연·설치·이동 공간과 온도 중단 기준을 확정한 다음 실행한다. 현재 PWM 제한을 올리지 않는다.

| 단계 | 조건·후보 시간 | 관측과 다음 단계 |
| --- | --- | --- |
| 설치 점검 | 전원 차단 상태에서 부착·리드 고정, 사진/지점 ID 기록 | 절연·간섭·이동 여유 확인 후에만 통전 |
| 준비 | READY / DISARMED / IDLE, PWM/CPS 0, 관찰 스크립트 v5 설치 | 같은 회차 ID로 온도 기록·영상·브라우저 로그 연결 |
| 공중 점검 | 양 궤도 공중, 전진 최대 1초 1회 후 놓음 | 새 프로브 고정/리드 간섭만 확인. 기존 정지 시험 재인수가 아니며 지상 발열 결과와 분리 |
| 지상 대기 | 정상 장착·안정된 바닥, DISARMED 60초 이상 | 시작 온도와 최근 30초의 변화 기록. 계속 변하면 대기 연장 |
| 짧은 구동 | 전진 → 후진 → 좌회전 → 우회전, **각 최대 2초**, 사이마다 정지 관측 **30초 이상** | 각 동작의 실제 시간·PWM/CPS·온도·실제 움직임 기록. 공간 부족 시 더 일찍 놓고 실제 시간 기록 |
| 반복 | 위 네 동작 묶음 **2회** 후보 | 두 번째 묶음 직전 온도 기록. 잔열이 있으면 누적 조건으로 해석 |
| 종료 관측 | DISARMED 후 **120초 이상** 온도 기록 | 정지 후 늦게 나타나는 최고 관측값 포함. 상승이 지속되면 정상 종료로 처리하지 않음 |

각 A/B/C 쌍은 같은 순서·표면·전원/궤도 조건으로 진행한다. 다른 쌍으로 옮길 때 전원을 끄고 부착을 바꾼다. 새 회차 시작 온도와 주위 온도가 앞 회차와 다르면 그 차이를 기록하며 서로 다른 회차의 값으로 동시 좌우/부품 온도 차이를 계산하지 않는다.

2초 펄스로 온도 변화가 작거나 프로브 응답이 늦으면 **그 짧은 조건에서의 관측 한계**를 남긴다. 이를 열평형/장시간 안전성으로 확대하지 않는다. 임의로 시간을 늘려 열을 만들지 않으며 추가 운용 범위가 필요하면 별도 프로파일을 정한다.

시험 중 온도 표시를 관측할 사람/배치가 필요하다. 영상은 사후 전사를 돕지만 실시간 중단 감시를 대체하지 않는다. 혼자서 조종·표시 확인·주행 공간 감시를 동시에 할 수 없는 배치라면 관측자를 두거나 배치를 바꾼다. 주행 중 DevTools로 포커스를 옮겨 기록하지 않는다.

## 5. 중단 기준과 판정

다음은 숫자와 무관하게 즉시 중단한다: 명령 중 한쪽 궤도가 지속 정지/거의 움직이지 않음, 의도하지 않은 동작, 통신/전원 이상, 프로브 이탈·리드 간섭, 센서 단선/표시 소실, 냄새·연기·변형·LiPo 알람. 정상 입력으로 멈추지 않으면 기존 S0 절차를 따른다. 정지 후 잔열에 의한 상승도 관측하되, 사전 중단 기준에 도달하면 통전을 중단하고 원인을 검토한다.

**수치 온도 기준은 아직 미확정이다.** 실물 시험 전 지점마다 `중단 온도`, `회차 판정 기준`, `근거/여유`, `프로브·고정재 제한`을 세션 양식에 채운다. 제조사 제한과 측정 표면이 다르면 그대로 변환하지 않는다. 자료가 없으면 그 사실과 프로젝트의 보수적인 시험 제한 근거를 명시해 먼저 정한다. 빈 기준표로 구동 시험을 시작하거나 사후 측정값에 맞춰 PASS 기준을 만들지 않는다.

| 대상 | 현재 근거와 남은 일 |
| --- | --- |
| MG540P30_12V 모터 | 2026-08-17 제조사 회신 원문에서 온도 데이터 미제공을 명시한 사실을 재확인했다. 8/18 회신에도 온도 조건이 추가되지 않았다. 케이스/권선 한계와 운전 조건 미확정 |
| MDD10A | 제조사 매뉴얼의 전류 정격은 주위 25°C 시험 조건을 명시한다. 이를 모듈 표면 허용 온도로 해석하지 않는다. [Cytron 매뉴얼, p.5](https://makermotor.com/content/cytron/pn00218-cyt4/MDD10A%20User%27s%20Manual.pdf) |

### 수치 초안 철회와 근거 공백 — 2026-10-22

**상태: WITHDRAWN / NOT_RUN / 온도 기준 미확정.** 사용자가 수치의 근거를 질문했다. Codex가 앞서 제안한40/45°C·시작 대비+10/+15°C 및 초기 표면/주위 차이5°C 조건은 제조사 허용값·열모델·실측·정량적인 측정 불확도/여유 계산으로 뒷받침되지 않은 임의 선택이었다. 초기 시험 제한 후보로 제시한 것을 철회한다. 낮게 보이는 숫자라도 안전성이나 적정성을 보증하지 않으며, 실행/합격/중단 기준에 재사용하지 않는다.

[Nidec 열저항 설명](https://www.nidec.com/en/products/small-precision-motors/technology/motor/glossary/item/thermal_resistance/)과 [maxon NTC 측정 설명](https://support.maxongroup.com/hc/en-us/articles/360007861394-Temperature-sensor-NTC)은 권선/표면 온도차와 측정 지연을 설명하는 원리 참고다. 이 로봇의 허용 온도나 위 수치의 근거가 아니다. 다른 제조사 모터의 온도 한계를 MG540에 대입하지 않는다.

확보된 근거는 [사양 요약](../../assets/datasheets/QUICK_REFERENCE_ko.md)의 제조사 회신/부품/계측기 조건까지다. UT210E 정확도 조건23±5°C는 계측기 적용 조건으로 유지하되 모터 열 안전 범위로 사용하지 않는다.

온도 기준을 정하려면 모터의 케이스 또는 권선 허용 온도와 운전 조건을 확보해야 한다. 드라이버/전원부는 실제 측정점과 소자/모듈 한계를 연결하고, 접합/표면 차이·프로브/접촉 오차·응답 지연을 고려해야 한다. 근거가 부족하면 허용 온도 수용 판정을 미결로 남긴다. 추가 자료 없이 다른 숫자로 대체하지 않는다.

기존 각 최대2초 구동·휴지30초 이상·종료 관측120초 이상도 **미실행 프로파일 초안**이다. 온도 제한 철회로 이 시간을 검증/승인한 것으로 해석하지 않는다. 온도/전류의 관측값 기록과 정격 적합성 입증을 구분하고, 계측기 수령만으로 허용 온도 근거가 생긴다고 판단하지 않는다.

### 기준 확정에 필요한 결과와 준비한 문의

가장 직접적인 근거는 **해당 모델의 지정된 케이스 측정점에 대한 허용 온도와 적용 운전 조건**이다.
제조사가 권선/접합 한계만 제공하면 실제 측정점에서 그 내부 온도를 추정할 열 특성이나
검증 결과가 더 필요하다. 여기에 실제 프로브·접촉에 의한 과소표시, 응답 지연 및 정지까지의
추가 온도 상승을 평가해 기준을 정한다. 측정값의 반복성이나 두 채널의 일치만으로 허용 한계가
새로 생기는 것은 아니다.

다음 문안은 기존 WHEELTEC 문의 스레드에 보낼 수 있도록 준비한 **로컬 초안 / 미발송**이다.
전체 원본 메일이나 개인 연락처를 저장하지 않고 필요한 기술 내용만 정리했다.

```text
Subject: MG540P30_12V — case temperature limits and continuous-duty conditions

Hello,

I am following up on your August 17, 2026 reply, which stated that temperature
data was not available. I use two MG540P30_12V motors (1:30, Hall encoder) in
a tracked robot and am preparing external case-temperature measurements.

Could your motor supplier or engineering team confirm:
1. Maximum permissible continuous motor-case temperature, the exact measurement
   location, and applicable ambient temperature and mounting/cooling conditions?
   Please distinguish the motor body from the gearbox and encoder limits.
2. Whether the 12 V / 1.44 A rated operating point is continuous duty, and under
   what ambient/load/cooling conditions; if intermittent, the permitted run/rest
   cycle. Are additional restrictions needed for approximately 19 kHz PWM?
3. If no case limit is available, the maximum winding temperature and any thermal
   data or validated method that relates case measurements to winding temperature?

Please provide model-specific documentation, or identify which values remain
unavailable. We do not plan to perform a stall test or treat 9 A as continuous.

Thank you.
```

MDD10A는 실제 보드 revision과 부품 측정점을 명시해 Cytron에 표면 측정 기반의 권장 제한과
열 보호 적용 여부/조건을 확인할 필요가 있다. XL4015는 IC 자료에 더해 실제 모듈의 방열 구조와
다이오드·인덕터 등 부품 식별이 필요하다. 이번 조사에서는 실물 식별이나 신규 제조사 회신을
확보한 것으로 처리하지 않는다.

제조사가 수치를 제공하지 않으면 허용 온도 적합성은 계속 미확정이다. 관측 가능한 표면의
온도 이력을 수집하는 목표와 열적합성 입증은 구분하며, 그에 따른 MVP 수용 범위 변경을
이번 조사만으로 자동 승인하지 않는다. T-LOAD-001은 NOT_RUN, 기존 지상 1m 선행 조건은 유지한다.

결과는 다음처럼 구분한다.

- `NOT_RUN`: 장비/설치/기준 미확정 등으로 미실행.
- `INCONCLUSIVE`: 표시 누락·접촉 불확실·조건 불일치 등으로 판정 불가.
- `STOPPED`: 사전에 정한 중단 조건 발생. 원인과 끝까지 관측한 범위 기록.
- `PASS_DECLARED_PROFILE`: 필요한 지점/동작/반복의 유효 데이터와 실제 움직임을 확보했고, 사전 기준을 만족한 **선언한 프로파일에 한정한** 판정.

`T-LOAD-001` 최종 판정은 [검증 매트릭스](../verification/05_Final_MVP_Requirements_and_Verification_Matrix_ko.md)를 갱신할 때 근거와 함께 결정한다. 지금은 PLANNED를 유지한다. 지상 1m의 기존 기본 온도 판정 선행 조건도 유지한다.

## 6. 기록 방법

[세션 양식](templates/temperature_session_template_ko.md)을 복사하고 [CSV 헤더](templates/temperature_readings_template.csv)에 실제 관측만 추가한다. 템플릿의 빈칸은 미측정이며 0°C가 아니다.

- 회차별 `run_id`, 지점/프로브/채널 ID, 사진, firmware 기준점, 공중/지상·전원·궤도·바닥·추가 계측기 질량, 시작/종료 주위 온도와 셀 전압(실제 읽었을 때만)을 남긴다.
- 영상 기준 준비 완료, 구동 시작/놓음, 실제 정지, 온도 표시 시점을 기록한다. 대기·휴지에는 10초 간격 전사를 기본 후보로 하고 구동 전후·최고 관측 시점을 추가한다. 2초 내 표시 변화가 없더라도 보간한 온도를 만들지 않는다.
- `elapsed_s`는 해당 온도 회차의 시작 기준이다. `video_s`, `browser_ms`는 다른 시계다. 구동/PWM 변화 등 공통 사건으로 대응시키고 오차를 기록한다. 대응을 모르면 해당 칸을 비워 둔다.
- 브라우저 로그는 기존 v5를 사용하며 정지 후 `copy(g6StopObserve.report())`로 회차별 저장한다. ring buffer 유실 여부를 확인하고 과거 자료가 모두 남았다고 가정하지 않는다.
- 지점별 시작값 `T0`, **최고 관측값** `Tmax`, `ΔT=Tmax−T0`, 종료값, 실제 구동/휴지 시간, 이상 여부를 표에 정리한다. `ΔT`는 시작 표면 대비 변화이며 주위 온도 대비 상승과 구분한다.
- GM-1312 표시 분해능을 전체 측정 정확도로 쓰지 않는다. 센서·접촉·고정·표시 갱신·전사 간격 때문에 실제 최고 온도를 놓칠 수 있다. 2채널의 다른 회차 결과를 하나의 동시 열 지도로 합치지 않는다.

## 7. 다음 실행점

계획·기록 양식·공개 자료 조사와 WHEELTEC 추가 문의 초안은 준비했다. `TK-MVP-04-02`는 **초안 준비 / 실물 부착·수치 기준 미확정**, `TK-MVP-04-01/03`은 장비 대기다. 기준 확정에는 모델별 허용 온도와 운전 조건의 추가 근거가 필요하다. GM-1312 수령 후 프로브·고정재·측정 위치 확인은 별도 준비 항목이며 제조사 근거 공백을 대신하지 않는다. 새 제조사 문의 발송과 실제 구동은 수행하지 않았다. 추가 ADC 구현이나 전류계 구매를 선행 작업으로 넣지 않는다.
