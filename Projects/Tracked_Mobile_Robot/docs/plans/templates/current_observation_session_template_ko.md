# 외부 모터 전류 관측 — 작성 전 템플릿

상태: **NOT_RUN / 실행 전 기준 미확정**. 장비 도착 전 문서 준비용이다. 실제 회차 폴더에 복사해 사용한다. 빈칸은 미측정이며0A로 채우지 않는다.

[계측/센서 준비 계획](../2026-10-22_Motor_Current_Temperature_Monitoring_and_Procurement_ko.md), [온도 세션 양식](temperature_session_template_ko.md), [전류 CSV 헤더](current_readings_template.csv)를 함께 사용한다. 온도 절차/중단 조건을 중복 작성하지 않고 같은 회차 ID로 연결한다.

미확정 기준·설치/관측 조건이 남으면 구동 전 준비로 유지한다. 정격1.44A·스톨9A는 제조사 회신의 모터 수치이며 이 양식의 자동 중단값이나 스톨 시험 지시가 아니다. 별도 검토 없이 구동 시간을 늘리지 않는다.

## 한 대의 UT210E로 기록하는 순서

1. 실제 설명서/구성 확인과 영점·정지 중 표시 점검을 먼저 기록한다. 수령 전에는 수행 완료로 표시하지 않는다.
2. 선택한 모터 **한 도선**의 표시를 고정된 배치/관측자로 기록한다. 두 도선을 함께 감싼 값을 모터 전류로 사용하지 않는다. 열전대는 기존 온도 양식의 T1/T2 위치를 따른다.
3. 좌우를 모두 관측하려면 클램프 이동은 정지·전원 차단 상태에서 하고 별도 run_id로 남긴다. 회차를 pair_id로 묶고 시작 온도·전원·운전 조건 차이를 기록한다. 두 회차 값을 동시 측정으로 합치지 않는다.
4. 기존 짧은 프로파일에서 실제로 표시가 잡힌 구간만 기록한다. 갱신이 늦어 읽지 못한 구간은 `MISSING`/`INCONCLUSIVE`이며 기동 피크0A로 쓰지 않는다. HOLD는 붙잡은 표시일 뿐 피크 검출 기능으로 취급하지 않는다.
5. 종료 후 영점 변화와 실제 최종 상태/전원 종료를 기록한다. 관측하지 않은 시간·상태를 채우지 않는다.

이 순서는 시험 준비 항목이며 현재 통전 지시가 아니다. 외부 UT210E/GM-1312 기본 관측은 보드 센서 설치·ADC 구현과 분리해 준비할 수 있다.

## 데이터 의미

CSV에는 `measurement_point=MOTOR_L` 또는 `MOTOR_R`, `quantity_kind=DC_DISPLAY`를 명시한다. 모터 단자 전류·MDD 공통 입력 전류, 평균 DC 표시·PWM RMS·순간 피크를 혼용하지 않는다. `max_observed_display_A`는 관측한 표시의 최대값이며 전기적 순간 피크가 아니다.

`video_s`·`browser_ms`는 대응이 확인된 경우만 입력한다. 브라우저 상태/PWM/CPS는 실제 같은 구간의 TEL에서 전사한다. 수동 기록을 위해 조종 중 브라우저 포커스를 옮기지 않는다. 온도는 기존 CSV에 기록하고 같은 run_id·시간 대응 근거로 연결한다.

## 요약과 판정

| 항목 | 기록 |
| --- | --- |
| 실제 방향·구동/휴지 시간 / 유효 관측 구간 | |
| 대기 표시 / 구동 중 대표 표시와 선택 구간 / 최고 관측 표시·시각 | |
| 영점 전후 변화 / 범위 초과·누락·변동 / 비교 회차 조건 차이 | |
| 같은 회차의 온도 기록·최고 관측·사전 기준 비교 | |
| 관측한 이상 / 중단 사유 / 실제 최종 DISARMED·출력/CPS0·전원 종료 | |
| 결과 NOT_RUN / INCONCLUSIVE / STOPPED / 선언한 범위의 관측 완료와 근거 | |

센서 ADC값 비교·정량 정확도·고주파 RMS·기동 피크·장시간 열 수용과 전체 MVP 판정은 이 표의 완료만으로 성립하지 않는다. 출력이나 부하 허용 범위를 사후 관측값에 맞춰 확장하지 않는다.
