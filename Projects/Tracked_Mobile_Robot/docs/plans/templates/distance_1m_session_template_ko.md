# 1m 거리 비교 준비·기록표 — T-ODO-001

작성: 2026-10-20. `TK-MVP-03-05` / `REQ-ODO-001` / `MVP-011`.
**현재 NOT_RUN. PC 기록표 준비이며 지금 주행하라는 지시가 아니다.** 기존 정지 검증과 기본 온도 판정, 실제 실행 준비가 충족된 뒤 사용한다. 빈칸은 미측정이다.

이번 기준선은 현재 직진 보정 전진0.96/후진0.93과 일반 cap15%를 유지한다. 최대 전진 명령의 PWM은 좌/우144/150‰, 후진은−140/−150‰이며 실제 TEL과 회차의 source/이미지를 확인한다. 먼저 전진 기준 회차를 남기고 후진은 별도 ARM·별도 실측으로 기록한다. 이 시험에 동일 PWM 단계 비교나 IMU 보정을 섞지 않는다.

## 측정 방법

1. 평평한 바닥에 시작선과 목표 1,000mm 지점을 표시한다. 측정 도구·눈금·표시 방법과 주행 여유 공간을 기록한다.
2. 좌우 궤도 사이 차체 중심선 위의 고정 기준점을 정해 사진에 표시한다. 같은 점의 바닥 투영을 시작과 정지 후에 읽는다. 궤도 링크 이동이나 명령 `vx`를 실제 차체 이동거리로 쓰지 않는다.
3. 정지 상태에서 관찰 v5 설치 → 새 ARM/유효 정지 기준점 → 전진 → 놓음/실제 정지 → DISARM/정지 TEL → 원본 저장을 한 회차로 묶는다. 코드·출력 제한은 유지하고 구동/휴지 시간은 온도 시험으로 확인된 조건을 따른다. 1m를 위해 연속 구동 시간을 임의로 늘리지 않는다.
4. 목표선 부근에서 정지한 **실제 끝점**을 읽는다. 오버슈트해도 손으로 차체를 목표선에 맞추지 않는다. 초기/종료 기준점 사이에 후진·회전 보정·손으로 이동이 끼면 단순 전진 비교 회차로 채택하지 않는다.
5. 원시 JSON과 외부 거리 기록을 별도로 보존한다. 바닥 기준 실제 이동 `x`는 종료 투영값−시작 투영값이다. 목표1,000mm를 실측값 대신 넣지 않는다.

처음에는 기준 회차1개를 분석한다. 이후 반복 측정이 필요하면 같은 조건의 독립 회차를 추가하고 회차별 결과를 모두 남긴다. 각 회차의 실제 거리·옆으로 벗어남·방향 변화가 큰 경우 함께 기록해, 엔코더 평균 궤도 이동량을 직선 변위와 동일한 물리량으로 단정하지 않는다.

## 계산과 해석

초기 모델은 [14톱니·피치9.64mm·1560counts/rev](../../../assets/logs/wifi_link/2026-10-20_track_geometry_14t_revision/geometry_model.json)다. 좌우 공통 `k=1687/19500 ≈ 0.08651282 mm/count`이며 지상 보정 전이다.

```text
ΔL = 종료 left_count − 시작 left_count
ΔR = 종료 right_count − 시작 right_count
dL = k × ΔL
dR = k × ΔR
d_est = (dL + dR) / 2
부호 있는 오차 = d_est − x
절대 오차 = |d_est − x|
절대 백분율 오차 = 100 × |d_est − x| / |x|   (x ≠ 0)
```

`x`는 같은 회차의 독립적인 바닥 측정값이다. 회전/휨·슬립이 있으면 이 비교에 그 영향이 섞인다. `d_est`는 궤도 이동량 기반 추정이며 별도 자세 보정된 실제 경로 길이가 아니다. 분석기의 소수6자리 출력을 물리 측정 정확도로 쓰지 않는다.

PC 분석은 [기존 도구 사용법](../../../03_Firmware/tests/README.md#관찰-v5-구간-거리-분석--2026-10-20)을 따른다. 도구가 저장하는 시작점은 ARM ACK 후 유효 정지 sample, 끝점은 DISARM ACK 후 유효 정지 sample이다. **그 사이에 사람이 차체/궤도를 움직인 데이터도 count에 들어갈 수 있으므로** 외부 거리 구간과 일치시킨다.

분석기의 [외부 실측 비교 옵션](../../../03_Firmware/tests/README.md#외부-실측-거리와-비교--2026-10-20)에 `--actual-distance-mm`, `--boot-id`, `--arm-seq`를 함께 입력한다. 전진 실측은 양수, 후진은 음수이며 목표1,000mm가 아닌 실제 변위를 사용한다. `--measurement-note`에 측정 방법과 이 세션 기록 경로를 남길 수 있다. 선택한 유일한 ACCEPTED 구간에 대해 좌/우/평균 추정 거리와 평균 기준 오차를 자동 계산한다. 원본 단절·ACK/기준점 누락·FAULT 등으로 REJECTED인 구간은 비교를 거부한다. 계산 성공은 실제 측정·직진성·전체1m 판정의 자동 PASS가 아니다.

현재 요구사항은 1m에서 실제/추정 거리와 오차를 **기록하는 것**이다. 임의의 ±몇 % 정확도 목표를 추가하지 않는다. 목표에 못 미친 짧은 이동은 실제 길이의 예비 회차로 남기고 1m 완료로 포장하지 않는다. 최종 T-ODO-001 판정은 실제 거리·구간 유효성·측정 한계를 대조한 뒤 결정한다. 향후 계수를 보정하면 보정 회차와 독립 검증 회차를 구분한다.
