## 다음 세션 목표

**전원 분배·보호·단자 연결의 문서상 미결 항목을 실물과 대조하고, 진입 조건이 충족되면
모터를 분리한 상태에서 실제 MDD10A B+ 입력의 전원 차단·수동 재투입을 1차 검증한다.**

오늘 확인한 것은 실제 S0-B 감지에서 STM32 PWM이 정지하고 software latch/reset이 동작한다는
점이다. 다음에는 K1 출력에 MDD10A 입력이 연결된 조건에서 전압이 실제로 사라지는지 확인한다.
두 시험은 측정 대상이 다르다. T004 통과만으로 전체 E-stop 또는 실모터 검증 완료로 처리하지 않는다.

## 유지할 완료 기준선

- T004 정상/active/open 부팅, S0 차단, latch/reset/no-replay, active wire-open, 최종 hook0 PASS.
- ESP/STM controlled hook 모두 0U, 정적 검사 30/30 PASS. 새 변경·실패가 없으면 재빌드나
  전체 회귀 캡처를 반복하지 않는다.
- MDD10A B+와 두 모터, BNO 모듈은 분리 상태를 출발점으로 삼는다. 실제 재개 시 상태만 확인한다.
- JESTOP Pin3 원복, run07 PC7 정상 LOW. 왼쪽 PB4/PB5의 임시 15 kΩ GND pull-down 유지.
- 오른쪽 부팅 +10 cps 1회와 영구 encoder 입력 조정부는 별도 미완료로 유지한다.
- 최종 안내는 S1 OFF·LiPo 분리였다. 보관 중 전원 상태는 파일로 확인할 수 없으므로 시작 때 확인한다.

### 1. 처음 확인할 실물 항목

Git closeout 중 9/22 04:18 저장 VRT(`26bc7f6c...a8c666`)가 추가됐다. 시험 때 확인한 파일은
`96f881a5...c36aa9`다. 새 도면을 측정점/배선 지시에 쓰기 전에 관련 Net 변경을 대조한다.
도면 저장만으로 실물 배선이 바뀌었다고 가정하지 않는다.

아래는 **기존 문서상 미결 목록**이다. 이미 실물에서 해결했다면 변경 내용과 근거를 기록하고
닫는다. 미해결로 단정하거나 완료한 배선·도통 시험 전체를 반복하지 않는다.

- **+/− 분배부:** 현재 차량용 퓨즈 허브를 임시 사용 중인지, 대체 분배부를 이미 적용했는지.
  S1 OUT→#1 IN+/#2 IN+/K1 30/F2와 LiPo−/buck return의 실제 분기·고정·절연 상태.
- **F1:** 기록상 실물 `257 / 32V / 10`과 주문 `0287010.PXCN`의 식별 차이를 해소했는지.
  부품 확인 없이 퓨즈 정격을 올리거나 교체를 지시하지 않는다.
- **F2:** 실제 1 A fuse/holder 표시와 control branch 연결 기록을 확인한다.
- **K1 주전류 단자:** 현재 wire/terminal 식별. 문서에는 14 AWG와 `280756-4`의
  AWG 12~10 범위 차이가 남아 있다. 실제 부품이 달라졌다면 그 정보를 우선 확인한다.
- **MDD10A:** B+ 분리·절연, 두 모터 분리, B−와 공통 GND의 실제 연결 여부.
- **계측기:** 사용할 DMM 모델·DC voltage range와 측정 지점을 기록한다.

단자·퓨즈의 새로운 적합성 판단이 필요하면 제조사 자료와 실제 표시를 대조한다.
필요한 변경이 확정되기 전에 부품을 임의 구매하거나 배선을 바꾸지 않는다.

### 2. T005A 진입 조건

[Physical E-stop 검증 계획](../verification/06_Physical_EStop_Requirements_and_Verification_Plan_ko.md)의
T-ESTOP-001~003 잔여 항목과 T005A 조건을 검토한다. T004는 완료 근거를 재사용한다.

- 기존 검사를 재사용할 수 있는 항목과 아직 실제 측정·식별이 필요한 항목을 분리한다.
- T003의 LED-loop current·계측기 정보 등 남은 증거가 진입을 막는다면 해당 항목만 보완한다.
- 현재 부품·배선에서 사용할 bench 보호 조건과 `V_RAIL_OFF_MAX`, 전압을 읽을 시점을
  시험 전에 정한다. 임의의 수치를 PASS 기준으로 소급 적용하지 않는다.
- DMM은 steady-state rail 전압 판정용이다. 릴레이 접점 개방/rail decay의 µs timing이나
  transient를 DMM 결과로 주장하지 않는다.
- 로직분석기는 기존 PC7/PB6/PB7/UART/GND에만 유지한다. 3S/MDD 전력 rail은 DMM 등
  정격에 맞는 계측기로 측정한다.

조건이 남으면 그 근거와 수정 항목을 정리하는 것으로 이번 세션 목표를 제한한다.
MDD10A B+ 연결은 위 조건을 닫고 구체적인 무전원 연결 지시를 제시한 다음에 수행한다.

### 3. 조건 충족 시 시행할 첫 시험 묶음

**아래는 예정된 순서이며 지금 전원을 연결하라는 실행 지시가 아니다.**
사용자가 실제 조작하고, 각 묶음의 측정 위치·기대값·중단 조건을 확인한 뒤 진행한다.

| 순서 | 조건 | 확인할 대상 |
| --- | --- | --- |
| A | S0 해제, S2 미조작으로 전원 인가 | 실제 MDD10A B+–B−의 OFF 전압, 두 PWM 0 |
| B | S2를 눌러 명시적으로 전원 재투입 | MDD10A 입력 rail ON 전압; hook0/무명령의 PWM 0 유지 |
| C | S0 누름 | 실제 MDD10A 입력 rail OFF, PC7 active, PWM 0 |
| D | S0만 해제, S2 미조작 | rail 자동 재인가 없음; software latch 유지 |
| E | 전원 OFF→ON, S2 미조작 | rail 자동 재인가 없음; PWM 0 |

이 첫 묶음은 **정적 motor rail / nominal no-auto-restart 하위 시험**이다. 여기에 통과해도
T005A 전체 PASS로 올리지 않는다. Explicit reset/new ARM/new CMD 결합, UART/ESP 상실,
back-power 조건은 첫 결과 뒤 별도 묶음으로 정한다. 현재 사용 가능한 명령 송신 경로를
소스에서 확인한 후 필요한 자극을 정하고, 새 firmware를 Codex가 임의 작성하지 않는다.

## 이번 세션 범위 밖과 이후 순서

실모터는 연결하지 않는다. IMU/CAN/FreeRTOS/ROS 2와 새로운 firmware 기능도 이번 목표에
추가하지 않는다. 오른쪽 encoder 및 영구 입력 조정부는 실제 모터 시험 전에 별도로 정리한다.
T005A와 관련 선행 gate가 닫히면 기구 장착 확인→띄운 단일 모터 저듀티→powered encoder
noise/sign→배터리 ADC·주행/odometry 순서로 이어간다.

펌웨어 입력·양 보드 빌드·플래시는 사용자 담당이다. 진행 중에는 대화에 결과를 모으고,
작업 블록 종료 때 문서에 한 번 반영한다. 사용자는 9/22 종료 시 Git 저장·원격 갱신을 요청했다.
재개할 때 최신 커밋·작업 트리·원격 동기화 상태를 확인한다.
