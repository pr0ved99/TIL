## Response-Gated Startup Source Checkpoint

- startup path: `500 ms settle -> LF sync -> RX reset -> DISARM(seq=S) -> matching ACK -> PING(seq=S+1) -> matching PONG -> READY`, where `S` is generated per boot
- state path: `SETTLE -> SYNC_WAIT -> WAIT_DISARM_ACK -> WAIT_PONG -> READY`, 실패 시 `FAILED`
- response timeout: `500 ms`; DISARM과 PING은 각각 최대 `3회` 전송
- ACK는 `seq`와 `type`, PONG은 `seq`가 모두 일치해야 다음 상태로 진행하고 response latch는 해당 wait state에서만 유효
- startup TX는 frame과 LF를 한 번에 쓰며 TX 또는 RX flush/reset 실패는 `FAILED`로 종료
- duplicate required field, integer overflow, trailing comma와 부분 prefix를 거부하고, overlong/control-byte 오염 line은 LF까지 폐기한 뒤 복구
- `ARM`/`CMD` scripted sequence는 `READY` 전에는 시작할 수 없음
- `BRIDGE_SCRIPTED_TEST_ENABLED=0U`에서도 안전 startup의 DISARM/PING handshake는 수행되며, 이후 scripted ARM/CMD만 차단됨
- 판정: source implementation `PASS`, static contract/build `PASS`, actual board runtime/retry/recovery `UNVERIFIED`

## Decisions

- Exact PWM frequency/duty and DIR transition settle subtests are closed as PASS.
- Current strict-parser normal PING/safety sequence is PASS under the historical controlled startup preamble. Response-gated startup source, exact response matching, static contracts and build are PASS지만 실제 board happy path·retry exhaustion·wrong-response ignore·malformed recovery는 미검증이므로 release 판정은 `PARTIAL`이다.
- The boot capture is evidence of a sampled all-inactive interval, but it does not contain an external reset marker. It is not treated as independent proof of the complete reset-to-boot window.
- The B1 six-step behavior is a temporary controlled-bench hook, not production behavior.
- A logic analyzer capture proves STM32 pin behavior only. It does not prove MDD10A power output, motor stop, current behavior, or physical E-stop operation.
- RX desynchronization currently rejects contaminated frames and recovers at the next line boundary. Immediate motor stop on desynchronization is not implemented; command timeout remains the fallback and this policy requires a later safety decision.

## Remaining Gates

- Active-output `DISARM`, command timeout and injected software-fault shutdown latency must be measured with trigger-to-PWM-inactive evidence.
- STM32 safe image was reflashed/run and no motor-control signal activity was observed, but the capture has no external reset marker and therefore does not close the final boot-window gate.
- Physical E-stop and real lifted/no-load motor-stop behavior remain unverified.
- UART startup은 source 구현과 static/build 검증을 통과했지만, 실제 board에서 happy path, ACK/PONG 누락 retry exhaustion, 잘못된 `seq`/`type` 무시, malformed-frame recovery를 아직 검증해야 한다.
- ESP source의 `BRIDGE_SCRIPTED_TEST_ENABLED=0U`는 startup DISARM/PING handshake를 유지하고 이후 ARM/CMD script만 차단한다. Board에는 과거 controlled `1U` image가 남아 있을 수 있으므로 다음 safe build/flash 전에는 MDD10A/Battery power를 연결하지 않는다.
