# 2026-11-18 진행 기록 — 최종 완성까지의 계획 검토본

## 요청과 이번 결과

사용자는 기존 회로 설계에서 이미 알 수 있었던 조건을 진행 중 계속 추가한 이유를 지적하고, 세부 설계부터 최종 완성까지의 전체 작업을 먼저 계획 문서로 작성한 뒤 검토하겠다고 요청했다.

[전체 세부 실행 계획 v0.1](../plans/2026-11-18_Detailed_Design_to_Final_Completion_Plan_ko.md)을 작성했다. 현재 상태는 **사용자 검토 전**이다. 직접 논의하던 계측 쉴드의 전체 전기 설계를 상세화하고, 첫 ADC 데이터·PCB·조립/정량 검증·IMU/속도 제어·CAN/RTOS/LL·가상 및 실물 Nav2·최종 인수까지 연결했다. RL/영상 AI는 선택 범위다.

## 근거와 판단

- 10/23 요구사항의 최초 Git 저장본에도 MCU OFF/배터리 ON과 입력 이상 조건이 있었다. 10/28 첫 전압 회로안에도 배선 단락 에너지 제한을 후속으로 적어 두었다. 이를 나중에 새로 생긴 요구라고 설명하지 않는다.
- 초기 분압 계산과 실제 배선/전원/고장을 포함한 완성 설계를 구분했다. 미결을 해결하는 순서와 완료 조건을 명확히 하지 못해 작업이 확대된 진행상의 문제를 반영했다.
- 공급 구조의 미결을 명시했다. 별도 확장3.3V라는 목표와 현재 CAD의 STM_3V3 전류/NTC 공급을 E01/Q03에서 대조·결정한다.
- 보유24AWG 실리콘 연선, 감지선 길이/외경·최종 커넥터 미정, 출발점 Rp CAD/BOM 미반영 상태를 유지한다.
- 하루5~7시간은 사용자 보고이며 과거 기간의 실제 투입 시간을 추정하지 않는다. 새 계획은 기본232~388h, 일반 수정 여유25% 포함290~485h의 검토용 추정이며 납기 약속이 아니다.

## 계획의 구조

완료 범위 C0~C5, 요구사항 PLAN-R01~13, 결정표 Q01~12, 작업과 시험 ID, Gate G0~G7을 연결했다. 첫5작업일의 제안 결과물은 검토된 한 채널의 실제 ADC→PC CSV다. PCB 전체 완성과 정밀 기준계 확보를 첫 기능 확인의 선행 조건으로 두지 않는다.

조건·부품·오차·샘플링·정상/고장/전원 순서·제조/장착을 함께 다루고, 각 미결이 막는 단계와 막지 않는 작업을 적었다. 기존 완료 실습/제외 시험을 자동 반복하지 않는다. 사용자 검토 후 범위·일정·수용 기준을 확정한다.
