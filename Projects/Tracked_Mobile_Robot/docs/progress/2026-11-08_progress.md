## 계산과 이해를 구분

분압/47kΩ 부하를 포함해 최종 VADC=2.371352579V, 환산계수K=6.747204165다. 입력 환산10mV는 ADC쪽1.482095362mV이고 상승 판정 전압은2.369870484V다. 실제 VRAIL이16V일 때 환산 측정값의 정착 잔차를 보는 기준이다. 10mV는 이 실습에서 정착 성분에 둔 예시 기준이며 전체 정확도 목표±0.10V나 모든 오차의 합계와 같지 않다.

C1 중심 근사 τ=0.363286170ms/1τ 전압1.498981V는 **계산값**이다. 저장 모델은C2=100pF를 포함한다. 두 노드 KCL에서 유도한 a,b와 시정수를 [재현 계산](../../assets/logs/pcb_design/2026-11-08_learning_closeout/second_order_calculation.py)으로 확인했다. 느린 시정수0.363634542ms·빠른 시정수0.098014422µs이며,1µs 입력 상승을 포함한10mV 도달 계산2.683406ms는 사용자 관측 구간 안이다. 새 GUI 실행이나 실물 측정이 아니다.

사용자는 분압된 ADC 전압의 잔차와16V 환산 오차, 정착 시간의 목적을 자신의 말로 확인했다. **두 성분과 a·b 유도는 아직 복습이 필요하다.** 빠른/느린 성분을 각각C2/C1의 충전 구간이나 그래프의 급경사/완만한 구간으로 설명하지 않는다. 두 노드 전압에 함께 나타나는 지수항이며, 초반 가파름/후반 완만함은1차 RC에도 있다. 노트 작성 완료를 학습 전체 이해 완료로 승격하지 않는다.
