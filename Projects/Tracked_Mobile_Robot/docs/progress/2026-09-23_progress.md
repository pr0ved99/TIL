## 해석 경계와 남은 작업

- 정지 monitor는 STM 부팅 4.2초부터다. 이전 300/400ms right_cps 1회 튐의 해결 증거가 아니다.
- monitor 당시 임시 빵판 저항 제거·실제 엔코더 연결 여부는 별도 확인되지 않았다.
  이후 무전원 저항 검사에는 임시 저항과 STM32 분리를 안내했고 사용자는 측정 전체 PASS를 보고했다.
- 1kΩ+15kΩ은 범용 5V 분압기가 아니다. 실제 엔코더 출력과 연결한 상태의 LOW/HIGH를
  STM32 장착 전에 확인해야 한다. 이번에 엔코더 수동 회전 검증을 완료로 처리하지 않는다.
- 커넥터 실제 제품과 4선 케이블 준비 여부는 미확정이다. 사용자가 해당 단계부터 다음으로 미뤘다.
- 전압 검사 후 S1 OFF/LiPo 분리를 안내했다. 마지막 분리 완료 개별 답변은 없으므로 재개 시
  실제 무전원 상태를 확인한다. LiPo/USB 동시 공급 금지 정책은 유지한다.
- 최초 실모터 gate, 구동 중 encoder noise/sign, IMU 전원/모드, CAN과 배터리 진단은 미완료다.
  첫 주행 전 기본 저전압 경고/정지는 필요하며 post-MVP PA4/PB0 이중 rail ADC와 구분한다.
