## What changed

- 사용자가 촬영한 실제 만능기판 component-side 정면 사진을 의미 기반 파일명으로 변경해
  `assets/photos/perfboard`에 보존했다.
- 사진의 용도, 해시와 증거 한계를 `assets/photos/perfboard/README.md`에 기록했다.
- Solder-side 전체 정면 사진을 추가해 fixed-header solder joint와 component/solder-side의 좌우
  반전 방향을 확인했다.
- 10 mm cutting-mat grid와 같은 평면에서 촬영한 solder-side 정면 사진을 추가했다. 기판 인쇄
  `PY-10*15CM 2.54MM`, 약 `150 x 100 mm` 외곽 및 printed column `01~54`를 확인했다.
- NUCLEO-F446RE, GY-BNO08X, ESP32-S3 DevKitC를 실제 socket에 모두 장착한 component-side
  정면 사진을 추가했다. 실제 body envelope, 우측 상단 open area와 ESP32 antenna 방향을
  확인했으며 printed column 전체 범위가 `55~01`임을 교차 확인했다.
- 사용자가 pin-header 높이를 `8 mm`로 확인했다. 이 값으로 현재 배치 입력을 진행하며 별도
  측면 촬영은 생략한다.
- 사용자가 WHEELTEC `MG540P30_12V` 전류·토크 자료 재문의 메일을 전송했다고 보고했다.
  제조사 회신 전까지 K1/F1/main-current 부품은 계속 `TBD`로 유지한다.

## Why

- 영구 납땜된 NUCLEO/ESP32/BNO085 socket/header를 보존하면서 low-current 회로의 실제
  open-hole 영역을 계산하기 위한 첫 실물 입력이다.

## Current blockers

- WHEELTEC `MG540P30_12V` 공식 전류·토크 자료의 제조사 회신이 아직 없다. 메일 전송은
  사용자 보고이며 수신·회신 또는 데이터 정확성을 입증하지 않는다.
- ESP32 antenna가 기판 가장자리를 향하는 것은 확인했지만 perfboard copper pad와의 RF keep-out
  적합성은 아직 확인하지 않았다.
- Pin-header 높이 `8 mm`는 사용자 확인 입력값이며 제조 공차를 포함한 정밀 측정값은 아니다.
- Grid는 `docs/progress/2026-07-23_progress.md`의 사용자 실물 확인값 `55 x 37홀`과 이번 사진의
  `55~01` 인쇄를 함께 근거로 사용한다.

## Next concrete actions

1. `55 x 37홀` component-side 좌표계로 fixed-header와 module occupied-hole map을 작성한다.
2. Removal envelope와 ESP32 antenna keep-out 후보 영역을 겹쳐 표시한다.
