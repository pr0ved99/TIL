- 수정본 표시를 기준으로 안내한 세 측정에 사용자가 `1,2,3 모두 .002~3이야`로 응답했다.
  직전과 같은 `2 kΩ` range에서 각각 `0.002~0.003 kΩ = 2~3 Ω`의 공통 범위 보고로 기록한다.
  각 지점의 단일 고정값은 제공되지 않았으므로 임의로 배정하지 않는다.

| ID | 재측정 경로 | 사용자 보고 범위 | 판정 |
| --- | --- | --- | --- |
| K2-R02a | JESTOP.6 → pin 1 `C37,R21` | `0.002~0.003 kΩ` | OPERATOR-REPORTED PASS — low Ω |
| K2-R02b | JESTOP.6 → pin 8 `C41,R19` | `0.002~0.003 kΩ` | OPERATOR-REPORTED PASS — low Ω |
| K2-R03 | J3_AUX5V.2 GND → pin 12 `C37,R19` | `0.002~0.003 kΩ` | OPERATOR-REPORTED PASS — low Ω |

- 세 값 모두 확인된 lead baseline `.003 kΩ`와 가까운 낮은 저항대다. 이번 세 경로의
  재측정 보류를 해소한다. 이전 약 `1 kΩ` raw는 핀 식별 혼동 당시의 기록으로 그대로 보존한다.
  이 판정은 사용자 보고에 따른 직접 도통 subset이며 정밀 접속저항·부하 적합성이나
  Gate 1/Physical E-stop 전체 PASS를 뜻하지 않는다.
- 다음은 K2-R04a `JESTOP.2 → pin 4 C40,R21`, K2-R04b `JESTOP.2 → pin 9 C40,R19`,
  K2-R05 `JK1COIL.1 → pin 5 C41,R21`의 무전원 low-Ω 검사다.
  전원/USB/motor 분리, MDD10A B+ 절연, S1 OFF/S0 latched/S2 released를 유지한다.
  R04~R09와 Gate 2 이후는 대기하며, 새 배선 변경·전원 인가·flash는 없다.
- 사용자 신규 `*_수정본.pdf` 2건도 읽기 확인했다. 부품면의 K2 위/아래 번호는 수정 VRT와
  일치하고 납땜면은 K2 국소 번호의 수평 반전과 일치한다. 파일 식별값과 검증 범위는
  [VeroRoute README](../../09_Electrical_Design/VeroRoute/README.md)에 기록했다.
  전체 출력 배율·source-VRT linkage·실물 검증을 새 PASS로 추가하지 않는다.
