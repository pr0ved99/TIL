## 시스템 통합 엔지니어 관점 자체 평가

- 사용자 요청으로 현재 README·인수 판정41·실행 계획·실제 drive_command_mapper/ESP 태스크·큐/검증 코드 일부를 대조했다. 실제 무선 주행/정지, STM 최종 출력 판단, 엔코더/거리 로그와 물리 조작 근거는 통합 강점이다. 전류/온도 ADC·PCB 제작/측정·속도 폐루프·IMU/CAN/ROS 2 통합은 아직 별도 후속 역량이다. ESP는 이미 FreeRTOS 태스크/큐를 사용하므로 RTOS 전체를 미사용으로 평가하지 않는다.
- 현재 명령 매핑은 고정 gain을 포함한 open-loop PWM이다. 속도 요청 단위와 실제 속도 추종 성능을 구분한다. PC 테스트 일부는 Python 참조 모델/소스 계약 검사이며 실제 C 실행 및 보드 검증과 같은 증거로 세지 않는다.
- Codex 진행 방식의 보완: PC2 OFF 경로가 확인되기 전에 일반 다이오드 모델을 길게 설명했고, 사실·가정·미결을 문서에 반복하면서 설계 결정과 구현의 완료 단위가 흐려졌다. 앞으로 요구 동작→근거/가정→선택과 계산→구현→관측/판정의 한 묶음을 끝내고, 보류 항목은 다음 판단 조건을 특정한다.
- 제안한 방향: 기존 운용/영상/로그를 현 구동 기준점으로 재사용하고, 모니터링은 센서→ADC→단위/보정/유효성/시각→기존 통신→화면/로그→기준 계측까지 채널별로 완성한다. PCB는 ADC6+CAN 범위를 보존하며 시스템 관측/접속/유지보수에 기여하는 결과로 평가한다. 이후 속도 폐루프의 오차/주기 검증, 목적 있는 CAN·STM 스케줄링, ROS 2 명령/odom/시각/연결 유실 계약을 단계별로 다룬다.
- 기존 MVP 후 첫 IMU 기본 검증 순서와 사용자 제외 조사는 유지한다. 오늘 노트북 PCB 작업을 장비 실습으로 바꾸거나 미검증을 PASS로 승격하지 않았다. 새 단계 순서/요구 수치/일정은 제안이며 채택·캘린더 변경이 아니다. 독립 설계·수정·디버깅 능력은 코드 입력 사실만으로 확정하지 않는다.

### 왼쪽 NTC의 정상·단선·단락 설명

- 사용자가 공급/기준 전압 추종의 의미를 확인한 뒤 입력 고장 검토로 진행했다. 저장 연결 기록의 R3 10kΩ → T_LEFT_RAW → R4 1kΩ → PC2와 외부 NTC/GND 분기를 대조했다.
- 공급 3.3V·정상 MCU·충분한 안정 시간·ADC 부하 무시 조건에서 정상 25°C/10kΩ은 약1.65V, NTC 두 선 회로의 단선은 약3.3V, J5 신호-GND 단락은 약0V다. R3는 단락 시 전원-GND 전류를 제한한다. 고장 직후 C3 과도는 이 정상상태 설명과 구분한다.
- 상·하한은 고장 판정의 단서이며 정상 온도 범위와 분리할 임계값·대기 시간은 미정이다. 다른 전원선과의 단락·MCU 무전원 보호는 별도 후속 검토다. CAD/BOM 변경이나 실물 검증은 수행하지 않았다.

### MCU 무전원과 R4 보호 경계

- ST DS10693에서 PC2=FT 및 FT/TTa 주입 조건 차이를 확인하고, AN4899의 ADC 연결/샘플링 시 기생 경로 설명을 대조했다. MCU OFF에서 항상 상측 다이오드가 도통한다는 단순 모델이나 TTa ±5mA를 PC2에 적용하지 않는다.
- R4는 센서 측 전류 제한이며 차단 기능은 없다. 핀을0V로 잡는 설명용 저항망 계산은 정상25°C0.275mA/NTC 단선0.300mA로, 실제 역급전 전류나 허용값이 아니다. C3는 R4 뒤에 있어 C3→ADC 국소 방전은 R4를 우회할 수 있음을 확인했다.
- NTC의 MCU 전원 추종/실제 동시 차단과 OFF 입력 분리·잔류 전하 처리 후보를 다음으로 비교한다. 무전원 허용·보호 부품 확정이나 실물 검증은 남았고 CAD/BOM 변경 없음.

### NTC 블록 추천 정리 — 무전원 가정과 방전 계산 구분

- RM0390의 PC2 리셋 입력 모드/GPIOC_MODER=0 및 ADC 비활성/ADON=0을 확인했다. 리셋의 논리 상태와 VDD=0V의 전기적 보증은 구분하며 ADC 샘플링 그림으로 무전원 도통을 확정하지 않는다.
- C3→R4→NTC→GND 방전 경로를 확인했다. NTC10kΩ/초기1.65V·ADC 부하 무시·공급 개방 모델은11kΩ·시정수1.1ms·1%까지5.07ms, 공급0V 고정 모델은6kΩ·0.6ms·2.76ms다. 별도 공급이 살아 있거나 NTC도 끊긴 조건에 이 수치를 적용하지 않는다.
- NTC STM 공급 B안과 기존10k/1k/100nF를 분압·필터 후보로 추천한다. R4를 무전원 역급전 차단으로 설명하지 않으며 추가 차단 소자는 근거 없이 선정하지 않는다. B안 채택/CAD 반영과 무전원 허용 확정은 아직 남았다. 다음 독립 검토는 전류센서 #5241 출력과12kΩ의 부하/ADC 정착이다.
