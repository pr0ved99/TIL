## 결정과 미완료

- W5 PING/DISARM은 진단·비구동 명령 범위다. READY·PING OK를 구동 허가로 쓰지 않는다. FAULT/ESTOP_ACTIVE 유지와 응답 OK는 모순이 아니다.
- 요청4 TIMEOUT 이후의 요청5는 사용자가 PING을 다시 누른 별도 요청이었다. 빠른 연속 클릭이 두 요청을 통과시켰다는 근거로 쓰지 않는다.
- 브라우저 결과 대기3000ms 만료는 ‘결과 확인 불가’이며 STM 응답500ms TIMEOUT과 구분한다. 재접속/결과 만료 뒤 자동 재전송하지 않는다.
- 리셋 invalid-line/err의 전기 원인·구동 중 재기동 안전은 미완료. 새 로직 분석기/전압/모터 관측 없음.
- 별도 `esp32_uart_bridge`의 수동 hook1U·default-off30 PASS/1 FAIL은 유지된다. W5 테스트를 전체 기존 검사 PASS로 합치지 않는다.
- MVP-002/T-COM-002·전체 T005A/모터 수용/주행의 기존 PARTIAL 또는 미검증 상태를 유지한다.

1. 새 대화에서 현재 인수인계·보고서34와 필요한 UART/상태 계약을 읽고 ARM/CMD의 소유권·명령 유효시간·재허가 조건표를 작성한다. 로봇 없이 가능한 설계 작업이다.
