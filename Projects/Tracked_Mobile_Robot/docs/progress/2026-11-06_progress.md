## 프로젝트와 학습의 현재 상태

- NUCLEO-F446RE가 구동·명령 timeout·안전 허가·엔코더를 맡고 ESP32-S3가 Wi-Fi/WebSocket UI와 UART 명령·상태를 연결한다. 첫 모터 드라이버는MDD10A다. 기존 기본 주행/정지·거리 비교·통합 영상의 근거는 보존하되 전체 MVP 인수는PARTIAL/OPEN,T005A PARTIAL/T007 BLOCKED를 유지한다.
- 현재 집중 범위는 모니터링 PCB의 전압 2채널 설계다. 자료는37-4 잡음·평균,38-1~3 기준 계기·보정,39-1~3 설계 판단·부품/검증 조건·회로도 인계까지 작성했다. 사용자 필기 완료 보고는36-19까지다.
- 진행 기준은0~16V·보정 후±0.10V·주위20~30°C·10Hz/입력 안정 후300ms,기존분압/TPS3840PL30/TMUX1511/내장ADC 유지다. R1~R5 ±0.1%·TCR25ppm/°C 이하,사용 조건에서0.1W/25V 이상을 선정 기준으로 제안했다. 실제 주문품·구매나제작 승인은 아니다.
- ADC12bit·명목14MHz·480cycles,채널당100Hz·유효10개→10Hz,VREFINT·채널별1V/15V 두 점 보정은 첫 검증안이다. 독립점0/0.5/4/8/12.6/16V와주위20/25/30°C에서 같은 계수로 확인하는 계획이다. 실제 잡음·계수·독립점 잔차는 미확보다.
- 기준 비교 경계G25mV 조건에서 관측 차이 크기75mV 이하PASS,75초과125이하보류,125초과FAIL이다. 실제 전체 정확도나보호PASS로 기록하지 않는다. 검증 기준 경계를DUT 물리 오차와중복 합산하지 않는다.
- 실물은11/5 전원 분리 완료 사용자 보고 상태다. NotebookLM14단원/39소스 안내와01~07 프로듀서 메모 화면 제공 이력은 별도이며,전체 업로드 완전성과최종 영상 생성은 미확인이다. 바탕화면 묶음은 원문 스냅샷이고 자동 동기화되지 않는다.
