- A3 한 장을 Nucleo·전류·NTC / 전압2채널용 공간·TPS/TMUX / 테스트 포인트의6영역으로 정리했다.24부품과 관련 와이어·라벨·X·접합점을 이동하고 필드 간격·글자 크기를 정돈했다. 전압2채널 부품 번호를 표시한 공간은 추가 예정 영역이며 부품/배선 완료 표시가 아니다.
- [변경 전후 도면·백업·검증](../../assets/logs/pcb_design/2026-11-06_schematic_layout_review/README.md): 활성10net와 미연결 포함99net의 ref/pin/pinfunction/pintype 목록 동일,24부품 정보·내장 심벌 정의·UUID/인스턴스 동일. 와이어48·접합점6·라벨36·X70 유지. PCB/프로젝트 설정/심벌/라이브러리 표4파일과 무관한 기존19파일의 SHA256 동일. 원본이 검증한 후보와 같음을 확인했다.
- 다음은 사용자가 정돈된 **04 전압 입력 영역에 배터리측 J7/R7~R11/C5를 배치**하고 전단 연결→후단·공통→ERC로 진행한다. 이번 위임은 도면 재배치 범위이며 일반 회로 추가·펌웨어·실물의 사용자 직접 작업 흐름은 유지한다. 새 ERC/DRC·MCU 빌드/플래시·실물·Git/Calendar/Notion 게시 없음.

- 실제 Shield 저장 파일에서 J7=(50.8,184.15), R9=(127,194.31), C5=(152.4,194.31)mm를 확인했다. 제안했던 위100mil/아래300mil 이동이 반영됐고 J7-2가 R7/R8/R10의 y186.69mm와 정렬된다. [최신 배치 PDF·좌표 근거](../../assets/logs/pcb_design/2026-11-06_voltage_upstream_placement/README.md). 이 확인에서 Codex는 Shield 회로도를 수정하지 않았다.

## 제품 관점 회로 분석 — 잡음·정확도·고장 내성
