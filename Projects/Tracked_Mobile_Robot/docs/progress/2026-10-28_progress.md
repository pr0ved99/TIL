## 마지막 설명에서 보충한 내용

- 전류센서 단독은 독립 기준 전류와 입력 회로 앞 센서 출력 전압을 비교한다. 1.65V+44mV/A×I는 명목 모델이며 실측 결과가 아니다. 전류·전압 기준 경계, 출력 부하, 공급/온도/자계 조건과 보정에 쓰지 않은 점이 필요하다.
- NTC 단독은 안정·균일 온도 환경의 기준 온도와 낮은 자가발열 조건에서 측정한 저항을 제조사 RT와 비교한다. 센서 설치 뒤의 접촉/위치/열지연은 별도 전체계 평가다.
- 기존 명세22/23은 입력계 및 센서 포함 경로를 구체화했다. 센서 단독의 다점 시험 조건·기준기/치구·합격 경계는 후속 상세화 대상이며 이번에 완료/통과로 바꾸지 않는다. 새 계측기 구매를 요구하거나 측정을 시작하지 않는다.
