## K2 Bottom-View Correction

2026-09-03 계획의 K2 좌표표는 Panasonic `TX2-12V`의 bottom-view pin diagram을 실제
component-side 좌표에 그대로 적용해 위·아래 행을 반대로 해석했다. 실물 body의 원형 dimple을
pin 1 기준으로 다시 대조하면 다음과 같다.

| 실제 K2 pin | Component-side 좌표 | Intended Net / 기능 |
| ---: | --- | --- |
| 1 | `C37,R21` | `K2_COIL_P` |
| 3 | `C39,R21` | NC1, no board Wire |
| 4 | `C40,R21` | `ESTOP_CONTROL_PERMISSION` |
| 5 | `C41,R21` | `K1_COIL_P`, K1-enable-pole NO |
| 12 | `C37,R19` | GND |
| 10 | `C39,R19` | NC2, no board Wire |
| 9 | `C40,R19` | `ESTOP_CONTROL_PERMISSION` |
| 8 | `C41,R19` | `K2_COIL_P`, hold-pole NO |

최초 powered check 때는 `C37,R21=GND`, `C37,R19=K2_COIL_P`로 실제 pin 1/12 coil polarity가
반대였다. 이를 `C37,R21=K2_COIL_P`, `C37,R19=GND`가 되도록 수정한 뒤 아래 기능 확인을
수행했다. 이 좌표와 재작업 상태는 현재 세션 사진과 사용자 보고에 근거하므로, 다음 무전원
재진입 때 direct pad continuity로 한 번 더 고정한다.

기존 RevC FINAL VRT/PDF와 2026-09-03 계획의 K2 표는 당시 frozen digital checkpoint를 설명하는
역사 자료일 뿐, K2 실물 핀 식별의 정본으로 사용하지 않는다. 교정된 별도 revision과 PDF/hash가
생기기 전에는 이 progress와 새 remaining-gates 계획의 dimple/좌표표를 우선한다.

## S0-B Unpowered Truth Table

모든 전원을 분리한 상태에서 `JESTOP.3` (`C55,R15`, `S0B_LED_FEED`)과 `JESTOP.4`
(`C55,R16`, `S0B_TO_OPTO_ANODE`) 사이를 확인했다.

| S0 상태 | 관찰 | 판정 |
| --- | --- | --- |
| Released | continuity / beep | PASS |
| Pressed and mechanically latched | open / no beep | PASS |
| Manual release after latch | continuity / beep 복귀 | PASS |

이는 S0-B contact-state truth table의 operator-reported PASS다. Exact resistance/OL display와
lead-resistance baseline은 저장소에 남지 않았다. Sense conductor를 실제로 한쪽 분리하는
wire-break test, S0-A control path와의 end-to-end independence/cross-wire matrix 및 powered
VO617A-3/PC7 전압 측정은 실행하지 않았다. 따라서 `T-ESTOP-002`는 `PARTIAL`,
`T-ESTOP-003`은 `OPEN`이다.

## Verification Boundary

- 이번 powered 범위는 K2/K1 control relay chain의 nominal steady-state subset이다.
- MDD10A `B+`, motor, XL4015, STM32/ESP32 USB/logic와 PWM measurement는 포함하지 않았다.
- K1-87은 relay output terminal에서만 관찰했으며, MDD10A `POWER+` downstream rail의
  `V_RAIL_OFF_MAX` 판정이 아니다.
- Conditioned `ESTOP_SENSE`, sense-to-PWM timing, firmware latch/reset/new ARM+CMD와 UART-loss는
  포함하지 않았다.
- Session attachment로 사진을 검토했지만 원본 파일·hash·독립 raw DMM log가 repository에
  보존되지 않았다. 따라서 evidence provenance는 `operator-reported / session-attached`다.
- 이 결과로 `T-ESTOP-001~004`, 정식 `T-ESTOP-005A`, Physical E-stop 전체 또는 산업 안전
  적합성을 PASS 처리하지 않는다.
