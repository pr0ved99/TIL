## Decisions

- `06_STM32_UART_MVP_Detailed_Implementation_ko.md` is the detailed STM32 firmware implementation guide.
- The detailed firmware guide keeps the current UART MVP scope to USART2 RX interrupt, ring buffer, line parser, ACK/ERR/TEL, state machine, and timeout behavior without motor power.
- STM32 firmware project creation should start from standalone STM32CubeMX board selection, then be opened or imported in STM32CubeIDE.
- `STM32CubeIDE Empty Project` is not the starting point for this MVP because the project relies on CubeMX `.ioc` and generated HAL initialization code.
- README should act as the entry point, `PROJECT_MEMORY.md` as stable state, and the latest progress/handoff docs as continuation context.
