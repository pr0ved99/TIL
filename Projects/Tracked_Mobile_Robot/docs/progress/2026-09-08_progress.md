- 아직 별도 결과가 필요한 항목은 두 2P에서 각 board endpoint까지의 네 branch와 common GND
  두 경로다. 이 여섯 continuity 항목 전에는 전체 post-solder unpowered Gate를 닫거나 전원을
  인가하지 않는다.

## XL4015 #1 Topology Correction — No Inline 4P

- 사용자는 별도 4P connector가 없으며 XL4015 #1 OUT+/OUT-에서 곧바로 두 갈래로 나뉘어
  NUC용 2P와 ESP용 2P에 연결된다고 정정했다.
- 이전 문서의 inline 4P/master 가정과 그 cavity 검사 단계는 취소한다. VRT의 두 2P board landing과
  각 board endpoint routing은 실제 구조와 일치하므로 VRT/PDF를 다시 수정할 필요는 없다.
- Standalone 동시 구동에서는 두 2P를 모두 연결한다. NUC 또는 ESP 단독 시험에서는 시험하지 않는
  쪽 2P를 뺀다. Dual-USB mode에서는 두 2P를 **모두** 기판에서 빼고, #1 switch OFF만으로 rail
  isolation을 대신하지 않는다.

## XL4015 #1 Source Harness And Powered Board Tests — Operator-Reported PASS

- 두 2P source harness의 pin 1→XL4015 #1 OUT-, pin 2→OUT+ 도통·극성과 +/− gross-short
  부재를 확인했고 사용자는 전 항목 통과를 보고했다. 개별 Ω/사진은 제공되지 않았다.

  단독·동시 전원 시험을 완료했다.

| Mode | XL4015 #1 / board 측정값 | 분리 branch | 결과 |
| --- | --- | --- | --- |
| NUCLEO only | OUT/NUCLEO E5V `4.97/4.97 V`, STM32 3V3 `3.30 V` | ESP 5V `0 V` | PASS |

## XL4015 #2 AUX_5V Path And S1 Distribution — Operator-Reported PASS

- XL4015 #2는 board 연결 전 무부하 `5.03 V`, 전원 제거 후 `0 V`를 확인했다.
- 무전원 상태에서 `OUT+→J3.1 C52,R1→R13.1 C52,R2`,
  `OUT-→J3.2 C51,R1→LOGIC_GND C15,R4` 도통과 #1 두 5 V rail과의 절연을 확인했고
  사용자는 전 항목 통과를 보고했다. 개별 Ω/OL과 사진은 제공되지 않았다.
- 실제 입력 분배는 다음과 같다. JESTOP.1은 사용하지 않으며 JESTOP.1↔.2 jumper도 없다.

```text
LiPo+ -> F1 -> S1 -> S1 OUT / VBAT_PROTECTED
                     |- K1 pin 30
                     |- XL4015 #1 IN+
                     |- XL4015 #2 IN+
                     `- F2 IN -> F2 OUT -> 6P.1 -> S0-A NC -> 6P.2 -> JESTOP.2

LiPo- -> PWR_GND -> XL4015 #1 IN-, XL4015 #2 IN-, MDD return/common ground
```

- 이 구성에서 J3 `AUX_5V`는 `5.08 V`였다. XL4015 #1 OUT+와 #2 OUT+는 서로 연결하지
  않았고 MDD10A B+와 motor는 계속 분리했다.

## T-ESTOP-003 Conditioned Sense Voltage Test — Functional Subset PASS

- NUCLEO는 XL4015 #1로, S0-B/R13/VO617A 입력은 XL4015 #2 `AUX_5V`로 공급했다.
  ESP32, MDD10A B+와 motor는 분리했다.
- DMM은 `ESTOP_SENSE C29,R19`와 `LOGIC_GND C15,R4` 사이에 두고 S0 상태만 바꿨다.

| Condition | Measured `ESTOP_SENSE` | Verdict |
| --- | ---: | --- |
| S0 released / S0-B closed | `0.06 V` | LOW PASS |
| S0 pressed and latched | `3.27 V` | HIGH PASS |
| S0 manually released | `0.06 V` | LOW recovery PASS |
| S0-B sense conductor open | `3.27 V` steady | HIGH/open-fault PASS |

- 같은 실행의 STM32 3V3는 앞선 board-power 측정에서 `3.30 V`였다. 따라서 기준
  `LOW <= 0.3×VDD = 0.99 V`, `HIGH >= 0.7×VDD = 2.31 V`에 대해 LOW/HIGH margin을 만족한다.
- 전원 제거, S0-B 복구와 정상 LOW 복귀 확인도 사용자 보고로 통과했다. 복구 뒤 exact voltage,
  LED-loop current, DMM 모델/range, 사진·raw log와 온도는 기록되지 않았다. 따라서
  `T-ESTOP-003`의 **conditioned voltage/function subset은 PASS**지만 formal evidence package는
  `PARTIAL`로 남긴다.
- Firmware source 수정·flash·runtime은 수행하지 않았다. 다음 단계는 사용자가 직접 코드를
  작성하는 기존 학습 방식으로 `T-ESTOP-004` motor-disconnected PC7/PWM integration을 진행하는 것이다.
  MDD10A B+와 motor는 계속 분리한다.
