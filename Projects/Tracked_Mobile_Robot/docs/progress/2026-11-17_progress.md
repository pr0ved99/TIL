# 2026-11-17 진행 기록 — 보호 검토 범위 정리·Ubuntu/Nav2 계획

11/15 마감 후 이어온 11/16~17 대화를 11/17(Asia/Seoul)에 마감한다. 실제 수행 시간은 추정하지 않는다.

## 1. 오늘까지의 결과와 사용자 보고

- 사용자는 보유24AWG가 **실리콘 피복 연선**이라고 보고했다. 새 감지선의 실제 길이·피복 외경·전압/온도 정격·최종 커넥터는 미정이다. 보유 사실을 선정/설치 완료로 확대하지 않는다.
- J7/J8 독립 감지선과 출발점 보호 Rp, NTC와 포트 혼동을 줄일 JST-PA 후보를 검토했다. PAP-02V-S/SPHD-001T-P0.5의 적용 검토는 후보이며 실리콘 피복 외경과 압착 호환 확인 전이다.
- 보호 저항은 합선 판별 장치가 아니라 **고장 전류 제한**이다. 정상16V에서 약0.525mA/0.606mW, Rp 뒤 단락에서는2.2kΩ 명목7.273mA/0.11636W,−1%2178Ω이면0.11754W다. 정상 때 보호 저항만 특별히 큰 전류가 흐른다는 오해를 정정했다.
- MBB/SMA0207 0.6W·50ppm/K 옵션과 PR01 1W·250ppm/K 부품군의 데이터시트를 비교했다. 정격/설치 조건은 확인하되, TCR은 오차 상한 계산으로 기여를 보고 작으면 검토 종료한다. 별도 온도 실습·과도한 부품 탐색을 자동 추가하지 않는다. 최종 품번/구매/CAD 반영 없음.
- 퓨즈는 고장 경로를 개방하고, 저항은 전류를 제한하는 차이가 있다. ADC 저전압만으로 단선/합선/실제0V/TMUX OFF를 구분할 수 없다. 기존 MVP에도 주전류 F1 검토가 있었으며 모든 고장을 누락했다고 기록하지 않는다.
- 제조사/공개 회로의 분압 ADC 사례와 우리 출발점Rp+TPS/TMUX 조합을 구분했다. TPS/TMUX는 MCU 무전원에서도 남는 감지 입력의 분리 목적이며 케이블 고장 전류 제한을 대신하지 않는다. 기존 NTC/전류 포트 고장 검토는 존재하지만 모든 배선별 KiCad 실습 일정은 없었다.
- 수기 전체·모든 개념 이해 완료는 미보고다. 기존 B/03_15 실습을 재실행하지 않았다.

## 2. 새 사용자 방향과 계획

사용자는 **현 노트북 내부 저장장치 절반을 Ubuntu 듀얼부팅에 배정**할 방향을 명시했고 전환 시점 추천을 요청했다. 별도 SSD 사용으로 추정한 설명은 이 보고로 정정했다.

[Ubuntu·Nav2·RL 계획](../plans/2026-11-17_Ubuntu_Nav2_Simulation_and_RL_Roadmap_ko.md)을 작성했다. 11/17~18 기존 일정 후11/19 백업·사전 점검, 조건 충족 시11/20 설치 권고,11/21 환경 점검. Ubuntu24.04/Jazzy/Harmonic은 제안 기준이며 현재 최신 LTS라고 표현하지 않는다. 가상 로봇/IMU/LiDAR·odom/TF→Nav2 기준선→선택적 RL 비교를 단계화했다.

11/19~12/2는 하루별 결과물/선행 조건을 정의했고,12/3 리뷰 뒤12/4~9 RL은 조건부 초안이다. 설치/시뮬레이션·RL은 NOT_STARTED. 전류/전압/온도 mock/replay는 실제 센서/ADC 검증을 대신하지 않는다. PCB 제작과 별개로 진행하되 기존 bare-metal/ESP 단일 ingress·STM 안전 권한을 유지한다. 기존 YOLO 계획은 후속 보존, CAN/RTOS/LL 목표도 유지한다.

## 3. 환경 확인과 미결

읽기 전용 조회: WD Blue SN5000 1TB GPT, C: 약999.1GB/여유773.3GB. 기존9/8 256GB 저장공간 기록은 과거 이력이다. 현재 용량상 약 절반 배정 제안이 가능하나 실제 축소 가능량·백업 복원·암호화 상태는 별도다.
