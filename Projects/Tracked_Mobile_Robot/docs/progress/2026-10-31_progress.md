# 2026-10-31 전압 ADC 부품 조건·전원 제어 초안 — 진행 중 마감

사용자가 오늘 작업만 종료하고 모든 정리를 요청했다. **작업/프로젝트 완료가 아니다.** 10/30 마감 이후의 사용자 GUI 결과와 부품·계측 학습을 보존한다. 실험별 시각과 실제 종료 시간은 추정하지 않는다.

## 오늘 진행한 범위

1. 고정30µs delay helper를 넣은 TRAN: 사용자 화면에서 VTRIP 약10.300ms, VCTRL/VADC 하강 약10.330ms를 확인했다.
2. 가정한 빠른 하강25V/ms: 사용자10.040ms 커서에서 VADC2.37135258V, VDDA2.3V, 차이−71.3526mV를 확인했다. 사용자의 지적처럼 임의 기울기의 조건부 결과이며 실제 보드 고장 증거가 아니다.
3. 보호 부하 포함 ±0.1% OP: 최대/최소2.37547V/2.36724V. 해석식과 표시 반올림 범위에서 일치하며 명목 K6.747204165 환산 오차는+27.7924/−27.7536mV다. 0.1% 저항을 새로 사기로 한 것이 아니다.
4. TMUX1511 RON·ON 누설·IPOFF의 시험 조건과 전원/논리 한계, STM32 PA4/PB0 입력 유형·ADC/VREFINT·보정 범위를 검토했다. IPOFF10nA@25°C와2µA 전 온도 행을 구분했다.
5. 두 점 보정 이후 남는 비선형성·온도·기준 계기 오차를 구분했다. 저항 키트 TCR은 미상이며 UT210E의 설명서 한계만으로±0.10V 검증을 확정할 수 없다. 수령·추가 구매는 새로 확인하지 않았다.
6. VDDA 감시 TPS3840PL30 → RESET → TMUX SEL1/2의 전원 제어 논리 초안을 정리했다. 실제 보드 전원 경로·제작 회로도 반영은 아직이다.
7. 마지막 학습: VIT−는 하강 문턱, VIT+는 복귀 문턱이며, tP_HL 후 RESET LOW / tD 후 HIGH다. 완전 OFF 시작 tSTRT와 CT-open tD를 중복 가산하지 않는다.

## 검증 범위와 미완료

해석식 재계산, 사용자 OP 표시값 대조, 저장 속성·파일 해시 및 문서 링크 검사를 수행했다. 새 SPICE 실행, ERC/PCB 검증, MCU 빌드/플래시·실물 조작은 하지 않았다. 100pF·1/25V/ms·고정30µs 모델은 실부품/실전원 전체 동작을 보증하지 않는다.

실제 VDDA/VDD 취출·중간 저전압 구간·전원 복귀/ADC 정착·무전원 핀 I–V·전체±0.10V 오차 예산·제작 회로/ERC·실물 검증은 미완료다. NTC 공급 기본안도 제작 쉴드 미반영이며 전류/NTC 전원 순서 검토가 남는다. 기존 MVP PARTIAL/OPEN, AI/배치 후속, 완료 시험 반복 금지를 유지한다.
