## P-01 Completed — ADR-015

- Final MVP의 유일한 production external command ingress는 ESP32-S3다.
- Production link는 `ESP32 UART1 GPIO17/GPIO18 <-> STM32 USART1 PA9/PA10`이다.
- STM32 USART2 PA2/PA3는 bench debug/encoder logger와 historical PC-first evidence로만 유지한다.
- Optional PC control은 `PC -> ESP32 -> STM32`로 전달하며 direct dual-owner를 허용하지 않는다.
- STM32가 final drivetrain/safety authority를 유지한다.
- Source loss는 output/stored command zero -> `DISARMED` -> new `ARM` + new `CMD`로 고정했다.
- 결정 정본은 [`../../01_System_Architecture/19_Architecture_Decision_Record_ko.md`](../../01_System_Architecture/19_Architecture_Decision_Record_ko.md)의 ADR-015다.
- Source audit에서 protocol RX binding은 `uart_mvp_init(&huart1)` 하나뿐이고 USART2
  `HAL_UART_Receive*` 호출은 0건임을 확인했다. USART2는 logger TX 호출만 유지한다.
- 기존 host/static test discovery를 다시 실행해 `20/20 PASS`를 확인했다.
- FreeRTOS target enum, protocol `STATE` 목록, historical PC-first guides와 protocol learning
  note도 동기화했다. Timeout 전용 state와 direct PC/ESP32 dual-ingress 표현은 target에서
  제거했고, 과거 후보나 bench 이력으로 필요한 곳에서만 명시적으로 보존했다.

이 완료는 architecture/ownership evidence다. 현재 firmware timeout은 여전히 `ARMED`를
유지하므로 source 변경과 board-runtime 증거는 `P-03`에 남아 있다. `PC -> ESP32`
production forwarding과 production motion mapper도 아직 구현되지 않았다.

## P-02A Completed — Production Open-Loop Mapper Design

- 정본을
