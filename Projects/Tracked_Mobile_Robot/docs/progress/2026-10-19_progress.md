## 한눈에 보기

**최신 재판단:** 사용자가 부하 측정의 MVP 필수 여부를 다시 물었다. **실제 궤도 하중의 기본 주행·정지와 외부 온도 관측은 MVP, 정량 전류 측정·전류/전압 ADC 모니터링은 post-MVP**로 구분했다. MVP-014/REQ-MON/T-MON은 DEFERRED, MVP-015/T-LOAD는 ADC 없이 수행하는 외부 온도 범위다. IMU는 MVP 직후 첫 확장이다. 아래 앞선 MUST 추가안은 재판단 전 이력이며, 새 실물 측정/구매/펌웨어 작업은 없다.

## 현재 결정과 다음 행동 — 예산 제한 철회 후

1. **5만 원 상한은 철회됐다.** 아래의 예산 제한 비교는 이전 검토 이력이다. 온도계는 사용자가 **BENETECH GM-1312**로 선택했으며 센서·건전지·고정/절연 부속을 정한다. 선택과 구매·수령을 구분한다.
2. **전류는 센서 모듈→STM32 ADC→UART/ESP32/브라우저 로그 방향으로 전환**한다. UT210E는 사용자가 비용으로 거절했으므로 아래 추천/가격은 이전 이력이다. 새 수치 예산 상한은 제시되지 않았다.
3. 첫 센서 위치는 **K1 87→MDD10A B+** 분기를 후보로 삼는다. ADC 신호는PC0/ADC1_IN10을 우선 검토한다. 기존 전력단을 변경하기 전 모듈/부속·고정·신호 보호·실제 핀 연결을 확정해야 한다. 현재 배선·코드 변경은 없다.
4. 관측용 수집 경로부터 구현한다. ADC 입력 범위·영점·환산·잡음·샘플링·TEL 전송 검증 후 짧은 대표 조건의 전류·CPS·표면 온도를 기록한다. 일반15%/회전20%·직진 gain960/930의 기존 실물 결과를 새 계측 완료로 확대하지 않는다. 자동 과전류 차단은 이번 관측 경로와 별도 설계다.

## STM32 ADC 전류 센서 방향 검토

사용자 제안은 **상용 계기 구매 대신 센서·ADC·텔레메트리 수집 기능을 추가하는 선택**이다. 부품비와 반복 수집 편의의 장점이 있고, 아날로그 회로/샘플링/교정/전송을 검증하는 구현 시간이 추가된다. 정확한 기준 계측기를 이미 확보한 것처럼 취급하지 않는다.

### 우선 후보와 가격

- **Pololu #5241, ACS71240KEXBLT-030B3 Current Sensor Carrier, ±30A / 3.3V.** [모듈 제조사](https://www.pololu.com/product/5241), [Allegro 센서 데이터시트](https://www.allegromicro.com/-/media/files/datasheets/acs71240-datasheet.pdf)에서 전원3.0~3.6V, 명목0A 출력1.65V, 감도44mV/A, 아날로그 출력과 전력 경로를 확인했다. 3.3V 버전의 명목 ±30A 출력은0.33~2.97V다. 실제 공차·전원 순서·과입력 보호는 회로 검토에 포함한다.
- [디바이스마트 해당 모듈](https://www.devicemart.co.kr/goods/view?no=15515618)의10/19 HTML에서 VAT 별도8,400원/포함 **9,240원**을 확인했다. 이는 모듈 표시가이며 배송·전력 연결/고정 부속과 실재고/납기·최종 결제액은 미확정이다. IC 단품 가격과 조립된 모듈 가격을 구분한다.
- [Pololu의 전력 연결 설명](https://www.pololu.com/product/5241)에 따른 굵은 전선/단자 연결과 절연 고정이 필요하다. 모듈의 측정 범위30A를 모든 커넥터·배선의 연속 허용 전류로 대입하지 않는다. 모터 동력 전류는IP+/IP− 경로로만 통과시키며 STM32 핀·브레드보드·신호용 점퍼로 흘리지 않는다.
- 저가ACS712 모듈은 별도 대안이다. [ACS712 제조사 자료](https://www.allegromicro.com/en/products/sense/current-sensor-ics/integrated-current-sensors/acs712)는5V 전원을 요구하므로 아날로그 출력의STM32 직접 연결을 전제하지 않는다. 이번에는3.3V 출력 모듈을 우선한다. ACS71240과ACS712의 모델/감도/전원 사양을 혼용하지 않는다.

### ADC 핀과 전력 경로

- 실제 `.ioc`에는ADC가 구성되지 않았고, `main.c`에도ADC 초기화/수집이 없다. PA0/PA1은TIM5 엔코더, PA2/PA3은USART2, PA5는LED다. PA4/PB0은기존 배터리/rail 진단 예약이므로 이번 전류 후보에서 우선 피했다.
- **PC0→ADC1_IN10 후보.** [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf)의PC0/ADC123_IN10을 확인했고 현재 `.ioc`에PC0 배정이 없음을 대조했다. 보드 커넥터·만능기판 실물/net 연결과CubeMX 구성을 확인하기 전에는 확정 배선으로 사용하지 않는다. 디지털 핀의5V tolerant 표기는ADC 입력 허용 전압을 뜻하지 않는다.
- 첫 후보 전력 경로: **K1 87→센서IP+→센서IP−→MDD10A B+**. 센서 신호 전원은STM32와 맞는3.3V/GND, VIOUT는입력 필터/보호 검토 후ADC로 연결하는 설계다. [기존 K1/MDD 배선 기록](../verification/27_T_ESTOP_005A_Motor_Disconnected_Rail_and_Safe_Restore_Report_2026-09-23_ko.md)을 근거로 한 계획이며 오늘 배선을 바꾼 것이 아니다.
- 이 위치는 **드라이버의두 모터 합산 DC 입력 분기 전류**를 관찰한다. 배터리 전체 전류·각 모터 권선/RMS 전류와 구분한다. 배터리 전체 측정이 필요하면 추후 분기 전 위치를 별도로 검토한다.

### 수집과 검증 범위

1. 모듈 선택·부속·전원/입력 필터·고정·실물 핀을 확정한다. 센서와ADC의전원 순서, 무전원 MCU로의역급전, 출력 포화와단선 시의처리를 회로/데이터 유효성 설계에 포함한다.
2. 우선 ADC raw와입력 전압을 읽고XL830L의전압 측정값과 교차 확인한다. **실제 무전류 조건**의센서 영점을 확인한다. DISARMED/대기 소비전류를임의로0A 처리하지 않으며, 비교하는USB 전력계의정확도가 미확정인 점도 보존한다.
3. 명목식 `I_A=(VOUT−VZERO)/0.044`에실측 영점과ADC 기준 전압/감도를 적용한다. 3.3V/12bit의이상적양자화는약18mA/count이지만 이것을전체 정확도로 쓰지 않는다. 센서 offset/gain·ADC·기준 전압·접촉·잡음의한계가 남는다.
4. 아날로그 저역통과 필터와ADC 샘플 주기를 함께 정하고, 기존 모터 제어/timeout을 지연시키지 않는주기 수집·평균·mA 환산을 구현한다. 약19kHz PWM을 느린ADC 평균만으로 읽어 순간 피크/RMS를 얻었다고 기록하지 않는다. 정확한RC·주기·DMA/interrupt 방식은 후속 설계다.
5. 계획 데이터는 `bus_current_ma`·ADC raw·측정 유효성이다. UART TEL 길이/파서→ESP JSON→브라우저 관찰 스크립트까지 계약을 맞춘다. MCU 시각과PWM/CPS를 함께 보존해 조건별 전류 변화를 해석한다. 센서FAULT를 기존PC7 E-stop 회로에 즉시 합치거나 수치만으로 자동 정지시키는 범위는 아니다.
6. PC 검사/사용자 빌드·플래시·수집 검증 후현재 출력의대표 구동에서전류·온도·CPS를 비교한다. 센서 설치 전선 변경과새 펌웨어에필요한 관련 검사만 수행하며 완료한 과거 gate 전체를 다시 시작하지 않는다.

현재는 **부품/설계 검토**다. 펌웨어는 사용자 입력 원칙이며 새 코드·CubeMX 재생성·빌드/플래시·배선·실측은 수행하지 않았다. 관측용 전류ADC가이번 요청으로 선행 검토되는 것이며, 기존 배터리ADC/자동 저전압·rail 안전 진단 계획까지 구현 완료하거나 자동으로 확장한 것은 아니다.

## 전용 DC 전류계 추천과 측정 계획

**이전 검토 이력:** 사용자가8만 원대 비용을 거절하고센서 모듈+ADC 방식을 선택했으므로 현재 구매안이 아니다.

- **추천 모델:** UNI-T UT210E. [제조사 개별 제품 사양](https://meters.uni-trend.com.cn/content/1354.html)에서 DC2/20/100A, 최소 표시 분해능1mA, ZERO/HOLD, jaw17mm를 확인했다. 최소 표시 한 자리는 정확도가 아니다. 최대100A 수치보다 낮은 전류 범위와 영점 기능이 이번 선택의 근거다.
- **조회 가격:** [국내 판매 페이지](https://uni-tnm.com/product/ut210e-mini-clamp-meter-클램프-미터소형/113/)의80,300원+기본 배송4,400원=84,700원. BUY/SOLD OUT 문구가 함께 추출돼 실제 주문 가능 상태는 확정하지 않았다. 표시가를 결제액·확보된 재고로 기록하지 않는다.
- **설명서 대조:** 위 판매처가 제공하는 [UNI-T 영문 설명서](https://damoatool02.cafe24.com/pdf/Uni-T/UT210E%20English%20Manual.pdf)의 제조사 스캔(2018 REV.2)에서 초당2~3회 갱신, 단일 도체 클램프, DC 선택·ZERO 절차를 확인했다. 구판의 DC2A 범위는1mA/±(2%+8digits),20A 범위는10mA/±(2%+3digits)로 되어 있어 제조사 웹페이지의 요약 정확도만 모든 범위에 일괄 적용하지 않는다. 수령품의 설명서/리비전을 기준으로 최종 기록한다.
- **용도:** 정상 구동 중 공급 전류의 크기·조건 간 변화를 표시값으로 관찰한다. 빠른 기동 피크, 약19kHz PWM의 전류 파형/RMS, 자동 연속 로깅을 지원하는 것으로 선정하지 않았다. 표시값/일반 최대값을 실제 순간 피크로 해석하지 않는다.

- 처음에는 DC20A 범위로 관찰한다. 더 낮은 범위는 먼저 관측한 전류와 수령품 설명서를 근거로 선택한다. 두 모터 각각의12V 정격1.44A·stall9A 제조사 회신은 참고 입력이며, 이를 현재15/20% PWM의 배터리 전류나 순간 최대값으로 환산하지 않는다. [모터 회신](../../assets/vendor/wheeltec/2026-08-17_mg540p30_12v_support_reply_ko.md).

- 기록할 항목은 배터리 전압, CMD/PWM, 좌우 CPS, 공급 전류의 표시 범위, 주변/모터/드라이버 표면 온도와 경과 시간이다. 한 계기로 두 분기 위치를 잰 값은 동시 측정으로 기록하지 않는다.
- 전체/드라이버 입력 전류만으로 어느 모터의 권선 전류가 큰지, 오른쪽 정체 원인이 마찰/기어/전기 중 무엇인지 확정하지 않는다. 개별 모터 PWM 전류와 과도 파형 계측은 이번 기본 공급 전류 관측 범위 밖이다.

## 클램프 접근성과 현재 배선 배치 검토

- 사용자 지적에 따라 전류 범위뿐 아니라 실제 클램프 접근성을 검토했다. 근거는 [10/2 하부 버스바 사진](../../assets/photos/wiring/2026-10-02_01_chassis_lower_busbars_wiring_top.jpg), [스위치 뒤 배선](../../assets/photos/wiring/2026-10-02_02_chassis_switch_harness_oblique.jpg), [상부 전장 사선 사진](../../assets/photos/wiring/2026-10-02_04_electronics_deck_wiring_oblique.jpg), [상부 평면 사진](../../assets/photos/wiring/2026-10-02_05_electronics_deck_wiring_top.jpg)과 10/18 궤도·보드 장착 및 배터리 단독 운용 기록이다. 사진은 궤도와 MCU 본체 장착 전이므로 현재 여유 치수나 실제 장착 가능 여부를 확정하지 않는다.
- [UT210E 제조사 사양](https://meters.uni-trend.com.cn/content/1354.html)은 턱 개구 17mm, 외형 175×60×33.5mm다. 개구 치수는 필요한 주변 공간과 같지 않다. 턱을 열어 단일 도체를 감싸고 완전히 닫을 공간, 본체를 지지할 공간이 필요하다. 전선 끝을 분리해서 관통시키는 방식은 아니다.
- **S1 OUT→Bar+:** 하부 버스바·릴레이·묶음 배선과 상판 때문에 조립 상태의 접근성이 불리하다. 회로상 측정점은 맞지만 그대로 손쉽게 클램프를 걸 수 있다고 한 이전 계획은 보완이 필요하다.
- **K1 87→MDD10A B+:** MDD 전원 단자 앞쪽의 휘어진 전원선 구간은 하부보다 접근 후보로 유리하다. 다만 두 전원선이 가까이 붙어 있고 S0/S2·상판 가장자리가 인접하므로 한 가닥만 감싸는 실물 여유는 미확정이다. 색상만으로 B+를 식별하지 않는다.
- **외부 배터리 연결 리드:** 내부보다 접근 후보로 유리하지만 +/− 중 한 가닥을 분리해 감쌀 여유가 있어야 한다. 필요하다면 정격이 맞는 측정용 연장 하네스로 공간을 만들 수 있으나 현재 제작·설치한 것은 아니다.
- 결론은 클램프 사용 불가능이 아니라 **현재 조립 상태에서 반복 주행 로깅용으로는 불편하며, 접근 구간을 확보한 벤치 검증 도구에 더 적합**하다는 판단이다. 센서/ADC 방향은 유지하되 센서도 K1→MDD 전력선의 직렬 삽입, 절연 고정 공간과 신호선 경로가 필요하다. 다음은 센서 설치 위치와 부속 설계이며 사진만으로 무개조 장착을 보장하지 않는다.
- 이번 작업은 사진·문서·제조사 사양 대조와 문서 보완이다. 구매, 전원 조작, 배선 변경, 펌웨어 작업이나 새 실측은 없다.

## ADC 입력 핀 수와 사용 가능 후보 대조

- 사용자 질문에 따라 현재 `.ioc`, GPIO/TIM 초기화, 핀 배정 문서와 ST DS10693 Rev11/UM1724 Rev17을 대조했다. F446RE LQFP64 외부 ADC 가능 핀은 PA0~PA7/PB0~PB1/PC0~PC5의 16개다.
- 다른 기능으로 설정된 5개(PA0/PA1 엔코더, PA2/PA3 UART, PA5 LED), IMU 배선 2개(PB1/PC4), 전압 ADC 예약 2개(PA4/PB0), 선택적 gate/brake 예약 1개(PC5)를 보존하면 추가 후보는 **PA6/PA7/PC0/PC1/PC2/PC3의 6개**다. 전류 후보 PC0 사용 뒤에는 신규 여유 5개가 남는다. 전압 예약 2개까지 합하면 ADC 용도로 계획 가능한 핀은 8개다.
- 펌웨어에 미배정된 핀 11개를 모두 사용 가능하다고 해석하지 않는다. 현재 ADC 측정 구현은 0채널이며, 후보 수는 설정/실물 배선 완료 수가 아니다. Arduino A0~A5 외에도 ST morpho 핀을 사용할 수 있다.
- [핀 배정 문서](../../01_System_Architecture/06_MCU_Pin_Allocation_Candidate_ko.md#adc-입력-수와-현재-여유--2026-10-19)에 채널·커넥터 위치를 추가했다. PC0는 기본 연결 기준 A5/CN7 pin38이다. 실제 solder bridge와 만능기판 인출 확인은 남으며 배선·펌웨어·빌드·실측 변경은 없다.

## 전류와 LiPo 전압을 함께 관측하는 방안 검토

- 당시 사용자는 전류 측정과 LiPo 전압 측정을 함께 진행하는 방안에 대한 의견을 요청했고, PC0 전류 + PA4 upstream 전압의 관측용 2채널을 함께 설계하도록 제안했다. 이후 아래 MVP 범위 재정립에 관측용 2채널을 포함했다. 자동 저전압/rail 진단 범위는 후속으로 유지한다.
- PA4 후보는 S1 뒤 Bar+ / K1 앞 전압을 분압·보호·필터 회로로 읽는 구성이다. 배터리에서 공급되는 주전원 전압이지만 배터리 단자 자체와는 배선/접점 전압 강하 차이가 있을 수 있다. PC0 후보는 K1→MDD B+ 분기의 전류이므로 전체 배터리 전류와 구분한다. 두 값을 곱한 결과를 로봇 전체 소비전력으로 표시하지 않는다.
- 전압·전류·PWM·CPS를 MCU 시각과 함께 수집하면 구동 부하와 공급 전압 변화의 상관관계를 확인할 수 있다. 이것만으로 배터리/배선/기계 원인이나 잔량을 확정하지 않으며 전체 팩 전압은 개별 셀 감시를 대신하지 않는다.
- ADC 수집/기준 전압/텔레메트리 확장은 함께 설계하되, 분압 회로를 STM 연결 전에 DMM 전압 모드로 검증하고 전압 채널부터 확인한 뒤 전류 채널 영점/환산·통합 로그를 검증하는 순서를 제안한다. 기존 설계의 divider/clamp/bleed 값은 아직 NOT SELECTED이며 3S 전압을 ADC에 직접 연결하지 않는다. ADC 순차 변환과 PWM 리플을 고려해 샘플 시각·필터 조건을 정해야 한다.
- PB0 downstream 전압과 자동 차단은 이번 2채널 관측 제안에 포함하지 않는다. LiPo 셀 알람·현재 감독하 운용 조건을 유지한다. 다음은 사용자 방향 선택 후 모듈과 분압/보호/필터·고정 부속 및 연결도를 확정하는 것이다. 코드·배선·새 실측 변경은 없다.

- **후속:** 정량 전류 측정, PC0 전류/PA4 전압 회로·ADC/보정·TEL/브라우저와 전류/온도 상관 분석. MVP-014·REQ-MON-001~003·T-MON-001~003을 SHOULD / POST-MVP, DEFERRED로 변경했다. 상세 후보와 기준은 보존했다.

- **이유:** 단순히 측정 장비가 없어서 검증을 생략하는 결정이 아니다. 이번 인수의 목표·사용 조건과 후속 상태 모니터링 기능을 나눈 것이다. 실제 하중 기능에 문제가 남거나 발열 이상이 관측되면 해당 기본 구동 문제는 MVP 미결로 남는다.
- **다음 작업:** 잔여 실제 정지·거리 인수 준비와 GM-1312 외부 온도 관측 계획을 ADC 구매/구현과 독립적으로 진행한다. IMU 첫 후속 순서는 유지하고 전류/전압 모니터링은 별도 후속 묶음으로 진행한다. 기존 제외 합의한 재검토를 다시 시작하지 않는다.
