D2 양끝과 K2 coil Net의 배선이 먼저 완성돼야 하므로, 현재 open 결과를 D2 불량이나 완성 배선
PASS로 해석하지 않는다.

## Assembly-Prerequisite Correction

`C-03` U1.2↔U1.3 측정에서 continuity가 없었고, 사용자는 해당 GND 그룹을 아직 연결하지 않았다고
확인했다. 따라서 이 결과는 `FAIL`이 아니라 `NOT RUN / ASSEMBLY PENDING`이다. 부분 실장 상태에서
부품 자체의 U1/R14/K2 검사는 유효하지만, `C-03~C-08` intended-Net continuity는 각 Net의 Wire와
joint를 완성한 뒤에만 판정한다.
