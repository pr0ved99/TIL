# 2026-11-25 진행 기록

11/24 밤 실측 후 11/25에 3V3 점퍼와 프로브 위치를 확인하고 마감했다. 사용자 입력·저장·빌드(오류/경고 0)·플래시를 거친 STM32 벤치 이미지에서 PA4와 VREFINT를 각각 읽었다. [시험 49와 세 구간 원본](../verification/49_PA4_VREFINT_Bench_2026-11-25_ko.md)

- 1.797 V, 1.513 V, 영점의 독립 구간에서 유효 589·608·1,021쌍을 확인했다. VREFINT_CAL=1508이며 두 비영 입력에서 PC 보정 환산값이 DMM에 더 가까웠다.
- 영점에서는 3V3 점퍼를 뺀 채 9.95 kΩ 양단 0 V, 같은 GND와 A2 점퍼 끝 사이 0.4 mV를 읽었다. PA4 평균 3.92카운트, 최대 73카운트의 원인은 미확정이다.
- 종료 시 두 USB·배터리·외부 전원 두 2핀 분리를 사용자가 확인했다. 마지막 배선은 A2에서 9.95 kΩ을 거쳐 GND로 이어지고, 11.82 kΩ의 3V3 쪽은 개방이다.
- 집에서는 2-rank 타이머 트리거·DMA 버퍼와 오류 검출 기준을 설계한다. 노트북에서는 ELEC-01의 보호 저항·분기 퓨즈·환산 오차 검토를 이어간다. 제작 Shield·실제 배터리 계측·자동 저전압 정지는 후속이다.
