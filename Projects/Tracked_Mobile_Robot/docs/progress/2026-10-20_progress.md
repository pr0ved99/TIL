- 사용자 제시 [RCBank BX100 제품 페이지](https://www.rcbank.co.kr/shop/goods/goods_view.php?goodsno=11475) 화면으로 사용 모델을 식별했다. 버튼 조작 뒤 보고한 `3.40`은 셀당 경고 설정 표시3.40V다. 조작 전 설정값이나 실제 경고 발생 전압으로 소급하지 않는다.
- 셀 표시값은 순서대로4.05/4.09/4.06V. 산술 합계12.20V, 최대−최소0.04V이며 별도 총전압 실측값이 아니다. 정확도 교정·실제 저전압 경고/경고 시 정지 시험은 미수행으로 REQ-POWER-004/T-PWR-004 PARTIAL을 유지한다. 설정값을 범용 안전 한계로 판정하거나 과방전 유발 시험을 추가하지 않았다.
- 분리 안내 뒤 사용자가 “다음”이라고 했고, 이어 알람·주전원 분리 완료를 명시했다. **현재 알람·로봇 주전원 분리 완료**로 기록한다. 같은 종료 상태를 다시 묻거나 완료한 물리 절차를 반복하지 않는다.
- [1m 거리 비교 준비·기록표](../plans/templates/distance_1m_session_template_ko.md)를 추가했다. 고정 차체 기준점·독립 바닥 실측·유효 ARM/DISARM count 구간·초기14톱니 모델의 추정 거리·오차를 한 회차로 묶는다. 목표1,000mm를 실제 이동값으로 대체하지 않으며 회전/휨·슬립·수동 이동의 영향을 기록한다.
- 기록표는 NOT_RUN이다. GM-1312 수령/프로브·수치 온도 기준 확정 → 기본 온도 관측·판정 → 조건 충족 후 지상1m 순서를 유지한다. 이 정리에서 firmware 수정·빌드/플래시·추가 구동·Git/Notion 게시를 수행하지 않았다.
- 문서 확인: 관련10개 문서의 로컬 파일 링크519개·사용한 제목 대상2개, 전압 합계/차이·거리 계수와 요구사항 판정 범위를 확인했다. 문서 범위 `git diff --check` 통과. 새 측정값이나 firmware 검증 결과를 만든 것은 아니다.

## 현재 보정값 기준 거리 검증과 실측 비교 도구

- 사용자 “보정값 적용한 이동거리 검증이 지금 할 작업같다”에 따라 현재 보정값 기준선의 거리 검증 준비로 진행했다. 실제 주행은 기존 기본 온도 판정 후이며 전류 계측/ADC를 선행 조건으로 추가하지 않았다. PWM 단계별 CPS·전류·발열 특성 비교와 IMU 제어는 이 회차에 섞지 않는다.
- `analyze_encoder_distance.py`에 외부 실측 변위 비교를 추가했다. `--actual-distance-mm`와 명시적인 `--boot-id`/`--arm-seq`로 유일한 ACCEPTED 구간을 선택한다. 입력과 모델 hash·원래 구간 판정은 보존하고 좌/우/평균 추정 거리 및 평균 기준 부호 있는/절대/백분율 오차를 계산한다.
- 전진 양수/후진 음수. 0·비유한/비십진 입력, 빠진/잘못된/중복 구간 ID와 REJECTED 구간은 비교를 거부한다. 오차는 원시 count 차이와 유리수 계수로 계산하며 표시 반올림값을 재사용하지 않는다. 계산 성공을 실제1m 정확도 PASS로 판정하거나 gain/거리 계수를 자동 수정하지 않는다.
- 기존36개와 새 비교9개, 총45개 PC 검사 PASS. 기존 공중 raw3건 재생·입력 보존, 합성 전후진/소수/오차0/잘못된 부호·구간 선택/거부·CLI 정상/오류와 기존 출력 보존을 포함한다. [검증 기록](../../assets/logs/wifi_link/2026-10-20_encoder_actual_distance_comparison_review/validation.json). 합성 실측 입력을 지상 결과로 사용하지 않았다.
- [기록표](../plans/templates/distance_1m_session_template_ko.md)와 도구 사용법/백로그/인수인계에 반영했다. 기준선은 전진0.96/후진0.93, 일반 cap15%, 14톱니 초기 거리 계수다. 현재 알람·주전원 분리 완료. 새 firmware 입력/build/flash·통전/주행·Git/Notion 게시 없음.
