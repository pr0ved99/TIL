| 항목 | 결과 |
| --- | --- |
| Command timeout | `timeout_ms=300`; UART-calibrated frame-end-to-last-edge 약 `299.690 ms`; 정지 후 약 `8.939 s` 재출력 없음 — `PASS` |
| Software fault | PA5 marker 뒤 expected next pulse 억제, 이후 edge 0, 약 `2.052 s` no-reactivation — `PASS` |
| External reset, pull-down 없음 | DIR/PWM 네 선이 NRST LOW 동안 약 `159 ms` HIGH — `FAIL`, root-cause evidence 보존 |
| External reset, signal별 `10 kΩ` pull-down | 5 s/20 M samples에서 DIR/PWM 네 선 transition과 HIGH sample 0 — `PASS` |
| Final safe source/runtime | 모든 hook `0U`, contract `15/15`, post-READY TEL 155/155 safe over 15.4 s — `PASS` |

Fault marker는 PWM LOW phase에서 발생했으므로 marker보다 `5.25 us` 앞선 last fall을
"fault latency"로 부르지 않는다. 이번 evidence가 입증하는 범위는 expected next pulse 억제와
reset 전 latch다.
