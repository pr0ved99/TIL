# 2026-11-21 진행 기록

## SIM-03 평지 정지 자세

사용자가 RViz에서 차체 전방과 LiDAR 배치를 확인했다. Gazebo의 `empty` 월드에서 기존 TMR을 바닥 기준 20mm에 생성하자 처음에는 수평으로 보였고 이후 뒤로 기울었다. 사용자가 관찰한 월드에서 `gz model -m tmr -p`로 읽은 피치는 −0.192845rad(−11.05°)였다.

기존 모델의 좌우 가상 바퀴는 차체 중앙의 같은 축에 있다. 궤도 시각 형상에는 앞뒤를 받칠 충돌 형상이 없어 차체가 피치 방향으로 회전할 수 있었다. 차체 중심에서 앞뒤로 각각 90mm에 반지름 10mm의 구형 충돌 형상을 추가했다. 수평 자세에서 바닥과의 간격은 0.2mm다. [모델](../../05_ROS2_Integration/src/tmr_description/urdf/tmr.urdf.xacro)

별도 Gazebo Harmonic 월드에서 같은 바닥·중력·1ms 물리 스텝을 사용해 네 모델을 20mm 높이에서 놓았다. 속도 명령 없이 1초·10초·60초에 월드를 일시정지하고 모델 자세를 읽었다. 수평에서 시작한 기존 모델의 60초 피치는 −11.04909°, 수정본은 +0.12731°였다. 초기 피치를 ±5°로 준 수정본 두 개도 1초·10초·60초 표본에서 각각 ±0.12731°였다. [자세 표본](../../assets/logs/ros2/2026-11-21_tmr_ground_support/pose_samples.csv)

사용자는 Gazebo에서 원래 `tmr`과 옆에 배치한 수정본 `tmr_supported`의 자세 차이를 확인했다.

## SIM-03 평지 전진과 정지

`tmr_sim`의 주행 launch는 별도 Gazebo 파티션에서 `empty` 월드를 열고, 지지 접점이 있는 TMR에 좌우 차동 구동과 관절 상태 플러그인을 활성화한다. ROS에서 Gazebo로 `/cmd_vel`을 전달하고, Gazebo에서 ROS로 `/odom`, `/tf`, `/joint_states`, `/clock`을 전달한다. 시뮬레이션 시간으로 실행한 `robot_state_publisher`가 고정 TF와 바퀴 TF를 제공한다. [실행 방법](../../05_ROS2_Integration/README.md#gazebo에서-전진과-정지-확인)

- 별도 ROS 도메인 85에서 `forward_stop`으로 +0.10m/s를 시뮬레이션 시간 2초간 지시한 뒤 0 명령을 보냈다. 기록 회차에서 Gazebo 월드의 전방 변위는 0.197923m, 바퀴 오도메트리 변위는 0.198300m였다. 주행 중 관측한 최대 오도메트리 선속도는 0.100m/s였다.
- 정지 후 두 차례 읽은 월드 위치가 6자리 소수 정밀도에서 일치했다. 두 표본 모두 오도메트리 선속도와 각속도가 0이었고, 정지 시 `odom → base_footprint` TF의 x 값이 오도메트리와 일치했다. 두 바퀴의 관절 상태 및 차체·센서 프레임을 확인했다. [명령과 자세 표본](../../assets/logs/ros2/2026-11-21_tmr_forward_stop/result.json)
- 사용자가 도메인 85의 Gazebo에서 직접 전진을 확인했다. 이후 월드의 x 좌표는 0.396308m였고, 조회한 오도메트리 속도의 여섯 성분은 모두 0이었다. 실물 궤도 슬립과 통신 유실 시 자동 정지는 별도 검증 항목이다.

## SIM-03 평지 후진과 정지

`reverse_stop`은 전진과 같은 주기와 지속시간을 사용하고 선속도의 부호를 바꾼다. 사용자 월드와 분리한 도메인 86의 평지에서 먼저 기존 `forward_stop`의 전진·정지를 다시 확인한 뒤 후진했다. 후진 시 월드의 x 변위는 −0.198023m, 오도메트리는 −0.198400m였으며 주행 중 오도메트리 선속도는 −0.100m/s에 도달했다. 정지 후 두 표본에서 선속도와 각속도가 0이었고 월드 위치가 일치했다. 이어서 도메인 85의 위치와 정지를 읽고 다음 절의 좌우 회전으로 진행했다. [후진 측정값](../../assets/logs/ros2/2026-11-21_tmr_reverse_stop/result.json)

## SIM-03 제자리 회전 실습

사용자가 `turn_stop`의 각속도를 `±pi / 8`로 수정하고 도메인 85에서 좌우 회전을 한 번씩 실행했다. [사용자 실행 로그](../../assets/logs/ros2/2026-11-21_tmr_half_turn/user_commands.txt)에서 양수·음수 각속도와 각 실행의 0 명령을 확인했다. 정지 후 Gazebo 차체의 최종 yaw는 −8.02°, 바퀴 오도메트리의 최종 yaw는 −7.11°였다. 이 두 값은 좌·우를 합친 최종 자세다.

별도 Gazebo 월드에서 같은 코드를 실행해 각 명령의 시작과 정지 후 자세를 따로 읽었다. 2초 동안 22.5°/s를 지시하도록 설정했을 때 좌회전 변화량은 월드 +42.16°·오도메트리 +37.48°, 우회전은 월드 −50.23°·오도메트리 −44.64°였다. 두 회차 모두 관측한 오도메트리 각속도가 지시값에 도달했고 정지 뒤 두 표본에서 월드 위치와 방향이 유지됐다. 방향과 정지를 확인했다. 각도 차이를 분석할 때는 명령이 전달된 시간과 바퀴 오도메트리·월드 자세의 차이를 따로 본다. [각 방향의 자세·바퀴 회전량 표본](../../assets/logs/ros2/2026-11-21_tmr_half_turn/result.json)
