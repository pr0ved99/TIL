# 2026-10-17 진행 기록

## 한눈에 보기

**UR-02와 UR-03 AC-S01~08의 선택한 zero-only 실물시험 묶음을 마감했다.** 모터 동력을 차단한 조건에서 제어·거부·정지·복구와 UART/PWM/PC7을 확인했다. 항목별 근거와 남은 경계는 [보고서37](../verification/37_Zero_Only_ACS_Bench_Closeout_2026-10-17_ko.md)이 기준이다.

- AC-S02 동일 A ticket의 B CMD 거부/A 성공, B ARM 거부/A 유지, B DISARM 정지 근거 확보.
- AC-S03 탭 전환 정지·자동 재무장 없음; AC-S04 CMD ACK 한 개 유실과 정상 이미지 복원; AC-S06 CMD_TIMEOUT 뒤 CMD-only NOT_ARMED와 새 수동 ARM/zero/DISARM 완료.
- 10/16의 정상 PWM0·만료 ARM·ESP/STM reset·sense latch·늦은 DISARM ACK/BLOCKED 및 수동 복구·정상 이미지 복원도 항목별 표에 통합했다.
- 원본 실패·미완료를 보존했다. B DISARM helper 오판과 실제 B 정지 성공을 구분하고, AC-S06 restore run01 자동 정지 원인·D1 reset transient는 미확정으로 유지한다.

## 코드와 근거

현재 ESP mode0와 STM 시험 switch14개0U를 확인했다. 마지막 B ARM 시험의 boot3570331004, A6/B7/control8, 최종 DISARM573834470 ACK/새 정지 TEL·IDLE/DISARMED와 실제 PWM LOW를 대조했다. B는 한 페이지 안의 별도 WebSocket이며 두 번째 탭 전환은 필요 없다.

이번 문서 마감에서 펌웨어를 수정하거나 보드 빌드·플래시·전원 조작을 하지 않았다. 이전 사용자 입력·빌드/플래시·실물 관측은 각 회차에 보존했다. 선택적 hook과 UART 줄 취소 구현, PC 검사, 원시 캡처/해독 결과를 Git 반영 대상으로 정리했다.

## 검증

- 현재 저장본 native PC 검사 5개 runner 모두 exit0: UART recovery, partial injection, watchdog, late ACK, CMD ACK drop의 `--saved`.
- [마감 검사 manifest](../../assets/logs/wifi_link/2026-10-17_acs_closeout/validation.json)에 명령·결과·소스 hash와 원본 PC 출력을 보존했다. PC 출력의 보드 미검증 문구는 해당 runner의 증거 경계이며 별도 실물 회차를 취소하는 판정이 아니다.
- ESP/STM 정규화 소스 hash가 마지막 회차와 일치한다. 소스 식별값은 플래시 바이너리 readback과 구분한다.
- 원시 로그·JSON·소스 snapshot·PVS의 줄바꿈 자동 변환을 막도록 Git 속성을 추가했다.
