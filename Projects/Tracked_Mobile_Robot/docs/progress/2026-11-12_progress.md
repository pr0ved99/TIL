# 2026-11-12 진행 기록 — 주파수 분석과 디지털 필터의 역할 구분

사용자는 alias 때문에 주파수 성분을 다르게 해석하게 되는 점은 이해했다고 보고했고, 보드가 주파수를 분석해 디지털 필터링할 예정이라 이 내용을 배우는지 질문했다.

현재 인수인계, 학습21의40-1 수집/DMA 비교안, 온도 명세23의 코드 평균 후 환산 순서를 확인했다. 현재 기본 비교안은 일정 간격 ADC 수집과 정해진 샘플 평균/환산이다. FFT로 잡음 주파수를 실시간 식별하여 필터를 자동 조정하는 기능은 현재 계획에 포함하지 않는다. 이번 제한 검색에서 애플리케이션 소스의 FFT/arm_rfft/arm_cfft/MX_ADC*_Init/HAL_ADC_Start_DMA 표기는 발견하지 못했으며, 이를 포괄적인 구현 검증으로 확대하지 않는다.

설명 요점: 평균 자체가 디지털 필터이고 주파수 분석을 선행해야 실행되는 연산은 아니다. 설계 시 주파수별 입력/감쇠/alias를 검토하는 이유는 원하는 변화를 보존하면서 간섭을 줄이는 수집·필터 조건을 정하기 위해서다.19,001Hz가100Hz 수집에서1Hz로 접히면 샘플만으로 실제1Hz 변화와 구분하지 못하므로, 이후 FFT나 필터가 원래 성분을 자동 복원한다고 가정하지 않는다. 전단 아날로그 경로/원시 수집과 결과 간추림 전 디지털 필터의 역할을 구분한다.

사용자 이해 보고는 해당 개념 범위로만 기록한다. 기존40-3 비교 기준과 다음 포트·전원 조건표 순서는 유지하며 새 FFT/적응 필터 실습·펌웨어 구현·빌드/플래시·실물·외부 게시를 추가하지 않았다. 기존 변경은 보존했다.

## 온도 B안 이해 보고와 오늘 결론

사용자는 alias의 의미와 실제 저주파 신호를 사후 필터로 구별할 수 없는 이유를 질문한 뒤 온도 B안으로 돌아왔다. B는2kHz/1,000개·최근0.5초 평균이며 출력은계속1Hz다. G_B(0.9)≈0.698647(69.86%)와 출력 alias |0.9−1|=0.1Hz를 분리해 설명했다. A는G_A(0.9)≈0.109292(10.93%)로 진폭은 더 작지만 같은0.1Hz로 보인다. 이 비율은 ADC 전압 진폭 기준이며 온도 비선형 환산에 그대로 적용하지 않는다.

사용자 “그래 이해했어. 일단 오늘은 여기까지만 하자. 마무리하고 정리해”를 해당 설명의 이해 보고와 다섯 항목 마감 요청으로 기록한다. 전체40장 수기/모든 개념 이해 완료로 확대하지 않는다. 기존37-2 수기/두 시정수 원리 이해 보고는 유지한다. Notion의 기존40-2·40-3 필기 원문 존재를 확인했으나 원문 존재만으로 전체 수기 완료를 판정하지 않는다.

**설계 판단:** 전압·전류2kHz/200개·100ms, 온도 A2kHz/2,000개·1초 평균을 비교 기준으로 유지한다. B는실제응답여유가부족할경우잡음/alias/구간대표성과함께평가할대안이다. 기존100Hz첫DC시험안유지. A/B 명목 최대응답의극한약1.975/1.487초는수학모델이며실제PASS가아니다.
