## 확정한 연결 구성

기존 [전원 배선 기준](../verification/27_T_ESTOP_005A_Motor_Disconnected_Rail_and_Safe_Restore_Report_2026-09-23_ko.md)과 사용자 목록을 대조했다.
사용자는 `F1 → S1 → Bar+`로 연결했다고 확인했으며, 이후 K1 30 분기와 F2 직렬 경로도 맞다고 답했다.

| 연결 | 확인한 구성 |
| --- | --- |
| + 분배 | LiPo+ → F1 → S1 → Bar+; Bar+에서 XL4015 #1/#2 IN+, K1 30, F2 IN으로 분기 |
| − 분배 | LiPo−, MDD10A B−, XL4015 #1/#2 IN−를 Bar−에 연결 |
| 모터 전원 | K1 87 ↔ MDD10A B+ |
| K1 코일 | JK1COIL Pin1 ↔ K1 86, Pin2 ↔ K1 85 |
| S0-A NC | Bar+ → F2 → 6P Pin1 → S0-A → 6P Pin2 → JESTOP Pin2 |
| S0-B NC | 6P Pin3/4를 경유해 JESTOP Pin3/4에 연결 |
| S2 NO | 6P Pin5/6을 경유해 JESTOP Pin5/6에 연결 |

JESTOP Pin1은 미사용이며 Pin1–2 점퍼를 추가하지 않는다. 방수커넥터를 생략하는 안은 사용자가 선택하지 않았고 기존 구성 유지로 결정했다.

## 무전원 점검

LiPo·USB·로직분석기 분리, S1 OFF/S0 잠금 조건으로 안내했다. 수치는 사용자 보고이며 계측 화면/자동 로그는 없다.

- 최초 Bar+↔Bar−, MDD B+↔B−, 두 XL4015 OUT+↔OUT−에서 모두 약 0.30V 보고. 프로브 금속 끝끼리 맞대면 0V였다.
- 사용자는 전압이 "2초마다 0.001V씩" 감소한다고 보고했다. 이 보고를 교정된 방전 속도/정밀 시간 측정으로 사용하지 않는다.
- 여분 1kΩ으로 방전 후 Bar는 0V에 근접했다고 보고했다. MDD에는 0.27V가 남아 있어 B+↔B−에 별도로 1kΩ을 적용한 뒤 0V 확인. 두 XL4015 출력도 이후 모두 0V 보고.
- 임시 방전 저항 제거 후 위 네 레일의 +/− 사이에서 지속 도통음이 없다고 보고했다. 이는 저전압 단락 선별이며 절연 내압 시험이 아니다.
- 다음 연결에서 모두 도통음 확인: Bar+↔S1 OUT/K1 30/F2 IN/XL4015 #1 IN+/#2 IN+, Bar−↔MDD B−/#1 IN−/#2 IN−, K1 87↔MDD B+, JK1COIL Pin1↔K1 86, Pin2↔K1 85.
- Bar+↔JESTOP Pin2와 JESTOP Pin3↔Pin4는 각각 S0 해제 시 도통/잠금 시 무도통. JESTOP Pin5↔Pin6은 S2 놓음/누름/놓음에서 무도통/도통/무도통으로 모두 정상 보고.

## 전원 인가 관측

모터 A/B 동력선 분리, MDD B+/B− 유지, USB 분리, STM JP5=E5V/JP1=OPEN을 준비 조건으로 안내한 뒤 사용자가 "진행하자"고 답하고 아래 수치를 보고했다.
측정 중 각 준비 항목의 사진·개별 확인 응답은 없다. 후속 배선 사진에서는 STM/ESP가 빠져 있어 측정 당시 점퍼·보드 장착 상태를 소급 검증하지 않는다. 이번에 모터 구동 명령·UART TEL/PWM 캡처는 수행하지 않았다.

모든 전압은 빨강 프로브를 표의 +, 검정을 해당 −에 두는 DC 20V 측정으로 안내했다. 시점은 안내한 수동 측정 시점이며 계측기로 동기화하지 않았다.

| 조건 | 측정 지점 | 사용자 보고 |
| --- | --- | --- |
| S1 ON, S0 잠금, S2 미조작 | Bar+↔Bar− | 12.11V |
| 동일 | XL4015 #1 OUT+↔OUT− | 5.02V |
| 동일 | XL4015 #2 OUT+↔OUT− | 4.95V |
| 동일 | MDD B+↔B− | 0.50V |
| S0만 해제, S2 미조작 | MDD B+↔B− | 0.48V |
| S2를 눌렀다 뗌 | MDD B+↔B− | 12.11V |
| S0 눌러 잠금, 약 5초 후 | MDD B+↔B− | 1.0V |
| 위 조작 약 30초 후 | MDD B+↔B− | 0.57V |

| S0 해제 후 S1 ON, S2 미조작, 약 5초 후 | **MDD B+↔B−** | **0.52V** |

## 해석과 남은 범위

- 입력 분배와 두 5V 출력의 극성·전압을 확인했다. S0 해제만으로는 MDD 입력이 배터리 전압으로 올라가지 않았고, S2 후 12.11V가 관측됐다. S0 잠금 뒤 전압은 하강했다.
- S1 OFF 때 Bar 전압 하강과 S1 재투입/S2 미조작 때 낮은 MDD 전압을 확인했다. **0.67V는 버스바 값, 0.52V는 MDD 값**으로 구분한다.
- 0.48~0.57V와 0.67V를 0V로 기록하지 않는다. 잔류 충전/역급전 원인과 차단 전압·시간의 최종 수용 기준은 이번에 확정하지 않았다. 기존 [report27](../verification/27_T_ESTOP_005A_Motor_Disconnected_Rail_and_Safe_Restore_Report_2026-09-23_ko.md)의 전체 T-ESTOP-005A PARTIAL을 자동 승격하지 않는다.
- 이번 결과는 재연결 후의 사용자 보고에 따른 기본 점검이다. 전류·발열·차단 과도 파형, 실제 모터 정지, STM PC7/펌웨어와의 결합 검증을 새로 완료한 것은 아니다.
- 펌웨어 수정·빌드·플래시·Git 커밋/푸시는 이번 배선 점검에서 실행하지 않았다. ESP는 최근 확인한 Wi-Fi 단독 앱 기준이며 UART bridge 복원 보고가 없다.
- 마지막 측정 후 **S1 OFF → S0 잠금 → LiPo 분리**를 안내했다. 두 전압값 보고 뒤 사용자가 "분리했고"라고 답해 전원 분리 완료를 확인했다.

## 공유기 STA 연결 확인

- 사용자가 ESP의 `USB` 표기 포트를 사용하기로 했다. VS Code의 `idf.port`와 `idf.monitorPort`는 COM4로 저장돼 있고, PC에서도 ESP USB 직렬 장치(COM4)를 확인했다. 플래시 방식은 UART/esptool을 유지하며 현재 sdkconfig에는 USB 보조 콘솔 출력이 활성화돼 있다.
- 저장된 개인 설정의 `WIFI_LINK_USE_AP=0`을 확인했다. SSID/비밀번호 원문은 출력하거나 이 기록에 저장하지 않았다. ESP32-S3는 공유기의 2.4GHz에 접속하며, PC는 같은 내부망의 유선 연결로도 통신할 수 있다고 설명했다.
- 사용자가 "연결 확인 완료"라고 보고했다. **STA 연결 완료는 사용자 보고**이며 이번 접속 IP·부팅 로그·페이지 JSON은 별도로 받지 않았다. STA 연결 해제/복구 시험이나 STM 통합 완료로 확대하지 않는다.
- 현재 소스는 HTTP 폴링이며 WebSocket은 미구현이다. 다음 작업으로 ESP 단독 WebSocket 상태 전송과 연결 해제/복구 표시를 안내한다. 이후 실제 STM TEL 통합(W4), 무선 명령(W5)을 별도로 진행한다.

## ESP 단독 WebSocket 입력 안내 준비

- [전체 코드·설정·설명·시험 기준](../plans/2026-10-02_ESP_Standalone_WebSocket_Code_Guide_ko.md)을 작성했다. `status_json()` 공통 생성, `/ws` 주기 상태 전송, 서버 종료와 전송 예약의 동기화, 브라우저 무응답/재접속 처리를 포함한다.
- 입력 대상은 `sdkconfig.defaults`, `main/CMakeLists.txt`, `main/wifi_link_main.c`이며 menuconfig에서 `HTTPD_WS_SUPPORT`를 별도로 활성화한다. 개인 SSID/비밀번호는 유지한다.
- 기준 코드의 브라우저 JavaScript 모의 검사 **11개 PASS**, 설치된 ESP-IDF 6.0.2 header의 HTTP API 13개 대조. C 빌드나 실제 WebSocket 실측 결과가 아니다.
- 실제 펌웨어 소스와 빌드 설정은 수정하지 않았다. 사용자가 입력하고 저장 파일 검토를 받은 뒤 직접 빌드·플래시한다. STA의 기존 최대 5회 재시도 한계는 안내에 명시했고 STM/모터 명령은 추가하지 않는다.

## 다음 행동

1. 전원 분리 확인으로 기본 점검 묶음 마무리. 실제 조립 마감 시 위 보호·고정·간섭 항목을 반영한다. 배선 변경/실패가 없다면 완료한 전기 검사를 반복하지 않는다.
2. WebSocket 입력 안내에 따라 사용자가 설정·코드를 저장하면 실제 파일을 검토한다. 이후 사용자 빌드·플래시와 WS-1~4 검증을 한 단계씩 진행한다. 이번 전원 점검 결과로 모터 구동을 자동 재개하지 않는다.
3. 로봇 제어를 재개할 때 ESP의 실제 실행 앱과 전원 구성을 확인한다. [10/1 Wi-Fi 결과](2026-10-01_progress.md#wi-fi-ap-실측--w1w2w3-결과)와 9/30 UART bridge 시험 설정을 구분한다.
