# 2026-10-30 전압 ADC 학습 마감

사용자가 밤 작업 종료와 다섯 항목 정리를 요청했다. 전날 마감 이후 이어진 공차·보정·누설·전원 차단 실습을 묶어 보존한다. 실제 세션 시작/종료 시각은 추정하지 않는다.

## 결과와 근거

전압 분압의 공차·보정·가정한1µA 누설과 일반 스위치 ON/OFF·VDDA 연동·C2 방전을 사용자 GUI에서 확인했다. ON/OFF VADC는2.37135V/123.143µV, 마지막 TRAN은701행과 지수형 하강을 관찰했다.

- ±1% 저항 조합의16V 명목 환산 오차는 +0.269408/−0.265808V, ±0.1%는 약±0.0268V다. 12.6V에서 모델 비율로 보정한12.600V는 실제 계기/보드 보정과 구분한다.
- 1µA 누설 OP는VDIV2.61628V/VADC2.61528V, 해석식 배터리 환산 오차−30.106mV다. VREFINT는 개념 검토이며 실제 코드 취득/구현 없음.
- 스위치 Roff1G/Ron2Ω, R5 47k의 ON 부하와 OFF 풀다운을 확인했다. 변경 K≈6.747204이며 이전 K≈6.106383을 그대로 적용하지 않는다.
- B1은 VDDA>3V이면VCTRL=VDDA, 아니면0이다. V3는10~13.3ms에3.3→0V로 내려가는 학습용 조건이다.
- C2=100pF는VADC–GND 비교값이다. 분압 노드의C1=100nF와 구분한다. TRAN 단위 누락을 수정한 명령은 `.tran 100n 10.35m 10.28m 100n`이다.

## 저장/대조와 수정하지 않은 범위

사용자 콘솔 첨부5701바이트를 그대로 보존하고 SHA256을 대조했다. 대화 OP/화면 관찰은 전사로 표시했다. 회로11개를 KiCad CLI로 netlist 내보내기만 수행해 연결·값을 확인했다. 새 시뮬레이션/빌드/플래시는 실행하지 않았다.

일부 중간 파일의 이름과 저장값이 다르다. `03_01_01`/`03_03`은 ±1% Min, `03_04`는 ±0.1% Max, `03_07`에는V3가 없고 `03_08`은V2고정 baseline이다. 원본을 고치지 않고 실습 README/manifest에 기록했다. **재개 파일03_09는B1·V3·C2가 모두 저장되어 있다.** 워크북의 두 커서는 시각 설정만 있으며 전압 수치 증거가 아니다.

## 판단과 다음 작업

100pF·1V/ms·3V 무지연 감시는 학습용 가정이다. τ4.7µs/99%21.6443µs는 계산값이고 두 커서 전압은 미보고다. 실제 보호 성능·ADC 정확도·실물은 미검증이며 제작 쉴드/MCU/구매 변경과 새 시뮬레이션 실행은 없다. 기존 MVP PARTIAL/OPEN·AI/배치 후속을 유지한다.

03_09 저장 모델에서 실제 ADC 쪽 정전용량과 감지/차단 지연의 근거·적용 조건부터 정리한다. 이후 보호 구조에 맞는 환산비와 ±0.10V 오차 예산으로 복귀한다. 실제 TPS3840/TMUX1511 선정은 조건부 검토 상태다. 데이터시트 지연을 조건 없이 합쳐 최악 성능 PASS로 주장하지 않는다. 이미 완료한 OP/AC/ON/OFF를 자동 반복하지 않는다.
