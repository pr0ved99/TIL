## 마감 후 PCB 학습 재개 — 37-4 잡음·평균 처리

- 사용자 `이제 오늘 할거 진행해보자` 요청으로 기존 PCB 학습을 재개했다. [학습21](../../07_Embedded_Learning_Notes/01_Concept_Notes/21_Voltage_ADC_Tolerance_Isolation_and_Discharge_Lab_ko.md)에 37-4를 추가하고 학습 목차·설계26·현재 인수인계·진행 목차를 맞췄다. 자료 작성은 37-4까지, 사용자 필기 완료 보고는 36-19까지다.

- 설명 계산: 조건부 원시 표준편차 20mV·N=10 → 평균 표준편차 약6.32mV. 최대 오차가 아니다. 100Hz·10개/1kHz·100개 묶음은 모두 결과10Hz이며 마지막 샘플 직후 결과의 평균적인 샘플 나이는 각각45/49.5ms다. 55ms에12.6→12.0V로 바뀌는 이상적 예제의100ms 묶음 평균은12.3V다. 실제 잡음·응답 측정값으로 기록하지 않는다.

- 후속 대화에 NotebookLM 01~07에 대응하는 프로듀서 메모 화면이 제공되었다. 따라서 아래 준비 시점의 `업로드/메모 미실행`은 당시 상태다. 소스 전체 업로드의 완전성이나 최종 영상 생성 완료는 확인하지 않았다. 바탕화면39소스 묶음은 기존 스냅샷이며 이번37-4를 자동 반영하지 않는다.
- 이번 범위는 로컬 자료 작성·수식/링크 확인이다. 전원 분리 상태를 유지하며 새 실물 시험·펌웨어·CAD·시뮬레이션 실행은 없다. 이전 마감의 Git/Calendar/Notion 게시 영수증을 이번 후속의 게시 완료 근거로 확대하지 않는다. 기존 일정은 변경하지 않았다.
