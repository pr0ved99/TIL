- 근거: 보유 ST DS10693 Rev10(2021-01) p139 Table74 RADC MAX6kΩ/CADC TYP4·MAX7pF·tS/tCONV, p140 각주4/Equation1, p143 Fig46, p145 Table83 TS_vrefint MIN10µs/tSTART TYP6/MAX10µs. p139/140/145 표를 렌더해 열 위치도 확인했다. AN2834 Rev10 p27 Fig26/p43 §4.4.2 Fig38·39로 외부·내부 경로와 전하 주입의 한계를 대조했다.
- 공식 웹 DS10693 Rev11(2026-05)의 관련 위치는 p140/141/144/146으로 보유 판본과 구분했다. ST 공식 HAL 헤더의 ADC_ClockPrescaler/ADC_sampling_times로 /6와3·15·28·56·84·112·144·480cycles를 확인했다. RM0390 공식 PDF 로컬 다운로드는 두 URL에서 시간 초과했으므로 미확인 쪽 번호를 안내하지 않았다.
- 현재 `stm32_uart_mvp` main.c/.ioc의 PCLK2는 명목84MHz, 측정용 ADC 초기화 없음/HAL_ADC_MODULE_ENABLED 비활성을 확인했다. 펌웨어 변경 없이 /6→14MHz·480cycles를 검증 시작 후보로 기록했다.
- Python 수식 계산: VADC에서 본 저항성 외부 모델4463.863Ω, RADC6kΩ/CADC7pF·14MHz·12bit의 Equation1 경계10.451cycles.15cycles는 단순 모델에서의 첫 선택지이며 실제 C1/C2/채널 전환까지 PASS로 판정하지 않는다. VREFINT는14MHz에서140cycles 이상이므로144/480cycles가 시간상 후보이며480cycles 취득34.286µs·12bit 포함35.143µs다.
- 1/4LSB는 ADC 전체 정확도가 아니다.3.3V·12bit의 ADC 쪽0.2014mV/명목 K 환산 VRAIL 쪽1.359mV는 취득 조건의 규모 비교다. 기존18MHz TUE의 보증 조건과 새14MHz 후보를 혼용하지 않는다.
