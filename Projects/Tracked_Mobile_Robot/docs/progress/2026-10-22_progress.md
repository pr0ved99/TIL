## 설계 검증과 보드 모니터링의 역할

- 데이터시트와 현재 부품/출력 조건을 기준으로 설계하고, 실제 전류·표면 온도를 관측해 해당 운전 조건의 적합성을 확인한다. 구매 자체는 설계 적합성 PASS가 아니다.
- 로봇 모니터링은 **모터별 전류 2채널 + 모터 케이스 온도 2채널**을 우선한다. 모터 전류와 MDD10A B+/B- 입력 전류는 PWM/회생·순환 경로 때문에 같은 값으로 취급하지 않는다. STM/ESP 개별 공급 전류의 상시 채널은 현재 최소 구성에 추가하지 않는다.
- 외부 GM-1312·UT210E는 기본 관측과 센서값의 교차 확인에 사용한다. 두 측정기의 표시나 센서와의 일치만으로 추적 가능한 교정·정확도를 입증하지 않는다. UT210E의 1mA는 최소 범위의 표시 분해능이며 오차가 1mA라는 뜻이 아니다. PWM 전류의 순간 피크·기동 파형·고주파 RMS 검증은 별도 계측 범위다.
- GM-1312 프로브는 모터 좌우, MDD10A 두 채널, XL4015 두 모듈을 필요 회차별로 옮겨 관측할 수 있다. 센서 2개가 전력계 전체의 온도를 상시 대표하지 않는다. 노출 열전대 접점과 XL4015 금속 탭 등 전위가 있는 부분의 접촉/절연을 검토한다.
- ADC는 우선 STM32 내장 ADC 활용을 검토한다. ADS1115, 벤치 파워서플라이, 별도 탑재 컴퓨터는 이번 구매 완료 목록에 없다. PSU는 필수가 아니며 현재 ESP·노트북 경로를 유지한다. CAN은 후속 단계이고 이번 구매 완료로 구현 완료가 되지 않는다.
- MVP 외부 온도와 지상1m의 기존 선행 조건은 유지한다. 구매한 UT210E를 이용한 기본 전류 관측을 준비하되 센서 ADC/브라우저 구현이나 정밀 전류 검증을 새로운 MVP 필수 선행 조건으로 자동 추가하지 않는다.

## 미완료와 다음 행동

1. 장비가 도착하면 수령한 것만 확인하고 센서 모델·핀/전원/출력, GM-1312 프로브 수량·형태, UT210E ZERO/범위·구성을 대조한다. 도착일은 확정하지 않는다.
2. 현 source/실행 이미지와 기존 증거의 차이를 정리하고, 측정 위치·단일 도선 클램프 접근·부착/절연·기록 주기·운전/휴지·수치 중단 기준을 준비한다. 미수령이면 회로·기록 준비만 진행한다.
3. 준비 완료 후 사용자가 한정된 전류/온도 회차를 수행한다. 실제 관측으로 선행 조건을 충족한 뒤 지상1m로 진행한다. 20cm 추가 시험이나 완료 시험의 무근거 반복은 요구하지 않는다.

최신 실물 끝점은 여전히 10/21 15cm 회차의 DISARMED/DISARM·요청/PWM/CPS 0이다. 종료 전원 분리는 새로 보고되지 않았으며 오늘 전원 상태를 추정하지 않는다.
