## 설계 검증과 보드 모니터링의 역할

- 데이터시트와 현재 부품/출력 조건을 기준으로 설계하고, 실제 전류·표면 온도를 관측해 해당 운전 조건의 적합성을 확인한다. 구매 자체는 설계 적합성 PASS가 아니다.
- 로봇 모니터링은 **모터별 전류 2채널 + 모터 케이스 온도 2채널**을 우선한다. 모터 전류와 MDD10A B+/B- 입력 전류는 PWM/회생·순환 경로 때문에 같은 값으로 취급하지 않는다. STM/ESP 개별 공급 전류의 상시 채널은 현재 최소 구성에 추가하지 않는다.
- 외부 GM-1312·UT210E는 기본 관측과 센서값의 교차 확인에 사용한다. 두 측정기의 표시나 센서와의 일치만으로 추적 가능한 교정·정확도를 입증하지 않는다. UT210E의 1mA는 최소 범위의 표시 분해능이며 오차가 1mA라는 뜻이 아니다. PWM 전류의 순간 피크·기동 파형·고주파 RMS 검증은 별도 계측 범위다.
- GM-1312 프로브는 모터 좌우, MDD10A 두 채널, XL4015 두 모듈을 필요 회차별로 옮겨 관측할 수 있다. 센서 2개가 전력계 전체의 온도를 상시 대표하지 않는다. 노출 열전대 접점과 XL4015 금속 탭 등 전위가 있는 부분의 접촉/절연을 검토한다.
- ADC는 우선 STM32 내장 ADC 활용을 검토한다. ADS1115, 벤치 파워서플라이, 별도 탑재 컴퓨터는 이번 구매 완료 목록에 없다. PSU는 필수가 아니며 현재 ESP·노트북 경로를 유지한다. CAN은 후속 단계이고 이번 구매 완료로 구현 완료가 되지 않는다.
- MVP 외부 온도와 지상1m의 기존 선행 조건은 유지한다. 구매한 UT210E를 이용한 기본 전류 관측을 준비하되 센서 ADC/브라우저 구현이나 정밀 전류 검증을 새로운 MVP 필수 선행 조건으로 자동 추가하지 않는다.

- ESP BIN의 app description ELF hash `02234cc1…`는 로컬 ELF와 일치한다. 현재 PAGE 전체는 ELF/BIN의 PAGE byte와 정확히 같다. 버전 `9bc9e97-dirty`는 빌드 시점 메타데이터이며 현재 Git HEAD와 비교해 낡은 이미지로 단정하지 않는다.
- 10·15cm browser 원본의 기록 hash를 재확인했다. boot/control/ARM 식별은 있지만 두 MCU의 firmware hash는 없다. 기존 목표 도달·정지 관측은 유지하고 현재 실행 이미지 신원으로 확대하지 않는다.
- 10/20 게시 소스와 비교하면 timeout/E-stop 출력 차단 본문에 거리 취소가 추가됐다. RX 예산64byte·비동기 TX/거리 supervisor의 스케줄링 변경은 당시 PC 검사로 연결하며,10/20 실제 단절/복구를 새 이미지 전체 오류 경로 PASS로 복사하지 않는다.

## 배송 대기 중 NTC 온도 입력 회로 계산

사용자가 온도 기준의 근거를 질문했다. 앞서 Codex가 제안한40/45°C·+10/+15°C 및 초기 표면/주위 차이5°C는 제조사/열모델/실측·측정 불확도/여유 계산 근거가 없는 임의 선택임을 확인했다. 안전한 초기 시험값으로 제시한 것을 정정하고, 계획의 실행 후보 표를 제거해 WITHDRAWN/NOT_RUN으로 갱신했다. 요약/인수인계도 철회와 온도·전류 기준 미확정으로 정합화했다. 위 초안 작성 항목은 철회 전 이력으로만 보존한다.

Nidec/maxon 자료는 온도차/지연 원리 참고이며 수치 근거가 아니다. 다음은 실제 모터 허용 온도/운전 조건, 드라이버/전원부 측정점과 한계 연결 근거를 보완하는 일이다. 수령·프로브 확인만으로 허용 온도를 확정하거나 다른 임의 숫자로 대체하지 않는다. 구동·실측·펌웨어/빌드·외부 앱/Git 게시 변경은 없다.
