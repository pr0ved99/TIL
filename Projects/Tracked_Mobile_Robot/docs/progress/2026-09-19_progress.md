## 현재 도면과 미완료 경계

- 현재 기준은 [CTRL수정본 VRT](../../09_Electrical_Design/VeroRoute/Tracked_Mobile_Robot_Perfboard_RevC_Estop_Logic_Power_UART_Debug_WIP_CTRL수정본.vrt)다.
  Git 저장 시 확인한 파일은 9/19 02:33:28 저장, 160,699 bytes,
  SHA-256 `96f881a54fd5efcd8a3a8456fb3716284d28075944ffd3d8f2bb95f179c36aa9`다.
  기존 9/18 검토본(161,191 bytes, SHA-256 `251b271958db7ae46055e674bef86913f683b9c5241d12fd48fa47f34cbcb772`)과 다르다.
  Wire 132개/부품 28개, Broken Nets 0 및 검출된 Net 불일치 0은 9/18 검토 결과다.
  최신 파일은 그대로 보존하며 이번 Git 종료 작업에서 재검토하지 않았다. 다음 도면 사용 전에 변경분을 대조한다.
- CTRL·ENC는 각각 **3핀 커넥터 두 개**다. CTRL_2 Pin2(C35/R6)는 PC7,
  Pin3(C35/R7)는 GND다. 이전 6핀 배정을 재사용하지 않는다.
- IMU는 6핀 한 개: 아래 Pin1부터 RST/PC4, INT/PB1, SDA/PB9, SCL/PB8, NC, GND.
  BNO 전원·모드·풀업 및 펌웨어 통합은 미완료이며 센서 모듈은 분리 상태로 둔다.
- JDBG_ENC는 MCU 측 측정점이다. 실제 엔코더 입력 커넥터와 입력 신호 조정부는 별도 미완료다.
- `...UART_Debug_IMU_WIP.vrt`는 9/16 이전 리비전이며 기존 addIMU PDF도 최신 VRT와 동기화된 도면이 아니다.
  최신 부품면/납땜면 PDF 재출력 완료는 확인되지 않았다.
- CAN PA11/PA12 예약과 보유 SN65HVD230 MCU-230 모듈 기록을 유지한다. CAN 실물 배선/통신 완료는 아니다.

기존에 작성한 ESP T004 coordinator와 Python 검증 코드, VRT/PDF 리비전, README·색인 및
진행/인수인계 문서를 함께 보존한다. 이번 종료 작업에서 펌웨어를 수정하거나 빌드·플래시하지 않았다.

- ESP는 T004 hook만 `1U`, 나머지 세 hook은 `0U`; STM 출력/응답 주입 hook은 `0U`다.
- 9/19 확인한 ESP·STM protocol·Python 검사 파일 hash는 체크리스트의 기존 기록과 같다.

  현재 T004=1U 소스의 신규 검사/빌드/실행 PASS로 확대하지 않는다.
