# 2026-09-27 Progress

## 종료 지점

**ESP의 M1 수동 1회 시험 코드를 사용자가 입력하다가 휴식으로 중단했다.**
현재 파일은 미완성 WIP이며 빌드·플래시·콘솔 입력·전동 구동 검증을 하지 않았다.
이번 마감에는 9/26~27 대화에서 모은 엔코더·전력단·배터리 결과도 함께 보존했다.

## 완료한 작업

- 실제 엔코더 연결 후 네 A/B LOW 0V/HIGH 약 2.86V, 정지 10초 이상 CPS0,
  양방향 변화·독립성·정지 복귀 사용자 보고 PASS.
- STM 단독 warm reset 원본을 저장하고 SHA-256 일치를 확인했다.
  TEL 169개/16.8초, STM t_ms=200~17000, 300/400ms 포함 양쪽 CPS/PWM 보고값 0.
  처음의 제어문자 5회·embedded CR 1회 거부도 원본에 보존했다.
- 차량 좌우를 A=왼쪽/M1/JENC_1/TIM3, B=오른쪽/M2/JENC_2/TIM5로 정정했다.
  엔코더 커넥터 교환 후 전진 양수/후진 음수·독립성·정지 0 사용자 보고 PASS.
  A의 동력선은 +→M1A/−→M1B, B 동력선은 분리 유지다.
- STM32 main.c는 이 좌우 관계를 설명하는 주석만 정정했다. TIM3 부호 반전·TIM5 유지와
  1560 counts/rev, 타이머 설정·실행 코드는 유지했다. 과거 원본의 A/B 측정값은 바꾸지 않았다.
- S1 OFF/ON 직후 양쪽 CPS −10/+10은 바로 0으로 복귀했다는 사용자 보고로 마감했다.
  같은 검사를 반복하거나 필터·저항을 추가 변경하지 않는다.
- F1/F2 Littelfuse 10A/1A 사용자 확인, 버스바·14/16 AWG 실제 배선,
  S0/S2 rail 관측 및 셀 전압 보고를 아래 report 30에 구분해 기록했다.

## 검증 범위와 미완료

- 안내 블록의 삽입 위치·기존 함수 연결·CMD 한 번과 mapper의 50/0 permille 계산을 정적으로 대조했다.
  이는 사용자 입력 파일의 컴파일 또는 보드 실행 검증이 아니다.
- 원본 로그 복사/해시, TEL 수·연속성·값을 재계산했다. 수정 문서 24개의 로컬 링크 대상 672개가 모두 존재하며
  Markdown 공백·코드 펜스 오류가 없음을 확인했다. ESP 파일은 위 SHA와 동일하고 STM 변경은 주석뿐이다.
- 전체 diff 공백 검사에는 사용자 WIP의 빈 poll 몸체 안 1474행 끝 공백 1곳이 남는다.
  입력 상태를 바이트 단위로 보존하기 위해 그대로 두었으며 전체 diff 검사를 PASS로 표기하지 않는다.
- 사용자 입력 코드에는 컴파일을 막는 미완성/오타가 있어 이번에는 빌드·플래시·펌웨어 테스트를 실행하지 않는다.
  과거 30/30 검사는 당시 완료 이미지의 기록이며 새 WIP의 통과 결과가 아니다.
- T004의 기존 PASS, T005A 전체 PARTIAL은 유지한다. 이번 rail 감소를 전체 rail-off PASS로 확대하지 않는다.
- 실제 전동 구동·방향·구동 중 노이즈·기구 고정 검증·주행은 미완료다.
- 종료 시 S1 OFF/LiPo 분리 완료는 별도 사용자 보고가 없다. 문서만으로 전원 상태를 단정하지 않는다.
