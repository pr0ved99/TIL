## 6P 상태 정정과 조립 규칙

기존 `6P waterproof harness/18 AWG received` 표현은 편의를 위한 도착 요약이었다. Actual part는
다음과 같다.

```text
loose male/female housings
+ loose open-barrel terminals
+ yellow individual seals
+ red secondary locks
+ separate 18 AWG wire
```

따라서 아직 harness continuity PASS라고 기록하지 않는다. Actual mating-face numbering과 pin
assignment가 동결되고 first-article crimp가 통과하기 전에는 terminal 또는 secondary lock을
housing에 삽입하지 않는다.

공구 도착 후 순서는 다음과 같다.

1. `WX-03B` actual jaw/profile과 18 AWG/6P loose terminal fit을 확인한다.
2. 여분 terminal과 seal 하나로 first-article crimp를 만든다.
3. Conductor wings, seal wings, conductor damage와 exposed-strand 상태를 육안 검사한다.
4. 강한 손당김, housing insertion과 retention을 확인한다.
5. PASS 뒤에만 cavity map에 따라 전체 12 terminal을 압착·삽입한다.
6. 결합한 male 6개 x female 6개, 총 36개 cross-housing 조합에서 intended 6개는 도통,
   unintended 30개는 open인지 확인한다.
7. 분리된 각 housing 안에서는 같은 쪽 15개 조합을 각각 검사해 내부 pair-short가 없는지 확인하고,
   movement와 terminal retention도 확인한다.

K1 `280756-4` terminal은 2개뿐이므로 첫 연습 대상으로 쓰지 않는다. K1 crimp는 final AWG 12
wire와 die fit을 확인한 뒤 수행하며, 무전원 외관/당김만으로 loaded release를 선언하지 않는다.
