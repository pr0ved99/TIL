# 2026-11-03 전압 보호회로 필기 학습 — 회차 마감 / 설계 진행 중

11/3 학습30~35 자료를11/4에 점검·마감했다. [11/4 정리](2026-11-04_progress.md)의 게시 영수증이 최신이며 아래 게시 미실시 문구는 작성 당시 상태다.

## 진행 범위

- 사용자가 필기 형식으로 순차 진행하도록 요청했다. 학습21의 후속 목차를 30 전원 경로 → 31 감시기/스위치 공급점 → 32 TPS 핀 → 33 TMUX/주변 부품 → 34 전원 상태 → 35 결정/검증으로 제시했다.
- [학습21의 30절](../../07_Embedded_Learning_Notes/01_Concept_Notes/21_Voltage_ADC_Tolerance_Isolation_and_Discharge_Lab_ko.md#30-nucleo의-vdd와-vdda-전원-경로)을 작성했다. 사용자 확인 전이다.
- ST 공식 UM1724 Rev17 및 MB1136 C04와 로컬 STM32F446 DS10693 Rev10을 대조했다. +3V3→JP6→VDD→L1→SB57→AVDD→MCU VDDA 경로, CN7-16/+3.3V, CN7-5/VDD, CN10-7/AVDD를 문서상 식별했다.
- 실제 보드 리비전/점퍼 상태·파형·외부 부하 적합성은 미확인이다. CN10-7 식별을 보호부품 전원 채택으로 확대하지 않는다.
- 사용자 다음 진행 요청으로 학습21의31절을 추가했다. TPS VDD가 공급/감시 겸용인 점을 근거로 TPS3840PL30/TMUX1511의 공통 AVDD 공급을 상세 설계 기본 후보로 유지했다. CN10-7의 최종 공급 적합성/실물 보호 승인은 아니다.
- TI TPS Rev.E p6/p7, TMUX Rev.B p6에서 조건부 IDD 행을 대조했다. Typical 소계37.3µA, maximum 행 소계70.7µA. RESET→SEL 부하/과도·디커플링 충전을 포함한 전체 상한으로 확대하지 않으며, VRAIL에서 흐르는 분압 전류와 구분했다. 전원 잡음/디커플링 조건은 TPS p28·TMUX p26을 대조했다.
- 사용자의 VRAIL 질문에 배터리측 K1-30/모터공급측 K1-87의 분압 전 입력이며16V는 검토 조건임을 설명했다. 이어32절 TPS 핀 연결 초안을 작성했다: MR 미사용 개방, CT 우선 개방, PL RESET→TMUX SEL1/2, VDD–GND100nF 세라믹 후보. 복귀 지연과 하강 검출 지연을 구분했다. 사용자 읽기/실물 검증 완료를 추정하지 않는다.
- 사용자 지적에 따라 TPS CT-open tD의 잘못된 typical/nominal50µs 해석을 **MAX50µs**로 정정했다. 공식 Rev.E p7을 직접 렌더하고 MIN/TYP/MAX 머리글과 값의 좌표를 대조했다. CT-open의 MIN/TYP는 공란이며 CT10nF의6.2ms/1µF의619ms는TYP다. 학습21의29·32절, 설계26, 인수인계의 해당 값을 수정하고 표 이미지/대조 기록을 저장했다. 전류µA와 시간µs도 구분했다. 과거 외부 게시 내용은 이번에 갱신하지 않았다.

## 근거와 검증 경계

- 다음 진행 요청으로 학습21의33절을 작성했다. TMUX PW/TSSOP 기준 S1/D1·S2/D2의 두 분압 신호와 공통 RESET→SEL1/2를 분리하여 설명했다. PW는 핀 설명 기준 후보이며 패키지/구매 최종 선정이 아니다.
- TMUX Rev.B p3/p6와 TPS Rev.E p6를 공식 PDF 렌더로 직접 확인했다. 유효 공급 조건에서 TPS VOH MIN0.8VDD(3.3V에서2.64V)/VOL MAX0.20V와 TMUX VIH MIN1.2V/VIL MAX0.45V를 대조했다. 전원 하강 전 구간 보증으로 확대하지 않는다.
- 미사용 SEL3/4 및 S3/D3/S4/D4 접지, TMUX 전원용100nF를 상세 설계 후보로 기록했다. 미사용 신호 접지는 프로젝트 선택이며 제조사 NC 핀 지침과 구분했다. 내부 SEL 풀다운 TYP6MΩ과 외부 VADC47kΩ도 분리했다. 사용자 읽기 결과/실물 검증은 미보고다.
- 다음 진행 요청으로34절 전원 상태 학습 노트를 작성했다. TPS Rev.E p9 Figure6-2를 직접 렌더/대조하여 초기 기동·얕은 저전압 복귀·최소 동작 전압 아래에서의 재기동을 구분했다. tSTRT와 CT-open tD 중복 가산 금지, VPOR 아래 RESET 미정, 검출/스위치 전이/방전의 시점 차이를 연결했다.
- TMUX Rev.B p7/p16을 직접 대조하여 SEL 전이와 공급 전이 시간을 구분했다. p4의 VDD<1.5V 신호 범위와 p6의 VDD=0V 누설 시험은 서로 다른 근거다. 무전원 규격을 전체 과도 보호 PASS로 확대하지 않았다. 연결 후 ADC 초기화/정착·측정 유효 및 오래된 값 처리는 후속 요구이며 구현 완료가 아니다.
- 다음 진행 요청으로35절 후보 판단을 작성했다. TPS3840PL30–TMUX1511을 후속 계산의 기준 후보로 유지하고 최종 부품/제작 승인은 보류했다. 공급 경로, 하강 중 보호, 완전OFF, 복귀 유효성, 정확도의 필요한 증거/판정 경계를 표로 정했다. 0.1% 저항과100pF·고정30µs를 실물 사양으로 확정하지 않는다.
- 30~35절 설명 자료와 연결/상태 초안 작성은 완료했다. 사용자 이해 확인·실물 검증·전체 설계 완료와 구분한다. 요구조건15의0~16V DC·보정 후±0.10V·주위20~30°C·결과10Hz 제안을 다음 오차 예산의 검토 기준으로 이어간다. 이번에도 새 실습 실행 결과는 없다.

[자료 위치와 조회 기록](../../assets/logs/pcb_design/2026-11-03_nucleo_power_path/README.md). 보드 PDF는 공식 웹 원문으로 읽었고 로컬 다운로드는 timeout으로 실패했다. 기존 칩 PDF p39는 텍스트와 렌더를 대조했다.
