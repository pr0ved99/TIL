## Decisions

- 현재 motor/gearbox/encoder와 STM32 x4 decoding의 출력축 변환 상수는 `1560 counts/output rev`로 사용한다.
- 50회전 보정값은 작업자 관찰 기록이고 동적 mRPM raw log와 별개의 증거다.
- Firmware mRPM은 `trunc(CPS * 60000 / 1560)` 정수 계산으로 유지한다.
- mRPM은 현재 USART2 bench diagnostic용이다. Production STM32 -> ESP32 `TEL`은 기존 signed `left_cps/right_cps` 계약을 유지한다.
- Encoder-side vehicle mapping은 motor A -> right/TIM5, motor B -> left/TIM3로 확정한다. MDD10A powered channel 1/2의 물리 좌우 mapping은 다음 motor 시험에서 확인한다.
- Vehicle-frame encoder 속도는 전진 양수다. Left/TIM3 production CPS는 raw 부호를 반전하고 right/TIM5는 raw 부호를 유지한다. USART2의 `ENC3/ENC5` bench diagnostic은 raw 부호를 유지한다.
- 장기 누적값은 `int64_t`를 유지한다. 현재 `%ld` bench 표시는 nano-newlib 호환용 단기 진단 view다.
- Nominal 100 ms에서 1 count/sample은 10 CPS, 약 384 mRPM이므로 현재 integer mRPM은 저속 양자화가 있다.
- `Error_Handler()` 기반 software fault는 `motor_output_stop_all()` 후 IRQ를 끄고 reset 전까지 latch한다. 이번 PASS는 이 경로의 기능·정적 전압 범위이며 정확한 차단 시간을 뜻하지 않는다.
- Temporary motor-output 시험 조건문은 source에 남기되 두 compile-time macro의 기본값을 `0U`로 유지한다.
- 2026-07-20 scripted safety sequence PASS는 historical controlled-bench evidence로 유지한다. 정상 ESP32 부팅에서는 guard를 `0U`로 두어 자동 `PING/ARM/CMD/DISARM`을 보내지 않는다.
- Firmware flash 전 정적 contract test와 격리 build를 preflight gate로 사용하며, CubeMX 재생성 뒤에는 TIM5 init 보존 여부를 검사한다.

## Limitations / Open Items

- Raw dynamic log에는 timestamp/sequence가 없어 실제 sample interval과 frame drop을 독립 증명하지 않는다.
- 50회전 보정은 외부 tachometer나 각도 jig를 사용한 계측급 교정이 아니다.
- Powered-motor encoder noise와 actual input waveform/filter는 미검증이다.
- Wheel 유효 이동거리/회전이 아직 확정되지 않아 wheel mm/s와 odometry 변환은 구현하지 않았다.
- Production velocity command를 PWM/direction으로 변환하는 mapping과 closed-loop speed control은 아직 없다.
- Fault 전환 순간의 실제 PWM waveform과 shutdown latency는 계측하지 않았다.
- Physical E-stop은 아직 구현·시험하지 않았고 실제 motor-connected stop도 미검증이다.
- 이번 카페 작업은 laptop-only source/test/build 검증이다. STM32/ESP32 flash·runtime 확인과 실제 PWM, direction, shutdown latency, encoder noise 같은 전기 검증은 수행하지 않았다.
