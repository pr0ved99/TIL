# 2026-08-16 Progress

## What changed

- VeroRoute target은 이 작업에서 실물 외곽 치수 재현이 아니라 실제 사용 홀의 on-board 포함
  여부를 표시하는 경계로 사용한다고 범위를 명확히 했다.
- width `55`, height `37` 저장 화면에서 `C1..C55/R1..R37`의 점이 모두 흰 target 영역 안에
  있고 청록색 off-board 영역은 마지막 홀 바깥에서 시작하는 것을 사용자 캡처로 확인했다.
- 따라서 width `55`, height `37`을 target-hole-area PASS 값으로 확정했다.
- PDF export 직전 기준 화면은 `Layer=Bottom`, `Flip Horizontal=OFF`, `Flip Vertical=OFF`다.
  이 비반전 상태를 component-side 좌표 기준도로 먼저 보존하고, 납땜면 대조본은 별도 파일로
  horizontal flip만 적용한다.
- 이 변경은 표시 외곽만 다루며, 이미 완료된 STM32-MDD10A 5-Net 배선과 `Broken Nets` empty
  connectivity PASS에는 영향을 주지 않는다.
- 비반전 component-side reference PDF를 내보내 실제 파일을 검사했다. A4 landscape 1 page,
  3047 vector drawings, raster image 0개이며 C1..C55/R1..R37이 잘림 없이 포함됐다.
- PDF 숫자 guide 좌표의 인접 간격이 `7.2 pt`, 즉 `0.1 inch = 2.54 mm`로 반복됨을 확인해
  1:1 source geometry를 PASS했다. 인쇄 시에는 별도로 `Actual size/100%`를 적용해야 한다.
- horizontal flip만 적용한 solder-side mirrored PDF를 내보내 component-side PDF와 직접
  대조했다. 열 번호는 `1..55`에서 `55..1`로 반전되고 행 번호는 `1..37` 순서를 유지한 채
  왼쪽에서 오른쪽으로 이동했다. page/drawing bounds와 vector object 수가 동일하므로
  horizontal-mirror pair를 PASS했다.
- export 후 horizontal flip을 OFF로 되돌려 저장했으며 WIP 크기와 SHA-256이 export 전
  비반전 baseline과 동일함을 확인했다.
- component-side reference PDF를 `Actual size/100%`로 출력해 실물 만능기판과 겹쳐 확인했다.
  사용자가 홀 배열이 정확히 일치한다고 확인했으므로 printer-scale 및 physical-hole-overlay
  Gate를 PASS했다.
- 사용자가 실물 만능기판에 10 kOhm 풀다운 저항 `R9~R12` 납땜을 완료했다. 현재 기록은
  physical assembly 완료 사실만 반영하며, 저항값·인접 패드 단락·GND 공통 연결은 무전원
  멀티미터 검사 전이므로 전기적 PASS로 판정하지 않는다.
- 무전원 멀티미터 검사에서 R9~R12 개별 저항은 `9.7~10.2 kOhm`, GND 공통선을 경유한
  서로 다른 신호 상단 간 저항은 `19.5~20.1 kOhm`으로 측정됐다. 10 kOhm 풀다운 2개의
  직렬 경로와 일치하며, 저항 실장과 GND 공통 연결을 PASS했다.
- 사용자가 부품면 절연 점퍼 방식으로 STM32-MDD10A 인터페이스의 5개 배선을 완료했다.
  연속성 및 Net 간 비단락 검사는 아직 수행 전이므로 physical wiring complete / electrical
  verification pending 상태로 기록한다.
- 5-Net 무전원 검사에서 각 동일 Net 경로는 모두 `1.4 Ohm`, 네 신호의 GND 대비 저항은
  `9.76~10.33 kOhm`, 신호 상호 간 저항은 `19.6~20.2 kOhm`으로 측정됐다. 풀다운 경로와
  Net 간 비단락은 PASS했다. 동일하게 반복된 `1.4 Ohm`은 리드·접촉 저항 가능성이 크므로
  프로브 단락 기준값을 측정한 뒤 보정 연속성 PASS를 확정한다.
- 프로브 직접 단락값은 `2.7 Ohm`으로 측정돼 동일 Net의 `1.4 Ohm`보다 크게 나왔으며,
  단순 차감 시 음수가 되므로 해당 멀티미터/프로브 접촉 조건으로는 저저항 정량 보정이
  유효하지 않다. 이 5개 선은 고전류 경로가 아닌 논리 인터페이스이며 동일 Net 연속성,
  신호-GND 약 10 kOhm, 신호 상호 간 약 20 kOhm, Net 간 비단락이 모두 확인됐으므로
  계측기 분해능 범위의 5-Net 전기 연결 PASS로 판정한다.
- 영구 R9~R12와 5-Net 배선에 NUCLEO를 장착하고 MDD10A/LiPo/motor/ESP32를 분리한 채
  USB power-up 5초를 캡처했다. 세션은 `1 MHz`, `5,000,000 samples`, `unitsize=1`이며
  D0=J5-1/DIR1, D1=J5-2/PWM1, D2=J5-3/DIR2, D3=J5-4/PWM2가 모두 HIGH sample `0`,
  transition `0`으로 5초 전 구간 LOW였다. Permanent-pulldown power-up Gate를 PASS했다.
- 같은 배선과 분리 조건에서 `NRST asserted/held`와 `NRST press-release cycle`을 각각
  5초 캡처했다. 두 원본 세션 모두 `1 MHz`, `5,000,000 samples`이며 D0~D3의 HIGH sample과
  transition이 모두 `0`이었다. 사용자 수행 기록상 cycle 시험은 약 1초에 NRST를 누르고
  약 2초에 놓았다. 캡처에는 별도 NRST marker 채널이 없으므로 정확한 누름·해제 시각은
  원본만으로 독립 재구성할 수 없지만, 출력 all-LOW 데이터와 수행 기록을 합쳐 complete
  external-reset cycle Gate를 PASS하고 permanent-pulldown/5-Net 물리 검증을 닫는다.
- 무전원 상태에서 J5-MDD10A 5선의 정상 경로와 교차 비단락을 확인했다. MDD10A를 분리해
  입력-GND 저항을 DIR1/PWM1/DIR2/PWM2 순서로 측정한 값은 각각 `10.05`, `10.32`,
  `9.93`, `9.75 kOhm`이었다. 기존 외부 풀다운 `9.76~10.33 kOhm`과 병렬 연결되면
  약 `4.88~5.16 kOhm`이 예상되므로, 연결 상태의 약 `5 kOhm`은 hard short가 아니라
  두 pull-down 경로의 병렬값과 일치한다. De-energized MDD10A logic reintegration을 PASS했다.
- MDD10A POWER와 motor terminal을 분리하고 5선 logic harness만 연결한 상태에서 NUCLEO를
  USB로 구동했다. MDD10A GND 기준 DIR1/PWM1/DIR2/PWM2는 모두 `0 V`였다.
  Logic-connected/driver-unpowered static safe-state를 PASS했다.
- Motor terminal과 실제 motor를 분리하고 모든 controlled test hook이 `0U`인 정상 안전
  firmware 상태에서, 기존 fuse/switch 경로로 MDD10A 전원을 인가했다. 사용자가
  `M1A/M1B/M2A/M2B` 출력 LED가 모두 꺼져 있고 발열·냄새·이상음 등 이상 현상이 없음을
  확인했다. 영구 R9~R12 및 5선 harness 변경 후 powered/no-motor 최소 회귀시험을 PASS했다.
  이는 기존 2026-07-26의 12.35 V 입력·6-step 출력 시험과 2026-07-29 timeout/DISARM
  all-off 시험을 대체하거나 반복한 것이 아니라, 이번 물리 변경으로 기본 안전 상태가
  깨지지 않았는지만 확인한 회귀 증거다.
- 위 최소 회귀시험은 final perfboard path가 active HIGH와 20 kHz PWM을 전달하는지는
  검증하지 않았다. 기존 active 6-step과 정밀 timing 증거는 permanent perfboard 실장 전
  배선/MCU-pin 시험이므로, 실제 motor를 연결하기 전 final perfboard의 MDD10A-input 지점에서
  motor-disconnected active 6-step을 한 번 더 검증한다.
- Board power/back-power Mode 1에서 LiPo, XL4015, MDD10A power와 motor를 분리하고,
  STM32-ESP32 UART TX/RX도 분리한 채 common GND만 유지했다. NUCLEO USB만 연결했을 때
  무전원 ESP32의 `5V-GND`와 `3V3-GND`가 모두 `0 V`였다. 직접 연결된 board power rail을
  통한 NUCLEO-to-ESP32 역급전이 없음을 PASS했다. UART 신호선을 분리한 시험이므로 GPIO
  protection 경로를 포함한 결과로 확대하지 않는다.
- 반대 방향 Mode 2에서도 같은 분리 조건과 common GND만 유지하고 ESP32 USB만 연결했다.
  무전원 NUCLEO의 `+5V-GND`와 `+3V3-GND`는 모두 `0 V`였다. 직접 연결된 board power
  rail을 통한 ESP32-to-NUCLEO 역급전이 없음을 PASS했다. 이 결과 역시 UART TX/RX가
  분리된 전원-rail 경계 시험이다.
- Board power Mode 3에서는 두 board 사이에 `PA9(TX)->GPIO18(RX)`,
  `PA10(RX)<-GPIO17(TX)`와 common GND만 연결하고, `5V/VBUS/VIN` rail은 연결하지 않은 채
  NUCLEO와 ESP32를 각각 USB로 구동했다. 측정값은 NUCLEO `+5V=4.93 V`, `+3V3=3.30 V`,
  ESP32 `5V=4.66 V`, `3V3=3.27 V`였다. 두 regulated 3.3 V rail이 정상이고 개발용
  dual-USB/UART mode를 PASS했다. ESP32-S3-DevKitC-1 공식 회로도에는 USB VBUS에서
  `VCC_5V`로 들어가는 `1N5819` Schottky 경로가 있으므로 header의 `4.66 V`는 그 전압강하와
  일치한다. USB connector VBUS 자체를 측정한 값으로 확대하지 않는다.
- Buck-only mode 준비를 위해 모든 board USB와 외부 전원을 분리한 상태에서 NUCLEO의
  3-pin `JP5`가 기존 `PWR-U5V` USB 선택 상태임을 확인했다. `JP1`은 이미 open 상태였고
  `CN7 E5V`, ESP32 `5V/GND` 위치도 확인했다. 이후 사용자가 JP5 jumper를
  `PWR-E5V`로 이동했으며, 아직 XL4015 출력은 어느 board에도 연결하지 않았다.
- Board 연결 전 XL4015 #1을 기존 검증된 입력 경로에서 무부하 재측정했다. 입력은
  `12.27 V`, 출력은 `5.03 V`였으며 출력 극성과 NUCLEO E5V 허용 범위 안임을 확인했다.
  Board에 연결하기 전 buck no-load voltage Gate를 PASS했다.
- NUCLEO의 `JP5=PWR-E5V`, `JP1=open`, USB 분리 상태에서 XL4015 #1 출력만
  `CN7 E5V/GND`에 연결해 단독 구동했다. 부하 상태 측정값은 `E5V=5.01 V`,
  `+3V3=3.30 V`였으며 NUCLEO buck-only external-E5V mode를 PASS했다.
- ESP32-S3-DevKitC-1의 두 USB 포트를 모두 분리하고 XL4015 #1을 header `5V/GND`에만
  연결해 단독 구동했다. 측정값은 `5V=5.01 V`, `3V3=3.27 V`였으며 ESP32 buck-only
  external-5V mode를 PASS했다.
- XL4015 #1의 `OUT+/-`를 NUCLEO `E5V/GND`와 ESP32 `5V/GND`에 병렬 분기하고,
  두 USB를 모두 분리한 채 UART TX/RX/GND를 연결해 동시 buck-only 구동했다. 측정값은
  NUCLEO `E5V=5.00 V`, `3V3=3.30 V`, ESP32 `5V=5.00 V`, `3V3=3.27 V`였다.
  두 board 동시 부하에서도 5 V/3.3 V rail이 유지돼 combined buck-only mode를 PASS했다.
- Buck input switch를 OFF하고 USB가 모두 분리된 상태로 10초 뒤 NUCLEO `E5V/3V3`와
  ESP32 `5V/3V3`를 다시 측정했으며 네 rail 모두 `0 V`였다. 외부 공급 차단 시 잔류 또는
  다른 source의 역급전이 없음을 확인해 board power/back-power Gate를 최종 PASS했다.
- 확정 운용 정책은 다음과 같다. 개발 모드는 두 board를 각각 USB로 공급하고 board 간에는
  UART TX/RX/GND만 연결하며 `5V/VBUS/VIN`은 연결하지 않는다. 한 board만 USB로 켤 때는
  무전원 board로 향하는 TX/RX도 분리한다. Standalone 모드는 XL4015 #1 `5.0 V`를 NUCLEO
  `E5V`와 ESP32 `5V`에 병렬 공급하고 모든 USB를 분리한다. NUCLEO는
  `JP5=PWR-E5V`, `JP1=open`을 사용한다. USB와 buck의 동시 공급은 이 프로젝트에서
  금지하며, source 전환은 전원 OFF/케이블 분리/rail 0 V 확인 뒤에만 수행한다.
- WHEELTEC가 공개한 `R1/R3/R3X/TT` chassis 자료 묶음도 추가 조사했다. 내려받은 271개
  파일 중 PDF 59개, 문서명 71개, ZIP 27개의 member name/source text와 STP/DWG 등 loose
  CAD/text 파일을 `MG540`, `540P30`, rated/start/stall-current 계열 키워드로 검색했지만
  `MG540P30_12V` current-rating 근거는 0건이었다. 남아 있는 `.downloading` 2개는 serial
  terminal과 waveform-viewer 실행 파일로 motor rating 자료가 아니다. 따라서 이 묶음은
  일반 chassis 설치/개발 참고자료일 뿐 K1/F1 정격을 닫는 motor datasheet로 사용할 수 없다.

## Why

- `54 x 36`은 55 x 37홀의 중심 interval 수라서 마지막 열과 행을 흰 영역에서 제외한다.
- 이번 VeroRoute Gate의 목적은 실제 사용 홀 `C1..C55/R1..R37`이 모두 작업 영역 안에 있는지
  확인하는 것이며, 실제 150 x 100 mm 외곽과 edge margin은 Onshape/실물로 별도 검토한다.

## Blockers

- 실제 150 x 100 mm 외곽과 edge margin은 VeroRoute target 표시만으로 판정하지 않는다.
- WHEELTEC chassis 자료 묶음에도 MG540 current rating이 없어 K1/F1/main-wire 정격은
  manufacturer reply 또는 승인된 current-limited characterization 전까지 계속 blocked다.
