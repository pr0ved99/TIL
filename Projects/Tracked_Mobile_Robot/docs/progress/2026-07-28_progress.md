## Today Work Log

1. RevA baseline
   - 프로젝트를 `09_Electrical_Design/KiCAD/Tracked_Mobile_Robot_Wiring_RevA`에 생성했다.
   - title은 `Tracked Mobile Robot Wiring`, revision은 `RevA`, 상태는 `DRAFT`로 기록했다.
   - MCU/driver 관련 핀 묶음은 물리 헤더가 아니라 `FUNCTIONAL` connector로 표현했다.

2. Dual encoder interface
   - TIM3는 `PB4/TIM3_CH1 = A`, `PB5/TIM3_CH2 = B`로 기록했다.
   - TIM5는 `PA0/TIM5_CH1 = A`, `PA1/TIM5_CH2 = B`로 기록했다.
   - 각 A/B 신호는 `1 kΩ series + MCU-side 15 kΩ pull-down` 구조로 작성했다.
   - Encoder connector front view는 `motor+`, `GND`, `B`, `A`, `5V`, `motor-` 순서다.
   - XL4015 #2의 `ENCODER_5V`와 common GND를 두 encoder에 분배하도록 기록했다.

3. MDD10A and main power
   - Motor channel 1은 TIM3 motor, channel 2는 TIM5 motor bench 식별명으로 기록했다.
   - Logic mapping은 `PC8 -> DIR1`, `PB6/TIM4_CH1 -> PWM1`, `PC9 -> DIR2`, `PB7/TIM4_CH2 -> PWM2`와 common GND다.
   - 전원 경로는 `3S LiPo -> FUSE_TBD -> MAIN_DC_SWITCH -> VBAT_SW`다.
   - `VBAT_SW`에서 MDD10A와 XL4015 #1/#2 input으로 병렬 분기하도록 기록했다.

4. STM32–ESP32 UART
   - `STM32 PA9/USART1_TX -> ESP32 GPIO18/RX`
   - `ESP32 GPIO17/TX -> STM32 PA10/USART1_RX`
   - 두 보드는 common GND를 사용한다.
   - 기존 `115200, 8-N-1` board-only bridge 검증 결과를 반영했다.

5. Candidate and verification
   - XL4015 #1 출력은 `XL4015_1_OUT_CANDIDATE`로만 두고 STM32/ESP32에는 연결하지 않았다.
   - BNO085, 차량 left/right, forward polarity와 fuse rating을 TBD로 표시했다.
   - 저장된 schematic에 ERC를 실행해 `0 Errors / 0 Warnings`를 확인했다.
   - 검토용 PDF를 날짜가 고정된 파일명으로 export했다.

## Decisions

- Raw 5 V encoder A/B를 STM32에 직접 연결하지 않는다.
- Encoder input은 채널별 `1 kΩ series + MCU-side 15 kΩ pull-down`을 RevA 기준으로 유지한다.
- XL4015 #2는 encoder 5 V 공급원으로 사용한다.
- TIM3/TIM5 명칭은 bench 식별명이며 차량 left/right를 의미하지 않는다.
- `VBAT_SW`는 MDD10A와 두 XL4015 input에 병렬 분배한다.
- XL4015 #1 출력은 USB backfeed 정책이 확정되기 전까지 candidate로 유지한다.
- ERC 통과는 연결 규칙 검사이며 bench 시험, 전류 용량, footprint 또는 제조 적합성을 대체하지 않는다.
