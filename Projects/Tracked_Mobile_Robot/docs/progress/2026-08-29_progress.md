# 2026-08-29 Progress

## Summary

P-04A applied PWM telemetry를 완료하고 P-04B의 `reason/command_age_ms` actual-source 연결과
motor/LiPo-disconnected STM32+ESP32 UART runtime subset까지 진행했다. 기존 TEL의
`left_pwm/right_pwm=0` placeholder는 motor-output cache로 교체됐고, 이어서 stop reason과 마지막
accepted CMD age가 STM32 TEL에서 ESP32 strict parser/log까지 전달되도록 확장했다.

P-04A는 `PASS — UART/software-cached applied-output telemetry scope`다. P-04B는 no-CMD
sentinel, accepted-CMD age reset, 500 ms timeout과 direct-PC7
`ESTOP_ACTIVE -> ESTOP_LATCHED` subset이 PASS했지만 active reset reject/released reset success와 hook-0 target
reflash/runtime restore가 남아 **PARTIAL**이다. Hook-0 isolated STM32/ESP32 build는 PASS했다.
카페 세션에서 남은 reset vector용 default-off ESP32 test harness와 정적 계약을 추가했고 current
canonical은 `29/29`이다. Harness 자체의 board runtime은 아직 실행하지 않았다. Battery는 계속
P-05 범위다.

## Source Changes

### STM32

- `motor_output_applied_t`와 `motor_output_get_applied()` 추가
- cached duty/DIR에서 signed permille 복원
- `send_tel()`의 `left_pwm/right_pwm`를 실제 getter 결과에 연결
- stop/DISARM/timeout/error 경로의 cache zero 유지

### ESP32

- TEL 구조체에 signed `left_pwm/right_pwm` 추가
- strict parser와 monitor log에 두 field 연결
- default-`0U` `BRIDGE_P04B_ESTOP_RESET_TEST_ENABLED` closeout hook 추가
- startup `READY` 뒤 `ESTOP_ACTIVE` reset 1회 -> `ESTOP_LATCHED` reset 1회 ->
  `DISARMED/ESTOP_RESET/PWM 0/0` 종료 FSM 추가
- P-04B reset 경로의 `ARM/CMD/DISARM` 송신 금지, 예상 밖 상태의 fail-stop/no-retry 적용

### P-04B reason/command age

- STM32 `robot_reason_t`와 `reason_name()` 추가
- `BOOT/NONE/DISARM/CMD_TIMEOUT/ESTOP_ACTIVE/ESTOP_LATCHED/ESTOP_RESET/OUTPUT_ERROR` 연결
- successful accepted CMD에서만 갱신되는 timestamp/valid state 추가
- accepted CMD 전 `command_age_ms=4294967295`, 이후 마지막 accepted CMD age 보고
- STM32 TX와 ESP32 line buffer를 `384 bytes`로 확대
- ESP32에 `reason[32]`, unsigned `command_age_ms` required parse/log 추가

### Contract tests

## Evidence Boundary

- 이 값은 software-cached applied target이며 measured PWM feedback이 아니다.
- P-04A run에는 logic analyzer, MDD10A output, actual motor가 포함되지 않았다.
- symmetric forward `+50/+50`만 runtime 검증했고 negative/asymmetric polarity는 provisional이다.
- safe restore UART 로그는 관찰 가능한 안전 동작을 증명하지만 exact flashed binary identity를
  단독으로 증명하지 않는다.
- `batt_mv`는 계속 placeholder다.
- P-04B direct-PC7 결과는 actual PC7 voltage, operator action timestamp, VO617A-3/S0-B conditioned
  path, K1 rail-off, physical PWM pin 또는 actual motor stop을 증명하지 않는다.
- P-04B reason/age hook-0 source와 isolated build는 PASS했지만 post-test target reflash/runtime
  restore는 아직 open이다.
- P-04B reset harness는 default `0U`, canonical `29/29`와 ESP32 build까지만 PASS했다. 실제
  active-reset ERR, released-reset ACK/TEL 또는 target flash를 증명하지 않는다.
