# 2026-08-29 Progress

## Summary

P-04의 첫 단계인 **P-04A applied PWM telemetry**를 구현하고 motor/LiPo-disconnected
STM32+ESP32 UART runtime에서 통과시켰다. 기존 TEL의 `left_pwm/right_pwm=0` placeholder는
motor-output 계층이 마지막으로 성공 적용한 signed permille cache로 교체됐다.

P-04A는 `PASS — UART/software-cached applied-output telemetry scope`다. P-04 전체는 아직
`PARTIAL`이며 E-stop/timeout reason과 command-age는 P-04B, battery는 P-05에 남아 있다.
