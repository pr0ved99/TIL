# 2026-07-27 Progress

## Summary

- STM32CubeMX에서 두 번째 quadrature encoder 입력을 `PA0/TIM5_CH1`, `PA1/TIM5_CH2`로 구성했다.
- TIM3 16-bit와 TIM5 32-bit counter를 동시에 시작하고 두 count를 USART2로 출력하는 bench logger를 구현했다.
- Debug build를 통과한 뒤 motor power를 분리한 상태에서 두 encoder를 동시에 연결해 독립 손회전 시험을 수행했다.
- TIM5 회전 중 TIM3가 고정되고 TIM3 회전 중 TIM5가 고정되는 것을 raw log로 확인했다.
- 두 경로 모두 출력축 1회전당 약 1560 count를 재현했으며 dual motor-off count/sign subtest를 `PASS`로 판정했다.

## Today Work Log

1. CubeMX dual encoder configuration
   - 기존 `PB4/TIM3_CH1`, `PB5/TIM3_CH2` 경로를 유지했다.
   - `PA0/TIM5_CH1`, `PA1/TIM5_CH2`를 `Encoder Mode TI1 and TI2`로 추가했다.
   - TIM5는 prescaler 0, period `0xFFFFFFFF`, rising/direct/div1, input filter 0으로 생성했다.
   - NVIC interrupt는 사용하지 않고 polling counter 방식으로 유지했다.

2. Dual bench logger
   - TIM3 counter는 `32768`, TIM5 counter는 `0x80000000`에서 시작하도록 설정했다.
   - 두 timer를 `HAL_TIM_Encoder_Start(..., TIM_CHANNEL_ALL)`로 시작했다.
   - USART2/ST-LINK VCP에 250 ms마다 ENC3/ENC5 raw, centered count와 direction을 한 줄로 출력하도록 확장했다.
   - 이 logger는 blocking bench code이며 production speed module이 아니다.

3. Build
   - STM32CubeIDE bundled GNU Tools for STM32 14.3.rel1 환경에서 Debug build를 실행했다.
   - Build exit code는 0이었다.
   - ELF size는 text 24380, data 92, bss 2708, total 27180 bytes였다.
   - 기존 `Board_Hardware_Init` unused-function warning 1건은 남아 있으며 TIM5 변경과 직접 관련되지 않는다.

4. Dual motor-off hand rotation
   - 각 A/B channel은 `1 kΩ series + MCU-side 15 kΩ pull-down`과 common GND 조건을 유지했다.
   - MDD10A motor power는 연결하지 않고 shaft를 손으로만 돌렸다.
   - Raw log에서 ENC5는 `0 -> +1557 -> -6`으로 움직였고 그동안 ENC3는 `0`을 유지했다.
   - 이어 ENC3는 `0 -> +1561 -> +7`으로 움직였고 그동안 ENC5는 `-6`을 유지했다.
   - 사용자가 별도로 보고한 새 경로 1회전 값은 `+1555 / -1566`이며, 기존 시험 encoder도 예상값을 재현했다.

## Decisions

- Bench input names remain `ENC3/TIM3` and `ENC5/TIM5` until physical vehicle left/right assignment is fixed.
- `1560 counts/output rev` remains the provisional conversion constant.
- 손으로 정확히 360°를 맞추는 데 한계가 있으므로 단일 회전 수치는 exact CPR calibration으로 사용하지 않는다.
- Small return offsets (`-6`, `+7`) are retained in the raw evidence and are not edited to zero.
- This result closes the TIM5/dual motor-off input item only; it does not prove powered-motor noise immunity.

## Blockers / Open Items

- 16-bit/32-bit wrap-safe modular delta and accumulated position module are not implemented.
- Fixed-period RPM/rad/s calculation and telemetry are not implemented.
- Vehicle left/right assignment and forward-positive sign are not fixed.
- 최종 counts/rev 보정은 축 기준선을 표시한 다회전 반복 측정으로 수행해야 한다.
- Powered-motor encoder noise, appropriate digital input filter and long-run behavior are not verified.
- Oscilloscope/logic analyzer phase and pulse-shape evidence is still unavailable.
