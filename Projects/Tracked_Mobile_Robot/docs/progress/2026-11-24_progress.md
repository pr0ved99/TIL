## 11/24 오후 노트북 실습 · SIM-06 전압 표본의 시각과 유효성

사용자가 노트북 실습을 선택했다. 새 감시기 `watch_voltage_state`는 측정 후 경과 시간과 발행자가 보낸 `valid`를 함께 출력한다. Jazzy에서 `tmr_sim`을 빌드하고 별도 도메인 78에서 ROS 메시지로 확인했다. 같은 11.82 V 모의값에 `valid=false`를 붙였을 때 수신 직후 `FRESH valid=false`, 1.541초 뒤 `STALE valid=false`가 됐다. 이어서 유효한 표본은 `FRESH valid=true`, 유효성 필드를 생략한 표본은 `FRESH valid=unknown`으로 수신했다. 사용자가 도메인 77에서 직접 관찰한 출력은 `WAITING` → `FRESH valid=false age=0.000 s` → `STALE valid=false age=1.597 s`였다. 이어서 11.82 V의 유효 표본 한 건을 보내 `FRESH valid=true age=0.001 s`와 `STALE valid=true age=1.582 s`를 직접 확인했다. 이로써 전압 한 채널에서 최근/오래됨과 유효/무효의 네 조합을 모두 관찰했다. **모의 주행 요청.** 감시기에 `/tmr/sim/check_drive_request` 서비스를 추가했다. 요청 시각에 전압 표본의 경과 시간을 계산하고, 최근이며 유효할 때만 통과시킨다. Jazzy에서 패키지를 빌드한 뒤 도메인 78에서 빈 상태, 최근 유효·무효, 두 표본의 시간 초과, 유효 표시 누락, 새 유효 표본으로 복귀를 시험했다. 유효 표본의 첫 요청은 통과했고 1.521초 뒤의 요청은 보류됐다. 별도 경계 검사에서 마지막 표시가 FRESH일 때도 요청 당시 정확히 1.5초면 보류됐다. 서비스는 판정 결과만 반환한다. 사용자가 도메인 77에서 확인한 같은 모의 요청은 유효 표본 발행 중에 `success=True, FRESH valid=true age=0.328 s`, 발행 중단 후에 `success=False, STALE valid=true age=11.554 s`였다. 두 age는 각각 서비스 요청을 처리한 순간의 측정 후 경과 시간이다. 사용자는 이어서 무효 표본을 계속 발행하는 실습에서 서비스 응답 `success=False`를 확인했다. 같은 감시기를 켜 둔 채 새 유효 표본으로 바꾼 뒤 새 요청에서 `success=True`를 확인했다. 무효 표본과 복귀 회차는 사용자가 보고한 응답값만 기록했다. 전압 표본에 따른 모의 요청 보류·복귀 실습을 마쳤고 다음 노트북 항목은 별도의 모의 전류 표본 발행·수신이다.
