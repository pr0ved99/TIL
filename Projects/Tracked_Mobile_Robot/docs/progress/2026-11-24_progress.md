# 2026-11-24 진행 기록 · 첫 실물 ADC와 PC 수신 G1

한국 시각 11월 23일 낮의 노트북 작업과 23일 밤~24일 새벽 집 벤치가 이어진 세션이다. 집에서는 NUCLEO-F446RE의 저전압 입력 한 채널로 A11~A14를 통과했다. 다음 집 실습은 E07/M01의 PA4·VREFINT 두 채널 설계, 노트북은 SIM-06의 표본 시각과 유효성 판정이다.

## 노트북에서 마친 일

- Gazebo·RViz에서 Nav2 목표 도착과 주행 중 취소 후 정지, 지도에 없는 벽을 LiDAR로 감지한 뒤 우회·도착을 확인했다. 비용지도·MPPI 주행 설정을 비교하고 평가용 방과 시드를 고정했다.
- NAV-03 바퀴 모드 5경로 × 4시드에서 20/20회 도착·정지, 장애물 접촉 0회였다. 최대 위치 오차 14.51 cm, 방향 오차 5.30°였다. 별도로 취소와 스캔 단절 때의 정지를 확인했다.
- 가상 IMU의 회전 부호·발행 주기를 확인했다. 바퀴 전진 속도와 IMU Z축 각속도를 EKF에 연결하고 런처와 실행 의존성을 패키지에 등록했다. 설치본에서 벽 우회 P05는 27.00초, 최종 위치 오차 1.52 cm·방향 오차 2.95°였고 해당 TF 발행자는 하나였다.
- SIM-06에서 11.82 V 모의 전압의 시각·지연과 발행 중단/재개를 측정했다. 사용자가 관찰한 1.502초 STALE은 시각 판정이다. 새 표본의 발행 측 `valid=false`와 묵은 표본을 구분하는 실습이 남았다. [11/23 주행·센서 원본과 검증](2026-11-23_progress.md)

## 집에서 마친 일

**A11 · 입력 및 전원 확인.** S0 잠금, S1 OFF, 배터리 분리에서 XL4015 #1의 출력 0.00 V와 NUCLEO·ESP32 외부전원 두 2핀 분리를 확인했다. NUCLEO는 JP5 U5V·JP1 OPEN, 보드 전원은 두 USB로 공급했다. #2는 엔코더·S0 감지용 분기다. 실측 저항은 11.82 kΩ·9.95 kΩ, 직렬 양 끝은 21.7 kΩ였다. 사용자가 보고한 3V3–GND는 3.31 V였다.

**A12 · CubeMX부터 첫 실측까지.** A2(PA4)에 ADC1 채널 4, 순위 1, 12비트, PCLK2/6(14 MHz), 480사이클, 소프트웨어 단발 변환을 설정했다. 사용자가 벤치 루프를 입력하고 매크로 이름과 줄바꿈을 수정했다. CubeIDE 빌드 오류·경고 0개, ST-LINK 다운로드 검증 성공, Resume 후 USART2 115200 8N1에서 seq·부팅 후 ms·raw·valid를 수신했다. `TMR_ADC_BENCH_ENABLED=1U`에서 모터 초기화 전에 벤치 루프에 머문다. 1.512 V의 첫 104개는 seq 0~103, 모두 유효, 평균 1872.33이었다. [사용자 터미널에서 옮긴 첫 CSV](../../assets/logs/mvp_measurements/2026-11-24_a12_pa4/first_uart_samples.csv) · [벤치 소스](../../03_Firmware/stm32_uart_mvp/Core/Src/main.c)

**A13 · 세 입력의 방향과 반복성.** 각 행은 별도 구간에서 얻은 연속 327개이며, 모두 33.904초·104 ms 간격·누락 0·valid 1이다. 낮은 입력 때 저항 양단은 0 V, A2 점퍼 끝–GND는 0.7 mV였다. 1.797 V는 A2가 연결된 상태에서 중간점과 GND 사이인 11.82 kΩ 양단을 잰 값이다.

1.512 V의 [최초 수집본](../../assets/logs/mvp_measurements/2026-11-24_a13_pa4/mid_1p512v_partial.csv)은 재개 직후 순번 간격과 29.744초짜리 연속 구간이 있어 별도 보존했다. 위 표는 재수집한 연속 구간이다. 3.31 V를 기준으로 환산한 높은 입력 평균은 약 1.798 V다. 실제 기준전압 추정·정밀 보정과 배터리 전압 보호는 후속이다.

**A14 · 실제 수신 중단과 복귀.** 보드 입력 1.797 V, 전원 고정 상태에서 PC 기록기만 포트를 4초간 닫았다가 열었다. 82.026초에 유효 표본 732개를 기록했다. seq 3684가 마지막으로 수신된 후 1.508초에 STALE, 초기 버퍼를 비운 뒤 seq 3733에서 FRESH가 됐다. 비어 있는 48개 순번을 그래프에서도 빈 구간으로 표시했다. 1.5초는 이 벤치의 PC 수신 기준이다. 펌웨어 invalid 출력 분기는 실보드에서 고장 주입으로 검증하지 않았다. ## 자고 일어난 뒤 시작할 곳

- **집에서** 먼저 마지막 전원·점퍼 상태와 분압 연결을 확인한다. 서로 다른 두 값을 구분하도록 PA4와 내부 기준전압 VREFINT의 채널 순서, raw 필드, 비교 대상을 설계한다. 기준값은 실측 3V3 3.31 V와 현재 입력 1.797 V다. 다음 단계에서 사용자 입력·빌드·플래시로 넘어간다. 마지막 회로는 3V3 → 9.95 kΩ → A2 → 11.82 kΩ → GND다.
- **노트북만 있을 때** ROS 2 도메인 77의 모의 전압 실습으로 돌아가 최근이면서 유효/무효인 표본과 수신이 끊긴 표본을 구분한다. [SIM-06 실행 근거](../../assets/logs/ros2/2026-11-23_tmr_sim06_battery/user_observations.txt)
- **전원 인계**는 S0 잠금, S1 OFF, 배터리와 보드 외부전원 두 2핀 분리다. 마감 확인 당시 USB 장치 두 개가 PC에서 열거됐다. 물리적 USB 분리 완료는 사용자 보고 또는 후속 확인을 기록한다. 기록기는 종료됐고 보드에는 ADC 벤치 펌웨어가 탑재돼 있다.
