# 2026-11-15 마감 — B 재실습·감지선 단락 비교·배터리 ADC 근거

11/14 이전 마감 이후 이어온 작업을11/15에 종료한다. 파일명에 남은11/14는 사용자 실습 원본 이름이며 변경하지 않는다. 실제 작업 시각/시간을 추정하지 않고 Calendar 기존 경계를 유지한다.

## 1. 완료 범위와 사용자 보고

- B Retry01의 사용자 KiCad 원본/10초 CSV와2kHz·200개 블록 평균 결과를 확보했다. 표준편차3.012779mV→0.234124mV(약12.87배 감소), 두 신호의 평균 차이5mV 유지. 사용자는 일정한 치우침을 평균으로 제거할 수 없다는 결론을 이해했다고 명시했다. 수기 전체 완료는 미보고다.
- 사용자가 요청해 실제 Retry01 CSV 후처리를 보여주는 HTML을 만들었다. 과거 별도 가상 HTML과 구분한다. 원본에는 추가 잡음/보정을 넣지 않았다.
- C 주기성/alias 실습은 사용자가 이해했고 넘어가자고 하여 **실행 생략**으로 종료했다. 실행/PASS로 기록하지 않는다.
- 03_15 보호/무보호 두 회로를 사용자가 작성·실행했다. 각각150,023행/0~15ms/최대100ns 간격/필요 신호가 있는 CSV를 확인했다. 전류합·옴의 법칙·I²R은 CSV 반올림 범위 안에서 일치했다.
- 사용자는 출발점 저항 유무에 따른 단락 전류/발열 부담의 차이를 이해했다고 보고했다. C1/C2 충전 전류, V1고정16V와 VRAIL변화, 전력과 에너지의 차이를 설명했다. 수기 완료나 모든 개념 이해를 자동 확대하지 않는다.
- 요청한 [배터리 ADC 제조사 근거 문서31](../../09_Electrical_Design/31_Battery_Voltage_ADC_Reference_Basis_2026-11-15_ko.md)를 작성했다. ST Drone v0.97 p65, UM2197 Rev3 pp8/14/16/19, AN2834 Rev10 p16§3.2.7의 위치·조건과 프로젝트 적용 범위를 기록했다.

## 2. 단락 관측과 해석

| 약9ms CSV 관측 | R7=2.2kΩ | R7 없음 |
| --- | --- | --- |
| 공급 전류 | 7.26612mA | 8.00014A |
| VRAIL | 15.9927V | 7.99986V |
| VADC | 1.11366mV | 1.18568V |
| PCB 입력 I(R1) | 0.255353µA | 282.871µA |
| 저항 전력 | R7=0.116152W | R6=64.0023W |

V1은16V고정, R6와S2 ON저항 각각1Ω은 학습 가정이다. R7을 빼면 대부분 전류가S2로 흐르고 R6/접촉부 각각약64W, 전원 전체약128W다. 고정 정착값으로5ms를 근사한 에너지는 무보호약0.64J/보호약0.000581J이며 실제 CSV 에너지 적분 결과가 아니다. 온도/손상/퓨즈동작 모델은 없다.

무보호 복귀 시 R1 약616→566µA의 변화는 C1/C2 충전과 VDIV상승으로 설명했다. C1제거 시 C2만 남는 빠른 과도와 두 커패시터 모두 무시한 저항 회로 비교는 계산 설명이며 새 실습을 수행하지 않았다.

## 3. 저장·최신화 누락 수정

무보호 CSV는 정상 저장됐으나7개 신호 워크북이 보호용 이름에 저장된 것을 발견했다. 사용자가 무보호 파일명으로 다시 저장한 것을 확인했고, 마감에서는 잘못 저장된 보호용 파일을 백업한 뒤 마지막 TRAN탭을 보호용8개 신호로 재구성했다. 과거 분석탭은 보존했다. 이전 원본 워크북의 바이트 복원이 아니라 표시 설정 복원이며 새 시뮬레이션이 아니다.

현재 안내의 B 목적 미이해/C진행전/03_15미실행을 이번 상태와 맞춘다. 날짜별 과거 기록은 보존한다. 제작 Shield/MVP의 원본·기본 exports PDF·reports를 기존 검증 근거와 대조하고, 제작 CAD가 바뀌지 않았으므로 불필요한 PDF/ERC 재생성을 하지 않는다.11/6 applied.pdf는 과거 스냅샷이다. NotebookLM 기존 업로드/영상은 별도여서 이번 결과를 자동 반영하지 않는다.

## 4. 다음 작업과 유지 경계

다음 첫 작업은 **J7/J8 감지선 출발점·길이·굵기·커넥터·절연/고정 조건표 → 보호 저항 정격/온도/전압/펄스/TCR 대조**다. 감지선 사양은 사용자 보고 미정.2.2kΩ/±1%/0.5W급 이상은 검토 출발값이고 제작 CAD/BOM 반영·구매는 아직이다. 이후 정상 전달비/오차 예산과 포트 보호/전원 전이를 대조한다. 완료 실습의 반복·새 FFT/잡음 실습을 자동 추가하지 않는다.
