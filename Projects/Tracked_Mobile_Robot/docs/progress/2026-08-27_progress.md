## Firmware P-03A/P-03B Timeout Recovery Status

Current source contract:

```text
each RX-loop iteration
-> E-stop latch enforcement
-> command_timeout_enforce() before RX byte processing
-> deadline crossed: motor_output_stop_all()
-> stored vx/w zero
-> DISARMED
```

Accepted `ARM`은 output과 stored command를 zero로 유지하고
`CMD_TIMEOUT_DEFAULT_MS=300`과 current `HAL_GetTick()`으로 first-CMD window를 다시 시작한다.
따라서 timeout 이전 stored command는 자동 복원되지 않고, accepted `ARM` 뒤 default window
안에 들어온 valid `CMD`만 적용될 수 있다.

Evidence boundary:

- 현재 `TEL`은 timeout 뒤 `DISARMED`와 zero command 값만 보여 준다. 명시적 timeout reason
  telemetry는 P-04 pending이다.
