# 2026-07-26 Progress

## Summary

- NUCLEO-F446RE의 MDD10A용 motor-output 경로를 `TIM4 CH1/CH2 + DIR GPIO`로 구성했다.
- STM32 핀 단독 DMM 시험에서 boot/idle safe state와 staged output 변화를 확인했다.
- 3S LiPo 12.36 V 조건에서 MDD10A 입력 12.35 V를 측정하고 motor-disconnected 전원 시험을 통과했다.
- 첫 powered/no-motor 시험에서 양 채널의 PWM/DIR가 MDD10A header에서 서로 바뀐 것을 LED 패턴으로 진단했다.
- 배선을 교정한 뒤 M1A, M1B, stop, M2A, M2B, stop의 6-step LED sequence를 확인했다.
- 임시 test macro를 `0U`로 되돌리고 재빌드·플래시한 뒤 모든 MDD10A output LED가 꺼진 safe state를 확인했다.
- MG540-A/B encoder 입력을 채널별 `1 kΩ series + MCU-side 15 kΩ pull-down`으로 구성하고, STM32 입력 분리 상태의 HIGH 3.06~3.07 V를 확인했다.
- TIM3 `PB4/PB5` encoder mode에서 두 motor를 순차 손회전해 정지 count, 양방향 부호와 출력축 1회전당 약 1560 count를 확인했다.
- 정확한 PWM 파형, 의도한 post-DIR settle, active timeout/DISARM output-zero, encoder LOW·위상 timing, TIM5와 powered-motor noise는 아직 미검증이므로 전체 motor/encoder 통합은 `PARTIAL`로 유지한다.

## Today Work Log

1. STM32 motor-output configuration
   - `PB6 / TIM4_CH1`을 channel 1 PWM으로 설정했다.
   - `PB7 / TIM4_CH2`를 channel 2 PWM으로 설정했다.
   - `PC8`, `PC9`를 각 channel의 DIR GPIO로 설정했다.
   - TIM4 period는 `4199`, test duty cap은 `100 permille = 10%`로 구성했다.
   - `motor_output_stop_all()`과 direction-change 시 `compare zero -> 1 ms wait -> DIR write -> PWM restore` 순서의 raw output path를 추가했다.
   - 이 주파수와 시간은 source/CubeMX 설정값이며 실제 파형 계측값은 아니다.

2. STM32 pin-only DMM validation
   - MDD10A main power와 motor를 분리한 상태에서 `PB6`, `PB7`, `PC8`, `PC9`를 확인했다.
   - Boot/idle 상태에서 네 핀 모두 0 V를 확인했다.
   - 임시 button-driven 6-step sequence의 PWM/DIR 상태 변화와 stop 복귀를 DMM으로 확인했다.

3. MDD10A standalone power-input validation
   - Battery pack voltage는 12.36 V였다.
   - MDD10A `B+`와 `B-` 사이 입력은 12.35 V였다.
   - Motor는 연결하지 않았고 heat, smell, smoke, abnormal noise 또는 fuse 문제는 없었다.
   - Switch OFF 직후 `-0.24 V`, 이후 `-0.14 V`가 관측되며 0 V 방향으로 천천히 감쇠했다. 저장 커패시터/부유 기준점 영향으로 추정하지만 원인은 확정하지 않았고, 이 값만으로 역전원 여부를 판정하지 않았다.

4. Initial PWM/DIR wiring fault diagnosis
   - 초기 배선에서는 step 1과 4에 LED가 켜지지 않았다.
   - Step 2에서는 M1A가 밝고 M1B가 약하게, step 5에서는 M2A가 밝고 M2B가 약하게 켜졌다.
   - 이 증상으로 양 MDD channel의 PWM/DIR가 서로 바뀐 것을 확인하고 시험을 중단했다.
   - MDD10A 실크 인쇄를 기준으로 두 signal pair를 교정했다.

5. Corrected powered-no-motor sequence
   - Step 1: M1A LED active
   - Step 2: M1B LED active
   - Step 3: all related LEDs off
   - Step 4: M2A LED active
   - Step 5: M2B LED active
   - Step 6: all output LEDs off
   - Motor output terminal은 전 과정에서 비워 두었다.

6. Test closeout
   - Final bench mapping을 `PB6 -> PWM1`, `PC8 -> DIR1`, `PB7 -> PWM2`, `PC9 -> DIR2`, common GND로 확정했다.
   - `MOTOR_OUTPUT_PIN_TEST_ENABLED`를 `0U`로 되돌렸다.
   - 사용자가 rebuild/flash 후 powered-no-motor 상태에서 모든 output LED가 꺼졌음을 확인했다.
   - 시험 종료 사진에는 battery와 motor terminal이 분리된 상태가 보인다.

7. MG540 encoder signal-safety measurement
   - 두 motor를 bench 식별명 `MG540-A`, `MG540-B`로 구분했으며 차량 left/right는 아직 지정하지 않았다.
   - Encoder PCB connector pad 순서를 정면/connector-up 기준 왼쪽부터 `motor+`, `GND`, `B`, `A`, `5V`, `motor-`로 식별했다.
   - MG540-A의 무전원 encoder 5 V-GND 저항은 824 Ω이었고 A-GND, B-GND와 A-B는 DMM `1`/OL이었다.
   - XL4015 #2 rail은 MG540-A 연결 전 5.06 V, 연결 후 5.03 V였고 MG540-B 연결 상태에서도 5.03 V였다.
   - MG540-A raw A/B는 shaft 정지 위치에 따라 약 0 V 또는 약 5 V가 됐다. 따라서 raw direct STM32 연결은 금지했다.
   - MG540-A는 10 kΩ signal-to-GND 조건에서 A/B 정지 HIGH가 모두 2.48 V였고 회전 중 DMM 평균은 각각 1.23 V, 1.24 V였다.
   - MG540-A의 15 kΩ 조건에서 A는 회전 평균 1.48 V, 정지 HIGH 2.98 V였으며 B는 거의 같은 동작만 확인하고 정확값은 기록하지 않았다.
   - MG540-B의 15 kΩ 조건에서 A는 1.46/2.97 V, B는 1.47/2.96 V였다. 앞 값은 회전 DMM 평균, 뒤 값은 정지 HIGH다.
   - Loaded HIGH는 약 10.3~10.5 kΩ internal pull-up과 일치하지만 open-collector/open-drain 구조를 확정하는 증거로 확대하지 않았다.

8. TIM3 encoder input implementation
   - CubeMX에서 `PB4/TIM3_CH1 = A`, `PB5/TIM3_CH2 = B`를 `Encoder Mode TI1 and TI2`로 설정했다.
   - TIM3는 prescaler 0, period 65535, rising/direct/div1, input filter 0인 x4 quadrature count 조건이다.
   - 각 채널은 `encoder A/B -> 1 kΩ series -> STM32 input node`, 그 node에서 `15 kΩ -> common GND`로 연결했다.
   - STM32 GND, encoder GND와 XL4015 OUT-를 공통으로 묶고 motor power는 분리했다.
   - PB4/PB5를 분리한 상태에서 conditioning node HIGH는 MG540-A A/B 모두 3.06 V, MG540-B A/B 3.06~3.07 V였다.

9. Motor-off hand-rotation count
   - 두 motor를 동일한 TIM3 bench input에 한 개씩 순차 연결했다.
   - Output shaft 끝을 정면으로 보는 기준에서 clockwise는 positive, counter-clockwise는 negative였다.
   - MG540-A 1회전: CW +1560, CCW -1560~-1570.
   - MG540-B 1회전: CW +1562, CCW -1560.
   - 현 단계의 잠정 scale은 `1560 counts/output rev`이며, 차량 forward sign과 실제 left/right assignment는 아직 확정하지 않았다.
   - 저장 raw log는 MG540-A의 정지 안정성과 양방향 count 증감만 포함한다. 1회전 수치와 MG540-B 결과는 같은 bench session에서 별도로 관찰한 값이다.
   - 현재 USART2/ST-LINK VCP logger는 250 ms 주기, 50 ms timeout의 blocking bench code이며 compile-time gate 없이 활성화돼 있다. 다음 구현 단계에서 기본 OFF 또는 제거한다.

## Decisions

- MDD10A bench signal mapping은 `PB6/TIM4_CH1 -> PWM1`, `PC8 -> DIR1`, `PB7/TIM4_CH2 -> PWM2`, `PC9 -> DIR2`로 고정한다.
- `left/right`는 현재 firmware channel 이름이며 실제 차량 좌우 mapping은 motor 장착 후 확정한다.
- 실제 차량 forward/reverse 방향도 motor 연결 전에는 확정하지 않는다.
- 임시 raw output test는 10% 상한을 유지하고 시험 종료 시 반드시 macro를 `0U`로 되돌린다.
- LED와 DMM 결과는 static routing 검증으로만 인정하며 주파수, duty와 deadtime 검증으로 대체하지 않는다.
- 실제 motor 연결 전 active timeout/DISARM output-zero gate를 반드시 통과한다.
- Encoder motor는 당분간 `MG540-A/B`로만 부르고 차량 left/right는 장착 후 확정한다.
- Raw 5 V encoder A/B는 STM32에 직접 연결하지 않는다.
- 최종 motor-off hand-count 조건은 채널별 `1 kΩ series + MCU-side 15 kΩ pull-down`, common GND로 고정한다.
- Shaft-end view의 CW positive/CCW negative는 bench 배선 부호이며 차량 forward sign으로 확대하지 않는다.
- `1560 counts/output rev`는 손회전 잠정값이다. 최종 배선, TIM5와 powered 조건에서 재검증한다.

## Blockers / Open Items

- Oscilloscope 또는 logic analyzer를 이용한 실제 20 kHz와 10% duty 측정이 없다.
- 현재 source는 `PWM zero -> 1 ms wait -> DIR change -> 즉시 PWM resume` 순서다. 의도한 post-DIR settle로 고치고 실제 timing을 확인해야 한다.
- UART command를 제한된 motor-output 값으로 변환하는 production mapping이 아직 완료되지 않았다.
- Active PWM 상태의 timeout, DISARM과 fault에서 실제 핀/MDD output-zero 시험이 없다.
- Encoder의 정확한 LOW, pulse shape와 A/B phase timing은 아직 계측하지 않았다.
- TIM5 PA0/PA1, 두 encoder 동시 동작, powered-motor noise와 적절한 input filter는 아직 확인하지 않았다.
- 현재 `raw - 32768` 출력은 16-bit wrap-safe production 누적 count가 아닌 제한된 bench 표시값이다.
- 실제 motor no-load, current, heat, noise와 vehicle left/right/forward mapping은 아직 시험하지 않았다.
