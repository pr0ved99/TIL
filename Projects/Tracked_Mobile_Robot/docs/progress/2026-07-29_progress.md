## Decisions

- Plus 전환 전에는 현재 `gpt-5.6-sol`, Low reasoning과 priority 설정을 변경하지 않는다.
- 전환 후 일반 작업은 `gpt-5.6-terra` + Low reasoning을 기준으로 한다.
- Fast/priority는 상시 사용하지 않는다.
- 반복 요약용 서브에이전트는 Luna + Low로 제한하고, 하드웨어 안전 판단에는 사용하지 않는다.
- 프로젝트 `AGENTS.md`의 읽기 범위 축소는 Plus 전환 smoke test 후 별도 변경으로 진행한다.
- Encoder 내부 누적값과 delta/CPS 계산은 `int64_t`로 유지한다.
- 현재 newlib-nano console logger는 짧은 bench 범위에서 `(long)`/`%ld`를 사용하지만, 내부 자료형을 32-bit로 축소한 것으로 해석하지 않는다.
- 방향이 바뀌면 현재 duty 유무와 관계없이 양 PWM을 먼저 0으로 만든다. 1 ms pre-zero와 1 ms post-DIR은 초기 안전값이며 실제 파형 계측으로 확정된 값이 아니다.
- Button test는 증거 수집 후 반드시 `MOTOR_OUTPUT_PIN_TEST_ENABLED 0U`로 복귀한다.
- LED sequence PASS는 channel/direction 기능 확인이며 정확한 20 kHz, 10% duty 또는 1 ms timing의 물리 계측 증거가 아니다.
- Timeout/DISARM subtest의 PASS 범위는 motor-disconnected MDD10A LED 기능 시험이다. Actual PWM pin zero, 정확한 shutdown latency, motor stop, fault/E-stop 및 production velocity-to-PWM mapping까지 확대 해석하지 않는다.
- Production field mapping은 현재 `TIM3 -> left_cps`, `TIM5 -> right_cps`인 잠정 mapping이다. 사용자 제어 순서로 bench motor A -> TIM5, B -> TIM3가 확인됐지만 실제 차량 left/right와 forward-positive 기준은 장착 후 확정한다.

## Blockers / Open Items

- 실제 Plus 전환은 아직 수행하지 않았다.
- 플랜별 정확한 사용량과 모델 노출은 변경될 수 있으므로 전환 당일 Usage와 모델 선택기를 다시 확인해야 한다.
- `openaiDeveloperDocs` MCP는 현재 세션 도중 등록되어 재시작 후 인식 여부를 확인해야 한다.
- UART `CMD`는 아직 `motor_output_set_raw()`에 production mapping되지 않았다.
- Active PWM 상태의 timeout과 `DISARM`은 MDD10A LED 수준에서 기능 PASS했다. Actual PB6/PB7 pin/waveform과 fault/error/E-stop shutdown은 미검증이다.
- 실제 20 kHz/10% PWM과 pre-zero/post-DIR 1 ms timing은 oscilloscope/logic analyzer로 계측하지 않았다.
- Encoder count/s의 STM32 production `TEL` 포함과 ESP32 end-to-end 파싱은 main power ON, output hook `0U`, commanded output zero의 독립 손회전 조건에서 통과했다. Active PWM/motor-current noise 시험은 아니다.
- Powered-motor encoder noise, vehicle left/right와 forward sign, exact counts/rev 및 wheel-speed calibration은 미검증이다.
