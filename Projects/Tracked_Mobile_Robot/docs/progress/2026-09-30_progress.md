### 사용자 요청에 따른 Git 마감

- 문서 개편 이후 사용자가 Git 최신화를 요청했다. 64d51ad 이후 누적된 수동 콘솔 완성·오른쪽 DIR 보정·ESP 진입 파일 이름 변경·시험 원본과 보고서·학습 자료·문서 개편을 현재 작업 브랜치의 마감 커밋에 포함한다.
- 대상: agent/dual-encoder-bringup → origin/agent/dual-encoder-bringup. main 병합은 포함하지 않는다. 마감 전 fetch 결과 기존 HEAD와 upstream의 ahead/behind는 0/0이었다.
- Python 계약 검사 재실행: 31개 중 30 PASS, 1 FAIL. test_all_bench_hooks_are_present_and_disabled가 BRIDGE_M2_PULSE_TEST_ENABLED=1U 때문에 실패했다. 이미 기록된 시험 설정을 보존하며 펌웨어나 검사 기준은 바꾸지 않았다.
- 시험 원본 12개의 크기·SHA-256이 manifest와 일치한다. 기존 Git 속성의 text 비활성화로 원본 로그의 줄바꿈 바이트도 보존한다.
- 스테이징된 원본 12개의 SHA-256도 일치한다. 코드·문서의 git diff --check는 통과했다. 원본 01_uart_startup_ready.txt의 44행 끝 공백 1건은 증거 바이트 보존을 위해 유지했다.
- 이번 Git 작업에서 새 펌웨어 구현·보드 빌드·플래시·물리 시험은 수행하지 않았다. 커밋·원격 반영 결과는 Git 이력과 origin 브랜치로 확인한다.
