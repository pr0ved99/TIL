### 적층 방향 재검토: 기존 기판 최상층 유지

- 사용자는 기존 기판을 가장 위에 두고, 납땜 부품을 탈거하지 않으며, 새 하층을 MVP 이후 Advanced 확장용으로 쓰는 방향을 제안했다.
- 추천 방향을 이에 맞췄다. 앞선 새 상층·ESP32 이동안은 비교 이력으로 남기고, 기존 부품 탈거를 요구할 근거는 없다고 정리했다. 기존 모듈을 유지하는 새 기판 공간 예산은 ADC/CAN/연결부 46 cm²이며 실물 배치 검증은 아니다.
- 기존 납땜면·점퍼와 새 하층 부품의 간격, 하층과 플레이트의 간격, 안테나 아래 금속물, 높이 증가와 케이블 길이가 확인 대상이다. 기존 ESP32 UART USB와 STM32 간섭은 이 변경만으로 해결되지 않는다. 현재 ESP32 외부 연장 시험 상태도 그대로다.
- Advanced는 확장 기판의 역할명으로 적절하다. 다만 기본 저전압 경고·정지는 첫 주행 전 준비 항목이며, 해당 입력 회로를 새 기판에 둘 경우 그 부분은 먼저 준비해야 한다. 두 rail 자동 진단의 post-MVP 분류는 유지한다.
- 다음 설계 작업은 새 하층 배치·실측·지지점 대조다. 검토 문서와 색인을 갱신했으며 구매·실물·VRT/PDF·펌웨어 변경은 없다.

### 기존 기판과 새 하층의 연결 구상

- 사용자 요청으로 기존 납땜을 유지하는 층간 전기 연결안을 확장 검토 문서에 추가했다. 기존 UART/엔코더/PWM/DIR/PC7/IMU 경로는 유지하고 새 기능의 신호를 인출하는 구상이다.
- 초안: ADC 3핀(PA4/GND/PB0), CAN 4핀(3V3/GND/PA12 TX/PA11 RX). 이름·핀 순서는 제안이며 VRT 부품·실물 커넥터 확정이 아니다. ADC 입력 감지선과 CANH/CANL은 하층의 외부 연결로 구분했다.
- 기존 핀/CAN 계획, STM32 `.ioc`, ST UM1724와 TI SN65HVD230 자료를 대조했다. ADC/CAN 설정은 아직 없으며, CAN 인출부의 최신 VRT Net·실물 접근성 확인은 남아 있다.
- NUCLEO 헤더에서 인출하거나 기존 납땜점에 선을 추가하는 방법을 비교했다. 커넥터를 선 중간에 두면 기존 기판에 새 커넥터 몸체를 배치할 공간을 줄일 수 있다.
- STM32 3.3 V의 공급 여유·ADC 무전원 입력 보호·하네스 길이·접점 고정·커넥터 규격은 미확정이다. 다음은 실제 접점과 층간 높이·측면 케이블 통로의 대조이며 구매·납땜·펌웨어 작업은 하지 않았다.

### 아키텍처 문서의 최신화 필요 범위 검토

- 사용자는 `01_System_Architecture`의 오래된 내용이 남은 이유와 수정 가능 범위를 요청했다. 47개 Markdown(한국어 27개·영문 20개)의 구성·상태 표현을 훑고 주요 불일치를 현재 코드, report 26/31, 최신 검증 매트릭스와 대조했다. 모든 데이터시트 수치·안전 요구사항을 전수 재인증한 검토는 아니다.

- 코드에서 PC7은 GPIO 입력이며 현재 EXTI 완료로 기록하면 안 된다. TEL은 실제 적용 PWM 값을 사용하고 ESP M2 시험 hook은 1U다. report 26의 모터 분리 T004 PASS와 report 31의 B/M2 양방향 관측을 전체 T005A·실모터 S0 정지 PASS로 확대하지 않는다.

### 층간 연결 구상 재개: ADC·CAN 인출 접점

- 최신 VRT 두 헤더의 핀 레코드와 PDF, 기존 헤더 좌표 검토·ST UM1724 표29를 대조했다. PA4=C21/R28, PB0=C22/R28, PA12=C11/R4, PA11=C12/R4의 저장된 Net은 모두 0이다. GND/3V3 인출 후보도 구분했다.
- 기존 납땜 부품을 유지하면서 NUCLEO 상면 헤더에서 인출해 외곽으로 내리는 방법을 우선안으로 구체화했다. ADC는 PA4/PB0 인접 하층 구역, CAN은 PA11/PA12 인접 하층 구역을 검토한다.
- ADC 단독 검토의 4핀과 층간 초안의 3핀은 각각 신호별 귀환선/공통 귀환선 대안임을 명시했다. 커넥터·길이·공급 여유·실물 접근성 확정은 남겨 두었다.
- 수정: 전기설계 12·13 및 현재 인수인계와 이 기록. VRT/PDF·펌웨어·실물은 변경하지 않았다. 다음은 상면 핀 접근 가능 높이와 새 기판의 고정홀·커넥터 외곽을 맞추는 작업이다.
