## Repository Audit Findings

### 실제 motion output gap

- STM32 `UART_MVP_OUTPUT_TEST_ENABLED`는 안전 기준선 `0U`다.
- 현재 `handle_cmd()`는 hook enable + exact `vx=50`, `w=0`일 때만 fixed test duty를
  `motor_output_set_raw()`에 전달한다.
- 따라서 current production CMD는 range/state/E-stop validation, storage와 ACK까지 수행하지만
  일반 `vx,w`를 left/right PWM/DIR로 변환하지 않는다.
- Final MVP 전에 작은 open-loop mapper가 필요하다. PID는 이 종료선에 포함하지 않는다.

### command source와 telemetry gap

- Current STM32 protocol owner는 USART1/ESP32 path이고 USART2는 encoder evidence TX로 사용된다.
- Charter는 PC 또는 ESP32 한 command source를 허용하지만 master plan의 일부 문장은 둘 모두를
  final acceptance로 요구해 범위가 상충한다.
- Final motion ownership은 하나로 고정하고, dual-owner를 금지한다. 현재 최단 baseline은
  ESP32 -> STM32 USART1이다.
- STM32 TEL의 `left_pwm`, `right_pwm`, `batt_mv`는 현재 hard-coded zero이므로 actual applied
  state와 battery monitoring으로 연결해야 한다.

### power, mechanical과 odometry gap

- `REQ-POWER-004` low-voltage warning/motor-stop 수치와 target behavior가 미완료다.
- F1 `257` marking 대 ordered 287 identity, S1 exact DC basis, final AWG12/16 path, loaded
  voltage-drop/thermal과 downstream back-power가 열려 있다.
- battery physical retention, full-harness strain relief와 track tension/alignment preflight가
  요구사항/시험에 충분히 닫혀 있지 않다.
- Encoder CPS와 1560 counts/rev는 존재하지만 final 1 m 이동량 계산, calibration/validation
  분리와 repeat rule이 미완료다.
- Adapter plate는 repository manufacturing records 기준 `NOT SUBMITTED`이며 order ID/payment/
  vendor receipt가 없다. E-stop mounting freeze와 실제 주문 제출이 `P-07`에 포함된다.
