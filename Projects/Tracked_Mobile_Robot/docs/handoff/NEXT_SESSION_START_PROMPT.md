# 다음 세션 시작 프롬프트

Tracked_Mobile_Robot 프로젝트를 이어서 진행하자. 루트/프로젝트 AGENTS.md, CURRENT_SESSION_CONTEXT.md 상단, docs/progress/2026-11-17_progress.md, docs/plans/2026-11-17_Ubuntu_Nav2_Simulation_and_RL_Roadmap_ko.md를 먼저 읽어.

나는 현재 Windows이고 같은 노트북 내부 SSD를 절반 나누어 Ubuntu 듀얼부팅할 계획이다. 전환 시점은 아직 미정이며11/19 백업·점검 후11/20 설치 권고안을 만들었다.11/17 읽기 전용 조회에서 내부1TB/C:여유약773GB였고 암호화 상태는 접근 거부로 UNKNOWN이다. 과거 별도Ubuntu SSD 기록을 현재 설치로 취급하지 마.

첫 작업은 백업 복원·암호화/복구 정보·설치 USB·실제 축소 가능량 확인이다. 환경 준비가 안 되면 ROS 토픽/TF 계약과 가상 모델 가정표를 Windows에서 준비하자. 실제 파티션 변경/설치는 사용자가 확인된 절차로 수행한다.

PCB를 기다리지 않고 가상 IMU/LiDAR·odom/TF→Nav2 기준선→선택적 RL 비교를 병행한다. Ubuntu24.04/Jazzy/Harmonic은 설치 전 제안이다. 내장ADC·실물IMU/LiDAR·물리속도 제어 완료로 가정하지 마. 하드웨어 연결은 ESP 단일명령입구/STM 최종안전권한을 유지한다.

전기 작업은 보호저항/퓨즈 결정표와 설치·포트/전원전이 조건을 닫는 데 집중한다. 보유24AWG는 실리콘 피복 연선이다. 새길이/외경/커넥터는 미정. 보호저항은 합선 판별이 아닌 전류 제한이고 TCR은 간단한 오차상한으로 중요도를 판단한다. 새 온도/잡음 실습이나 완료 B/03_15를 자동 반복하지 마.

Git 무관 변경·과거 기록을 보존하고 MCU빌드/플래시·실물은 시작하지 마. 자료 작성/수기·이해/구현/실측을 구분하며 NotebookLM은 별도다.11/17 마감 영수증의 외부 게시 실제 결과를 확인해.
