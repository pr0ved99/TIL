## PCB 학습 재개

자료 작성37-3까지, 사용자 필기 완료36-19까지. 다음37-4 잡음·평균 처리·10Hz 결과 검증 →38 기준 계기/보정 계수 →39 전체 오차 예산 판단. 완료RC/공차/두 점 보정 기본 실습을 반복하지 않는다. [학습21](../../07_Embedded_Learning_Notes/01_Concept_Notes/21_Voltage_ADC_Tolerance_Isolation_and_Discharge_Lab_ko.md).

14MHz/480cycles는 ADC 초기 후보이고 구현/PASS가 아니다.0.1% 저항·100pF·고정30µs는 비교 가정이다. 전원 전환 보호/전체±0.10V 정확도·제작 전압2채널 회로/ERC는 미완료다. TPS CT-open tD는 지정 조건 MAX50µs, 최소 대기 보장이 아니다.

11/9월·10화는 프로젝트 휴무로 유지한다. [날짜별 계획](../plans/2026-11-04_to_15_PCB_Laptop_Work_Plan_ko.md)의11/5 실적/11/6 재개점을 따른다.

## 작업 방식

필기는 목적→근거/조건→식/단위→관측→판단을 생략하지 않고 순차 진행한다. 데이터시트 판본·쪽·표/행·시험 조건·MIN/TYP/MAX를 명시한다. 사용자 요청 없는 subagent/독자 SPICE/MCU 빌드·플래시/실물 조작을 시작하지 않는다.

정리는 문서·진행·선택 Git/push·기존 Calendar 시간 보존·Notion 학습/진행 갱신의 다섯 항목이다. 실제11/5 게시 결과는 진행 기록/관측 폴더 publication.json을 따른다.
