# Portfolio Notes

이 폴더는 Tracked Mobile Robot 프로젝트를 포트폴리오 관점에서 정리하는 공간이다.

목적은 단순히 구현 목록을 나열하는 것이 아니라, 로봇 시스템 통합 엔지니어 관점에서 어떤 역량을 보여줄 수 있는지, 현재 프로젝트가 어떤 강점을 갖고 있는지, 앞으로 어떤 증거를 더 쌓아야 하는지를 추적하는 것이다.

- README를 작성하거나 수정할 때 이 문서의 표현을 가져간다.
