# 차량 좌우 매핑 정정과 엔코더 손회전 확인

검사 세션 기준일: 2026-09-26. 문서 정리: 2026-09-27.
근거는 이번 대화의 사용자 실물 확인과 검사 통과 보고다.
새 원본 로그·사진·정량 CPS 값은 첨부되지 않았다.

## 현재 기준

사용자가 **모터 A는 실제 차량의 왼쪽 궤도 위치**라고 정정했다.
좌우는 차량 뒤에서 전진 방향을 바라보는 기준으로 통일한다.
과거 `A=right/TIM5, B=left/TIM3` 기록을 현재 실물의 연결 지시로 사용하지 않는다.

| 구분 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 모터 식별 | MG540-A | MG540-B |
| MDD10A 채널 | M1: Motor+→M1A, Motor−→M1B | M2: Motor+→M2A, Motor−→M2B |
| 동력선 상태 | A의 M1A/M1B 연결 사용자 확인 | B 동력선은 분리 유지; M2 연결은 계획 |
| PWM / DIR | PB6 / PC8 | PB7 / PC9 |
| 엔코더 커넥터 | JENC_1 | JENC_2 |
| A상 / B상 입력 | PB4 / PB5, TIM3 | PA0 / PA1, TIM5 |
| 출력 / 피드백 필드 | left_pwm / left_cps | right_pwm / right_cps |

JENC 두 곳 모두 Pin1=GND, Pin2=B raw, Pin3=A raw, Pin4=AUX_5V다.
엔코더 케이블을 서로 교환했으며, 개별 A/B 신호선 순서와 기판의 1kΩ 직렬·15kΩ 풀다운은 유지한다.
이는 모터 식별명과 차량 좌우의 정정이다. 과거 모터 A/B의 측정값을 서로 바꾸거나 이름을 소급 변경하지 않는다.

## 교환 후 검사

안내 조건: 두 보드는 USB 공급, XL4015 #1의 보드용 2P 두 개 분리,
S0 잠금·S2 미조작, LiPo/S1로 XL4015 #2 엔코더 전원 공급.
두 모터는 섀시에서 분리한 상태로 한 개씩 손회전한다. 전동 구동 명령은 보내지 않는다.

| 동작 | left_cps | right_cps | 결과 |
| --- | --- | --- | --- |
| 모터 A를 실제 장착 기준 전진 방향으로 손회전 | 양수 | 0 | 사용자 보고 PASS |
| 모터 A를 반대 방향으로 손회전 | 음수 | 0 | 사용자 보고 PASS |
| 모터 B를 실제 장착 기준 전진 방향으로 손회전 | 0 | 양수 | 사용자 보고 PASS |
| 모터 B를 반대 방향으로 손회전 | 0 | 음수 | 사용자 보고 PASS |
| 양쪽 정지 | 0 | 0 | 사용자 보고 PASS |

사용자 응답: “정상이야 통과. 다음은?”
이번 검사에서 축 끝 기준 CW/CCW와 회전량·CPS 절댓값은 별도로 보고되지 않았다.
채널 독립성·전진 부호·정지 복귀의 수동 검사 통과이며, 전동 구동 방향·전류·노이즈 통과가 아니다.

## 코드와 과거 증거

- 현 코드의 TIM3→left, TIM5→right 순서를 유지한다.
- production CPS는 기존처럼 TIM3 raw 부호 반전, TIM5 raw 부호 유지다.
  커넥터 교환 뒤 실제 전진 부호 검사가 통과했으므로 이 수식은 변경하지 않는다.
- main.c의 과거 `Motor B/left`, `Motor A/right` 주석만 현재 관계로 정정한다.
  ESP parser, 타이머 설정과 1560 counts/output-rev는 이번 좌우 정정으로 바꾸지 않는다.
- MDD10A의 DIR LOW/HIGH 중 어느 값이 실제 전진인지는 첫 짧은 구동 시험에서 확인한다.
- 7월 로그·50회전 보정·날짜별 보고서는 당시 연결 조건의 이력으로 보존한다.
  옛 좌우 표기를 현재 안내에서 다시 적용하지 않도록 최신 문서에서 이 정정을 연결한다.

## 다음 작업

M1만 낮은 듀티로 한 번 구동하고 종료하는 수동 시작 시험 경로를 준비한다.
현재 ESP의 네 기존 시험 hook과 STM의 출력 시험 hook은 0U다.
현재 ESP monitor는 명령 입력을 STM으로 전달하는 일반 콘솔이 아니며,
T004의 반복 CMD 시험을 그대로 첫 실모터 시험으로 사용하지 않는다.
사용자가 기능 코드를 입력하고 두 보드의 빌드·플래시를 수행한다.

이 기록으로 T005A의 잔여 수용 기준이나 실제 모터 구동 gate를 전체 PASS로 바꾸지 않는다.
