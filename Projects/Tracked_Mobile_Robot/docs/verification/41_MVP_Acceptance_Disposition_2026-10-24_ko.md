### 기존 원본에서 확인한 설명 정정

- **엔코더 디지털 전이 근거는 있다.** report32의 A/B3초 구동에서 각각1432/1384전이, 역방향/동시2비트 전이0/0, CPS 적분과 전이 수 일치, 마지막 전이 후 약20초 고정을 확인했다. A S0 회차의 마지막 반대 전이1개와10/24 정지 과도기 오른쪽 -1count는 별도 남긴다. 디지털 관측으로 아날로그 overshoot/출력형식까지 확인한 것은 아니다.
- **실제 구동 중 S0 관측도 있다.** report32에 PC7 활성 이후 추가 PWM 없음·CPS0 유지·마지막 엔코더 전이를 보존했다. 다만 정식 T007의 동기 motion video·정지 시간/거리와 판정 기준을 모두 충족한 기록은 아니다. “S0 시험을 전혀 안 했다”와 “정식 수용은 미완료”를 구분한다.
- **온도/전류를 남은 필수 시험으로 되돌리지 않는다.** 이전 no-load/E-stop 절차의 current/heat 문구는10/19·10/23 후속 분리 결정과 함께 읽는다. 현재 REQUIREMENT를 우선하며, 오래된 체크리스트만으로 후속 장비/시험을 복원하지 않는다.

## 3. 미재현 현상과 후속 범위

ACC-COM-01·ACC-UI-01은 원인OPEN이다. v5.2 정상3조건을 수집했고, 당시 긴 지연이나 옛 버튼 활성 문제는 재현되지 않았다. 지금 같은 IDLE/속도0/전진을 추가하면 원인을 분리할 새로운 관측 없이 표본만 늘어난다. 수정 근거가 생기거나 사용자가 진단을 선택할 때 필요한 구간만 다룬다. ESP 계측B는 자동 구현하지 않는다.

기구 장착·간격/접근·배선 경로의 사용자 보고 PASS와 T-MECH-002 전체 identity/치수·사진의 PARTIAL을 유지한다. 기존 장착 확인을 반복하지 않는다. 온도·전류/ADC·IMU/CAN/PCB, 정밀 rail transient T006·단일고장 T005B는 후속이다. `READBACK 미확인`, `사진 미기록`, `원인OPEN`, `수용 기준 미정`을 모두 같은 실물 재시험으로 바꾸지 않는다.

## 4. 다음 한 단계

**10/24 후속 정정: 아래는 당시 제안이며 현재 실행 지시에서 취소했다.** 같은 제조사 자료 검토와 수치 기준 미확정은10/17에 이미 기록했고, 사용자가 후속 조사 재개를 제외했다. 일반적인 “진행”을 해당 조사 재개 승인으로 확대하지 않는다. 현재 결론과 실행 범위는5절을 따른다.

**T005A의 전원 차단 판정 기준을 설계 검토한다.** 이미 측정된10/17 값은 S2 후12.03V, S0 후5초1.43V/30초0.58V, 전원 재투입·S2 미조작 MDD0.46V다. 이 값에 맞춰 합격선을 사후 선택하지 않는다. 다음 산출물은 아래 세 가지에 대한 근거와 제안이며 아직 채택값은 없다.

1. K1 뒤 MDD B+↔B−의 `V_RAIL_OFF_MAX`와 확인 시점: 어떤 잔류 에너지·재기동 조건을 배제하려는 기준인지 먼저 명시.
2. 직접 rail 차단, back-power 없음, PWM0, 실제 궤도 정지 각각을 입증하는 방법과 현재 보유 근거의 대응. DMM 값을 모터 정지시간으로 변환하지 않음.
3. 이 기준 검토가 기존 사용자 제외 범위와 겹치는 지점 및 정식 인수에 계속 남을 조건. 기준 한 개를 정한다고 정격/release·T007까지 모두 닫히는 것으로 취급하지 않음.

[기존 E-stop 시험 계약](06_Physical_EStop_Requirements_and_Verification_Plan_ko.md)의 T005A/T007을 기준으로 제안한다. 시험 또는 범위 변경이 실제로 필요해지면 구체적 대상·선행 조건·PASS/중단 조건을 먼저 제시한다. 지금은 새 S0/주행 시험, MCU 입력이나 전원 조작 지시가 없다.

전체 MVP 종료 규칙은 유지한다. 적용 MUST의 PARTIAL/BLOCKED가 남아 있으므로 **전체 완료 판정은 하지 않는다**. 후속 자료 준비와 제한 기능의 완료 기록은 계속 가능하다.

## 5. 기준 검토 결과와 중복 재개 정정

[10/17 기록](../progress/2026-10-17_progress.md#제조사-자료-검토-후속)과 [당시 사용자 범위 정정](../progress/2026-10-17_progress.md#진행-범위-정정과-g4c-재개)을 확인했다. 이번에 다시 지정한 rail-off 기준 조사는 기존 미결을 반복한 것이다. 정격/단자/도면 조사, 제조사 문의, 추가 방전·역급전 시험을 다음 필수 작업으로 복원하지 않는다. 기존 PARTIAL은 유지하며 제외를 PASS로 해석하지 않는다.

확인한 사실과 기준의 한계는 다음과 같다.

| 구분 | 근거와 현재 판단 |
| --- | --- |
| MDD 전원 전압 | [제조사 매뉴얼](../../assets/datasheets/Cytron_MDD10A_User_Manual.pdf) V2.0 p.5의 전원 입력 범위는5–30V다. **5V는 무토크/출력 차단 보장 임계값이 아니다.** [공식 FAQ](https://www.cytron.io/p-10amp-5v-30v-dc-motor-driver-2-channels)는 UVLO를 언급하지만 차단/복귀 전압·공차·무전원 출력 상태를 수치로 제시하지 않는다. 보호 기능 부재로 단정하지도 않는다 |
| PWM0와 전원 차단 | 매뉴얼 p.8은 PWM LOW에서 두 모터 출력 LOW를 명시한다. 정상 전원 조건의 이 진리표를 전원 감쇠 중/무전원 출력 보장으로 확장하지 않는다. [현재 회로 계약](../../01_System_Architecture/25_Physical_EStop_RevB_Circuit_Architecture_ko.md)의 K1은 양극 공급 경로를 끊으며 GND/제어선은 남는다. PWM0·K1 공급 차단·잔류 전압0은 각각 다른 사실이다 |
| 기존 DMM 관측 | 10/17은 모터 전력선4개와 MDD 제어5핀을 분리한 조건이다. S0 후5초1.43V/30초0.58V는 입력 전압 감소 근거다. 전체 배선 조건의 역급전 부재·순간 차단시간·실제 궤도 정지시간은 입증하지 않는다. 잔류 전압 원인을 커패시터로 확정하지 않는다 |
| 잔류 에너지/시간 | 정지한 회로의 커패시터 에너지는 `E = C×V²/2`로 평가할 수 있지만 전체 유효C·에너지 유입 경로·허용 에너지가 미확정이다. 모터 회전 중 에너지도 별개다. 매뉴얼 p.3/9는 회생 전류를 설명하므로, K1이 열려 배터리 흡수 경로가 끊긴 상황의 거동을 문구만으로 보장할 수 없다. 기존 두 전압값만으로 단일RC를 역산해 방전시간을 합격 처리하지 않는다 |
| 실제 정지/재시작 | report32의 A 구동 S0 후 PWM 차단·엔코더 마지막 전이 근거와 기존 S2 재인가/무자동복귀 subset은 보존한다. 마지막 전이127.32ms는 PC7 활성 기준 해당 회차의 관측이며 물리 정지시간의 합격선이 아니다. DMM 저전압·S0 해제·S2 누름 중 어느 하나도 자동 주행 허가가 아니다 |

따라서 **이번에 채택한 `V_RAIL_OFF_MAX`·`T_RAIL_DECAY_MAX`·`T_K1_OPEN_MAX` 값은 없다.** 0.58V에 맞춘1V/30초 같은 기준을 만들지 않는다. 정량 기준을 다시 다루기로 별도 결정할 경우에는 허용 운동/에너지와 장치의 전원 상실 동작, 계측 불확도를 먼저 연결해야 한다. 정밀 과도계측T006·단일고장005B는 계속 후속이다.

이번 확인에는 저장 매뉴얼 p.5/8 표의 육안 대조와 [공식 제품 페이지](https://my.cytron.io/p-10amp-5v-30v-dc-motor-driver-2-channels)의 매뉴얼 연결을 사용했다. 웹 PDF export는 접근되지 않아 저장 PDF를 읽었으며, [검토 기록](../../assets/logs/wifi_link/2026-10-24_demo_evidence_preparation/review.json)에 파일 해시·범위를 남겼다. 새 실물 근거와 요구사항 판정 변경은 없다.

현재 진행 가능한 후속은 **기존 영상·로그로 시연 자료를 준비하는 것**이다. 저장소에10/18 영상4개가 실제로 있으며, [시연 구성안](../plans/2026-10-24_MVP_Demo_Outline_ko.md)에 원본 식별·사용할 장면·자막 초안을 추가했다. 추가 S0/주행 시험이나 제조사 응답을 이 문서/편집 작업의 선행 조건으로 두지 않는다. 영상 파일 보유와 새 시연 편집본 완성·전체 인수·공개는 구분한다.
