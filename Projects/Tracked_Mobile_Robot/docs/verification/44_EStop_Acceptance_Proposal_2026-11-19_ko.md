# 전원 차단·실제 정지 수용 결정안

작성2026-11-19 · 갱신2026-11-20 · **T005A 정상 기능 수용 범위 변경 사용자 채택 / 한정 PASS / T007 미완료**

최신 채택 결정은 **§10의 T005A 정상 기능 한정 PASS**, 최신 실물은 **§15의 A만 연결/B 미연결·S2 조작 보고**다. §16은 한정 영상 관측의 실행 조건 변경안이며 **미채택**이다. §12의 A/B 모두 연결 해석과 B 분리 요청은 철회됐다. §9의 미채택 표현은11/19 제안 당시 기록으로 보존한다. §8의 UT210E 부하 진단은 당시 조건의 완료 근거다. 이전 PARTIAL/다음 작업/모터4선 분리는 당시 기록이며, 수치 rail-off/잔류 에너지의 정량 보장과 T007 실제 정지는 여전히 미완료다.

사용자 답변: **“제안한 성능 목표 채택”**. 실제 속도≤0.10m/s, 정지시간≤1.0초, 잔여 이동≤0.10m를 제한된 저속 시험의 성능 목표로 확정했다. 정본 요구사항24와 시험 계획06에 반영했다. 이 답변을 rail-off 기준 승인이나 새 통전 승인으로 확대하지 않는다.

## 1. 이번 결정

이미 수행한 배선·손당김·방전·PWM 차단·복구 시험은 해당 조건의 근거로 재사용한다. 새 전선·단자·압착기 구매와 같은 시험의 반복을 다음 작업으로 지정하지 않는다.

전원 차단과 기계 정지를 별도로 판정한다. 아래 정지 성능 목표는 제안 후 사용자가 채택했다. 전원 차단의 전기적 수용까지 해결한 안은 아니며, 원래 MUST를 줄여 전체 MVP를 PASS로 만들지 않는다.

## 3. 전원 차단 — 유지할 요구와 남은 결정

목적은 S0가 배터리의 지속적인 구동 에너지 공급을 끊고, 다른 전원 경로로 위험한 구동이 유지되거나 자동 재개되지 않게 하는 것이다.

- K1의 주전력 공급 차단, PWM0, 무자동재출발을 각각 확인한다. K2 표시나 소프트웨어 FAULT만으로 전력 차단을 판정하지 않는다.
- K1이 열려도 저장 전하 때문에 입력 전압이 즉시0V가 되지 않을 수 있다. 다만 현재 남은 전압의 원인을 커패시터로 확정한 것은 아니다.
- 기존10/17의 S2 후12.03V, S0 후5초1.43V/30초0.58V 및 S2 없이 배터리 수준으로 복귀하지 않은 관측을 보존한다. 이에 맞춰1V/30초 같은 합격선을 새로 만들지 않는다.
- MDD10A의 최소 동작전압5V를 무구동 보장 경계로 쓰지 않는다. 기존 제조사 검토에서도 보장된 차단 전압을 확보하지 못했다. 같은 검색을 반복하지 않는다.

**결정:** 기존 `V_RAIL_OFF_MAX` 요구를 유지한다. 현재 근거만으로 이 값을 정해 T005A를 PASS로 바꿀 수 없다. 추가 진단을 하더라도 결과가 어떤 수용 판단을 가능하게 하는지 먼저 정해야 한다. §9.10의10kΩ 임시 부하는 원래 회로의 방전 조건을 바꾸므로, 그 결과만으로 원래 회로를 합격시킬 수 없다.

전압 수용 요구를 삭제하거나 후속으로 옮기는 것은 요구사항 변경이다. 이번 검토에서는 시행하지 않는다. **전원 차단 수용 기준을 미리 닫지 못한 설계/검증 계획의 미결이며, 사용자가 방전 시험을 하지 않았다는 뜻이 아니다.**

## 4. 실제 정지 — 사용자 채택 성능 목표

아래 값은 제한된 저속 시험의 프로젝트 성능 목표로 채택했다. 제조사 보장이나 법정 안전 기준은 아니다. 기존127.32ms를 합격시키기 위해 배수를 적용해 산출한 값도 아니다.

| 항목 | 채택 목표 | 목적 / 적용 경계 |
| --- | --- | --- |
| 시험 직전 선속도 | 0.10m/s 이하 | 움직이는 궤도 또는 차체의 실측 속도로 확인. duty5~10%만으로 충족했다고 보지 않음 |
| 정지시간 상한 | 1.0초 | 작동 시점부터 잔여 운동이 끝나는 시점까지의 명시적인 성능 목표 |
| 정지거리 상한 | 0.10m | 작동 뒤 허용할 잔여 이동 예산. 실제 측정값으로 별도 판정 |
| 복구 | 기존 무자동재출발 요구 유지 | S0 해제나 RESET만으로 재시동하지 않음. 이미 확보한 단계별 근거 재사용 |

수치의 맥락: 속도0.10m/s에서1.0초 동안 같은 속도가 유지된다면 이동은0.10m다. 시간과 거리 목표를 같은 이동 예산으로 연결한 것이다. 실제 감속·미끄러짐을 계산한 결과가 아니므로 두 항목을 독립 측정한다. 이 거리를 사람이 접근해도 되는 안전거리로 해석하지 않는다. 끼임 위험에는 짧은 이동도 위험하며 기존 공중 고정·접근 제한 조건을 유지한다.

T007 공중 단일 모터 조건에서는 차체 이동 대신 궤도 표면 이동 또는 축 회전각/회전수로 잔여 운동을 기록한다. 지상 정지거리와 동일한 실험으로 취급하지 않는다. 경사·고속·추가 적재 조건에는 위 목표를 확장하지 않는다.

**채택 경위:** 기존 문서에 없던 허용 시간·이동량을 사용자가 이번에 선택했다. 정본 요구사항과 시험 계획의 해당 목표 미정을 해소한다. 기존 정지 모습만으로 이 목표의 충족을 판정하지 않는다.

## 5. 측정으로 넘어갈 조건과 방법

1. 전원 차단 수용 미결을 먼저 해결한다. T005A가 PARTIAL인 상태에서 T007 선행 조건을 무시해 새 구동을 시작하지 않는다.
2. 정지 목표 채택은 완료했다. 이후 보완할 것은 **작동 기준 시각과 실제 운동 종료/이동량을 같은 기록에 담는 정량 근거**다. 기존 S0 기능·방전·정역회전을 다시 입증하는 시험이 아니다.
3. 기존 카메라 영상은 작동부 가림과 공통 시각 부재 때문에 이 계측에 쓰지 않는다. 후속 측정은 카메라의 작동 표시/운동 표식/눈금과 LA의 PC7/PWM/엔코더를 어떻게 대응시킬지 먼저 정한다. PC7 기준 지연과 물리 S0 작동 기준 지연을 혼용하지 않는다.
4. 프레임 간격·시각 대응·눈금 오차를 포함한 측정 상한이 기준 안에 들어와야 PASS다. 계측 오차를 붙이면 기준을 넘는 결과는 합격으로 반올림하지 않는다. 촬영 횟수나 장비 구매를 지금 추가하지 않는다.

**결정안 작성 시점 결과:** 정지 성능 목표 확정 완료, 전원 차단의 수치 수용 미결. 이후 §8의 모터 분리·부하 진단을 사용자가 수행했다. 상위9 PASS·4 PARTIAL, T005A PARTIAL/T007 BLOCKED 유지. 새 빌드/플래시·구매·외부 게시 없음.

## 7. 후속 진단 준비 — 알려진 작은 부하에서 K1 OFF 전압

**설계 당시 상태:저항 사양 확인, 무전원 연결 준비 안내. 이후 §8에서 측정·종료 완료.** 사용자가 **“1% 1/4W야”**라고 확인했다. 이번 진단용10kΩ·±1%·0.25W의 사용자 보고이며 포장/구매 링크를 다시 요구하지 않는다. 실제 저항값은 후속9.95kΩ 보고를 사용한다. 다른 보유 저항 전체의 규격으로 확대하지 않는다.

### 7.1 닫을 질문과 기존 시험의 차이

현재 부족한 관측은 **배터리와 정상 로직 전원이 공급되고 K1만 OFF인 조건에서, MDD B+↔B− 전압이 알려진 작은 부하를 연결해도 유지되는지**다. 9/27·10/2의 모든 전원을 분리한1kΩ 방전 관측은 완료 근거로 보존한다. 당시 시험을 미실행이라고 하거나 반복할 필요가 있다는 뜻은 아니다.

이 진단은 전체 T005A PASS 조건을 새로 정한 것이 아니다. 알려진 부하에서의 전압·전류 근거를 얻어 지속 공급 경로 조사가 필요한지 판단한다. 원래 회로의 무부하 rail 수용, 모든 전원 조합의 역급전 부재, 실제 기계 정지 판정은 별개다. 계획 §9.10을 자동 필수 작업으로 복원하지 않는다.

### 7.2 부하 계산과 준비 조건

3S 완충12.6V와10kΩ을 가정하면:

```text
I = 12.6 / 10000 = 1.26mA
P = 12.6² / 10000 = 15.876mW
```

허용오차 하한9.9kΩ에서12.6²/9900=16.04mW로, 사용자 확인 정격0.25W의 약6.4%다. 실제 저항값을 새로 측정한 결과가 아닌 공칭/허용오차 계산이며 이번 부하 준비에 사용할 수 있다. 별도 저항 측정이나 구매를 새 필수 단계로 추가하지 않는다.

**이번에 안내할 한 작업 묶음:** 배터리·두 보드 USB·LA를 분리하고 S1 OFF/S0 잠금 상태에서 모터로 가는 전력4선을 분리·절연한다. K1→MDD B+와 B− 귀환, 제어5핀·엔코더 배선은 유지한다.10kΩ을 기존 MDD B+↔B− 측정점에 절연된 고정식 집게/후크로 병렬 연결한다.12AWG 주전력선 압착부를 풀거나 저항 다리를 기존 단자에 억지로 끼우지 않는다. 집게/저항 다리끼리 또는 옆 단자와 닿지 않게 고정한다. 고정 방법이 확보되지 않으면 연결을 진행하지 않고 그 사실을 알려주도록 안내한다. 완료 조건은 위 전원 분리·모터 분리/절연·저항 병렬 고정이며, 현재 배터리 재연결/S2/ARM은 안내하지 않는다. 연결 준비 완료는 T005A PASS가 아니다.

### 7.3 준비 완료 후 사용할 측정 범위

아래는 수행 전의 진단 설계다. 실제 결과는 §8이며 같은 측정을 반복하는 실행 지시로 사용하지 않는다.

- 모든 전원을 분리한 상태에서 준비한다. 모터 전력4선은 분리·절연하고 K1→MDD B+ 및 B− 귀환은 유지한다. 저항과 전압 측정 리드는 B+↔B−에 고정한다. 통전 중 저항을 손으로 대거나 배선을 바꾸지 않는다.
- 첫 대상은 정상 배터리/buck 공급 구성, 제어5핀 연결, USB·LA 분리 조건이다. 기존 보드 전원 연결 규칙을 유지한다. ARM/CMD는 보내지 않는다. 이 조건은 10/17의 제어5핀 분리 조건과 구분해 기록한다.
- 같은 구성에서 K1 OFF 초기값, deliberate S2 후 ON 값, S0 후5초/30초 값을 기록한다. 30초에도 하강 중이면 정상상태 누설값으로 해석하지 않는다. 실제 연결/표시가 식별되지 않거나 예상 밖 재인가·모터 움직임·연기·이상이 있으면 S1 OFF/전원 분리로 종료한다.
- 각 전압에서 저항에 흐르는 전류 `I_R=V/R`와 전력 `P_R=V²/R`를 계산한다. 이는 그 부하 조건의 관측량이며 다른 부하에서의 공급 가능 전류 상한이 아니다.

| 일부 전압이 유지되거나30초에도 계속 변화함 | 지속 유입과 잔류 방전의 구분이 남음. 값·기울기·저항 전류로 다음 필요한 분리 조건을 정하고 같은 관측을 무작정 반복하지 않음 |

진단의 완료 조건은 준비 조건과 전원 구성, 측정값·시각·저항값이 기록되어 위 판단이 가능한 것이다. **이 단계의 자료 확보 완료를 T005A 합격이라고 표시하지 않는다.** 현재 `V_RAIL_OFF_MAX`는 미결이고, 이 진단만으로4개 PARTIAL을 모두 닫을 수 있다고 약속하지 않는다.

측정 부하의 일반 원리는 [Fluke Application Note2514193 A-EN-N Rev B,3/2007](https://media.fluke.com/0e76ffe6-557c-474e-beb5-b1060066e152_original%20file.pdf)의 p1 고/저입력 임피던스 설명과 p2 저에너지 전압의 부하 반응 설명을 참고했다. 원문은 주로120V AC 용량 결합 사례와3kΩ 전용 어댑터에 관한 것으로, 본 로봇의 DC 잔류 원인·안전 판정이나10kΩ 임시 부하를 인증하는 자료가 아니다. 여기서는 원리만 참고하고 부하 전력은 별도로 계산했다.

## 8. 9.95kΩ 부하 진단 결과와 종료 — 사용자 보고

**진단 자료 확보 및 안전 종료 완료.** 계기 이름은 사용자 후속 답변의 **UT210E**를 적용한다. 저항은 공칭10kΩ·±1%·1/4W, 사용자 별도 실측값9.95kΩ이다. 저항 측정에 사용한 계기와 전압 측정 범위/분해능·교정 상태·주변 조건은 별도 보고되지 않았다. 실제 수행 시각은 추정하지 않는다.

원본 근거는 이 대화의 사용자 측정값·준비/종료 완료 보고다. [구조화한 기록](../../assets/logs/mvp_closeout/2026-11-19_loaded_rail_diagnostic/observations.json)은 이 보고를 옮긴 것이며 계기에서 내보낸 원시 로그가 아니다.

### 9.2 현재 계약에서 실제로 남는 문제

원래 T005A는 직접 측정값이 확정된 `V_RAIL_OFF_MAX` 이하여야 한다. 이 수치는 아직 없고, 원래 회로의 잔류 에너지나 무구동 보장과 연결한 근거도 없다. 따라서 **원래 계약을 유지한 채 전체 T005A를 PASS로 쓰는 것은 불가능**하다. 이번5mV에 맞춰10mV 같은 합격선을 사후 선택하지 않는다.

반면 정상 K1 공급 차단과 PWM0·무자동복구의 기능 근거는 위와 같이 이미 있다. 모터가 연결되지 않은 시험에서 모든 잔류 에너지의 무위험까지 입증하도록 요구하면, 별도 T007의 실제 정지 및 T006의 정밀 과도 검토와 경계가 겹친다. 이것은 사용자 시험 누락이 아니라 수용 조건을 미리 정하지 못한 계획 문제다.

시험 계획06에 남은14AWG 기반 K1 선재 불일치는11/19 양쪽12AWG 확인으로 해소됐다. F1/F2 전체 정격 검토나 T003 잔여 정량 current/열을 이 정상 기능 시험의 새 작업으로 자동 복원하지 않는다. 각 항목의 원래 근거/후속 범위는 보존하며, 이번 대조만으로 해당 전체 시험 ID를 PASS로 올리지 않는다.

### 9.3 권고하는 수용 문구 — 미채택 초안

> T-ESTOP-005A는 정상 S2와 정상 하네스, 기록된 배터리/buck 운용 구성, 모터 분리 조건에서 **정상 공급 차단·출력 정지·무자동 재출발 기능**을 수용한다. K1 무여자 주접점 open/제어 경로 근거와 MDD 입력의 직접 전압 관측을 함께 사용하며, K2 표시나 소프트웨어 상태만으로 주공급 차단을 판정하지 않는다. §9.1의 여섯 정상 동작 항목을 충족하고 상충하는 미해결 관측이 없어야 한다. 통신 유실 항목은 timeout에 따른 PWM 정지이며 K1 자동 차단을 요구한 것으로 해석하지 않는다.
>
> `V_RAIL_OFF_MAX`에 의한 잔류 전압·에너지의 정량 수용은 이 정상 기능 PASS에서 분리하여 **OPEN**으로 유지한다. 미정 값을 채택한 것, 임시 저항이 없는 회로가5mV까지 방전된 것, 모든 역급전 경로가 제거된 것으로 주장하지 않는다. 임시 저항은 진단 부하이며 영구 설계로 추가하지 않는다.
>
> PASS 표기는 `PASS — 모터 분리·시험한 정상 전원 구성의 기능 범위`로 한정한다. 실제 정지시간/거리T007, 정밀 rail 전이T006, 단일고장005B 및 전체 전원 조합의 잔류 에너지/역급전 수용을 포함하지 않는다.

**이 변경의 효과와 손실:** 기존 기능 근거로 정상 기능 시험을 닫을 수 있다. 대신 기존 T005A에 포함됐던 수치 rail-off 수용을 이 PASS에서 보장하지 않게 된다. 따라서 이를 단순 문구 정리나 원래 조건 그대로의 합격이라고 표현해서는 안 된다. 잔류 전압·에너지 위험을 검증 완료로 처리하는 승인도 아니다.

**다음 한 결정:** 위 수용 범위 변경안을 채택할지 사용자 검토를 받는다. 기존 문서의 필수 합격 조건을 바꾸므로 확인이 필요하다. 유지 선택 시 원래 수치 수용은 미결로 남으며, 동일 부하 시험을 반복하는 것으로 해결되지 않는다. 채택 전에는 현재 T005A PARTIAL/T007 BLOCKED를 유지한다.

현재 실물은 §8.4대로 전원 분리·임시 저항 제거·모터 전력4선 분리 상태다. 이번 작업은 기존 근거 대조와 변경안 작성이며 새 실물 측정·통전·구매·빌드/플래시·외부 게시가 없다.

## 10. 2026-11-20 채택과 최종 T005A 판정

사용자는 §9의 구체적인 수용 범위 변경안에 대한 채택 질문 직후 **“진행하자”**라고 답했다. 이를 제시한 범위 변경의 채택으로 반영한다. 별도의 새 수치 기준, 잔류 위험 제거, 다른 시험의 일괄 PASS 또는 통전 승인으로 확대하지 않는다.

**T-ESTOP-005A: PASS — 모터 분리·시험한 정상 전원 구성의 공급 차단·PWM 정지·무자동 재출발 기능 범위.** 판정일은11/20이며 새 시험일이 아니다. §9.1의 여섯 정상 동작에 대해 보고서24/26/27,10/17 관측,11/19 부하 진단을 재사용했다. 각 회차의 구성·실행 이미지·사용자 보고/원시 캡처의 증거 수준을 보존하며 동시 측정으로 합치지 않았다.

### 10.1 적용한 계약 변경

- 요구사항24의 `V_RAIL_OFF_MAX`는 잔류 전압·에너지 및 전체 전원 조합의 정량 수용용 **TBR/OPEN**으로 남긴다. T005A 정상 기능 PASS의 수치 선행 조건에서는 분리하고 기존 T006/rail 진단 후속과 연결한다.
- 시험 계획06의 T005A는 §9.3의 수용 문구로 변경했다. K1 무여자 주접점 open/제어 경로와 직접 MDD 입력 전압 관측, PWM·복구 기록을 함께 사용한다. 단순 K2 표시로 차단을 대신 판정하지 않는다.
- 정상 통신 유실은 timeout에 따른 PWM 정지로 판정한다. 통신 유실 때 K1이 자동으로 열린다는 요구/근거는 추가하지 않는다.
- 이 판정은 **원래 수치 조건을 만족한 것으로 소급한 PASS가 아니라, 사용자 채택으로 범위를 변경한 뒤의 PASS**다. 기존 보고서의 PARTIAL을 덮어쓰지 않는다.

### 10.3 다음 작업 — 무전원 정지 측정 준비

목적은 T007에서 물리 S0 조작과 실제 궤도 운동을 같은 영상으로 측정하는 것이다. 기존 영상의 손 가림/작동 시각 불명확 문제를 피하는 준비다. T007 구동은 선행 수용과 고정구/실측 방법이 정리된 뒤 별도로 안내한다.

1. 현재 전원 분리·임시 저항 제거·모터 전력4선 분리 상태를 유지한다. 이 단계에서 모터를 다시 연결하지 않는다.
2. 기존 공중 고정 위치에서 카메라를 고정해 **S0의 눌리는 부분과 시험할 한쪽 궤도의 움직임**이 같은 화면에 들어오게 구도를 잡는다. 실제 누르는 손이 작동부 전체를 가리지 않는 방향을 선택한다.
3. 궤도 옆의 고정된 위치에 자/눈금이 보이게 배치한다. 자·카메라가 궤도와 닿거나 궤도 안쪽으로 들어가지 않게 한다. 가능하면60fps 이상 설정을 사용하되 실제 설정값을 기록한다. 낮은 fps 자체를 즉시 FAIL로 보지 않고 후속 불확도 계산에 반영한다.
4. **준비 종료 기준:** S0 작동부·궤도·눈금이 식별되는 구도와 촬영 설정을 확보한 상태. 촬영/구동을 실행했거나 T007을 PASS한 상태가 아니다. 같은 화면 구성이 불가능하면 전원은 그대로 두고 그 제한만 보고한다.

Codex의 병행 작업은 T001~T003/T-MOTOR-003에 남은 수용 항목을 기존 범위 결정과 대조하는 것이다. 추가 구매·새 반복 시험부터 지정하지 않는다. 이번에 변경한 것은 문서와 판정이며 펌웨어·회로·실물 배선·Git/Notion/Calendar 게시를 변경하지 않았다.

## 11. 120fps 설정과 A 모터 무전원 재연결 — 사용자 완료 보고

사용자는 촬영 설정 **120fps**를 보고했다. 이어 무전원 상태에서 왼쪽A 두 선만 재연결하라는 안내에 **“완료”**라고 답했다. 연결 대응은 [보고서31 §2](31_Single_Motor_Pulse_Cross_Test_and_Right_DIR_Correction_2026-09-29_ko.md)의 동력선 표를 재사용했다.

- 왼쪽A Motor+→M1A, Motor−→M1B 연결 완료(USER-REPORTED).
- 오른쪽B 전력 두 선은 각각 절연·분리 유지. S1 OFF·S0 잠금, 배터리/USB/LA 분리 유지.
- K1/87→B+·GND바→B− 및 제어/엔코더선 유지. 새 통전·구동·전압 측정 보고 없음.
- 위 연결 완료를 T007 실행/실측 PASS로 확대하지 않는다. §10.3의 모든 모터 분리 상태는 준비 초기 이력이다.

다음은 **S0 작동부·왼쪽 궤도·고정 눈금이 같은 화면에 들어오는 촬영 구도 사진**이다. 손으로 S0를 조작할 때의 가림과 눈금 배치를 확인하기 위한 준비이며 기존 S0 기능 재시험이 아니다.120fps의 명목 프레임 간격은 약8.33ms지만, 시간/거리 판정은 실제 영상과 불확도에 따라 수행한다. 촬영 구도/사진은 아직 미제공이고 T007 구동 선행 수용은 별도로 남는다.

## 12. 이전 B 연결 해석과 분리 안내 — §13의 사용자 정정으로 철회

사용자 “B도연결했어. 다음”으로 **현재 A/B 전력선 모두 연결** 상태를 기록한다. 새 통전/구동 보고는 없으며 마지막 전원 지시는 S1 OFF·S0 잠금·배터리/USB/LA 분리다. 이번 T007 준비는 한쪽 모터 조건이므로 무전원 상태에서 B 전력 두 선을 M2A/M2B에서 분리·각각 절연하고 A를 유지하도록 안내한다. **분리 완료는 아직 미보고**다. 이 안내는 동작 시험 반복이나 두 모터 동시 시험으로의 변경이 아니다. 촬영120fps 설정 보고는 유지하며 구도 사진/실제 정지 영상은 아직 없다.

## 13. 사용자 직접 정정 — A만 연결, B 미연결·준비 완료

사용자는 “그래 준비 다 됐어”에 이어 “저 뒤에는 연결 안 했습니다”, **“모터 B에는 연결 안했다는 말이야”**라고 명확히 했다. 현재 상태는 **A만 연결 / B 미연결**이다. §12의 모두 연결 해석과 B 분리 요청을 철회하며, B를 연결했다가 다시 분리했다는 새 작업 이력으로 만들지 않는다. 추가 배선 변경을 요구하지 않는다.

120fps 설정과 준비 완료는 사용자 보고다. 구도 사진/실제 정지 영상은 아직 제공되지 않았으며 새 통전/구동이나 정량 정지 측정 완료로 확대하지 않는다. 마지막 전원 지시는 S1 OFF·S0 잠금·배터리/USB/LA 분리 유지다. T005A 정상 기능 PASS/T007 실행 BLOCKED 판정은 변경하지 않았다.

## 14. 다음 실행 단계 — S0 잠금 상태의 제어보드 기동·상태 조회

사용자 “다음”에 대해 기존 [운용 절차 §3](../handoff/CURRENT_MVP_OPERATION_RUNBOOK_ko.md)의 기동/브라우저 연결 단계만 안내한다. 목적은 현재 부팅·통신 상태를 파악하는 것이며 이미 완료한 S0 기능 시험을 새로 반복해 PASS를 더하는 작업이 아니다.

- 기존 공중 고정, A만 연결/B 미연결, USB/LA 분리를 유지한다. S0 잠금·S1 OFF에서 기존 배터리/셀 알람을 연결하고 S1 ON 뒤 제어 페이지를 연다.
- S2·ARM·방향 입력은 하지 않는다. 이번 단계에서 S0 해제나 STM reset도 안내하지 않는다.
- 예상: 제어보드 기동/통신 표시, 실제 궤도 무동작. S0 잠금 때문에 ESTOP_ACTIVE/FAULT가 표시될 수 있으며 이를 없애려고 ARM/S2를 반복하지 않는다.
- 중단: 예상 밖 움직임 또는 배터리 알람이면 S1 OFF 후 전원을 분리한다. S0는 이미 잠긴 상태이므로 같은 버튼을 다시 누르는 것을 유일한 대응으로 안내하지 않는다.
- 사용자에게 받을 결과: 실제 무동작 여부와 화면의 상태/정지 원인. 이번 기동 결과는 아직 미보고다.

T002의 단선/독립성, T003의0.06V/3.27V, T004·T005A 정상 기능 근거는 재사용한다. T001 전체 정격/release, T002/003 evidence package, T-MOTOR-003 전체 수용과 T007 구동 보류는 이 기동 안내로 해제하지 않는다. 시험 계획06 상단의 “무전원 계측 준비만 가능”이라는 일괄 표현을 정상 제어보드 기동과 모터 재인가/구동을 구분하는 표현으로 바로잡았다. 새 구매·배선 변경·빌드/플래시·합격 판정·외부 게시 없음. 결과 기록은 bench 작업 묶음 종료 때 갱신한다.

## 15. S2 조작 사용자 보고 — 실제 전원 상태 정정

사용자가 “S2까지 눌러서 대기중이니깐 빨리 영상찍자 어떻게 찍으면 돼?”라고 보고했다. A만 연결/B 미연결은 유지한다. 모터 전원이 재인가됐을 수 있으므로 전원 분리나 S0 잠금 상태를 현재 사실로 쓰지 않는다. 실제 rail 전압·K1 상태·S0 위치·ARM 여부·무동작 여부는 따로 확인되지 않았다. 방향 입력 없이 S0를 다시 잠그도록 안내했으며 수행 결과는 아직 미보고다. 새 구동·촬영 결과·PASS 판정은 없다.

## 16. 한정 영상 관측 실행 조건 변경안 — 미채택 종료, §17 참조

### 변경이 필요한 이유

[시험 계획06 Current decision](06_Physical_EStop_Requirements_and_Verification_Plan_ko.md#current-decision)은 T001~T004+T005A 전체 PASS 전 powered single-motor test를 시작하지 않도록 명시한다. 이번에 채택된 것은 T005A 정상 기능 수용과 정지 성능 목표이며 다른 선행 전체를 면제한 것이 아니다. 실행 조건 대조를 끝내기 전에 반복적으로 준비를 안내한 것은 Codex 진행 오류다.

### 제안하는 변경

**전체 미완료 판정과 원래 정식 인수 조건을 보존하면서, 기존 기능 근거에 기반한 감독하 공중 A 저속 정지 영상 관측에 한해서 별도의 실행 허가를 두자.** 구동 선행 조건을 실제로 완화하는 변경이므로 단순 문구 정정이나 기존 기준 충족으로 표현하지 않는다. 이 제안은 아직 채택되지 않았다.

관측 범위는 기존 구성·A만 연결/B 미연결·공중 고정·작업자 감독·S0/S1 접근·기존 셀 알람·USB/LA 분리·기존 펌웨어로 한정한다. 지상 주행·증속·적재·구속 시험·배선/코드 변경은 포함하지 않는다. 실제 UI 상태와 출력 제한을 확인한 뒤 한 회차씩 안내하며, 입력 속도 요청을 실측 속도로 취급하지 않는다. 이번 정지시간/잔여 이동량은 영상에서 직전 실제 속도≤0.10m/s가 확인된 표본만 목표와 대조한다. 초과 표본은 해당 목표의 합격 근거로 채택하지 않는다.

S0 작동 후 운동이 지속되거나 예상 밖 움직임·고정구 이동·셀 알람이 있으면 구동을 중단하고 S1 OFF로 전원을 끊는다. 회전체에 손을 넣거나 진행 중 배선을 만지지 않는다. 승인된 구동 안내 전에는 S0 잠금을 유지하고 ARM/방향 입력을 하지 않는다.

### 촬영 설계 — 구동 지시 아님

- 120fps 원본 촬영, 고정 카메라. S0 작동부·왼쪽 궤도의 식별 가능한 특징·고정 눈금을 한 화면에 담는다. 궤도의 직선 구간을 가능한 옆에서 촬영해 원근 오차를 줄인다.
- 눈금은 움직이는 궤도와 닿지 않는 고정부에 두며 손으로 들지 않는다. 표식/눈금 조정이 필요하면 전원을 분리한 상태에서 한다. 새 사진 제출을 반복 선행으로 요구하지 않는다.
- 실제 측정 회차에서는 정지 조작 전 움직임과 S0를 누르는 과정, 완전히 멈춘 뒤 최소2초를 끊지 않고 기록할 계획이다. 일반 정지/명령 해제가 먼저 일어난 회차를 S0 단독 정지 결과로 채택하지 않는다. 구체적인 조작은 실행 조건 채택 후 안내한다.
- S0 작동 시각의 가림, 마지막 미세 움직임, 프레임 시각/눈금 오차를 포함해 시간·잔여 이동 상한을 평가한다. 공중 궤도 이동량을 지상 차체 정지거리로 바꾸지 않는다. 편집/메신저 변환본보다 촬영 원본을 보존한다.

채택되더라도 이번 관측이 다른 미완료 항목이나 전체 MVP를 PASS로 바꾸지 않는다. 현재는 **T007 실행 BLOCKED**, 제안만 작성했으며 사용자 채택 후 그 범위에 한해 실행 문서를 갱신한다.

## 17. 사용자 결정 — 기존 선행 조건을 모두 닫은 뒤 촬영

사용자는 실행 조건 변경안 질문에 **“기존 선행 조건을 모두 닫은 뒤 촬영”**을 선택했다. §16 제안은 미채택으로 종료하고 같은 예외를 다시 요청하지 않는다. T004 및 채택된 범위의 T005A PASS, T001~T003/T-MOTOR-003 미완료, T007 실행 BLOCKED를 유지한다. S0 잠금→S1 OFF→배터리 분리를 안내했으나 종료 완료는 아직 미보고다.

### T001 과거 판정 대조

사용자의 “T001이 왜 BLOCKED야? 이전에도 계속 BLOCKED였어?”에 대해 현재 문서뿐 아니라 Git 저장본을 대조했다.

- 보고서19(2026-08-28): T001~T004 BLOCKED/NOT PASSED.
- 보고서24(2026-09-05): T001 PARTIAL. 부품/조립 근거 추가 후 전체 부품·배선·단자 검토와 당시 부하/열 근거가 남음.
- 시험 계획06 Git `2dde4b0d`(2026-09-07), `2346eb50`(2026-09-24): T001 PARTIAL/BLOCKED. F1/F2 identity·보호협조, K1 14AWG/단자 불일치, 정확한 최종 구성, 부하/열을 당시 사유로 열거함.
- 최신 상태도 PARTIAL/BLOCKED이지만, 11/19 K1 양쪽12AWG 확인으로 선재 불일치는 해소됐고 정량 전류/열은 기존 후속 분리 결정을 따른다. 11/7 기능 도면은 ERC0/0·부품명 갱신 근거가 있으나 전면 as-built 승인과 동일하지 않다.

따라서 오늘 새로 발견한 고장 때문에 BLOCKED가 된 것이 아니다. 이전 문서가 PARTIAL과 BLOCKED를 혼용하고 있으며, 문서상 BLOCKED 정의는 선행 부품·계측·회로 부재에 따른 실행 불가다. 지금 문서 검토 자체를 진행할 수 없는 것으로 해석하지 않는다. 기존 미결 표시를 그대로 새 숙제로 복원하거나, 해소된14AWG 문제·후속 열 시험을 현재 구동 금지 사유로 다시 쓰지 않는다. 실제 남은 수용 항목의 대조 없이 T001 전체를 PASS로 바꾸지도 않는다.
