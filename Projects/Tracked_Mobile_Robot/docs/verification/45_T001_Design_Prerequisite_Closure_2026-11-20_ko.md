# T001 설계 선행 조건 — 근거 대조와 잔여 항목

**현재 — 2026-11-20 비실물 검토 완료:** [통합 결과46](46_MVP_Nonphysical_Closeout_2026-11-20_ko.md)에 부품/선재 식별, 퓨즈·코일·옵토 계산, 저장 ERC와 기존 시험 근거 대조를 완료했다. 현재 소스27개에 대한 검사 입력29건의 해시가 이전 검사와 일치한다. 상위9 PASS·4 PARTIAL, T004/T005A 정상 기능 PASS 유지. 남은 것은R1 전체 보호협조 수용,R2 clamp stress 근거,R3 T002/T003 기록 수용,R4 엔코더 전기적·실제 정지 증거다. 자료 부족을 시험 미수행으로 바꾸거나 같은 부품/정상 동작을 재확인하지 않는다. 사용자 결정대로 기존 선행을 모두 닫은 뒤 촬영한다. 배선 길이/길이 기반 전압강하 검토는 제외했고, 후속 열·전류·T006을 새 필수로 복원하지 않는다.

**아래는 통합 검토46 작성 전의 대조 이력이다.** 당시의 “다음은 자료 대조”, 다운로드403, 사용자 S1 확인 요청은 현재 대기 작업이 아니다. 웹 PDF로 확인한 최신 퓨즈/홀더 정격·계산 결과와 현재 잔여 조건은46을 따른다.


2026-11-20. 현재 작업은 **T001부터 기존 선행 조건을 순서대로 닫는 것**이다. 사용자가 선택한 “기존 선행 조건을 모두 닫은 뒤 촬영”을 따른다. 한정 구동 예외는 미채택으로 종료했다. 이 문서는 새 구동 허가나 T001 전체 PASS 판정이 아니다.

## 1. 작업 순서와 경계

T001 → T002 → T003 → T-MOTOR-003의 남은 조건 → T007 순서로 처리한다. T004와 채택된 정상 기능 범위의 T005A는 PASS를 재사용한다. T001의 원래 기준은 [시험 계획06](06_Physical_EStop_Requirements_and_Verification_Plan_ko.md#t-estop-001-design-and-component-review), 요구 정본은 [요구사항24](../../01_System_Architecture/24_Physical_EStop_Safety_Requirements_ko.md)다.

이미 완료한 시험, K1 양쪽12AWG 확인과 손당김 검사를 반복하지 않는다. 후속으로 분리한 정량 전류/열, T006 정밀 과도, T005B 단일고장 확장을 옛 목록만 보고 다시 필수로 붙이지 않는다. 새로운 합격선이나 실행 예외를 만들지 않는다.

### 1.1 11/20 배선 길이 검토 삭제 결정

사용자가 “너무 디테일하니깐 기존 설계 검토에서 삭제해”라고 지시했다. 직전 요청한 **XT60 음극→GND 버스바 및 GND 버스바→MDD B− 길이 확인과 그 값을 이용한 전압강하 계산**을 MVP/T001 필수 검토에서 삭제한다. 전체 전력 경로의 길이 측정으로 우회해 다시 요구하지 않는다. 현재 판정은 **범위 제외**이며 PASS 실측/미완료/필수 후속으로 기록하지 않는다.

사용자 보고로 XT60 음극→GND 버스바는16AWG가 확인됐고, GND 버스바→MDD B−는 기존 보고서27의16AWG를 재사용한다. 추가 통전·도통·길이 측정은 수행하지 않았다. 다음은 Codex의 기존 퓨즈/릴레이 근거 대조이며 사용자에게 길이 답변을 기다리지 않는다.

차단 시 전원측 접점의 전압 검토에는 전원12.6V와 코일 역전압을 함께 고려해야 한다. 데이터시트 VC22.5V를 사용한 검토값은35.1V다. 이것은 실제 파형 측정값/배선 오버슈트 보증값이 아니다. 따라서 TX2의 `2A30VDC 저항 부하` 한 줄만으로 유도 부하 차단까지 PASS 처리하지 않는다. 펄스 에너지·시간·온도 및 접점 부하 조건의 검토가 남으며 정밀 파형T006을 지금 자동 재개하지 않는다.

### 5.3 보호협조의 남은 근거를 특정

1. **S1: PASS, 사용자 수용 완료**. 사용자 제공 판매 사양DC32V·50A와 기존 ON/OFF 근거를 이번 MVP의 수용 근거로 채택했다.3S 최대12.6V는32V보다 낮다. 제조사명·고유 형번 미제공을 사유로 이 항목을 미완료로 유지하지 않는다. 판매 자료를 제조사 시험성적서나 실제 고장전류 차단 시험으로 표현하지 않는다.
2. **F1 홀더 형번·명목정격: 확인 완료**. 사용자 제공 FHAC0002ZXJ,32VDC30A와 기존12AWG/입고 검사 근거를 연결했다.8/26 장착 계획의 FHAC0002ZXJA 계열 기록을 놓쳐 다시 요청한 것은 Codex 검색 누락이었다. 사용자 형번은 그대로 보존하고 기존 표기의 접미사 차이만으로 재확인·교체를 요구하지 않는다.12.6V<32V, 사용 퓨즈10A<홀더30A의 명목 비교는 충족한다. F2 홀더 FHAC0001ZXJA는 원래 부품 목록/메모리/입고 기록에 있었다.30A를 F2 홀더 정격으로 옮겨 적지 않는다. 반환 경로와 분기별 보호협조는 아래 기존 검토에서 구분한다.
3. **퓨즈 적용 근거**: F1은 두 모터만이 아니라 buck/F2 분기도 공급한다. 정상 전류가10A 미만이라는 것만으로 모든 가는 분기선의 단락 보호를 증명하지 않는다. 기존 시간–전류 자료와 실제 경로별 조건을 연결해야 한다. 이번 공식 ATOF PDF 재다운로드는403으로 실패했고, 새 판본을 확인했다고 기록하지 않는다.
