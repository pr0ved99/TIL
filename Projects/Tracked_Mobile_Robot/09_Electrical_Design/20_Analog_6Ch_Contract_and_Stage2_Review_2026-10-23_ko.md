# 아날로그 6채널 연결 계약과 2단계 종합 검토

2026-10-23. 전류2·온도2·전압2채널의 논리 연결과 측정 기준을 합친 **2단계 검토본**이다. 핀/기능/포트 제안을 작성한 상태이며 전원·보호 회로 선정이나 제작 승인 완료를 뜻하지 않는다. 기존 센서4채널 CAD를 확정 회로로 사용하지 않는다.

## 채널과 커넥터 계약 제안

아래 이름은 기능 식별자이며 CAD reference 번호가 아니다. 핀 순서는 **쉴드 측 커넥터의 설계 제안**으로, 센서 모듈의 실제 패드 순서와 별도 대조한다. 제품/키/피치/압착 부품은 미선정이다.

| 채널 / 기능 포트 | 외부 연결 / 핀 순서 제안 | STM 접점 후보 | PCB 안에서 처리 |
| --- | --- | --- | --- |
| I_LEFT / CUR_L | 3P: 1=SIG_GND, 2=EXP_3V3, 3=I_L_OUT | PC0 / ADC1_IN10 / CN7-38 | 외부 #5241 출력→필터/보호→ADC |
| I_RIGHT / CUR_R | 3P: 1=SIG_GND, 2=EXP_3V3, 3=I_R_OUT | PC1 / ADC1_IN11 / CN7-36 | 왼쪽과 독립된필터/보정 경로 |
| T_LEFT / TEMP_L | 2P: 1=SIG_GND, 2=NTC_L_NODE | PC2 / ADC1_IN12 / CN7-35 | PCB의 VEXC→고정 저항→NTC 노드, 노드→필터/보호→ADC |
| T_RIGHT / TEMP_R | 2P: 1=SIG_GND, 2=NTC_R_NODE | PC3 / ADC1_IN13 / CN7-37 | 왼쪽과 독립된 분압/보정 경로 |
| V_UPSTREAM / RAIL_UP | 2P: 1=SENSE_GND, 2=VBAT_PROTECTED_SENSE_RAW | PA4 / ADC1_IN4 / CN7-32 | K1 전단 감지 분기→분압/필터/보호→ADC |
| V_DOWNSTREAM / RAIL_DOWN | 2P: 1=SENSE_GND, 2=MOTOR_VBAT_SAFE_SENSE_RAW | PB0 / ADC1_IN8 / CN7-34 | K1 후단 감지 분기→별도 분압/필터/보호→ADC |

PC0/PC1의 Morpho 접점은 보드 solder bridge 선택에 따라 PB8/PB9와 관련될 수 있다. 실제 PC0/PC1 연결을 대조하고 기존 IMU PB8/PB9를 보존한다. 표의 핀 번호나 저장 VRT의 Net0만으로 사용 가능한 실물 접점이라고 판정하지 않는다.

- SIG_GND/SENSE_GND는 신호 역할 명칭이며 초기 비절연 구조에서는 정해진 공통 기준으로 귀환한다. 임의로 접지를 분할하거나 모터 전류를 이 선으로 귀환시키지 않는다. 전압 감지 귀환과 기존 보드 GND의 루프/전압 강하는 배선 검토에 포함한다.
- #5241의 IP+/IP−와 모터 주전류 단자는 이3P 신호 포트에 포함하지 않는다. 모듈은 외부 전력 경로에 두고 +i 방향과 전류 부호를 채널별로 기록한다. FAULT는 초기 관측 회로에서 미사용 후보이며 고속 과전류 차단을 구현했다고 하지 않는다.
- NTC는 극성 없는 저항이지만 포트의 GND/분압 노드 역할은 구분한다. 외부 센서 두 선에 VEXC 전원을 직접 공급하는3선 센서로 취급하지 않는다.
- RAIL_RAW는 배터리 수준의 미분압 신호다. PA4/PB0나 센서3.3V 포트로 직접 연결하지 않는다. 감지선 출발점의 단락 에너지 제한/보호도 검토하며 PCB 입구의 저항만으로 전체 감지선 보호가 끝났다고 하지 않는다.
- 전압2P는 NTC2P·전원2P와, 전류3P는 CAN/논리/기존 UART3P와 상호 오접속되지 않을 형식/키를 요구한다. 좌우 또는 전단/후단의 같은 형식은 명확한 채널 라벨·하네스 식별로 관리하되 교환 가능성과 오진 위험을 검토한다. 실물 키 검토 전 오접속 방지 완료를 선언하지 않는다.

## 측정 기준과 환산 계약

명목12bit 근사에서 `q = raw / 4096`, `V_ADC ≈ q × VREF_ADC`로 둔다. 실제 offset/gain·누설·획득/정착·양자화와 기준 전압 오차는 별도 예산이다. 입력을 무조건3.3V 전체 스케일로 계산하지 않는다.

| 측정량 | 기준/환산안 | 남은 조건 |
| --- | --- | --- |
| 전류 | `I = (V_OUT − V_ZERO_CAL) / S_CAL`. #5241 명목 영점1.65V·감도44mV/A를 초기 값으로만 사용 | 출력은 **nonratiometric**이므로 영점/감도를 EXP_3V3에 비례시켜 환산하지 않음. ADC 기준·채널 영점/감도 보정과 오차 대조 |
| NTC | `g=VEXC/VREF_ADC`, `R_NTC=R_FIXED×q/(g−q)` 후 제조사103JT R-T 표 보간 | 별도 LDO 여기안에서 `g=1` 금지. R_FIXED 실제값과 VEXC/VREF 오차·변동을 포함해 입력계±1°C 목표 검토 |
| 전단/후단 전압 | `V_RAIL = V_ADC × (R_TOP+R_BOTTOM)/R_BOTTOM`, 채널별 보정 | 분압비·정상 입력 상한·과도/역극성·누설·ADC 기준과 저항 온도 특성 계산 |

전류±30A의 이상적인 명목 출력은약0.33~2.97V다. NTC의10kΩ 고정 저항·VEXC3.3V 예는0°C2.425V,25°C1.650V,100°C0.293V다. 모두 명목 계산점이며 실제 허용 범위/보호 정격을 대체하지 않는다. 전압 측정 목표0~16V도 과도 내성을 보장하지 않는다. 성능·갱신/응답 목표는 [요구조건](15_Expansion_PCB_Requirements_2026-10-23_ko.md#측정-성능-목표-제안)을 유지한다.

STM32F446RE LQFP64에서는 별도 VREF+ 핀이 없어 ADC 기준은 내부적으로 VDDA에 연결된다. 외부 정밀 기준을 AREF에 주입하는 방식으로 이를 바꾸지 않는다. 내부 VREFINT/공장 보정값을 이용한 VDDA 추정은 후속 후보이나, 이것만으로 별도 EXP_3V3의 실제 VEXC를 알 수 있는 것은 아니다.

### NTC 여기 전압의 결정 경계

현재 공급 제안은 **#2→별도 LDO→VEXC**다. 다음 회로 단계에서 실제 VEXC와 ADC 기준의 초기 보정/온도·부하 변동을 계산해6외부 채널 유지 가능성을 먼저 판단한다. 고정3.300V로 가정한 계산이나 최초 DMM 한 번만으로 이후의 기준 전압 변동이 제거됐다고 하지 않는다.

목표를 못 맞추면 VEXC 관측 경로나 STM 아날로그 기준을 따르는 여기 방식 등을 비교해야 한다. 이 경우 추가 ADC/회로 또는 전원 계약 변경을 사용자와 검토한다. **PA6/PA7을 자동 사용해7채널로 늘리거나 두3.3V 출력을 합치지 않는다.** 외부 ADC나 새 센서 MCU도 현재 필수 부품으로 추가하지 않는다.

## 입력 이상과 데이터 유효성 계약

| 조건 | 요구 동작 / 검출 한계 |
| --- | --- |
| 초기 전원·정착 전 | NOT_READY. 실제 전원/RC 정착 시간으로 결정하며 과거20ms 후보를 새 전체 회로에 자동 적용하지 않음 |
| NTC 단선 | 노드가 **VEXC** 쪽으로 상승. VEXC가 STM VDDA보다 높으면 정상 ON에서도 입력 상한 문제가 생길 수 있으므로 보호/차단을 검토 |
| NTC 두 선 간 단락 | 노드가 GND 쪽으로 하강. 정상 고온과 오류를 구분할 임계값/오차를 재계산 |
| 전류 출력선·전원·GND 단선 | 부유/임의 중간값 가능. 영점 부근이라는 이유만으로 정상0A 판정 금지. 바이어스·전원 유효성/진단의 검출 가능 범위를 회로로 대조 |
| 전압 감지선 단선·GND 단락 | 분압 구조에 따라 정상0V와 구별되지 않을 수 있음. K1 OFF/배터리 분리와 모든 배선 고장을 전압 하나로 구분한다고 하지 않음 |
| 상한/하한 포화·범위 밖 | 원시값과 오류/OUT_OF_RANGE를 보존. 정상 최대/최소로 잘라서 숨기지 않음 |
| ADC 갱신 중단 | STALE. 채널별 측정 시각/갱신 여부로 판정하며 기존 명령 timeout과 구분 |
| STM OFF·외부 센서/rail ON | ADC 역급전/클램프 전류/전원 레일 상승 방지. 저항 하나 또는 VDDA로의 다이오드만으로 해결된 것으로 간주하지 않음 |

기존 NTC 문서의 `raw≥4079`/`raw≤16`은 동일 기준 전원 가정의 과거 후보다. 새 별도 전원에서는 VEXC/VDDA·필터·보호·정상범위를 대조해 다시 정한다. 포화만으로 단선과 과전압을 완전히 구별하지 못한다. 잘못된 기준 비율 `g≤q`에서도 정상 온도를 계산하지 않는다.

후속 데이터에는 채널 ID·원시 ADC·물리값/단위·측정 시각·유효성/오류와 적용 보정 정보를 대응시킨다. 구체 필드/전송 ID·STALE 시간은 펌웨어/CAN 계약에서 정한다. 이번에 기존 TEL 형식·CAN ID·정지 제한을 바꾸지 않는다. K1 후단 잔류 전압은 커패시터/회전 중 역기전력 등과 대조하며 즉시 접점 용착으로 단정하지 않는다. 전류/온도 자동 정지 기준도 별도 결정이다.

## 2단계 종합 판정

| 항목 | 현재 상태 | 다음 결정/확인 |
| --- | --- | --- |
| 역할·기능 범위 | 사용자 채택: STM 센서/구동, ESP 무선–CAN, 개발용 CANable. ADC6채널+CAN | 기존 UART/IMU·최종 안전 주체 유지 |
| MCU 핀 | STM6ADC·PA11/12와 ESP GPIO4/5 후보 표 작성 | PC0/1 bridge·HG 헤더·물리 접근 대조 |
| 공급 구조 | #2 병렬 분기·단일 LDO/300mA·TO-220급 제안 | #2 전체 여유·최종 레귤레이터·발열/고장 보호 |
| 포트·종단 | 센서/전압6채널과 전원/논리/CAN 핀 순서·2/3노드 종단 제안 | 실제 모듈 핀·커넥터 제품/키·절연/PC 접지 |
| 측정 기준 | 전류/NTC/전압의 서로 다른 환산 조건 명시 | **VEXC/VDDA 정확도와 MCU 무전원 보호가 회로 선정 전 우선 미결** |
| 기구·향후 확장 | 상면 쉴드 후보, 기존 IMU 유지, LiDAR 모델 미정 | 소켓/간섭/높이·고정·실제 포트 위치. 임의 LiDAR 회로 추가 없음 |

**2단계의 구성·연결 검토본을 작성했다. 전체 설계 확정/제작 가능 PASS는 아니다.** 다음3단계의 첫 작업은 **ADC 기준·NTC 여기 전압과 MCU 무전원 보호 방식 비교/계산**이다. 이 경계를 정한 뒤 전류 출력 부하/RC, NTC 분압, 전압 분압/보호와 전원 부품을 순서대로 선정한다. 실물 정보가 필요한 항목은 집에서 확인할 목록으로 유지하고, 노트북에서 가능한 계산은 진행한다.

CAD/BOM·펌웨어/빌드/플래시·배선/통전·구매와 Git/Calendar/Notion 추가 게시 없음. 이번에 기존 MVP 범위를 늘리지 않았다.
