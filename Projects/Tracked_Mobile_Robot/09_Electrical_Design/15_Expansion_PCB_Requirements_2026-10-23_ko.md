# 로봇 확장 PCB 기능과 요구조건 초안

기준일: 2026-10-23. 설계 1단계인 요구사항 정의를 위한 검토본이다.

이 PCB의 제안 목적은 **기존 로봇 제어 기판을 유지하면서 좌우 모터 상태와 전원 상태를 관측하고 CAN 확장을 연결하는 것**이다. 현재 주요 포함 후보는 전류2·온도2·전압2채널과 CAN이다. 기능 범위와 성능 조건을 함께 검토한 뒤 핀·전원·커넥터 설계로 넘어간다.

**10/23 목표 구성 채택:** 사용자가 STM32 센서/구동 집중·ESP32 무선 게이트웨이·두 MCU 사이 CAN·개발용 CANable 관측 구성을 선택했다. 별도 센서 MCU는 추가하지 않는다. STM용과 ESP용 CAN 트랜시버가 각각 필요하며 실제 부품·배치·전원·GPIO는2단계 검토 대상이다. 아래 성능 수치와 제작 후보까지 개별 확정된 것은 아니다. [현재 전체 구성](16_Expansion_PCB_System_Blocks_and_Interfaces_2026-10-23_ko.md)을 따른다.

전단 전압을 배터리 상태 관측에 함께 활용하는 구성이므로 별도 배터리 ADC를 자동 추가하지 않는다. 기존 셀별 리포 알람과 새 전체 전압 ADC의 역할은 구분한다.

기존 전류 계획은 필터된 평균/추세 관측이다. 순간 피크·정확한 RMS 측정·고속 과전류 차단이 필요해지면 별도 요구사항으로 추가하고 입력 대역폭과 보호 경로부터 다시 검토한다. 센서 측정 범위나 FAULT 임계값을 모터의 안전 운전 기준으로 사용하지 않는다. 온도 관측 범위와 모터 허용 온도도 구분한다.

## 측정 성능 목표 제안

상태: **사용자 검토 전 설계 목표**. 아래 오차·범위·갱신 주기는 관측 목적에 맞춘 프로젝트 제안이며 제조사 보증이나 실측 성능이 아니다. 회로 계산에서 목표 달성 가능성을 확인하고, 어려우면 부품 변경과 목표 조정의 비용을 비교한다.

| 측정량 | 범위 제안 | 허용 오차 목표 | 결과 갱신 주기 |
| --- | --- | --- | --- |
| 모터 전류, 좌우 각각 | 센서 명목 범위 −30~+30A를 수용. 정확도 검토 우선 구간은 −10~+10A | 우선 구간에서 ±max(0.20A, 읽음값 절댓값의5%). 채널별 영점/감도 보정 후, 초기 검증 주위20~30°C | 100ms마다, 10Hz |
| 모터 케이스 온도, 좌우 각각 | 0~100°C를 관측 범위로 설계 | **입력 회로·ADC·환산만 ±1°C** 목표. NTC 자체 편차·자가발열·접촉/열지연을 포함한 전체 오차는 별도 평가 | 1초마다, 1Hz |
| K1 전단·후단 전압 각각 | 0~16V DC | ±0.10V. 보정 후, 초기 검증 주위20~30°C | 100ms마다, 10Hz |

전류 목표의 예는0A에서±0.20A, 1A에서±0.20A, 5A에서±0.25A, 10A에서±0.50A다. 저전류를 정밀 계측하는 것보다 좌우 부하와 눈에 띄는 변화를 구분하는 데 초점을 둔다. ±10~30A 구간도 측정값을 보존하되 같은 정확도는 아직 요구하지 않는다. −30~+30A는 **신호 수용 범위**이며 로봇을 그 전류까지 구동하거나 시험하라는 뜻이 아니다.

온도0~100°C 역시 관측 범위이며 운전 허용/중단 온도가 아니다. ±1°C 입력계 목표는 정밀 저항으로 제조사 R-T 표의 온도를 모사해 확인한다. 시험 저항과 기준 계기의 불확도를 포함해 판정한다. 실제 센서를 붙인 뒤 GM1312와 비교하는 시험은 센서·프로브·접촉 조건을 포함하므로 이 입력계 시험과 구분하고, 계기 정확도를 넘는 절대 온도 성능을 주장하지 않는다.

전압0~16V는 기존3S LiPo의 완충 약12.6V를 포함하고 정상 측정 상단에 여유를 두려는 제안이다. 회생/서지·역극성·오접속 내성의 정격은 별도 보호 요구사항으로 정한다. 16V를 초과하는 과도를 견딘다는 뜻이 아니다.

### 갱신 주기와 응답 조건

위 주기는 **필터/평균 처리된 새 측정 결과를 생성하는 주기**다. ADC 원시 수집률·평균 구간·아날로그 필터 차단 주파수는 3단계 회로 검토에서 정한다. 브라우저/통신 전달 지연과 온도센서의 물리적 열응답도 별개다.

- 전류·전압의 초기 시스템 응답 목표는 입력이 안정된 뒤300ms 이내에 새 정상상태 값이 허용 오차 범위로 반영되는 것이다. 평균/필터 때문에 생기는 지연을 포함하며 고속 차단 기능은 별도다.
- 온도는 저항 대입 입력이 안정된 뒤2초 이내에 환산 결과가 반영되는 것을 초기 목표로 둔다. 실제 모터 케이스 온도 변화에 대한 센서 열응답을2초로 보장하는 조건은 아니다.
- 결과에 측정 시각과 유효성을 함께 남긴다. 정상 갱신 중단·단선/단락·범위 밖 값을 마지막 정상값이나0으로 덮어쓰지 않는다. 정확한 STALE 시간·고장 검출 한계는 후속 인터페이스/회로 검토에서 정한다.

### 목표를 고른 근거

- Pololu#5241 제조사 명목은±30A, 44mV/A, 영점1.65V다. 이상적인3.3V/12bit ADC에서는 약18.3mA/count이므로0.20A는 약11count다. 이는 양자화 측면의 초기 점검이며 센서 드리프트·ADC/기준 전압·누설·잡음의 오차 예산을 대체하지 않는다. [Pololu 원문](https://www.pololu.com/product/5241), [보관 사양](../assets/datasheets/QUICK_REFERENCE_ko.md#6-pololu5241--acs71240--후속-전류센서).
- SEMITEC103JT의 동작 범위는−50~125°C이며 공기 중 열시정수는약5초다. 프로젝트의0~100°C와1Hz는 실내 모터 케이스 추세 관측을 위한 선택이다. 제조사 범위 전체를 보증하려는 요구가 아니다. [SEMITEC 원문](https://www.semitec-global.com/uploads/2022/01/P9-JT-Thermistor.pdf), [기존 NTC 계산안](../docs/plans/2026-10-22_NTC_Temperature_Input_Design_ko.md). 기존100sample/s·표시10Hz는 당시 후보이며 새 제안의 표시1Hz와 구분한다.
- 0~16V를12bit 전체 스케일에 대응시킨 이상적 분해능은약3.91mV/count다. ±0.10V 달성 여부는 분압 저항·기준 전압·ADC·보정·온도 특성으로 검토한다. [기존3S 전원 조건](../01_System_Architecture/12_Power_Distribution_and_Safety_Architecture_ko.md).
- 10Hz/1Hz, 전류·전압 오차와 응답 목표는 관측 용도에 따른 **설계 제안**이다. 원문에서 해당 수치를 보장하는 것은 아니다. PWM 파형·순간 피크·RMS를 확인하는 별도 계측 요구와 구분한다.

## CAN 사용 환경 제안

목표는 **로봇 안의 STM32와 ESP32를 연결하고 개발 중 CANable을 함께 연결하는 공통 CAN 버스**다. 첫 송수신 확인은 STM32+CANable 두 노드로 시작할 수 있으며 이후 ESP를 연결해 목표 구성을 검증한다. 실제 모듈 확인과 배선 시험으로 아래 환경을 대조한다.

| 항목 | 요구조건 초안 |
| --- | --- |
| 목표 노드 | STM32+트랜시버, ESP32+별도 트랜시버. 개발 시 노트북+CANable을 같은 버스에 추가 |
| 통신 방식 | Classical CAN, 초기500 kbit/s·표준11bit ID. 기존 CAN 계획의 초기 조건 계승 |
| 초기 배선 환경 | 실내·총 버스 길이1m 이내를 **초기 시험 환경의 제안**으로 둠. 실제 하네스 길이는 별도 확인 |
| 배선 구성 | CANH/CANL 트위스티드 페어와 적절한 기준 GND, 선형 버스. 모터 전력선과의 근접·분기 길이를 배치 때 검토 |
| 종단 | 물리 버스 양 끝에120Ω씩. 보유 모듈 내장 종단을 먼저 확인하고 PCB 측 종단 적용/해제 상태를 식별 가능하게 구성 |
| 전기 인터페이스 | STM32·ESP32 각각의3.3V 논리와 호환. 보유 MCU-230 실제 전원·TX/RX·RS와 ESP용 별도 트랜시버를 대조 |
| 접지·절연 | 초기 비절연 구성은 검토 후보. CANable의 실제 절연 여부, PC USB/전원 연결 시 귀환 경로·전위차를 대조한 뒤 확정. 절연이 필요하면 트랜시버와 버스측 전원을 함께 재설계 |
| 역할 | 목표는 ESP–STM 명령/상태 전달과 CANable 관측. 기존 UART 기준 유지 → CAN 상태 송수신 → 명령/단절/오류 검증 → 제어 입력 전환 순서. STM32 최종 출력/안전 판단 유지 |
| 고장 조건 | 케이블 분리·상대 노드 무전원·버스 오류·자기 노드 무전원을 검토. 오류를 관측 가능하게 하고 의도하지 않은 모터 출력이 생기지 않게 함 |

1m는 버스의 기술적 최대 길이가 아니라 첫 시험 범위를 제한하기 위한 프로젝트 제안이다. 500 kbit/s도 아직 보유 장비에서 검증한 값이 아니다. LiDAR 데이터 전송, 다수 노드, CAN FD, 장거리·실외 네트워크는 이 초기 환경을 확대할 때 별도로 검토한다.

근거: [기존 CAN 통합 계획](../01_System_Architecture/14_CAN_Bus_Integration_Plan_ko.md), [TI SN65HVD230 데이터시트](https://www.ti.com/lit/ds/symlink/sn65hvd230.pdf), [TI CAN 물리 버스 설명 §5](https://www.ti.com/lit/an/sloa101b/sloa101b.pdf). IC 자료는 사용자 보유 모듈의 내장 종단·커넥터·절연 구성을 증명하지 않는다.

## 전원 공급과 이상 조건

기존 로직5V 공급과 개발용 USB 전환 정책을 계승한다. 모터 주전류와 신규 로직 부하의 공급/귀환 경로를 구분하고, 전류센서 신호·NTC·CAN에 필요한 전원을 합산한다.

| 상황 | 요구 동작과 검토 기준 |
| --- | --- |
| 정상 로직 전원 | 최신 방향: XL4015 #2 AUX5V 출력에서 확장부로 병렬 분기해3.3V 생성. 이전 #1 분기안 대체. 계산용235mA·연속 설계300mA·500mA급 이상 후보는 [전원 예산](17_Expansion_Power_Budget_2026-10-23_ko.md) 참고. 기존 엔코더 소비·#2 전체 여유·부품/방열/전원 영역 수는 미정. 기존 보드3.3V 출력과 직결하지 않음 |
| 전원 여유 | 센서·CAN의 정상/송신/기동 부하와 부품 최대값을 계산. 정지 상태5.02V 관측을 새 부하 수용 능력으로 대신하지 않음 |
| 모터 전원 차단 | K1이 꺼져도 로직·상태 관측은 유지 가능한 기존 전원 구성을 보존. 전단/후단 측정값의 차이를 기록 가능하게 함 |
| STM 전원 OFF, 전압 입력 ON | 배터리 감지 입력0~16V가 연결된 상태에서도 MCU 절대최대/주입 전류 조건을 지키고, 입력 경로를 통해 STM 로직 전원이 비의도적으로 올라가지 않도록 설계 |
| 센서/STM 전원 순서 차이 | 센서 ON/STM OFF와 센서 OFF/STM ON의 출력 전압·누설·유효성 검토. 무전원 센서 값을 정상값으로 사용하지 않음 |
| 신호 이상 | NTC 단선·단락, 전류센서 전원/출력선 단절, ADC 입력의 GND 단락을 검토하고 검출 가능한 범위를 명시. 정상값과 전기적으로 구분 불가능한 단절은 한계로 남기거나 별도 진단 추가 |
| USB 개발 전원 | 기존 절차대로 전원을 끄고 전환. NUCLEO/ESP의 USB5V·buck5V·XL4015 #2 AUX5V를 새 PCB가 임의로 연결하지 않음 |
| 외부 포트 | CAN·센서 케이블의 ESD/오접속을 고려. 보호 소자·누설·허용 전압·전류를 회로 계산으로 대조 |
| 보호 내성의 수치 | 전압 감지선 역극성·과도 입력, 신호선에5V/배터리 전압 오접속, CAN 버스 단락의 보장 범위는 미정. 미정 상태를 내성 확보로 간주하지 않고 회로 확정 전에 정격·시험 조건을 정함 |

전원 설계에는 기존 주전류 보호 구조의 교체를 포함하지 않는다. 과전류·온도 자동 정지 임계값도 이 보드의 측정 범위에서 유도하지 않는다.

근거: [기존 전원 분배·전환 계약](11_XL4015_1_Dual_Board_Power_Distribution_Plan_2026-09-08_ko.md), [전원·안전 아키텍처](../01_System_Architecture/12_Power_Distribution_and_Safety_Architecture_ko.md), [ST UM1724 전원 공급 절](https://www.st.com/resource/en/user_manual/um1724-stm32-nucleo64-boards-mb1136-stmicroelectronics.pdf). 추가3.3V 부하의 가용 전류와 MCU 무전원 입력 한계는 다음 구성/회로 단계에서 보드 회로와 MCU 원문으로 대조한다.

## 제작과 조립 조건 제안

| 항목 | 요구조건 초안 |
| --- | --- |
| 기판 구조 | 2층 PCB를 우선 후보로 검토. 전체 기능·접지·배선의 수용성을 확인한 뒤 확정 |
| 조립 방법 | 인두로 조립·교체 가능한 부품과 접근 공간을 우선. 보유 리드형 저항·구매한100nF 커패시터 활용 검토. SMD가 필요하면 패키지와 패드 접근성을 먼저 검토 |
| 기계 결합 | NUCLEO 상면에 꽂는 쉴드 방식 우선. 기존 만능기판 납땜 부품·IMU 위치·축 방향 유지 |
| 크기·높이 | 전체 기능·커넥터·배선·실제 소켓 높이·아래 부품과의 간섭으로 결정. 기존 CAD 템플릿 외곽이나 과거150×100mm 예산을 확정 크기로 사용하지 않음 |
| 지지·탈착 | 커넥터 탈착·케이블 당김에서 헤더/기판에 무리한 힘이 걸리지 않게 지지. 기존 배선을 탈거하지 않고 새 PCB 점검/분리가 가능한 방향으로 검토 |
| 점검 접근 | RESET/USER·ST-LINK/USB·전원 점퍼·IMU/엔코더/UART 점검점을 접근 가능하게 유지. ESP32 안테나 주변 금속·기판 간섭도 검토 |
| 커넥터 | 기능·극성·핀1을 식별하고 케이블을 교체 가능하게 구성. 2단계에서 기능/핀 순서·오접속 방지 조건, 3단계에서 전기 정격/실제 품번, 5단계에서 실물/풋프린트 대조 |
| CAN 모듈 | 보유 MCU-230을 탈착 가능한 방식으로 활용하는 안 우선 검토. 실물 치수/내장 회로 대조 전 풋프린트 확정 금지 |
| LiDAR | 모델 미정 상태의 전용 전원 회로·인터페이스 부품 대신 연결 조건과 하네스 통로를 관리. 선택 뒤 새 PCB 포함 여부 결정 |
| 비용 | 보유품 중복 구매 제외. 제작·부품·배송비 상한과 주문 수량은 미정이며 부품 선정/발주 전에 확인 |

장착에 필요한 실물 확인은 소켓 방향·핀 접근·상면 높이·지지점·모듈/커넥터 치수다. 노트북 작업에서는 모델과 제조사 도면을 대조하고, 확인되지 않은 높이·외곽은 후보로 유지한다.

## 요구사항에서 남은 조건과 결정 단계

| 미정 조건 | 정할 내용 | 설계에 미치는 영향 |
| --- | --- | --- |
| 전류 측정 성능 | 위 목표 검토, ±10~30A 구간 오차·온도 범위 확대·보정 조건 | 필터, ADC 수집 조건, 보정·오차 예산 |
| 온도 측정 성능 | 위 입력계 목표 검토, 센서 부착 조건·전체 오차 평가 방법 | 분압값, 환산과 고장 판정, 시험 조건 |
| 전압 측정 성능 | 위 목표 검토, 과도 입력·저항/기준 전압 온도 특성 | 분압비, 입력 보호, 저항 정격·오차 예산 |
| CAN 조건 | 초기 환경안 검토, 보유 모듈·접지 경로·절연 필요성 | 2단계 전원/인터페이스 계약 전 대조. 절연 결정 전 관련 부품 확정 보류 |
| 전원 이상 조건 | 추가 부하 예산·허용 오접속/과도 입력·무전원 보호의 수치 | 2단계 공급 구조, 3단계 보호 회로 확정 전에 정함 |
| 크기와 제작 | 전체 기능 수용 면적·실물 높이·지지점·층수·예산 | 2단계 기구 경계, 3단계 부품, 5단계 실물/풋프린트, 발주 전 비용 확인 |

센서 데이터시트의 한계·분해능은 완성된 측정계의 요구 성능이나 정확도를 대신하지 않는다. 현재 CAD의 저항값·필터값·헤더 외곽을 요구조건으로 역산하지 않는다.

## 2단계 후속 종합 검토

[ADC6채널 연결·측정 기준과2단계 종합 검토본](20_Analog_6Ch_Contract_and_Stage2_Review_2026-10-23_ko.md)에 구성/포트의 최신 판정을 모았다. 전체 설계 승인이나 CAD 완성은 아니며 다음3단계는 ADC 기준·NTC 여기·무전원 보호 방식 비교/계산부터 진행한다.

## 현재 검토 상태와 다음 항목

1단계 산출물은 기능·측정 성능·CAN 환경·전원 이상·제작 조건을 포함한1차 검토본이다. 사용자의 다음 단계 진행 요청에 따라 [2단계 전체 구성·인터페이스 초안](16_Expansion_PCB_System_Blocks_and_Interfaces_2026-10-23_ko.md)을 작성했다. 여기의 수치와 CAN/전원/제작 조건은 설계 제안이며 사용자에 의한 개별 수치 확정이나 실물 검증으로 확대하지 않는다. 보호 내성·가용 전류·실물 높이 등 미정 조건의 결정 시점을 지키며 회로도/PCB 작업으로 건너뛰지 않는다.
