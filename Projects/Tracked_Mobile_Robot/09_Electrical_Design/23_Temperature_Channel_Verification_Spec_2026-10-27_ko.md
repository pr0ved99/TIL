# 온도 측정 채널 검증 명세

기준일: 2026-10-27 · 시험 설계 기준 v0.1 · 전류 다음에 왼쪽/오른쪽 각각 확인.

## 1. 이번에 정한 결과

온도 입력계는 **NTC 대신 알려진 저항을 연결하여 0~100°C에 대응하는 환산값을 확인**한다. 허용 오차는 기존 제안의 **±1.0°C**, 비교 기준의 오차 경계 목표는 **0.25°C 이하**다. 실제 NTC를 모터에 붙인 측정과는 시험 범위가 다르다.

이번에 채택한 시험용 환산 기준은 **SEMITEC 제조사 저항–온도 표와 log(R) 보간**이다. B=3435K 단일 공식은 비교 계산에만 사용한다. 실제 표의0°C 저항을 B 공식에 넣으면약0.776°C가 나오므로, ±1°C 예산 대부분을 모델 근사에서 소비할 수 있기 때문이다.

| 결정 | 이번 기준 | 의미 |
| --- | --- | --- |
| 측정 목적 | 좌우 모터 케이스 온도·상승 추세 | 내부 권선 온도/자동 정지 기준이 아님 |
| 전기 입력계 범위 | 제조사0~100°C 명목 저항에 대응 | 모터를100°C까지 가열하는 시험이 아님 |
| 입력계 허용치 | 각1초 처리 결과±1.0°C | 분압·RC·ADC·환산을 포함, 센서/접촉 오차 제외 |
| 기준 경계 | G_T≤0.25°C 계획 | 정밀 저항의 오차를 °C로 바꾸고 배선/변동까지 포함 |
| 첫 환경 | 회로/저항/계기 주위23±2°C | 모사 온도와 실제 주변 온도를 구분 |
| 첫 수집 | 14MHz/480cycles·100Hz,100개 비중첩 평균·1Hz 출력 | 시험 설정이며 MCU 구현 전 |
| 첫 회로 | R3/R5=10kΩ, R4/R6=1kΩ, C3/C4=100nF | 현재 CAD의 STM_3V3 여기 조건을 검증 |
| 전체 온도 정확도 | 이번에는 수치 보증을 설정하지 않고 비교 관측 | GM1312·프로브·접촉 오차를 포함한 별도 평가 |

기준값·절차 작성은 완료했으나 실물 시험은 **NOT_RUN**, 기준 저항/배선/펌웨어 준비는 **NOT_READY**다. 10kΩ/1kΩ 보유품의 허용오차와 GM1312/NTC 수령은 확인 전이다.

## 2. 회로와 저항 대입 위치

| 채널 | 센서 대신 저항 연결 | 분압/직렬/필터 | ADC 관측점 | STM |
| --- | --- | --- | --- | --- |
| 왼쪽 | J5-1 ↔ J5-2 GND | R3 / R4 / C3 | TP5 / T_LEFT_ADC | J1-35 → PC2 / ADC1_IN12 |
| 오른쪽 | J6-1 ↔ J6-2 GND | R5 / R6 / C4 | TP6 / T_RIGHT_ADC | J1-37 → PC3 / ADC1_IN13 |

```text
STM_3V3 → R3 10kΩ → J5-1 ── R4 1kΩ ── PC2 / TP5
                      │                   │
                 시험 저항 R_TEST       C3 100nF
                      │                   │
                J5-2 / 신호 GND ──────────┘
```

저항은 NTC를 분리한 센서 커넥터에 연결한다. ADC 핀에 저항을 직접 연결하여 R3/R4를 우회하지 않는다. 저항값 확인은 전원을 끄고 회로에서 분리한 상태에서 한다. 실제 단자 위치/번호는 [netlist](KiCAD/TMR_Monitor_Shield_RevA/reports/netlist.xml)와 조립품을 대조해야 한다.

현재 CAD의 STM_3V3와 MCU VDDA가 완전히 같은 전압이라는 보증은 없다. `g=VEXC/VREF`로 두면 `R=R_FIXED×q/(g−q)`, `q=V_ADC/VREF`다. 첫 모델은 g=1이며 실제 저항 대입 시험이 그 전원 경로를 포함해 확인한다. 정밀하게 g를 별도 측정할 수 없다면1이라고 실측 기록하지 않는다. 별도 EXP 여기 전원으로 바뀌면 이 시험 기준의 전원 조건과 환산을 다시 검토한다.

## 4. 입력계 오차 배분과 부품 판단

±1°C를 다음처럼 배분하여 부품/보정의 검토 기준으로 사용한다. 이는 각각 달성했다고 측정한 값이 아니다. 비교 기준 G_T는 DUT 오차 예산에 섞지 않고 판정 때 별도로 더한다.

| DUT 항목 | 배분 | 확보 방법 |
| --- | ---: | --- |
| 고정 저항값·드리프트 | 0.25°C | 보유품 식별, 값/계수 보정 또는 확인된 정밀도 |
| ADC·입력 누설·수집/잡음의 보정 후 잔차 | 0.55°C | 저항 독립점, 채널/수집률 조건별 비교 |
| 여기/ADC 기준 비율의 변화 | 0.15°C | 같은 전원 계통 유지, 공급 조건 변화에 대한 비교 |
| 환산 구현의 수치 오차 | 0.05°C | 기준 LUT와 독립 계산값 비교 |
| 합계 | **1.00°C** | 절대값 합산 계획, 상쇄를 기대하지 않음 |

제조사 표를 이용한 민감도 계산은 다음과 같다. 각 열은 해당 항만 바꾼 계산이며 실제 합성 오차/실측값이 아니다.

| 모사 온도 | R_FIXED±1% | 입력 누설±1µA | ADC±4LSB 비교 모델 | g±0.1% |
| ---: | ---: | ---: | ---: | ---: |
| 0°C | 0.233°C | 0.303°C | 0.117°C | 0.088°C |
| 25°C | 0.267°C | 0.195°C | 0.105°C | 0.054°C |
| 50°C | 0.311°C | 0.180°C | 0.147°C | 0.044°C |
| 80°C | 0.357°C | 0.216°C | 0.287°C | 0.042°C |
| 100°C | 0.398°C | 0.284°C | 0.485°C | 0.044°C |

누설 모델의 소스 저항은 **1kΩ+(10kΩ∥R_TEST)**다. 1kΩ만 곱하지 않는다. ADC4LSB는 ST18MHz 표의 비교값으로,14MHz에서의 정확도를 보증하지 않는다. 보정 전 TUE와 INL·양자화를 다시 중복 더하지 않는다.

따라서 **10kΩ1%를 명목값 그대로 사용하고 보정 없이 전 범위±1°C라고 주장할 수 없다.** 고온에서 분압 저항0.398°C만으로 배분0.25°C를 넘고 ADC/누설에도 여유가 작다. 먼저 보유품의 값을 확인하고 아래 보정형을 비교한다. 결과가 부족할 때 고정 저항 정밀도·ADC 보정/구동을 개선한다. 10kΩ·1kΩ·100nF라는 명목 회로값 자체를 지금 바꾸거나 일괄 구매하지 않는다.

100°C 점에서 위 네 항을 보수적으로 더한 비교 모델은 약1.21°C로1°C를 넘는다. 실제 동시 오차를 예측한 값은 아니지만, 현재 명목 회로만으로 요구 충족을 보증할 수 없다는 설계 근거다. 특히 ADC/누설 배분0.55°C는 보정 후 독립점에서 검증해야 하며, 부족하면 예산만 느슨하게 바꾸지 말고 회로/환산 변경과 목표의 필요성을 함께 검토한다.

g 변화±0.1%의 명목 계산은 표의 점들에서 약0.088°C 이하다. 이를 전원 비율 변화의 첫 관리 목표로 둔다. 그 변화가 확인되지 않은 공급 조건까지 보정 계수를 확대 적용하지 않는다.

## 5. 환산과 보정 방법

1. 원시 ADC 입력이 유효한지 먼저 확인한다. 유효한100개 샘플의 코드 평균을 q로 바꾸고, g=1 첫 모델에서 `R_est=R_FIXED×q/(1−q)`를 계산한다.
2. 제조사 표의 인접 두 점 `(T_a,R_a),(T_b,R_b)` 사이에서 `T=T_a+(T_b−T_a)×ln(R_est/R_a)/ln(R_b/R_a)`를 사용한다. 제조사 표 밖은 외삽하지 않는다.0~100°C 운용 범위 밖은 별도 OUT_OF_RANGE다.
3. **무보정형**에서는 R_FIXED=10000Ω으로 모든13점을 검사하여 기준선을 남긴다.
4. **보정형**에서는 기준10kΩ 부근 저항의 실제 `R_cal`과 평균 `q_cal`로 `R_FIXED_eff=R_cal×(1−q_cal)/q_cal`을 구한다. 이 유효 계수를 고정하고 나머지12점을 독립 검증한다.25°C 보정점 재확인은 드리프트 확인으로만 센다.
5. 유효 계수는 실제 저항을 정밀 측정한 결과와 다르다. 한 점에서의 ADC 오프셋/기준 비율 영향도 흡수할 수 있어 다른 온도·전원에서 맞는다는 보증이 없다. 잘 맞지 않으면 원인을 분리하고 보정 모델 개정을 별도 버전으로 기록한다.

정밀 계기로 R_FIXED를 직접 확인한 값을 사용하는 대안도 가능하다. 그 경우 계기 경계를 기록하고 유효 계수 보정과 중복 적용하지 않는다. 전류 채널 보정 계수를 PC2/PC3에 그대로 복사하지 않는다.

0.05°C 수치 오차 배분은 **정의한 LUT 모델을 프로그램이 얼마나 정확히 계산하는지**의 기준이다. 성긴 제조사 표 사이에서 실제 센서 곡선이 얼마나 다른지는 센서 포함 평가 항목이다. 계산 코드의 통과를 실제 NTC 정확도로 확대하지 않는다.

## 6. 장비와 기준 저항의 적합성

0.1% 저항을 기준으로 사용할 때, 그 저항 오차만의 온도 상당 경계는 표의0~100°C 점에서 최대약0.0401°C다. 여기에 온도계수·접점·값의 신뢰성·기준 모델 계산을 넣어 G_T≤0.25°C인지 판단한다. **0.1% 표시만 보고 추가 항을0으로 놓지 않는다.**

UT210E 저항 모드의 원문 사양은 해당 범위에서±(1%+2digits)다. 예를 들어10kΩ/20kΩ 범위는±120Ω,975.3Ω/2kΩ 범위는약±11.753Ω이어서 명목 저항을 정밀하게 인증하는 기준기로 자동 채택할 수 없다. 이 경계를 비선형 R-T 환산에 넣어 적합성을 판정해야 한다. XL830L도 실제 판본/범위 사양 확인 전 정밀 기준으로 쓰지 않는다.

| 준비물 | 결정 |
| --- | --- |
| 값/허용오차/TCR가 확인된 기준 저항 또는 저항 조합 | MON-L05 정량 판정에 필요. 보유품 확인 후 부족한 조건만 확보 |
| DMM | 배선·공급 확인용. 사양이 충분할 때만 기준 저항 측정에 활용 |
| GM1312와실제 제공 프로브 | 센서 부착 후 비교 관측용. 저항 대입 시험에는 필수 아님 |
| 오실로스코프 | 입력 정착·잡음 파형을 정량 평가할 때 사용. 정적 저항 대입의 필수 준비물은 아님 |
| 고정밀 온도 챔버/교정기 | 현재 입력계 시험에는 요구하지 않음 |

저항 대입은 전기적으로100°C를 모사하므로 실제 고온 환경을 만들 필요가 없다. 필요한 기준 저항은 부품 식별이 남아 있으며 이번 문서로 구매하지 않았다.

## 7. MON-L05 시험 순서와 판정

1. NTC를 분리한 시험 구성을 무전원에서 확인하고 기준 저항을 연결한다. R3/R4/C3와 STM 전원·ADC 기준 경로를 포함한 실제 배선을 기록한다. 출력 동작은 비활성 상태로 둔다.
2. 우선25·50·80°C 상당 저항으로 감소하는 전압/증가하는 온도의 방향, 채널 식별, 원시값 기록을 확인한다. 이3점 기능 확인으로 전체 정확도 PASS를 쓰지 않는다.
3. 무보정형13점과 보정형12독립점을 구분한다. 입력 변경 후2초 이상 기다리고 기준 상태가 안정됐는지 확인한다. 이후10초씩1Hz 처리값과100Hz 원시값을 기록한다.
4. 상승·하강·임의 순서로3회 수행한다. 계수는 회차 간 고정한다. 같은 방식으로 오른쪽을 별도 확인한다.
5. 기준 저항의 `R_ref±G_R` 양끝을 R-T 함수에 넣어 `G_T,R=max(abs(T(R_ref±G_R)−T(R_ref)))`를 구한다. 접속/변동의 온도 상당 경계를 더하여 최종 G_T를 기록한다.
6. `d_T=T_DUT−T(R_ref)`에 대해 `abs(d_T)+G_T≤1.0°C`면 PASS, `abs(d_T)−G_T>1.0°C`면 FAIL, 나머지는 INCONCLUSIVE다. 각1초 출력에 적용하고 평균/산포도 보존한다.

G_T=0.25°C인 경우 관측 차이의 PASS 여유는0.75°C다. 코드값이나 시험 저항값이 없으면 온도계 화면 숫자만으로 판정하지 않는다.1Hz 정상 기록 구간은 최대 생성 간격1010ms 이하·누락0을 v0.1 실행 기준으로 둔다.10ms는 원시 수집 한 틱의 계획 여유다.

응답 시험 MON-L04-T는25↔50°C 상당 저항 전환을 양방향5회 수행하는 별도 회차다. 입력 안정 시각부터2초 안에 새값의 허용대에 들어가고 이후2초간 유지해야 한다. 저항 스위치의 바운스와 안정 시각/MCU 시계 대응을 확인하지 못하면 수치 시간 PASS는 보류한다. 이것은 NTC의 실제 열응답2초를 보장하는 시험이 아니다.

## 8. 센서 포함 온도 비교와 포함하지 않는 주장

NTC를 실제 표면에 부착한 뒤에는 **같은 표면의 대응 위치·같은 안정 시간대**에서 GM1312와 비교한다. 주위 온도·센서별 고정재·접촉 면적·프로브 종류·관측 시간·위치 사진을 함께 남긴다. 두 프로브의 위치를 바꾼 비교는 위치 구배와 채널/프로브 편차를 구분하는 데 도움이 된다.

GM1312 본체 표기는±0.1%+0.6°C이고, 설명서 동봉 K형 프로브는2.5°C 또는0.75% 표기를 가진다. 본체 분해능0.1°C가 전체 정확도0.1°C라는 뜻은 아니다. 실제 제공된 프로브·접촉 조건까지 포함하면 현재 구성으로 **실제 모터 케이스 온도±1°C**를 증명할 수 없다.

NTC 자체 R25/B 편차, 보간 모델의 실제 곡선 차이, 자가발열, 접착/접촉·열지연도 추가된다. 명목25°C에서 분압 전력0.272mW와 정지 공기 중 방열계수로 얻는 자가발열 추정은약0.389°C이며 실제 부착 상태의 보정 상수로 사용하지 않는다.

따라서 이번 전체 온도 비교의 결과는 `CHARACTERIZATION`으로 남긴다. 실제 차이와 산포·반응 방향을 보고하고, 전체 정확도 수치 PASS를 새로 만들어 넣지 않는다. 모터의 허용 케이스 온도가 확보되지 않았으므로 고온까지 운전/가열하거나 과거 철회한40/45°C 중단값을 복원하지 않는다.

## 8-1. NTC 자체 정확도와 부착 후 정확도의 구분

10/28 마감 보충. NTC 자체는 **안정되고 온도가 균일한 시험 환경에서, 기준 온도 T_ref와 NTC 저항 R_meas**를 비교한다. 분압/ADC 대신 적합한 저항계로 읽어 입력계 영향을 분리하며, 측정 전류에 의한 자가발열도 확인한다. 센서/기준 프로브에 적합한 치구·매질과 절연 조건이 확정되기 전 임의 침수/가열 시험을 지시하지 않는다.

제조사 RT 표의 R_nom(T_ref)와 저항 잔차를 비교하거나, 이번 RT/log 보간으로 얻은 `T(R_meas) - T_ref`를 온도 잔차로 기록한다. 25°C의10kΩ 및 R25 허용차는 해당 조건의 사양이며 전 온도 범위 정확도를 뜻하지 않는다. 여러 온도점에서 열평형·위치 구배·기준 온도계/저항계의 경계를 포함하고, 보정을 적용했다면 별도 독립점으로 확인한다.

NTC를 모터에 붙인 뒤의 MCU 표시 비교는 센서·입력계에 접촉/위치/열지연까지 포함하는 전체 시험이다. 현재 GM1312와 동봉 프로브 조합만으로 실제 표면 ±1°C를 입증하지 않는다. **센서 단독의 다점 온도·치구·기준 경계와 합격 기준은 미확정, 실제 시험 NOT_RUN**이다. 이번 보충은 방법의 구분이며 기존 8절의 CHARACTERIZATION을 정확도 PASS로 바꾸지 않는다.

## 9. 이상값과 데이터 유효성 시험

정상0~100°C 명목 q는약0.0889~0.7347다. 첫 **진단 시험용** rail 기준은 `q≤0.02` 또는 `q≥0.95`를3회 연속100Hz 원시값에서 관측하는 것으로 둔다. 두 한계는 정상 범위에서 떨어뜨린 실무 선택이며 제조사 고장 진단 규칙이 아니다. 실제 부품/전원/ADC 오차를 넣어 여유를 다시 확인한 뒤 펌웨어에 반영한다.

| 입력/상태 | 기대하는 처리와 제한 |
| --- | --- |
| NTC 커넥터 단선 | 높은 rail 후보. R3 연결·여기 전원 정상 조건에서 확인 |
| 센서 단자 간 단락 | 낮은 rail 후보. 수동 분압의 제한 전류 조건 확인 후 별도 시험 |
| 표 범위/운용 범위 밖 | OUT_OF_RANGE,0°C/100°C로 잘라 정상값처럼 숨기지 않음 |
| 중간값 누설·케이스에서 이탈 | 이 회로만으로 구분을 보장하지 못함 |
| 초기 정착·갱신 중단 | NOT_READY/STALE; 마지막 정상값과 현재 측정을 구분 |

진단은 평균 전에 수행하고 유효 샘플만으로 완전한 새 블록을 만들었을 때 정상 처리로 복귀한다. rail 이름을 곧바로 특정 선의 단선/단락 확정으로 해석하지 않는다. 단선 시험에 쓰는 교체/스위치 연결은 조립 확인 후 정한다. 임의의 외부 고전압이나 MCU 무전원 상태의 입력 주입은 이 시험에 포함하지 않는다.

모니터링 데이터의 첫 PC 검증 기준은 전류500ms·온도3000ms 이상 새 유효 결과가 없으면 STALE로 둔다. 값의 나이는 같은 MCU 실행/시계의 마지막 유효 `sample_end`를 기준으로 하고 재부팅/순번 역전은 분리한다.500/3000ms는100ms/1초 주기의 모니터링 표시용 계획이며 기존 브라우저 TEL250ms·control200ms·STM 명령300ms 제한을 변경하지 않는다. 모니터링 복구가 ARM/자동 재주행을 유발해서는 안 된다.

## 10. 기록과 설계 완료 조건

회차별 기준 저항값/사양/조합, G_R/G_T, R_FIXED 또는R_FIXED_eff, g 가정/측정 근거, 원시 코드·평균 구간/출력 시각, 환산 모델 버전, 기준 온도·DUT 온도·잔차, 판정, 좌우 채널, 공급/주위 조건을 기록한다. 공통 필드는 [전류 명세22](22_Current_Channel_Verification_Spec_2026-10-27_ko.md)의 회차 양식과 맞춘다.

입력계 통과 뒤 실제 NTC 비교로 진행한다. 저항 대입에서 실패하면 NTC 교체에 앞서 기준 저항/환산식·g·R_FIXED·ADC 잔차를 확인한다. 센서 부착 후에만 차이가 커지면 센서/프로브와 접촉·위치·열평형을 분리한다. 한 채널 PASS를 다른 채널이나 실제 표면 정확도로 복사하지 않는다.

이번 문서 작업의 완료 조건은 시험점·오차 배분·기준 장비 성능·보정/독립점·판정·기록 방법을 정하는 것이다. 실제 검증 완료 조건은 MON-L05와별도 비교 회차의 측정 근거다. 현재 MON-L01~08 실물 결과를 변경하지 않는다.

전류/온도 명세 작성 다음에는 **NTC 여기 전원과 ADC 기준·무전원 입력 보호의 남은 설계 결정을 정리하고, 전압2채널의 분압/보호 설계로 연결**한다. 정밀 장비 확보를 기다리며 학습 노트를 처음부터 반복하지 않는다.
