# 확장 PCB 전원 부하와 3.3V 생성 사양

기준일: 2026-10-23. 설계2단계 전원 예산 계산안이다. **XL4015 #2 AUX5V → 별도 분기 → 3.3V 레귤레이터 → 센서·CAN 회로**를 검토한다. 실제 배선·출력 설정·CAD/BOM은 변경하지 않았다.

## 저항으로 전원을 낮추기 어려운 이유

직렬 저항은 `VOUT = VIN − ILOAD × R`이다. 5V에서100mA일 때3.3V가 되도록17Ω을 넣으면 다음처럼 부하에 따라 출력이 바뀐다.

| 부하 전류 | 출력 전압 |
| ---: | ---: |
| 0mA | 5.00V |
| 10mA | 4.83V |
| 100mA | 3.30V |
| 150mA | 2.45V |

이 예는 저항 선정안이 아니다. 전류센서#5241의 동작 전원3.0~3.6V를 유지할 수 없음을 설명한다. 두 저항 분압도 부하와 병렬로 연결되어 출력이 달라진다. 저항 분압은 전압을 관측하는 ADC 입력에 사용하고, 부하 전원에는 출력 전압을 조절하는 레귤레이터를 사용한다.

전압 감지 주분압 전류는 K1 전단/후단의 배터리 감지 분기에서 공급되므로 3.3V 레일에 중복 가산하지 않는다. 분압 저항의 전류·발열은3단계에서 별도 계산한다. STM32·ESP32·기존 IMU의 전원은 기존 #1/보드 경로에 남으므로 신규3.3V 부하에 다시 더하지 않는다.

### CAN 전류를 17mA씩만 더하지 않은 이유

TI SN65HVD230 RevO §8.5의 최대17mA는 **무부하** 공급전류다. 종단된 버스의 송신 전류가 추가된다. 정상 버스의120Ω±1% 두 개를 병렬로 보면 최소59.4Ω이며, 공급 상한3.6V를 사용한 단순 검토는 다음과 같다.

`17mA + 3.6V / 59.4Ω ≈ 77.6mA / 노드`

이 값도 제조사 보증 최대값이 아니라 부하 전류와 무부하 전류를 합친 크기 검토다. 두 노드를 각각100mA로 잡아 정상 통신에 보수적으로 공간을 두었다. 실제 동시 송신·우선순위 중재·종단 부하는 공통 버스에서 연결되므로 각 노드 예산 합이 평소 실측값이라는 뜻은 아니다. 모듈 LED·I/O 부하·기동·ESP 부품 선택 후 다시 대조한다.

버스 단락·잘못된 종단·보호 소자 동작 등 고장 전류는 이 정상 부하 예산에 포함하지 않았다. 전류 제한과 E-stop 감지 전원 영향은 별도 검토한다.

### LDO 발열 계산

LDO의 손실은 대략 `PLOSS = (VIN − VOUT) × IOUT + VIN × IGND`다.

| 조건 | 전압 강하에 의한 손실, IGND 제외 |
| --- | ---: |
| 5.00V → 3.30V, 예산235mA | 약0.400W |
| 5.00V → 3.30V, 설계300mA | **0.510W** |
| 5.25V → 3.30V, 설계300mA | **0.585W** |

IGND 예산1mA를 가정하면 마지막 조건은약0.590W다. 출력 허용오차까지 포함한 최종 최대값·기동/단락 손실은 부품 선정 후 계산한다. 단순 효율은3.3/5≈66%다.

0.585W에서 열저항100°C/W라면 접합 온도 상승은약58.5°C, 200°C/W라면약117°C다. 열저항은 패키지·구리 면적·층수·방열 경로에 따라 달라진다. 따라서 작은 패키지의500mA 표기만 보고 선택하지 않는다. TI TLV755P 자료는 LDO 손실과 PCB별 열저항 차이를 확인한 **방법론 참고**이며 해당 부품을 구매/채택한 것이 아니다.

## 기존 XL4015 #2 부하와 합산

#2는 기존 엔코더2개와 S0-B optocoupler 감지 입력을 공급한다. 릴레이 코일은 별도의 배터리/F2 제어 경로다. 새 분기는 **#2 출력에서 병렬로** 가져오며 S0 접점·LED 감지 루프 뒤에서 전원을 빼지 않는다. #1과#2 OUT+는 합치지 않는다.

| 기존/추가 부하 | 현재 수치 |
| --- | --- |
| 엔코더2개 | 전원3.3~5V는 확인. 소비전류는 보유 제조사 회신에 없어 미정 |
| S0-B 감지 | 임시10mA 예산. 기존 선택 저항670.1Ω에서5.25V/670.1Ω≈7.83mA는 LED/접점 강하를 무시한 계산이며 실측 전류 아님 |
| 새 LDO 입력 | 설계 부하300mA + IGND 예산1mA = 301mA |

따라서 LDO 방식의 현재 합산식은 다음과 같다.

`I_XL4015#2 ≥ I_ENC_L + I_ENC_R + 311mA`

**신규3.3V의 설계 부하 목표는 산정했지만, #2 전체 전원 여유는 아직 미확정**이다. 엔코더 소비전류, 모듈의 실제 CC 설정·방열·부하 전압/과도 응답과 분기선/커넥터가 남아 있다. 판매 표기5A나 기존 무부하/전압 관측을 전체 수용 능력으로 간주하지 않는다. 추가 부하 정상/고장 시 기존 S0-B 감지 기능의 영향을 대조한다.

## 공급 구조 후속 검토

[3.3V 공급·조립 검토](18_Expansion_3V3_Supply_Structure_and_Assembly_2026-10-23_ko.md)에서 단일 LDO와 TO-220급을 우선 제안했다. 후보 출력 오차를 넣은 손실 사례는0.615W이며 위0.590W의 명목 출력 사례와 구분한다. 최종 부품·실제 열저항·전원 OFF 보호는 미확정이다. 다음은 ESP GPIO/커넥터 계약이다.

## 다음 작업과 경계

현재는2단계 계산안이다. 후속 공급 구조 검토에서 단일 LDO/TO-220급을 우선 제안했고 무전원·USB·NTC 기준 전압의 미결 조건을 기록했다. 다음은 **ESP CAN GPIO·전원/GND·커넥터 계약**이다. 하나/복수 레귤레이터의 최종 선택과 품번·보호/기준 전압 회로는 그 계약을 바탕으로3단계에서 결정한다.

보유품 추가 정보가 필요한 엔코더 소비전류·MCU-230 부속과 최종 부하 실측은 집에서 확인할 항목으로 남긴다. 지금 추가 통전이나 MCU 빌드/플래시를 요구하지 않는다.
