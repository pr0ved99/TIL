# 전류 측정 채널 검증 명세

기준일: 2026-10-27 · 시험 설계 기준 v0.1 · 연결 대상: 왼쪽 먼저, 오른쪽 독립 반복.

## 1. 이번에 정한 결과와 적용 범위

전류 입력 회로의 **보정 후 DC 잔차 목표를 ±4.4mV**, 비교 기준의 오차 경계 목표를 **1.1mV 이하**로 정한다. 전체 전류는 기존 제안 `±max(0.20A, 읽음값 절댓값의 5%)`를 이번 시험 설계 기준으로 사용한다. 센서 제외 시험과 센서 포함 시험을 각각 판정한다.

4.4mV는 제조사 보증값에서 바로 나온 값이 아니다. 저전류 전체 예산 0.20A 중 입력계에 0.10A, 센서의 보정 후 잔차에 0.10A를 배정하는 **설계 배분**이다. `0.10A × 44mV/A = 4.4mV`다. 센서에 남긴 예산의 달성 여부는 실제 보정·독립점으로 확인해야 한다. 고전류에서 전체 허용치가 커져도 입력계 기준은 우선 4.4mV로 유지한다.

이 명세는 학습 설명을 실제 시험 조건으로 바꾼 결과다. 기존 2mV 예시는 채택하지 않는다. 요구사항15의 제안값을 제조사 정격이나 로봇 안전 임계값으로 바꾸지 않으며, 실물 검증 상태는 모두 **NOT_RUN**이다. 전류 측정 펌웨어와 시험 입력원·조립품은 아직 준비 확인 전이다.

| 결정 | 이번 기준 | 근거와 남는 제한 |
| --- | --- | --- |
| 측정 목적 | 모터별 DC 및 필터된 부하 추세 | 피크·RMS·고속 과전류 차단과 구분 |
| 우선 정확도 범위 | −10~+10A, 주위20~30°C라는 기존 목표 유지 | 첫 실물 회차는 아래의 제한된 범위만 확인 |
| 첫 입력계 시험 | 1.21~2.09V 대입, 12kΩ/100nF 포함 | 모터에 ±10A를 흘리는 시험이 아님 |
| 첫 센서 포함 시험 | 검토된 DC 시험 부하로 −1.8~+1.8A | 실제 시험원·전력 경로가 준비되어야 실행 가능 |
| 첫 환경 | 주위23±2°C, 계기 RH≤75% 조건 준수 | 전체20~30°C의 보증은 후속 조건별 확인 필요 |
| 첫 수집 조건 | ADC14MHz/480cycles, 채널별100Hz, 10개 평균/100ms | 시험 설정 기준이며 펌웨어에 적용하지 않았음 |
| 부품 판단 | 12kΩ/100nF는 첫 비교 대상 유지 | 정확도 보증·제작값 확정은 보류 |

## 2. 현재 CAD와 시험 시작점

저장된 [netlist](KiCAD/TMR_Monitor_Shield_RevA/reports/netlist.xml)의 연결을 기준으로 했다. 해당 단자가 완성 실물에 존재한다는 뜻은 아니다. 실물 배선은 조립 시 대조한다.

| 채널 | 시험 전압 입력, R 앞 | R/C | ADC 관측점, R 뒤 | STM |
| --- | --- | --- | --- | --- |
| 왼쪽 | J3-3 / I_LEFT_RAW | R1 12kΩ / C1 100nF | TP3 / I_LEFT_ADC | J1-38 → PC0 / ADC1_IN10 |
| 오른쪽 | J4-3 / I_RIGHT_RAW | R2 12kΩ / C2 100nF | TP4 / I_RIGHT_ADC | J1-36 → PC1 / ADC1_IN11 |

신호 귀환은 해당 J3/J4-2 또는 TP2 GND다. J3/J4-1은 센서 전원이며 시험 전압 입력이 아니다. 현재 CAD에서는 J1-16의 STM_3V3가 센서 전원에도 연결된다. 별도 EXP 공급안은 아직 CAD에 없다.

```text
입력계: 검토된 DC 입력원 → J3-3 → R1 → PC0 → ADC 코드 → 보정 전압
                                      └ C1 → 신호 GND
전체계: 검토된 DC 전류 → #5241 → 위 입력계 → 영점/감도 보정 → A
```

기준 전압은 **R 앞의 실제 입력점**에서 읽는다. R 뒤 TP3에만 전압을 넣으면 R1의 영향을 검증하지 못한다. 기준 전압원을 센서 VIOUT와 병렬로 연결하지 않도록 센서 출력을 분리한 시험 구성이 필요하다.

**프로브 부하도 회로를 바꾼다.** 10MΩ 전압계를 R 뒤에 연결하면 12kΩ과 분압하여 1.65V에서 약1.978mV 내려가는 이상 모델이 된다. 4.4mV 목표에 비해 무시할 수 없다. 기본 정확도 판정 중에는 R 뒤 프로브를 제거하고, R 앞 기준값과 ADC 값을 비교한다. R 뒤 파형/전압 측정은 프로브 저항·용량을 기록한 별도 진단으로 둔다.

## 3. 오차 예산과 지금의 판단

| 항목 | 계산 또는 사양 | 설계 판단 |
| --- | --- | --- |
| 저전류 전체 오차 | 0.20A × 44mV/A = 8.8mV | 전체 예산이며 항목마다8.8mV를 허용하지 않음 |
| 입력계 배분 | 0.10A 상당 = 4.4mV | R/C·ADC·전압 기준/환산·처리 잡음의 합산 잔차 목표 |
| 센서 잔여 배분 | 저전류에서0.10A 상당 | 영점/감도 보정 후 잔차·환경 변화에 대한 목표, 충족 미확인 |
| ADC 눈금 | 3.3V/4096 = 0.805664mV | 분해능이며 정확도 아님 |
| ADC 사양 비교 | ST의18MHz 표75 TUE 최대±4LSB →3.223mV | 14MHz/실제 입력 조건의 보증으로 전용하지 않음 |
| R1 누설 민감도 | 12kΩ × 1µA = 12mV =0.273A 상당 | 무보정 최악 모델만으로 목표 충족을 주장할 수 없음 |
| 센서 영점 편차 | 해당KEXBLT-030B3의25~125°C 표에서±15mV | 명목1.65V만 빼는 방식으로 저전류 목표 보증 불가 |

ADC의 TUE·오프셋·이득·INL·양자화를 모두 독립 최대값처럼 더하지 않는다. 보정 전 사양과 보정 후 잔차도 구분한다. 위 센서 영점/감도 개별 극한을 제조사가 제시한 전체 오차와 다시 중복 합산하지 않는다. 저온·수명 조건은 원문 표의 별도 범위다.

12mV는 모든 보드에서 발생하는 실측 오차가 아니다. 일정한 오프셋은 보정으로 줄일 수 있지만, 입력 전압·온도·시간·수집률에 따라 변하면 두 점 보정 후에도 잔차가 남는다. 따라서 현재 결론은 **12kΩ의 무조건 채택을 보류하고, 보정 후 잔차와 조건 의존성을 먼저 비교**하는 것이다. 저항을 바로 줄이면 #5241의 출력 부하 조건도 다시 검토해야 한다. 버퍼 추가 역시 부품·전원·출력 범위 검토 후의 선택이다.

센서 잔여0.10A가 실제로 확보되었다고 가정해 입력계 PASS만으로 전체를 PASS 처리하지 않는다. 전체계 시험은 반드시 별도로 수행한다.

## 4. 장비 성능과 추가 확보 조건

| 용도 | 현재 장비로 가능한 수준 | 이번 결정 |
| --- | --- | --- |
| 배선/전원 대략 확인 | 보유 XL830L, 수령 확인 전 UT210E | XL830L의 정확한 사양/상태 확인 전 mV 판정 기준으로 사용하지 않음 |
| MON-L01 전압 정확도 | UT210E의1.65V/2V 범위 사양 경계는±14.55mV | 4.4mV 판정 기준으로 부적합. 총 비교 경계≤1.1mV인 기준 경로 필요 |
| DC 전류 비교 | UT210E 2A 범위에서1A→±0.028A,1.5A→±0.038A | 안정 DC의 제한 범위 비교에 활용 가능; 영점/위치/시간 차이 추가 |
| 19kHz 파형·리플 | FX2는 디지털 신호 분석기 | 아날로그 크기/필터 감쇠 측정에는 스코프·프로브 필요. 후속 별도 시험 |

UT210E의 2.09V는 20V 범위를 쓰면 분해능10mV와3digits 항 때문에 경계가약44.63mV가 된다. “화면 소수점이 보인다”는 이유로 기준기로 채택하지 않는다. 수령 여부는 기존 기록상 미확인이다.

필요한 것은 특정 고가 계측기 구매가 아니라 **1.21~2.09V에서 기준 전압계·입력 안정성·접속 영향을 합친 경계≤1.1mV인 비교 경로**다. 이1.1mV는 목표4.4mV의1/4을 기준 측정에 사용하는 프로젝트 계획값이며 법정 교정 규칙이 아니다. 적합한 장비 대여/공용 장비도 가능하다. 기존 저전압원과 분압망도 사용할 수 있지만 실제 단자 전압, 출력 임피던스, 안정성을 기록해야 한다. 정확히1.738V를 설정하는 전용 발생기가 필수는 아니다.

현재 해당 정밀 기준 경로는 확보 확인 전이므로 **정량 정확도 실행 준비는 NOT_READY**다. 이것이 기능 확인이나 다른 PCB 설계 작업 전체를 막는 조건은 아니다. 새 장비 주문은 하지 않는다.

## 5. 공통 판정 방법

`d = DUT 처리값 − 같은 입력의 기준값`, `T = 허용 오차`, `G = 비교 기준의 보수적 오차 경계`로 둔다. G에는 계기 사양 또는 교정 근거, 기준 입력의 변동, 접속·관측 시간 차이 등 검증된 경계를 포함한다. 알 수 없는 항을0으로 놓지 않는다.

| 조건 | 판정 |
| --- | --- |
| abs(d)+G ≤ T | PASS |
| abs(d)−G > T | FAIL |
| 그 사이 | INCONCLUSIVE |
| 기준/입력/연결/설정 증거가 준비되지 않음 | NOT_READY, 시험 NOT_RUN |

여기서 G는 포괄계수 k=2를 적용한 교정 불확도라고 부르지 않는다. 독립성/분포 근거 없이 제곱합 제곱근으로 줄이지 않는다. DUT 자체 오차를 기준기 G에 다시 더하지 않는다. 실제 기준기 교정 성적서가 있으면 조건과 포함 항목을 구분하여 대체한다.

입력계의 T=4.4mV, 계획 G≤1.1mV다. G=1.1mV일 때 허용되는 관측 차이는3.3mV 이하가 된다. 전체계에서는 **각 DUT 처리 결과**의 `T=max(0.20A, 0.05×abs(I_DUT))`를 쓴다. 기준 전류를 대입해 허용치를 계산하는 다른 정의로 바꾸지 않는다.

## 6. MON-L01 전압 대입 시험 절차

실행 전에는 완성 배선의 핀/극성, 입력원과 STM의 전원 순서, 정상 ADC 입력 범위, GND, 센서 출력 분리를 확인한다. MCU OFF 상태에서 외부 입력을 계속 인가하는 시험은 이 절에 포함하지 않는다. 모터 출력은 비활성 상태로 둔다. 예상 범위를 벗어난 전압·비정상 발열·리셋·통신 이상이 발생하면 해당 회차를 중단한다.

1. 왼쪽 한 채널로 시작한다. 실제 R/C 값·부품 허용오차, 전원 방식, 보드/회로/펌웨어 버전, 계기 범위와 정확도 조건을 기록한다.
2. 첫 조건은 12bit·14MHz·480cycles·100sample/s다. 10개 원시값을 묶어100ms 결과를 만든다. 기준 전압을3.3V라고 가정해 정확도 기준으로 쓰지 않는다.
3. 초기 준비와 입력 변경 후 **1초 이상** 기다리고, 기준 전압 변동이 G 계획 안에 들어오는지 확인한다. 1초 경과만으로 입력 안정성을 증명한 것으로 취급하지 않는다.
4. 보정점1.21V와2.09V 각각에서10초 원시 코드와 기준 입력값을 수집한다. 실제 기준 측정값을 사용하여 `V_est=a×mean_code+b`의 a,b를 구하고 고정한다. 이는 센서 영점/감도 보정과 별개다.
5. 아래 독립점에서 안정 후10초씩 기록한다. 상승·하강·임의 순서로3회 수행하고 계수를 바꾸지 않는다. 각 회차 약100개의100ms 결과를 개별 판정하며 평균·표준편차·최솟값·최댓값도 남긴다.
6. 보정점은 마지막에 다시 읽어 드리프트만 비교한다. 그 점을 독립 정확도 검증 통과 수에 넣지 않는다.
7. 같은 조건을 오른쪽에 독립 적용한다. 두 채널을 함께 읽는 실제 스캔 조건과 1kHz/100개 평균 조건은 고정 계수로 별도 비교한다. 아직 없는 전압 채널을 구현된6채널 스캔이라고 기록하지 않는다.

| 명목 전류 상당값 | 전압 목표 | 역할 |
| ---: | ---: | --- |
| −10A / +10A | 1.210 / 2.090V | 두 점 보정 |
| −7.5 / −5 / −2 / −1A | 1.320 / 1.430 / 1.562 / 1.606V | 독립 검증 |
| 0A | 1.650V | 독립 검증; 실제 센서의 영점 시험은 아님 |
| +1 / +2 / +5 / +7.5A | 1.694 / 1.738 / 1.870 / 1.980V | 독립 검증 |
| −30 / +30A | 0.330 / 2.970V | 입력 범위·포화 관측만, 같은 정확도 기준 적용 안 함 |

설정값을 정확히 맞추는 것보다 실제 기준 전압을 기록하는 것이 우선이다. 시험점 통과는 그 점/조건의 증거이며 연속 전 범위·모든 온도에 대한 보증이 아니다. 범위 확인점은 현재 전원에서 정상 ADC 입력 범위 안임을 먼저 확인한다.

## 7. MON-L02 센서 포함 안정 DC 시험

로봇 모터 부하를 억지로 만들지 않고, 정격/발열/제한 전류를 검토한 별도 DC 부하와 #5241 전력 경로를 사용한다. 보유 USB 저항 부하를 정전류 부하나1.8A 대응 부하로 간주하지 않는다. 준비된 입력원이 없으면 이 단계는 NOT_READY로 둔다.

- 영점: 센서의 IP 경로에 전류가 흐르지 않는 분리 상태를 확인한다. 단순 모터 정지를0A 기준으로 사용하지 않는다.
- 보정: 독립 영점과 +1.5A 부근의 **실측 기준 전류**로 채널별 `V_zero_cal`, `S_cal`을 구한다. 앞 절의 입력계 보정 뒤에 한 번 적용하며 같은 오프셋을 중복 보정하지 않는다.
- 검증: +0.25,+0.5,+1.0,+1.8A, 그리고 −0.25,−0.5,−1.0,−1.8A 부근을 사용한다. 음의 경로는 무전원 상태에서 검토된 시험 전력 경로의 방향을 바꾸는 별도 회차다. 센서/STM 신호 전원을 뒤집지 않는다.
- 각 점에서 안정 후10초씩3회 기록한다. UT210E는2A DC 범위·ZERO·동일 방향·한 도선 조건을 사용한다.2A 경계에 붙는2.000A를 첫 최대점으로 잡지 않는다.
- UT210E 표시를 대응 시간에 기록하고, 실제 DC 안정도/관측 시간 차이를 G에 넣는다.2~3회/초의 표시를100ms마다의 순간 기준이나19kHz 파형의 정확한 평균 보증으로 쓰지 않는다.

| 기준기 표시 예 | 계기 사양 경계만 | T가0.20A인 DUT 결과에서 남는 관측 차이 여유 |
| ---: | ---: | ---: |
| 0.25A | 0.013A | 0.187A |
| 0.50A | 0.018A | 0.182A |
| 1.00A | 0.028A | 0.172A |
| 1.80A | 0.044A | 0.156A |

마지막 열은 추가 접속/영점/안정도 경계를 빼기 전이다. 예를 들어1.8A에서 기준 전류의 실제 추가 경계를 확보하지 못하면 수치 PASS는 보류한다. ±1.8A 시험 완료를 ±10A 목표 달성으로 확대하지 않는다. 확대 시험은 검토된 부하/배선과20A 범위의 계기 오차를 사용하여 별도로 준비한다.

## 7-1. 센서 자체 정확도를 따로 확인하려면

10/28 마감 보충. 위 7절의 센서 포함 경로 시험과 별개로, **독립 기준 전류 I_ref와 입력 회로 앞 센서 출력 V_out**을 직접 비교해야 센서 단독의 영점·감도·비선형 잔차를 평가할 수 있다. STM ADC 결과만 비교하면 입력계 영향도 함께 들어간다.

1. 검토된 안정 DC 전류 경로에서 실제 전류를 기준기로 측정하고, 센서 출력은 STM 입력계의 부하 영향을 분리한 조건에서 적합한 전압계로 관측한다. 전원·GND·출력 부하 조건을 함께 남긴다. 이는 준비 완료 전의 배선 지시가 아니다.
2. 명목 모델 `V_nom = 1.65V + 0.044V/A × I_ref`와 직접 출력의 차이를 계산한다. 1A에서1.694V는 명목 예상값이지 측정 결과가 아니다. 전류로 환산한 명목 잔차는 `(V_out - 1.65V)/0.044V/A - I_ref`다.
3. 무보정 결과와 보정 후 결과를 나누고, 보정에 쓰지 않은 양·음 전류점에서 반복한다. 기준 전류·출력 전압 계측 경계, 영점/안정도·공급/온도·외부 자계 조건을 포함한다. UT210E의 DC 전류 비교 적합성을 정밀 출력 전압 기준 적합성으로 확대하지 않는다.

명세의 센서 잔여 예산0.10A는 달성해야 할 설계 배분이며 제조사 센서 정확도나 검증 결과가 아니다. 센서 단독의 입력점·조건별 합격 경계·기준기/치구 상세는 후속으로 확정한다. 현재는 **검증 방법의 구분을 문서화한 상태, 센서 단독 시험 NOT_RUN**이다. 서로 다른 조건의 전체 오차나 허용 입력계 오차를 단순 차감하여 센서 오차로 확정하지 않는다.

## 8. 시간·PWM·오류 확인과 판정 이후

| ID | 시험 | 완료 조건 / 범위 |
| --- | --- | --- |
| MON-L01 | 전압 대입 DC | 위 독립점의 각 처리값을4.4mV/G 규칙으로 판정 |
| MON-L02 | 센서 포함 DC | 해당 전류/채널/환경에서 전체 기준 판정 |
| MON-L03 | 100Hz와1kHz·PWM 영향 | 원시값/처리값·계수 고정 비교, 첫 DC PASS와 분리 |
| MON-L04-I | 1.43↔1.87V 입력 응답 | 입력 안정 시각부터300ms 이내 허용대 진입, 이후1초 유지; 양방향5회 |
| MON-L07-I | 누락/오래된 값 | 새 시각/유효성을 보존, 오래된 값을0A나새값으로 표시하지 않음 |
| MON-L08-I | 출력선 단절/전원 조건 | 현재 회로는 중간값의 단절을 정상과 구분 못할 수 있음. 감지 가능 범위만 판정 |

응답시간은 외부 입력이 실제로 안정된 시각과 MCU 결과 시각의 대응이 필요하다. 검증된 입력원 트리거/정착 상한 또는 스코프 기록을 이용한다. FX2는 디지털 마커 대응에 사용할 수 있지만 아날로그 정착 자체의 증거는 아니다. 근거가 없으면 응답 수치 판정은 보류한다.100ms 결과 주기는 중앙값/최대간격/누락을 보고하며, v0.1 실행 기준은 정상 기록 구간 최대 간격110ms 이하·누락0이다.10ms는 수집 한 틱만큼 허용한 계획 여유다.

DC 잔차가 크면 기준 경로→전압 환산/기준 변화→입력 누설/획득 조건 순으로 분리한다. **센서 제외 DC부터 실패하면 센서 교체를 첫 조치로 삼지 않는다.** 입력계는 통과하고 전체계만 실패하면 센서 보정·감도/영점 변화·외부 자계/전류 경로를 확인한다. PWM에서만 문제가 생기면 수집 위상·입력 파형·공통 GND와 필터를 별도 검토한다.

MON-L07의 첫 PC 시험에서는 새 유효 전류 결과가500ms 이상 없으면 STALE로 표시한다. 같은 MCU 실행/시계의 마지막 유효 sample_end를 기준으로 경계 직전/동일/직후·순번 역전·재부팅·복구를 검사한다. 표시용 시험 기준이며 기존 브라우저 TEL250ms·control200ms·STM 명령300ms 제한을 바꾸지 않는다. 공통 유효성 조건은 온도 명세23의9절을 따른다.
