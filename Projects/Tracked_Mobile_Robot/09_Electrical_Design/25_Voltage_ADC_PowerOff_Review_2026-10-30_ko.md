# 전압 ADC 공차·무전원 차단 검토

2026-10-30 마감. 설계 단계는 **회로 계산·보호 후보 검토**다. [학습 노트21](../07_Embedded_Learning_Notes/01_Concept_Notes/21_Voltage_ADC_Tolerance_Isolation_and_Discharge_Lab_ko.md)과 [근거](../assets/logs/pcb_design/2026-10-30_voltage_adc_closeout/README.md)에 사용자 결과·계산·가정을 분리했다.

## 이번에 좁힌 판단

- 12k+12k/4.7k의 ±1% 최악 조합은16V에서 명목 환산 오차 +0.2694/−0.2658V다. 저항만으로도 ±0.10V를 넘을 수 있다. ±0.1%는 약±0.0268V로 줄지만 전체 정확도 달성은 아니다.
- 12.6V에서 알려진 실제 모델 분압비로 환산한12.600V는 보정 원리 확인이다. 실물 보정·독립점 검증과 구분한다. VREFINT 사용도 개념 검토이며 실제 ADC 코드 미취득이다.
- 가정한 ADC 누설1µA가 VADC에 약−4.9303mV, 배터리 환산에 약−30.106mV를 더한다. 누설/보호를 오차 예산에 포함해야 한다.
- 배터리 입력은 MCU 전원과 독립적으로 살아 있을 수 있어, 전원 OFF 전후 조건을 우선 검토한다. 전류/온도 채널도 잔류 전하·전원 순서 검토가 남는다.
- 일반 S1과 R5의 ON/OFF 및 VDDA 연동 방전을 사용자 GUI에서 확인했다. 이는 후보 구조의 동작 설명 근거이며 실제 IC/MCU 보호 성능 판정이 아니다.

## 실제 부품 선정 전 남은 조건

TPS3840PL30/TMUX1511은 후보 비교다. 실제 사용 공급 범위·하강/복귀·기본 제어 상태·온도별 누설·핀 허용 조건을 만족한다고 아직 판정하지 않았다.

- 전원 감시 임계값 오차, 하강 전달 지연의 시험 조건과 느린 하강 적용 가능성.
- 스위치 SEL 전이와 공급 OFF 동작의 구분, 제어 전압 유효성, 부하 RC 및 전하 주입.
- 핀/배선/스위치/ADC 동작별 정전용량의 근거와 범위. CADC7pF를 총 입력 용량으로 사용하지 않는다.
- 실제 VDDA 하강 파형과 빠른 차단, 재인가·히스테리시스·MCU OFF 입력 허용/주입 조건.
- 보호 추가로 달라진 전체 분압비와 누설/저항/VDDA/ADC/온도/보정 후 잔차의 ±0.10V 예산.

감지점 최소2.955V와 명목 VADC2.371353V,1V/ms만 가정하면 시간 간격583.647µs다. 감시기30µs와 스위치55ns를 더한30.055µs는 각각의 시험 조건이 다르므로 **보장된 시스템 지연이나 최종 여유**가 아니다. 실제 파형·부품 조건과 모든 최악 편차를 확인하기 전에는 보호 PASS로 승격하지 않는다.

## 재개점과 구현 경계

`03_09_Voltage_ADC_Discharge_TRAN.kicad_sch`에서 입력 용량·지연의 근거 정리부터 이어간다. 저장 모델 차이는 [실습 README](KiCAD/Simulation/03_Voltage_Divider/README.md)를 먼저 확인한다. 완료한 기본 AC/OP와 기존3-1 학습을 자동 반복하지 않는다.

제작 쉴드 CAD/BOM·펌웨어·물리 배선은 이번 마감으로 변경하지 않는다. NTC MCU VDD 공급안도 실제 쉴드 미반영이며, 두 전압 채널은 공통 한 채널 모델에서 검토 중이다. 공간/배치와 AI는 후속, 기존 MVP PARTIAL/OPEN 유지.
