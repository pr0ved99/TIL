2026-10-23. **RevA.0 초안 / 회로도·초기 부품 배치 / 미배선 / 제작용 아님**.

**2단계 종합 검토본:** [ADC6채널 연결·측정 기준](../../20_Analog_6Ch_Contract_and_Stage2_Review_2026-10-23_ko.md). PC0/1 전류·PC2/3 온도·PA4/PB0 전압의 포트/핀 순서를 모았다. 전류센서 nonratiometric·NTC VEXC/VDDA 비율·미분압 rail 보호를 구분했다. 구성 검토본 작성 완료이며 승인/실측 PASS는 아니다. 당시 다음 작업이었던 ADC 기준·NTC 여기·무전원 경로 비교/계산은 아래 10/24 검토에 기록했다. 현재 다음 작업은 상단 최신 재개점을 따른다.

**CAN 연결 계약 초안:** [GPIO·커넥터 검토](../../19_CAN_GPIO_and_Connector_Contract_2026-10-23_ko.md). ESP GPIO4 TX/GPIO5 RX와 ESP 가까운 트랜시버 배치를 제안했다. 별도3.3V 전원·논리3선·버스3선,2/3노드 종단 전환을 기록했다. 기존 UART17/18 유지, HG 실물/전원 OFF 보호·커넥터 제품/키는 미확정. 다음은 ADC6채널 포트/기준 계약과2단계 종합 검토다.

**전원 구조 검토안:** [3.3V 공급·조립 검토](../../18_Expansion_3V3_Supply_Structure_and_Assembly_2026-10-23_ko.md). #2 병렬 분기→단일 LDO→센서/CAN 분배와 TO-220급을 우선 제안한다. 출력 오차 포함 발열 사례0.615W, MCP1825S는 ±2.5%로 초기±1% 탐색 조건에 미달하여 미선정. 무전원 역급전·NTC 기준·#2 전체 여유는 OPEN이다. 다음은 ESP GPIO/커넥터 계약이며 CAD/BOM은 유지한다.

**채택한 목표:** STM 센서/구동 집중 + ESP Wi-Fi–CAN 게이트웨이 + 개발용 CANable. 별도 센서 MCU 추가 없음. 두 MCU용 트랜시버와 각 노드의 전원/핀/배치를 검토한다. 최신 확장 전원은 XL4015 #2 AUX5V 병렬 분기 → 별도3.3V 생성안이다. 추가 부하235mA/연속 설계300mA·LDO 손실약0.51~0.59W 계산안을 검토하며 실제 품번·방열·#2 전체 공급 여유는 미확정이다. [전원 예산 계산](../../17_Expansion_Power_Budget_2026-10-23_ko.md).

**현재 작업은3단계 입력 회로 상세 검토다.** NTC와 전류 RC·ADC 획득·수집 주기·평균·보정 후 오차 예산과 검증 학습 자료를 정리했다. 요구 채택·시험 조건 확정과 실측·부품 확정은 남았다.2단계 계약은20번 문서의 검토본이며 아래 CAD의 실제 전원·커넥터 순서는 아직 이전 초안이다.

이번 회차는 노트북만으로 설계 학습 자료를 정리했고 10/26 마감한다. 다음 물리 작업 시각은 지정하지 않았다. NUCLEO-F446RE 상면 확장 쉴드를 검토하며, **현재 CAD에는 전류 2채널·온도 2채널의 센서 부분만 작성되어 있다. 전체 확장 기능을 반영한 설계가 아니다.** 이 보드 완성은 현재 MVP의 새 선행 조건이 아니다.

## 전체 기능 범위 재대조 — 2026-10-23

사용자가 CAN·향후 LiDAR까지 고려하도록 요청했고, **IMU는 기존 만능기판에 이미 자리를 배치했음**을 재확인했다. 센서 4채널만으로 범위를 좁힌 초기 안내를 정정한다. 기존 기판을 유지하면서 아래 기능을 검토하며, 이번 범위 대조로 CAD 회로나 BOM에 부품을 추가한 것은 아니다.

| 기능 | 새 PCB에서의 처리 | 현재 근거·남은 결정 |
| --- | --- | --- |
| 좌우 모터 전류 2채널 | 외부 #5241의 전원·출력 신호 접속, 입력 필터·보호 | PC0/PC1 초안 있음. 모터 전류가 통과하는 센서 주전류 단자·배선은 외부 유지 |
| 좌우 모터 온도 2채널 | 외부 NTC 접속, 분압·필터·보호 | PC2/PC3 초안 있음. 보호·단선 판정·실물 부품 대조 미완료 |
| **K1 전단·후단 전압 2채널** | 분압·필터·보호·측정점 추가 설계 대상 | PA4/PB0 기존 예약. 현재 CAD에는 없음. 상류 `VBAT_PROTECTED_SENSE`와 하류 `MOTOR_VBAT_SAFE_SENSE` 구분 |
| **CAN** | 트랜시버 접속, CANH/CANL/GND 커넥터, 종단 선택·디커플링·보호 검토 | PA12 TX/PA11 RX 예약. 보유 MCU-230 활용 우선 검토; 실제 단자·크기·RS·내장 종단 미확인. 현재 CAD에는 없음 |
| IMU | **기존 만능기판 위치·배선 유지. 새 PCB에 중복 실장하지 않음** | PB8/PB9 I2C, PB1 INT, PC4 RESET 보존. 기존 JDBG 접근·상면 간섭만 검토. 새 IMU 커넥터도 기본 추가 대상이 아님 |
| 로직 전원·유지보수 | 센서와 CAN을 포함한 3.3V 부하 예산, 전원 디커플링·입력 보호·역급전 경로, 전원/신호 시험점 검토 | 기존 XL4015 전원 경계와 USB 전환 정책 유지. 기존 UART/엔코더/제어/SWD/RESET 접근 보존; 모든 신호의 커넥터 중복 추가는 불필요 |
| 향후 LiDAR·상위 컴퓨터 | 모델 선정 전까지 필요한 전원·데이터 연결 조건과 하네스 통로를 미결 항목으로 관리 | 별도 장착이 기존 방향. 공급 전압·정상/기동 전류·USB/UART/Ethernet 등 실제 인터페이스·커넥터가 정해진 뒤 PCB 포함 여부 결정. 지금 레귤레이터·USB 허브·레벨 변환기를 임의로 추가하지 않음 |
| 예비 확장 | 기존 핀 예약과 물리 접근성 보존 | PA6/PA7 추가 ADC 후보, PC5/PC6 선택적 gate/brake 예약. 현재 필수 회로나 확정 커넥터로 승격하지 않음 |

따라서 기존 계획을 합치면 **아날로그 6채널(전류 2 + 온도 2 + 전압 2)과 CAN**이 새 확장 PCB의 주요 검토 범위다. 전단 전압 입력을 배터리 상태 관측에도 활용하는 안이므로 별도 배터리 ADC를 자동으로 더해 7채널로 세지 않는다. 현재 리포 알람의 사용자 보고 검증과 앞으로 구현할 ADC 측정은 별개다.

CANable V2.0 Pro는 보유한 **PC 측 USB-CAN 장치**다. 새 PCB 실장 부품이나 추가 구매 대상으로 세지 않는다. CAN 종단은 물리 버스 양 끝의 120Ω 구성을 기준으로 하되, 보유 모듈의 내장 종단부터 확인해 중복 추가를 피한다. LiDAR 데이터 경로는 해당 모델과 상위 ROS 2 컴퓨터의 연결을 별도로 정하며, CAN 포트가 LiDAR 데이터 포트를 대신한다고 가정하지 않는다.

MDD10A·XL4015·K1·버스바·퓨즈·배터리는 기존 별도 전력 구역을 유지한다. 엔코더 조정부, PWM/DIR 풀다운, E-stop 감지와 ESP32 UART 회로도 기존 기판에 남긴다. 새 PCB의 부품 수와 면적은 이 경계를 기준으로 산정한다.

## 기능과 핀 계약

전류센서 #5241의 VCC/GND/VIOUT 신호만 쉴드로 연결한다. IP+/IP−와 모터 전력 배선은 쉴드 외부에 둔다. NTC는 모터 쪽에 있고 쉴드에는 분압·필터만 있다. 기존 엔코더·PWM/DIR·E-stop·UART 회로를 옮기지 않는다.

| 쉴드 신호 | MCU 후보 | J1 = NUCLEO CN7 접점 | 조건 |
| --- | --- | ---: | --- |
| STM_3V3 | NUCLEO 3.3V 공급 | 16 | 전체 가용 전원 여유 확인 필요 |
| GND | 공통 신호 기준 | 20 | 모터 전류 귀환 경로로 사용하지 않음 |
| I_LEFT_ADC | PC0 / ADC IN10 | 38 | PC0/PB8 solder bridge 선택 확인 |
| I_RIGHT_ADC | PC1 / ADC IN11 | 36 | PC1/PB9 solder bridge 선택 확인 |
| T_LEFT_ADC | PC2 / ADC IN12 | 35 | 실제 접근·간섭 확인 |
| T_RIGHT_ADC | PC3 / ADC IN13 | 37 | 실제 접근·간섭 확인 |

핀 번호 근거는 [ST UM1724 Rev17 표29, 인쇄59쪽](https://www.st.com/resource/en/user_manual/um1724-stm32-nucleo64-boards-mb1136-stmicroelectronics.pdf)이다. 기존 IMU의 PB8/PB9·PB1/PC4를 보존한다. J2=CN10과 J1의 나머지 핀은 **현재 센서 부분 초안에서만 미사용**이다. CAN·전압 회로 추가 시 해당 예약 핀의 NC 표시를 다시 검토해야 한다. 회로도의 X 표시는 NUCLEO 내부나 기존 기판의 배선을 끊는다는 뜻이 아니다.

## 3단계 함께 검토 — 현재 회로의 전원과 왼쪽 NTC

2026-10-23 사용자 요청으로 실제 회로를 함께 읽는 방식의 상세 검토를 시작했다. 저장 `.kicad_sch`에서 KiCad CLI로 netlist를 새로 추출했으며 활성 연결10개는 기존 보고와 같았다. [실제 연결·명목 계산 기록](reports/current_circuit_walkthrough.json)에 회로도/PCB hash를 남겼다. 새 ERC/DRC 수용이나 실물 검사가 아니다.

현재 `STM_3V3`는 J1-16(CN7-16)에서 들어와 J3-1/J4-1의 전류센서 전원과 R3-1/R5-1의 NTC 여기 전원을 함께 공급한다. 별도 LDO/EXP_3V3·CAN·전압2채널은 현재 CAD에 없다.20번 문서의 별도 전원안/핀 순서는 제안이며 아직 적용되지 않았다.

| 포트 | 현재 CAD 핀 순서 | 후속 계약 제안 / 적용 상태 |
| --- | --- | --- |
| J3/J4 전류 | 1=STM_3V3, 2=GND, 3=VIOUT | CUR_L/R는1=GND, 2=EXP_3V3, 3=VIOUT 제안. 미적용 |
| J5/J6 NTC | 1=분압 노드, 2=GND | TEMP_L/R는1=GND, 2=분압 노드 제안. 미적용 |

두 표를 섞어 배선하지 않는다. 향후 실제 회로/PCB/BOM을 함께 바꾸고 새 연결 검사를 수행해야 핀 순서 변경이 반영된다.

첫 상세 블록은 오른쪽 위 J5/R3/R4/C3다. 외부 NTC는 J5-1과J5-2 사이이며25°C 명목10kΩ이다. R3=10kΩ과 분압을 이루므로3.3V 여기 조건에서 노드는1.65V다. ADC 입력이 이상적인 무부하라면 R4에는 DC 전압 강하가 거의 없고 ADC도1.65V를 본다. ADC 기준도3.3V인 조건의 이상적 코드 좌표는2048이다.

R4=1kΩ과C3=100nF의 실제1차 필터 계산에는 R3와NTC의 병렬 저항이 포함된다.25°C의 소스 저항은 `1k+(10k||10k)=6kΩ`, 시정수0.6ms·차단 주파수약265Hz다. 표시1Hz를 만드는 필터와 동일한 뜻이 아니며 ADC 수집/평균·aliasing 검토는 별도다. 정상 온도 상승은 NTC 저항/노드 전압 하강으로 관측한다. 외부 NTC가 단선되면 노드는 여기 전원 쪽으로, 단락되면 GND 쪽으로 향한다. 원시값만으로 모든 배선/접촉 불량을 판별할 수 있는 것은 아니다.

전원 구조는 두 안을 다음 비교 대상으로 둔다. **A: 기존 제안대로 NTC도 EXP에서 공급**하면 VEXC/VDDA 비율·단선 시 상한/무전원 보호를 해결해야 한다. **B: 능동 센서/CAN은 EXP, NTC 여기만 STM 측에 유지**하면 기준 전원 추종·동시 차단을 단순화할 수 있으나 STM_3V3↔VDDA 실제 경로/차이·잔류 전압을 확인하고 기존 전원 계약을 수정해야 한다. NTC 두 개의 명목 부하는25°C 합계0.33mA, 두 센서 단락 시10kΩ 명목에서0.66mA다. B는 상세 검토용 추천 대안이며 사용자 채택·CAD 반영 전이다. 기존 #2 공급 선택을 조용히 변경하지 않는다.

이번 블록에서는 현회로 연결·분압·필터 동작을 읽고 전원 선택의 영향을 확인했다. 다음은 이 두 공급안과 ADC 보호 방식을 비교해 수정할 전원 net을 정하는 것이다. 회로/PCB·BOM·펌웨어·실물 배선은 유지했다.

### 2026-10-24 재개 — NTC 공급과 ADC 기준의 관계

사용자가 기존 순서의 진행을 선택했다. 전체 기능의 가배치·공간 검토는 이후 단계로 두고, 현재 블록은 NTC 전원과 ADC 기준을 비교한다. 회로도/PCB SHA-256은 위 `current_circuit_walkthrough.json`의 기존 읽기 결과와 동일하다.

- STM32F446RE의 LQFP64에서는 별도 VREF+ 핀이 없고 ADC 기준이 VDDA에 내부 연결된다. [ST DS10693 Rev11 p.144–145](https://www.st.com/resource/en/datasheet/stm32f446re.pdf#page=144).
- NUCLEO의 SB57 ON은 VDDA/VREF+를 VDD에 연결한다. JP6는 MCU 전류 측정용 연결이며 JP6 OFF/전류계 미연결에서는 MCU가 공급되지 않는다. [UM1724 Rev17 §7.8, 표10](https://www.st.com/resource/en/user_manual/um1724-stm32-nucleo64-boards-mb1136-stmicroelectronics.pdf#page=24). 따라서 보드의 3.3V 출력과 MCU 전원이 모든 점퍼 설정에서 동시에 꺼진다고 가정하지 않는다. 현재 실물 보드 revision·JP6/SB57 상태를 새로 확인한 것은 아니다.
- [MB1136 C04 회로 자료](https://www.st.com/resource/en/schematic_pack/mb1136-default-c04_schematic.pdf)의 +3V3/VDD/AVDD 경로와 매뉴얼의 연결 조건을 대조했다. AREF에 외부 전원을 넣거나 점퍼를 변경하는 작업은 이번 범위가 아니다. 로컬 PDF 다운로드는 timeout으로 저장하지 못했으며 웹 제공 자료를 사용했다.

다음은 **NTC와 R3가 모두10kΩ인25°C 명목 조건의 설명용 계산**이다. 3.2V는 전원 차이를 보여주기 위한 가정이며 실측값이나 허용오차 정격이 아니다. 충분히 안정된 상태의 이상적인 분압·무부하 ADC를 가정한다.

| NTC 분압 공급 | ADC 기준 | ADC 입력 | 입력/기준 비율 | 12bit 이상적 코드 좌표 |
| --- | --- | --- | --- | --- |
| 3.30V | 3.30V | 1.650V | 50% | 2048 |
| 3.20V | 3.20V | 1.600V | 50% | 2048 |
| 3.30V | 3.20V | 1.650V | 51.5625% | 2112 |

계산은 `V_ADC=VEXC×10k/(10k+10k)`, `q=V_ADC/VREF_ADC`, `raw≈4096×q`다. 코드 범위는0–4095이며 위 값은 중간 입력의 명목 좌표다. 동일 비율로 움직이는 전원 변화는 이 이상 모델에서 상쇄된다. 실제 저항 편차·GND 전위차·배선/필터 전압차·ADC 오차와 빠른 과도까지 제거되는 것은 아니다.

**B안(NTC 여기만 STM 측, 능동 센서/CAN은 EXP)은 계속 비교용 추천안이며 아직 채택하지 않았다.** 같은 전원 계통을 따르는 것은 NTC 비율 측정을 단순화할 근거지만, CN7-16의3.3V가 살아 있고 MCU 측 공급만 끊긴 조건이나 C3 잔류 전압에서는 입력 보호 검토가 필요하다. R4를 역급전 차단 부품으로 간주하지 않는다. 다음은 A/B 각 안의 정상·단선·단락·STM 무전원 전류 경로를 비교한 뒤 공급안과 보호 방식을 결정하는 것이다.

### 2026-10-24 MCU 무전원 검토 — R4의 경계

- 검토 조건은 NTC 분압 공급이 살아 있고 MCU VDD/VDDA가 내려가는 경우다. 현재 CAD의 STM_3V3와 MCU 공급이 실제로 함께 꺼지는지는 JP6 등 보드 경로에 따라 달라지므로 자동으로 동일시하지 않는다.
- [DS10693 표10 p.47](https://www.st.com/resource/en/datasheet/stm32f446re.pdf#page=47)에서 PC0~PC3는 FT이며, 표14 각주3은 FT의 허용 입력 상한 내 양의 주입이 발생하지 않는다고 설명한다. TTa의 ±5mA 정격이나 VDDA+0.3V 조건을 PC2의 모든 상태에 복사하지 않는다. 절대최대 정격을 무전원 정상 동작 보증으로 사용하지 않는다.
- [ST AN4899 §5.3.6/그림13](https://www.st.com/resource/en/application_note/an4899-stm32-microcontroller-gpio-configuration-for-hardware-settings-and-lowpower-consumption-stmicroelectronics.pdf#page=22)은 FT 입력이 ADC에 연결되고 샘플링할 때 VDDA/VREF+ 쪽 기생 경로가 도통할 수 있고 그 허용 전류는 보증하지 않는다고 설명한다. 따라서 일반적인 내부 다이오드 모델은 가능한 경로를 설명할 뿐, PC2가 MCU OFF에서 반드시 전원 레일을 역급전한다고 확정하는 모델이 아니다. 실제 전원 하강/리셋/ADC 스위치 조건은 OPEN이다.
- R4는 센서 측에서 ADC로 흐르는 전류를 제한하지만 회로를 차단하지 않는다. 설명용 DC 부하 모델에서 ADC 핀을 외부에서0V로 유지한다고 가정하면, 25°C NTC10kΩ의 소스는1.65V/5kΩ이고 R4 포함 전류는1.65/(5000+1000)=0.275mA다. R4 없이0.330mA, NTC 단선/R4 포함3.3/(10000+1000)=0.300mA다. 이는 저항망 계산이며 실제 무전원 핀 전류·클램프 전압·안전 허용값이 아니다.
- **C3는 R4 뒤 ADC 핀과 같은 노드다.** C3에서 ADC 내부로 흐르는 경로가 생기면 R4를 거치지 않으므로 R4가 그 국소 방전 전류를 제한한다고 하지 않는다. 전원 레일로 외부 다이오드를 추가하는 경우에도 레일이 꺼졌을 때의 유입/방전 경로를 별도로 검토해야 한다.
- 다음 후보는 NTC 공급의 실제 MCU 전원 추종/동시 차단 조건과, 전원 OFF 입력 분리 또는 잔류 전하 처리 방식의 비교다. NTC STM 공급 B안과 보호 부품은 미확정이며 CAD/BOM·실물 변경 없음.

### 2026-10-24 추가 확인 — 리셋 상태와 실제 방전 경로

- [RM0390 §7.4.1](https://www.st.com/st-web-ui/static/active/en/resource/technical/document/reference_manual/DM00135183.pdf#page=186)의 GPIOC_MODER 리셋값은0이며 PC2는 입력 모드다. [§13.13.3 ADC_CR2/ADON](https://www.st.com/resource/en/reference_manual/rm0390-stm32f446xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf#page=384)의 리셋 상태는 ADC 비활성이다. 이는 유효한 전원/리셋의 논리 상태이며 VDD=0V에서 트랜지스터 상태·누설 전류의 전기적 보증은 아니다. 따라서 샘플링 중인 ADC 그림만으로 무전원 PC2의 도통을 확정하지 않는다.
- 사용자 지적대로 C3에는 **C3 양단 노드→R4→NTC→GND** 경로가 있다. NTC 정상10kΩ, C3 초기1.65V, 센서 공급이 개방되고 ADC가 부하를 주지 않는 이상 모델에서 R4+NTC=11kΩ, 시정수1.1ms, 초기 전압의1%까지 약5.07ms다. 공급 노드가 이상적으로0V에 고정되면 R3도 GND 귀환으로 작용하여 등가6kΩ·시정수0.6ms·1%까지약2.76ms다. Python으로 계산했다.
- 두 방전 예는 센서 전압 공급이 제거된 조건이다. 별도 센서 전원이 계속 켜져 있으면 C3가0V로 방전된다는 설명을 적용하지 않는다. NTC 단선과 공급 개방이 겹치면 위11kΩ 경로도 없어지며 실제 누설/부하가 필요하다. 어느 예도 MCU 무전원 안전 PASS가 아니다.
- **현재 검토 결과/추천:** NTC 여기만 STM 전원 계통을 따르는 B안을 우선 제안하고, R3 10kΩ·R4 1kΩ·C3 100nF는 분압/필터의 현 후보로 유지한다. R4를 확정된 무전원 역급전 보호의 주목적으로 설명하지 않는다. 별도 EXP의 능동 센서/CAN과 두 전원 출력을 합치지 않는다. B안 채택·CAD 변경·보호 소자 추가는 아직 하지 않았다.
- 추가 OFF 차단 소자는 확정되지 않은 내부 도통 가정만으로 선정하지 않는다. 전원 하강/점퍼 조건의 전기적 허용은 OPEN으로 남기고, 독립적으로 진행 가능한 다음 검토는 #5241 전류 출력과 R1/R2 12kΩ의 부하·ADC 획득/정착 조건이다.

## 첫 회로 읽기 — 왼쪽 온도 채널

회로도 오른쪽 위의 `J5 → R3/R4 → C3 → T_LEFT_ADC`를 먼저 본다.

```text
STM_3V3 ─ R3 10k ─┬─ R4 1k ─┬─ PC2 후보 (CN7-35)
                  │         │
             J5-1 → NTC    C3 100nF
             J5-2 ← GND     │
                  └─────────┴─ GND
```

- R3와 외부 103JT-025가 온도에 따른 저항 변화를 전압으로 바꾼다. 명목 25°C에서 두 저항이 10kΩ이면 노드 전압은 3.3V의 절반인 1.65V다.
- 온도가 올라가면 NTC 저항이 작아져 ADC 쪽 전압이 내려간다. J5는 두 선만 필요하며 NTC 자체에는 극성이 없다.
- R4와 C3는 ADC로 전달되는 빠른 변동을 줄이는 입력 필터다. 실제 시정수에는 R3와 NTC의 병렬 저항도 들어간다.
- `T_LEFT_ADC`라는 같은 이름의 net이 CN7-35와 TP5로 이어진다. 회로도에서 연결을 강조해 직접 확인한다.
- 이 초기 회로에서 NTC 단선은 높은 전압, 단락은 낮은 전압으로 나타날 수 있다. 실제 판정 임계값·초기 대기·STALE 처리는 후속 ADC 설계 사항이다.

오른쪽 온도 채널은 J6/R5/R6/C4로 같은 구조다. 전류 입력 J3/R1/C1과 J4/R2/C2는 능동 센서 출력이므로 분압 저항을 복사하지 않는다. 12kΩ 뒤 100nF는 기존 느린 추세 관측 계산 후보이며, 100nF를 센서 VIOUT에 직접 연결하지 않는다.

### 2026-10-24 전류 입력 — 측정 목표와 12kΩ/100nF 대조

**결론:** 현 R1/R2 12kΩ·C1/C2 100nF는 필터 후보로 유지하며, 정확도까지 만족한 제작값으로 확정하지 않는다. [기존 요구사항](../../15_Expansion_PCB_Requirements_2026-10-23_ko.md#측정-성능-목표-제안)의 전류 추세 관측·결과10Hz·300ms 응답·보정 후 ±max(0.20A, 읽음값 절댓값의5%)를 검토 기준으로 재사용한다. 이 수치들은 설계 제안이며 이번 계산으로 사용자 채택 또는 실측 달성으로 바뀌지 않는다. 결과10Hz는 ADC 원시 수집률이나 필터 차단 주파수가 아니다.

- 실제 연결은 `J3.3 → R1 12kΩ → I_LEFT_ADC/PC0`, ADC 노드에서 `C1 100nF → GND`다. 오른쪽도 R2/C2로 같은 구조다. 센서가 전류를 전압으로 변환하고, RC가 그 출력의 빠른 변동을 줄인다.
- [Pololu #5241](https://www.pololu.com/product/5241)의 명목 감도44mV/A·영점1.65V로 `VOUT=1.65+0.044×I`다. −10/0/+10A는1.21/1.65/2.09V다. 비례전원형 출력이 아니므로 NTC의 전원/ADC 기준 추종 논리를 그대로 적용하지 않는다.
- [최초12kΩ 선정 기록](../../14_Motor_Monitoring_Expansion_Interface_2026-10-22_ko.md#신호-회로-블록과-부속-예산)은 센서의 직접 용량 부하 최대4.7nF·GND 저항 부하 최소10kΩ를 고려한 후보였다. [Allegro Rev16 p.8](https://www.allegromicro.com/-/media/files/datasheets/acs71240-datasheet.pdf)의 두 규격을 재확인했다. 직렬12kΩ 뒤100nF는 직접100nF 부하와 다르며, 이상적인 직렬 RC 가지의 임피던스 크기는12kΩ 이상이다. 다만 저항 부하 규격을 만족한다는 사실만으로 복합 RC 부하의 출력 안정성을 보증할 수 없다. 저항 앞 케이블 용량도 따로 남는다.

측정 요구를 회로 단위로 옮기면, 명목 감도44mV/A에서 저전류 허용 오차0.20A는8.8mV다. 이는 센서·입력 회로·ADC·기준 전압·환산의 보정 후 오차를 센서 출력 전압으로 환산한 전체 기준이며 각 항목에8.8mV씩 허용한다는 뜻이 아니다. 기준3.3V/12bit의 이상적인1LSB는 `3.3/4096=0.805664mV`, 전류로18.3105mA/count이고8.8mV는약10.923count다. 이는 분해능 점검이며 완성 계측의 정확도 보증이 아니다. 정상 명목−30/−10/0/+10/+30A 출력은0.33/1.21/1.65/2.09/2.97V다. 실제 ADC 기준은 VDDA이므로3.3V는 계산 가정이고, 전원/온도/센서 편차·이상 입력 여유는 별도다.

센서 출력 저항을 무시하고 ADC 무부하·명목 R/C를 가정한 계산:

| 항목 | 계산 결과 | 해석 |
| --- | --- | --- |
| 시정수 `R×C` | 1.2ms | 필터 반응의 시간 척도 |
| 차단 주파수 `1/(2πRC)` | 132.63Hz | 이 주파수에서 진폭 약70.7%; 그 이상이 모두 사라지는 경계가 아님 |
| 입력 계단 변화의 잔여 오차1% 도달 `−ln(0.01)RC` | 5.53ms | 변화량의99%를 따라가는 시간; 절대 전류 오차 또는 전체300ms 응답 판정과 다름 |
| 19kHz 정현파 성분 진폭비 `1/√(1+(2πfRC)²)` | 0.00698, 약0.698% | 필터 앞100mV 진폭 예라면 뒤0.698mV; 실제 잡음 진폭/파형을 측정한 결과가 아님 |

**정확도 검토에서 드러난 제한:** [STM32F446 DS10693 Rev11 Table56 p.117, Figure46 p.144](https://www.st.com/resource/en/datasheet/stm32f446re.pdf)는 정상 입력 범위의 누설 ±1µA와 ADC 입력 모델을 제시한다. 이 크기의 누설을 가정하면 `12kΩ×1µA=12mV`, 전류 환산은 `12mV/(44mV/A)=0.273A`다. 저전류 구간 목표 ±0.20A의 신호 전압은 ±8.8mV다. 따라서 “안정 후 입력 전류가 작으므로 전압 강하는 무시 가능”은 이 정밀도에서 별도 검증 없이 사용할 수 없다.

이는 실물에서 항상0.273A 오차가 난다는 결론이 아니다. 일정한 오프셋은 영점 보정으로 줄일 수 있지만 전압·온도·시간에 따른 누설 변화, 보호소자 누설, ADC/기준 전압·센서 오차가 남는다. ±1µA 정격은 프로젝트 초기20~30°C에서의 실측 누설값도 아니다. 이 계산은 미보정 누설 항의 상한 검토이며, 보정 후 목표 미달 확정과 구분한다. C를 키우거나 결과를 평균내도 정상상태 DC 누설 오차 자체는 제거되지 않는다.

**다음 설계 판단:** ADC 획득 시간·채널 전환/수집률과 보정 후 오차 예산을 함께 계산한 뒤, 현 RC 유지와 입력 구동/필터 변경안을 비교한다. 저항만 줄이면 센서 출력 부하 조건도 다시 검토한다. 현재는 이 기준에 따라12kΩ의 채택을 보류하며 CAD/BOM·펌웨어는 변경하지 않았다.

**후속 실물 검증 항목:** 알려진 DC 전압을 센서 출력 대신 넣어 입력계의 영점·감도 보정 후 오차와 전압 변화 응답을 먼저 확인하고, 센서 포함 시험에서 기준 전류와 비교한다. 저전류 ±0.20A/그 이상 읽음값5%와300ms는 위 제안 기준으로 판정한다. DC 대입만으로 센서 정확도·PWM 잡음 제거·에일리어싱까지 통과 처리하지 않는다. 오늘은 Python 명목 계산과 자료 대조만 수행했다.

### 2026-10-24 ADC 획득 시간 — 내부/외부 커패시터 구분

[계산 입력·식·결과](reports/current_adc_acquisition.json). 오늘은 전류 입력의 수집 시간 후보를 계산했으며 ADC 설정/보드 측정은 수행하지 않았다. [DS10693 Rev11 Table74 p.140/식1 p.141](https://www.st.com/resource/en/datasheet/stm32f446vc.pdf)의 내부 스위치 저항 상한6kΩ·샘플/홀드 용량 상한7pF·12bit 변환 시간식을 확인했다. RE URL의 부분 조회가 실패해 같은 STM32F446xC/E 문서인 VC URL로 확인했다. 로컬 Rev10의 해당 표/식도 대조했으며 개정 전체가 같다는 결론은 아니다. 6kΩ는 보수적인 상한 입력이고3.3V에서 측정한 스위치 저항이 아니다.

`센서 → R1 12kΩ → ADC 핀/C1 100nF → 내부 샘플 스위치/RADC → 내부 CADC`의 두 커패시터를 구분한다. 내부 커패시터는 입력을 획득·보존해 변환하는 회로의 등가 모델이고 C1은 외부 필터/전하 공급원이다. [AN2834 Rev10](https://www.st.com/resource/en/application_note/an2834-how-to-get-the-best-adc-accuracy-in-stm32-microcontrollers-stmicroelectronics.pdf)의 샘플/홀드 원리와 외부 용량의 반복 전하 교환 설명을 참고했다. 내부 용량이 매번0V 또는 이전 입력 전압으로 시작한다고 단정하지 않고 전체 스케일3.3V 차이를 검토용 경계로 둔다.

**모델 A: 외부 C1을 제외한 저항·내부 용량의 획득 계산.** 이는 설명용 비교이며 실제 CAD에서 C1을 제거한 것이 아니다. 센서 출력 저항/기생성분은 무시한다. R1±1%를 가정해12.12kΩ를 쓰면 `(12.12k+6k)×7pF=0.12684µs`다. 3.3V/12bit의1LSB는0.805664mV, ST 식1의 획득 잔차 기준0.25LSB는0.201416mV다. `오차=초기차×exp(−t/τ)`에서 초기차3.3V를 이 기준까지 줄이는 유효 시간은 `τ×ln(16384)=1.23086µs`다. ST 식1은 유효 시간을 `(k−0.5)/fADC`로 계산하므로14MHz에서k>17.732가 필요하다. 이0.25LSB는 해당 동적 오차 항의 계산 기준이며 전체 전류 정확도 목표와 다르다.

| 14MHz 샘플 설정 후보 | 설정 시간 k/fADC | 식1 유효 시간 | 모델 A의0.25LSB 조건 |
| --- | --- | --- | --- |
| 3cycles | 0.2143µs | 0.1786µs | 불충족 |
| 15cycles | 1.0714µs | 1.0357µs | 불충족 |
| 28cycles | 2.0000µs | 1.9643µs | 충족 |
| 480cycles | 34.2857µs | 34.2500µs | 충족 |

**모델 B: 외부 C1이 미리 안정된 뒤 한 번 전하를 주고받는 계산.** 두 용량의 전압 차이를3.3V로 두고 그 짧은 동안 센서의 보충을 무시하면 `ΔV=3.3×7pF/(100nF+7pF)=0.230984mV≈0.2867LSB`다. 이는 외부 노드의 단순 전하 공유 변화이며 모든 내부 스위칭/최종 변환 오차의 보증 상한이 아니다. 명목 감도44mV/A로5.25mA에 대응한다.0.25LSB보다 크므로 모델 A의 충족을 실제 C1 포함 회로의0.25LSB 보증으로 옮기지 않는다. 초기−10%로90nF만 대입하면0.25665mV이며, X7R의 온도/바이어스까지 포함한 최소 유효 용량은 별도다.

외부 C1의 명목 회복 시정수는 `12k×100nF=1.2ms`다. 한 번 생긴 전압 차이의 남는 비율은1ms 후43.46%,10ms 후0.0240%다. 짧은 간격으로 같은 방향의 전하 교환이 반복되면 편차가 누적될 수 있으므로 채널당 재수집 간격을 함께 정해야 한다. 이 두 간격은 설명용 비교이며 전류 수집률을100Hz 또는1kHz로 선택한 것이 아니다. 실제 전하 부호/크기는 채널 입력과 ADC 내부 동작에 따라 달라진다.

**설정 후보/현재 결론:** 기존 PCLK2=84MHz 설정을 읽었고 `/6=14MHz`,12bit·480cycles를 계속 검토 후보로 둔다. 샘플34.29µs+SAR 변환12cycles(0.857µs)=채널당35.14µs, 같은 설정의6채널 연속 변환은210.86µs다. 트리거 지연/소프트웨어 시간 제외이며 실제 스캔 순서/수집률은 미정이다. 480cycles는 최소 필요값의 결론이 아니고, 넉넉한 획득 창을 두는 기존 후보다. 명목6채널 시간 자체는100ms 결과 주기를 크게 차지하지 않지만 필터/평균/전달까지의300ms 요구 충족 증거는 아니다.

다음은 채널별 재수집 간격·PWM/샘플링 관계·평균 지연과 보정 후 오차 예산을 함께 정해 RC 유지 또는 변경을 판단하는 것이다. 획득 시간을 늘려도 정상상태 누설1µA×12kΩ=12mV 항은 제거되지 않는다. CAD/BOM·펌웨어·빌드/플래시·실물 변경 없음.

## 풋프린트와 형상은 아직 후보

- J1/J2: 설치된 KiCad 10.0.5의 `STM32_Nucleo-64_Morpho` 템플릿에서 패드 좌표·외곽을 가져왔다. 소켓은 설치 라이브러리의 최신 동일 형식으로 교체하고 **76개 패드 좌표와 밑면 실장**을 대조했다. 소켓 높이·접촉 길이·실물 맞춤은 미검증이다.
- 외곽은 템플릿의 윤곽이며 최종 크기 선정 결과가 아니다. 템플릿 장착홀은 지지 방식이 정해지지 않아 제거했다. RESET/USER·전원 점퍼·ST-LINK·기존 하네스 접근을 검토한 뒤 외곽/지지점을 정한다.
- R1~R6: 축형 DIN0207, 7.62mm 리드 간격을 배치 후보로 사용했다. 보유 저항의 실제 몸체·허용오차를 확인한 결과가 아니다.
- C1~C4: 구매한 Vishay의 명목 5mm 리드 피치에 맞춘 **범용 D5.0/W2.5mm 임시 외형**이다. 해당 Vishay 몸체 최대치·리드 지름과의 일치가 확인된 전용 풋프린트가 아니다.
- J3/J4: JST-XH 3핀, J5/J6: JST-XH 2핀은 배치 후보다. 소켓/하우징/크림프 품번·보유 여부·케이블 방향은 미확정이며 구매 목록이 아니다. J3/J4의 1=3V3, 2=GND, 3=VIOUT는 **쉴드 커넥터 번호**이고 Pololu 모듈 패드의 물리 순서를 뜻하지 않는다.
- TP1~TP6는 직접 프로브를 댈 패드다. 별도 금속 시험점 부품 구매를 전제로 하지 않는다.

## 제작 전 남은 설계

1. 전체 기능 범위에 맞춘 CAN·전압 2채널 회로와 전원/접속 계약. 현재 센서 부분의 검사 통과를 전체 기능 검토 완료로 간주하지 않는다.
2. ADC 입력 ESD/오접속 보호, 센서 또는 MCU가 꺼졌을 때 역급전과 누설, 단선 검출 방식.
3. #5241 carrier의 기존 디커플링과 추가 케이블/쉴드 전원 디커플링, 3.3V 가용 전류. 초기 파일에는 별도 디커플링 소자를 추가하지 않았다.
4. 전류 12kΩ 후보의 누설 오차·ADC 획득 시간·샘플링 조건. 필터 계산만으로 실측 성능을 확정하지 않는다.
5. 각 부품의 실제 몸체/리드/소켓/하우징 도면, 사용자가 가진 부품과의 대응.
6. CN7-36/38 보드 설정과 상면 점유, 소켓 높이·부품 간섭·기구 지지·케이블 당김 처리.
7. 회로 확정 후 최종 배선·구리영역·규칙 검사와 1:1 대조. 현재 Gerber/드릴 제작 파일은 생성하지 않았다.

현재 10kΩ 저항은 보유품의 허용오차가 미확인이다. 0.1% 추가 구매를 요구하지 않는다. 입력값/온도 환산을 확정할 때 실제 사용값을 반영한다.
