## 1. 이번에 재현할 상황

출발점 보호 저항 뒤, PCB 상단24kΩ 앞에서 감지선의 피복이 손상되어 공통GND선 또는 GND에 연결된 금속과 접촉하는 상황이다. 금속 차체가 실제GND라고 가정하는 것이 아니다. MCU전원VDDA는3.3V로 유지한다.

기존S1은TMUX역할로ON유지, 새S2는잘못된접촉을재현한다. S2는 실제 추가할 보호소자가 아니다. 진단펌웨어도 추가하지 않는다. 고장 때VADC가낮아져도 실제저전압과고장원인을그값하나로구분할수없다는 점을 확인한다.

## 2. 구성할 회로

~~~text
V1(16V)─R6(1Ω)─●VRAIL─R7(2.2kΩ)─●VRAW─R1(12k)─R2(12k)─●VDIV─R4(1k)─S1─●VADC
                                │                      │                │
                                S2                     R3(4.7k)         R5(47k)
                                │                      C1(100n)         C2(100p)
                                0                      │                │
                                                       0                0
~~~

R3/C1은각각VDIV–0병렬, R5/C2는각각VADC–0병렬이다. 위문자도에서세로로나열된것을직렬로연결하지않는다. S1의기존B1/VDDA제어배선은보존한다.

| 실습 reference | 값/역할 |
| --- | --- |
| V1 | 모델PWL 0 16 15m 16; t=0부터16V 유지 |
| R6 | 1Ω; 전원 내부/상류 배선 저항을 모사한 가상 등가값 |
| R7 | 2.2kΩ; 후보 출발점 보호 저항Rp |
| S2 | Simulation_SPICE:SWITCH; 접촉 고장 모사 |
| V4 | Simulation_SPICE:VPWL; S2제어,0V정상/3.3V단락 |
| V3 | 모델PWL 0 3.3 15m 3.3; MCU공급 유지 |
| R1~R5/C1/C2/S1/B1 | 03_14의기존값/연결 유지 |

R6=1Ω와S2 ON저항1Ω는학습용비교값이며 실제배터리/하네스사양이아니다. 실제배터리 단락전류예측도아니다. 비교안에서보호저항을없애도유한한전류를계산하고,전원전압강하를구분할수있게한다. 실습R7은Shield실제R7과다른reference다.

## 3. 사용자가 구성할 순서

1. [기존03_14회로](03_14_Voltage_ADC_InputSettling_TRAN.kicad_sch)를열고다른이름으로저장한다. 새파일명은03_15_Voltage_Sense_CableShort_TRAN.kicad_sch, 같은폴더다. 원본03_14/workbook은유지한다.
2. V1의심벌속성→시뮬레이션모델에서기존PWL문자열을0 16 15m 16으로바꾼다. 화면Value만16으로바꾸면기존PWL이남으므로모델값을수정한다. V3도0 3.3 15m 3.3으로맞춘다.
3. V1+에서R1상단저항으로가는선을나누어R6=1Ω,R7=2.2kΩ을직렬삽입한다. 기존VRAIL라벨은R6와R7사이에둔다. R7과R1사이에는VRAW라벨을둔다. V1+는선택적으로VBAT_IDEAL라벨을둔다. 같은VRAIL라벨을저항양쪽에중복배치하지않는다.
4. 새S2를추가한다. 핀1(no+)은VRAW,핀2(no−)는SPICE0,GND에연결한다. 핀3(ctrl+)은V4+,핀4(ctrl−)는0에연결한다. 물리적화면방향대신핀번호/핀명으로대조한다.
5. S2모델의문턱(thr)=1.65V,히스테리시스(hyst)=0V,ON저항(ron)=1Ω,OFF저항(roff)=1GΩ로설정한다. 기존S1의ron2/roff1G/thr1.65는그대로다.
6. 새V4는VPWL로추가,마이너스는0,플러스는S2제어+에연결한다. PWL은다음문자열이다.

~~~text
0 0 5m 0 5.001m 3.3 10m 3.3 10.001m 0 15m 0
~~~

5ms부터1µs동안상승하고10ms부터1µs동안하강한다. 문턱1.65V/히스테리시스0이므로이상스위치의전환은각각약5.0005ms/10.0005ms다. 실제고장발생/제거시간을측정한것이아니다.

사용자저장본을확인한뒤TRAN으로간다. 첫안내의작업범위는회로구성/저장까지다.
