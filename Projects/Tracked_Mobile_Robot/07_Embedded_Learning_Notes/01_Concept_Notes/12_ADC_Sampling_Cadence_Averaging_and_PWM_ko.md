# ADC 수집 주기·평균·PWM의 관계

2026-10-25 재개. [이전 학습 노트](11_Monitoring_ADC_Requirements_RC_and_Sampling_ko.md)의 14절에서 이어간다. 이번 기록은 수집 주기 비교의 첫 블록이며, 수집률·평균 방식·RC를 확정한 설계가 아니다.

## 1. 오늘의 설계 목표

전류·전압 결과를 100ms마다 만들고, 안정된 새 입력을 300ms 안에 허용 오차 범위로 반영한다는 제안 목표에 맞춰 원시 수집·평균·RC 조건을 연결한다. 온도 결과는 1초마다라는 별도 제안이다. 이 수치들은 [측정 요구 초안](../../09_Electrical_Design/15_Expansion_PCB_Requirements_2026-10-23_ko.md)의 검토 목표다.

흐름은 수집 주기/채널 순서 → PWM과 aliasing → 평균 지연 → 보정 후 오차 예산 → RC 후보 판단이다. 오늘 첫 블록에서는 서로 다른 시간의 의미와 100Hz/1kHz 비교 근거를 만든다.

## 2. 1회 획득, 반복 수집, 결과 갱신은 서로 다르다

| 시간 | 무엇을 정하는가 | 기존 값 또는 비교 예 |
| --- | --- | --- |
| 획득 창 | ADC 내부 샘플링 C가 입력을 따라갈 시간 | 14MHz·480cycles 후보에서 약34.29µs |
| 획득+변환 | 한 채널 원시 코드 한 개가 만들어지는 시간 | 위 후보의 12bit 변환 포함 약35.14µs |
| 채널별 수집 간격 | 같은 채널을 다시 읽기 시작하는 간격 | 10ms 또는1ms를 비교 |
| 결과 갱신 간격 | 처리한 새 전류·전압 결과를 만드는 간격 | 요구 초안100ms |

1ms 간격으로 수집해도 한 번의 ADC 동작이 1ms 전체를 쓰는 것은 아니다. 위 후보에서는 한 채널 약35µs가 걸리고 다음 수집 시점까지 다른 채널 변환과 대기 등이 들어간다. 6채널을 순서대로 읽으면 약210.86µs다. 각 채널은 같은 순간에 읽히지 않으므로 이후 스캔 순서와 시각 정의도 필요하다.

```text
센서 전압 → RC → ADC 원시 값 여러 개 → 평균·보정 → 새 결과
                  반복 수집 간격                  결과 갱신 간격
```

“100ms마다 새 결과”라는 요구만으로 ADC도100ms마다 한 번 읽어야 한다고 결론내리지 않는다. 한 결과를 여러 샘플로 만들 수 있다.

## 3. 같은 100ms 결과에 샘플을 몇 개 넣을 것인가

100ms=0.1초다. 1초에 읽는 횟수를 Hz로 표시하고, 일정 간격 수집에서 `샘플 수=수집률×구간 길이`로 계산한다. 아래는 100ms 블록마다 한 번 결과를 내는 설명용 구성이다.

| 채널별 수집률 | 같은 채널의 수집 간격 | 100ms 블록의 샘플 수 | 매번6채널을 읽을 때 ADC 시간 비율 |
| --- | --- | --- | --- |
| 10Hz | 100ms | 1개 | 약0.211% |
| 100Hz | 10ms | 10개 | 약2.11% |
| 1kHz | 1ms | 100개 | 약21.09% |

시간 비율은 `6채널 변환210.86µs / 반복 간격`이다. ADC 변환 시간의 비율이며 CPU 점유율이 아니다. 트리거·소프트웨어·통신 비용, 실제 다른 채널 설정은 제외했다. 10Hz는 차이를 보여주는 기준선이고 100Hz/1kHz도 검토용 비교점이다.

평균 예: 실제 입력이 거의 일정하다는 상황에서 전류 환산값2.0,2.2,1.8,2.0A를 얻었다면 평균은2.0A다. 여러 샘플에서 반대 방향으로 나타나는 흔들림은 상쇄될 수 있다. 그러나 값의 변화가 실제 부하 변화라면 평균은 그 변화도 늦추며, 항상 같은 방향으로 치우친 오차는 평균으로 없어지지 않는다.

같은100ms 구간을 평균한다면 수집률이 높다는 이유만으로 평균에 포함되는 시간 범위가 짧아지지 않는다. 예를 들어 마지막 샘플을 받자마자 결과를 내는 경우10ms 간격10개는 첫~마지막90ms,1ms 간격100개는99ms를 걸친다. 평균 샘플 나이는 각각45ms/49.5ms다. 이것은 전체 계단 응답 시간이나 브라우저 지연이 아니며 출력 시점이 더 늦으면 그 시간도 더해진다.

## 4. 자주 읽을 때 외부 C의 회복도 확인한다

이전 단일 전하 공유 모델에서 C1 노드에 작은 변화가 생긴 뒤 센서 쪽 전압으로 돌아가는 명목 시정수는1.2ms였다. 같은 모델의 자유 회복 비율은 `exp(-t/1.2ms)`다.

- 10ms 뒤에는 처음 작은 변화의 약0.0240%가 남는다.
- 1ms 뒤에는 약43.46%가 남는다.

43.46%는 센서 전압 전체가 그만큼 틀린다는 뜻이 아니다. 단일 샘플링으로 생긴 작은 교란에 대한 비율이다. 반복될 때의 실제 오차는 전하 이동의 크기·방향·채널 순서·내부 동작에 따라 달라진다. 1ms 전체를 순수 회복 시간으로 보는 단순 비교이며 유한한 획득 창까지 결합한 모델은 아니다. 이 표만으로1kHz를 불가능 또는 안전하다고 판정하지 않는다.

ST도 외부 C에 대한 반복 전하 이동과 변환 사이의 회복 시간을 함께 검토한다. [AN2834 Rev10 §4.4.3, pp.45–46](https://www.st.com/resource/en/application_note/cd00211314.pdf#page=45). 해당 문서의 예시 소자값을 현재 F446 입력의 확정값으로 복사하지 않는다.

## 5. PWM의 같은 부분만 읽으면 평균도 해결하지 못한다

우선 이해용으로 정확한19,000Hz 리플과1,000Hz 수집을 가정한다. 1ms 동안 리플이19번 반복한다. 그러면 다음 샘플도 리플의 같은 위치를 읽게 된다. 꼭대기를 읽던 경우 계속 꼭대기를 읽을 수 있고,100개를 평균해도 그 치우침이 유지된다. 실제 센서 신호의 평균과 샘플 평균이 다를 수 있다는 뜻이다.

고주파 성분이 샘플링 뒤 다른 낮은 주파수나 DC처럼 보이는 현상이 aliasing이다. 이미 느린 성분처럼 보이게 된 오차를 단순 평균으로 항상 구별·제거할 수는 없다. [Analog Devices의 ADC 학습 자료 §20.2](https://wiki.analog.com/university/courses/electronics/text/chapter-20).

### 현재 소스 설정을 사용한 명목 비교

실제 파일 [tim.c](../../03_Firmware/stm32_uart_mvp/Core/Src/tim.c)의 TIM4는 PSC=0, ARR=4420, up-counting이다. [main.c](../../03_Firmware/stm32_uart_mvp/Core/Src/main.c)의 명목 HSI16MHz·PLL/버스 설정과 현재 타이머 클록 경로에서 TIM4 클록은84MHz다. 명목 주파수는 다음과 같다.

```text
fPWM = 84,000,000 / ((0+1) × (4420+1))
     ≈ 19,000.226Hz
```

이는 소스의 명목 계산이며 HSI 오차·실측 주파수·현재 보드 이미지 확인이 아니다. 아직 구현하지 않은 이상적100Hz 또는1kHz 등간격 수집과 비교하면, PWM 기본파의 alias 주파수는 둘 다 약0.226Hz로 계산된다.

```text
100Hz 수집: |19,000.226 - 190×100| ≈ 0.226Hz
1kHz 수집:  |19,000.226 - 19×1,000| ≈ 0.226Hz
주기 ≈ 1/0.226Hz ≈ 4.421초
```

100ms 동안에는 이 느리게 보이는 흔들림의 약0.0226주기만 지나간다. 직사각형 블록 평균의 이산시간 진폭비를 계산하면10개 평균과100개 평균 모두 약0.99916이다. **샘플링된 이 리플 성분의 약99.916%가 남는다**는 이상적 계산이다. RC 앞 리플의99.916%가 그대로 통과한다는 뜻은 아니다. 아날로그 RC의 기존 감쇠는 그 전에 별도로 적용된다.

원래 리플 크기·고조파·실제 수집 시각·ADC 획득 동작과 잡음 스펙트럼은 미측정이다. 따라서 실제 전류 오차A를 여기서 확정하지 않는다. 단순히 평균 개수를100개로 늘렸다는 사실만으로 PWM 영향 제거를 주장할 수 없다는 비교 근거다.

## 6. 이번 블록의 결론과 다음

- 결과10Hz와 원시 수집률을 분리했다. 채널별100Hz/1kHz는 시간적으로 가능한 비교점이며 선택 완료가 아니다.
- 전체6채널 스캔 시간과 C1의 회복, PWM 위상 관계가 서로 다른 판단 기준임을 확인했다.
- 현재 RC·수집·평균만으로 오차 목표 충족을 선언하지 않는다. DC 누설과 보정 후 잔차도 따로 남아 있다.
- 다음은5절의 같은 위상/느린 alias 현상을 파형·샘플로 이해하고, 필요한 신호 대역과 아날로그 감쇠·수집 시각 전략·평균 지연을 비교한 뒤 오차 예산으로 연결한다. 구현할 수집률/채널 순서는 그 비교 후 정한다.
