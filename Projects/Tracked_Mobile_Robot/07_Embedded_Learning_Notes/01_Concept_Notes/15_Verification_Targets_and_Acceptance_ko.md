# 3-1. 검증 대상과 합격 기준

학습 회차: 2026-10-25 · 정리: 2026-10-26. [2-6 후보 종합 판단](14_Current_RC_ADC_Candidate_Decision_ko.md) 다음 자료다. 3장은 **3-1부터 3-4까지 총 네 편**으로 끝낸다. 이 문서는 필기용 검증 계획이며 시험 결과가 아니다.

**핵심:** 무엇을 시험했는지, 무엇과 비교했는지, 어느 정도 차이까지 허용할지를 먼저 정해야 “통과했다”는 말에 의미가 생긴다.

**3-1 보충 설명 · 10/27:** [전체 측정 정확도와 입력계 정확도](19_Total_Measurement_vs_Input_Chain_Accuracy_ko.md) · [Notion 복습 문서](https://app.notion.com/p/406a7326f87b81d0a897f34791e226c8). 시험 시작점과 비교 단위가 다른 이유를 1.738V/1.742V 및 2.00A/2.12A 가상 예시로 풀어쓴다. 새 시험 결과나 요구 확정이 아니다.

---

**① 계산 다음에 검증이 필요한 이유**

2장에서는 R1=12kΩ, C1=100nF, ADC 14MHz·12bit·480cycles를 후보로 검토했다. 계산은 가정한 회로와 조건에서 예상되는 동작을 알려준다. 실제 부품 편차, 전원, 배선, 센서 출력, ADC 동작이 모두 그 가정과 같은지는 따로 확인해야 한다.

예를 들어 `12kΩ×100nF=1.2ms`는 명목 RC 시정수다. 이 계산만으로 전류 표시가 실제 전류에서 0.20A 이내로 맞는다고 말할 수 없다. **응답 속도와 정확도는 서로 다른 요구**이기 때문이다.

현재 수치 목표의 원본은 [확장 PCB 요구조건 초안](../../09_Electrical_Design/15_Expansion_PCB_Requirements_2026-10-23_ko.md)이다. 아래 목표는 사용자 검토 전 제안이며 제조사 보증이나 실측 성능이 아니다.

---

**② 측정 경로를 나누면 문제의 위치를 찾을 수 있다**

```text
실제 전류 → 전류센서 → RC 입력 회로 → ADC → 보정·평균 → 측정 결과 → 브라우저
                        ↑
                알려진 전압으로 대체 가능
```

| 검증 범위 | 입력과 비교 대상 | 알 수 있는 것 | 이 시험만으로 알 수 없는 것 |
| --- | --- | --- | --- |
| 입력 회로·ADC | 센서 대신 알려진 DC 전압, 기준 전압 계측 | 입력 전압을 코드/환산값으로 읽는 잔차 | 센서의 전류 정확도 |
| 센서 포함 전체 경로 | 알려진 전류, 적합한 기준 전류 계측 | 센서+입력계+환산의 전체 차이 | 다른 온도·모든 PWM 조건의 성능 |
| PWM·수집 조건 | 같은 정의의 평균 전류, 원시값과 처리값 | 리플·수집률·위상·평균에 따른 변화 | 계측 대역폭 밖의 순간 피크 |
| 응답·유효성 | 입력 변화 시각, 새 결과 시각과 상태 | 지연·갱신 중단·이상값 처리 | 물리적 과전류 차단 성능 |

센서 출력을 전압 발생기로 대신한 시험에서는 **센서를 제외한 경로**만 검증한다. 이것을 센서 전체 정확도 PASS로 기록하지 않는다. 브라우저에서 숫자가 잘 보이는 것도 전기적 정확도의 증거를 대신하지 않는다.

---

**③ 목표마다 적용 조건을 함께 적는다**

| 대상 | 정확도 제안 | 결과 주기·응답 제안 | 적용 경계 |
| --- | --- | --- | --- |
| 좌우 전류 | ±max(0.20A, 읽음값 절댓값의 5%) | 100ms마다, 안정된 입력을 300ms 이내 반영 | 우선 −10~+10A, 영점·감도 보정 후, 주위 20~30°C |
| 좌우 온도 입력계 | ±1°C | 1초마다, 저항 대입 안정 후 2초 이내 반영 | 0~100°C 모사, 입력 회로·ADC·환산만 포함 |
| K1 전단·후단 전압 | ±0.10V | 100ms마다, 안정된 입력을 300ms 이내 반영 | 0~16V, 보정 후, 주위 20~30°C |

전류 센서의 ±30A는 **신호 수용 범위**다. 로봇을 30A로 구동하거나 그 전류까지 시험하라는 뜻이 아니다. 온도 ±1°C에는 NTC 자체 편차·자가발열·모터 접촉·열지연이 포함되지 않는다. 전압 16V는 분압기를 거치는 시스템 입력 범위이며 MCU ADC 핀에 직접 넣을 전압이 아니다.

현재 CAD는 전류 2·온도 2채널의 초안이다. 전압 2채널과 CAN·전원·보호의 구현 완료를 이 표에서 추론하지 않는다. 오늘의 작업은 설계 학습과 계획 작성이다.

---

**④ 허용 오차를 계산하는 기준은 ‘읽음값’이다**

전류 목표를 식으로 쓰면 다음과 같다.

```text
T = max(0.20A, 0.05 × |I_read|)

T      : 허용하는 차이의 크기 [A]
I_read : 보정·처리 후 우리 장치가 출력한 전류 [A]
max    : 두 수 중 큰 값 선택
| |    : 부호를 없앤 크기
```

| 장치 읽음값 | 읽음값 크기의 5% | 선택되는 T |
| --- | ---: | ---: |
| 0A | 0A | 0.20A |
| 2A | 0.10A | 0.20A |
| −5A | 0.25A | 0.25A |
| 10A | 0.50A | 0.50A |

0.20A와 5% 조건이 만나는 크기는 `0.20/0.05=4A`다. ±4A 안에서는 고정 0.20A 조건이 크고, 그 밖에서는 5% 조건이 커진다. 원본이 읽음값 기준이므로 비교 계산에서 기준 계기의 값으로 몰래 바꾸지 않는다.

---

**⑤ 기준 계기도 완전히 정확하지 않다**

기준 계기에 2.00A가 표시되어도 실제 전류가 정확히 2.000000A라는 뜻은 아니다. 계기의 정확도 사양, 분해능, 교정 상태, 영점, 계측 범위와 방법에 따른 불확실성이 있다. PWM 전류라면 기준 계기가 평균값을 읽는지 RMS를 읽는지도 맞춰야 한다.

```text
d = I_read − I_ref

d     : 우리 장치와 기준 계기의 관측 차이 [A]
I_ref : 같은 구간·같은 측정량에 대한 기준 계기 결과 [A]
```

여기에 시험 비교의 불확도 `U_test [A]`를 붙인다. 기준 계기, 비교 시각, 반복 측정의 추정 불확도 등을 어떤 방법으로 포함했는지 기록한다. 지금 알아내려는 장치의 편향 전체를 다시 불확도에 더해 중복 계산하지 않는다.

NIST의 확장 불확도 표기는 `U=k×u_c`다. `u_c`는 결합 표준 불확도이고 `k`는 포함인자다. **k=2가 항상 정확히 95%를 뜻하지 않으며**, 분포와 추정의 신뢰성 같은 조건이 필요하다. 이런 구간은 절대적으로 벗어날 수 없는 최대오차 경계와 다르다. [NIST 확장 불확도](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-6-expanded-uncertainty), [불확도 보고 방법](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-7-reporting-uncertainty).

현재 보유/주문 계기의 모델명만으로 이 불확도를 확정할 수 없다. 사용 범위·정확도 사양·실제 연결·DC/PWM 응답을 확인하기 전에는 정밀 정확도 판정을 보류한다. 새로운 계기 구매가 자동 결론은 아니다.

---

**⑥ 경계에 가까운 결과는 보류할 수 있어야 한다**

다음은 이번 학습에서 제안하는 판정 규칙이다. 채택 여부와 불확도의 포함 수준을 시험 전에 명시해야 한다.

```text
PASS         : |d| + U_test ≤ T
FAIL         : |d| − U_test > T
INCONCLUSIVE : 그 사이 — 불확도 구간이 허용 경계와 겹침
NOT_RUN      : 시험하지 않음
NOT_READY    : 기준·장비·연결 조건이 부족하여 시작 조건 미충족
```

확장 불확도를 쓸 때 위 규칙은 정한 포함 수준에 따른 의사결정이다. 오류 가능성이 0인 보증은 아니다. 관측 차이만 작다고 PASS로 넘기는 일을 줄이려는 규칙이다.

**가상 예시:** 기준 계기 2.00A, `U_test=0.03A`라고 설명을 위해 가정한다. 아래 값은 실제 로그가 아니다. 세 읽음값 모두 4A 미만이므로 `T=0.20A`다.

| 우리 읽음값 | 관측 차이 크기 | 계산 | 제안 규칙의 판정 |
| --- | ---: | --- | --- |
| 2.12A | 0.12A | 0.12+0.03=0.15 ≤ 0.20 | PASS |
| 2.19A | 0.19A | 0.16~0.22A가 경계와 겹침 | INCONCLUSIVE |
| 2.25A | 0.25A | 0.25−0.03=0.22 > 0.20 | FAIL |

평균값의 정확도만 볼지, 각각의 100ms 출력이 허용 범위 안에 들어와야 하는지도 정해야 한다. **이 노트의 실행안은 안정 구간의 유효한 각 처리 결과를 확인하고 평균·산포도 함께 기록하는 제안**이다. 긴 평균 하나로 순간적인 초과를 숨기지 않는다. 유한한 관측 구간의 통과를 무한 시간 보증으로 확대하지 않는다.

---

**⑦ 입력계 시험에는 별도의 오차 배분이 필요하다**

명목 감도 44mV/A라면 전체 저전류 허용치 0.20A는 다음 전압에 해당한다.

```text
0.20A × 44mV/A = 8.8mV
```

8.8mV는 센서·입력 회로·ADC·기준 전압·처리 등을 합친 전체 예산이다. 입력 회로 하나에 전부 사용할 수 있다고 정한 값이 아니다. 2-5의 센서 3mV·입력계 2mV 등의 분배는 설명용 예시이며 채택된 규격이 아니다.

따라서 **입력계 허용 잔차 `T_input`을 아직 정하지 않았다면**, 전압 대입 시험에서는 잔차·산포·조건 의존성을 측정해 남기고 해당 정확도 PASS는 보류한다. 보정 감도가 명목 44mV/A와 달라지면 전류↔전압 환산도 그 감도로 다시 계산한다.

---

**⑧ 시험 전에 채울 기록표**

| 항목 | 적을 내용 |
| --- | --- |
| 대상 | 채널, 센서 포함 여부, 회로/펌웨어 버전 |
| 요구 | 범위, 허용 오차 식, 결과 주기, 응답 시간, 제안/채택 여부 |
| 조건 | 전원, 주위 온도, 입력값, PWM, ADC 클록·획득·수집률·채널 순서·평균 |
| 기준 | 계기·범위·모드·불확도 근거, 동일 측정량/시간 구간 여부 |
| 보정 | 영점·감도 계수, 보정에 사용한 점, 독립 검증점, calibration_id |
| 결과 | 원시 로그 경로, 단위, 관측 차이, 불확도, 판정과 제외 범위 |

**이 절의 도착점:** 시험 대상과 비교 기준을 문장으로 설명할 수 있고, 근거가 부족할 때 보류할 수 있다. 실제 값과 조건을 채우지 않은 지금의 실물 시험 상태는 **NOT_RUN**이다.
