# 2-5. 측정 오차 예산과 보정

2026-10-25. [2-3·2-4 수집·평균·PWM 노트](12_ADC_Sampling_Cadence_Averaging_and_PWM_ko.md)에서 이어지는 필기 자료다. 전류 한 채널을 예로 들어 설명한다. 수치 목표는 제안 상태이며, 아래 가상 보정값과 예산 배분 예시는 실측값·제조사 보증·채택 설계가 아니다.

**이번 질문:** 전류를 허용 오차 안에서 읽으려면 측정 경로 전체에 얼마만큼의 오차를 허용할 수 있고, 보정 후 무엇을 확인해야 하는가?

---

**① 측정 오차와 목표부터 정한다**

참값은 정확히 알 수 없으므로 실제 시험에서는 불확도를 가진 기준 계기로 비교한다. 관측한 차이는 `우리 측정값 - 기준 계기 값`이다. 예를 들어 기준이2.00A, 우리 값이2.12A라면 차이는+0.12A다. 이 차이가 곧 참값에 대한 오차로 완전히 확정되는 것은 아니다.

[요구 초안](../../09_Electrical_Design/15_Expansion_PCB_Requirements_2026-10-23_ko.md)의 전류 목표:

- 정확도 검토 우선 구간−10~+10A, 채널별 영점·감도 보정 후, 초기 주위20~30°C.
- 허용 오차 크기 `max(0.20A, 0.05 × |읽음값|)`.
- 두 항을 더하지 않고 큰 쪽을 택한다. 읽음값 절댓값4A에서 두 항이0.20A로 같아진다.

| 읽음값 예 | 읽음값 절댓값의5% | 허용 오차 목표 |
| --- | --- | --- |
| 0A | 0A | ±0.20A |
| 1A | 0.05A | ±0.20A |
| 4A | 0.20A | ±0.20A |
| 5A | 0.25A | ±0.25A |
| −10A | 0.50A | ±0.50A |

초안은 읽음값 기준이며 시험 시 임의로 기준 계기 값 기준으로 바꾸지 않는다. 기준 계기의 불확도를 포함한 최종 합격 규칙은3장 검증 계획에서 정한다. 안정된 입력의 정확도와300ms 응답 목표는 별개로 확인한다.

---

**② 전류 목표를 입력 환산 전압으로 바꾼다**

Pololu #5241의 명목 영점은1.65V, 감도는44mV/A다. 감도는 전류가1A 변할 때 출력 전압이44mV 변한다는 뜻이다. 이상적 선형 관계는 `V = V0 + S×I`, 역환산은 `I = (V-V0)/S`다.

전류 오차0.20A에 대응하는 전압:

```text
전압 오차 = 전류 오차 × 감도
          = 0.20A × 44mV/A
          = 8.8mV
```

따라서 저전류 구간의 전체 목표는 명목 감도로 환산하면±8.8mV다. 5A 읽음의±0.25A는±11mV, 10A 읽음의±0.50A는±22mV다. 실제 보정 감도가 달라지면 그 감도로 다시 환산한다.

**입력 환산 전압 오차**는 서로 다른 원인이 최종 전류값에 미치는 영향을 ADC 입력 전압의 오차처럼 같은 단위로 표현한 것이다. ADC 기준 전압 오차처럼 핀의 실제 전압이 변하지 않는 원인도 이 단위로 비교할 수 있다. ±8.8mV는 각 부품마다 따로 주는 한도가 아니다.

---

**③ 여러 오차가 하나의 최종 결과에 합쳐진다**

```text
전류 → 센서 → 저항·배선·보호 → ADC → 보정·평균·환산 → 전류 결과
       영점/감도    누설/GND     기준/변환    잔차/리플/반올림
```

| 오차 원인 | 결과에 미치는 영향 | 확인 방법의 방향 |
| --- | --- | --- |
| 센서 영점·감도·비선형성 | 무전류에서도 값이 뜨거나 전류 크기에 따라 차이가 달라짐 | 영점·감도 보정, 보정에 쓰지 않은 전류점 비교 |
| 입력 저항과 누설·GND 차이 | 센서 기준 전압과 ADC가 보는 전압이 달라짐 | 입력 전압/온도별 잔차, 배선·접지 검토 |
| ADC 획득·변환·기준 전압 | 내부 충전 부족, 코드 오차, 전압 환산 비율 오류 | 전압 대입, 실제 수집 순서/주기와 기준 전압 검토 |
| 리플·잡음·에일리어싱 | 변동 또는 한쪽으로 치우친 결과 | PWM 조건과 수집 위상별 관측 |
| 보정 기준과 연산 | 기준값의 오차가 보정 계수로 전달되거나 반올림 잔차 발생 | 기준 계기 불확도, 계수 저장/단위/연산 점검 |
| 온도·시간 변화 | 보정 당시와 다른 영점·감도·누설 | 사용 조건에서 보정 후 변화 확인 |

이 표는 원인 지도다. 온도 변화는 센서·입력·ADC 항목에 각각 포함될 수 있으므로 숫자 합산에서는 중복을 제거한다. 전류센서는 nonratiometric 출력이므로 NTC의 공통 여기/기준 전압 비율 상쇄를 그대로 적용하지 않는다.

---

**④ 오차 예산은 전체 한도를 항목별로 나누어 관리하는 방법이다**

같은 조건에서 각 항목의 오차 크기가 각각E1, E2, … 이하로 제한된다면, 보수적인 합산은 `전체 오차 크기 ≤ E1+E2+…`다. 서로 상쇄할 것을 전제로 최대 오차를 줄이지 않는다.

아래는 **배분 방법만 보여주는 임의 예시**다. 해당 수치를 실제로 달성했다는 자료도, 이 배분을 채택한 결정도 없다.

| 보정 후 확인할 항목 | 설명용 전압 환산 한도 |
| --- | ---: |
| 센서·보정 기준의 잔차와 해당 온도 변화 | 3.0mV |
| 입력 누설·배선/GND 등 입력 경로 잔차 | 2.0mV |
| ADC·기준 전압·양자화·환산 잔차 | 1.5mV |
| 처리 후 PWM 리플·잡음 영향 | 1.0mV |
| 설계 여유 | 1.3mV |
| 합계 | 8.8mV |

개별 항목이8.8mV보다 작다는 것만으로 전체 목표를 만족하지 않는다. 예를 들어 서로 다른 항목의4mV와6mV가 같은 방향이면10mV이므로8.8mV보다 크다.

실제 예산표에는 항목별 근거(데이터시트/모델/측정), 사용 조건, 보정 전·후 구분, 아직 모르는 값이 필요하다. 모르는 항목을0으로 넣지 않는다. 랜덤 잡음은 최대값과 RMS/표준편차의 의미가 다르므로 같은 열에 섞어 더하지 않는다. 독립성·분포·신뢰 수준 근거 없이 제곱합의 제곱근으로 합계를 낮추지 않는다.

ADC 총오차 사양을 사용했다면 그 사양에 이미 포함된 영점·이득·비선형 오차를 다시 더하지 않는다. 시스템 오차 합산과 데이터시트 TUE의 정의를 구분한다.

---

**⑤ 영점 보정은 무전류일 때의 기준을 맞춘다**

이하 값은 모두 가상의 계산 예시다. 사용자가 전류를 흘리라는 실물 지시가 아니다.

명목 환산식:

```text
I = (측정 전압 - 1.650V) / (0.044V/A)
```

실제0A라는 조건에서 측정 경로가1.658V를 보고한다고 가정하면:

```text
보정 전 표시 = (1.658-1.650)V / (0.044V/A)
             ≈ 0.182A
```

이때 확인된 무전류 값1.658V를 영점 V0_cal로 사용하면 같은 조건의0A가0A로 환산된다.

```text
I = (측정 전압 - 1.658V) / (0.044V/A)
```

전류가 흐르는 상태에서 임의로 현재 값을 영점으로 저장하면 실제 전류까지 지워진다. 보정 당시 무전류임을 확인해야 한다. 좌우 채널의 편차가 같다고 가정하지 않는다.

---

**⑥ 감도 보정은 전류 증가에 대한 전압 증가 비율을 맞춘다**

같은 가상 예시를 이어서, 기준0A에서1.658V이고 기준5A에서1.883V라면:

```text
감도 S_cal = 전압 증가량 / 전류 증가량
           = (1.883-1.658)V / (5-0)A
           = 0.225V / 5A
           = 0.045V/A = 45mV/A
```

이 측정 경로에서는44mV/A 대신 확인한45mV/A로 환산하는 것이다.

```text
I_cal = (측정 전압 - V0_cal) / S_cal
      = (측정 전압 - 1.658V) / (0.045V/A)
```

1.883V를 대입하면5A다. 보정한 두 점을 맞추는 것은 식을 만든 결과이므로 다른 전류·온도에서의 정확도 증명이 아니다.

이 보정은 안정된 조건에서 센서뿐 아니라 그 뒤 측정 경로의 고정된 영점·비율 오차 일부도 함께 흡수할 수 있다. 특정 MCU의 자동 ADC 교정 기능이 존재한다는 주장과는 별개인 시스템 보정 방법이다. 실제 계수는 ADC code 단위로 저장할 수도 있다.

---

**⑦ 보정 후에도 남는 오차를 확인한다**

위의 보정식을 그대로 사용하면서 보정에 사용하지 않은 기준2.00A를 측정했을 때1.751V를 얻었다고 가정하자.

```text
I_cal = (1.751-1.658)V / (0.045V/A)
      ≈ 2.067A
기준과의 차이 ≈ +0.067A
```

차이는 남아 있다. 이 수치만으로 그 원인을 비선형성이나 잡음 하나로 특정할 수는 없다. 기준 계기 불확도까지 고려한 판정도 별도로 필요하다.

영점·감도 보정으로 전부 없어지지 않는 것:

- 두 보정점을 잇는 직선에서 벗어나는 비선형성.
- 보정 이후 온도·전원·기준 전압·누설의 변화.
- 리플/에일리어싱과 잡음, 획득 부족·채널 간 영향.
- 기준 계기의 오차와 보정 계수 계산/저장 잔차.

현재 센서는 출력이 공급 전압에 비례하지 않으므로 ADC 기준 전압 변동을 자동 상쇄하지 않는다. 전압 환산은 대략 `V_est = code/4096 × 사용한 Vref 값`이므로 실제 Vref와 소프트웨어가 사용한 값의 차이를 관리해야 한다. 보정 시 고정된 오차가 흡수되어도 이후 변화까지 제거되지는 않는다.

---

**⑧ 현재 R1·ADC·리플 계산을 같은 단위로 비교한다**

12kΩ 저항을 지나는 누설 전류 크기를1µA로 놓은 기존 한계 모델:

```text
|전압 차이| = 1µA × 12kΩ = 12mV
|전류 환산 차이| = 12mV / (44mV/A) ≈ 0.273A
```

ST 데이터시트의 I/O 누설 조건 VSS≤VIN≤VDD, 풀업/풀다운 비활성 등의 적용 조건을 확인해 사용한 단순 모델이다. 실제 보드의20~30°C 누설 실측이나 보정 후 잔차가 아니다. 일정한 부분은 보정으로 줄일 여지가 있지만 변화분은 남을 수 있다. 반복 평균이나 C 증가로 일정한 DC 전압 차이를 없앨 수 없다.

이상적12bit·기준3.3V에서:

```text
1LSB = 3.3V / 4096 ≈ 0.8057mV
전류 한 칸 = 0.8057mV / (44mV/A) ≈ 0.01831A
```

한 칸의 크기는 분해능이다. 전체 정확도를±0.01831A로 보증하지 않는다. 양자화만의 이상적±0.5LSB 모델과 ADC 전체 오차도 서로 다르다.

2-4의 가상 리플: RC 앞19kHz 진폭100mV, 이상적 감쇠0.00698이면 RC 뒤 진폭은0.698mV다. 전류 환산 진폭은 `0.698mV / (44mV/A) ≈ 0.0159A`다. 샘플 위상에 따라 이 크기의 일부가 치우침이나 느린 변동으로 나타날 수 있다. 실제 리플·총오차의 측정값은 아니다.

| 기존 수치 | 전류 환산 | 의미 |
| --- | ---: | --- |
| 전체 저전류 목표8.8mV | 0.20A | 제안 허용 오차 크기 |
| 누설 모델12mV | 약0.273A | 보정 전 한계 조건의 단순 계산 |
| ADC1LSB 약0.8057mV | 약0.01831A | 분해능 |
| 가상 필터 후 리플 진폭0.698mV | 약0.0159A | 설명용 단일 성분 진폭 |

조건과 의미가 다른 이 네 숫자를 그대로 더해 실제 전체 오차로 선언하지 않는다. 최종 합산에는 같은 조건의 보정 후 잔차와 겹치지 않는 항목이 필요하다.

---

**⑨ 다음 판단에 필요한 결과**

전류 목표를 전압으로 환산하는 기준과 보정 방법을 설명했다. 아직 센서/입력/ADC/기준/리플의 보정 후 잔차가 모두 확보되지 않았으므로 예산 충족이나12kΩ 확정을 선언하지 않는다.

다음은 고정한 목차의 마지막인 **2-6. R·C와 ADC 설정 후보 종합 판단**이다. 필터 감쇠·응답·획득·반복 수집·누설·오차 예산을 같은 표에서 연결한다. 이후3장 검증 계획으로 넘어간다.
