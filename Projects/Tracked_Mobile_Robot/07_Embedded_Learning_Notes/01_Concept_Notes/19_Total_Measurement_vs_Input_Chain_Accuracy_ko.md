# TMR 학습 노트 · 3-1 보충: 전체 측정 정확도와 입력 회로 정확도 구분

작성: 2026-10-27 · **3-1의 보충 설명**이며 새 3-5장이 아니다. 3장은 기존 3-1~3-4 네 편을 유지한다. 아래 시험 숫자는 **명목 계산 또는 가상 예시**다. 실제 시험 결과가 아니며 현재 상태는 **NOT_RUN**이다.

전체 측정 정확도는 **실제 물리량을 최종 결과까지 얼마나 잘 읽었는가**, 입력 회로 정확도는 **센서가 만들어줄 전기 신호를 센서 대신 넣었을 때 그 뒤의 경로가 얼마나 잘 읽는가**를 묻는다.

시험의 시작점이 다르므로, 한쪽의 통과를 다른 쪽의 통과로 대신할 수 없다.

## 1. 왜 두 가지를 나누는가

기준 전류계에는 2.00A, 우리 장치에는 2.20A가 표시됐다고 가정하자. 우선 확인한 사실은 두 장치의 표시가 0.20A 다르다는 것이다. 이것만으로 어느 부품이 원인인지 알 수는 없다.

전류센서가 전류를 전압으로 바꾸는 단계에서 차이가 생겼을 수도 있고, 입력 저항·배선·ADC·기준 전압·보정 계수에서 생겼을 수도 있다. PWM 전류를 서로 다른 시간 구간이나 평균/RMS로 비교했다면 애초에 비교하는 측정량이 다를 수도 있다.

그래서 **센서 뒤쪽을 먼저 분리해서 시험하고, 센서를 포함한 전체 경로를 다시 시험한다.** 앞 시험은 원인을 좁히는 데 필요하고, 뒤 시험은 실제 사용 목적을 확인하는 데 필요하다.

기준 계기 역시 오차와 불확도가 있다. 이 문서에서 '기준값'은 조건과 불확도를 확인한 비교값이지, 완벽하게 알고 있는 참값이라는 뜻이 아니다.

## 2. 먼저 전체 경로를 그려보자

현재 전류 모니터링 설계는 다음 흐름으로 이해할 수 있다.

```text
실제 전류 [A]
  ↓
전류센서: 전류 → 전압
  ↓
센서 출력 전압 [V]
  ↓
입력 회로: 배선·직렬 저항·커패시터·보호 회로
  ↓
ADC: 전압 → 디지털 코드
  ↓
전압/전류 환산·보정·평균
  ↓
전송·브라우저 표시 [A]
```

여기서 '회로만의 정확도'라는 표현을 **R과 C 두 부품만의 성능**으로 이해하면 범위가 너무 좁아진다. 이번 학습에서 더 정확한 이름은 **센서를 제외한 입력계의 정확도**다.

입력계에는 시험 시작점 이후의 배선·RC·보호·ADC와 기준 전압의 영향, 그리고 검사하는 출력까지의 환산 처리가 포함된다. 구현되지 않은 보호 부품이 이미 있다는 뜻은 아니다. 실제 시험 기록에는 그때 연결된 회로와 처리 버전을 적어야 한다.

브라우저를 결과 확인점으로 삼으면 단위 변환·반올림·전달 여부도 확인할 수 있다. 다만 화면에 숫자가 정상적으로 나온다는 사실만으로 전기적 정확도를 입증할 수는 없다. 갱신 지연은 정확도와 별도로 측정한다.

## 4. 입력계는 어디부터 시험하는가

현재 왼쪽 전류 채널 초안의 위치를 개념적으로 그리면 다음과 같다.

```text
정상 측정:
센서 출력 → J3.3 → R1 12kΩ → ● → PC0 ADC → 코드·환산
                              │
                           C1 100nF
                              │
                             GND

센서 제외 입력계 시험:
기준 전압원 → 정한 입력점 → 동일한 R1/C1 → PC0 ADC → 코드·환산
              ↑
       이 점의 기준 전압을 계측
```

입력계를 통째로 확인하려면 **확인하려는 입력 부품 앞에서** 전압을 대입해야 한다. 예를 들어 ADC 핀 쪽으로 R1을 우회해 넣었다면, 그 결과는 R1을 통과하는 전체 입력계 시험과 범위가 다르다. ADC 핀 쪽 기준 전압과 ADC 환산값을 비교하면 ADC 이후 경로를 좁혀 보는 데 사용할 수 있지만, 앞쪽 전압 강하를 검증한 것으로 기록하면 안 된다.

이 그림은 회로도상의 위치 설명이다. 시험용 실물 단자와 보호가 준비됐다는 뜻이 아니다. 실제 연결 시에는 센서 출력과 시험 전압원을 동시에 연결해 서로 구동하지 않도록 분리 방식·공통 GND·허용 입력·전원 순서를 확인해야 한다. 지금은 전원 투입이나 배선을 지시하는 절차가 아니다.

전압원의 전면 설정값도 그대로 기준으로 사용하지 않는다. **연결된 상태에서 정한 입력점의 전압**을 적합한 기준 계기로 측정하고, 그 계기의 불확도를 함께 기록한다.

ADC 정확도가 ADC 부품 하나만으로 결정되지 않고 주변 회로와 기준 전압 등의 영향을 받는다는 설명은 [ST AN2834](https://www.st.com/resource/en/application_note/cd00211314.pdf)와도 일치한다.

## 5. 입력계 시험의 숫자를 처음부터 계산해보자

### 5.1 왜 1.738V를 고르는가

선정한 Pololu #5241의 명목 특성은 무전류 출력 1.65V, 감도 44mV/A다. 감도는 **전류가 1A 변하면 출력이 44mV 변한다**는 뜻이다. [Pololu #5241 공식 사양](https://www.pololu.com/product/5241)

```text
V_sensor = V_zero + S × I

V_sensor : 센서의 명목 출력 [V]
V_zero   : 명목 0A 출력, 1.65V
S        : 명목 감도, 0.044V/A
I        : 모사하려는 전류 [A]

I = 2A라고 놓으면
V_sensor = 1.65V + 0.044V/A × 2A
         = 1.738V
```

즉 **1.738V는 명목 2A에 해당하는 신호를 모사하기 위해 고른 전압**이다. 이 전압을 대입했다고 실제 센서나 모터에 2A가 흐른 것은 아니다. 명목 영점·감도도 실제 개별 센서를 측정한 보정값과 구분한다.

### 5.2 우리 장치가 1.742V로 읽었다면

다음 값은 전부 설명용 가정이다.

| 항목 | 가정한 값 |
| --- | ---: |
| 정한 입력점에서 기준 계기로 확인한 전압 | 1.738V |
| ADC 코드와 정한 처리 방식으로 환산한 전압 | 1.742V |
| 입력계의 관측 차이 | +0.004V = +4mV |

```text
e_input = V_read − V_input_ref
        = 1.742V − 1.738V
        = +0.004V = +4mV

V_read      : 우리 장치가 환산한 전압 [V]
V_input_ref : 입력점의 기준 전압 [V]
e_input     : 센서 제외 입력계에서 관측한 차이 [V]
```

여기서 알 수 있는 것은 **이 조건에서 입력계가 기준보다 4mV 높게 읽었다**는 사실이다. 실제 센서의 정확도는 아직 시험하지 않았다. 기준 계측과 비교 과정의 불확도도 남아 있으므로, 이 4mV를 모든 조건에서의 확정 오차로 취급하지 않는다.

### 5.3 이 차이가 전류 표시에는 얼마나 영향을 주는가

같은 명목 감도를 적용하면 다음과 같다.

```text
전류로 환산한 차이
= 4mV ÷ 44mV/A
≈ 0.0909A
≈ 90.9mA
```

이 값은 **입력계의 4mV 차이를 전류 단위로 표현한 것**이다. 센서 포함 전체 전류 오차를 직접 측정한 값이 아니다. 전류 환산에 실제 보정 감도 S_cal을 사용한다면 이 계산에도 S_cal을 적용해야 한다.

## 6. 센서 포함 전체 시험은 무엇을 비교하는가

이번에는 실제 센서를 사용한다. 기준 계기로 같은 경로의 전류를 확인하고 우리 장치의 전류 결과와 비교한다.

```text
센서가 실제로 측정하는 전류
  → 센서 출력
  → R/C·ADC
  → 보정·환산
  → 우리 장치의 전류 결과
```

**별도의 가상 예시:**

```text
I_ref  = 2.00A   : 기준 전류 계측
I_read = 2.12A   : 우리 장치의 최종 전류 결과

e_total = I_read − I_ref
        = 2.12A − 2.00A
        = +0.12A
```

이 +0.12A에는 센서와 입력계, 적용한 처리 경로의 영향이 함께 반영된다. 센서 뒤를 통과하는 전압의 오차도 전류 단위로 환산되어 최종 결과에 들어간다.

5절의 +0.0909A와 여기의 +0.12A를 빼서 **'센서만의 오차는 +0.0291A'라고 단정하면 안 된다.** 서로 별개인 설명 예시이고, 실제로도 입력 조건·전원·부하·보정·시간이 동일한지 먼저 확인해야 하기 때문이다. 최대오차나 불확도 크기를 단순히 빼서 센서 성능을 분리할 수도 없다.

센서 자체의 출력을 더 좁혀 확인하려면 기준 전류와 센서 출력 전압을 함께 측정하고 영점·감도·부하 조건을 대조하는 별도 시험이 필요하다.

## 7. 결과 조합으로 어디를 더 살펴볼 수 있는가

| 입력계 시험 | 전체 시험 | 해석 |
| --- | --- | --- |
| 기준 만족 | 기준 만족 | 두 범위가 각각 시험한 조건에서 만족. 다른 온도/PWM 조건은 별도 |
| 기준 만족 | 기준 미달 | 센서·센서 부하·전원/GND·온도·보정·비교 방법을 추가 확인. 센서 불량으로 즉시 단정하지 않음 |
| 기준 미달 | 기준 미달 | 입력계 문제부터 좁혀볼 근거가 있음. 센서 정상 여부는 아직 모름 |
| 기준 미달 | 기준 만족 | 오차 상쇄, 전체 보정 효과, 시험 조건 차이 가능. 입력계 개별 요구 충족으로 바꾸면 안 됨 |

서로 다른 오차가 반대 방향이면 전체 숫자가 우연히 잘 맞을 수 있다. 전체 보정으로 특정 조건의 오프셋이 줄어들 수도 있다. 그러므로 전체 결과가 좋다는 이유만으로 각 단계의 요구가 모두 충족됐다고 말하지 않는다.

전압원과 실제 센서는 출력 임피던스와 부하 구동 능력이 다를 수 있다. 전압원으로 안정된 DC를 잘 읽은 결과는 실제 센서를 붙였을 때의 샘플링 충전·PWM·동적 안정성 시험을 대신하지 않는다.

## 8. 허용 오차도 각각 따로 정해야 한다

기존 전류 전체 경로의 제안 목표는 다음과 같다.

```text
T_total = max(0.20A, 0.05 × |I_read|)
```

I_read는 **우리 장치의 읽음값**이다. 2.12A라면 5%는 0.106A이고, 둘 중 큰 값인 0.20A를 제안 허용치로 선택한다. 이 목표는 아직 검토 제안이며 실측 성능이 아니다. [Notion 3-1 검증 대상과 합격 기준](https://app.notion.com/p/404a7326f87b81b7bf78c03a54178726)

명목 감도 44mV/A로 저전류 허용치 0.20A를 전압으로 바꾸면:

```text
0.20A × 44mV/A = 8.8mV
```

**8.8mV는 전체 경로의 오차를 입력 전압으로 환산해 본 값**이다. 입력 회로 한 부분에 8.8mV를 전부 허용해도 된다는 결정이 아니다. 센서·입력계·기준 전압·보정 후 잔차 등 여러 항목에 어느 정도를 배분할지 따로 정해야 한다.

따라서 입력계는 T_input이라는 별도 허용치를 정한다. 기존 자료의 2mV 배분 등은 설명 예시이며 채택된 요구가 아니다. **T_input을 아직 정하지 않았다면 +4mV를 측정했다고 정확도 PASS를 붙이지 않고, 잔차와 조건을 먼저 기록한다.**

허용 오차는 설계 요구이고, 시험 불확도는 우리가 비교 결과를 얼마나 확실히 아는지에 관한 것이다. 둘을 같은 것으로 합치지 않는다.

## 9. 기준 계기의 불확도까지 고려하면

기존 3-1에서는 다음 판정 방식을 제안했다. d는 같은 측정량·시간 구간의 관측 차이, U_test는 비교 과정의 불확도, T는 해당 시험 범위의 허용치다. 세 값은 같은 단위로 계산한다.

```text
PASS         : |d| + U_test ≤ T
FAIL         : |d| − U_test > T
INCONCLUSIVE : 그 사이, 허용 경계와 불확도 구간이 겹침
```

**가상 예시:** I_ref=2.00A, I_read=2.12A, U_test=0.03A라고 가정하면:

```text
관측 차이 크기 = 0.12A
허용치 T_total = 0.20A
0.12A + 0.03A = 0.15A ≤ 0.20A
→ 제안 규칙에 따라 해당 점은 PASS
```

U_test=0.03A는 실제 계기의 확인된 성능이 아니다. 설명을 위한 가정이다. 입력계의 전압 시험에는 전압 단위의 차이·불확도·허용치를 사용해야 한다.

기준 계기의 범위·모드·정확도 사양·반복성·시간 정렬 등을 확인하고 불확도의 계산 근거와 포함 수준을 남겨야 한다. 위 판정도 선택한 불확도 수준에 따른 결정이며 오류 가능성이 0이라는 보증은 아니다. 상세한 불확도 해설은 기존 3-1을 따른다. [Notion 3-1 검증 대상과 합격 기준](https://app.notion.com/p/404a7326f87b81b7bf78c03a54178726)

## 10. 온도와 전압에서는 어떻게 나뉘는가

### 10.1 NTC 온도

```text
실제 온도 측정:
모터 케이스의 온도 → 부착한 NTC의 저항
  → 분압·필터·ADC → 온도 환산

입력계 시험:
NTC 대신 정밀 저항 → 동일한 분압·필터·ADC → 온도 환산
```

정밀 저항을 넣는 이유는 **'NTC가 특정 온도에서 이 저항값을 만들었다고 가정했을 때, 뒤 회로와 계산이 올바른 온도를 내는가'**를 확인하기 위해서다. 적용하는 저항-온도 표/식과 저항의 실제 값·불확도를 함께 기록한다.

이 시험에는 실제 NTC의 개체 편차, 자가발열, 모터와의 접촉 상태, 케이스와 센서 사이의 열 지연이 포함되지 않는다. 따라서 기존 온도 목표의 입력계 ±1°C를 모터 실제 온도의 전체 정확도 ±1°C로 바꾸면 안 된다. 이 프로젝트의 저항 대입/센서 포함 구분은 3-2에 정리되어 있다. [Notion 3-2 정확도와 보정 검증](https://app.notion.com/p/404a7326f87b81e9adeed4f4edd952d1)

모터 케이스 온도를 측정해도 권선 내부 온도를 직접 측정한 것은 아니다. 실제 부착 시험의 기준 프로브도 같은 위치·열평형·측정 시점을 고려해야 한다.

### 10.2 버스 전압

버스 전압은 별도 전류센서 같은 변환 소자 없이 분압 회로가 전압을 ADC 범위로 바꾼다. 따라서 이름보다 **시험 시작점**으로 범위를 나누는 것이 더 정확하다.

| 시작점 | 포함되는 범위 | 제외되는 범위 |
| --- | --- | --- |
| 버스 전압 입력점 | 입력 보호·분압·필터·ADC·버스 전압 환산 | 시험하지 않은 과도/환경 조건 |
| 분압 뒤 ADC 쪽 | 그 지점 이후의 ADC·환산 경로 | 앞쪽 분압 저항 비율·보호·배선의 영향 |

전체 버스 전압 정확도를 확인하려면 확정된 분압·보호 회로의 앞에서 입력을 주고 같은 버스 입력점의 기준값과 비교해야 한다. 0~16V라는 목표는 버스 쪽 범위이며 ADC 핀에 직접 넣는 전압 범위가 아니다. 현재 전압 2채널 회로는 미완료이므로 실제 연결 시험을 시작하지 않는다.

## 11. 보정과 검증, 안정성과 정확도를 혼동하지 말자

- **1.65V를 넣어 0A로 표시되게 조정:** 입력계/환산을 그 점에 맞춘 것. 실제 센서의 0A 출력 측정과 다르다.
- **실제 센서에 기준 전류를 흘려 영점·감도 계수 계산:** 센서 포함 경로를 그 조건에 맞춘 것. 다른 입력에서의 정확도는 독립 검증점으로 확인한다.
- **값이 거의 흔들리지 않음:** 반복성/산포에 관한 관측. 일정하게 틀린 값도 안정적으로 표시될 수 있다.
- **평균을 늘려 흔들림 감소:** 일정한 오프셋·기준 전압 오차·감도 오차가 자동으로 없어지는 것은 아니다.
- **PWM에서 기준 계기와 비교:** 같은 평균 전류인지 RMS인지, 같은 시간 구간인지 먼저 맞춘다. DC 통과를 PWM 조건 통과로 확대하지 않는다.
- **보정점에서 값이 맞음:** 계수를 만든 점에 맞는 것은 독립 검증이 아니다. 보정에 사용하지 않은 점과 다른 조건의 잔차를 확인한다.

입력계 보정과 전체 경로 보정을 연달아 적용할 때 같은 오프셋/이득을 두 번 보정하지 않도록, 계수가 어디에 적용되는지와 버전을 함께 남긴다.

## 12. 필기에 남길 결론과 다음 작업

> 전류 전체 시험은 전류를 기준으로 비교한다. 입력계 시험은 센서 대신 넣은 전압을 기준으로 비교한다. 같은 최종 전류 단위로 표시하더라도 시험의 시작점이 다르면 검증한 범위가 다르다.

작성 당시에는 다음 표의 미정을 채우는 것이 다음 작업이었다. 이후 명세22/23에서 시험용 입력계 예산·시험점을 정했으므로 아래 표는 당시의 검토 항목으로 읽는다. 현재 다음 설계는 전원/보호 미결과 전압2채널이며 실물 시험을 시작한 상태가 아니다.

| 기록 항목 | 입력계 시험 | 센서 포함 전체 시험 |
| --- | --- | --- |
| 시작점과 포함 부품 | 회로도에서 대입점·R/C·ADC 경로 확정 | 센서 전류 경로부터 결과까지 확정 |
| 입력/기준 계기 | 전압 입력원·기준 전압 계측 | 전류 경로·기준 전류 계측 |
| 설정/조건 | 전원·기준 전압·ADC·평균·온도 | 같은 항목 + 센서 부하·PWM·실제 전류 정의 |
| 보정/독립 검증점 | 전압 대입 보정과 별도 확인점 | 센서 포함 보정과 별도 확인점 |
| 허용치 | T_input 미정, 배분 검토 필요 | 기존 T_total 제안의 채택/조건 검토 |
| 결과 기록 | 전압 잔차·산포·불확도·판정 | 전류 차이·산포·불확도·판정 |
| 현재 상태 | NOT_RUN | NOT_RUN |

이 보충 문서를 작성한 것으로 요구 채택·부품 확정·사용자 학습 완료·실물 PASS를 표시하지 않는다. 현재 작업 순서는 최신 인수인계와 명세22/23을 따른다.

## 13. 센서 자체의 정확도는 별도의 기준으로 확인한다

10/28 마감 보충. 입력계 시험과 전체계 시험 사이에 **센서 단독 시험**을 구분한다.

| 확인 범위 | 실제 비교 | 포함되는 주요 영향 |
| --- | --- | --- |
| 전류센서 단독 | 기준 전류와 센서 출력 전압의 관계 | 센서 영점/감도·출력 부하·온도/공급·자계, 기준 전류/전압 계측 |
| NTC 단독 | 안정·균일한 기준 온도와 실제 NTC 저항 | 실제 RT 곡선·자가발열·열평형/구배, 기준 온도/저항 계측 |
| 센서를 제외한 입력계 | 알려진 전압/저항 대입과 MCU 환산 결과 | 분압/RC·ADC 기준/누설·수집/환산 |
| 센서 포함 전체계 | 실제 전류/표면 온도 기준과 최종 표시 | 센서+입력계, 설치/접촉/배선·시간 대응 |

전류센서는 입력 회로 앞 출력 전압을 적합한 기준기로 직접 읽고 기준 전류와 대조한다. NTC는 적합한 온도 환경에서 낮은 자가발열 조건으로 저항을 읽어 제조사 RT와 비교한다. 보정 전/후를 구분하고 보정에 사용하지 않은 점에서 확인한다. 기준기는 참값 자체가 아니므로 각 계측의 오차 경계/불확도와 조건을 남긴다.

**전체 오차에서 허용 입력계 오차를 빼서 센서 오차를 구할 수는 없다.** 같은 조건에서 분리 측정한 잔차와 기준 경로의 경계가 필요하다. 온도는 센서 자체 편차와 모터 부착 후의 접촉·위치·열지연도 구분한다.

현재 [전류 명세22](../../09_Electrical_Design/22_Current_Channel_Verification_Spec_2026-10-27_ko.md)·[온도 명세23](../../09_Electrical_Design/23_Temperature_Channel_Verification_Spec_2026-10-27_ko.md)는 입력계/전체계 시험 설계를 구체화한 문서다. 센서 단독 시험은 방법·필요 기준을 보충했으며 다점 조건·치구/기준기·합격 경계가 확정된 실행 명세는 아니다. 실제 시험은 모두 NOT_RUN이다.
