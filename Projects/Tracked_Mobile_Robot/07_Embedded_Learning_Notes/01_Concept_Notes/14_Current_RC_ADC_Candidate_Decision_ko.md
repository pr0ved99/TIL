# 2-6. R·C와 ADC 설정 후보 종합 판단

2026-10-25. [2-5 오차 예산·보정](13_Current_Measurement_Error_Budget_and_Calibration_ko.md)에 이어지는2장의 마지막 필기다. 전류 입력 R1/C1(오른쪽 R2/C2)을 종합한다. 다음은3장 검증 계획이며2-x 항목을 더 늘리지 않는다.

**현재 판단:** 12kΩ/100nF와 ADC14MHz·12bit·480cycles를 비교·검증 후보로 유지한다. 필터와 시간 계산만으로 보정 후 정확도나 최종 부품을 확정하지 않는다. DC 입력계 검증의 첫 비교 조건으로 채널별100Hz·100ms 블록10개 평균을 제안한다. 운용 수집률/평균 채택이나 MCU 설정 변경은 아니다.

---

**① 전체 측정 경로에 맞춰 판단한다**

```text
모터 전류 → 센서 출력 → R1/C1 → ADC 획득·변환
         → 일정 간격 수집 → 평균·보정 → 전류 결과
```

부품 하나의 계산이 성립하는 것, 여러 동작을 정해진 시간 안에 배치할 수 있는 것, 완성 측정값이 허용 오차 안에 드는 것은 서로 다른 판단이다. 한 항목이 성립했다고 다음 항목까지 확인된 것으로 기록하지 않는다.

[현재 요구 초안](../../09_Electrical_Design/15_Expansion_PCB_Requirements_2026-10-23_ko.md): 정확도 우선 구간−10~+10A, 채널별 영점·감도 보정 후·주위20~30°C에서±max(0.20A, 읽음값 절댓값의5%). 전류 결과100ms마다, 안정된 입력을300ms 이내 허용 오차 범위로 반영하는 제안이다. 44mV/A 명목 감도에서 저전류 전체 예산은8.8mV다. 목표 채택/실측 달성은 아직 아니다.

---

**② 현재 전류 RC의 장점과 한계를 같은 표에서 본다**

| 판단 항목 | 기존 계산 | 현재 해석 |
| --- | --- | --- |
| 시정수 | 12kΩ×100nF=1.2ms | 변화에 따라가는 시간 척도 |
| 차단 주파수 | 1/(2πRC)≈132.63Hz | 차단 주파수에서도 진폭 약70.7%가 남는1차 필터 |
| 19kHz 단일 정현파 감쇠 | 진폭 약0.00698배 | PWM 관련 고주파 성분을 줄일 계산 근거 |
| 계단 입력의 변화량1% 잔차 | 약5.53ms | RC만의 응답, 전체 전류 허용 오차/300ms 판정과 별개 |
| 입력 누설1µA 가정 | 12mV, 약0.273A 환산 | 미보정 한계 모델, 실제 보정 후 잔차는 미확인 |
| 센서 출력의 복합 RC 부하 | 직렬12kΩ 뒤100nF | 직접100nF와 다르지만 출력 안정성 확인 필요 |

19kHz 감쇠율은 주파수 성분의 비율이지 실제 남는 전압의 절댓값이 아니다. 예를 들어 필터 앞 진폭100mV를 가정해야 뒤0.698mV, 약0.0159A라는 계산을 할 수 있다. 실제 리플의 진폭·고조파는 미측정이다.

99% 응답 역시 변화량 기준이다. 설명용4A 계단 변화의1%는0.04A다. 이 계산은 모든 오차를 포함한 정확도 보증이 아니다. 실물 R/C 허용오차와 온도/바이어스 영향까지 확정한 값도 아니다.

---

**③ 저항을 줄이는 방법에는 다른 조건이 따른다**

같은 누설 전류 크기에서 저항이 작아지면 `|전압 차이|=|누설 전류|×R`가 작아진다. 그러나 R만 줄이면RC가 작아져 필터의 차단 주파수가 높아지고19kHz 감쇠가 약해진다. 센서가 커패시터를 충전할 때의 출력 부하도 달라진다.

한계를 분명히 보기 위해 **보정 없이1µA가 흐르며 전체8.8mV를 누설에 모두 쓸 수 있다고 가정**하면:

```text
R ≤ 허용 전압 차이 / 누설 전류
  = 8.8mV / 1µA
  = 8.8kΩ
```

다른 오차까지 있으면 이 가정의 허용 저항은 더 작아져야 한다. 따라서12kΩ을 미보정1µA 조건에서 단순히 충분하다고 말할 수는 없다. 이 계산은 보정 후 잔차 조건으로12kΩ이 반드시 실패한다는 의미가 아니다.

Allegro ACS71240 Rev16 p.8은 출력에서GND로의 저항 부하 최소10kΩ, 직접 용량 부하 최대4.7nF를 제시한다. 이것이 직렬 저항을 반드시10kΩ 이상 쓰라는 직접 규정은 아니다. 직렬 RC는 주파수에 따라 센서가 보는 부하가 달라지며, 고주파에서 임피던스가 직렬 R에 가까워진다. 따라서R을 줄인 안도 해당 부하 조건과 출력 안정성을 다시 확인해야 한다. 현재12kΩ도 복합 RC 안정성의 보증을 받은 것은 아니다.

판단 방향은 현재 회로의 보정 후 잔차를 확보하고, 부족하면 센서 출력 구동 조건까지 포함해R/C 변경 또는 버퍼 등 입력 구조 변경을 비교하는 것이다. 이번 단계에서 새 부품 구매/버퍼 채택을 결정하지 않는다.

---

**④ C를 늘리거나 획득 시간을 늘려도 모든 오차가 줄지는 않는다**

| 조정 | 기대 효과 | 함께 달라지거나 남는 문제 |
| --- | --- | --- |
| R 감소, C 유지 | 동일 누설의 전압 차이 감소 | 고주파 감쇠 약화, 센서 부하 변화 |
| C 증가, R 유지 | 고주파 감쇠 강화, 단일 전하 공유 교란 감소 | RC 응답 느려짐, 회복 시정수 증가, DC 누설 차이는 유지 |
| R 감소·C 증가로RC 유지 | 이상적 필터 주파수/계단 응답 유지, 동일 누설의 전압 차이 감소 | 센서 부하·ADC 전하 교환 동작은 같지 않으므로 재검토 |
| ADC 획득 시간 증가 | 내부 샘플링 C가 입력을 따라갈 시간 확보 | 처리 시간 증가, DC 누설·기준 전압·alias를 자동 제거하지 않음 |

큰 C는 한 번 생기는 전압 교란을 줄이는 효과와 회복을 느리게 하는 효과가 함께 있다. 반복 오차를 한쪽 효과만으로 판단하지 않는다. RC 곱이 같다고 ADC 앞 실제 회로의 모든 성질이 같은 것도 아니다.

---

**⑤ ADC14MHz·480cycles는 검증 후보로 유지한다**

[기존 획득 계산](../../09_Electrical_Design/KiCAD/TMR_Monitor_Shield_RevA/reports/current_adc_acquisition.json)은 외부 C를 생략한 모델과 외부 C의 단일 전하 공유 모델을 분리한다.

- 외부 C 없는 모델: 유효 획득 약1.23086µs가0.25LSB 잔차 조건에 필요했다.14MHz에서28cycles도 해당 모델 조건을 만족하며480cycles만 가능한 것은 아니다.
- 외부100nF 단일 전하 공유 모델: 노드 변화 약0.230984mV/0.2867LSB다. 모든 내부 전하 주입·최종 ADC 오차의 상한이 아니다.

480cycles 후보의 시간 계산:

```text
획득 시간 = 480 / 14,000,000초 ≈ 34.29µs
한 채널 획득+12bit 변환 = (480+12) / 14,000,000초 ≈ 35.14µs
6채널을 모두 같은 설정으로 순서대로 변환 = 6×35.14µs ≈ 210.86µs
```

14MHz는1초에14,000,000번의 ADC 클록이라는 뜻이다. 위 계산은 트리거/소프트웨어 시간 제외,6채널 동일 설정의 시간 비교다. 현재 CAD는 전류2+온도2이고 목표6채널에는 전압2가 더 있다. 실제 모든 채널 설정을 이 값으로 확정한 것은 아니다.

현재 제안 목표에 비해 이 획득 시간을 둘 시간 여유가 있어, 기존 후보를 후속 검증 기준으로 유지한다. 정확도를 모두 증명했다는 의미는 아니다. 샘플링 획득 창과 같은 채널의 반복 간격을 각각 정해야 한다.

---

**⑥ DC 입력계 검증은100Hz·10개 평균을 첫 비교 조건으로 제안한다**

| 같은 채널의 원시 수집률 | 100Hz | 1kHz |
| --- | ---: | ---: |
| 수집 간격 | 10ms | 1ms |
| 100ms 블록의 샘플 수 | 10개 | 100개 |
| 수집률의 절반(나이퀴스트 주파수) | 50Hz | 500Hz |
| 매번6채널 변환 시 ADC 시간 비율 | 약2.11% | 약21.09% |
| 단일 외부 C 교란의 자유 회복 잔여 비율 | 약0.0240% | 약43.46% |
| 명목 PWM 기본파의 이상적 alias | 약0.226Hz | 약0.226Hz |

ADC 시간 비율은CPU 점유율이 아니다. 회복 비율은센서 전압 전체의 오차율이 아니며, 유한한 획득 동작까지 결합한 실제 반복 모델도 아니다. alias는 PWM19000.226Hz와 이상적 균일 수집을 비교한 값이고 실측 스펙트럼이 아니다. [수집 비교 JSON](../../09_Electrical_Design/KiCAD/TMR_Monitor_Shield_RevA/reports/current_sampling_cadence_review.json).

100Hz를 DC 시험의 첫 비교 조건으로 제안하는 이유는 변환 시간 부담이 작고, 반복 수집 간 회복 시간이 길며,100ms 결과마다10개 샘플을 비교할 수 있기 때문이다. 여기에1kHz를 비교하면 수집률 증가에 따라 영점/잔차/산포가 바뀌는지 확인할 수 있다.

**100Hz가 PWM 잡음을 해결한다는 선정은 아니다.** 두 비교점 모두 기본파가약0.226Hz로 보일 수 있다. PWM 동작 시에는 실제 리플 크기·위상·고조파와 센서 출력 안정성을 별도로 확인한다. 원시값과 처리값을 함께 남겨 평균으로 문제가 가려지지 않게 검토한다.

특히100Hz 수집의 나이퀴스트 주파수는50Hz인데, 현재RC의 차단 주파수는약132.6Hz다. 따라서50Hz 위 성분이충분히 억제된 입력이라고 볼 수 없다. 1kHz에서는나이퀴스트 주파수가500Hz로 높아지지만,1차RC는 그 위를완전히 제거하지 않으므로입력 스펙트럼과허용 오차를 함께 봐야 한다. 이것도100Hz를DC 시험의시작 조건과 운용 최종값으로 구분하는 이유다.

실제 타이머 주기·채널 순서·PWM과의 위상 관계·평균 출력 시점은 아직 미구현/미선정이다. 같은 클록에서 파생되는PWM/ADC 타이머의 관계는 실제 설정으로 다시 계산한다.

---

**⑦ 100ms 갱신과300ms 응답은 따로 판단한다**

100ms마다 결과를 생성해도 그 결과가 새 입력을 충분히 반영했다는 보장은 없다. 겹치지 않는100ms 블록 평균에서는 변화가 블록 중간에 일어나면 이전 입력의 샘플과 새 입력의 샘플이 섞인다. 다음 블록은 새 입력 위주로 채워진다. 이상적인 즉시 계단 변화라도 최초의 전부 새 입력인 블록 결과까지는 위상에 따라거의200ms가 걸릴 수 있다.

실제 RC 입력은 점차 변한다. RC 잔차·평균·스케줄·보정 후 고정 오차를 포함해허용 범위 진입을 확인해야 한다. RC의5.53ms와 결과 주기100ms를 단순히 더해전체 응답 통과를 선언하지 않는다. 변환210.86µs가 짧다는 것만으로300ms 응답을 증명하지도 않는다. 브라우저 전달 지연은 별도 항목이다.

---

**⑧ 현재 판단과 다음 검증의 순서**

| 대상 | 이번 판단 | 확정에 필요한 근거 |
| --- | --- | --- |
| R1/R2 12kΩ | 현재 비교·검증 후보 유지, 부품 확정 보류 | 보정 후 누설/입력 잔차·센서 부하 적합성 |
| C1/C2 100nF | 명목 필터·전하 공급 후보 유지 | 유효 용량·리플·출력 안정성·실제 응답 |
| ADC14MHz·12bit·480cycles | 검증 후보 유지 | 실제 채널 순서/획득·수집 조건에서 잔차 |
| 채널별100Hz·10개/100ms 블록 평균 | DC 입력계 시험의 첫 비교 조건 제안 | 1kHz 비교·응답·산포·PWM 조건 검토 |
| 영점·감도 보정 | 잔차를 판정할 보정 방법으로 검토 유지 | 채널별 계수·기준 계기 불확도·독립점 검증 |
| 전체 정확도/300ms 응답 | 미판정 | 같은 조건의 보정 후 잔차와 시간 기록 |

앞의 표는 학습·설계 검토 결과이며 사용자 채택 또는CAD/펌웨어 반영이 아니다. 2-5의 임의 예산 배분 숫자도 그대로 미채택이다.

NTC는 별도 입력이다. R4=1kΩ만으로 필터를 계산하지 않는다.25°C의명목10kΩ NTC와R3=10kΩ에서 `Rsource=1k+(10k||10k)=6kΩ`, C3=100nF이면τ0.6ms/fc약265Hz다. 온도에 따라NTC가 변하므로전류 채널 결과를NTC 전체 온도 범위의 수용으로 옮기지 않는다. 기존STM측 NTC 공급B안도 후보다.

다음은 **3-1. 검증 대상을 나누고 합격 기준 정하기**다. 알려진DC 전압으로입력 회로·ADC를 먼저 분리해확인하는 계획 → 센서와 기준 전류 비교 → PWM 조건의리플/alias 확인 → 응답·유효성 확인으로 시험표를 만든다. DC 대입 시험은센서 정확도나PWM 조건의 성능까지 입증하지 않는다. 노트북에서시험 계획을 작성할 수 있으며 지금 전원을 켜거나배선을 바꾸라는 지시가 아니다.
