## 1. 무엇을 확인하려고 했는가

배터리 전압을 STM32 ADC로 읽으려면 먼저 큰 전압을 분압해야 한다. 그러나 출력이 3.3V보다 작다는 것만으로 정확도와 전원 OFF 조건까지 해결되지는 않는다. 이번 실습은 다음 질문을 순서대로 확인했다.

1. 저항 공차 때문에 전압 환산 결과가 얼마나 달라지는가?
2. 실제 분압비와 ADC 기준 전압을 알면 어떤 오차를 줄일 수 있는가?
3. ADC 쪽으로 작은 누설 전류가 흐르면 VDIV와 VADC가 달라지는가?
4. 배터리는 살아 있고 MCU 전원만 내려갈 때 측정 경로를 어떻게 끊을 것인가?
5. 끊은 뒤 ADC 쪽에 남은 전하는 어떻게 사라지는가?

현재는 **분압/보호 구조를 이해하고 후보의 미결 조건을 좁히는 단계**다. 실제 쉴드, STM32 ADC 수집 펌웨어, 배선이나 보드를 검증한 실험은 아니다.

## 2. 처음 사용한 전압 분압 회로

```text
VRAIL ─ R1 12k ─ R2 12k ─● VDIV ─ R4 1k ─ VADC
                         ├─ R3 4.7k ─ GND
                         └─ C1 100nF ─ GND
```

VDIV는 저항 분압 직후의 노드이고, VADC는 ADC가 연결될 쪽의 노드다. 지금 모델에 실제 ADC는 없다. 정상 DC에서 이상적인 C1에는 전류가 흐르지 않고, VADC도 무부하라 R4 전류가 0이다. 따라서 R4의 전압 강하가 없어 VDIV=VADC가 된다. **두 노드가 원래 같은 선이라는 뜻은 아니다.** 부하나 누설을 추가하면 달라진다.

분압비 A와 배터리 환산 계수 K는 서로 역수다.

```text
A = R3 / (R1 + R2 + R3) = 4.7 / 28.7 = 0.1637630662
K = 1/A = 6.106382979
VADC = VRAIL × A
추정 VRAIL = 측정 VADC × K
```

명목값에서 16V→2.620209V, 12.6V→2.063415V다. 16V는 검토용 입력 상한으로 유지한 값이며, 실제 배터리가 항상 16V라는 뜻이 아니다. 입력 상한에서 전압 여유와 저항 전력을 확인하되 실제 운용점에서도 별도로 확인한다.

## 3. 공차를 넣으면 왜 오차가 생기는가

예를 들어 R1/R2가 작아지고 R3가 커지면 출력 전압이 커진다. 실제 회로의 분압비는 변했는데 펌웨어가 명목 K를 계속 사용하면, 배터리 전압을 실제보다 높게 환산한다.

오차의 부호는 이 노트에서 `환산 전압 − 실제 입력 전압`으로 통일한다.

| 조건 | R1=R2 | R3 | 16V에서 출력 계산 | 명목 K 환산 오차 계산 |
| --- | ---: | ---: | ---: | ---: |
| 명목 | 12,000Ω | 4,700Ω | 2.620209V | 0V |
| ±1% 출력 최대 조합 | 11,880Ω | 4,747Ω | 2.664328V | +0.269408V |
| ±1% 출력 최소 조합 | 12,120Ω | 4,653Ω | 2.576679V | −0.265808V |
| ±0.1% 출력 최대 조합 | 11,988Ω | 4,704.7Ω | 2.624594V | +0.026778V |
| ±0.1% 출력 최소 조합 | 12,012Ω | 4,695.3Ω | 2.615830V | −0.026742V |

사용자가 보고한 OP 출력 2.66433V, 2.57668V, 2.61583V 등은 계산과 표시 정밀도 범위에서 대응한다. 사용자가 보고한 +0.026751702V는 반올림한 출력 2.62459V로 환산한 결과다. −0.026740213V도 출력 2.61583V로 계산한 결과다. 이상적인 저항값으로 끝까지 계산한 표와 마지막 자리가 다른 이유는 **중간 출력값의 반올림**이다.

이것은 지정한 공차 모서리 조합의 계산/모의실험이다. 실제 저항을 측정한 것이 아니며 모든 오차를 합친 최종 ±0.10V 달성 판정도 아니다.

## 4. 저항을 멀티미터로 측정해서 환산비를 정하면 되는가

원리는 맞다. 실제 R1/R2/R3에 가까운 값으로 K를 계산하면 초기 저항 공차의 영향을 줄일 수 있다. 단, 측정값 자체에 계기의 오차가 있고, 회로에 연결된 채 측정하면 병렬 경로가 섞일 수 있다. 무전원·필요한 분리 조건에서 측정해야 하며 온도 변화와 장기 변화도 남는다.

0.1% 저항 사용과 보정은 서로 대체되는 선택만은 아니다. 정밀 저항은 보정 전 오차를 줄이고, 보정은 실제 조립된 경로의 초기 편차를 줄일 수 있다. 보정 후에도 별도의 입력점에서 확인해야 한다.

사용자는 ±1% 출력 최대 조합에 12.6V를 넣어 **VDIV=VADC=2.09816V**, 전류 441.997µA를 보고했고, 해당 비율로 환산한 결과 12.600V를 보고했다. 이는 **알고 있는 모델 저항값에 맞는 환산비를 적용한 확인**이다. 실측 저항으로 보정한 보드의 정확도 시험은 아니다. 제안했던 다점 보정/독립점 시험 전체를 완료로 처리하지 않는다.

## 5. VREFINT로 줄이는 오차는 따로 있다

ADC 코드는 입력 전압과 기준 전압의 비율에 따라 달라진다. MCU의 실제 기준이 3.3V와 다를 때, 무조건 3.3V를 곱하면 저항이 정확해도 전압 환산이 틀어진다.

STM32F446의 내부 기준 VREFINT를 읽고 칩의 공장 보정값과 비교하여 VDDA를 추정하는 방향을 검토했다. 같은 ADC 해상도로 맞춘 경우 개념식은 다음과 같다.

```text
VDDA 추정 = 공장 보정 당시 기준 전압 × VREFINT_CAL / VREFINT_ADC
입력 전압 추정 ≈ ADC 입력 코드 / full-scale 코드 × VDDA 추정
배터리 전압 추정 ≈ 입력 전압 추정 × 보정된 K
```

정확한 보정 상수·해상도 변환·획득 조건은 실제 STM32 코드 적용 때 확인해야 한다. 이 회차에는 실제 VREFINT 코드 취득이나 펌웨어 변경이 없었다. 설명용 ADC 숫자를 칩의 실측값으로 기록하지 않는다. 이 방법은 기준 전압 변동에 따른 환산 오차를 줄이는 것이며 저항·누설·ADC 자체 오차까지 자동으로 없애지는 않는다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

## 6. ADC 쪽에 1µA가 흐르면

VADC에서 GND로 1µA가 흐르는 이상적인 전류원 I1을 추가했다. 실제 MCU 누설의 측정값이 아니라 **누설의 영향을 계산하기 위한 가정**이다.

사용자 OP 결과는 VDIV=2.61628V, VADC=2.61528V였다. R4에 1µA가 흐르므로 두 노드의 차이는 `1µA × 1kΩ = 1mV`다. R4 전류의 음수 표시는 부품 핀 기준 방향과 실제 전류 방향이 반대라는 뜻이다.

하지만 전체 오차는 1mV만이 아니다. 분압 회로 자체의 출력 저항도 영향을 준다.

```text
Rth = (R1+R2) || R3 = 24k || 4.7k = 3930.3136Ω
추가 VADC 하강 = I누설 × (Rth + R4)
              = 1µA × 4930.3136Ω = 4.930314mV
배터리 환산 오차 = −4.930314mV × K = −30.106383mV
```

보호 소자를 추가할 때도 누설이 정확도에 미치는 영향을 같은 방식으로 검토해야 한다. 보호 회로를 달았다고 정확도 검토가 끝나는 것은 아니다.

## 7. 왜 전압 입력의 MCU OFF 조건을 먼저 보는가

전압 측정은 MCU 전원과 별개인 배터리를 직접 분압한다. MCU가 꺼져도 배터리가 연결되어 있으면 입력에 전압이 계속 남을 수 있다. 따라서 MCU 전원이 내려가는 동안/내려간 뒤 ADC 핀의 허용 전압과 전류 조건을 검토해야 한다.

전류·온도 센서를 MCU 쪽 전원에서 공급하는 안은 지속적인 외부 공급 경로를 줄일 수 있지만, 잔류 전하·전원 순서·배선 고장 검토가 면제되지는 않는다. NTC의 VDD 공급 기본안도 실제 쉴드에 아직 반영하지 않았다.

입력 전압이 VDDA보다 커졌다는 그래프만으로 고장이나 주입 전류의 크기를 확정할 수 없다. 실제 MCU 내부 보호 구조와 핀 규격, 외부 경로가 필요하다. 이번 모델에는 내부 클램프와 전원 레일의 역급전이 없다.

## 8. S1, V2, VCTRL은 각각 무엇인가

S1은 SPICE의 전압 제어 스위치다. 신호 경로와 제어 입력은 별개다.

```text
VDIV ─ R4 1k ─ S1 ─● VADC
                    └─ R5 47k ─ GND

S1 제어+ ← VCTRL (처음에는 V2가 공급)
S1 제어− ← GND
```

이번 모델은 제어 임계값 1.65V, ON 저항 2Ω, OFF 저항 1GΩ을 사용했다. V2=3.3V이면 ON, V2=0V이면 OFF다. V2는 스위치 제어를 시험하기 위한 전압원이며 VDDA 자체가 아니다.

실제 회로에서는 MCU가 꺼져도 안전한 상태를 만드는 전원 감시기와 아날로그 스위치 등의 구성을 검토한다. 일반 SPICE 스위치가 실제 IC의 공급 전압 범위·무전원 허용·지연·누설을 모두 재현하지는 않는다.

## 9. R5=47kΩ을 왜 넣었는가

스위치가 꺼진 ADC 쪽을 GND 기준으로 잡아 주는 풀다운이다. OFF여도 모델의 1GΩ을 통해 작은 전류가 흐르므로, R5가 없거나 지나치게 크면 ADC 쪽을 낮은 전압으로 유지하기 어렵다.

R5에는 ON일 때도 전류가 흐른다. “저항이 크므로 전하가 전혀 안 빠지고 ADC만 읽는다”는 설명은 틀리다. R5가 크면 ON 상태의 분압 부하는 줄지만 OFF 누설에 의한 잔류 전압과 방전 시간은 커진다. R5가 작으면 그 반대다. **47kΩ은 이 상충을 관찰하는 비교값이며 최종 선정값은 아니다.**

사용자 OP 확인:

| 상태 | VCTRL | VDIV | VADC | I(S1)=I(R5) |
| --- | ---: | ---: | ---: | ---: |
| ON | 3.3V | 2.42191V | 2.37135V | 50.4543µA |
| OFF | 0V | 2.6202V | 123.143µV | 2.62007nA |

OFF 결과는 `2.62007nA × 47kΩ ≈ 123.143µV`와 맞는다. 완전히 0V가 아닌 것은 유한한 OFF 저항 때문이다. 실제 스위치는 누설 전류 규격으로 따로 평가해야 한다.

## 10. 스위치와 R5를 넣으면 환산비도 바뀐다

분압부를 테브난 등가회로로 바꾸면, 무부하 전압은 2.620209V이고 출력 저항은 Rth다. 그 뒤 R4, 스위치 ON 저항, R5가 이어진다.

```text
A새 = A명목 × R5 / (Rth + R4 + Ron + R5)
    ≈ 0.1482095362
K새 = 1/A새 ≈ 6.747204165
```

따라서 16V에서 2.371353V가 된다. 여기에 옛 K=6.10638을 적용하면 약14.4804V로 잘못 환산한다. 실제로 이 구조를 채택한다면 **변경된 전체 입력 경로에 맞춰 보정과 오차 예산을 다시 계산**해야 한다. 이번 실습 결과를 기존 분압비와 섞지 않는다.

## 11. VDDA 하강 파형은 실제 보드 측정값인가

아니다. V3에 다음 PWL을 설정했다.

```text
PWL(0 3.3 10m 3.3 13.3m 0 15m 0)
```

0~10ms에는 3.3V, 10~13.3ms에는 직선으로 0V까지, 이후에는 0V다. 하강 기울기는 1V/ms다. 이 시간은 계산을 쉽게 하고 경로를 비교하려고 정한 **학습용 입력 조건**이며 KiCad 기본값도 실제 보드의 하강 시간도 아니다.

처음에는 V2를 3.3V로 유지해 S1을 계속 ON으로 두었다. VADC는 배터리 때문에 약2.37135V를 유지하고 VDDA만 내려가므로 약10.92865ms에 두 선이 교차한다. 사용자는10.930ms에서 VDDA2.370V를 확인했다. 서로 독립인 입력을 이렇게 설정했으므로 교차는 예상되는 결과다. 이를 보호 회로 성능을 입증한 결과라고 해석하지 않는다.

## 12. VDDA와 스위치를 실제로 연동한 모델

V2 대신 B1 행동 전압원을 사용했다.

```text
B1 /VCTRL 0 v=V(/VDDA) > 3 ? V(/VDDA) : 0
```

뜻은 `VDDA가 3V보다 높으면 VCTRL=VDDA, 그렇지 않으면 VCTRL=0`이다. VDDA가3V로 내려가는10.3ms에 제어를 끊는다. 3V는 전원 감시 기준이고, S1의1.65V는 제어 입력 ON/OFF 기준이다. 두 임계값은 역할이 다르다.

사용자 그래프에서 VCTRL과 VADC가 약10.3ms에 떨어지는 것을 확인했다. 커서10.2939ms/3.00615V는 임계점 직전 ON 상태다. 두 임의 커서 사이366.184µs를 감시기 지연으로 읽으면 안 된다. **B1에는 감지 지연·히스테리시스가 없다.**

## 13. 왜 C2=100pF를 추가했는가

스위치를 끊는 것과 ADC 쪽 전압이 사라지는 것은 같은 사건이 아니다. ADC 쪽에 정전용량이 있으면 그 전하가 방전되는 데 시간이 걸린다. 이를 그래프로 보기 위해 **VADC–GND에 C2=100pF를 가정해서 추가**했다.

100pF는 데이터시트로 산정한 총 입력 용량, 실측값, 보장된 최악값, 제작 PCB에 넣기로 한 추가 커패시터가 아니다. µs 단위의 방전을 관찰하기 쉽게 정한 학습용 비교값이다. 값을 소개할 때 이 출처를 먼저 설명했어야 한다.

실제 ADC 쪽 용량을 정하려면 핀·배선·보호 소자·스위치·ADC 동작 상태를 구분해야 한다. STM32F446의 CADC=7pF 최대는 내부 샘플/홀드 용량으로, 핀 전체에 항상 연결된 총용량과 같지 않다. CIO=5pF 전형값도 별도 조건이다. 수치 몇 개를 더해 전체 최악값으로 단정하지 않는다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

C1=100nF는 스위치 **앞 VDIV**, C2=100pF는 스위치 **뒤 VADC**에 있다. 스위치를 끊은 뒤의 ADC 쪽 방전 시간에 R5×C1을 사용하면 다른 노드를 계산하게 된다.

## 14. 방전 곡선과 시정수

OFF 누설을 우선 무시하면 C2가 R5로 방전한다.

```text
τ = R5 × C2 = 47,000Ω × 100×10⁻¹²F = 4.7µs
VADC(t) ≈ V시작 × exp[−(t−tOFF)/τ]
tOFF = 10.3ms, V시작 ≈ 2.371353V
```

| 계산 지점 | 그래프 절대 시각 | 예상 전압, 누설 무시 |
| --- | ---: | ---: |
| OFF 직전 | 10.3000ms | 약2.371353V |
| OFF 후1τ | 10.3047ms | 약0.872372V |
| 변화량99% 방전, 4.605τ | 10.3216443ms | 약23.714mV |

정확히는 유한한 OFF 누설 때문에 최종값 Vf가 약123µV로 남고 `V(t)=Vf+(V시작−Vf)exp(−Δt/τ유효)`로 접근한다. 표는 이해를 위한 근사다.

**확인된 범위:** 사용자 그래프에서10.300ms 이후 VADC 지수형 하강, 콘솔701행을 확인했다. 저장 워크북에는10.3047ms와10.32164ms 커서 위치가 있다. 그러나 그 지점의 전압 숫자는 아직 사용자 보고/CSV로 확보하지 않았다. 표의 예상값을 측정 결과나99% PASS로 바꾸지 않는다.

## 15. TRAN 설정 오류와 수정

```text
오류: .tran 100n 10.35m 10.28 100n
수정: .tran 100n 10.35m 10.28m 100n
```

첫 명령의10.28은 초 단위라 종료 시각10.35ms보다 늦다. 그래서 `TSTART is invalid, must be less than TSTOP`가 발생했다. `m`을 붙여10.28ms로 수정했다.

네 숫자는 출력 간격100ns, 종료10.35ms, 저장 시작10.28ms, 최대 계산 간격100ns다. UIC는 사용하지 않았다. 저장 시작 시각은 계산을 그 시각부터 시작하라는 뜻이 아니다. 초기 동작점과 앞선 시간 계산을 거친 뒤 해당 구간을 저장한다. 성공 로그의 `Initial Transient Solution` 전압은 초기값이며 마지막 시점 값이 아니다.

## 16. 실제 부품 후보와 아직 결정하지 않은 부분

전원 감시기 TPS3840PL30과 스위치 TMUX1511을 후보로 대조했다. 채택·구매·회로 반영은 하지 않았다.

- TPS3840의3.0V 감지점 ±1.5%를 적용하면2.955~3.045V다. 하강 전달 지연의30µs 최대는 지정된 입력 변화·과구동·부하 조건에서의 값이다. 임의의 완만한 전원 하강에도 같은 최악 지연을 보증한다고 확대하지 않는다. 복귀 지연과 하강 검출 지연도 구분한다. [TI TPS3840](https://www.ti.com/lit/ds/symlink/tps3840.pdf).
- TMUX1511의 제어 전이55ns 최대도 공급·부하·제어 에지 조건이 붙는다. 출력 부하의 RC 시간은 시스템 지연에 별도로 반영해야 한다. 전원 OFF 때의 동작 시간과 SEL 제어 전이 시간은 다르다. 전원/신호 전압 범위, 온도별 누설, 저전압 제어 상태까지 확인해야 한다. [TI TMUX1511](https://www.ti.com/lit/ds/symlink/tmux1511.pdf).

현재1V/ms 가정에서 명목3V 감지점부터 VDDA가2.371353V가 될 때까지의 간격은628.647µs다. 감지점만2.955V로 낮추면583.647µs다. 30µs+0.055µs=30.055µs를 비교한 것은 **조건부 규모 비교**다. 다른 공차·누설·용량·실제 하강 기울기를 포함한 최악 조건 PASS가 아니다.

## 19. 10/31 추가 학습 — 검출과 차단 사이의 시간

이하 19~29절은 2026-10-31에 이어서 공부한 내용이다. 18절까지의 다음 작업은 10/30 당시 이력이며, 현재 재개점은 29절이다. [설계26](../../09_Electrical_Design/26_Voltage_ADC_Component_Conditions_and_Control_Draft_2026-10-31_ko.md)과 [오늘 근거](../../assets/logs/pcb_design/2026-10-31_voltage_adc_closeout/README.md)에 연결한다.

VDDA가 기준을 통과하는 순간과 실제 차단 명령이 나오는 순간은 같지 않다. 이를 나눠 보기 위해 B1의 즉시 판단 출력을 VTRIP으로 부르고, 그 신호를 30µs 뒤에 내보낸 것을 VCTRL로 만들었다.

```text
VDDA → 임계값 비교 B1 → VTRIP → 학습용 고정 지연 30µs → VCTRL → S1
```

저장한 `detector_delay_30us.cir`은 XSPICE delay 모델이다. TPS3840 제조사 모델을 넣은 것이 아니다. 30µs라는 비교값은 TPS3840의 하강 전달 지연 규격을 참고했지만, 그 규격의 시험 조건을 임의 PWL 파형 전체에 적용할 수는 없다.

**사용자 확인:** 느린 하강 모델에서 VTRIP은 약10.300ms에 LOW, VCTRL과 VADC 하강은 약10.330ms에 시작했다. 두 사건의 간격은 약30µs다. R5와 C2가 만드는 방전은 차단 뒤에 시작한다.

```text
R5 = 47kΩ, C2 = 100pF (학습용)
τ = R5 × C2 = 4.7µs
변화량 99% 방전 시간 ≈ 4.605 × τ = 21.64µs
```

21.64µs는 **방전 시작 후**의 시간이다. 임계값 통과 후 총 시간과 같지 않다. 30µs+0.055µs+21.64µs≈51.70µs는 단계별 규모를 비교한 값이다. 감시기·스위치·RC의 조건과 측정 기준이 달라 실제 회로의 보장된 최대 시간으로 사용하지 않는다.

읽을 곳: [TI TPS3840 SNVSB03E Rev.E, 2026-05](https://www.ti.com/lit/ds/symlink/tps3840.pdf) **p7 §6.6 tP_HL 행과 각주(2), p9 Fig6-2 TPS3840PL**. typ15/max30µs는 VDD가 지정 경계를 넘는 스텝, CL=10pF와 slew 조건에서 정해진다. [TMUX1511 SCDS390B Rev.B, 2025-03](https://www.ti.com/lit/ds/symlink/tmux1511.pdf) **p7 tTRAN, p15 Fig6-5**의 55ns 최대는 지정 VDD·RL200Ω·CL15pF 조건이며 시스템 출력이 완전히 방전되는 시간과 다르다.

## 20. 빠른 전원 하강을 넣은 이유와 한계

기존 1V/ms 대신 25V/ms를 넣은 것은 **같은 지연이 있어도 전원이 더 빨리 내려가면 여유가 줄어든다**는 관계를 보기 위한 비교였다. 두 기울기 모두 실제 Nucleo 측정값이 아니다.

```text
하강 시작 = 10.000ms, 시작 전압 = 3.3V
VDDA(t) = 3.3 − 25 × (t_ms − 10.000)
3.0V 통과 = 10.012ms
고정 30µs 지연 후 차단 = 10.042ms
```

사용자는 **10.040ms**에서 VADC=2.37135258V, VDDA=2.30000000V, VDDA−VADC=−71.3526mV를 확인했다. 10.042ms의 전이점 대신 차단 전인 10.040ms를 선택해 두 전압의 관계를 읽은 것이다. 명목 VADC와 VDDA가 같아지는 계산 시각은 약10.037146ms다.

사용자가 지적한 대로, 이 교차는 임의로 정한 하강 조건 때문에 생긴 결과다. 따라서 결론은 **“이 가정에서는 지연 중 교차가 생긴다”**까지다. “실제 보드에서 고장이 났다”, “주입 전류가 얼마 흐른다”, “후보 부품을 폐기해야 한다”는 결론은 아니다. 모델에 실제 MCU 입력 경로나 감시기의 공급 변화 특성이 없기 때문이다.

지연 모델은 VTRIP의 아날로그 레벨 자체도 늦춘다. 따라서 하강 중 VCTRL이 현재 VDDA보다 높게 보일 수 있다. 이것도 실제 감시기 출력 파형을 검증한 근거가 아니다. 같은 임의 파형 실습을 반복하는 대신 실제 전원 경로·파형·부품 적용 조건을 확인하는 것이 다음 설계 작업이다.

## 21. R5와 스위치가 있는 회로의 저항 공차

이번에는 R5 부하가 포함된 환산비를 쓴다. 다음 식에서 Ra=R1+R2, Rb=R3, Rc=R4+RON, Rd=R5다.

```text
A = VADC / VRAIL
  = Rb × Rd / [Ra × Rb + (Ra + Rb) × (Rc + Rd)]
K = 1 / A = 6.747204165 (명목)
환산 오차 = VADC × K명목 − VRAIL
```

| 조건 | R1/R2 각각 | R3 | R4 | R5 | 사용자 VADC | 반올림 전 계산의 입력 환산 오차 |
| --- | --- | --- | --- | --- | --- | --- |
| 명목 | 12000Ω | 4700Ω | 1000Ω | 47000Ω | 이전2.37135V | 0 |
| ±0.1% 출력 최대 | 11988Ω | 4704.7Ω | 999Ω | 47047Ω | 2.37547V | +27.7924mV |
| ±0.1% 출력 최소 | 12012Ω | 4695.3Ω | 1001Ω | 46953Ω | 2.36724V | −27.7536mV |

모두 VRAIL16V, RON2Ω 조건이다. 최대 조합은 VDIV2.42601V/I(R5)50.4915µA, 최소 조합은 VDIV2.41781V/I(R5)50.4172µA도 보고됐다. OP는 초기 정상 상태이므로 파일에 빠른 PWL이 남아 있어도 그 하강 시간 해석을 한 결과가 아니다.

**0.1% 저항을 구매하기로 한 것이 아니다.** 1%와 0.1%의 차이는 앞서 비교했고, 오늘은 보호 부하를 포함한 오차 크기를 본 것이다. 저렴한 키트 저항은 실측 비율을 이용한 보정 가능성과 부품 정체·온도 특성 확인을 별개로 남긴다. 제조사 정보 없이 TCR을 특정 수치로 정하지 않는다.

## 22. 스위치의 RON과 누설은 어떤 오차를 만드는가

데이터시트의 typical은 대표값이며 모든 부품이 정확히 그 값이라는 뜻이 아니다. 최대값도 표의 공급·신호·온도 조건을 함께 읽어야 한다. 전형적 특성 그래프에서 특정 온도/전압의 저항을 대략 읽을 수 있어도 그 곡선을 생산 편차까지 포함한 보증값으로 삼지 않는다.

읽을 곳: **TMUX1511 Rev.B p6 §5.5 RON과 IS(ON)/ID(ON) 행, p14 §6.3 Fig6-3 누설 측정 구성**.

- 사용자 확인: RON typ2Ω/max4.5Ω. 시험은 표의 공급 범위, VS 범위와 ISD8mA 조건을 따른다.
- 다른 값을 명목으로 유지하고 RON만 2→4.5Ω으로 바꾸면 입력 환산은 약−0.7702mV 변한다. 2Ω은 최소값이 아니므로 이것은 전체 오차의 상·하한이 아니다.
- 사용자 확인: ON 누설 min−50nA/typ0.01nA/max50nA. 부호는 전류 방향이다. 두 단자 시험 항목을 독립적인 두 개의 최대 전류처럼 무조건 더하지 않는다.

VADC 노드에 단일 누설 전류가 흐르는 등가 비교에서:

```text
Req = 47kΩ || [1kΩ + 2Ω + (24kΩ || 4.7kΩ)]
    ≈ 4463.863Ω
|ΔVADC| = 50nA × Req ≈ 0.223193mV
|ΔVRAIL 환산| = |ΔVADC| × K ≈ 1.50593mV
```

이는 누설을 한 노드의 전류원으로 대체한 계산이다. 실제 IC의 모든 핀·온도·신호 조건을 재현한 측정은 아니다. RON 변화·누설·ADC 오차를 각자의 조건 없이 합치면 근거가 섞인다.

## 23. 전원이 꺼졌을 때 10nA와 2µA를 구분하기

정상 전원에서 스위치를 OFF한 누설과 **스위치 전원 자체가 0V일 때**의 IPOFF는 다른 항목이다.

읽을 곳: **TMUX1511 Rev.B p6 §5.5 IPOFF 두 행**, **p22 §7.3.4 Powered-off Protection**, **p4 §5.3**.

| IPOFF 행 | 시험 조건 | 최소/전형/최대 |
| --- | --- | --- |
| 첫 행 | VDD=0, VS=0~3V, VD=0, TA=25°C | −10 / 0.01 / +10nA |
| 둘째 행 | VDD=0, VS=0~3.6V, VD=0, 표의 TA=−40~125°C | −2 / 0.01 / +2µA |

사용자가 읽은 “최대10nA”는 첫 행에서 맞다. 그러나 온도 범위와 입력 전압 범위가 다른 둘째 행도 따로 있다. 20~30°C 범위를 확인하려고 25°C 행만 그대로 가져오면 보증 범위를 넓히는 셈이다. 2µA를 비교용으로 보는 것은 이 조건 차이를 놓치지 않기 위해서다.

```text
10nA × 47kΩ = 0.47mV
2µA × 47kΩ = 94mV
```

위 식은 **양의 누설 전류가 R5로 흐른다는 단순 모델**이다. 데이터시트는 VD=0으로 시험했고 실제 출력은 저항/MCU에 연결된다. MCU 무전원 입력 I–V, 음의 전류 방향, 중간 공급 전압도 모델에 없다. 따라서 94mV가 어떤 일반적인 다이오드 전압보다 작다고 곧바로 “안전”을 선언하지 않는다. VDD=0에서의 규격은 VDD가 0~1.5V를 통과하는 모든 순간에 대한 보증과도 다르다.

## 25. VREFINT와 두 점 보정이 줄이는 오차의 범위

목표는 ADC의 기준 전압이 늘 3.300V라고 가정해서 생기는 오해를 줄이는 것이다. 공장에 저장된 VREFINT 보정 코드와 현재 VREFINT ADC 코드를 같은 해상도에서 비교한다.

```text
VDDA추정 = 3.3V × N공장보정 / N현재VREFINT
VRAIL추정 = N전압채널 / 4096 × VDDA추정 × K
```

3.3V는 해당 공장 보정 조건의 전압이다. N공장보정을 모든 칩에서 같은 값으로 가정하거나 VREFINT를 정확히 1.21V인 기준으로 취급하지 않는다. 실제 코드는 아직 취득하지 않았다.

설명을 위한 N공장보정=1500, 실제 VDDA3.3V, 실제 입력16V 예에서 N현재가1496이면 약+42.78mV, 1504이면 약−42.55mV의 환산 차이가 생긴다. 1499/1501이면 약+10.67/−10.66mV다. 이는 코드 오차 민감도 비교이고 실제 관측값이 아니다. 두 채널이 공유하는 곱셈 이득 오차는 비율 계산에서 일부 상쇄될 수 있으므로 동일 ADC 오차를 독립 최악값으로 중복 계산하지 않는다.

3.3V·12bit라면 1LSB≈0.805664mV ADC, 현재 K에서 약5.43598mV 입력 환산이다. DS10693 Rev10 p140 Table75(온라인 Rev11 p141)의 ADC18MHz 조건에서 ET typ3/max4LSB와 각 오프셋·이득·선형성 항목을 읽었다. ET가 포함하는 성분을 전부 다시 더하지 않는다. 예컨대 4LSB 환산21.7439mV, 비선형성3LSB 환산16.3079mV는 크기 비교다. 계획 중인 ADC 클록/샘플링 조건과 다르면 그대로 성능 보증으로 채택하지 않는다.

두 점 보정은 일차식의 기울기/오프셋을 맞추는 방법이다. 예시 `X=1.01×V실제+0.020`을 완전히 일차식으로 가정했으므로 두 점으로 정확히 복원되는 것이다. 실제 비선형성·온도 변화·기준 계기 오차까지 사라지지는 않는다. 보정점 외8V/12.6V 등의 독립점, 보정 범위 밖16V의 외삽, 0V 부근은 구분해서 검증해야 한다. 사용자가 이미 이해한 두 점 보정을 처음부터 반복할 필요는 없다.

## 26. 온도와 기준 계기까지 포함해야 하는 이유

저항의 초기 공차와 TCR은 다르다. 25°C에서 측정해 보정한 비율도 온도가 바뀌면 달라질 수 있다. 보유 저항은 저렴한 키트라는 사용자 보고만 있고 정확한 제조사/TCR 자료는 없다.

5°C 변화, R1~R5의 TCR 부호가 서로 불리하게 놓이고 RON은 고정이라는 **가정 계산**에서 입력16V의 환산 변화는 다음 정도다.

| 가정한 각 저항 TCR 범위 | 환산 변화의 계산 범위 |
| --- | --- |
| ±25ppm/°C | 약−3.471~+3.472mV |
| ±50ppm/°C | 약−6.942~+6.944mV |
| ±100ppm/°C | 약−13.882~+13.891mV |

이 표는 키트 저항의 성능표가 아니다. 동일 TCR이 함께 움직이면 비율이 일부 상쇄될 수 있으나 그 추적 성능도 근거가 필요하다. VREFINT의 온도 특성 역시 초기 보정과 별개다. 50ppm/°C를 5°C 선형 변화에 대입한16V×250ppm=4mV는 조건부 규모 비교이며 모든 국소 온도 구간의 독립 보증으로 사용하지 않는다.

온도 시험에서는 같은 보정 계수를 유지하고 `d(T)=추정 전압−기준 전압`의 변화를 비교해야 한다. 입력원 자체가 변했는데 DUT 출력만 변했다고 센서 온도 드리프트로 판단하면 안 된다.

읽을 곳: [UNI-T UT210E 설명서 MAY2018 REV2](../../assets/datasheets/UNI-T_UT210E_User_Manual.pdf), **PDF p2 IX Technical index → 1 DC voltage → 20.00V 행**. 10mV 분해능, ±(읽음값의0.7%+3digits), 23±5°C·RH<75%·1년 조건이다.

```text
12.6V: 12.6 × 0.007 + 3 × 0.01 = 0.1182V
16.0V: 16.0 × 0.007 + 3 × 0.01 = 0.1420V
```

±0.10V 목표보다 기준 계기 설명서 한계가 크다. 두 값이 잘 맞는다는 이유만으로 목표 달성을 확정할 수 없다. 위 수치는 제조사 정확도 한계이지 교정 성적서로 얻은 개별 계기의 실제 오차/확장불확도가 아니다. 당장 새 계기를 사기로 한 것도 아니며 필요하면 적합한 기준기를 빌리거나 확보하는 후속 조건으로 남긴다.

합격 경계를 `T=0.10V`, 기준/입력원/치구의 독립 비교 경계를 `G`로 정한다면 다음처럼 판정한다.

```text
|d| + G ≤ T : PASS
|d| − G > T : FAIL
그 사이      : INCONCLUSIVE (판정 보류)
시험 준비 부족: NOT_READY (판정 결과와 별개)
```

G≤25mV는 제안한 검증 배분이며 아직 확보한 장비의 성능이 아니다. DUT의 오차를 기준 경계에 중복 포함하지 않는다.

## 27. 실제 회로에서 VCTRL은 누가 만드는가

시뮬레이션의 V2/B1은 제어 조건을 이해하기 위한 도구다. 실제 초안은 **TPS3840PL30이 STM ADC 전원을 감시하고 RESET 출력으로 TMUX1511의 SEL을 제어**하는 것이다.

```text
STM ADC 전원 VDDA → TPS3840PL30.VDD + TMUX1511.VDD
TPS3840PL30.RESET → TMUX1511.SEL1/SEL2
각 전압 분압 → 1kΩ → TMUX 신호 경로 → VADC → ADC
                                      └→ 47kΩ → GND
```

부품 핀의 이름 VDD와 실제 연결할 전원 노드 VDDA는 구분한다. Nucleo의 실제 VDDA/VDD 필터 및 취출 위치는 아직 확인을 끝내지 않았다. 임의로 전원선을 합치거나 이미 배선한 것으로 기록하지 않는다.

PL은 active-low push-pull RESET이다. 정상일 때 HIGH, 저전압 조건에서 LOW이므로 TMUX의 HIGH=ON/LOW=OFF와 방향이 맞는다. TPS의 VOH/VOL 시험 조건에서 HIGH 최소0.8VDD, LOW 최대0.2V와 TMUX의 VIH최소1.2V/VIL최대0.45V를 비교했다. 이는 유효한 공급·출력 부하 조건에서 논리 레벨이 맞는다는 확인이며 전원 하강 전 구간의 보호 보증은 아니다.

읽을 곳: **TPS3840 Rev.E p3 변형, p4 §5 핀, p6 §6.5 VOH/VOL, p19~20 §7.4**, **TMUX1511 Rev.B p3 핀, p6 VIH/VIL, p22 Table7-1**. TMUX SEL의 내부6MΩ 풀다운은 전원이 제어 입력에 없을 때의 기본 상태용이다. VADC 잔류 전압을 낮추는 R5와 다른 저항이다.

RESET을 STM NRST에 새로 연결하기로 한 것은 아니다. MR/CT 핀, 디커플링, 사용하지 않는 TMUX 채널, 복귀 후 ADC 정착 시간은 다음 회로 검토에 남겼다.

## 28. VIT−, VIT+, tP_HL, tD를 한 흐름으로 이해하기

마지막에 사용자는 tP_HL은 하강, tD는 상승 복귀의 지연이라고 확인했다. VIT−의 의미와 “경계를 넘는 즉시 HIGH인가”를 다음처럼 정리했다.

읽을 곳: **TPS3840 Rev.E p6 §6.5 VIT−/VHYS, p7 §6.6와 각주(1)(2), p9 Fig6-2 TPS3840PL, p30 Table9-2 PL30**.

| 표기 | 의미 | PL30 명목 예 |
| --- | --- | --- |
| VIT− | 전압이 내려갈 때 저전압을 판단하는 문턱 | 3.0V |
| VIT+ | 전압이 올라갈 때 복귀 조건을 만족하는 문턱 | 약3.1V |
| VHYS | 두 문턱의 차이, 히스테리시스 | typ100mV |
| tP_HL | 하강 문턱을 지난 뒤 RESET이 LOW로 바뀌는 전달 지연 | 표의 조건에서 typ15/max30µs |
| tD | 상승 문턱을 지난 뒤 RESET 해제까지의 대기 | CT-open nominal50µs |
| tSTRT | 완전 무전원 상태에서 시작할 때의 startup 지연 | CT-open min100/typ220/max350µs |

VIT−의 마이너스는 음수 전압이라는 뜻이 아니라 **하강 방향의 문턱**이라는 표시다. PL30의 VIT− 공차는±1.5%이며 히스테리시스도 범위가 있으므로3.0/3.1V를 모든 부품의 정확한 전환값으로 보지 않는다.

```text
전원 하강:
VDDA가 VIT− 아래로 → tP_HL 경과 → RESET LOW → 스위치 OFF

전원 복귀:
VDDA가 VIT+ 위로 → tD 대기 → RESET HIGH → 스위치 ON
```

따라서 “VIT+에서 RESET HIGH”는 **문턱을 넘고 복귀 지연이 지난 뒤 HIGH**라는 뜻으로 읽어야 한다. 3.05V에서 아래로 내려가는 중이면 아직3.0V에 닿지 않았으므로 정상 상태를 유지할 수 있다. 이미 저전압으로 차단됐다가 위로 올라오는 중이면 아직3.1V에 못 미쳐 차단을 유지한다. 이처럼 이전 상태에 따라 동작이 달라지는 구간이 히스테리시스다. 경계 근처 작은 흔들림으로 ON/OFF가 반복되는 것을 줄인다.

완전 OFF에서 시작하는 tSTRT는 정상 동작 중 복귀 tD와 다르다. 데이터시트 각주에 따라 CT-open tD는 startup 규격에 포함되므로50µs를 또 더하지 않는다. 외부 CT를 추가하는 경우의 지연은 해당 식과 조건으로 다시 정해야 한다. CT-open을 최종 회로로 확정한 것은 아니다.

## 29. 오늘 완료한 학습과 다음 작업

**학습/문서화 범위 완료:** 고정30µs 지연의 의미, 가정한 빠른 하강의 한계, 보호 부하 포함 공차, RON/누설/전원 OFF 규격, STM ADC와 기준 계기 오차, 전원 제어 논리 초안, VIT−/VIT+와 두 지연의 구분.

**설계 전체는 진행 중:** 실제 전원 취출·전원 순서, 중간 저전압 상태, 입력 용량/전하 주입·정착, MCU 무전원 입력, 전체±0.10V 오차 예산, 제작 회로도/ERC와 실물 검증은 남았다. 100pF·임의 하강 기울기·0.1% 비교값을 실제 부품 결정으로 바꾸지 않는다.

다음은 **Nucleo의 실제 VDDA/VDD 전원 경로를 확인하고 TPS3840PL30–TMUX1511 연결 초안의 MR/CT/SEL/디커플링과 시작·차단·복귀 조건표를 완성하는 작업**이다. 이후 후보 채택 조건과 남은 실측 항목을 확정해 전체 오차 예산·제작 회로도 단계로 연결한다. 이미 끝낸 RC/공차/두 점 보정 설명을 재시작하지 않는다.

사용자가 회로 작성·GUI 실행을 이어가며 Codex는 근거 위치·조건·계산과 기록을 돕는다. 이번 마감에서는 새 시뮬레이션·MCU 빌드/플래시·물리 조작·구매를 하지 않았다.
