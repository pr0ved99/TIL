## 1. 무엇을 확인하려고 했는가

배터리 전압을 STM32 ADC로 읽으려면 먼저 큰 전압을 분압해야 한다. 그러나 출력이 3.3V보다 작다는 것만으로 정확도와 전원 OFF 조건까지 해결되지는 않는다. 이번 실습은 다음 질문을 순서대로 확인했다.

1. 저항 공차 때문에 전압 환산 결과가 얼마나 달라지는가?
2. 실제 분압비와 ADC 기준 전압을 알면 어떤 오차를 줄일 수 있는가?
3. ADC 쪽으로 작은 누설 전류가 흐르면 VDIV와 VADC가 달라지는가?
4. 배터리는 살아 있고 MCU 전원만 내려갈 때 측정 경로를 어떻게 끊을 것인가?
5. 끊은 뒤 ADC 쪽에 남은 전하는 어떻게 사라지는가?

현재는 **분압/보호 구조를 이해하고 후보의 미결 조건을 좁히는 단계**다. 실제 쉴드, STM32 ADC 수집 펌웨어, 배선이나 보드를 검증한 실험은 아니다.

## 2. 처음 사용한 전압 분압 회로

```text
VRAIL ─ R1 12k ─ R2 12k ─● VDIV ─ R4 1k ─ VADC
                         ├─ R3 4.7k ─ GND
                         └─ C1 100nF ─ GND
```

VDIV는 저항 분압 직후의 노드이고, VADC는 ADC가 연결될 쪽의 노드다. 지금 모델에 실제 ADC는 없다. 정상 DC에서 이상적인 C1에는 전류가 흐르지 않고, VADC도 무부하라 R4 전류가 0이다. 따라서 R4의 전압 강하가 없어 VDIV=VADC가 된다. **두 노드가 원래 같은 선이라는 뜻은 아니다.** 부하나 누설을 추가하면 달라진다.

분압비 A와 배터리 환산 계수 K는 서로 역수다.

```text
A = R3 / (R1 + R2 + R3) = 4.7 / 28.7 = 0.1637630662
K = 1/A = 6.106382979
VADC = VRAIL × A
추정 VRAIL = 측정 VADC × K
```

명목값에서 16V→2.620209V, 12.6V→2.063415V다. 16V는 검토용 입력 상한으로 유지한 값이며, 실제 배터리가 항상 16V라는 뜻이 아니다. 입력 상한에서 전압 여유와 저항 전력을 확인하되 실제 운용점에서도 별도로 확인한다.

## 3. 공차를 넣으면 왜 오차가 생기는가

예를 들어 R1/R2가 작아지고 R3가 커지면 출력 전압이 커진다. 실제 회로의 분압비는 변했는데 펌웨어가 명목 K를 계속 사용하면, 배터리 전압을 실제보다 높게 환산한다.

오차의 부호는 이 노트에서 `환산 전압 − 실제 입력 전압`으로 통일한다.

| 조건 | R1=R2 | R3 | 16V에서 출력 계산 | 명목 K 환산 오차 계산 |
| --- | ---: | ---: | ---: | ---: |
| 명목 | 12,000Ω | 4,700Ω | 2.620209V | 0V |
| ±1% 출력 최대 조합 | 11,880Ω | 4,747Ω | 2.664328V | +0.269408V |
| ±1% 출력 최소 조합 | 12,120Ω | 4,653Ω | 2.576679V | −0.265808V |
| ±0.1% 출력 최대 조합 | 11,988Ω | 4,704.7Ω | 2.624594V | +0.026778V |
| ±0.1% 출력 최소 조합 | 12,012Ω | 4,695.3Ω | 2.615830V | −0.026742V |

사용자가 보고한 OP 출력 2.66433V, 2.57668V, 2.61583V 등은 계산과 표시 정밀도 범위에서 대응한다. 사용자가 보고한 +0.026751702V는 반올림한 출력 2.62459V로 환산한 결과다. −0.026740213V도 출력 2.61583V로 계산한 결과다. 이상적인 저항값으로 끝까지 계산한 표와 마지막 자리가 다른 이유는 **중간 출력값의 반올림**이다.

이것은 지정한 공차 모서리 조합의 계산/모의실험이다. 실제 저항을 측정한 것이 아니며 모든 오차를 합친 최종 ±0.10V 달성 판정도 아니다.

## 4. 저항을 멀티미터로 측정해서 환산비를 정하면 되는가

원리는 맞다. 실제 R1/R2/R3에 가까운 값으로 K를 계산하면 초기 저항 공차의 영향을 줄일 수 있다. 단, 측정값 자체에 계기의 오차가 있고, 회로에 연결된 채 측정하면 병렬 경로가 섞일 수 있다. 무전원·필요한 분리 조건에서 측정해야 하며 온도 변화와 장기 변화도 남는다.

0.1% 저항 사용과 보정은 서로 대체되는 선택만은 아니다. 정밀 저항은 보정 전 오차를 줄이고, 보정은 실제 조립된 경로의 초기 편차를 줄일 수 있다. 보정 후에도 별도의 입력점에서 확인해야 한다.

사용자는 ±1% 출력 최대 조합에 12.6V를 넣어 **VDIV=VADC=2.09816V**, 전류 441.997µA를 보고했고, 해당 비율로 환산한 결과 12.600V를 보고했다. 이는 **알고 있는 모델 저항값에 맞는 환산비를 적용한 확인**이다. 실측 저항으로 보정한 보드의 정확도 시험은 아니다. 제안했던 다점 보정/독립점 시험 전체를 완료로 처리하지 않는다.

## 5. VREFINT로 줄이는 오차는 따로 있다

ADC 코드는 입력 전압과 기준 전압의 비율에 따라 달라진다. MCU의 실제 기준이 3.3V와 다를 때, 무조건 3.3V를 곱하면 저항이 정확해도 전압 환산이 틀어진다.

STM32F446의 내부 기준 VREFINT를 읽고 칩의 공장 보정값과 비교하여 VDDA를 추정하는 방향을 검토했다. 같은 ADC 해상도로 맞춘 경우 개념식은 다음과 같다.

```text
VDDA 추정 = 공장 보정 당시 기준 전압 × VREFINT_CAL / VREFINT_ADC
입력 전압 추정 ≈ ADC 입력 코드 / full-scale 코드 × VDDA 추정
배터리 전압 추정 ≈ 입력 전압 추정 × 보정된 K
```

정확한 보정 상수·해상도 변환·획득 조건은 실제 STM32 코드 적용 때 확인해야 한다. 이 회차에는 실제 VREFINT 코드 취득이나 펌웨어 변경이 없었다. 설명용 ADC 숫자를 칩의 실측값으로 기록하지 않는다. 이 방법은 기준 전압 변동에 따른 환산 오차를 줄이는 것이며 저항·누설·ADC 자체 오차까지 자동으로 없애지는 않는다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

## 6. ADC 쪽에 1µA가 흐르면

VADC에서 GND로 1µA가 흐르는 이상적인 전류원 I1을 추가했다. 실제 MCU 누설의 측정값이 아니라 **누설의 영향을 계산하기 위한 가정**이다.

사용자 OP 결과는 VDIV=2.61628V, VADC=2.61528V였다. R4에 1µA가 흐르므로 두 노드의 차이는 `1µA × 1kΩ = 1mV`다. R4 전류의 음수 표시는 부품 핀 기준 방향과 실제 전류 방향이 반대라는 뜻이다.

하지만 전체 오차는 1mV만이 아니다. 분압 회로 자체의 출력 저항도 영향을 준다.

```text
Rth = (R1+R2) || R3 = 24k || 4.7k = 3930.3136Ω
추가 VADC 하강 = I누설 × (Rth + R4)
              = 1µA × 4930.3136Ω = 4.930314mV
배터리 환산 오차 = −4.930314mV × K = −30.106383mV
```

보호 소자를 추가할 때도 누설이 정확도에 미치는 영향을 같은 방식으로 검토해야 한다. 보호 회로를 달았다고 정확도 검토가 끝나는 것은 아니다.

## 7. 왜 전압 입력의 MCU OFF 조건을 먼저 보는가

전압 측정은 MCU 전원과 별개인 배터리를 직접 분압한다. MCU가 꺼져도 배터리가 연결되어 있으면 입력에 전압이 계속 남을 수 있다. 따라서 MCU 전원이 내려가는 동안/내려간 뒤 ADC 핀의 허용 전압과 전류 조건을 검토해야 한다.

전류·온도 센서를 MCU 쪽 전원에서 공급하는 안은 지속적인 외부 공급 경로를 줄일 수 있지만, 잔류 전하·전원 순서·배선 고장 검토가 면제되지는 않는다. NTC의 VDD 공급 기본안도 실제 쉴드에 아직 반영하지 않았다.

입력 전압이 VDDA보다 커졌다는 그래프만으로 고장이나 주입 전류의 크기를 확정할 수 없다. 실제 MCU 내부 보호 구조와 핀 규격, 외부 경로가 필요하다. 이번 모델에는 내부 클램프와 전원 레일의 역급전이 없다.

## 8. S1, V2, VCTRL은 각각 무엇인가

S1은 SPICE의 전압 제어 스위치다. 신호 경로와 제어 입력은 별개다.

```text
VDIV ─ R4 1k ─ S1 ─● VADC
                    └─ R5 47k ─ GND

S1 제어+ ← VCTRL (처음에는 V2가 공급)
S1 제어− ← GND
```

이번 모델은 제어 임계값 1.65V, ON 저항 2Ω, OFF 저항 1GΩ을 사용했다. V2=3.3V이면 ON, V2=0V이면 OFF다. V2는 스위치 제어를 시험하기 위한 전압원이며 VDDA 자체가 아니다.

실제 회로에서는 MCU가 꺼져도 안전한 상태를 만드는 전원 감시기와 아날로그 스위치 등의 구성을 검토한다. 일반 SPICE 스위치가 실제 IC의 공급 전압 범위·무전원 허용·지연·누설을 모두 재현하지는 않는다.

## 9. R5=47kΩ을 왜 넣었는가

스위치가 꺼진 ADC 쪽을 GND 기준으로 잡아 주는 풀다운이다. OFF여도 모델의 1GΩ을 통해 작은 전류가 흐르므로, R5가 없거나 지나치게 크면 ADC 쪽을 낮은 전압으로 유지하기 어렵다.

R5에는 ON일 때도 전류가 흐른다. “저항이 크므로 전하가 전혀 안 빠지고 ADC만 읽는다”는 설명은 틀리다. R5가 크면 ON 상태의 분압 부하는 줄지만 OFF 누설에 의한 잔류 전압과 방전 시간은 커진다. R5가 작으면 그 반대다. **47kΩ은 이 상충을 관찰하는 비교값이며 최종 선정값은 아니다.**

사용자 OP 확인:

| 상태 | VCTRL | VDIV | VADC | I(S1)=I(R5) |
| --- | ---: | ---: | ---: | ---: |
| ON | 3.3V | 2.42191V | 2.37135V | 50.4543µA |
| OFF | 0V | 2.6202V | 123.143µV | 2.62007nA |

OFF 결과는 `2.62007nA × 47kΩ ≈ 123.143µV`와 맞는다. 완전히 0V가 아닌 것은 유한한 OFF 저항 때문이다. 실제 스위치는 누설 전류 규격으로 따로 평가해야 한다.

## 10. 스위치와 R5를 넣으면 환산비도 바뀐다

분압부를 테브난 등가회로로 바꾸면, 무부하 전압은 2.620209V이고 출력 저항은 Rth다. 그 뒤 R4, 스위치 ON 저항, R5가 이어진다.

```text
A새 = A명목 × R5 / (Rth + R4 + Ron + R5)
    ≈ 0.1482095362
K새 = 1/A새 ≈ 6.747204165
```

따라서 16V에서 2.371353V가 된다. 여기에 옛 K=6.10638을 적용하면 약14.4804V로 잘못 환산한다. 실제로 이 구조를 채택한다면 **변경된 전체 입력 경로에 맞춰 보정과 오차 예산을 다시 계산**해야 한다. 이번 실습 결과를 기존 분압비와 섞지 않는다.

## 11. VDDA 하강 파형은 실제 보드 측정값인가

아니다. V3에 다음 PWL을 설정했다.

```text
PWL(0 3.3 10m 3.3 13.3m 0 15m 0)
```

0~10ms에는 3.3V, 10~13.3ms에는 직선으로 0V까지, 이후에는 0V다. 하강 기울기는 1V/ms다. 이 시간은 계산을 쉽게 하고 경로를 비교하려고 정한 **학습용 입력 조건**이며 KiCad 기본값도 실제 보드의 하강 시간도 아니다.

처음에는 V2를 3.3V로 유지해 S1을 계속 ON으로 두었다. VADC는 배터리 때문에 약2.37135V를 유지하고 VDDA만 내려가므로 약10.92865ms에 두 선이 교차한다. 사용자는10.930ms에서 VDDA2.370V를 확인했다. 서로 독립인 입력을 이렇게 설정했으므로 교차는 예상되는 결과다. 이를 보호 회로 성능을 입증한 결과라고 해석하지 않는다.

## 12. VDDA와 스위치를 실제로 연동한 모델

V2 대신 B1 행동 전압원을 사용했다.

```text
B1 /VCTRL 0 v=V(/VDDA) > 3 ? V(/VDDA) : 0
```

뜻은 `VDDA가 3V보다 높으면 VCTRL=VDDA, 그렇지 않으면 VCTRL=0`이다. VDDA가3V로 내려가는10.3ms에 제어를 끊는다. 3V는 전원 감시 기준이고, S1의1.65V는 제어 입력 ON/OFF 기준이다. 두 임계값은 역할이 다르다.

사용자 그래프에서 VCTRL과 VADC가 약10.3ms에 떨어지는 것을 확인했다. 커서10.2939ms/3.00615V는 임계점 직전 ON 상태다. 두 임의 커서 사이366.184µs를 감시기 지연으로 읽으면 안 된다. **B1에는 감지 지연·히스테리시스가 없다.**

## 13. 왜 C2=100pF를 추가했는가

스위치를 끊는 것과 ADC 쪽 전압이 사라지는 것은 같은 사건이 아니다. ADC 쪽에 정전용량이 있으면 그 전하가 방전되는 데 시간이 걸린다. 이를 그래프로 보기 위해 **VADC–GND에 C2=100pF를 가정해서 추가**했다.

100pF는 데이터시트로 산정한 총 입력 용량, 실측값, 보장된 최악값, 제작 PCB에 넣기로 한 추가 커패시터가 아니다. µs 단위의 방전을 관찰하기 쉽게 정한 학습용 비교값이다. 값을 소개할 때 이 출처를 먼저 설명했어야 한다.

실제 ADC 쪽 용량을 정하려면 핀·배선·보호 소자·스위치·ADC 동작 상태를 구분해야 한다. STM32F446의 CADC=7pF 최대는 내부 샘플/홀드 용량으로, 핀 전체에 항상 연결된 총용량과 같지 않다. CIO=5pF 전형값도 별도 조건이다. 수치 몇 개를 더해 전체 최악값으로 단정하지 않는다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

C1=100nF는 스위치 **앞 VDIV**, C2=100pF는 스위치 **뒤 VADC**에 있다. 스위치를 끊은 뒤의 ADC 쪽 방전 시간에 R5×C1을 사용하면 다른 노드를 계산하게 된다.

## 14. 방전 곡선과 시정수

OFF 누설을 우선 무시하면 C2가 R5로 방전한다.

```text
τ = R5 × C2 = 47,000Ω × 100×10⁻¹²F = 4.7µs
VADC(t) ≈ V시작 × exp[−(t−tOFF)/τ]
tOFF = 10.3ms, V시작 ≈ 2.371353V
```

| 계산 지점 | 그래프 절대 시각 | 예상 전압, 누설 무시 |
| --- | ---: | ---: |
| OFF 직전 | 10.3000ms | 약2.371353V |
| OFF 후1τ | 10.3047ms | 약0.872372V |
| 변화량99% 방전, 4.605τ | 10.3216443ms | 약23.714mV |

정확히는 유한한 OFF 누설 때문에 최종값 Vf가 약123µV로 남고 `V(t)=Vf+(V시작−Vf)exp(−Δt/τ유효)`로 접근한다. 표는 이해를 위한 근사다.

**확인된 범위:** 사용자 그래프에서10.300ms 이후 VADC 지수형 하강, 콘솔701행을 확인했다. 저장 워크북에는10.3047ms와10.32164ms 커서 위치가 있다. 그러나 그 지점의 전압 숫자는 아직 사용자 보고/CSV로 확보하지 않았다. 표의 예상값을 측정 결과나99% PASS로 바꾸지 않는다.

## 15. TRAN 설정 오류와 수정

```text
오류: .tran 100n 10.35m 10.28 100n
수정: .tran 100n 10.35m 10.28m 100n
```

첫 명령의10.28은 초 단위라 종료 시각10.35ms보다 늦다. 그래서 `TSTART is invalid, must be less than TSTOP`가 발생했다. `m`을 붙여10.28ms로 수정했다.

네 숫자는 출력 간격100ns, 종료10.35ms, 저장 시작10.28ms, 최대 계산 간격100ns다. UIC는 사용하지 않았다. 저장 시작 시각은 계산을 그 시각부터 시작하라는 뜻이 아니다. 초기 동작점과 앞선 시간 계산을 거친 뒤 해당 구간을 저장한다. 성공 로그의 `Initial Transient Solution` 전압은 초기값이며 마지막 시점 값이 아니다.

## 16. 실제 부품 후보와 아직 결정하지 않은 부분

전원 감시기 TPS3840PL30과 스위치 TMUX1511을 후보로 대조했다. 채택·구매·회로 반영은 하지 않았다.

- TPS3840의3.0V 감지점 ±1.5%를 적용하면2.955~3.045V다. 하강 전달 지연의30µs 최대는 지정된 입력 변화·과구동·부하 조건에서의 값이다. 임의의 완만한 전원 하강에도 같은 최악 지연을 보증한다고 확대하지 않는다. 복귀 지연과 하강 검출 지연도 구분한다. [TI TPS3840](https://www.ti.com/lit/ds/symlink/tps3840.pdf).
- TMUX1511의 제어 전이55ns 최대도 공급·부하·제어 에지 조건이 붙는다. 출력 부하의 RC 시간은 시스템 지연에 별도로 반영해야 한다. 전원 OFF 때의 동작 시간과 SEL 제어 전이 시간은 다르다. 전원/신호 전압 범위, 온도별 누설, 저전압 제어 상태까지 확인해야 한다. [TI TMUX1511](https://www.ti.com/lit/ds/symlink/tmux1511.pdf).

현재1V/ms 가정에서 명목3V 감지점부터 VDDA가2.371353V가 될 때까지의 간격은628.647µs다. 감지점만2.955V로 낮추면583.647µs다. 30µs+0.055µs=30.055µs를 비교한 것은 **조건부 규모 비교**다. 다른 공차·누설·용량·실제 하강 기울기를 포함한 최악 조건 PASS가 아니다.

## 17. 저장 파일과 실험 당시 상태를 구분하기

회로 파일을 다시 읽어 확인한 결과, 일부 파일명은 실제 저장값과 일치하지 않는다. 원본을 덮어쓰거나 실험을 다시 실행하지 않고 [파일 대조표](../../09_Electrical_Design/KiCAD/Simulation/03_Voltage_Divider/README.md)에 차이를 남겼다.

다음에 열 파일은 **03_09_Voltage_ADC_Discharge_TRAN.kicad_sch**다. B1·V3·C2가 모두 저장되어 있다. `03_08`은 이름과 달리 V2 고정 제어 상태이며, `03_07`에는 V3가 없다. 중간 파일 이름만 보고 완료 실험을 재현할 수 있다고 판단하지 않는다.

이번 TRAN 원본은 텍스트 콘솔 로그이고, 그래프는 대화에 첨부된 화면을 관찰한 기록이다. 새 PNG/파형 CSV가 저장되었다고 주장하지 않는다. 이전10/28 PNG/CSV는 별도 기본 실습 근거로 유지한다.

## 18. 다음에 바로 이어갈 작업

1. 100pF라는 가정을 실제 ADC 쪽 용량의 어떤 근거로 대체하거나 범위화할지 정한다. 내부 샘플링 용량과 항상 연결된 외부 용량을 구분한다.
2. 전원 감시기/스위치의 지연·무전원 허용·누설 조건을 실제 전원 하강 조건과 대조한다. 아직 모르는 조건을 임의의 최악값으로 확정하지 않는다.
3. 필요한 경우에만 모델을 보완하고 사용자가 실행한다. 이미 확인한 ON/OFF와 기본 RC 실습을 처음부터 반복하지 않는다. 두 커서 전압의 정량 확인은 아직 남은 항목이다.
4. 보호 구조가 정해지면 변경된 환산비·누설·VDDA·ADC·온도·보정을 합쳐 전압 ±0.10V 오차 예산으로 돌아간다. 준비된 내용만 실제 쉴드 두 전압 채널/NTC 공급 검토로 옮긴다.

이번에는 학습과 모델 동작 이해까지 마감한다. 실제 ADC 핀 보호, 센서 정확도, PCB 제작 적합성, 전체 MVP 인수는 별도 미완료다.
