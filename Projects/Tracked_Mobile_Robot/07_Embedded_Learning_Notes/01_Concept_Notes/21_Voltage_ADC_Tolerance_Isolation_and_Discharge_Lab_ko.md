## 1. 무엇을 확인하려고 했는가

배터리 전압을 STM32 ADC로 읽으려면 먼저 큰 전압을 분압해야 한다. 그러나 출력이 3.3V보다 작다는 것만으로 정확도와 전원 OFF 조건까지 해결되지는 않는다. 이번 실습은 다음 질문을 순서대로 확인했다.

1. 저항 공차 때문에 전압 환산 결과가 얼마나 달라지는가?
2. 실제 분압비와 ADC 기준 전압을 알면 어떤 오차를 줄일 수 있는가?
3. ADC 쪽으로 작은 누설 전류가 흐르면 VDIV와 VADC가 달라지는가?
4. 배터리는 살아 있고 MCU 전원만 내려갈 때 측정 경로를 어떻게 끊을 것인가?
5. 끊은 뒤 ADC 쪽에 남은 전하는 어떻게 사라지는가?

현재는 **분압/보호 구조를 이해하고 후보의 미결 조건을 좁히는 단계**다. 실제 쉴드, STM32 ADC 수집 펌웨어, 배선이나 보드를 검증한 실험은 아니다.

## 2. 처음 사용한 전압 분압 회로

```text
VRAIL ─ R1 12k ─ R2 12k ─● VDIV ─ R4 1k ─ VADC
                         ├─ R3 4.7k ─ GND
                         └─ C1 100nF ─ GND
```

VDIV는 저항 분압 직후의 노드이고, VADC는 ADC가 연결될 쪽의 노드다. 지금 모델에 실제 ADC는 없다. 정상 DC에서 이상적인 C1에는 전류가 흐르지 않고, VADC도 무부하라 R4 전류가 0이다. 따라서 R4의 전압 강하가 없어 VDIV=VADC가 된다. **두 노드가 원래 같은 선이라는 뜻은 아니다.** 부하나 누설을 추가하면 달라진다.

분압비 A와 배터리 환산 계수 K는 서로 역수다.

```text
A = R3 / (R1 + R2 + R3) = 4.7 / 28.7 = 0.1637630662
K = 1/A = 6.106382979
VADC = VRAIL × A
추정 VRAIL = 측정 VADC × K
```

명목값에서 16V→2.620209V, 12.6V→2.063415V다. 16V는 검토용 입력 상한으로 유지한 값이며, 실제 배터리가 항상 16V라는 뜻이 아니다. 입력 상한에서 전압 여유와 저항 전력을 확인하되 실제 운용점에서도 별도로 확인한다.

## 3. 공차를 넣으면 왜 오차가 생기는가

예를 들어 R1/R2가 작아지고 R3가 커지면 출력 전압이 커진다. 실제 회로의 분압비는 변했는데 펌웨어가 명목 K를 계속 사용하면, 배터리 전압을 실제보다 높게 환산한다.

오차의 부호는 이 노트에서 `환산 전압 − 실제 입력 전압`으로 통일한다.

| 조건 | R1=R2 | R3 | 16V에서 출력 계산 | 명목 K 환산 오차 계산 |
| --- | ---: | ---: | ---: | ---: |
| 명목 | 12,000Ω | 4,700Ω | 2.620209V | 0V |
| ±1% 출력 최대 조합 | 11,880Ω | 4,747Ω | 2.664328V | +0.269408V |
| ±1% 출력 최소 조합 | 12,120Ω | 4,653Ω | 2.576679V | −0.265808V |
| ±0.1% 출력 최대 조합 | 11,988Ω | 4,704.7Ω | 2.624594V | +0.026778V |
| ±0.1% 출력 최소 조합 | 12,012Ω | 4,695.3Ω | 2.615830V | −0.026742V |

사용자가 보고한 OP 출력 2.66433V, 2.57668V, 2.61583V 등은 계산과 표시 정밀도 범위에서 대응한다. 사용자가 보고한 +0.026751702V는 반올림한 출력 2.62459V로 환산한 결과다. −0.026740213V도 출력 2.61583V로 계산한 결과다. 이상적인 저항값으로 끝까지 계산한 표와 마지막 자리가 다른 이유는 **중간 출력값의 반올림**이다.

이것은 지정한 공차 모서리 조합의 계산/모의실험이다. 실제 저항을 측정한 것이 아니며 모든 오차를 합친 최종 ±0.10V 달성 판정도 아니다.

## 4. 저항을 멀티미터로 측정해서 환산비를 정하면 되는가

원리는 맞다. 실제 R1/R2/R3에 가까운 값으로 K를 계산하면 초기 저항 공차의 영향을 줄일 수 있다. 단, 측정값 자체에 계기의 오차가 있고, 회로에 연결된 채 측정하면 병렬 경로가 섞일 수 있다. 무전원·필요한 분리 조건에서 측정해야 하며 온도 변화와 장기 변화도 남는다.

0.1% 저항 사용과 보정은 서로 대체되는 선택만은 아니다. 정밀 저항은 보정 전 오차를 줄이고, 보정은 실제 조립된 경로의 초기 편차를 줄일 수 있다. 보정 후에도 별도의 입력점에서 확인해야 한다.

사용자는 ±1% 출력 최대 조합에 12.6V를 넣어 **VDIV=VADC=2.09816V**, 전류 441.997µA를 보고했고, 해당 비율로 환산한 결과 12.600V를 보고했다. 이는 **알고 있는 모델 저항값에 맞는 환산비를 적용한 확인**이다. 실측 저항으로 보정한 보드의 정확도 시험은 아니다. 제안했던 다점 보정/독립점 시험 전체를 완료로 처리하지 않는다.

## 5. VREFINT로 줄이는 오차는 따로 있다

ADC 코드는 입력 전압과 기준 전압의 비율에 따라 달라진다. MCU의 실제 기준이 3.3V와 다를 때, 무조건 3.3V를 곱하면 저항이 정확해도 전압 환산이 틀어진다.

STM32F446의 내부 기준 VREFINT를 읽고 칩의 공장 보정값과 비교하여 VDDA를 추정하는 방향을 검토했다. 같은 ADC 해상도로 맞춘 경우 개념식은 다음과 같다.

```text
VDDA 추정 = 공장 보정 당시 기준 전압 × VREFINT_CAL / VREFINT_ADC
입력 전압 추정 ≈ ADC 입력 코드 / full-scale 코드 × VDDA 추정
배터리 전압 추정 ≈ 입력 전압 추정 × 보정된 K
```

정확한 보정 상수·해상도 변환·획득 조건은 실제 STM32 코드 적용 때 확인해야 한다. 이 회차에는 실제 VREFINT 코드 취득이나 펌웨어 변경이 없었다. 설명용 ADC 숫자를 칩의 실측값으로 기록하지 않는다. 이 방법은 기준 전압 변동에 따른 환산 오차를 줄이는 것이며 저항·누설·ADC 자체 오차까지 자동으로 없애지는 않는다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

## 6. ADC 쪽에 1µA가 흐르면

VADC에서 GND로 1µA가 흐르는 이상적인 전류원 I1을 추가했다. 실제 MCU 누설의 측정값이 아니라 **누설의 영향을 계산하기 위한 가정**이다.

사용자 OP 결과는 VDIV=2.61628V, VADC=2.61528V였다. R4에 1µA가 흐르므로 두 노드의 차이는 `1µA × 1kΩ = 1mV`다. R4 전류의 음수 표시는 부품 핀 기준 방향과 실제 전류 방향이 반대라는 뜻이다.

하지만 전체 오차는 1mV만이 아니다. 분압 회로 자체의 출력 저항도 영향을 준다.

```text
Rth = (R1+R2) || R3 = 24k || 4.7k = 3930.3136Ω
추가 VADC 하강 = I누설 × (Rth + R4)
              = 1µA × 4930.3136Ω = 4.930314mV
배터리 환산 오차 = −4.930314mV × K = −30.106383mV
```

보호 소자를 추가할 때도 누설이 정확도에 미치는 영향을 같은 방식으로 검토해야 한다. 보호 회로를 달았다고 정확도 검토가 끝나는 것은 아니다.

## 7. 왜 전압 입력의 MCU OFF 조건을 먼저 보는가

전압 측정은 MCU 전원과 별개인 배터리를 직접 분압한다. MCU가 꺼져도 배터리가 연결되어 있으면 입력에 전압이 계속 남을 수 있다. 따라서 MCU 전원이 내려가는 동안/내려간 뒤 ADC 핀의 허용 전압과 전류 조건을 검토해야 한다.

전류·온도 센서를 MCU 쪽 전원에서 공급하는 안은 지속적인 외부 공급 경로를 줄일 수 있지만, 잔류 전하·전원 순서·배선 고장 검토가 면제되지는 않는다. NTC의 VDD 공급 기본안도 실제 쉴드에 아직 반영하지 않았다.

입력 전압이 VDDA보다 커졌다는 그래프만으로 고장이나 주입 전류의 크기를 확정할 수 없다. 실제 MCU 내부 보호 구조와 핀 규격, 외부 경로가 필요하다. 이번 모델에는 내부 클램프와 전원 레일의 역급전이 없다.

## 8. S1, V2, VCTRL은 각각 무엇인가

S1은 SPICE의 전압 제어 스위치다. 신호 경로와 제어 입력은 별개다.

```text
VDIV ─ R4 1k ─ S1 ─● VADC
                    └─ R5 47k ─ GND

S1 제어+ ← VCTRL (처음에는 V2가 공급)
S1 제어− ← GND
```

이번 모델은 제어 임계값 1.65V, ON 저항 2Ω, OFF 저항 1GΩ을 사용했다. V2=3.3V이면 ON, V2=0V이면 OFF다. V2는 스위치 제어를 시험하기 위한 전압원이며 VDDA 자체가 아니다.

실제 회로에서는 MCU가 꺼져도 안전한 상태를 만드는 전원 감시기와 아날로그 스위치 등의 구성을 검토한다. 일반 SPICE 스위치가 실제 IC의 공급 전압 범위·무전원 허용·지연·누설을 모두 재현하지는 않는다.

## 9. R5=47kΩ을 왜 넣었는가

스위치가 꺼진 ADC 쪽을 GND 기준으로 잡아 주는 풀다운이다. OFF여도 모델의 1GΩ을 통해 작은 전류가 흐르므로, R5가 없거나 지나치게 크면 ADC 쪽을 낮은 전압으로 유지하기 어렵다.

R5에는 ON일 때도 전류가 흐른다. “저항이 크므로 전하가 전혀 안 빠지고 ADC만 읽는다”는 설명은 틀리다. R5가 크면 ON 상태의 분압 부하는 줄지만 OFF 누설에 의한 잔류 전압과 방전 시간은 커진다. R5가 작으면 그 반대다. **47kΩ은 이 상충을 관찰하는 비교값이며 최종 선정값은 아니다.**

사용자 OP 확인:

| 상태 | VCTRL | VDIV | VADC | I(S1)=I(R5) |
| --- | ---: | ---: | ---: | ---: |
| ON | 3.3V | 2.42191V | 2.37135V | 50.4543µA |
| OFF | 0V | 2.6202V | 123.143µV | 2.62007nA |

OFF 결과는 `2.62007nA × 47kΩ ≈ 123.143µV`와 맞는다. 완전히 0V가 아닌 것은 유한한 OFF 저항 때문이다. 실제 스위치는 누설 전류 규격으로 따로 평가해야 한다.

## 10. 스위치와 R5를 넣으면 환산비도 바뀐다

분압부를 테브난 등가회로로 바꾸면, 무부하 전압은 2.620209V이고 출력 저항은 Rth다. 그 뒤 R4, 스위치 ON 저항, R5가 이어진다.

```text
A새 = A명목 × R5 / (Rth + R4 + Ron + R5)
    ≈ 0.1482095362
K새 = 1/A새 ≈ 6.747204165
```

따라서 16V에서 2.371353V가 된다. 여기에 옛 K=6.10638을 적용하면 약14.4804V로 잘못 환산한다. 실제로 이 구조를 채택한다면 **변경된 전체 입력 경로에 맞춰 보정과 오차 예산을 다시 계산**해야 한다. 이번 실습 결과를 기존 분압비와 섞지 않는다.

## 11. VDDA 하강 파형은 실제 보드 측정값인가

아니다. V3에 다음 PWL을 설정했다.

```text
PWL(0 3.3 10m 3.3 13.3m 0 15m 0)
```

0~10ms에는 3.3V, 10~13.3ms에는 직선으로 0V까지, 이후에는 0V다. 하강 기울기는 1V/ms다. 이 시간은 계산을 쉽게 하고 경로를 비교하려고 정한 **학습용 입력 조건**이며 KiCad 기본값도 실제 보드의 하강 시간도 아니다.

처음에는 V2를 3.3V로 유지해 S1을 계속 ON으로 두었다. VADC는 배터리 때문에 약2.37135V를 유지하고 VDDA만 내려가므로 약10.92865ms에 두 선이 교차한다. 사용자는10.930ms에서 VDDA2.370V를 확인했다. 서로 독립인 입력을 이렇게 설정했으므로 교차는 예상되는 결과다. 이를 보호 회로 성능을 입증한 결과라고 해석하지 않는다.

## 12. VDDA와 스위치를 실제로 연동한 모델

V2 대신 B1 행동 전압원을 사용했다.

```text
B1 /VCTRL 0 v=V(/VDDA) > 3 ? V(/VDDA) : 0
```

뜻은 `VDDA가 3V보다 높으면 VCTRL=VDDA, 그렇지 않으면 VCTRL=0`이다. VDDA가3V로 내려가는10.3ms에 제어를 끊는다. 3V는 전원 감시 기준이고, S1의1.65V는 제어 입력 ON/OFF 기준이다. 두 임계값은 역할이 다르다.

사용자 그래프에서 VCTRL과 VADC가 약10.3ms에 떨어지는 것을 확인했다. 커서10.2939ms/3.00615V는 임계점 직전 ON 상태다. 두 임의 커서 사이366.184µs를 감시기 지연으로 읽으면 안 된다. **B1에는 감지 지연·히스테리시스가 없다.**

## 13. 왜 C2=100pF를 추가했는가

스위치를 끊는 것과 ADC 쪽 전압이 사라지는 것은 같은 사건이 아니다. ADC 쪽에 정전용량이 있으면 그 전하가 방전되는 데 시간이 걸린다. 이를 그래프로 보기 위해 **VADC–GND에 C2=100pF를 가정해서 추가**했다.

100pF는 데이터시트로 산정한 총 입력 용량, 실측값, 보장된 최악값, 제작 PCB에 넣기로 한 추가 커패시터가 아니다. µs 단위의 방전을 관찰하기 쉽게 정한 학습용 비교값이다. 값을 소개할 때 이 출처를 먼저 설명했어야 한다.

실제 ADC 쪽 용량을 정하려면 핀·배선·보호 소자·스위치·ADC 동작 상태를 구분해야 한다. STM32F446의 CADC=7pF 최대는 내부 샘플/홀드 용량으로, 핀 전체에 항상 연결된 총용량과 같지 않다. CIO=5pF 전형값도 별도 조건이다. 수치 몇 개를 더해 전체 최악값으로 단정하지 않는다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

C1=100nF는 스위치 **앞 VDIV**, C2=100pF는 스위치 **뒤 VADC**에 있다. 스위치를 끊은 뒤의 ADC 쪽 방전 시간에 R5×C1을 사용하면 다른 노드를 계산하게 된다.

## 14. 방전 곡선과 시정수

OFF 누설을 우선 무시하면 C2가 R5로 방전한다.

```text
τ = R5 × C2 = 47,000Ω × 100×10⁻¹²F = 4.7µs
VADC(t) ≈ V시작 × exp[−(t−tOFF)/τ]
tOFF = 10.3ms, V시작 ≈ 2.371353V
```

| 계산 지점 | 그래프 절대 시각 | 예상 전압, 누설 무시 |
| --- | ---: | ---: |
| OFF 직전 | 10.3000ms | 약2.371353V |
| OFF 후1τ | 10.3047ms | 약0.872372V |
| 변화량99% 방전, 4.605τ | 10.3216443ms | 약23.714mV |

정확히는 유한한 OFF 누설 때문에 최종값 Vf가 약123µV로 남고 `V(t)=Vf+(V시작−Vf)exp(−Δt/τ유효)`로 접근한다. 표는 이해를 위한 근사다.

**확인된 범위:** 사용자 그래프에서10.300ms 이후 VADC 지수형 하강, 콘솔701행을 확인했다. 저장 워크북에는10.3047ms와10.32164ms 커서 위치가 있다. 그러나 그 지점의 전압 숫자는 아직 사용자 보고/CSV로 확보하지 않았다. 표의 예상값을 측정 결과나99% PASS로 바꾸지 않는다.

## 15. TRAN 설정 오류와 수정

```text
오류: .tran 100n 10.35m 10.28 100n
수정: .tran 100n 10.35m 10.28m 100n
```

첫 명령의10.28은 초 단위라 종료 시각10.35ms보다 늦다. 그래서 `TSTART is invalid, must be less than TSTOP`가 발생했다. `m`을 붙여10.28ms로 수정했다.

네 숫자는 출력 간격100ns, 종료10.35ms, 저장 시작10.28ms, 최대 계산 간격100ns다. UIC는 사용하지 않았다. 저장 시작 시각은 계산을 그 시각부터 시작하라는 뜻이 아니다. 초기 동작점과 앞선 시간 계산을 거친 뒤 해당 구간을 저장한다. 성공 로그의 `Initial Transient Solution` 전압은 초기값이며 마지막 시점 값이 아니다.

## 16. 실제 부품 후보와 아직 결정하지 않은 부분

전원 감시기 TPS3840PL30과 스위치 TMUX1511을 후보로 대조했다. 채택·구매·회로 반영은 하지 않았다.

- TPS3840의3.0V 감지점 ±1.5%를 적용하면2.955~3.045V다. 하강 전달 지연의30µs 최대는 지정된 입력 변화·과구동·부하 조건에서의 값이다. 임의의 완만한 전원 하강에도 같은 최악 지연을 보증한다고 확대하지 않는다. 복귀 지연과 하강 검출 지연도 구분한다. [TI TPS3840](https://www.ti.com/lit/ds/symlink/tps3840.pdf).
- TMUX1511의 제어 전이55ns 최대도 공급·부하·제어 에지 조건이 붙는다. 출력 부하의 RC 시간은 시스템 지연에 별도로 반영해야 한다. 전원 OFF 때의 동작 시간과 SEL 제어 전이 시간은 다르다. 전원/신호 전압 범위, 온도별 누설, 저전압 제어 상태까지 확인해야 한다. [TI TMUX1511](https://www.ti.com/lit/ds/symlink/tmux1511.pdf).

현재1V/ms 가정에서 명목3V 감지점부터 VDDA가2.371353V가 될 때까지의 간격은628.647µs다. 감지점만2.955V로 낮추면583.647µs다. 30µs+0.055µs=30.055µs를 비교한 것은 **조건부 규모 비교**다. 다른 공차·누설·용량·실제 하강 기울기를 포함한 최악 조건 PASS가 아니다.

## 19. 10/31 추가 학습 — 검출과 차단 사이의 시간

이하 19~29절은 2026-10-31에 이어서 공부한 내용이다. 18절까지의 다음 작업은 10/30 당시 이력이며, 현재 재개점은 29절이다. [설계26](../../09_Electrical_Design/26_Voltage_ADC_Component_Conditions_and_Control_Draft_2026-10-31_ko.md)과 [오늘 근거](../../assets/logs/pcb_design/2026-10-31_voltage_adc_closeout/README.md)에 연결한다.

VDDA가 기준을 통과하는 순간과 실제 차단 명령이 나오는 순간은 같지 않다. 이를 나눠 보기 위해 B1의 즉시 판단 출력을 VTRIP으로 부르고, 그 신호를 30µs 뒤에 내보낸 것을 VCTRL로 만들었다.

```text
VDDA → 임계값 비교 B1 → VTRIP → 학습용 고정 지연 30µs → VCTRL → S1
```

저장한 `detector_delay_30us.cir`은 XSPICE delay 모델이다. TPS3840 제조사 모델을 넣은 것이 아니다. 30µs라는 비교값은 TPS3840의 하강 전달 지연 규격을 참고했지만, 그 규격의 시험 조건을 임의 PWL 파형 전체에 적용할 수는 없다.

**사용자 확인:** 느린 하강 모델에서 VTRIP은 약10.300ms에 LOW, VCTRL과 VADC 하강은 약10.330ms에 시작했다. 두 사건의 간격은 약30µs다. R5와 C2가 만드는 방전은 차단 뒤에 시작한다.

```text
R5 = 47kΩ, C2 = 100pF (학습용)
τ = R5 × C2 = 4.7µs
변화량 99% 방전 시간 ≈ 4.605 × τ = 21.64µs
```

21.64µs는 **방전 시작 후**의 시간이다. 임계값 통과 후 총 시간과 같지 않다. 30µs+0.055µs+21.64µs≈51.70µs는 단계별 규모를 비교한 값이다. 감시기·스위치·RC의 조건과 측정 기준이 달라 실제 회로의 보장된 최대 시간으로 사용하지 않는다.

읽을 곳: [TI TPS3840 SNVSB03E Rev.E, 2026-05](https://www.ti.com/lit/ds/symlink/tps3840.pdf) **p7 §6.6 tP_HL 행과 각주(2), p9 Fig6-2 TPS3840PL**. typ15/max30µs는 VDD가 지정 경계를 넘는 스텝, CL=10pF와 slew 조건에서 정해진다. [TMUX1511 SCDS390B Rev.B, 2025-03](https://www.ti.com/lit/ds/symlink/tmux1511.pdf) **p7 tTRAN, p15 Fig6-5**의 55ns 최대는 지정 VDD·RL200Ω·CL15pF 조건이며 시스템 출력이 완전히 방전되는 시간과 다르다.

## 20. 빠른 전원 하강을 넣은 이유와 한계

기존 1V/ms 대신 25V/ms를 넣은 것은 **같은 지연이 있어도 전원이 더 빨리 내려가면 여유가 줄어든다**는 관계를 보기 위한 비교였다. 두 기울기 모두 실제 Nucleo 측정값이 아니다.

```text
하강 시작 = 10.000ms, 시작 전압 = 3.3V
VDDA(t) = 3.3 − 25 × (t_ms − 10.000)
3.0V 통과 = 10.012ms
고정 30µs 지연 후 차단 = 10.042ms
```

사용자는 **10.040ms**에서 VADC=2.37135258V, VDDA=2.30000000V, VDDA−VADC=−71.3526mV를 확인했다. 10.042ms의 전이점 대신 차단 전인 10.040ms를 선택해 두 전압의 관계를 읽은 것이다. 명목 VADC와 VDDA가 같아지는 계산 시각은 약10.037146ms다.

사용자가 지적한 대로, 이 교차는 임의로 정한 하강 조건 때문에 생긴 결과다. 따라서 결론은 **“이 가정에서는 지연 중 교차가 생긴다”**까지다. “실제 보드에서 고장이 났다”, “주입 전류가 얼마 흐른다”, “후보 부품을 폐기해야 한다”는 결론은 아니다. 모델에 실제 MCU 입력 경로나 감시기의 공급 변화 특성이 없기 때문이다.

지연 모델은 VTRIP의 아날로그 레벨 자체도 늦춘다. 따라서 하강 중 VCTRL이 현재 VDDA보다 높게 보일 수 있다. 이것도 실제 감시기 출력 파형을 검증한 근거가 아니다. 같은 임의 파형 실습을 반복하는 대신 실제 전원 경로·파형·부품 적용 조건을 확인하는 것이 다음 설계 작업이다.

## 21. R5와 스위치가 있는 회로의 저항 공차

이번에는 R5 부하가 포함된 환산비를 쓴다. 다음 식에서 Ra=R1+R2, Rb=R3, Rc=R4+RON, Rd=R5다.

```text
A = VADC / VRAIL
  = Rb × Rd / [Ra × Rb + (Ra + Rb) × (Rc + Rd)]
K = 1 / A = 6.747204165 (명목)
환산 오차 = VADC × K명목 − VRAIL
```

| 조건 | R1/R2 각각 | R3 | R4 | R5 | 사용자 VADC | 반올림 전 계산의 입력 환산 오차 |
| --- | --- | --- | --- | --- | --- | --- |
| 명목 | 12000Ω | 4700Ω | 1000Ω | 47000Ω | 이전2.37135V | 0 |
| ±0.1% 출력 최대 | 11988Ω | 4704.7Ω | 999Ω | 47047Ω | 2.37547V | +27.7924mV |
| ±0.1% 출력 최소 | 12012Ω | 4695.3Ω | 1001Ω | 46953Ω | 2.36724V | −27.7536mV |

모두 VRAIL16V, RON2Ω 조건이다. 최대 조합은 VDIV2.42601V/I(R5)50.4915µA, 최소 조합은 VDIV2.41781V/I(R5)50.4172µA도 보고됐다. OP는 초기 정상 상태이므로 파일에 빠른 PWL이 남아 있어도 그 하강 시간 해석을 한 결과가 아니다.

**0.1% 저항을 구매하기로 한 것이 아니다.** 1%와 0.1%의 차이는 앞서 비교했고, 오늘은 보호 부하를 포함한 오차 크기를 본 것이다. 저렴한 키트 저항은 실측 비율을 이용한 보정 가능성과 부품 정체·온도 특성 확인을 별개로 남긴다. 제조사 정보 없이 TCR을 특정 수치로 정하지 않는다.

## 22. 스위치의 RON과 누설은 어떤 오차를 만드는가

데이터시트의 typical은 대표값이며 모든 부품이 정확히 그 값이라는 뜻이 아니다. 최대값도 표의 공급·신호·온도 조건을 함께 읽어야 한다. 전형적 특성 그래프에서 특정 온도/전압의 저항을 대략 읽을 수 있어도 그 곡선을 생산 편차까지 포함한 보증값으로 삼지 않는다.

읽을 곳: **TMUX1511 Rev.B p6 §5.5 RON과 IS(ON)/ID(ON) 행, p14 §6.3 Fig6-3 누설 측정 구성**.

- 사용자 확인: RON typ2Ω/max4.5Ω. 시험은 표의 공급 범위, VS 범위와 ISD8mA 조건을 따른다.
- 다른 값을 명목으로 유지하고 RON만 2→4.5Ω으로 바꾸면 입력 환산은 약−0.7702mV 변한다. 2Ω은 최소값이 아니므로 이것은 전체 오차의 상·하한이 아니다.
- 사용자 확인: ON 누설 min−50nA/typ0.01nA/max50nA. 부호는 전류 방향이다. 두 단자 시험 항목을 독립적인 두 개의 최대 전류처럼 무조건 더하지 않는다.

VADC 노드에 단일 누설 전류가 흐르는 등가 비교에서:

```text
Req = 47kΩ || [1kΩ + 2Ω + (24kΩ || 4.7kΩ)]
    ≈ 4463.863Ω
|ΔVADC| = 50nA × Req ≈ 0.223193mV
|ΔVRAIL 환산| = |ΔVADC| × K ≈ 1.50593mV
```

이는 누설을 한 노드의 전류원으로 대체한 계산이다. 실제 IC의 모든 핀·온도·신호 조건을 재현한 측정은 아니다. RON 변화·누설·ADC 오차를 각자의 조건 없이 합치면 근거가 섞인다.

## 23. 전원이 꺼졌을 때 10nA와 2µA를 구분하기

정상 전원에서 스위치를 OFF한 누설과 **스위치 전원 자체가 0V일 때**의 IPOFF는 다른 항목이다.

읽을 곳: **TMUX1511 Rev.B p6 §5.5 IPOFF 두 행**, **p22 §7.3.4 Powered-off Protection**, **p4 §5.3**.

| IPOFF 행 | 시험 조건 | 최소/전형/최대 |
| --- | --- | --- |
| 첫 행 | VDD=0, VS=0~3V, VD=0, TA=25°C | −10 / 0.01 / +10nA |
| 둘째 행 | VDD=0, VS=0~3.6V, VD=0, 표의 TA=−40~125°C | −2 / 0.01 / +2µA |

사용자가 읽은 “최대10nA”는 첫 행에서 맞다. 그러나 온도 범위와 입력 전압 범위가 다른 둘째 행도 따로 있다. 20~30°C 범위를 확인하려고 25°C 행만 그대로 가져오면 보증 범위를 넓히는 셈이다. 2µA를 비교용으로 보는 것은 이 조건 차이를 놓치지 않기 위해서다.

```text
10nA × 47kΩ = 0.47mV
2µA × 47kΩ = 94mV
```

위 식은 **양의 누설 전류가 R5로 흐른다는 단순 모델**이다. 데이터시트는 VD=0으로 시험했고 실제 출력은 저항/MCU에 연결된다. MCU 무전원 입력 I–V, 음의 전류 방향, 중간 공급 전압도 모델에 없다. 따라서 94mV가 어떤 일반적인 다이오드 전압보다 작다고 곧바로 “안전”을 선언하지 않는다. VDD=0에서의 규격은 VDD가 0~1.5V를 통과하는 모든 순간에 대한 보증과도 다르다.

## 25. VREFINT와 두 점 보정이 줄이는 오차의 범위

목표는 ADC의 기준 전압이 늘 3.300V라고 가정해서 생기는 오해를 줄이는 것이다. 공장에 저장된 VREFINT 보정 코드와 현재 VREFINT ADC 코드를 같은 해상도에서 비교한다.

```text
VDDA추정 = 3.3V × N공장보정 / N현재VREFINT
VRAIL추정 = N전압채널 / 4096 × VDDA추정 × K
```

3.3V는 해당 공장 보정 조건의 전압이다. N공장보정을 모든 칩에서 같은 값으로 가정하거나 VREFINT를 정확히 1.21V인 기준으로 취급하지 않는다. 실제 코드는 아직 취득하지 않았다.

설명을 위한 N공장보정=1500, 실제 VDDA3.3V, 실제 입력16V 예에서 N현재가1496이면 약+42.78mV, 1504이면 약−42.55mV의 환산 차이가 생긴다. 1499/1501이면 약+10.67/−10.66mV다. 이는 코드 오차 민감도 비교이고 실제 관측값이 아니다. 두 채널이 공유하는 곱셈 이득 오차는 비율 계산에서 일부 상쇄될 수 있으므로 동일 ADC 오차를 독립 최악값으로 중복 계산하지 않는다.

3.3V·12bit라면 1LSB≈0.805664mV ADC, 현재 K에서 약5.43598mV 입력 환산이다. DS10693 Rev10 p140 Table75(온라인 Rev11 p141)의 ADC18MHz 조건에서 ET typ3/max4LSB와 각 오프셋·이득·선형성 항목을 읽었다. ET가 포함하는 성분을 전부 다시 더하지 않는다. 예컨대 4LSB 환산21.7439mV, 비선형성3LSB 환산16.3079mV는 크기 비교다. 계획 중인 ADC 클록/샘플링 조건과 다르면 그대로 성능 보증으로 채택하지 않는다.

두 점 보정은 일차식의 기울기/오프셋을 맞추는 방법이다. 예시 `X=1.01×V실제+0.020`을 완전히 일차식으로 가정했으므로 두 점으로 정확히 복원되는 것이다. 실제 비선형성·온도 변화·기준 계기 오차까지 사라지지는 않는다. 보정점 외8V/12.6V 등의 독립점, 보정 범위 밖16V의 외삽, 0V 부근은 구분해서 검증해야 한다. 사용자가 이미 이해한 두 점 보정을 처음부터 반복할 필요는 없다.

## 26. 온도와 기준 계기까지 포함해야 하는 이유

저항의 초기 공차와 TCR은 다르다. 25°C에서 측정해 보정한 비율도 온도가 바뀌면 달라질 수 있다. 보유 저항은 저렴한 키트라는 사용자 보고만 있고 정확한 제조사/TCR 자료는 없다.

5°C 변화, R1~R5의 TCR 부호가 서로 불리하게 놓이고 RON은 고정이라는 **가정 계산**에서 입력16V의 환산 변화는 다음 정도다.

| 가정한 각 저항 TCR 범위 | 환산 변화의 계산 범위 |
| --- | --- |
| ±25ppm/°C | 약−3.471~+3.472mV |
| ±50ppm/°C | 약−6.942~+6.944mV |
| ±100ppm/°C | 약−13.882~+13.891mV |

이 표는 키트 저항의 성능표가 아니다. 동일 TCR이 함께 움직이면 비율이 일부 상쇄될 수 있으나 그 추적 성능도 근거가 필요하다. VREFINT의 온도 특성 역시 초기 보정과 별개다. 50ppm/°C를 5°C 선형 변화에 대입한16V×250ppm=4mV는 조건부 규모 비교이며 모든 국소 온도 구간의 독립 보증으로 사용하지 않는다.

온도 시험에서는 같은 보정 계수를 유지하고 `d(T)=추정 전압−기준 전압`의 변화를 비교해야 한다. 입력원 자체가 변했는데 DUT 출력만 변했다고 센서 온도 드리프트로 판단하면 안 된다.

읽을 곳: [UNI-T UT210E 설명서 MAY2018 REV2](../../assets/datasheets/UNI-T_UT210E_User_Manual.pdf), **PDF p2 IX Technical index → 1 DC voltage → 20.00V 행**. 10mV 분해능, ±(읽음값의0.7%+3digits), 23±5°C·RH<75%·1년 조건이다.

```text
12.6V: 12.6 × 0.007 + 3 × 0.01 = 0.1182V
16.0V: 16.0 × 0.007 + 3 × 0.01 = 0.1420V
```

±0.10V 목표보다 기준 계기 설명서 한계가 크다. 두 값이 잘 맞는다는 이유만으로 목표 달성을 확정할 수 없다. 위 수치는 제조사 정확도 한계이지 교정 성적서로 얻은 개별 계기의 실제 오차/확장불확도가 아니다. 당장 새 계기를 사기로 한 것도 아니며 필요하면 적합한 기준기를 빌리거나 확보하는 후속 조건으로 남긴다.

합격 경계를 `T=0.10V`, 기준/입력원/치구의 독립 비교 경계를 `G`로 정한다면 다음처럼 판정한다.

```text
|d| + G ≤ T : PASS
|d| − G > T : FAIL
그 사이      : INCONCLUSIVE (판정 보류)
시험 준비 부족: NOT_READY (판정 결과와 별개)
```

G≤25mV는 제안한 검증 배분이며 아직 확보한 장비의 성능이 아니다. DUT의 오차를 기준 경계에 중복 포함하지 않는다.

## 27. 실제 회로에서 VCTRL은 누가 만드는가

시뮬레이션의 V2/B1은 제어 조건을 이해하기 위한 도구다. 실제 초안은 **TPS3840PL30이 STM ADC 전원을 감시하고 RESET 출력으로 TMUX1511의 SEL을 제어**하는 것이다.

```text
STM ADC 전원 VDDA → TPS3840PL30.VDD + TMUX1511.VDD
TPS3840PL30.RESET → TMUX1511.SEL1/SEL2
각 전압 분압 → 1kΩ → TMUX 신호 경로 → VADC → ADC
                                      └→ 47kΩ → GND
```

부품 핀의 이름 VDD와 실제 연결할 전원 노드 VDDA는 구분한다. Nucleo의 실제 VDDA/VDD 필터 및 취출 위치는 아직 확인을 끝내지 않았다. 임의로 전원선을 합치거나 이미 배선한 것으로 기록하지 않는다.

PL은 active-low push-pull RESET이다. 정상일 때 HIGH, 저전압 조건에서 LOW이므로 TMUX의 HIGH=ON/LOW=OFF와 방향이 맞는다. TPS의 VOH/VOL 시험 조건에서 HIGH 최소0.8VDD, LOW 최대0.2V와 TMUX의 VIH최소1.2V/VIL최대0.45V를 비교했다. 이는 유효한 공급·출력 부하 조건에서 논리 레벨이 맞는다는 확인이며 전원 하강 전 구간의 보호 보증은 아니다.

읽을 곳: **TPS3840 Rev.E p3 변형, p4 §5 핀, p6 §6.5 VOH/VOL, p19~20 §7.4**, **TMUX1511 Rev.B p3 핀, p6 VIH/VIL, p22 Table7-1**. TMUX SEL의 내부6MΩ 풀다운은 전원이 제어 입력에 없을 때의 기본 상태용이다. VADC 잔류 전압을 낮추는 R5와 다른 저항이다.

RESET을 STM NRST에 새로 연결하기로 한 것은 아니다. MR/CT 핀, 디커플링, 사용하지 않는 TMUX 채널, 복귀 후 ADC 정착 시간은 다음 회로 검토에 남겼다.

## 28. VIT−, VIT+, tP_HL, tD를 한 흐름으로 이해하기

마지막에 사용자는 tP_HL은 하강, tD는 상승 복귀의 지연이라고 확인했다. VIT−의 의미와 “경계를 넘는 즉시 HIGH인가”를 다음처럼 정리했다.

읽을 곳: **TPS3840 Rev.E p6 §6.5 VIT−/VHYS, p7 §6.6와 각주(1)(2), p9 Fig6-2 TPS3840PL, p30 Table9-2 PL30**.

| 표기 | 의미 | PL30 명목 예 |
| --- | --- | --- |
| VIT− | 전압이 내려갈 때 저전압을 판단하는 문턱 | 3.0V |
| VIT+ | 전압이 올라갈 때 복귀 조건을 만족하는 문턱 | 약3.1V |
| VHYS | 두 문턱의 차이, 히스테리시스 | typ100mV |
| tP_HL | 하강 문턱을 지난 뒤 RESET이 LOW로 바뀌는 전달 지연 | 표의 조건에서 typ15/max30µs |
| tD | 상승 문턱을 지난 뒤 RESET 해제까지의 대기 | CT-open MAX50µs. 11/3 원문 열 대조로 nominal 표기 정정 |
| tSTRT | 완전 무전원 상태에서 시작할 때의 startup 지연 | CT-open min100/typ220/max350µs |

VIT−의 마이너스는 음수 전압이라는 뜻이 아니라 **하강 방향의 문턱**이라는 표시다. PL30의 VIT− 공차는±1.5%이며 히스테리시스도 범위가 있으므로3.0/3.1V를 모든 부품의 정확한 전환값으로 보지 않는다.

```text
전원 하강:
VDDA가 VIT− 아래로 → tP_HL 경과 → RESET LOW → 스위치 OFF

전원 복귀:
VDDA가 VIT+ 위로 → tD 대기 → RESET HIGH → 스위치 ON
```

따라서 “VIT+에서 RESET HIGH”는 **문턱을 넘고 복귀 지연이 지난 뒤 HIGH**라는 뜻으로 읽어야 한다. 3.05V에서 아래로 내려가는 중이면 아직3.0V에 닿지 않았으므로 정상 상태를 유지할 수 있다. 이미 저전압으로 차단됐다가 위로 올라오는 중이면 아직3.1V에 못 미쳐 차단을 유지한다. 이처럼 이전 상태에 따라 동작이 달라지는 구간이 히스테리시스다. 경계 근처 작은 흔들림으로 ON/OFF가 반복되는 것을 줄인다.

완전 OFF에서 시작하는 tSTRT는 정상 동작 중 복귀 tD와 다르다. 데이터시트 각주에 따라 CT-open tD는 startup 규격에 포함되므로50µs를 또 더하지 않는다. 외부 CT를 추가하는 경우의 지연은 해당 식과 조건으로 다시 정해야 한다. CT-open을 최종 회로로 확정한 것은 아니다.

## 29. 오늘 완료한 학습과 다음 작업

**학습/문서화 범위 완료:** 고정30µs 지연의 의미, 가정한 빠른 하강의 한계, 보호 부하 포함 공차, RON/누설/전원 OFF 규격, STM ADC와 기준 계기 오차, 전원 제어 논리 초안, VIT−/VIT+와 두 지연의 구분.

**설계 전체는 진행 중:** 실제 전원 취출·전원 순서, 중간 저전압 상태, 입력 용량/전하 주입·정착, MCU 무전원 입력, 전체±0.10V 오차 예산, 제작 회로도/ERC와 실물 검증은 남았다. 100pF·임의 하강 기울기·0.1% 비교값을 실제 부품 결정으로 바꾸지 않는다.

다음은 **Nucleo의 실제 VDDA/VDD 전원 경로를 확인하고 TPS3840PL30–TMUX1511 연결 초안의 MR/CT/SEL/디커플링과 시작·차단·복귀 조건표를 완성하는 작업**이다. 이후 후보 채택 조건과 남은 실측 항목을 확정해 전체 오차 예산·제작 회로도 단계로 연결한다. 이미 끝낸 RC/공차/두 점 보정 설명을 재시작하지 않는다.

사용자가 회로 작성·GUI 실행을 이어가며 Codex는 근거 위치·조건·계산과 기록을 돕는다. 이번 마감에서는 새 시뮬레이션·MCU 빌드/플래시·물리 조작·구매를 하지 않았다.

### 30-1. 이번에 확인할 문제

앞에서는 VDDA가 내려가면 전압 측정 경로를 차단하는 구조를 공부했다. 실제 부품을 연결하려면 먼저 그 VDDA가 보드 어디에 연결되어 있는지 알아야 한다. 명목상 3.3V라고 적힌 두 지점도 중간 점퍼/부품 때문에 전원이 차단되는 조건이 달라질 수 있다.

오늘 확인하는 것은 전압의 실측값이 아니라 **보드의 전원 연결 경로**다. 현재 열린 `stm32f446mc.pdf`는 MCU 칩 자료이고, JP6/CN7 같은 보드 부품은 Nucleo 보드 매뉴얼과 회로도에서 찾는다.

### 30-3. 전원 이름을 구분하기

| 이름 | 이번 회로에서의 의미 |
| --- | --- |
| +3V3 / +3.3V | 보드의 3.3V 전원망 이름. 이번 경로에서는 JP6 앞쪽 |
| VDD | JP6 뒤의 MCU 공급 전원망, MCU VDD 핀으로 이어짐 |
| AVDD | 보드 회로도에 표시된 아날로그 전원망 이름 |
| VDDA | MCU의 아날로그 전원 핀 이름. 보드 AVDD가 이 핀에 연결됨 |
| VREF+ | ADC의 상한 기준 전압. F446RE LQFP64에서는 VDDA에 내부 연결 |

VDD는 I/O와 내부 레귤레이터 등에, VDDA는 ADC/DAC 등 아날로그 블록에 전원을 공급한다. VDDA는 ADC 전용으로만 쓰이는 핀이 아니다. `AVDD`와 `VDDA`가 다른 글자라고 별도 전원이라고 판단하지 않고, 보드 배선이 어느 칩 핀에 닿는지를 확인한다.

또한 `VDDA`는 ADC를 구동하고 변환 기준이 되는 전압이고, 앞의 시뮬레이션 `VADC`는 **측정하려는 신호 입력 전압**이다. 두 이름을 구분한다.

### 30-4. 공식 회로도의 경로를 따라가기

아래는 정상 공급 구성의 관련 부분만 단순화한 것이다. SB2/JP6/SB57 연결을 전제로 하며 전원 입력 선택 전체를 그린 그림은 아니다.

```text
보드 +5V → U4 3.3V 레귤레이터 → SB2 → +3V3
                                         ├→ CN7-16
                                         └→ JP6 → VDD
                                                   ├→ CN7-5
                                                   ├→ MCU VDD 핀들
                                                   └→ L1 → SB57 → AVDD
                                                                  ├→ CN10-7
                                                                  ├→ MCU 13번 VDDA/VREF+
                                                                  └→ C30 100nF → AGND
```

JP6는 끼우거나 뺄 수 있는 전류 측정용 점퍼다. SB는 solder bridge, 즉 납땜 연결부다. L1은 회로도에 BEAD로 표시된 페라이트 비드로, 고주파 전원 잡음을 줄이는 데 사용하는 소자다. 비드는 별도 정전압 전원을 생성하지 않는다. C30은 아날로그 전원 쪽의 국소 디커플링 커패시터다.

동일 전원망 이름은 회로도의 다른 시트에서도 이어진다. 예를 들어 Sheet2의 VDD를 Sheet3과 Sheet5에서도 찾아야 전원에서 MCU 및 커넥터까지의 경로가 완성된다.

### 30-5. JP6 앞뒤를 왜 구분하는가

정상 상태에서 JP6가 연결되어 있으면 +3V3와 VDD가 모두 약3.3V로 보일 수 있다. 하지만 JP6를 통해서 공급되는 구조이므로 서로 다른 지점이다.

설명용으로 JP6 경로를 끊고, 전류계나 다른 외부 공급/우회 경로가 없다고 가정한다. 이때 +3V3 쪽은 계속 공급될 수 있지만 VDD 쪽의 정상 공급은 끊긴다. 따라서 +3V3에서 전원을 받는 외부 센서가 MCU와 반드시 동시에 꺼진다고 가정할 수 없다. 이는 문서 기반 회로 해석이며 실제 JP6를 빼는 실습 지시가 아니다.

CN7-16과 CN7-5를 외부에서 연결하면 JP6를 우회하는 경로가 생긴다. 동일한 명목 전압이라는 이유로 두 지점을 추가로 연결하지 않는다. MCU의 RESET과 전원 경로 차단도 별개다.

### 30-6. VDD와 VDDA가 연결되어 있는데 왜 따로 확인하는가

연결 관계가 있다는 사실과 모든 시각의 전압이 정확히 같다는 주장은 다르다. 중간 경로의 저항/임피던스, 부하, 커패시터 때문에 DC 차이나 과도 응답 차이가 생길 수 있다. 일반적인 DC 설명에서는 `전압 차이 ≈ 전류 × 경로의 DC 저항`으로 보지만, 현재 보드의 실제 차이를 이 식으로 측정했다고 기록하지 않는다.

ADC 기준에 직접 연결되는 전원망은 AVDD→VDDA다. 따라서 CN10-7은 그 전원망을 외부에서 접근할 수 있는 **문서상 접점**으로 식별했다. 감시기/스위치에 여기서 전원을 공급할지는 부하와 잡음 영향까지 검토할 다음 31절의 결정이다. AREF/AVDD를 임의의 외부 전원 출력이나 외부 기준전압 주입점으로 취급하지 않는다.

### 30-7. 필기할 결론과 이번 확인 작업

> Nucleo의 +3V3, VDD, AVDD는 명목 전압이 비슷해도 경로상의 위치가 다르다. 공식 C04 회로에서 +3V3는 JP6를 거쳐 VDD가 되고, VDD는 L1과 SB57을 거쳐 AVDD로 이어진다. AVDD는 STM32F446RE의 VDDA/VREF+ 핀에 연결된다. 전압 감시 대상을 정할 때는 이 경로와 실제 연결 상태를 함께 확인해야 한다.

사용자는 먼저 **UM1724 Rev17 p59 Table29에서 CN7-5 / CN7-16 / CN10-7 세 행**을 찾아 이름을 대조한다. 그다음 p24 §7.8과 C04 Sheet2/3을 따라 JP6 앞뒤 및 AVDD 경로를 확인한다. 새 계산/시뮬레이션/점퍼 변경은 이 절의 확인 작업에 포함하지 않는다.

**이번 자료 대조 결과:** 문서상 전원 경로와 접점 식별. **남은 것:** 사용자 읽기 확인, 실물 리비전/연결 상태, 실제 전압과 하강 파형, 후보 부품 전원 공급 적합성. 확인 뒤 다음 절은 31번이다.

## 31. 감시기와 스위치의 전원을 어디에서 가져올 것인가

### 31-1. 이번 목적과 판단

30절에서 찾은 AVDD는 MCU의 VDDA/VREF+로 이어지는 보드 전원망이다. 이번에는 보호 부품 두 개를 그 전원망에 연결할 근거를 검토한다.

**상세 설계의 기본 후보는 CN10-7의 AVDD에서 TPS3840PL30과 TMUX1511에 공통 공급하는 기존 초안을 유지한다.** ADC 전원 감시 대상과 두 부품의 공급점을 맞추려는 선택이다. 소비전류 규격은 작은 부하임을 보여 주지만, 아날로그 전원 잡음·실제 보드 연결·전원 과도 조건까지 적합하다고 입증한 것은 아니다. 이번 판단은 제작 승인이나 실물 결선 지시가 아니다.

### 31-2. TPS3840은 전원을 공급받는 핀의 전압을 감시한다

TI TPS3840 **SNVSB03E Rev.E, 2026-05, p4 §5 Table5-1의 VDD(2번) 행**을 읽는다. 이 핀은 IC 구동 전원이면서 감시 입력이다. 이 부품에는 별도의 SENSE 핀이 없다. [공식 PDF](https://www.ti.com/lit/ds/symlink/tps3840.pdf#page=4).

따라서 공급점을 바꾸면 감시 대상도 바뀐다.

| TPS3840.VDD에 연결할 보드 전원 | 직접 감시하는 지점 |
| --- | --- |
| CN7-16의 +3V3 | JP6 앞쪽 전원 |
| CN7-5의 VDD | JP6 뒤, 아날로그 필터 앞쪽 전원 |
| CN10-7의 AVDD | MCU VDDA/VREF+로 이어지는 아날로그 전원 |

이번 목적은 ADC 전원 상태에 따라 배터리 측정 경로를 차단하는 것이다. 그래서 AVDD 감시가 목적과 직접 맞는다. 보드 전원망 이름 `VDD`와 외부 IC의 핀 이름 `VDD`는 구분한다. IC 핀 이름이 VDD라고 해서 반드시 CN7-5에 연결해야 한다는 뜻은 아니다.

### 31-3. 공급과 제어의 연결 후보

```text
Nucleo AVDD (CN10-7)
  ├─ MCU VDDA/VREF+             : 기존 보드 연결
  ├─ TPS3840PL30.VDD            : 공급 + 이 전압 감시
  └─ TMUX1511.VDD               : 스위치 IC 구동 전원

TPS3840PL30.RESET ── TMUX1511.SEL1 / SEL2
각 IC의 GND ── 보드와 공통 기준 GND
```

TMUX1511의 VDD는 스위치 내부 회로에 전원을 공급하는 핀이고, S/D는 측정 신호가 통과하는 핀이다. 전원을 같은 곳에서 가져와도 두 핀의 역할은 다르다. TMUX의 정상 공급 범위는 TI **SCDS390B Rev.B, 2025-03, p4 §5.3 VDD 행의 1.5~5.5V**이며 명목3.3V는 그 안에 있다. [공식 PDF](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=4).

같은 전원을 쓴다는 사실만으로 ADC 입력이 모든 시각에 안전하다고 결론내리지 않는다. 검출/출력 지연, 스위치 전이, 출력 방전, 동작 범위 아래의 조건은 34절에서 연결해서 확인한다.

### 31-4. 부품 자체가 소비하는 전류 읽기

`IDD`는 IC의 VDD 핀으로 들어가는 공급 전류다. 단위부터 통일한다: 1000nA=1µA, 1000µA=1mA.

| 부품 | 원문 위치 | Typical | Maximum | 적용할 조건 |
| --- | --- | --- | --- | --- |
| TPS3840 | Rev.E p6 §6.5 `IDD` 행; p7 각주(3) | 300nA=0.3µA | 700nA=0.7µA | 공급이 VIT+보다 높음, TA −40~125°C. 표 머리 CT/MR open 등 조건 포함. Typical은 TJ25°C. 각주(3)은 VIT+=VIT−+VHYS |
| TMUX1511 | Rev.B p6 §5.5 `IDD` 행 | 37µA | 70µA | VSEL=0V/1.4V/VDD, VS=0~5.5V의 지정 시험. 표 머리 VDD1.5~5.5V, TA−40~125°C; Typical은 VDD3.3V/TA25°C |

원문: [TPS p6](https://www.ti.com/lit/ds/symlink/tps3840.pdf#page=6), [TMUX p6](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=6). 신호의 실제 적용 범위는 TMUX p4 §5.3도 함께 따른다.

감시기 1개와 4채널 스위치 IC 1개를 사용하는 초안이므로, 해당 IDD 행의 소계는 다음과 같다.

```text
Typical 소계 = 0.3µA + 37µA = 37.3µA
Maximum 행 소계 = 0.7µA + 70µA = 70.7µA = 0.0707mA
```

TMUX를 두 신호 채널에 사용한다고 IC의 IDD를 두 배로 계산하지 않는다. 위는 두 부품의 지정 조건 공급전류 소계이며 **완성 회로의 모든 상태에 대한 총 소비전류 상한**은 아니다. TPS RESET이 SEL 입력에 공급하는 전류, 전환 순간 및 디커플링 충전 등은 별도로 다루어야 한다. MR/CT/SEL 연결을 완성한 뒤 조건과 중복 여부를 확인한다.

### 31-5. 분압 회로 전류와 IC 공급 전류를 구분하기

```text
IC 공급: AVDD → TPS/TMUX 내부 회로 → GND

측정 신호: VRAIL → 12k → 12k → VDIV → 1k → TMUX S/D → VADC → 47k → GND
                              └→ 4.7k → GND
```

앞의 ON 시뮬레이션에서 R5에 약50µA가 흐른 것은 16V VRAIL이 공급한 신호 경로 전류다. 이를 AVDD에서 공급되는 TMUX IDD와 같은 전류로 해석하지 않는다. 실제 소자 누설은 따로 남지만, 주된 공급 경로를 먼저 구분해야 전원 부하를 올바르게 계산할 수 있다.

### 31-6. 소비전류가 작아도 남는 검토

이번 IDD 소계는 큰 DC 부하를 추가하는 구성은 아니라는 후보 판단에 도움이 된다. 하지만 AVDD는 ADC 기준에도 연결되므로 전류 크기만으로 채택을 확정할 수 없다. 배선의 임피던스, 스위치 동작에 따른 잡음, 디커플링, 전원 하강 시 관계를 확인해야 한다.

- TPS: **Rev.E p28 §8.3 및 §8.4.1**에서 낮은 임피던스의 VDD 연결과 핀 근처 최소0.1µF 세라믹 권고를 읽는다. [원문](https://www.ti.com/lit/ds/symlink/tps3840.pdf#page=28).
- TMUX: **Rev.B p26 §9**에서 전원 잡음 전파를 줄이는 디커플링과0.1~10µF 권고를 읽는다. [원문](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=26).

이것은 VDD–GND의 **전원 디커플링**이다. 앞에서 VADC–GND에 가정한 C2=100pF와 위치·목적이 다르다. 실제 값과 배치는 32~33절에서 다룬다. TPS 공급 앞에 독립적으로 큰 저항/커패시터 필터를 추가하면 감시 핀의 전압 변화가 실제 MCU VDDA와 달라질 수 있으므로 함께 검토해야 한다.

대안은 TPS는 AVDD에서 감시하고 TMUX 전원은 CN7-5 VDD에서 공급하는 것이다. AVDD 부하는 줄지만 서로 다른 공급 경로의 전원 순서·제어 레벨 관계를 검토해야 한다. 지금은 공통 AVDD 후보로 상세 검토를 계속하고, 잡음/전원 조건이 맞지 않으면 이 대안을 비교한다.

### 31-7. 필기 결론과 이번 확인 작업

> TPS3840은 자신의 VDD 핀 전압을 감시하므로 ADC 전원망 AVDD에 연결하는 후보가 목적에 맞는다. TMUX1511도 같은 AVDD에서 공급하는 초안을 유지한다. 두 IC의 IDD maximum 행 소계는70.7µA지만, 이는 전체 회로의 전 상태 소비전류나 보호 성능을 보증하지 않는다. 공급 부하와 아날로그 잡음·전원 순서 검토를 구분한다.

**이번 사용자 작업:** TPS p6 §6.5와 TMUX p6 §5.5의 IDD 행에서 값·단위·조건을 대조한다. 특히 TPS의 nA와 TMUX의 µA 차이를 확인한다. 새 시뮬레이션이나 배선 변경 없이 여기까지 읽고 다음 32절 MR/CT/RESET으로 진행한다. 사용자에게서 구체적인 읽기 확인 결과나 새 실측 결과는 아직 받지 않았다.

## 32. TPS3840의 MR·CT·RESET 연결 정하기

### 32-1. 이번 목적과 연결 초안

앞 절에서 전원 공급 후보를 정했다. 이번에는 감시기가 어떤 조건으로 스위치 연결을 허용할지 핀별로 정한다. TPS3840PL30의 DBV/SOT-23-5 핀 번호를 기준으로 한다.

| 핀 | 역할 | 이번 상세 설계 후보 |
| --- | --- | --- |
| 1 RESET | active-low push-pull 상태 출력 | TMUX SEL1/SEL2 제어. MCU NRST와 연결하지 않음 |
| 2 VDD | 공급 및 감시 입력 | 보드 AVDD, 앞 절 후보 유지 |
| 3 GND | 기준 접지 | 공통 GND |
| 4 MR | 외부에서 리셋 상태를 요구하는 입력 | 미사용·미연결 |
| 5 CT | 복귀 지연 설정용 커패시터 연결 핀 | 우선 미연결, 외부 지연 커패시터 없음 |

근거: [TI TPS3840 SNVSB03E Rev.E, 2026-05](https://www.ti.com/lit/ds/symlink/tps3840.pdf#page=4), **p4 Figure5-1 및 Table5-1**. 본문 인쇄 쪽과 PDF 쪽은 같다. 사용자가 핀 연결을 검토하는 단계이며 제작 회로도 수정/실물 연결을 수행하지 않았다.

### 32-2. MR은 감시 전압 외에 차단을 요구할 수 있는 입력

MR은 Manual Reset 입력이다. LOW를 인가하면 전압이 정상이어도 TPS의 RESET 출력을 활성 상태(PL에서는 LOW)로 만들 수 있다. 이 초안에서는 그 출력이 TMUX로 가므로 **측정 경로 차단을 요구하는 입력**이 된다. 입력 이벤트에도 규정된 펄스 폭/지연이 있으며 즉시 동작이라고 일반화하지 않는다.

이번에는 AVDD 감시에 의한 자동 차단만 구성하고 별도 수동 입력은 사용하지 않는다. 따라서 **MR 미연결을 후보로 선택**한다. 이는 아무 입력이나 띄워 둬도 된다는 뜻이 아니다. 이 부품에는 내부 MR 풀업이 있고 미사용 시 개방을 허용한다. 내부 풀업은 MR이 정상 동작에서 비활성 HIGH 쪽으로 유지되도록 하는 경로다.

읽을 위치: TPS **p4 Table5-1 MR 행**, **p6 §6.5 RMR=100kΩ 행**, **p18 §7.3.3 및 p19 첫 문단**. MR을 GND에 묶으면 수동 리셋 요구가 지속되므로 이번 의도와 다르다. 외부 구동을 추가한다면 MR 전압이 해당 IC의 VDD를 넘지 않는 조건까지 다시 검토해야 한다.

### 32-3. CT는 전원이 회복된 뒤 다시 연결할 때의 지연을 설정한다

이번 CT-open 후보는 외부 커패시터로 복귀 지연을 더 늘리지 않는 구성이다. CT가 비어 있어도 내부 복귀 지연은 남는다. TPS **p7 §6.6 tD의 CT-open 행은 MAX50µs**이며 MIN/TYP 칸은 비어 있다. 따라서 지정 시험 조건에서의 최대값으로 읽고, 항상50µs를 기다리거나 최소50µs를 확보한다는 뜻으로 해석하지 않는다. 외부 CT의 기능/식은 **p18 §7.3.2**에 있다.

**2026-11-03 정정:** 사용자가 MAX 열을 지적했다. 공식 Rev.E PDF p7 전체를 렌더하여 열 머리글과 수치의 가로 위치를 다시 대조했다. CT-open50µs는 MAX, CT10nF의6.2ms와 CT1µF의619ms는 TYP다. 이전 `typical50µs` 및 `최대값으로 읽으면 안 된다`는 설명은 잘못이므로 철회한다. 단위는 전류µA가 아닌 시간µs다. [원문 표 이미지와 대조 기록](../../assets/logs/pcb_design/2026-11-03_nucleo_power_path/README.md#tps3840-복귀-지연-열-정정--2026-11-03). 이 정정은 CT-open 후보 자체나 CT-open tD를 tSTRT에 중복 가산하지 않는 규칙을 바꾸지 않는다.

전원 복귀와 차단의 역할을 분리한다.

```text
정상 동작 중 전원 하강:
AVDD가 VIT− 아래로 내려감 → 검출 지연 tP_HL → RESET LOW → TMUX OFF

동작 중 저전압에서 회복:
AVDD가 VIT+를 넘어 회복 조건을 유지 → 복귀 지연 tD → RESET HIGH → TMUX ON
```

CT는 두 번째 경로의 복귀 대기 시간을 조절한다. CT를 추가하여 복귀 시간을 늘리는 것으로 앞서 검토한 빠른 전원 하강의 검출 지연 문제를 해결할 수는 없다.

CT-open을 먼저 검토하는 이유는 현재 추가 하드웨어 복귀 지연의 요구값이 정해지지 않았기 때문이다. 필요한 근거 없이 긴 시간을 고정하지 않고, 34절 전원 상태 검토에서 추가 지연이 필요하면 CT를 다시 선정한다. **스위치 ON 허용과 ADC 측정값 유효화도 별개**다. 연결 직후의 입력 정착·ADC 초기화/취득 조건은 측정 절차에서 다루어야 한다.

완전 무전원에서 켜지는 경우는 tSTRT 조건이다. p7 §6.6 및 **p9 Figure6-2의 각주A**에 따라 CT-open tD는 tSTRT에 포함되므로 중복 가산하지 않는다. 타이밍 표의 공급 범위1.5~10V, 온도−40~125°C, 출력 부하10pF, VDD slew 및 각 행 조건을 실제 회로 전체로 일반화하지 않는다. 기존 tP_HL15/30µs의 지정 입력 스텝 조건도 유지한다.

### 32-4. RESET은 이번 회로에서 스위치 제어 신호로 사용한다

PL의 active-low는 RESET 기능이 LOW에서 활성이라는 뜻이다. 정상 복귀 후 HIGH이고, 저전압 검출 후 LOW가 되는 출력 방향이 TMUX의 HIGH=ON/LOW=OFF와 맞는다.

| 감시 결과/시점 | TPS RESET | TMUX의 목표 상태 |
| --- | --- | --- |
| 정상 전압으로 복귀 지연까지 완료 | HIGH | 연결 ON |
| 저전압 검출 지연 후 | LOW | 차단 OFF |
| 전압이 회복되어 복귀 지연 중 | LOW 유지 | 차단 유지 |

이 표는 유효한 공급/부하 조건에서의 논리 대응이다. 전원이0V까지 내려가는 전체 구간의 출력 보증은34절에서 별도로 다룬다.

TPS의 PL은 HIGH/LOW를 능동적으로 구동하는 push-pull 출력이므로 HIGH를 만들기 위한 외부 풀업을 추가하지 않는다. **TPS p19 §7.3.4.1**에서 PL과 DL(open-drain)을 구분한다. TPS 타이밍 표 머리의100kΩ 시험용 풀업을 PL 회로의 필수 부품으로 옮기지 않는다.

TMUX 근거는 [TI SCDS390B Rev.B, 2025-03, p22 §7.5 Table7-1](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=22)이다. TPS 출력 전압/부하와 TMUX 입력 규격 대조는33절에서 연결한다. RESET이라는 핀 이름만으로 MCU NRST에 연결하지 않는다. 여기서는 측정 신호 통로를 제어하므로, 스위치가 다시 켜져도 모터 ARM이나 구동 재개 명령이 발생하는 구조가 아니다.

### 32-5. 전원 커패시터와 CT 커패시터를 구분한다

```text
AVDD ──┬── TPS VDD(2)
       └── C_SUP=100nF 후보 ── GND

GND ────── TPS GND(3)
미연결 ─── TPS MR(4)
미연결 ─── TPS CT(5)
           TPS RESET(1) ── TMUX SEL1/SEL2
```

`C_SUP`는 역할 설명용 이름이다. 제작 CAD의 참조번호를 배정하지 않았다. 전원 핀2와 접지 핀3 가까이에 두는100nF 세라믹을 첫 후보로 정한다. 근거는 TPS **p17 §7.3.1**의0.1~1µF 우회 용량 설명과 **p28 §8.4.1**의 전원 연결/배치 권고다. 부품 정격·패키지와 총 AVDD 용량/하강 파형 검증은 남는다.

전원 커패시터는 IC 근처에서 순간 전류를 공급하고 전원 흔들림을 줄이는 용도다. CT 커패시터는 복귀 타이머용이다. VADC의100pF는 앞선 방전 모델의 가정이다. 따라서 **CT 미연결과 전원 디커플링 추가는 모순되지 않는다.** CT를 개방할 때 긴 배선이나 큰 패드를 붙여 기생 용량을 늘리지 않는 주의도 TPS p28 §8.4.1에서 확인한다.

### 32-6. 필기 결론과 다음 작업

> TPS3840PL30은 AVDD에서 공급받는다. MR은 미사용·개방, CT도 우선 개방하며, RESET은 TMUX SEL1/SEL2에 연결한다. VDD–GND 사이에는 핀 가까이에 둘 별도의100nF 디커플링 커패시터를 후보로 둔다. CT 개방에도 복귀 지연은 남고, 지정 시험 조건에서 tD는 최대50µs다. 해당 행의 MIN/TYP는 비어 있으므로 항상50µs 또는 최소50µs라고 해석하지 않는다. 이는 연결 초안이며 전체 전원 OFF 보호 검증은 계속 진행한다.

이번 사용자는 **TPS p4 Table5-1에서 MR/CT/RESET 세 행**을 연결표와 대조한다. 다음33절은 TMUX의 SEL/S/D·미사용 채널·주변 부품이며, 새 시뮬레이션이나 실물 결선을 시작하지 않는다. 사용자의 다음 진행 요청을 핀 읽기 확인이나 설계 최종 승인으로 기록하지 않는다.

## 33. TMUX1511의 두 측정 채널과 제어 핀 연결하기

### 33-1. 이번 목적과 자료 위치

32절에서 TPS의 RESET 출력을 스위치 제어에 쓰기로 초안을 잡았다. 이번에는 그 선을 받을 핀과, 실제 측정 전압이 통과할 핀을 구분하고 전기적 연결 조건을 대조한다.

- TMUX: **TI SCDS390B Rev.B, 2025-03**, [p3 §4 Figure4-1 및 Pin Functions](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=3). 핀 번호는 **PW, 14핀 TSSOP 열**을 읽는다. 번호 설명을 위한 기준 패키지 후보이며 구매/풋프린트 확정이 아니다.
- 같은 문서 [p6 §5.5 LOGIC INPUTS의 VIH/VIL/RPD 행](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=6), p22 §7.4/§7.5 Table7-1, p26 §9.
- TPS: **TI SNVSB03E Rev.E, 2026-05**, [p6 §6.5 TPS3840PL 구획의 VOH/VOL 행](https://www.ti.com/lit/ds/symlink/tps3840.pdf#page=6).

위 자료의 인쇄 쪽과 PDF 쪽은 같다. TMUX p3/p6와 TPS p6는 원문 페이지를 렌더하여 핀 열·MIN/TYP/MAX 열을 시각적으로 확인했다. [검토 이미지](../../assets/logs/pcb_design/2026-11-03_nucleo_power_path/README.md#tmux1511-핀논리-레벨-대조--2026-11-03).

### 33-2. 신호가 흐르는 S/D와 스위치를 움직이는 SEL

TMUX1511은 독립된 SPST 스위치 네 개를 가진다. 한 채널은 S1과 D1 사이의 연결을 SEL1이 제어하는 구조다. S/D는 양방향 신호 핀이지만 이번 도면에서는 S를 분압기 쪽, D를 ADC 쪽으로 통일한다.

```text
측정 전압: 분압기 → 1kΩ → S1 ──[스위치1]── D1 → ADC
                                  ↑
제어 신호: TPS RESET ───────────── SEL1
```

SEL1의 HIGH는 연결, LOW는 차단을 지시한다. SEL에 배터리 전압을 측정용으로 넣는 것이 아니다. 또한 스위치는 네 입력 중 하나를 공통 출력에 고르는 구조가 아니다. 이번에는 두 경로를 동시에 연결/차단하면서 각 전압은 서로 다른 ADC 입력에서 읽는다. 논리 대응은 TMUX p22 Table7-1을 따른다.

### 33-3. 두 전압 채널의 연결 초안

| 기능 | PW/TSSOP 핀 | 프로젝트 연결 후보 |
| --- | --- | --- |
| 배터리 측정 통로 | S1=2, D1=3 | 배터리 분압기 뒤1kΩ → S1, D1 → VADC_BAT |
| 모터 공급 측정 통로 | S2=5, D2=6 | 모터 공급 분압기 뒤1kΩ → S2, D2 → VADC_MOTOR |
| 두 통로 제어 | SEL1=1, SEL2=4 | 두 SEL만 TPS RESET에 함께 연결 |
| IC 공급 | VDD=14, GND=7 | AVDD 후보와 공통 GND |

```text
K1-30 배터리측 → 전용 분압/필터 → 1kΩ → S1 / D1 → VADC_BAT → PA4 ADC
                                                       └→ 47kΩ → GND
K1-87 모터측   → 전용 분압/필터 → 1kΩ → S2 / D2 → VADC_MOTOR → PB0 ADC
                                                       └→ 47kΩ → GND

TPS RESET ──┬── SEL1
            └── SEL2
```

각 분압/필터는 앞에서 검토한 상단12kΩ+12kΩ, 하단4.7kΩ, VDIV–GND100nF 구조다. 각 ADC 출력 노드에도47kΩ을 하나씩 둔다. K1-30과 K1-87의 원전압이나 두 VADC를 서로 연결하지 않는다. TMUX로 들어가는 것은 **분압된 신호**다.

PA4/PB0는 기존 후보 계약이며 실제 배선 지시가 아니다. 두 SEL을 함께 구동해도 S1/D1과 S2/D2 사이에 측정 신호 연결이 생기는 것은 아니다. 보호 저항 부하가 유지되므로 앞서 계산한 부하 포함 환산비를 사용한다. 스위치 제어선은 MCU NRST나 모터 ARM과 연결하지 않는다.

### 33-4. TPS의 HIGH/LOW를 TMUX가 알아듣는가

출력과 입력이 모두 HIGH/LOW라는 이름을 써도 전압 기준이 맞아야 한다. VOH/VOL은 **TPS가 내보내는 전압**, VIH/VIL은 **TMUX가 입력으로 인정하는 전압 범위**다.

| 확인 | 데이터시트의 값 | 이번 조건의 비교 |
| --- | --- | --- |
| TMUX HIGH 입력 | VIH MIN1.2V, MAX5.5V | TPS HIGH가1.2V 이상이어야 함 |
| TMUX LOW 입력 | VIL MIN0V, MAX0.45V | TPS LOW가0.45V 이하여야 함 |
| TPS PL HIGH 출력 | VOH MIN0.8×VDD | VDD=3.3V에서 최소2.64V > 1.2V |
| TPS PL LOW 출력 | VOL MAX200mV | 최대0.20V < 0.45V |

TPS 조건: p6 PL 구획의 **1.5V<VDD<5V** 행을 사용한다. HIGH는 VDD>VIT+ 및 소스 전류2mA, LOW는 VDD<VIT− 및 싱크 전류2mA 조건이다. 표의 온도 범위는−40~125°C다. 정상 HIGH는 복귀 지연이 끝난 상태로 해석한다.

TMUX 조건: p6 표 머리의 VDD1.5~5.5V, GND0V, TA−40~125°C 범위다. VIH/VIL의 값은 TYP가 아니라 MIN/MAX 열이다. **0.45V보다 높고1.2V보다 낮은 입력에는 확정된 HIGH/LOW 판정을 요구하지 않는다.**

따라서 위 유효 공급/출력 상태에서는 직접 연결할 논리 레벨 여유가 있다. 다만 이것은 정상 논리 호환성의 대조이며 전원이0V까지 떨어지는 전 구간, 제어선의 용량과 전이 시간, 검출 지연 후 방전 완료까지 보증하지 않는다. 이 구분을34절에서 이어간다.

부하 참고: TMUX p6 IIH/IIL 행의 입력당 ±2µA 한계와 실제 SEL 전압 조건도 함께 읽는다(IIH는 VSEL=1.8V/VDD, IIL은0V). 두 입력을 구동하는 부하와 과도 용량을 분리한다. 앞 절 IDD 소계나 내부 풀다운 전류에 입력 누설을 중복 가산하여 전체 소비전류 상한으로 확정하지 않는다.

### 33-5. 미사용 채널과 두 종류의 풀다운

이번 PW 초안에서는 사용하지 않는 **SEL3=10, SEL4=13을 GND에 연결**한다. 미사용 S3=9/D3=8/S4=12/D4=11도 GND에 두어 별도 부유 노드를 만들지 않는 후보로 정한다. 이는0V가 신호 핀 권장 범위에 속한다는 p4 §5.3을 바탕으로 한 **프로젝트 설계 선택**이며 제조사가 미사용 S/D의 접지를 의무화했다는 뜻은 아니다. p3의 N.C. 행은 다른 패키지의 전용 NC 핀 설명이므로 이 선택의 근거로 사용하지 않는다.

SEL에는 내부 풀다운이 있으며 p6 RPD의 **TYP6MΩ**이다. p22 §7.3.7/§7.4에서 기본 LOW 방향을 만드는 기능을 읽는다. 이것과 외부 R5는 연결 노드와 목적이 다르다.

| 저항 | 연결 | 목적 |
| --- | --- | --- |
| 내부 풀다운 TYP6MΩ | SEL–GND | 제어 입력의 기본 LOW 방향 |
| 외부 R5 후보47kΩ | VADC–GND | 차단 후 ADC 쪽 전하/누설 경로 |

TPS가 구동하는 SEL1/2에는 이번 단계에서 새 외부 풀다운을 추가하지 않는다. 내부6MΩ만으로 감시기 출력이 정의되지 않는 모든 저전압 상태까지 안전하다고 판단하지 않으며, 그 검토는34절에 남긴다.

### 33-6. TMUX 전원에도 별도의100nF 후보를 둔다

```text
AVDD ──┬── TMUX VDD(14)
       └── C_MUX=100nF 후보 ── GND
GND ────── TMUX GND(7)
```

TI TMUX p26 §9는0.1~10µF의 전원 디커플링을 권고한다. 이번에는 범위 안의0.1µF=100nF 세라믹을 초기 후보로 두고 IC 전원/접지 핀 가까이 배치한다. C_MUX는 설명용 이름이고 제작 CAD 참조번호/패키지를 배정하지 않았다.

TPS 근처100nF와 TMUX 근처100nF는 같은 AVDD–GND에 연결되어도 각각의 IC 가까이에서 순간 전류 경로를 짧게 만드는 부품이다. 분압 노드의 필터100nF, CT 지연용 커패시터, 학습 모델 C2=100pF와 혼동하지 않는다. 추가 전원 용량이 AVDD 하강에 미치는 영향과 실제 잡음은 아직 검증하지 않았다.

### 33-7. 필기 결론과 이번 확인 작업

> TMUX1511의 두 스위치로 배터리/모터 공급 전압의 분압 신호를 각각 통과시킨다. S/D는 측정 신호, SEL은 연결 허용 명령이다. SEL1/2를 TPS RESET으로 함께 구동하고 측정 출력은 분리한다. PW 핀을 기준으로 연결 후보를 작성했으며, 미사용 채널은 접지하고 전원100nF를 별도로 두는 초안이다. 유효 공급 조건에서 TPS 출력과 TMUX 입력의 논리 레벨은 맞지만, 시작·하강·완전 OFF·복귀 전체의 보호 검증은 다음 단계다.

**이번 사용자 작업:** TMUX p3의 **TSSOP 열**에서 SEL1/S1/D1 및 SEL2/S2/D2를 위 연결표와 대조하고, p6 VIH/VIL과 TPS p6 PL VOH/VOL의 MIN/MAX 위치를 읽는다. 새 시뮬레이션이나 실물 결선은 요구하지 않는다. 다음34절에서 네 전원 상태를 순서대로 검토한다. 아직 사용자 대조 결과를 받지 않았다.

## 34. 전원 시작·정상·하강·완전 OFF·복귀를 연결하기

### 34-1. 이번에 추적할 전압과 상태

33절의 배선 초안을 시간 순서에 적용한다. 이번에는 새 하강 기울기를 가정해 시뮬레이션을 반복하지 않고, 어떤 상태에 어떤 규격을 적용할지 정리한다.

| 이름 | 이번 초안에서의 의미 |
| --- | --- |
| VRAIL | 배터리측 또는 모터 공급측의 분압 전 측정 대상 |
| AVDD | TPS/TMUX 공급 후보이며 Nucleo ADC 전원망에 연결되는 노드 |
| RESET=VCTRL 후보 | TPS가 TMUX SEL1/2로 보내는 제어 신호 |
| VADC | 스위치 뒤의 실제 ADC 입력 노드 |

AVDD가 내려가도 VRAIL은 남을 수 있다. 이번 보호 검토는 이 독립성을 다룬다. 실제 TPS/TMUX 핀과 MCU VDDA 사이의 배선·디커플링 때문에 생기는 차이는 실물 검증 대상으로 남긴다. 공급망 이름이 같다는 것만으로 빠른 과도 파형까지 같다고 보장하지 않는다.

주 자료는 **TI TPS3840 SNVSB03E Rev.E(2026-05)**의 [p9 Figure6-2](https://www.ti.com/lit/ds/symlink/tps3840.pdf#page=9), p7 §6.6/각주, p17 §7.3.1.1, p19~20 §7.4다. TMUX는 **TI SCDS390B Rev.B(2025-03)**의 p4 §5.3, p6 IPOFF, p7 §5.7, p15~16 §6.6/Figure6-6, p22 §7.3.4를 사용한다. 인쇄 쪽과 PDF 쪽이 같다.

### 34-2. 전원을 처음 켤 때 — 기동 조건을 먼저 만족한다

설계 의도는 전원이 충분해지기 전에는 측정 통로를 허용하지 않는 것이다. 그런데 AVDD=0V 근처에서 TPS가 정상 감시 기능을 수행한다고 가정하면 안 된다.

**VPOR는 RESET 상태를 제어할 수 있는 최저 전원 경계를 나타내는 규격**이다. VDD<VPOR에서 RESET은 미정이다. 항상 HIGH라는 뜻도, 항상 LOW라는 뜻도 아니다. TPS **p19 Table7-1, p20 §7.4.2/§7.4.3**에서 이 구간을 읽는다. 실제 전압 한계는 p6 PL VPOR 행과 p7 각주(4)의 부하/기울기 조건을 함께 따라야 한다.

```text
AVDD=0V 부근
  → TPS RESET의 논리값을 확정하지 않음
  → TMUX의 무전원 보호 규격을 별도로 적용

AVDD가 올라옴
  → 감시기가 동작 가능한 구간에서 RESET 차단 상태 유지
  → 정상 복귀 문턱과 기동 지연 조건 성립
  → RESET HIGH → SEL1/2 HIGH → 측정 통로 연결
```

최소 동작 전압 미만에서 올라온 기동에는 **tSTRT** 조건을 적용한다. CT-open의 값은 TPS **p7 §6.6에서 MIN100 / TYP220 / MAX350µs**다. 이것을 임의로 VIT+ 통과 시각에350µs를 더하는 규칙으로 바꾸지 않고 **p9 Figure6-2의 기산점/파형과 각주A**를 함께 읽는다. CT-open의 tD는 tSTRT에 이미 포함되므로 MAX350+50µs로 중복 가산하지 않는다.

시험 범위는 p7 표의 공급1.5~10V, CT/MR open, 출력 부하10pF, TA−40~125°C, 지정 전원 slew 및 각주 조건이다. Figure6-2는100mV/µs를 명시한다. 다른 실제 상승 파형 전체에 같은 최대 기동 시간을 곧바로 확장하지 않는다.

### 34-3. 정상 운용 중 — 연결 허용과 측정 유효를 구분한다

기동 또는 복귀 조건이 끝나 RESET HIGH가 되면 두 스위치는 연결된다. 목표 흐름은 다음과 같다.

```text
정상 AVDD/복귀 조건 성립 → RESET HIGH → TMUX ON
                                      ↓
                  분압 신호 정착 및 ADC 취득 조건 확인
                                      ↓
                               새 측정값 사용
```

STM32가 초기화 중이거나 입력 전압이 아직 정착 중이면 스위치 ON만으로 측정값을 유효 처리하지 않는다. 실제 ADC 순서/안정 시간·검증은 미구현이다. 전원이 이상해진 뒤 이전의 정상 측정값을 계속 최신값처럼 사용하지 않도록 유효성/오래된 값 처리도 후속 요구로 남긴다. 하드웨어 차단이 소프트웨어 유효 플래그를 자동 구현해 주는 것은 아니다.

PL30의 명목 하강 문턱 VIT−는3.0V이며,100mV typical 히스테리시스를 더한 명목 복귀 문턱 VIT+는3.1V다. 정확한 고정값이 아니라 문턱 정확도/히스테리시스 편차가 있다. TPS **p6 §6.5 VIT−/VHYS 및 p17 Figure7-1**을 따른다.

히스테리시스 구간에서는 이력이 중요하다. 명목3.05V라도 정상 HIGH에서 내려오는 중인지, 이미 저전압을 검출하고 회복 중인지에 따라 RESET 상태가 다를 수 있다. 전압 하나만 보고 즉시 ON/OFF를 결정하는 표로 단순화하지 않는다.

### 34-4. 전원이 내려갈 때 — 차단 명령과 방전 완료는 다른 시점이다

```text
AVDD가 VIT− 아래로 내려감
        ↓  검출 지연 tP_HL
TPS RESET LOW
        ↓  TMUX의 제어 입력에 따른 전이
측정 통로 차단
        ↓  ADC 노드의 용량과47kΩ 등에 따른 방전
VADC가 허용 범위로 내려가는지 확인
```

tP_HL의 TYP15/MAX30µs는 TPS **p7 §6.6의 지정 VDD 스텝(VIT+→VIT−보다10% 낮은 전압), 각주(2), p9 Figure6-2**에 따른 값이다. 이전 고정30µs TRAN은 이 지연의 의미를 보여 주는 모델이며 실제 모든 하강 파형에 대한 검증이 아니다.

TMUX도 전이가 즉시 끝나지 않는다. [p7 §5.7 tTRAN](https://www.ti.com/lit/ds/symlink/tmux1511.pdf#page=7)과 p15 Figure6-5는 **SEL 제어에 의한 전이**를 다룬다. 별도의 p15~16 §6.6/Figure6-6는 **TMUX 공급 자체의 상승/하강에 의한 전이**를 다룬다. 두 규격을 같은 시간으로 대체하거나 무조건 직렬 합산하지 않는다.

구체적으로 TMUX p7 tOFF(VDD)의 TYP1.2/MAX4µs는 VS3.6V, 공급 fall time1µs, RL200Ω/CL15pF의 시험이며 p16 그림은 공급1.5V 교차와 출력90% 측정점을 보여 준다. 우리47kΩ/가정100pF에서 전원 하강 뒤 언제 완전히 방전되는지에 대한4µs 보장이 아니다.

앞서 C2=100pF·R5=47kΩ으로 계산한99% 방전21.64µs도 차단 이후의 단순 RC 모델이다. 검출 지연까지 포함한 전체 차단 시간이 아니고 실제 ADC 용량이 확인된 것도 아니다. 이제 필요한 판단은 임의 기울기의 반복보다 **실제 파형/허용 한계에 대해 검출·전이·방전 과정에 여유가 있는가**다.

### 34-5. 매우 낮은 전압과 완전 OFF — 서로 다른 규격을 확인한다

| 전원 구간 | 사용할 근거 | 아직 확대하면 안 되는 주장 |
| --- | --- | --- |
| 두 부품의 유효 공급 범위 | TPS RESET 출력과 TMUX SEL 입력 조건 | 전압이0V일 때도 같은 논리 출력 보증 |
| AVDD가1.5V 아래로 내려가는 중 | TPS §7.4, TMUX §5.3의 저전압 신호 범위 및 공급 전이 규격 | 정상 SEL 논리 표만으로 전 구간의 차단/누설 시간 보증 |
| AVDD=0V에 정착 | TMUX powered-off protection/조건별 IPOFF | 완전 절연, 누설0, STM32 핀 자동 PASS |

TPS의 최소 동작 전압 아래 구간에는 UVLO/VPOR 관련 동작 설명이 있지만, 실제 RESET 부하와 전원 slew 조건을 대조해야 한다. TPS p6 PL VPOR 행은 **MAX300mV, VOL(max)200mV, sink200nA** 조건이고 p7 각주(4)는 slew≤100mV/µs다. 이 값을 앞 절의2mA 출력 시험이나 모든 SEL 부하 조건과 혼합하지 않는다.

TMUX p4 §5.3은 **VDD<1.5V에서 S/D0~3.6V**의 권장 범위를 명시한다. 따라서 이 구간의 정보가 전혀 없는 것은 아니다. 다만 p6 IPOFF는 VDD=0V에서의 조건별 시험이며, 공급 전이 시간/누설·MCU 입력 허용을 함께 보지 않고 완성 회로 전체를 PASS로 만들 수는 없다.

완전 OFF에서는 TMUX **p22 §7.3.4**의 고임피던스 동작과 **p6 IPOFF** 조건을 적용한다. 여기서 고임피던스는 전류가 전혀 흐르지 않는다는 뜻이 아니다.

```text
VRAIL은 남아 있음 → 분압기/스위치 입력에도 전압이 남을 수 있음
TMUX 공급0V       → 지정 조건에서 통로 고임피던스
ADC 출력 쪽      → 47kΩ 방전 경로 + 실제 누설/MCU 핀 특성
```

앞서 읽은±10nA 행은 VDD0V·VS0~3V·VD0V·TA25°C, ±2µA 행은 VDD0V·VS0~3.6V·VD0V·표 온도−40~125°C다. 두 행을 섞거나0V가 아닌 공급 전체로 일반화하지 않는다. 잔류 전압의 단순 I×47k 계산만으로 무전원 STM32 핀 보호가 입증되지는 않는다.

### 34-6. 전원이 회복될 때 — 어디까지 내려갔는지에 따라 구분한다

**동작을 유지할 수 있는 범위의 일시적인 저전압에서 회복한 경우**에는 다음 순서를 따른다.

```text
저전압 검출로 RESET LOW
  → AVDD가 VIT+를 넘어 복귀 조건 유지
  → tD 후 RESET HIGH
  → TMUX 연결
  → 입력 정착/ADC 조건 확인 후 새 측정값 사용
```

CT-open tD는 TPS **p7 §6.6 MAX50µs**, MIN/TYP 공란이다. 최소50µs를 확보한다는 뜻이 아니다. 따라서 CT-open을 선택한 것만으로 특정 길이의 최소 안정 대기 시간이 보장된다고 주장하지 않는다.

**감시기 최소 동작 전압 미만까지 내려갔다 회복하는 경우**에는 기동 tSTRT 조건을 다시 확인한다. 완전히0V가 되었을 때만 이 구분이 필요한 것이 아니다. TPS **p9 Figure6-2** 가운데의 얕은 하강은 tD, 오른쪽의 깊은 하강 뒤에는 tSTRT+tD가 표시되어 있고, 각주A가 CT-open tD의 중복 가산을 막는다.

두 경우 모두 측정 통로의 복귀다. 모터 ARM·자동 재주행을 허용한다는 설계 변경이 아니다.

### 34-7. 상태표와 필기 결론

| 상태 | 목표 동작/판단 | ADC 결과 취급 |
| --- | --- | --- |
| 시작 | 유효 전원과 기동 조건을 만족한 뒤 연결 허용 | 초기화/정착 확인 전 유효 처리하지 않음 |
| 정상 | 두 분압 신호를 각 ADC에 전달 | 정해진 취득·환산 조건의 새 결과 사용 |
| 하강 | 검출→차단 전이→방전 과정 확인 | 전원 이상/오래된 값 처리 요구를 별도 구현 |
| 완전 OFF | TMUX 무전원 규격과 누설/잔류 전압 확인 | MCU 정상 측정 상태가 아님 |
| 복귀 | 얕은 하강은tD, 깊은 하강은기동 조건 대조 | 재연결만으로 곧바로 유효 처리하지 않음 |

> 전원 상태에 따라 같은 연결 회로에 적용할 규격이 달라진다. 유효 공급 범위에서는 TPS RESET으로 TMUX를 제어하고, 완전 무전원에서는 TMUX 자체의 보호/누설 조건을 확인한다. 전원 하강 시 검출·차단·방전은 각각 시간이 걸리며, 전원 복귀 시 연결 허용과 ADC 측정 유효도 분리한다. 현재 상태 흐름을 문서화했지만 실제 전원 파형·저전압 출력 부하·잔류 전압·ADC 유효화 검증은 남는다.

**이번 사용자 작업:** TPS **p9 위쪽 Figure6-2(PL)** 한 그림에서 왼쪽 기동, 가운데 얕은 하강/복귀, 오른쪽 깊은 하강/복귀를 찾고 **각주A·B**를 읽는다. CT-open tD 중복 가산 금지와 VPOR 아래 미정 구간을 구분한다. 새 시뮬레이션/실물 조작 없이 그림을 대조하는 단계이며, 사용자 확인 결과는 아직 미보고다. 다음35절은 후보로 유지할 것·보류할 것·필요한 검증을 정리한다.

## 35. 설계 후보를 유지하고 남은 검증을 정하기

### 35-1. 이번 판단 — 후속 계산의 기준 후보로 유지한다

현재 TPS3840PL30–TMUX1511 구조를 계속 검토할 기준 후보로 유지한다. 분압된 두 전압을 전달하고, MCU ADC 전원 상태에 따라 경로를 제어하며, 무전원 입력을 별도 규격으로 다루려는 설계 목적과 연결 논리가 맞는다. 다만 실제 전원 과도·무전원 MCU 핀 보호·전체 측정 오차가 입증되지 않았으므로 최종 부품 확정과 제작 승인은 보류한다.

| 구분 | 지금의 판단 |
| --- | --- |
| 검토한 사실 | 저장 모델에서의 OP/TRAN 결과, 지정 시험 조건의 부품 규격, 공식 보드 도면상 전원 경로 |
| 유지할 설계 후보 | 두 분압 채널, TPS 전원 감시와 TMUX 제어, R5 방전 경로, 핀/디커플링 초안 |
| 아직 승인하지 않은 것 | 실제 부품·조립·전원 파형 전체의 보호, 보정 후±0.10V, 최종 BOM/PCB 제작 |

후보 유지란 이후 계산이 참조할 회로를 정한다는 뜻이다. 새로운 근거가 후보와 맞지 않으면 해당 부분을 수정한다. 반대로 새 근거 없이 임의 하강 기울기나 완료한 두 점 보정 실습을 반복하지 않는다.

실제 허용 전압·주입 조건, 부품 온도/입력 범위, 측정 준비가 정의되지 않은 항목은 검증 준비 미완료다. 파형/계측 수단의 적합성도 확인해야 하며, 새 장비를 샀다거나 실물 연결을 허용했다는 뜻은 아니다. 제작 회로도의 초안 작성은 이 검증을 준비하는 데 사용할 수 있지만 발주/실물 보호 완료 판정과 구분한다.

### 35-5. 보호와 정확도를 따로 판정한다

| 질문 | 다루는 성능 |
| --- | --- |
| MCU가 꺼져도 핀 조건을 지키는가? | 전원/입력 보호 |
| 실제12.6V를 얼마로 환산하는가? | 측정 정확도 |
| 전압이 변한 뒤 언제 새 값을 사용할 수 있는가? | 정착/취득/갱신 응답 |

보호 조건을 만족해도 분압비·ADC·기준 전압 때문에 측정 오차가 클 수 있다. 반대로 정상 상태에서 보정값이 잘 맞아도 전원 OFF 보호가 검증된 것은 아니다. 세 판정을 서로의 증거로 대체하지 않는다.

기존 [요구조건15의 측정 목표](../../09_Electrical_Design/15_Expansion_PCB_Requirements_2026-10-23_ko.md)는 **각 전압 채널0~16V DC, 보정 후±0.10V, 초기 주위20~30°C, 결과10Hz**의 설계 제안이다.0~16V 수용을16V 초과 서지/역극성 내성으로 확대하지 않는다.

정확도 검증에서 기준 계기의 오차/불확도는 회로 부품 오차와 구분한다. 기존26절의 UT210E 한계 때문에 그 계기와 값이 비슷하다는 사실만으로±0.10V 달성을 선언하지 않는다. 기준 측정의 경계를 별도 열에 두고 합격 판정에 반영한다.

### 35-6. 다음은 전체 전압 오차 예산을 만든다

**36절의 첫 작업:** 기존 모델/사용자 결과를 재사용하여 다음 열을 갖는 표를 작성한다.

```text
오차 원인 | 입력 전압으로 환산한 기여량 | 근거/적용 조건
          | 보정으로 줄이는 부분 | 보정 뒤 남는 부분 | 미정/추가 증거
```

저항 비율·스위치 저항/누설·MCU ADC·VDDA 추정·온도/잡음/정착을 모으되, 아직 값이 없는 항목을0으로 넣지 않는다. 기준 계기/검증 경계는 별도로 둔다. 다음 절에서 보정 전 공차와 보정 후 잔차, ADC 총 오차와 그 내부 항목의 중복 여부, 같은 방향으로 연동되는 오차를 구분하여 합산한다. 같은 값들을 무조건 더하거나 독립성 근거 없이 제곱합으로 줄이지 않는다.

이 단계에서는0.1% 저항 구매나 필터값 변경부터 시작하지 않는다. 어떤 항목이 목표를 제한하는지 근거를 모은 다음, 필요할 때만 부품/보정/조건을 변경한다. 원본 시뮬레이션을 다시 실행할 필요도 없다.

### 35-7. 필기 결론과 현재 완료 범위

> TPS3840PL30–TMUX1511을 전압 측정 보호 회로의 후속 계산 후보로 유지한다. 두 분압 경로·제어 핀·전원 주변·상태 흐름은 초안으로 정리했다. 실제 전원 하강/무전원 입력/복귀 유효성/전체 정확도는 필요한 증거를 정한 상태이며, 아직 실물 검증과 최종 부품·제작 승인은 남아 있다. 다음은 이 회로의 보호 부하를 포함하여 전체 전압 오차 예산을 작성한다.

30~35절의 설명 자료/후보 판단 작성은 여기까지다. 사용자 다음 요청을 읽기 확인이나 실물 PASS로 간주하지 않는다. 이번에는35-2의 유지 후보와35-4의 남은 증거를 나누어 필기하면 된다. 후속36절은 새 계산표 작업이며 이미 배운 RC·공차·두 점 보정을 처음부터 반복하는 단계가 아니다.

## 36. 전체 전압 오차 예산 — 회로 기여량을 같은 기준으로 모으기

2026-11-04 착수. 정상 ON 상태의 회로 기여량 표를 먼저 작성하고, 후속 요청으로 ADC·VDDA 추정 항목을 연결했다. 예정 작업을 사용자 재개 요청으로 먼저 시작하며, 전체 오차 예산 완료나 사용자 이해 확인을 뜻하지 않는다.

### 36-1. 오늘 무엇을 판단하려는가

35절에서는 TPS3840PL30–TMUX1511을 후속 계산의 기준 후보로 유지했다. 이제 이 보호 경로를 통과해 얻은 전압값이 목표 정확도에 얼마나 가까운지 판단할 표를 만든다.

기존 설계 제안은 **각 전압 채널0~16V DC, 보정 후±0.10V, 주위20~30°C, 결과10Hz**다. 여기서 ±0.10V는 측정 대상 VRAIL로 환산한 오차이며 ADC 핀에서 허용하는 ±0.10V가 아니다. 실제12.600V를 측정한다면, 이 제안 목표에 대응하는 환산값 범위는12.500~12.700V다. 실제 전압을 알아내는 기준 계기의 오차는 별도로 고려한다.

이번 표는 전원이 정상이고 TMUX가 ON이며 입력이 정착한 DC 조건을 다룬다. 전원 OFF 누설과 잔류 전압은35절 보호 검증 표에서 계속 추적한다. 그 값을 정상 측정 오차에 그대로 더하지 않는다.

### 36-2. 모든 항목을 VRAIL 쪽 mV로 표현한다

기준 한 채널은 R1/R2=12kΩ, R3=4.7kΩ, R4=1kΩ, R5=47kΩ, RON=2Ω 모델이다. R5는 측정 중에도 부하로 존재하므로 해당 부하를 포함한21절의 명목 계수 K를 사용한다.

```text
K = VRAIL / VADC = 6.747204165 (명목 모델)
VRAIL_est = K × VADC_est
오차 e = VRAIL_est − VRAIL_true

VADC 쪽 전압 오차가 ΔVADC라면, K를 고정했을 때:
ΔVRAIL_est = K × ΔVADC
```

`est`는 추정/환산값, `true`는 실제값이다. 예를 들어 VADC 추정값이1mV 높아지면 VRAIL 환산값은 약6.747mV 높아진다. 회로마다 발생 위치가 달라도 이 기준으로 바꾸면 ±100mV 목표와 비교할 수 있다.

```text
전체 목표 ±100mV ÷ K ≈ ADC 노드 등가 ±14.821mV
```

14.821mV는 전체 목표를 명목 계수로 역환산한 크기다. 각 부품에 따로14.821mV씩 허용한다는 뜻이 아니고, 보정/기준전압 오차까지 단일 전류원처럼 모델링했다는 뜻도 아니다. 보정 후 실제 기울기와 명목 K가 다르면 실제 계수로 다시 환산한다.

### 36-3. 첫 회로 기여량 표

기존21·22절의 계산을 같은 단위로 재계산했다. 수치 대조는 해석식 계산이며 새 KiCad 실행/실측 결과가 아니다. 공차1% 행은 같은 보호 부하 모델에서 추가 계산한 비교 시나리오다.

| 항목 | VRAIL 쪽 환산 오차 | 적용 조건/근거 | 보정으로 줄일 수 있는 부분 | 보정 후 남는 부분/미정 |
| --- | --- | --- | --- | --- |
| 저항 공차±0.1% 비교 | −27.754~+27.792mV | VRAIL16V, R1~R5 불리한 공차 조합, RON2Ω 고정, 명목 K 사용 | 안정된 저항비의 초기 이득 오차 | 실제 부품/TCR·온도 변화·보정 잔차 미정 |
| 저항 공차±1% 비교 | −275.803~+279.684mV | 위와 같은 모델에서 공차만1%로 변경 | 안정된 저항비의 초기 이득 오차 | 같은 미결. 보유 키트 공차를1%로 확인한 것은 아님 |
| RON2→4.5Ω 비교 | −0.770mV 변화 | VRAIL16V, 다른 값 명목 고정. 2Ω은TYP,4.5Ω은조건부MAX | 기준 조건에서 일정한 저항으로 작용하는 부분 | 신호/온도/공급에 따른 변화, 실제 부품 편차. 이 비교는 전체 상·하한이 아님 |
| ON 누설±50nA의 단일 등가 모델 | ±1.506mV | VADC 노드에 전류원 하나를 둔 비교, 명목 저항 사용 | 보정 조건에서 일정한 오프셋 성분 | 누설의 온도/신호 의존·실제 적용 조건·보정 후 변화 미정 |

**0.1%와1%는 둘 중 하나의 비교 조건이며 두 행을 더하지 않는다.** 부품 구매나 보유 키트의 공차 확정이 아니다. 목표가 보정 후±0.10V이므로,1% 비교에서 보정 전±약0.28V가 나온 사실만으로 부품을 폐기하거나 보정 후 목표가 불가능하다고 판정하지 않는다. 반대로 보정 후 반드시 통과한다고도 판정할 수 없다.

저항 공차의 계산은21절의 식을 사용했다. 최대 조합은 R1/R2/R4를 낮추고 R3/R5를 높이며, 최소는 반대다. 공차 비교에서는 RON을2Ω으로 고정한다.

RON 행은4.5Ω을 넣은 VADC에 기준 K를 곱해2Ω 모델과 비교한 것이다. 실제 IC의 RON은 고정된 저항 하나와 완전히 같지 않으며,2Ω을최솟값으로 해석하지 않는다.

누설 모델은 전압원을0으로 놓고 VADC에서 보이는 저항을 사용한다. 아래 `||`는 병렬 합성이다.

```text
Req = 47kΩ || [1kΩ + 2Ω + (24kΩ || 4.7kΩ)]
    = 4463.863Ω
|ΔVADC| = 50nA × Req = 0.223193mV
|ΔVRAIL_est| = K × |ΔVADC| = 1.505930mV
```

전류가 노드에서 빠져나가면 전압이 내려가고 유입되면 올라가는 단순 비교다. 제조사의 두 단자 누설 시험을 각각 독립 최대 전류로 더하지 않는다. 0V 부근은 정상 아날로그 입력 범위/클리핑 영향도 별도 확인해야 하므로, 이 선형 등가 계산만으로0~16V 전체 정확도를 보증하지 않는다.

### 36-5. 아직 총합을 적지 않는 이유

표의 숫자들은 성격이 다르다. 공차 값은 보정 전 시나리오이며, RON 값은 대표값에서 최대값으로 바꾼 민감도 비교다. 누설 값도 단일 등가 모델의 기여량이다. 이들을 더해서 보정 후 전체 오차라고 부를 수 없다.

보정으로 줄일 수 있는 것은 기준 조건에서 재현되는 일정한 이득/오프셋 성분이다. 보정 후에도 입력에 따른 비선형성, 온도/공급 변화, 잡음, 기준 측정과 계수의 불확실성이 남는다. 보정이 흡수한 초기 오차를 다시 독립 항목으로 더하면 중복이고, 남은 값을 측정하지 않았다는 이유로0으로 쓰면 누락이다.

| 전체 표에 이어 붙일 항목 | 현재 상태 | 다음에 정할 것 |
| --- | --- | --- |
| STM32 ADC/양자화/비선형성 | 기존25절의 규격·크기 비교만 있음 | 실제 클록/취득 조건, 총 오차와 성분의 중복 여부, 보정 후 잔차 |
| VREFINT/VDDA 추정 | 공장 보정식과 코드 민감도 학습 완료 | 두 ADC 측정의 공통/독립 오차, 기준 드리프트와 적용 조건 |

이 상태의 결론은 **회로 기여량 표 초안 작성, 전체 합계/±0.10V 달성 여부 미판정**이다. 현재 수치는 어떤 항목부터 조사할지 비교하는 근거이며 실제 보정 후 배분 완료값이 아니다.

### 36-6. 필기에 남길 문장과 다음 작업

> 전체 전압 오차 예산은 각 오차 원인을 VRAIL 쪽 mV로 맞추고, 적용 조건과 보정 전후의 차이를 기록하는 작업이다. 보호 부하를 포함한 명목 K는약6.7472이며 ADC 쪽1mV는 입력 환산약6.747mV에 해당한다. 저항 공차·RON·ON 누설의 첫 비교 표를 작성했지만 보정 후 잔차와 ADC·VDDA·온도·잡음·기준 계기 영향이 남아 있으므로 전체 정확도는 아직 판정하지 않는다.

첫 회로 표 작성 당시 다음 작업은 **ADC 오차와 VREFINT/VDDA 추정 기여량 연결**이었다. 사용자 후속 요청에 따라 아래36-7부터 이어 쓴다. 이미 완료한 두 점 보정 기본 설명이나 KiCad 공차 실습을 반복하지 않는다. 이번 절의 사용자 이해 확인은 아직 미보고다.

### 36-7. ADC의 1LSB를 VRAIL 쪽 오차로 환산하기

ADC가 입력 전압을 디지털 숫자로 바꾸는 과정에도 오차가 있다. 먼저 데이터시트의 단위인 LSB를 기존 표의 VRAIL 쪽 mV로 맞춘다. 여기서는 **12비트, 기준 전압3.3V, 명목 K=6.747204165**를 계산 조건으로 둔다.

```text
12비트 ADC의 코드 수 = 2^12 = 4096개 (코드0~4095)
1LSB = 3.3V / 4096 = 0.805664mV  ← ADC 입력 쪽
VRAIL 쪽 1LSB = K × 0.805664mV = 5.435980mV
```

즉 외부 전압 채널의 코드가1만큼 달라지면, 이 조건에서 VRAIL 환산값은 약5.436mV 달라진다. 아래 식의4096은 이상 ADC의 코드 폭 기준이다. 펌웨어의 끝점 환산 방식이나 보정 계수를 정할 때도 같은 정의를 유지해야 한다.

**읽을 자료:** 보유 ST `stm32f446mc.pdf`, **DS10693 Rev10,2021년1월,140쪽 §6.3.21 Table75의 ET 행**. 인쇄/PDF 쪽 번호가 같다. [보유 데이터시트](../../assets/stm32f446mc.pdf).

Table75는 **fADC=18MHz**, VDDA/VREF+=1.7~3.6V, VDDA−VREF+<1.2V 조건이다. ET(TUE, Total unadjusted error)는 **TYP±3LSB, MAX±4LSB**다. 최대값의 근거는 표 각주2의 특성 평가 시험 기반 보증이다. 이 MAX를 입력 전압 단위로 바꾸면 다음과 같다.

```text
|오차| 비교 = 4LSB × 5.435980mV/LSB = 21.743920mV
```

따라서 **18MHz 표의 적용 조건을 만족한다고 가정하면, 보정 전 ADC 총 오차±4LSB는 VRAIL 쪽 약±21.74mV에 해당**한다. VREF+를 정확하게 알고 외부 채널 코드 오차만 환산한 비교이며, VREFINT 계산까지 포함한 전체 정확도는 아니다.

클록 조건이 달라지면 사용할 표도 달라진다.141쪽 Table76의30MHz에서는 ET MAX±5LSB, Table77의36MHz에서는 MAX±7LSB다. 같은3.3V/K 환산은 각각±27.18mV,±38.05mV다. 표별 공급·입력 조건도 함께 적용해야 하며 세 값을 더하지 않는다.

현재 MVP의 `stm32_uart_mvp/Core`와 `.ioc` 검색에서는 측정용 ADC 클록·샘플링·채널 설정을 찾지 못했다. 따라서18MHz는 **이번 비교 조건**이며 구현된 설정이 아니다. 결과 갱신10Hz와 ADC 내부 클록18MHz도 서로 다른 값이다.

### 36-8. TUE에 오프셋·이득·비선형성을 다시 더하지 않는다

Table75에는 ET 외에도 EO(오프셋), EG(이득), ED(미분 비선형성), EL(적분 비선형성)이 있다. ET는 실제 변환 특성이 이상 특성에서 벗어난 정도를 총괄하는 규격이므로 아래와 같이 독립 오차로 더하면 안 된다.

```text
잘못된 합산: TUE + 오프셋 + 이득 + INL + DNL
```

ST **AN2834 Rev10,2024년10월,14쪽 §3.1.5 / Figure13**에서도 TUE가 EO·EG·EL·ED의 합이 아님을 설명한다. [공식 AN2834 14쪽](https://www.st.com/resource/en/application_note/cd00211314-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf#page=14). 로컬 최신 파일은 `assets/datasheets/cd00211314-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf`다. 기존 `AN2834.PDF` 구판과 구분한다.

두 점 보정으로 기준 조건의 일정한 기울기와 오프셋을 줄여도 입력에 따라 휘어지는 특성, 온도 변화, 잡음은 남을 수 있다. 그렇다고 **보정 후 오차=INL 규격 하나**라고 바로 정하지도 않는다. 보정점과 INL의 기준선 정의, 보정 데이터의 오차가 서로 다를 수 있기 때문이다.

이상 ADC의 양자화±0.5LSB 역시 별도 모델이다. TUE와의 합산 여부는 데이터시트의 이상 특성 기준과 우리가 비교하는 연속 전압 오차의 정의를 맞춘 뒤 정한다. 지금은±21.74mV에 다른 모든 ADC 항목을 일괄 가산하지 않는다.

### 36-9. VREFINT를 사용하면 두 ADC 측정의 비율이 들어간다

VDDA 추정식을 전체 환산식에 넣어 오차가 들어오는 위치를 확인한다. 세 코드의 뜻부터 구분한다.

| 기호 | 뜻 | 출처 |
| --- | --- | --- |
| Nx | 지금 외부 VADC 채널을 읽은 ADC 코드 | 사용자 펌웨어의 측정 |
| Nr | 지금 내부 VREFINT 채널을 읽은 ADC 코드 | 사용자 펌웨어의 측정 |
| Nc | 해당 칩의 VREFINT 공장 보정 ADC 코드 | 칩에 저장된 보정 데이터 |

```text
VDDA_est = 3.3V × Nc / Nr
VRAIL_est = K × (Nx / 4096) × VDDA_est
          = K × (3.3V / 4096) × Nc × (Nx / Nr)
```

공장 조건3.3V의 근거는 **DS10693 Rev10,145쪽 §6.3.24 Table84, VREFIN_CAL 행**이다. 공장 데이터는 **30°C,VDDA3.3V**에서 얻은 raw ADC 값이다. Nc는 실제 칩에서 읽어야 하며 대표값으로 대신하지 않는다.

분자는 측정하려는 외부 전압 코드이고 분모는 기준 전압을 추정하는 데 쓰는 내부 기준 코드다. **Nx가 커지면 환산 전압이 커지고, Nr가 커지면 추정 VDDA와 환산 전압이 작아진다.**

### 36-10. 같은 1코드라도 들어가는 위치에 따라 영향이 다르다

민감도만 보기 위해 **Nc=1500, 이상적인 현재 Nr=1500, 실제 VDDA3.3V, VRAIL16V**인 가상의 예를 둔다. 외부 채널과 나머지 조건은 고정하고 Nr만 바꾼다. 이는 실제 칩의 보정값·측정 로그가 아니다.

```text
VRAIL_est = 16V × 1500 / Nr
```

| Nr | 추정 VDDA | 환산 VRAIL | 실제16V와의 차이 |
| --- | --- | --- | --- |
| 1499 | 3.302201V | 16.010674V | +10.674mV |
| 1500 | 3.300000V | 16.000000V | 0mV |
| 1501 | 3.297801V | 15.989340V | −10.660mV |

36-7에서 외부 Nx의1코드 변화는 약5.436mV였지만, 이 예의 분모 Nr의1코드 변화는16V 환산값에 약10.67mV 영향을 준다. 내부 기준은 외부 신호와 코드 크기/식에서의 역할이 다르기 때문이다. 이 결과만으로 실제 VREFINT 오차가±1코드라고 정하지 않는다.

Nr에±4코드를 각각 대입하는 단순 민감도는 +42.781/−42.553mV다. 이것도 외부 채널의±21.744mV와 곧바로 독립 오차로 합치는 확정 예산이 아니다. 다음 절의 공통 오차와 개별 오차를 구분해야 한다.

### 36-11. 같은 ADC를 사용하면 일부 오차는 연동된다

두 현재 측정에 **같은 비례 이득 G만** 작용한다면 다음 비율에서 G가 상쇄된다.

```text
(G × Nx) / (G × Nr) = Nx / Nr
```

따라서 외부 채널의 이득 오차와 VREFINT 읽기의 같은 이득 오차를 완전히 독립인 최대 오차로 취급하면 지나치게 보수적인 합산이 될 수 있다. 반대로 같은 ADC라는 이유로 모든 오차가 사라지는 것도 아니다.

```text
같은 오프셋 b가 더해진 경우:
(Nx + b) / (Nr + b)는 일반적으로 Nx / Nr와 같지 않다.
```

입력 코드별 비선형성, 잡음, 채널별 정착 부족, 시간차 동안의 VDDA 변화도 서로 다르게 작용할 수 있다. 공장 Nc에 포함된 불확실성과 VREFINT 자체의 온도 변화 역시 위 G 상쇄식만으로 제거되지 않는다. 동일 이득/기준 상태의 비율 모델이 성립하는 범위를 확인해야 한다.

전체 예산에서는 **공통 성분과 개별 성분을 나눠 비율식으로 전파**한다. 상관관계를 모르는 항목을 임의로 독립이라 가정하여 제곱합으로 줄이지 않는다. 개별 상한을 더하는 보수적 범위를 사용할 경우에도 적용 조건과 중복 가능성을 명시한다.

### 36-13. 필기 결론과 다음 작업

> ADC의 LSB 오차도 명목 환산비 K를 통해 VRAIL 쪽 mV로 바꿀 수 있다. 예시 조건에서1LSB는약5.436mV이고18MHz 표의 ADC 총 오차 MAX±4LSB는약±21.74mV다. VREFINT를 사용한 전압 환산은 외부 코드와 내부 기준 코드의 비율이므로, 두 측정의 공통 이득과 개별 오차를 구분해야 한다. VREFINT 보정이 모든 오차를 제거하는 것은 아니며 전체 정확도는 아직 미판정이다.

다음은 **보정 당시와 사용 중 조건이 달라졌을 때 남는 오차**다. 저항비·VREFINT의 온도 변화부터 시작해 잡음/정착과 기준 계기·보정 계수의 영향을 연결한다. 보유 저항 키트의 미확인 TCR을 임의의 정밀 저항 사양으로 바꾸지 않는다. 이번 작성은 자료/해석식 작업이며 사용자 읽기·실물 시험·GUI 실행·ADC 구현 완료로 기록하지 않는다.

### 36-14. 보정 온도를 기준으로 변화량을 계산한다

26절에서 온도 영향의 개별 규모를 이미 비교했다. 이번 작업은 그 수치를 재사용하여 **보정 이후 남는 변화**를 전체 환산식에 연결하는 것이다. 보정 전 초기 저항 공차를 다시 더하는 작업이 아니다.

계산 예에서는 보정 당시 부품 온도를 Tcal=25°C, 사용 중 온도를20~30°C로 가정한다. 보정 계수를 그대로 유지하면 기준25°C에서의 온도차는 최대5°C다.20°C에서 보정하고30°C에서 사용했다면 온도차는10°C이므로 같은 계산값을 쓸 수 없다.

```text
ΔT = 사용 중 부품 온도 − 보정 당시 부품 온도
25°C 보정 → 30°C 사용: ΔT = +5°C
25°C 보정 → 20°C 사용: ΔT = −5°C
20°C 보정 → 30°C 사용: ΔT = +10°C
```

25°C 보정은 이번 비교를 위한 가정이며 실제 보정 절차를 확정한 것이 아니다. 요구 제안의20~30°C는 주위 온도다. 실제 저항 온도와 MCU 내부 온도는 자기 발열·주변 열원·배치 때문에 다를 수 있다. 주위 온도 범위를 그대로 각 부품의 ΔT 상한으로 확정하지 않는다.

### 36-15. 초기 공차와 TCR을 구분한다

초기 공차는 지정 조건에서 저항이 명목값과 얼마나 다른지를 나타낸다. TCR(Temperature Coefficient of Resistance)은 온도 변화에 따른 저항의 상대 변화율이며 ppm/°C로 표현한다.1ppm=0.0001%이므로100ppm/°C는1°C당0.01%에 해당한다.

선형 근사에서 α를 ppm/°C의 숫자로 쓰면:

```text
R(T) ≈ R(Tcal) × [1 + α × 10^−6 × ΔT]
```

예를 들어 기준 온도에서12kΩ이고 α=+100ppm/°C라면5°C 상승 시 변화량은12kΩ×100×10^−6×5=6Ω이다. 따라서12,006Ω이 된다. 부호가 반대면11,994Ω이다. 제조사 정보가 없는 보유 키트에 이 사양을 부여하는 것은 아니다.

분압에서는 **각 저항의 변화량과 저항끼리의 비율 변화**도 다르다. 부하 없는 두 저항 분압기에서 위·아래 저항이 동일한 비율로 변하면 분압비는 유지된다. 서로 다른 온도계수나 부품 온도 때문에 변화율이 달라지면 분압비도 변한다. 실제 회로에는 R4·R5·RON이 있으므로 두 저항만의 상쇄 예를 전체 회로 보증으로 확대하지 않는다.

일반 용어 근거: **Vishay, RESISTORS 101, VMN-SG2113-1205, 인쇄/PDF4쪽, Common Resistor Terminology의 Resistor Tolerance 및 Temperature Coefficient of Resistance 항목**. TCR tracking은 저항 사이의 TCR 차이를 뜻한다. [공식 지침4쪽](https://www.vishay.com/docs/49873/49873_sg2113.pdf#page=4). 이 지침은 정의 참고이며 보유 키트의 데이터시트가 아니다.

### 36-16. 실제 보호 부하를 포함한 저항비 온도 모델

기준 온도의 값은 R1/R2=12kΩ,R3=4.7kΩ,R4=1kΩ,R5=47kΩ,RON=2Ω으로 둔다. A는 VADC/VRAIL이며 기준값 Acal=0.1482095362, Kcal=1/Acal이다. 이번에는 ADC/기준 계기/누설 변화가 없고 기준 온도에서 이득 보정이 정확하다고 가정한다.

```text
Ra = R1 + R2
A = R3 × R5 / [Ra × R3 + (Ra + R3) × (R4 + RON + R5)]

보정 후 환산값(T) = VRAIL_true × A(T) / Acal
온도 변화에 의한 오차 = VRAIL_true × [A(T) / Acal − 1]
```

각 저항에36-15의 온도 모델을 대입하면 된다.26절의 비교를 재계산한 결과는 다음과 같다. R1~R5의 TCR 부호가 출력에 불리하게 조합되고, 모두 같은5°C 온도 변화를 겪으며 RON은2Ω으로 고정한 가정이다. 초기 공차는 새로 중첩하지 않는다.

| 가정한 R1~R5 각각의 TCR 범위 | VRAIL16V의 보정 후 환산 변화 |
| --- | --- |
| ±25ppm/°C | −3.471~+3.472mV |
| ±50ppm/°C | −6.942~+6.944mV |
| ±100ppm/°C | −13.882~+13.891mV |

최대 출력 쪽은 R1/R2/R4가 작아지고 R3/R5가 커지는 조합, 최소는 그 반대다. 이 값은 가정한 선형 저항 모델의 범위이며 실제 키트 성능이나 RON·누설까지 포함한 전체 온도 오차 상한은 아니다. RON2→4.5Ω 비교 전체를 다시 온도 드리프트로 더하지도 않는다. 그 비교는 기준 조건의 초기 편차까지 섞여 있을 수 있기 때문이다.

### 36-17. VREFINT도 보정 당시와 사용 중 값의 비율이 중요하다

VDDA 변동과 VREFINT 자체의 온도 변화를 구분한다. 실제 내부 기준 전압이 온도 때문에 올라가면, 같은 VDDA에서 VREFINT 코드 Nr는 커진다. 공장 코드 Nc를 고정한 추정식에서는 VDDA를 낮게 추정하고, 외부 전압 환산값도 낮아진다.

**읽을 위치:** 보유 ST STM32F446 **DS10693 Rev10,2021년1월, 인쇄/PDF145쪽 §6.3.24 Table83 `TCoeff` 행 및 각주2**. TYP30,MAX50ppm/°C이며 각주2는 설계 보증이다. 같은 표의 `VRERINT_s`는 VDD=3V±10mV에서 온도 범위에 걸친 변화 TYP3/MAX5mV이고 Table84의 공장 보정 온도는30°C다. [보유 데이터시트](../../assets/stm32f446mc.pdf).

규모 비교로50ppm/°C를5°C 구간의 선형 변화율로 적용하면 상대 변화 크기는250ppm=0.025%다. VREFINT가 이 비율만큼 증가한 경우, 기준 온도에서 정확히 보정한16V 환산값은 다음과 같다.

```text
δref = +50 × 10^−6 × 5 = +0.00025
환산값 = 16V / (1 + δref) = 15.996001V
오차 = 약 −3.999mV
```

반대로 같은 크기로 감소하면 오차는약+4.001mV다. 따라서 이 선형 모델에서는약±4mV의 규모다. **데이터시트의 MAX50ppm/°C를 읽은 것과, 임의의 모든5°C 국소 구간에±4mV를 보증하는 것은 구분한다.** 여기서는 규격에 기반한 선형 규모 비교로 두며 실제 온도 곡선/조건을 대신하지 않는다. 전체 온도 범위 변화5mV를 이4mV에 다시 독립 오차로 더하지 않는다.

공장 보정30°C만 사용하고 별도의 전체 경로 보정이 없다면20°C까지는10°C 차이다. 같은 선형 가정에서는16V 환산약±8mV 규모다. 반면25°C에서 전체 전압 경로를 보정했다면 그때 존재하던 일정한 이득 성분이 계수에 들어가고, 이후의 온도 변화는25°C를 기준으로 추적한다. 두 경우를 혼용하여5°C와10°C 기여량을 모두 더하지 않는다. 보정 자체의 기준 계기/계수 오차는 여전히 별도 미결이다.

### 36-18. 두 온도 영향을 전체 환산식에 연결하기

설명을 위해 정상 ON·정착 상태, 기준 온도에서 정확한 이득 보정, 오프셋/잡음/ADC 잔차 없음, 동일한 상태의 VDDA로 두 ADC 채널을 읽는 모델을 사용한다. 온도 T의 표기는 간단히 쓴 것이며 실물에서는 저항별 온도와 MCU 내부 온도를 따로 관리해야 한다.

```text
보정 후 VRAIL_est(T)
= VRAIL_true
  × [A(T) / A(Tcal)]
  × [VREFINT(Tcal) / VREFINT(T)]
```

첫 비율은 온도 때문에 분압/보호 경로의 전달비가 달라진 영향이다. 두 번째 비율은 내부 기준 전압이 달라져 VDDA 추정에 들어가는 영향이다. 이 식에서는 A가 올라가면 결과가 커지고 VREFINT가 올라가면 결과가 작아진다. 변화가 작을 때 상대 오차는 대략 다음과 같다.

```text
상대 환산 오차 ≈ 전달비의 상대 변화 − 내부 기준의 상대 변화
```

이는 부호를 이해하기 위한 전파식이다. 실제 두 변화가 항상 서로 상쇄된다고 가정하지 않는다. 앞 표의 가정 수치와 ADC 보정 전 TUE 등을 무조건 더해 보정 후 총합으로 발표하지 않는다. 실제 부품 조건이 확인되면 이 식을 기준으로 보수적 경계나 상관 모델을 정한다.

| 온도 예산 항목 | 이번 표에 남길 상태 | 채우기 위해 필요한 정보 |
| --- | --- | --- |
| R1~R5의 비율 변화 | 5°C·가정 TCR의 조건부 비교값 있음 | 실제 부품/TCR·부품 온도·같은 계수를 유지한 변화 관측 |
| VREFINT 변화 | 50ppm/°C 선형 적용 시5°C·16V에서약±4mV | 보정 기준 온도·MCU 내부 온도·적용 가능한 드리프트 경계 |
| RON/누설/ADC 잔차의 온도 의존 | 미정 | 초기 편차와 보정 후 변화를 구분한 조건/근거 |
| 보정 기준 계기·계수 영향 | 미정 | 보정 당시 기준의 오차/불확도와 독립 검증 경계 |

### 36-19. 필기 결론과 다음 작업

> 보정은 기준 조건에서의 전달 특성을 맞추는 작업이다. 온도가 달라지면 저항비와 VREFINT도 달라질 수 있으므로 보정 당시의 값과 현재 값의 비율로 잔여 오차를 계산한다. 같은 온도 변화에서도 저항끼리 얼마나 함께 변하는지가 중요하다. 이번 수치는 가정한 TCR과 선형 온도 모델의 비교이며, 보유 키트와 실물 회로의 온도 정확도를 확정한 값은 아니다.

사용자는36-19까지 필기 완료를 보고했다. 이후 **잡음·입력 정착·ADC 취득과 결과10Hz 처리 조건**은37절, 기준 계기/보정 계수는38절, 전체 판정은39절로 구분한다. 기존 작업의 편집상 분리이며 추가 요구사항이나 일정 확대가 아니다. 필기 완료는 실물/시뮬레이션 검증이나 전체 예산 완성을 뜻하지 않는다.

**작성 기준:** 분량보다 설계 판단과 근거의 연결을 우선한다.36절은 회로·ADC·기준전압·온도가 만드는 기여량을 같은 입력 전압 기준으로 표현하는 작업,37절은 그 값을 얻는 시간/처리 조건,38절은 보정과 검증 기준의 신뢰 범위,39절은 이들을 모은 목표 판정을 다룬다. 각 항목에 필요한 이유, 출처와 적용 조건, 가정, 계산/관측, 결론과 미결을 남긴다. 필요한 설명은 길더라도 생략하지 않으며, 항목 수나 페이지 수를 완료 기준으로 삼지 않는다.

## 37. 측정 시간과 잡음 — 언제 읽은 값을 사용할 것인가

이번 장은 네 항목으로 진행한다. 각 항목에서 예산에 넣을 조건과 남은 근거를 정하며, 이미 수행한 RC/공차 실습을 처음부터 반복하지 않는다.

| 순서 | 다룰 내용 | 현재 상태 |
| --- | --- | --- |
| 37-1 | 정착·취득·읽기 주기·결과 갱신을 구분하기 | 설명 자료 작성 |
| 37-2 | 입력 정착: 허용 잔차와 기다릴 시간 연결 | 설명 자료 작성 |
| 37-3 | ADC 취득: 입력 경로·내부 커패시터·채널 전환 조건 | 이번 설명 자료 작성 |
| 37-4 | 잡음·평균 처리와10Hz 결과의 검증 조건 | 다음 작업 |

38절과39절은 이후 작업이다. 여기서 장비 실습이나 실제 ADC 펌웨어 구현을 새로 시작하지 않는다.

### 37-1. 결과10Hz와 ADC의 취득 시간은 다른 조건이다

**이번 목적:** 기존 제안인 결과10Hz가 무엇을 정하고 무엇을 아직 정하지 않았는지 구분한다. 36절에서 정착된 전압의 환산 오차를 다뤘다면, 이제는 그 전압을 어느 시점에 읽어 결과로 사용할지를 정한다.

```text
배터리/모터 전원 VRAIL
  → 분압·필터·보호 경로의 전압 VADC
  → ADC 내부 커패시터에 입력 전압 취득
  → 디지털 코드 변환
  → 필요한 환산/평균 처리
  → 결과 갱신
```

같은 흐름 안에서도 다음 네 시간은 서로 다르다.

| 구분 | 뜻 | 이번 회로에서의 질문 |
| --- | --- | --- |
| 입력 정착 시간 | 입력 변화나 연결 후 아날로그 전압이 목표값의 허용 오차 안으로 들어오는 시간 | TMUX를 연결한 뒤 VADC가 사용할 수 있는 수준으로 안정됐는가? |
| ADC 취득 시간 | 한 번의 측정에서 ADC 내부 커패시터가 입력에 연결되어 충전되는 시간 | 해당 입력 저항/용량에서 충분히 취득했는가? |
| 채널 읽기 주기 | 같은 채널의 측정을 시작하는 시점 사이의 간격 | 배터리 채널을 몇 초마다 한 번씩 읽는가? |
| 결과 갱신 주기 | 처리한 새 결과를 제공하는 간격 | 환산된 전압을 몇 초마다 한 번씩 갱신하는가? |

취득 뒤에는 저장된 전압을 디지털 코드로 바꾸는 **변환 시간**도 있다. 기본적인 한 번의 ADC 동작은 `취득 시간 + 코드 변환 시간`이며, 타이머로 기다리는 시간이나 다른 채널 순서는 별도로 고려한다. 읽기 간격을 길게 설정해도 ADC 취득 설정이 저절로 길어지지는 않는다.

읽을 위치는 **ST AN2834 Rev10, 2024-10, 인쇄/PDF25~26쪽 §4.2.6, 특히26쪽 Figure25와 Sampling / Bit conversion 설명**이다. [공식 문서](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf#page=26) · [같은 판본의 로컬 PDF](../../assets/datasheets/cd00211314-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf). 이 부분은 일반 동작 설명이며26쪽의 STM32L5 설정 예시를 F446 설정으로 옮겨 쓰지 않는다.

기존의 결과10Hz 제안은 다음 한 가지를 말한다.

```text
결과 갱신 주기 = 1 / 10Hz = 0.1s = 100ms
→ 처리한 결과를100ms마다 한 번씩 제공한다.
```

이 조건만으로 ADC의 읽기 횟수, 취득 시간, 평균할 개수가 결정되지는 않는다. 이해를 위한 두 예는 다음과 같다. 둘 다 아직 실제 설정으로 선택한 것은 아니다.

| 설명용 방식 | 같은 전압 채널의 읽기 | 결과 처리 |
| --- | --- | --- |
| A | 100ms마다1회: 초당10회 | 각 측정값을 환산해 초당10개 결과 |
| B | 10ms마다1회: 초당100회 | 겹치지 않는10개씩 평균해 정상 반복 중 초당10개 결과 |

B는 여러 값이 모여야 결과가 나오므로 급격한 변화에 대한 응답도 달라진다. 평균이 항상 더 정확하거나100Hz가 이번 회로에 충분하다는 결론은 아니다. 잡음의 성격과 입력 변화 조건은37-4에서 다룬다. 외부 전압 채널과 VREFINT의 읽기 순서/시차도37-3 이후 실제 설정을 검토할 때 포함한다.

또한100ms 동안 다음 읽기를 기다렸다고 해서, ADC 내부 커패시터가 그100ms 내내 입력에 연결되어 있었던 것은 아니다. **외부 회로를 기다리는 것과 ADC 내부에서 취득 시간을 확보하는 것은 각각 확인해야 한다.**

> 필기 결론: 결과10Hz는100ms마다 처리 결과를 갱신한다는 뜻이다. 입력 정착 시간, ADC 취득 시간, 채널 읽기 주기와 결과 갱신 주기는 별도로 정해야 한다. 아직 정착되지 않거나 충분히 취득되지 않은 값을 빠르게 갱신해도 정확도는 보장되지 않는다.

이번 자료의 사용자 이해 확인/실행 결과는 아직 받지 않았다. 다음37-2에서는 **허용 잔차를 정하면 입력 정착 시간을 어떻게 계산하는지** 기존 모델에 연결한다. 새 GUI 실행을 완료했다고 기록하지 않는다.

### 37-2. 허용 잔차를 정하면 입력 정착 시간을 계산할 수 있다

**이번 설계 질문:** 전압이 변한 뒤 어느 시점부터 측정값을 사용해야 정착 부족에 의한 오차가 배정한 범위 안에 들어오는가? 앞선 시정수 실습의63.2%/99%를 실제 허용 오차와 연결한다.

**1. 잔차는 최종 전압과 현재 전압 사이에 남은 차이다**

입력이 일정한 새 값으로 변한 뒤 RC 출력이 그 값에 가까워지는 동안, 현재 출력과 충분히 시간이 지난 출력 사이에는 차이가 남는다. 여기서는 잡음이나 공차를 제외한 이 동적 차이만 정착 잔차라고 부른다.

```text
E_ADC(t) = |VADC_final − VADC(t)|

입력 쪽으로 환산한 정착 잔차:
E_RAIL(t) = K × E_ADC(t)
K = 6.747204165 (현재 명목 ON 모델)
```

`final`은 같은 조건에서 충분히 시간이 지난 값, t는 입력이 변한 뒤의 경과 시간이다. 상승에서는 현재 전압이 최종값보다 낮고 하강에서는 높을 수 있으므로, 잔차의 크기는 절댓값으로 비교한다. 정확한 계수와 이상적인 ADC를 가정한 정착 성분이며 실제 측정의 다른 오차는 별도로 남는다.

**2. 99%가 충분한지는 전압 변화량에 달려 있다**

정상 전원·TMUX ON을 유지하고 측정 대상 VRAIL만 이상적으로0V에서16V로 변한 경우를 비교한다.16V는 기존 검토 범위의 끝점이므로 변화 폭의 예시로 사용한다. 실제 배터리 전압이나 실제 전원 상승 파형이라고 주장하거나16V를 인가하도록 지시하는 것이 아니다.

```text
변화량 = 16V
99% 정착 → 변화량의1%가 남음
입력 환산 잔차 = 16V × 0.01 = 0.16V = 160mV
```

전체 제안 목표가±100mV이므로 이 경우에는 정착 잔차 하나만160mV여도 목표보다 크다. 반면1V 변화의1%는10mV다. 따라서 '99%까지 기다리면 된다'는 고정 기준보다 **변화량과 허용 잔차를 함께 정하는 것**이 필요하다.

**3. 전체 목표 중 정착에 얼마를 허용할지 구분한다**

계산 방법을 보이기 위해 VRAIL 기준 정착 기여의 크기를 **10mV 이하**로 가정한다. 전체100mV 목표의10%를 사용한 설명용 값이며, 다른 항목을 모두 합산해 승인한 배분이 아니다. 최종 배분은39절에서 판단한다.

```text
설명용 정착 허용값 E_allow_RAIL = 10mV = 0.010V
ADC 쪽 등가 허용값 = 10mV / K ≈ 1.482095mV
```

회로·ADC·기준전압·온도 등의 기여도 남기 때문에 전체100mV를 정착에 전부 사용하고 전체 정확도를 충족했다고 할 수 없다. 최종 배분이 달라지면 아래 시간도 다시 계산한다.

**4. 이번 시정수는 현재 회로의 C1에서 계산한다**

정상 ON 명목 회로는 다음과 같다. 우선 C1 중심의 느린 응답을 보기 위해 C2와 ADC의 스위칭 부하는 제외한1차 근사를 사용한다. 저장 회로에서 부품을 삭제한 것이 아니다.

```text
VRAIL ─ R1 12k ─ R2 12k ─● VDIV ─ R4 1k ─ RON 2Ω ─● VADC
                         │                           │
                         ├─ R3 4.7k ─ GND            └─ R5 47k ─ GND
                         └─ C1 100nF ─ GND

저장 모델에는 VADC–GND의 C2=100pF도 있음(학습용 가정).
```

C1에서 보이는 등가 저항을 구할 때 이상적인 VRAIL 전압원을0V, 즉 단락으로 놓아 생각한다. 이는 저항 계산을 위한 등가 회로이며 실제 배터리를 단락시키는 작업이 아니다. C1에서 보면 세 저항 경로가 병렬이다.

```text
R_eq_C1 = (R1 + R2) || R3 || (R4 + RON + R5)
        = 24kΩ || 4.7kΩ || 48.002kΩ
        ≈ 3.632862kΩ

tau = R_eq_C1 × C1
    = 3.632862kΩ × 100nF
    ≈ 0.363286ms
```

`||`는 병렬 합성, `tau`는 시정수다. R5가 측정 중에도 연결되어 있으므로 부하 없는 과거 분압 모델의0.393031ms를 그대로 재사용하지 않는다. R4×C1만 계산하는 것도 현재 연결을 반영하지 못한다. 앞서 OFF 상태에서 계산한 R5×C2=4.7µs는 다른 상태/커패시터의 방전 모델이다.

**5. 남은 오차를 시간으로 바꾸는 식**

일정한 최종 입력으로 변하는1차 RC 응답은 초기 잔차가 지수적으로 감소한다.

```text
E(t) = E0 × exp(−t / tau)

E(t) ≤ E_allow가 되도록 풀면:
t ≥ tau × ln(E0 / E_allow)     (E0 > E_allow > 0)
```

E0는 변화 직후의 초기 잔차, E_allow는 허용 잔차다. 둘은 같은 위치 기준·단위를 사용한다. `ln`은 자연로그이고 E0/E_allow는 남은 차이를 몇 배 줄여야 하는지를 나타낸다. 처음부터 E0≤E_allow라면 이 이상화된 정착 성분 때문에 추가로 기다릴 필요는 없다.

이번0→16V 예시를 입력 환산 기준으로 계산하면 다음과 같다.

```text
E0 = 16V
E_allow = 0.010V
E0 / E_allow = 1600
ln(1600) ≈ 7.377759

t ≥ 0.363286ms × 7.377759
  ≈ 2.680238ms
```

ADC 쪽 기준으로 계산해도 `E0_ADC=2.371352579V`, `E_allow_ADC=0.001482095V`이므로 같은 비율1600이 된다. 여기서약2.68ms는 **입력이 변한 뒤 경과한 시간**이고 전원 감시기 복귀 지연이나 프로그램 시작 시각을 포함하지 않는다.

같은1차 근사·16V 변화 조건의 비교는 다음과 같다.

| 기준 | 필요한 시정수 배수 | 경과 시간 | VRAIL 환산 잔차 |
| --- | --- | --- | --- |
| 99% 정착 | 4.605tau | 약1.673ms | 160mV |
| 5tau 대기 | 5tau | 약1.816ms | 약107.807mV |
| 99.9% 정착 | 6.908tau | 약2.509ms | 16mV |
| 설명용10mV 이하 | 7.378tau | 약2.680ms | 10mV |

흔히 사용하는5tau도 모든 정확도 요구에 충분한 것은 아니다. 충분한지는 표의 잔차와 해당 항목의 허용값을 비교해 결정한다.

**6. 근사 계산과 실제 대기 설정을 구분한다**

이번 계산은 명목 저항·C1=100nF·고정 RON2Ω·정상 공급·이미 ON인 스위치·이상적 입력 계단·ADC 취득 부하 제외 조건이다. 입력이 계속 변하는 경우나 TMUX OFF→ON에서 두 커패시터의 초기 전압이 다른 경우는 초기 조건과 회로 동작을 다시 적용해야 한다. 정상 상태에서 매 샘플마다16V 계단이 발생한다고 가정하는 것도 아니다.

저장 모델의 C2=100pF까지 포함한 두 노드 선형 RC 식을 별도로 계산하면 느린 모드 시정수0.363635ms, 빠른 모드0.098014µs, 같은10mV 도달 시간2.682906ms가 나온다.1차 근사의 시간 규모와 가깝지만100pF는 여전히 가정이고 실제 ADC 내부 샘플링 용량 모델이 아니다. 이 대조는 Python 수식 계산이며 새 KiCad/SPICE 실행이나 실측 결과가 아니다.

실제 대기 시간을 정하려면 허용 배분·R/C 실제값/공차·입력 변화·스위치 연결 시 초기 전압·실제 ADC 부하를 반영해야 한다. 따라서2.68ms를 지금 펌웨어의 보장 대기 시간으로 확정하지 않는다. 외부 회로의 정착 조건을 만족해도 ADC 내부 취득은37-3에서 별도로 확인한다.

근거 문서는 **ST AN2834 Rev10, 2024-10, 인쇄/PDF17쪽 §3.2.8·Figure16**이다. 외부 용량/기생 용량과 입력 저항이 측정에 영향을 준다는 부분을 읽는다. 내부/외부 경로 구분은 **27쪽 §4.2.6·Figure26**을 참고한다. [공식17쪽](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf#page=17) · [공식27쪽](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf#page=27). 위0.363286ms/2.68ms는 이 문서의 제조사 보장값이 아니라 프로젝트 명목 회로에서 직접 계산한 값이다.

**필기 결론과 이번 산출물**

> 정착 시간은 무조건1tau나5tau로 정하지 않는다. 입력 변화량과 정착에 허용할 잔차를 정한 뒤1차 모델에서 t≥tau×ln(E0/E_allow)로 계산한다. 현재 명목 ON 경로의 C1 중심 시정수는약0.363286ms이고,0→16V 변화에 정착 기여10mV를 가정하면약2.68ms가 필요하다.10mV 배분과 실제 대기 설정은 아직 확정하지 않았다.

예산에는 '정착 기여: 설명용10mV, 적용 조건: 명목 계단 응답, 실물/최종 배분: 미정'으로 남긴다. 새로운 부품값이나 펌웨어 설정을 채택하지 않았다. 다음은37-3 ADC 내부 취득·입력 경로·채널 전환 조건이다. 사용자 필기/실습 확인은 아직 받지 않았다.

### 37-3. ADC 내부 취득 시간과 채널 전환 조건

**이번 설계 질문:** 외부 VADC가 안정된 뒤 ADC 내부에도 그 전압을 충분히 취득할 시간을 주었는가? 산출물은 내부 입력 모델의 근거, 취득 시간 계산, 향후 구현에서 비교할 설정 후보와 검증 조건이다. 사용자의37절 필기/실행 완료를 의미하지 않는다.

**1. 외부 전압이 안정되어도 내부 취득은 매번 필요하다**

ADC는 입력 핀 전압을 읽을 때 내부의 작은 커패시터에 전하를 저장하고, 그 상태를 이용해 디지털 코드로 변환한다. 단순화하면 다음 두 단계다.

```text
외부 분압·필터·TMUX → VADC 핀
                         ↓
               내부 채널 선택/샘플링 스위치
                         ↓ RADC
               내부 샘플링 커패시터 CADC
                         ↓
                   디지털 코드 변환

취득: 내부 스위치가 연결된 동안 CADC가 입력 전압에 가까워짐
변환: 취득한 상태를 이용해 디지털 코드 결정
```

내부 커패시터를 충분히 충전/방전하기 전에 취득을 끝내면 입력과 다른 상태를 변환할 수 있다. 외부 회로를2.68ms 기다렸거나 결과를100ms마다 갱신한다는 것만으로 내부 취득 시간이 확보되지는 않는다.

근거는 **ST DS10693 Rev10, 2021-01, 인쇄/PDF143쪽 Figure46**의 RAIN·RADC·CADC와 **AN2834 Rev10, 2024-10, 인쇄/PDF43쪽 §4.4.2 Figure38·39**다. 후자는 입력으로의 전하 주입과 취득 중 정착도 설명한다. [보유 STM 데이터시트](../../assets/stm32f446mc.pdf) · [AN2834 공식43쪽](https://www.st.com/resource/en/application_note/an2834-how-to-optimize-the-adc-accuracy-in-the-stm32-mcus-stmicroelectronics.pdf#page=43).

**2. 이전100pF와 내부 CADC를 구분한다**

| 기호/위치 | 값과 근거 | 이번 역할 |
| --- | --- | --- |
| C1, VDIV–GND | 외부 필터 모델100nF | 분압 출력의 외부 응답 |
| C2, VADC–GND | 방전 실습의100pF 가정 | ADC 쪽 외부 노드에 남는 전하를 표현; 실물 확정값 아님 |
| CADC, MCU 내부 | TYP4pF / MAX7pF | 취득할 때 내부 스위치를 통해 연결되는 용량 |
| RADC, MCU 내부 | MAX6kΩ | 내부 샘플링 스위치 경로의 저항 |

CADC/RADC는 **DS10693 Rev10 p139 §6.3.21 Table74 해당 행**, 저항 조건은 **p140 각주4**에서 확인한다.6kΩ 최대는 VDD1.7V 조건 설명이 붙어 있으므로3.3V에서 항상6kΩ이라는 뜻이 아니다. 아래는 최대값을 사용한 계산 비교다. Figure46의 외부 기생 용량과 CADC도 서로 다른 위치다. C2=100pF가 총 노드 용량을 가정한 값이면 같은 패드/배선 용량을 다시 더하지 않는다.

현재 공식 웹 PDF는 **DS10693 Rev11, 2026-05**이며 Table74는140쪽, Equation1은141쪽, Figure46은144쪽, Table83은146쪽이다. 보유 Rev10과 쪽 번호를 혼용하지 않는다. [공식 Rev11 Table74](https://www.st.com/resource/en/datasheet/stm32f446re.pdf#page=140). 이번 설명은 보유 Rev10 쪽 번호를 기준으로 한다.

**3. 취득 시간은 ADC 클록과 샘플링 사이클로 정한다**

```text
tS = k / fADC

tS: 내부 취득 시간 [s]
k: 설정한 샘플링 사이클 수
fADC: ADC 클록 [Hz]
```

STM32F4 HAL의 선택지는3·15·28·56·84·112·144·480cycles다. 클록 분주 선택지는 PCLK2의 /2·/4·/6·/8이다. 근거는 ST 공식 `stm32f4xx_hal_adc.h`의 `ADC_sampling_times`와 `ADC_ClockPrescaler` 정의이며, 여기서 말하는 샘플링 사이클은 결과 갱신 주기가 아니다. [공식 HAL 헤더](https://github.com/STMicroelectronics/stm32f4xx-hal-driver/blob/master/Inc/stm32f4xx_hal_adc.h). 웹 소스 확인일2026-11-05이며 프로젝트 라이브러리를 설치/수정하지 않았다.

현재 저장된 `stm32_uart_mvp/Core/Src/main.c`의 SystemClock_Config와 `.ioc`는 명목 PCLK2=84MHz다. 측정용 ADC 초기화는 없고 HAL_ADC_MODULE_ENABLED도 비활성이다. 따라서 다음은 **향후 설정 후보**다.

```text
현재 PCLK2 명목84MHz
ADC 분주 /6을 후보로 적용하면 fADC = 84MHz / 6 = 14MHz
480cycles의 취득 시간 = 480 / 14MHz ≈ 34.286µs
```

| 샘플링 설정 | 명목14MHz에서 취득 시간 |
| --- | --- |
| 3cycles | 0.214µs |
| 15cycles | 1.071µs |
| 28cycles | 2.000µs |
| 56cycles | 4.000µs |
| 84cycles | 6.000µs |
| 112cycles | 8.000µs |
| 144cycles | 10.286µs |
| 480cycles | 34.286µs |

같은480cycles도 클록이 달라지면 시간이 달라진다. 최종 검토에는 실제 클록 구성과 클록 오차도 포함한다. 이전36절의18MHz는 데이터시트 정확도 표의 비교 조건이며 현재 구현된 ADC 클록을 뜻하지 않는다.

**4. 입력 저항이 클수록 필요한 취득 시간이 길어진다**

우선 C1/C2의 동적 효과를 제외하고, VADC에서 외부 회로 쪽을 바라본 저항만 계산한다. 이상 전압원을0V로 놓는 것은 등가 저항 계산 절차이며 실제 배터리를 단락하는 작업이 아니다.

```text
R_AIN_resistive = R5 || [R4 + RON + ((R1+R2) || R3)]
               = 47kΩ || [1kΩ + 2Ω + (24kΩ || 4.7kΩ)]
               ≈ 4463.863Ω
```

37-2의3632.862Ω은 **C1에서 본 저항**이고, 여기4463.863Ω은 **VADC에서 본 외부 저항**이다. 보는 위치가 달라 식도 다르다. 실제 입력은 C1/C2를 포함하므로 이 저항 하나로 전체 취득 과도를 판정하지 않는다.

**DS10693 Rev10 p140 Equation1**은 취득 관련 오차를1/4LSB 아래로 제한하는 외부 입력 저항 조건을 제시한다. 이를 필요한 사이클 수 형태로 바꿔 계산한다.

```text
RAIN_max = (k − 0.5) / [fADC × CADC × ln(2^(N+2))] − RADC

경계에서의 필요한 사이클:
k_req = 0.5 + fADC × (RAIN + RADC) × CADC × ln(2^(N+2))

N=12bit, fADC=14MHz
RAIN≈4463.863Ω, RADC=6000Ω, CADC=7pF

k_req ≈ 10.451cycles
→ 저항성 단순 모델에서는 그보다 긴15cycles가 첫 선택지
```

`ln`은 자연로그다. 저항×용량은 충전 시간의 규모를 만들고, 높은 분해능에서 작은 잔차까지 줄이려면 더 오래 취득해야 하므로 로그 항이 붙는다.0.5cycle 항까지 포함한 제조사 식을 사용했다. Table74의 RAIN MAX50kΩ도 Equation1 조건을 함께 읽어야 하며, 모든 샘플링 설정에서50kΩ까지 허용된다는 뜻은 아니다.

**15cycles면 실제 회로 검증까지 끝났다는 결론은 아니다.** 현재 회로에는 외부 커패시터의 전하 공급/회복, 내부 스위칭의 입력 교란과 채널 전환이 있고 R/C·RON도 실제 조건에 따라 달라진다. 이 계산은 저항성 모델에서 시간 규모를 비교한 근거다.

또한 식의1/4LSB는 ADC 전체 정확도가 아니다.3.3V·12bit에서1/4LSB는 ADC 쪽약0.2014mV, 명목 K=6.747204165로 환산하면 VRAIL 쪽약1.359mV다. 취득 조건을 만족해도 ADC 비선형성·기준전압·잡음 등의 기여가 남는다. 전체 예산에서 TUE와 겹치는 부분을 무조건 중복 합산하지 않는다.

**5. 채널을 바꾸면 다음 입력을 다시 취득해야 한다**

우리 계획은 배터리 측정, 모터 공급 측정, VREFINT 등을 읽는 것이다. 예를 들어 외부 입력이약2.37V인 채널 다음에0V에 가까운 채널을 읽으면 내부 취득 회로가 새로운 전압에 맞춰 충전 또는 방전해야 한다. 이전 내부 상태와 전하 주입의 영향이 충분히 줄기 전에 변환하면 첫 측정이 달라질 수 있다. 이는 동작 원리를 설명한 단순 모델이며 내부 커패시터가 반드시 이전 코드의 전압을 그대로 보존한다는 주장은 아니다.

```text
채널 A 선택·취득·변환
       ↓ 채널 변경
채널 B 선택·다시 취득·변환
```

이 내부 채널 선택과 외부 TPS/TMUX의 보호 스위치는 구분한다. 정상 전원에서 ADC 채널을 바꿀 때마다 외부 TMUX를 OFF→ON할 필요는 없다. 외부 입력이 안정된 채널을 읽는 것에37-2의0→16V 정착 시간을 매번 그대로 붙이지도 않는다. 향후 실제 읽기 순서와 최대 채널 간 전압 차이를 포함해 검증한다.

**6. VREFINT는 별도의 최소 취득 시간 조건이 있다**

**DS10693 Rev10 p145 §6.3.24 Table83**의 `TS_vrefint`는 **MIN10µs**, `tSTART`는 **TYP6µs/MAX10µs**다. 전자는 읽을 때 확보할 취득 시간, 후자는 내부 기준을 켠 뒤 안정화하는 시작 시간으로 서로 다르다. 표의 각주도 함께 읽고 검증 없이 최소 취득 시간을 줄이지 않는다.

```text
14MHz에서10µs 취득에 필요한 사이클 = 14MHz × 10µs = 140cycles
선택지 중144cycles → 약10.286µs
480cycles → 약34.286µs
```

외부 입력의 저항성 계산에서15cycles가 나와도 VREFINT에 그대로 적용하면1.071µs라서10µs 조건에 못 미친다. ADC 자체의 켜짐 후 안정화 tSTAB(MAX3µs, p139 Table74), VREFINT 시작 tSTART와 매 변환 취득 시간은 구분한다. 실제 활성화 순서에 따라 중첩될 수 있으므로 수치들을 무조건 더하지 않는다.

**7. 이번 후보와 검증 조건을 기록한다**

초기 검토 후보는 **12bit / 명목 fADC14MHz / 외부 전압 채널과 VREFINT의480cycles**다.10Hz 결과 제안에서는 최단 변환 시간보다 취득 여유를 먼저 확보할 수 있다. 다만480cycles도 전체 회로의 정확도를 증명하지는 않는다.

**DS10693 Rev10 p139 Table74 `tCONV`**에 따라12bit의 취득 포함 변환 시간은 `(k+12)/fADC`다.

```text
480cycles 취득: 약34.286µs
12bit 변환까지: (480+12)/14MHz ≈ 35.143µs / 채널
```

트리거 지연·채널 순서·DMA/소프트웨어·평균 처리 시간은 별도다. 앞선18MHz 조건 TUE 표를14MHz의 새 실물 측정 보증으로 바꾸지 않는다.

향후에는 같은 안정 입력을 연속 읽은 값과 서로 다른 전압 채널 사이를 왕복해서 읽은 값을 비교하고, 취득 시간을 늘렸을 때 채널 전환 직후 값/평균/흔들림이 달라지는지 원시 코드로 확인한다. 기준 입력의 안정도·잡음과 취득 부족을 구분하고 첫 값을 무조건 버리는 규칙부터 채택하지 않는다. 이 검증은 아직 수행하지 않았다.

> 필기 결론: 외부 VADC 정착과 ADC 내부 취득은 다른 조건이다. 내부 CADC는 TYP4pF/MAX7pF로 이전100pF 방전 가정과 구분한다. 취득 시간은 k/fADC로 계산하며 입력 저항, 외부 용량, 채널 전환과 VREFINT 최소10µs 조건을 함께 확인한다. 현재 클록에 맞춘14MHz·480cycles는 충분한 취득 여유를 확보하기 위한 시작 후보이고 구현/전체 정확도 검증은 남아 있다.
