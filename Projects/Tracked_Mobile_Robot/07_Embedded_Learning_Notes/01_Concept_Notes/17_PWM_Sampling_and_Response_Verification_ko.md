# 3-3. PWM·수집 조건과 응답 검증

학습 회차: 2026-10-25 · 정리: 2026-10-26. 이전: [3-2 정확도와 보정 검증](16_DC_Accuracy_and_Calibration_Verification_ko.md). 명목 계산과 후속 시험안을 설명한다. 실제 PWM 리플이나 응답을 측정한 문서가 아니다.

**핵심:** DC 입력에서 잘 읽더라도 모터 PWM과 ADC 수집의 시간 관계 때문에 다른 값이 보일 수 있다. 정확도, 흔들림, 새 값으로 바뀌는 시간은 각각 확인한다.

---

**① 먼저 ‘무슨 전류’를 비교하는지 맞춘다**

PWM 구동 전류에는 시간에 따른 변화가 있다. 이 프로젝트의 첫 목표는 필터된 평균·부하 추세 관측이다. 순간 피크, RMS 전류, 고속 과전류 차단은 별도의 요구다.

설명용으로 0A와 2A를 같은 시간 동안 오가는 이상적 파형을 생각해 보자.

```text
시간 평균 = (0+2)/2 = 1A
RMS = sqrt((0²+2²)/2) ≈ 1.414A
순간 최대 = 2A
```

이는 실제 모터 파형이 아니다. 인덕턴스와 전류 순환 경로 때문에 실제 파형은 다를 수 있다. 예시의 목적은 **같은 파형도 평균·RMS·최댓값이 서로 다르다**는 점이다. 평균 출력과 기준 계기의 RMS 표시를 그대로 빼면 측정량 자체가 다른 비교가 된다.

기준 계기의 모드·대역폭·평균 구간과 센서의 설치 위치를 확인한다. 공급선 전류와 모터 권선 전류도 PWM 순환 경로에 따라 같지 않을 수 있으므로, 같은 전류 경로를 비교하는지 먼저 정한다.

---

**② 19kHz 감쇠 계산이 알려주는 범위**

현재 명목 R=12kΩ, C=100nF인 1차 저역통과필터는 다음 계산을 갖는다.

```text
τ = R×C = 0.0012s = 1.2ms
f_c = 1/(2πRC) ≈ 132.63Hz
|H(f)| = 1 / sqrt(1+(f/f_c)²)
|H(19000Hz)| ≈ 0.00698
```

`|H|`는 **입력의 해당 정현파 성분 진폭에 곱하는 비율**이다. 입력 19kHz 성분의 진폭이 100mV라고 가정할 때만 출력 진폭 약 0.698mV를 계산할 수 있다. 명목 감도 44mV/A로는 약 0.0159A에 해당한다. 모두 설명용이며 입력의 실제 진폭은 아직 모른다.

PWM에는 기본파 외의 성분이 있을 수 있다. 접지·전원·배선·센서 출력 구동으로 유입되는 변화가 모두 이 단순 RC 한 개를 통과한다고 가정하지도 않는다. “0.7%가 남는다”는 계산만으로 전체 잡음이 허용 오차보다 작다고 결론 내리지 않는다.

---

**③ 빠른 변화가 느린 흔들림처럼 보이는 alias**

ADC는 연속 파형의 일부 시각만 읽는다. 일정 간격으로 읽는 시각과 신호 주기가 거의 맞물리면 매번 조금씩 다른 위상을 읽어 느린 변화가 생길 수 있다.

기존 명목 타이머 계산은 다음과 같다. 실제 ADC 트리거 설정의 확정을 의미하지 않는다.

```text
PWM 주파수 = 84,000,000 / (0+1) / (4420+1)
           ≈ 19000.226193Hz

100Hz 수집 : |19000.226193 − 190×100| ≈ 0.226193Hz
1000Hz 수집: |19000.226193 − 19×1000| ≈ 0.226193Hz
이 느린 변화의 주기 = 1/0.226193 ≈ 4.421초
```

위 식은 이상적인 균일 수집에서 기본파가 접혀 보이는 주파수의 예다. 실제 PWM·ADC가 공통 클록을 쓰는지, 분주값·위상·지터가 무엇인지 확인한 뒤 실제 설정으로 다시 계산해야 한다.

100Hz에서 1kHz로 높여도 이 예의 기본파 alias는 같다. 이미 샘플 값에 약 4.4초 주기의 변화로 나타나면 100ms 평균으로는 거의 제거되지 않는다. 기존 계산에서 해당 성분의 진폭 약 99.916%가 평균 뒤에도 남았다. **이는 RC 뒤에 남아 샘플에 들어온 성분에 대한 비율**이며 원래 PWM 전체가 그대로 남는다는 뜻이 아니다. [계산 JSON](../../09_Electrical_Design/KiCAD/TMR_Monitor_Shield_RevA/reports/current_sampling_cadence_review.json), [ADI 샘플링·alias 설명](https://wiki.analog.com/university/courses/electronics/text/chapter-20).

---

**④ 수집률만 높이면 해결되는지 비교한다**

| 비교 조건 | A: 채널별 100Hz | B: 채널별 1kHz |
| --- | ---: | ---: |
| 같은 채널 반복 간격 | 10ms | 1ms |
| 100ms 블록 평균 샘플 수 | 10개 | 100개 |
| 나이퀴스트 주파수 | 50Hz | 500Hz |
| 6채널·14MHz·480cycles일 때 변환 시간 비율 | 약 2.11% | 약 21.09% |

변환 시간 비율은 CPU 점유율이 아니다. 공통 후보인 ADC 획득 창 34.29µs와 위 표의 반복 간격도 다른 시간이다.

100Hz 수집의 나이퀴스트 주파수 50Hz는 RC 차단 주파수 132.63Hz보다 낮다. 따라서 수집 전에 50Hz 위 성분이 충분히 제거되었다고 볼 수 없다. 1kHz도 500Hz 위 성분을 완전히 제거하지는 못한다. 필터의 감쇠와 입력 성분의 실제 크기를 함께 봐야 한다.

비교할 때 입력, RC, ADC 획득 설정, 채널 순서, 보정 계수와 전원 조건을 가능한 한 고정하고 수집률을 바꾼다. 각각의 원시값·처리값·실제 수집 시각을 남겨 평균 이동, 산포, 느린 흔들림, 누락을 비교한다. 매 조건마다 재보정하여 차이를 숨기지 않는다.

---

**⑤ 평균 개수가 많다고 항상 잡음이 줄지는 않는다**

서로 독립적이고 평균이 0인 잡음은 단순 평균에서 표준편차가 대략 `1/√N`로 줄어드는 모델을 쓸 수 있다. `N`은 평균에 사용한 샘플 수다.

그러나 같은 방향으로 천천히 움직이는 오차, 일정한 영점 오차, PWM과 동기된 주기 오차에는 이 감소율을 그대로 적용할 수 없다. 연속 샘플끼리 상관되어 있을 수 있기 때문이다. 10개에서 100개로 늘렸다는 이유만으로 정확도가 √10배 좋아진다고 쓰지 않는다.

초기 관찰안으로 각 조건을 안정 후 20초 기록하면 명목 4.421초 변화가 약 4.5주기 들어온다. 이 길이는 해당 느린 변화를 보기 위한 **제안**이며 모든 잡음·드리프트를 대표하는 검증 시간은 아니다. 관측 결과와 자원 조건에 따라 길이를 정한다.

PWM 정지/동작 비교 역시 후속 조건표다. 실제 모터 조작은 물리 준비·중단 조건을 정한 뒤 사용자가 한 그룹씩 수행한다. 이번 학습 마감에서 주행 시험이나 새 계측기 연결을 실행하지 않는다. 파형 계측 수단이 부족하면 주파수/원인 확정은 보류하고 “조건에 따른 변화 관측”으로 기록한다.

---

**⑥ 갱신 주기와 응답 시간은 다르다**

100ms마다 결과가 나오는 것은 **갱신 주기**다. 입력이 바뀐 후 결과가 새 값에 충분히 가까워질 때까지는 **응답 시간**이다.

100ms 단위의 겹치지 않는 블록 평균을 가정하자. 블록 시작 직후 입력이 바뀌면 그 블록에는 이전 입력 샘플이 일부 남는다. 다음 블록은 새 입력으로 채워지고 끝날 때 결과가 나온다. 위상에 따라 처음으로 전부 새 입력을 담은 블록까지 거의 200ms가 걸릴 수 있다.

실제 입력은 RC를 거쳐 점진적으로 변하고, 보정 후 고정 잔차도 있다. 따라서 `RC의 99% 응답 5.53ms + 100ms`처럼 단순 합산해 300ms 목표 통과를 선언하지 않는다. 실제 처리 알고리즘과 출력 시점까지 포함해 확인한다.

---

**⑦ 응답 시험의 시작점과 도착점을 정한다**

전류·전압의 제안 목표는 **입력이 안정된 뒤 300ms 이내에 새 정상상태 값이 허용 범위로 반영**되는 것이다.

```text
t0 : 시험 입력이 새 값으로 안정되었음을 확인한 시각
t1 : 그 새 값에 대해 허용 범위에 들어간 유효 처리 결과의 시각
응답 시간 = t1 − t0
```

명령 버튼을 누른 시각은 전기 입력이 안정된 시각과 다르다. 브라우저 수신 시각도 MCU 측정 결과 생성 시각과 다르다. 기준 입력과 출력의 시각을 공통 시간축에 놓거나 두 시계의 대응 오차를 알아야 한다.

한 번 범위에 들어왔다가 다시 벗어나는 경우를 놓치지 않도록, **진입 후 1초 동안의 처리 결과도 범위에 남는지 확인하는 안**을 제안한다. 10Hz라면 약 10개 결과에 해당한다. 이 유지 시간은 추가 제안이며 원래 요구에서 확정한 값은 아니다. 정착 시각과 이를 확인하기 위한 관찰 종료 시각은 따로 적는다.

허용 범위에는 3-1의 읽음값 기준 오차와 불확도 규칙을 적용한다. 평균값만 보고 개별 결과의 초과를 지우지 않는다. 온도는 별도로 저항 대입 안정 후 2초 목표이며 실제 모터의 열응답 목표가 아니다.

---

**⑧ 100ms 간격의 결과로 1ms 정밀도를 주장하지 않는다**

가상 예시에서 입력 안정 시각을 0ms로 놓고, 180ms 결과는 범위 밖, 280ms 결과부터 범위 안이며 이후에도 유지되었다고 하자. 출력 관측상 진입은 **(180, 280]ms 구간**에 있다. 연속 내부값이 어느 순간 진입했는지를 1ms 단위로 안 것은 아니다.

기준 입력과 출력 시각 비교의 불확도까지 고려한 상단이 285ms라고 정당화할 수 있다면, 해당 관측의 300ms 이내 반영을 지지한다. 다만 앞 절의 유지 조건과 값의 불확도도 함께 만족해야 한다.

반대로 첫 범위 안 결과가 330ms라고 해서 연속 값이 반드시 300ms 이후 진입했다고 단정할 수는 없다. 직전 결과와의 관측 간격이 있기 때문이다. **300ms가 지난 310ms에도 범위 밖인 새 결과가 확인된다면** 시각 불확도를 고려한 뒤 응답 미달 근거로 삼을 수 있다. 결과 생성 주기 요구와 진입 시각 관측 한계를 함께 기록한다.

---

**⑨ 후속 비교표**

| 항목 | 기록할 근거 | 현재 상태 |
| --- | --- | --- |
| DC 100Hz/1kHz | 같은 계수의 평균·산포·잔차·원시 시각 | NOT_RUN |
| PWM 조건 변화 | 같은 전류 경로/측정량의 기준 비교, 실제 PWM 설정 | NOT_RUN |
| 느린 흔들림 | 시간열·관측 길이·위상 관계, 원인 단정의 한계 | NOT_RUN |
| 100ms 새 결과 생성 | MCU 생성 시각 간격·누락, 브라우저 시각과 분리 | NOT_RUN |
| 300ms 반영 | 입력 안정 시각·출력 허용 범위 진입·유지·시각 불확도 | NOT_RUN |

**이 절의 도착점:** DC 정확도, PWM 영향, 평균의 효과, 결과 갱신, 응답 시간을 각각 설명하고 따로 검증할 수 있다. 현재 100Hz·10개 평균은 첫 DC 비교 조건 제안이며 최종 운용 설정이 아니다.
