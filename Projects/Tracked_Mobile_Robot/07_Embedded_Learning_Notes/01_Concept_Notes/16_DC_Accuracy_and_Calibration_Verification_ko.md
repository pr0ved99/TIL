# 3-2. 정확도와 보정 검증

학습 회차: 2026-10-25 · 정리: 2026-10-26. 이전: [3-1 검증 대상과 합격 기준](15_Verification_Targets_and_Acceptance_ko.md). 이 문서는 실행 전 학습 자료다. 아래 수치는 명목 환산 또는 **가상 예시**이며 실측 결과가 아니다.

**핵심:** 보정에 사용한 점을 잘 맞췄다는 것과, 다른 입력에서도 정확하다는 것은 다르다. 센서를 제외한 입력계부터 잔차를 확인하고, 센서 포함 시험은 별도로 판정한다.

---

**① 먼저 ‘무엇이 틀어졌는지’ 볼 수 있는 입력을 만든다**

모터를 돌려 측정값이 흔들리는 것만 보면 전류 자체가 변했는지, 센서가 흔들렸는지, ADC가 잘못 읽었는지 구분하기 어렵다. 그래서 첫 비교 대상으로 **알려진 안정 DC 전압**을 제안한다.

```text
입력계 시험: 알려진 DC 전압 → R1/C1 → ADC → 환산값
전체 시험  : 알려진 전류 → 실제 센서 → R1/C1 → ADC → 전류값
```

왼쪽 초안은 J3.3에서 R1=12kΩ을 거쳐 PC0 ADC로 들어가고 C1=100nF가 ADC 쪽에서 GND에 연결된다. 오른쪽은 R2/C2와 PC1이다. 이는 **회로도상의 위치 설명**이며 완성된 실물의 시험 단자가 이미 있다는 뜻은 아니다.

나중에 연결할 때는 센서 출력과 시험 전압원을 서로 직접 밀어내는 연결을 피해야 한다. 전원을 끈 상태에서 센서 출력 분리 여부, 공통 GND, 입력 보호·허용 범위·전원 순서를 먼저 확인해야 한다. 실제 프로브 위치와 한 번의 조작은 실물 토폴로지를 확인한 뒤 정한다. 지금은 배선·전원 투입 지시가 아니다.

---

**② 명목 전압을 고르는 이유**

선정 센서의 명목 모델은 다음과 같다. 실제 부품은 Pololu #5241의 ACS71240KEXBLT-030B3이며 비례형 전원 추종 센서로 가정하지 않는다. [Pololu 사양](https://www.pololu.com/product/5241).

```text
V_sensor = V_zero + S × I

V_zero = 1.65V       : 명목 무전류 출력
S      = 0.044V/A    : 명목 감도, 1A 변화마다 44mV 변화
I                    : 부호를 포함한 전류 [A]
```

| 모사하려는 명목 전류 | 계산 | 전압 대입 후보 |
| --- | --- | ---: |
| −10A | 1.65 + 0.044×(−10) | 1.21V |
| −5A | 1.65 + 0.044×(−5) | 1.43V |
| 0A | 1.65 + 0 | 1.65V |
| +5A | 1.65 + 0.044×5 | 1.87V |
| +10A | 1.65 + 0.044×10 | 2.09V |

이 표의 ±10A는 **그 전류에 해당하는 전압을 모사한다는 의미**다. 실제 모터에 ±10A를 흘리라는 지시가 아니다. 시험 전압원의 설정 숫자도 실제 단자 전압과 같다고 단정하지 않는다. 연결 후 해당 입력점에서 읽은 기준 전압과 그 불확도를 기록해야 한다.

전압원이 센서와 다른 출력 임피던스를 가지면 동적 동작도 달라질 수 있다. DC 대입 통과는 센서의 RC 구동 안정성까지 확인한 결과가 아니다.

---

**③ ADC 코드, 기준 전압, 환산값을 함께 남긴다**

12bit ADC의 이상적 한 단계는 다음과 같다.

```text
1LSB = V_ref / 4096
V_ref를 3.3V로 가정하면 1LSB = 0.805664mV
전류 환산 한 단계 = 0.805664mV / (44mV/A) ≈ 0.01831A
```

`4096=2^12`는 코드 단계 수다. 코드 범위는 0~4095이며 실제 ADC 전달 특성·오프셋·이득 오차는 별도로 남는다. 18.3mA씩 구분할 수 있다는 계산은 18.3mA 정확도를 보장하지 않는다.

ADC 코드를 전압으로 바꿀 때 쓴 `V_ref`가 실제 ADC 기준 전압과 다르면 환산값도 달라진다. STM32F446RE 보드의 VDDA/VREF 연결과 실제 기준 전압을 확인해야 한다. 센서 전원이 변해도 ADC 값에서 자동 상쇄된다고 가정하지 않는다.

기록에는 최소한 `raw_code`, `reference_voltage`, `converted_voltage`, `calibration_id`, `sample_time`, `channel`이 필요하다. ADC 클록·획득 cycles·수집률·채널 순서·평균 길이는 설정표에 남긴다. 원시값이 없으면 나중에 보정 문제인지 수집 문제인지 다시 분리하기 어렵다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf), [ST AN2834 ADC 정확도 지침](https://www.st.com/resource/en/application_note/cd00211314.pdf).

---

**④ 보정은 영점과 기울기를 구하는 작업이다**

전류 환산의 기본식은 다음과 같다.

```text
I_est = (V_measured − V_zero_cal) / S_cal

I_est      : 보정 후 전류 추정값 [A]
V_measured : 정의한 측정 경로에서 얻은 전압 [V]
V_zero_cal : 실제 보정에서 구한 영점 전압 [V]
S_cal      : 실제 보정에서 구한 감도 [V/A]
```

**센서 포함 가상 보정 예시:** 알려진 0A에서 1.658V, 알려진 +5A에서 1.883V를 얻었다고 하자. 실제 시험값이 아니다.

```text
V_zero_cal = 1.658V
S_cal = (1.883 − 1.658)V / (5 − 0)A
      = 0.225V / 5A = 0.045V/A
```

명목 감도 44mV/A 대신 이 예시에서는 45mV/A를 사용한다. 0A와 5A는 계수를 만드는 데 사용했으므로 그 두 점이 맞는 것은 독립적인 정확도 검증이 아니다. 기준 전류 자체의 불확도도 계수와 결과에 영향을 준다.

ADC 코드 영역에서 바로 `I=a×code+b` 형태로 보정할 수도 있다. 어떤 영역을 쓰든 계수의 단위, 적용 조건, 기준점, 버전을 남겨야 한다. 전원·온도·수집 설정이 달라진 뒤에도 계수가 유효한지는 검증 대상이다.

---

**⑤ 보정에 쓰지 않은 점으로 잔차를 확인한다**

같은 가상 장치에 독립적인 +2A 입력을 주었고 1.751V가 나왔다고 하자.

```text
I_est = (1.751 − 1.658) / 0.045
      = 0.093 / 0.045 ≈ 2.0667A
d = 2.0667 − 2.0000 = +0.0667A
```

이 `+0.0667A`가 보정 후 남은 관측 차이다. 보정을 했다고 차이가 0이 되는 것은 아니다. 정확도 판정에는 [3-1의 기준 계기 불확도와 판정 규칙](15_Verification_Targets_and_Acceptance_ko.md)이 추가로 필요하다.

정해진 범위 전체를 주장하려면 양의 전류 쪽만 확인해서도 안 된다. 0A/+5A로 보정했다면 다른 양의 점, 음의 점, 범위 끝부분의 잔차를 따로 본다. 음의 구간은 이 두 보정점 밖의 외삽 구간이므로 특히 확인이 필요하다. 시험점 몇 개의 통과를 연속 범위 전체의 보증으로 확대하지 않는다.

---

**⑥ 입력계 보정과 센서 보정을 구분한다**

| 수행한 작업 | 보정되는 경로 | 남는 검증 |
| --- | --- | --- |
| 센서 대신 DC 전압 대입 | 입력 회로·ADC·전압 환산의 오프셋/기울기 | 실제 센서 영점·감도·비선형·온도 영향 |
| 실제 센서에 알려진 전류 | 해당 조건의 센서 포함 전체 경로 | 다른 전류·온도·PWM·전원에서 잔차 |
| 모터 정지 상태의 값 확인 | 당시 관측값 확인 | 실제 전류 0A인지의 독립 확인 |

1.65V를 넣어서 0A로 표시되게 만든 것은 **실제 센서의 0A 영점을 측정한 것과 다르다.** 모터를 멈췄다는 사실도 센서를 흐르는 전류가 정확히 0A임을 자동 증명하지 않는다. 센서가 놓인 전류 경로와 다른 부하를 확인해야 한다.

입력계와 전체 경로 보정을 중복 적용해 같은 오프셋/이득을 두 번 고치지 않도록 환산 파이프라인을 하나로 정한다. 계수에는 대상 채널과 적용 단계가 포함되어야 한다.

---

**⑦ 한 점의 숫자만 남기지 않고 반복성과 조건 의존성을 남긴다**

실행 전 제안은 각 안정 입력에서 일정 구간의 원시값과 100ms 처리 결과를 함께 저장하는 것이다. 예를 들어 안정 후 10초를 기록하면 10Hz 결과 약 100개를 얻는다. 이를 3회 비교하는 것은 초기 관찰안이며 통계적으로 충분함을 증명한 횟수가 아니다.

확인할 것은 평균, 최솟값·최댓값, 산포, 각 처리 결과의 허용 범위 이탈, 전원·주위 온도·시간 변화다. 평균이 맞아도 출력값이 크게 출렁일 수 있고, 산포가 작아도 일정하게 틀릴 수 있다.

보정 계수는 비교 중 고정한다. 수집률을 바꿀 때마다 다시 영점을 맞춰 버리면 설정 변경 때문에 생긴 편향을 숨길 수 있다. 조건별 보정이 필요하다면 고정 계수 비교와 재보정 후 결과를 분리해 기록한다.

좌우 채널은 각각 보정하고 각각 검증한다. 한 채널 PASS를 다른 채널에 복사하지 않는다. 채널 순서에 따른 전압 차이의 영향도 후보 설정의 일부다.

---

**⑧ 온도와 버스 전압에는 다른 입력 모사가 필요하다**

온도 입력계는 NTC 대신 **제조사 R-T 표에 해당하는 정밀 저항**으로 온도를 모사한다. 103JT-025의 명목 25°C·10kΩ은 기준점 하나이고, 다른 온도의 저항은 확인한 표/모델에서 가져온다. 저항 오차가 온도 오차로 얼마나 바뀌는지는 해당 구간의 비선형 환산을 적용해야 한다. [SEMITEC JT 사양](https://www.semitec-global.com/uploads/2022/01/P9-JT-Thermistor.pdf).

저항 대입의 ±1°C와 센서를 모터 케이스에 붙여 GM1312와 비교한 차이는 시험 범위가 다르다. 후자에는 센서 자체·접촉·위치·열평형·기준 프로브의 차이까지 들어간다.

버스 전압은 확정된 분압·보호 회로를 거친 0~16V 입력을 검증해야 한다. 현재 회로와 핀·보호 계약이 준비되지 않은 항목은 **NOT_READY / 시험 NOT_RUN**으로 남긴다. ADC 핀에 16V를 직접 대입하지 않는다.

---

**⑨ 결과를 남기는 최소 형식**

```text
시험 ID / 채널 / 회로·펌웨어 버전:
대상: 입력계만 / 센서 포함
전원·온도·PWM / ADC·수집·평균 설정:
보정점과 계수 / calibration_id:
독립 검증점 / 기준값·단위·불확도:
원시값·처리값 파일:
관측 차이 / 산포 / 허용 기준 / 판정:
미확인 범위와 다음 수정:
```

**이 절의 도착점:** “계수를 만들 때 사용하지 않은 입력에서도, 정의한 조건과 불확도를 고려했을 때 어느 정도 맞는가”를 설명할 수 있다. 현재는 계획 작성 완료이며 **실물 정확도·보정 시험 NOT_RUN**이다.
