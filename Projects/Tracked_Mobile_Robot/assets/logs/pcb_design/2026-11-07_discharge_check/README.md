R5=47kΩ·가정 C2=100pF에서 τ=4.7µs,99% 방전 시간은4.605τ≈21.644µs다. 초기값2.371352579V와 OFF 정상상태 계산값123.143µV를 사용한 단순 지수 근사는1τ에서872.449703mV다. 사용자 관측값과 약0.018975mV 차이다. 같은 근사에서 두 관측점의 잔류 비율은36.7887%와1.0002%로, 학습용 RC 방전 예상과 대응한다.

OFF 정상상태값은 이번 커서로 관측한 값이 아니며, 스위치 앞100nF 노드도 OFF 뒤 정착한다. 따라서 이 단순 지수 근사를 전체 두 노드 회로의 정확해나 보호 상한으로 해석하지 않는다. CSV 끝점10.35ms의171.652µV를 무한 시간 뒤 최종값으로 취급하지 않는다. 실제 TPS/TMUX·MCU 핀 보호나 실물 정확도 PASS가 아니다.

## CSV 출력 정밀도

CSV의 표기 시각 그대로 읽으면10.3047ms에서863.188mV,10.32164ms 선형 보간은23.5906mV로 GUI 커서값과 다르다. 이를 동일 정밀도 원본의 완전 일치로 기록하지 않았다.

KiCad **10.0.5** [SIMULATOR_CONTROL::ExportPlotAsCSV](https://github.com/KiCad/kicad-source-mirror/blob/10.0.5/eeschema/tools/simulator_control.cpp#L288)는 시간/전압 모두 `%g` 기본 유효숫자6자리로 출력한다. 약10ms에서 시간 반올림 폭은 최대약50ns이고, τ4.7µs의 급한 변화에서는 전압 대조에 영향을 준다. VCTRL의 저장 전압과 알려진 PWL 기울기도 약50ns 차이를 설명한다.

진단용으로 CSV 시각에50ns를 더해 보간하면872.4685mV/23.84091mV가 되어 보고한 커서값과 출력 자릿수 범위에서 맞는다. 내부 원래 시각 전체는 확보하지 않았으므로 이 진단을 원본 복원으로 부르거나 CSV를 일괄 수정하지 않는다. GUI 관측값은 별도 전사로 보존한다. 이번 목적에 필요한 두 관측점은 확보했으므로 이 출력 형식 확인 때문에 완료한 실습을 반복하지 않는다.
