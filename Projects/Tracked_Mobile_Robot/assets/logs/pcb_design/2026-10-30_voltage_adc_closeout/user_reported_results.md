# 사용자 결과 전사와 화면 관찰

출처: 이번 대화의 사용자 메시지/화면. 아래는 필요한 필드를 전사한 기록이며 원본 내보내기 파일이 아니다. 숫자 정밀도는 보고된 자릿수를 유지한다. 실제 보드 측정이 아닌 KiCad 실습 결과다.

## 공차와 보정 OP

| 대화의 실험 조건 | VRAIL | VDIV=VADC | R1/R2 전류 | 보충 |
| --- | ---: | ---: | ---: | --- |
| ±1% 출력 최대 조합 | 16V | 2.66433V | 561.266µA | R1/R2 각3.74243mW, R3 1.4954mW |
| ±1% 출력 최소 조합 | 16V | 2.57668V | 553.767µA | R1/R2 각3.7167mW, R3 1.42688mW |
| ±0.1% 출력 최소 조합 | 16V | 2.61583V | 557.117µA | R1/R2 각3.72827mW, R3 1.45732mW |
| ±1% 출력 최대 조합, 12.6V 독립 입력 | 12.6V | 2.09816V | 441.997µA | 사용자 보정 환산12.600V 보고 |

마지막 행의 독립 입력은 다른 전압을 대입한 확인이며 정식 다점 보정/독립 검증 전체가 아니다. I(R4)는 이상적인 무부하에서0 또는 수치상 극소값이다.

사용자 계산 보고: ±1% 낮은 출력의 명목 환산 오차 −0.265808327276502959…V. 0.1% 높은 출력의 반올림값 계산 +0.026751702127659574…V, 낮은 출력 계산 −0.026740212765957446…V. 낮은 출력의 이론값2.615829773009787843…V도 보고했다. 전체 정밀도 이론값과 중간 반올림 결과를 구분한다.

## TRAN 화면 관찰

1. VCTRL 고정3.3V baseline에서 VDDA는10ms/3.3V,10.930ms/2.370V로 내려가고 VADC는약2.371V 유지. 독립 전원 가정의 시각화다.
2. B1 연동 뒤 VCTRL·VADC가 약10.3ms에 하강. 표시 커서10.2939ms/3.00615V는 차단 직전이다. 커서 차이366.184µs는 감지 지연 측정이 아니다.
3. `.tran 100n 10.35m 10.28 100n`의 단위 누락으로TSTART 오류. `10.28m`로 수정한 뒤 화면10.280~10.350ms, 콘솔701행.
4. C2=100pF가 있는 마지막 화면:10.300ms 부근 VCTRL은 급격히0, VADC는2.371V 부근에서 지수형 하강, VDDA는3V 부근에서 계속 하강.
5. 최신 워크북에10.3047ms/10.32164ms 커서 시각은 저장되어 있다. 그 지점의 전압 수치/파형CSV는 미제공이다.

원본 성공 로그는 [user_discharge_tran_console.txt](user_discharge_tran_console.txt). 모델 초기값과 끝 시점 값을 혼동하지 않는다.
