## 40-2 후반 — 주파수 응답과 alias

[재현 코드](frequency_response_calculation.py)와 [계산 JSON](frequency_response_calculation.json)에 평균 진폭비/원시alias/출력alias를 기록했다. 코드 실행은 수학 모델 계산이며KiCad나 실제ADC를 실행하지 않는다. 저자 공개DSP Guide Chapter15 p280 Eq15-2를 참고했다.

가상9Hz/100mV 성분은2kHz/200개 평균과10Hz 출력에서1Hz/10.9296mV 피크가 된다.19,001Hz 잔류 성분의 평균 진폭비는100Hz/10에서98.38%,1kHz/100에서98.36%,2kHz/200에서0.1545%다.38,001Hz는2kHz에서도1Hz로 접혀98.36%가 남는다. 수식과 직접 복소합 최대차이 약4.1e-14, 가상 블록 출력1Hz 성분 대조 일치. 원시 성분 크기·아날로그RC 감쇠·실제PWM/클록 조건은 별도다.
