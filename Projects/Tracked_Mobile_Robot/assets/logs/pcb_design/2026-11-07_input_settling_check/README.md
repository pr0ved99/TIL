## 계산과 사용자 관측

정상 DC 계산에서 하단 등가 저항은 `4.7k || (1k + 2 + 47k) = 4280.850822Ω`, VDIV=2.421907798V, VADC 최종값=2.371352579V, K=6.747204165다. 47kΩ 부하를 포함한다.

C1 중심 1차 근사에서 `Req=24k || 4.7k || 48.002k=3632.861697Ω`, τ=0.363286170ms다. 1τ의 VADC 약 1.498981V는 계산 예상값이며 이 시점의 사용자 커서 관측은 아직 받지 않았다. 실제 모델에는 C2와 1µs 입력 상승 시간이 포함된다.

실습 기준인 입력 환산 잔차 10mV는 ADC 쪽 1.482095362mV다. 상승 판정 전압은 2.369870484V이며 이상 계단의 1차 근사 시간은 `τ ln(16/0.010)=2.680237775ms`다.

| 구분 | 그래프 시각 | 입력 변화 시작 후 시간 | 화면의 VADC | 입력 환산 잔차 |
| --- | --- | --- | --- | --- |
| 커서 1 | 3.680000ms | 2.680000ms | 2.36985654V | 약 10.094mV |
| 커서 2 | 3.690000ms | 2.690000ms | 약 2.36990V | 약 9.8mV |

커서 2 전압은 화면에서 반올림되어 있으므로 9.8mV도 근사로 기록한다. 화면의 두 커서 차이는 10µs/40.5808µV다. 커서 차동값으로 두 번째 전압을 역산한 수치를 직접 관측한 더 정밀한 전압처럼 쓰지 않는다.

입력 변화 시작 1.000ms를 기준으로, 잔차가 10mV 이하가 되는 시간은 관측한 상승 파형에서 2.680~2.690ms 사이로 좁혔다. 이는 모델의 정착 성분 확인이며 펌웨어 대기 시간 확정, 실제 ADC 전체 정확도나 보호 성능 PASS가 아니다.
