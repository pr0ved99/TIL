# 11/3 학습 마감과 11/4 문서·파일 관리 점검

11/3 필기30~35 회차를11/4 사용자 요청으로 재점검·마감했다. 전압 보호 설계 전체는 진행 중이며 실제 보드/회로/정확도 시험은 수행하지 않았다.

## 점검 결과와 조치

- 최초 목록: 파일13,495개,2,140,840,328bytes(약1.99GiB). 프로젝트 내부 모든 하위 폴더 파일을 목록/크기 기준으로 조사했다. 이는 모든 파일 내용/바이너리 기능의 검증이 아니다.
- 생성/벤더 폴더를 제외한 Markdown445개에서 상대 링크4,135개를 검사했다. 누락3개는 모두10/12 코드 안내 보관본이다. 보관본은 보존하고 [현재 탐색표](../../../../docs/handoff/PROJECT_FILE_MANAGEMENT_ko.md)에 대체 경로를 연결했다.
- build 등 재생성 폴더를 제외한1MiB 이상 파일에서 SHA256 동일 중복 그룹은0개였다. 작은 snapshot/의도적 복제, 영상 내용 유사성까지 판정한 것은 아니다.
- 기존 Git 추적2,708개 중 build/Debug/Release 경로344개를 확인했다. 기존 dirty 산출물과 과거 실행 근거는 보존하며 새 산출물 유입은 프로젝트 ignore로 제한했다.
- 같은 내용의 이름 불명확 KiCad wrapper2개를 확인했다. 사용자 기존 작업으로 보존하고 재개 파일로 사용하지 않는다.
- 대표 README·PROJECT_MEMORY·학습/전장/쉴드/계획/인수인계 색인과 다음 프롬프트의10/31 재개점을 필기30~35 마감/다음36절로 갱신했다. 과거 결과·원본은 이력으로 유지한다.
- 노션의 이전 `CT-open nominal50µs` 오류는 이번 정리의 교정 대상이다. 올바른 값은 TPS Rev.E p7 tD의 **MAX50µs,MIN/TYP공란**이며 각주/시험 조건을 유지한다.

## 현재 결정과 다음

TPS3840PL30–TMUX1511은 후속 계산의 기준 후보다. MR/CT우선개방·RESET→SEL1/2·공통AVDD(CN10-7)·각IC100nF 초안과 시작/하강/OFF/복귀의 미결을 정리했다. 실제 보드 조건/보호 성능·제작 승인은 계속 미완료다.

다음36절에서0~16V DC·보정 후±0.10V·주위20~30°C·결과10Hz 제안을 기준으로 전체 오차 예산을 작성한다. 기존 RC/공차/두 점 보정 실습을 반복하지 않는다. 최종 게시 결과는 publication.json과 [마감](../../../../docs/progress/2026-11-04_progress.md)을 따른다.
