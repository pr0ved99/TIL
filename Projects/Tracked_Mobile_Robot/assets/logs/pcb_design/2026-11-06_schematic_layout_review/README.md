# 회로도 전체 기능별 재배치 — 2026-11-06

**최신 도면 안내 · 2026-11-07:** 이 폴더는 당시 배치 스냅샷으로 보존한다. 현재 회로도와 ERC·부품 표기 최신화 결과는 [11/7 CAD 마감](../2026-11-07_cad_closeout/README.md)을 따른다.

사용자가 U1/U2 배치 후, 기존 빈 공간에 끼워 넣는 대신 전체 회로도를 정돈하도록 **이번 재배치를 Codex에 명시적으로 위임**했다. 사용자에게 저장·편집기 종료를 요청했고 `저장하고 닫았어` 응답 후 원본을 반영했다. 이후 회로 추가는 기존 사용자 직접 편집 흐름으로 이어간다.

A3 한 장을 다음 여섯 영역으로 나누고 **24개 부품 모두**를 기능별로 이동했다. 연결된 회로는 와이어·라벨·접합점·미연결 표시를 함께 이동했다.

| 위치 | 영역 | 내용 |
| --- | --- | --- |
| 상단 왼쪽 | 01 Nucleo 인터페이스 | J1/CN7, J2/CN10, 기존 라벨·X·메모 |
| 상단 가운데 | 02 전류 입력 | 왼쪽·오른쪽 채널의 커넥터/RC 정렬 |
| 상단 오른쪽 | 03 NTC 입력 | 왼쪽·오른쪽 분압/필터 정렬 |
| 중단 왼쪽 | 04 전압 입력 | 배터리측·모터 공급측을 위한 별도 공간. 추가 예정 참조번호는 설명 텍스트 |
| 중단 오른쪽 | 05 전압 감시기/스위치 | U1 TPS3840, U2 TMUX1511 및 기존 검토 메모 |
| 하단 왼쪽 | 06 테스트 포인트 | TP1~TP6를 같은 높이·일정한 간격으로 정렬 |

참조/값과 net 라벨 글자 크기는 1.27mm로 맞추고 커넥터 제목과 신호 라벨 간격을 확보했다. U1/U2 필드는 각 몸체 위에 배치했다. 제목·구획선·전압 회로용 안내 문구를 추가했으며 기존 전기/기구 메모 내용은 보존했다. PCB 배치·라우팅 변경이 아니다.

## 검증과 적용 경계

KiCad CLI 10.0.5로 변경 전, 후보, 실제 적용 원본에서 각각 netlist를 추출했다. net 번호나 단순 부품 수만 비교하지 않고 **net 이름별 ref/pin/pinfunction/pintype 목록**과 부품 ref/value/footprint/datasheet/libsource/UUID를 대조했다.

| 항목 | 결과 |
| --- | --- |
| 부품 | 24개 동일; U1/U2의 올바른 library ID·참조번호 확인 |
| 활성 net | 10개 동일 |
| 미연결 포함 전체 net | 99개 모두 동일 |
| 와이어 / 접합점 / 라벨 / X | 48 / 6 / 36 / 70개 유지 |
| 내장 심벌 정의·부품 UUID·인스턴스 경로 | 동일 |
| 보호 파일 | PCB·프로젝트 설정·프로젝트 심벌·라이브러리 표 4개와 무관한 기존 변경 19개, 총23개 SHA256 동일 |
| 원본 반영 | 원본의 적용 후 SHA256과 검증한 후보가 일치 |
| 시각 검토 | 전체 PDF와 하단 확대 이미지로 글자·구획선·도곽 간격 확인 |

이번은 **회로도 그래픽 재배치와 연결 보존 검증**이다. 새 ERC/DRC, MCU 빌드/플래시, 실물 시험은 수행하지 않았다. U1/U2는 배치만 되어 있고 19핀 모두 미배선이다. J1-32/34와 J2-7의 기존 X도 유지했다. 전압 분압·TPS/TMUX 제어 배선 및 정확도/보호 검증의 완료를 뜻하지 않는다.

## 근거 파일

- `before_items.json`: 변경 전 부품·라벨·메모의 위치/값.
- `before_netlist.xml`, `after_netlist.xml`, `applied_netlist.xml`: 변경 전/후보/실제 원본의 연결 대조 자료.
- `rearrange_schematic.py`: `before.kicad_sch`에서 후보를 만든 스크립트. 원본 쓰기는 별도 단계였으며 해시로 재배치 전 원본과 보호 파일을 확인한 뒤 적용했다. 이 스크립트는 당시 원본 해시를 요구하므로 현재 편집본에 무조건 재실행하는 용도가 아니다.
- `candidate/TMR_Monitor_Shield_RevA.kicad_sch`: 시각·netlist 검증 후 적용한 후보.
- `after.pdf/png`: 후보 출력. `applied.pdf/png`는 실제 원본에서 다시 추출했다.
- `footer_detail.png`: 최종 후보의 도곽·테스트 포인트·검토 메모 간격 확인.

다음 사용자 작업은 **04 영역의 배터리측 J7/R7~R11/C5 배치**, 이후 전단 연결→후단·공통→연결 대조/ERC다. 앞으로 전체 도면을 먼저 보고 기능별 공간과 정렬을 유지한다.
