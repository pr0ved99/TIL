# 40장 이전 실습 상태 점검

**후속 보완:** 사용자14장 정량 실습과 파일 저장을 완료해 [두 커서 관측·검증 기록](../2026-11-07_discharge_check/README.md)에 연결했다. 아래14장 미확보는 이 감사 당시 상태다. 다음은37-2 정상 ON 입력 정착 실습 준비다.

2026-11-07. 사용자 요청: “40챕터 이전에서는 실습 진행할 것들 있는지 확인해봐”. 학습21의1~39절, 실제 저장 모델/워크북, 사용자 실행 보고와 진행 기록을 대조했다. 이번은 기록 점검이며 새 시뮬레이션이나 실물 시험을 수행하지 않았다.

## 결론

**기존 기록에 명시적으로 남은 정량 확인은14장의 방전 커서 전압 두 값이다. 다음 새 GUI 실습으로는37-2의 정상 ON 입력 정착 비교를 권고한다.** 30~39절은 원래 모든 설명 뒤에 SPICE 실행을 의무화한 계획이 아니므로, 사용자 실행 기록이 없는 항목을 모두 누락된 필수 과제로 바꾸지 않는다.

36·38장의 온도/보정 오차 전달은 계산 실습으로 보충할 수 있다.37-3의 내부 취득 모델과34~35의 전원 상태별 해석은 모델의 목적/적용 조건을 정한 뒤 선택한다.37-4의 평균·잡음은40-2와 한 실습으로 연결한다.39절의 회로도 인계/ERC는 이후11/6 작업·11/7 마감에서 완료했다.

## 바로 보충할 실습의 범위

### A. 14장 — 방전의 두 정량 지점

03_09의 기존 학습 모델을 기준으로 OFF 직전/최종값과 두 커서 전압을 기록해 지수 응답과 비교한다. 당시 설명값은 τ=4.7µs, 변화량99% 방전 약21.64µs이며 C2=100pF 가정이다. 유한 Roff 때문에 최종 전압이 정확히0은 아니므로 변화량 기준으로 비교한다. 전체 ON/OFF·공차 실습을 다시 할 필요는 없다.

이번 저장본 점검에서 공통 워크북은 **03_11 빠른 하강용 `.tran 100n 10.1m 9.99m 100n`**이다. 이것을03_09 방전 기록의 분석 구간으로 그대로 사용하지 않는다. 실제 실행을 시작할 때 해당 회로/분석 설정을 복사본 또는 별도 워크북에 준비하고 기존 결과를 보존한다. 현재 폴더의 CSV/PNG는 기본 AC 결과뿐이며 방전 파형으로 취급하지 않는다.

### B. 37-2 — 정상 ON에서 입력 계단과 허용 잔차

전원과 스위치는 정상 ON으로 유지하고 측정 입력만 바꾸는 새 비교다.14장의 **OFF 뒤100pF 방전**과 달리 **ON 상태100nF 필터의 입력 정착**을 확인한다. 기존 회로의 복사본에서0→16V 가상 계단,100nF·47k 부하와 가정100pF를 명시하고 VADC 최종값 대비 잔차를 입력 기준으로 환산한다.

기존37-2 계산은 입력 환산10mV 잔차에 약2.680ms(1차)/2.683ms(가정100pF 포함)다. 이10mV는 설명용 배분이다. 입력 에지/시간 간격/정착 기준을 갖춘 모델에서 비교하며 실제16V 인가나 펌웨어 보장 대기시간 결정으로 확대하지 않는다. 추가 AC 비교는 같은 부하 모델의 약438Hz와 기존 무부하 약405Hz 차이를 확인할 때 함께 할 수 있으나 별도 필수 과제로 늘리지 않는다.

### C. 36·38 — 선택 가능한 수치 실습

가상 입력/기준 오차를 이용해 두 보정점으로 계수를 구한 뒤 독립점 잔차를 표시하고, 기준 오차·온도 변화·계수 반올림을 하나씩 바꾸어 비교한다. 스프레드시트나 수치 도구가 적합한 학습 과제이며 SPICE 회로를 다시 그릴 필요는 없다. 기존 설명을 다시 필기하는 대신 사용자가 값을 바꾸고 결과를 해석하는 방식이다. 실제 기준 계기 확보나 칩 보정 완료로 기록하지 않는다.

## 다음 진행 권고
