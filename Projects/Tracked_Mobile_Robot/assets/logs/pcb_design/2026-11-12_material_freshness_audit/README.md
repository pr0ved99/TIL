# 프로젝트 자료 최신성 점검 — 2026-11-12

**결론: 기본 PDF 외에도 현재 안내·부품/계측기 상태·검사 보고서·포트폴리오 설명에 최신화 누락이 있었다.** 상단에 새 재개점만 추가하거나 검토 로그에만 새 파일을 저장하고, 기본 열람 경로와 본문의 현재 상태표를 함께 갱신하지 않은 것이 원인이다. 이번 점검에서 아래 누락을 실제 기록/저장 원본과 대조해 수정했다.

## 점검 범위와 기준

- Git 추적/미추적 목록에서 빌드 캐시·의존성 출력 등을 제외한 프로젝트 자료 **2,602개**를 목록화했다. 이 중 **Markdown482개와 PDF59개**가 있다. [시작 시점 목록](inventory.json).
- Markdown482개의 상대 파일 링크를 검사했다. 현재 상태를 안내하는 README·메모리·인수인계·실행 계획·부품 대장·검증/포트폴리오 문서, CAD 파생 자료와 연결된 시험 근거를 내용 대조했다. 전체 과거 문장·모든 외부 URL·데이터시트 수치까지 새로 검증한 감사는 아니다.
- 최신 사실의 기준: 10/17~24 조립/주행/거리/시연 기록, 11/4 수령 보고, 11/5 제한 외부 계측/전원 분리, 11/7 검토 CAD, 11/12 학습/포트 목록과 실제 저장 원본이다.
- 날짜가 있는 원시 관측·코드 입력 안내·제작/검토 스냅샷은 당시 증거로 유지했다. 과거 결과에 새 PASS를 소급 적용하지 않았다. 영문 아키텍처는 이미 표시된 대로 한국어 정본의 보조 자료이며 전면 번역 동기화 대상으로 바꾸지 않았다.
