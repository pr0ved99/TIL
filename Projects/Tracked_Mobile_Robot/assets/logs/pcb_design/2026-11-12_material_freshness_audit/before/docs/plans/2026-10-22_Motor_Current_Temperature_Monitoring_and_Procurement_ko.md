# 모터 전류·온도 모니터링과 계측 장비 구매 마감

기준일: **2026-10-22**. [구매 완료 보고와 판단 근거](../progress/2026-10-22_progress.md), [부품/장비 대장](../../00_Project_Charter/02_Component_Inventory.md).

## 현재 확정 범위

사용자가 온도센서 2개·전류센서 2개·GM-1312·UT210E 구매 완료를 보고했다. 후속 답변으로 구매 센서 모델은 **SEMITEC `103JT-025`**, **Pololu `#5241 / ACS71240KEXBLT-030B3` ±30A·3.3V**로 확인됐다. 이어 **아직 모두 배송 대기**라고 확인했다. 실물 구성·결제액·납기는 미확인이다. 아래는 확인한 모델을 사용한 설계 초안이며 현재 배선·CubeMX 설정은 아니다.

모터별 전류와 케이스 온도 각 2채널을 우선한다. GM-1312와 UT210E로 한정된 운전 조건을 관측하고, 후속 센서 ADC 로그를 비교한다. 배터리 셀별 측정, 보드별 전류 상시 채널, 추가 ADC, PSU·탑재 컴퓨터는 이번 최소 구매 범위에 넣지 않는다. 향후 PCB에는 신호 수집/보호·커넥터·시험점을 검토하되 실제 전류·부품 정격·배선과 센서 모델이 확정되기 전 전력 경로를 설계 완료로 표시하지 않는다.

클램프는 개별 모터의 한 도선만 감싸는 방법을 계획한다. MDD10A 공통 입력 전류와 모터 전류를 혼용하지 않는다. DC 표시와 순간 피크/고주파 RMS, 표면 온도와 내부 권선/접합 온도는 관측 범위를 나눠 기록한다. 외부 측정기 비교는 기본 교차 확인이며 교정 인증을 대체하지 않는다.

## 모델 확인 후 연결 초안

**별도 확장 기판 구성:** [4채널 연결안](../../09_Electrical_Design/14_Motor_Monitoring_Expansion_Interface_2026-10-22_ko.md)에 STM 인출·기능별 커넥터·전류12kΩ/100nF 후보와 부속 예산을 정리했다. 기존 만능기판 추가 실장 여유는 확보되지 않았다. 현재 기판을 보존하고 신호 회로만 별도 확장하며 주전류 센서 경로는 별도다. 전류 필터는 계산 후보이며 출력 안정성·보호/누설·수집 주기를 확정한 제작 회로가 아니다.

### 전류 2채널

각 모터의 한 도선에 #5241의 **IP+ → IP− 전류 경로를 직렬 삽입**하는 구조다. 왼쪽 센서는 MDD10A 왼쪽 모터 출력 한쪽과 왼쪽 모터 단자 사이, 오른쪽도 대응 위치에 둔다. 모터의 반대 도선은 해당 드라이버의 다른 출력으로 연결되는 기존 경로를 따른다. 모터 출력선을 신호 GND로 연결하는 구성이 아니다. IP+/IP−의 물리 방향과 전진/후진 전류 부호는 실제 배선에서 대조한다.

신호 측은 센서 VCC=3.3V, GND=STM 신호 기준 GND, VIOUT=검토한 입력 필터/보호를 거쳐 ADC다. 모듈 밑면의 `3V3 B30` 표시와 실물 단자 라벨을 수령 후 확인한다. 주전류 연결은 적합한 전력 배선·고정/절연을 사용하고 2.54mm 신호 점퍼/만능기판 신호 패턴으로 통과시키지 않는다.

명목 전원3.0~3.6V, 영점1.65V, 감도44mV/A다. 출력은 **비례전원형(ratiometric)이 아니므로** 영점을 VCC/2로 자동 보정하지 않는다. 채널별 실측 영점을 저장하고 `I_A=(VOUT−VZERO)/0.044`를 초기 식으로 사용한다. ±30A 명목 출력은0.33~2.97V다. 이상적3.3V/12bit 양자화는 약18.3mA/count이며 센서/ADC·기준 전압·잡음까지 포함한 정확도가 아니다. [Pololu #5241](https://www.pololu.com/product/5241).

**필터는12kΩ 직렬 뒤100nF를 두는 계산 후보를 마련했으며 제작값은 미확정이다.** 센서 출력의 직접 용량 부하는 제조사 최대4.7nF 조건이므로 큰 커패시터를 VIOUT에 곧바로 붙이지 않는다. PWM 약19kHz 환경에서 평균 전류 관측용 대역폭·직렬 저항/출력 안정성·ADC sample time·샘플링/에일리어싱을 함께 검토한다. 센서 두 개의 IC 소비 전류 최대 조건은 합계24mA(각12mA)이며 기존3.3V 부하와 함께 전원 여유를 확인한다. [Allegro 전기 사양](https://www.allegromicro.com/-/media/files/datasheets/acs71240-datasheet.pdf).

모듈 FAULT의 명목 임계값±30A는 모터의 정격1.44A/스톨9A를 보호하는 설정이 아니다. 기존 PC7 E-stop 감지선과 합치지 않으며 초기 모니터링 연결에서는 미사용 후보로 둔다. 필터된 평균값/UT210E DC 표시만으로 PWM RMS·기동 피크·스톨 허용을 판정하지 않는다.

### 온도 2채널

**후속 계산 완료:** [온도 입력 설계](2026-10-22_NTC_Temperature_Input_Design_ko.md)에 채널별10kΩ±0.1% 분압·1kΩ 직렬·100nF 필터, ADC14MHz/480cycles 후보와 표 기반 환산/오류 판정을 구체화했다. 아래 개요의 초기 후보를 발전시킨 계산안이며 실물/최종 PCB 승인이나 ADC 구현 완료가 아니다. 전류 입력 필터는 여전히 별도 검토 대상이다.

103JT-025는 극성이 없는 2선 NTC이며 25°C에서10kΩ±1%, B25/85=3435K±1%다. 각 모터 케이스에 대응하는 위치로 부착하고 센서 헤드·리드의 기구적 응력과 절연/접촉 오차를 관리한다. [SEMITEC 제품 자료](https://www.semitec-global.com/uploads/2022/01/P9-JT-Thermistor.pdf).

```text
STM 아날로그 기준과 함께 검토한 3.3V
  └─ 기준 저항10kΩ(초기 후보) ─ 측정 노드 ─ 103JT-025 ─ 신호 GND
                                  └─ ADC 입력/필터 후보
```

이 방향에서는 온도가 오르면 ADC 전압이 낮아진다. 명목25°C=1.65V, 제조사 R-T 표의50°C≈0.967V·80°C≈0.472V(3.3V,10kΩ 이상 계산)다. `R_NTC=R_FIXED×V/(V_EXC−V)`로 저항을 구한 뒤 제조사 R-T 표를 우선 활용한다. B 식은 근사로 구분한다. 단선/단락·포화·유효성도 온도 값과 함께 처리할 설계다.

10kΩ/3.3V 후보의 NTC 소비 전력은 저항이 일치할 때 최대 약0.272mW다. 제조사 정지 공기 중 방열계수0.7mW/°C를 그대로 적용한 자가발열 추정은 약0.39°C이며, 모터 케이스에 붙인 실제 오차를 보증하지 않는다. GM-1312와 대응 위치의 평형 관측을 비교하고 부착 차이를 구분한다. 기준 저항2개·입력 부속은 보유 수량/허용오차를 확인한 뒤 부족분만 정한다.

현재 `.ioc`·GPIO 초기화에는 PC0~PC3 배정과 ADC 초기화가 없다. 기존 [핀 배정](../../01_System_Architecture/06_MCU_Pin_Allocation_Candidate_ko.md)의 추가 후보6개 중4개를 쓰는 초안이다. PA6/PA7과 기존 전압 예약 PA4/PB0·IMU PB1/PC4 등을 보존한다. PC0/PC1의 Arduino A5/A4 경로는 solder bridge에 따라 I2C 경로와 달라질 수 있으므로 실제 보드·만능기판 접근을 먼저 확인한다. [STM32F446 데이터시트](https://www.st.com/resource/en/datasheet/stm32f446re.pdf).

입력 회로·보호/전원 순서와 실제 부속을 확정한 뒤 ADC 스캔/DMA·샘플링·유효성/보정·UART/TEL 확장을 설계한다. 현재 펌웨어/TEL을 수정하거나 측정 채널이 구현됐다고 기록하지 않는다. 실제 시험 중단 온도/전류 기준과 부하 프로파일도 아직 확정하지 않았다.

## 다음 세션

현재 네 품목 모두 배송 대기다. 로컬 source/빌드·증거 대조는 이미 완료했으며 이를 반복하지 않는다. 오늘은 기록·연결 설계를 준비한다. 외부 전류에는 [세션 양식](templates/current_observation_session_template_ko.md)과 [CSV 헤더](templates/current_readings_template.csv), 온도에는 기존 [세션 양식](templates/temperature_session_template_ko.md)과 [CSV](templates/temperature_readings_template.csv)를 쓴다. 기록값이 없는 템플릿이며 시험 결과가 아니다.

수령 후 첫 작업은 실제 장비/프로브·센서 구성 확인이다. 배선·통전·구동·빌드/플래시는 사용자 수행이고, 센서 연속 모니터링을 완료해야 기존 외부 계측을 할 수 있는 것은 아니다. 수치 중단 기준·설치/감시 방법을 확정한 뒤 한정된 관측, 기존 온도/정지 등 선행 조건 충족 후 지상1m로 진행한다. 오늘 추가 물리 시험은 없다.
