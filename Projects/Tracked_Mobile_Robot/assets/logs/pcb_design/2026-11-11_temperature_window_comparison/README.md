25↔50°C 상당저항(10kΩ/4147Ω)을이상적으로전환한다. 고정10kΩ·직렬1kΩ·100nF, VEXC=VREF=3.3V를가정한다. 전압은전환후최종테브난저항의RC로정착한다. 이상ADC q를먼저평균하고저항으로환산한뒤기존log(R)보간표로온도를구한다. 실제양자화/ADC오차·잡음·공차·기준변화·연산/출력지터·스위치바운스·NTC열응답은제외했다.
