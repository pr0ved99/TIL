## 원본과 해석

카메라 `mvp_cam_long_01.mp4` 약144.03초, 화면 `mvp_long_01.mp4` 약145.77초는 Desktop 원본을 변경하지 않았다. [해시·추출 기록](manifest.json), [화면/물리 관측과 사용자 설명](observations.json), [초기 탁상 편집](../2026-10-24_demo_run01/README.md)을 보존한다.

새 영상은 공통 시계나 공통 화면이 없어 **화면 시각=카메라 시각+0.5초**를 시연용 근사 정렬로 사용했다. 카메라104초 S0 손 조작/122초 STM 보드 조작과 화면104초 ARMED→108초 FAULT,122.4초 DISARMED 표본을 참고한 값이다. 동기 오차를 계측한 값이 아니며 이전 탁상 영상의 공통 버튼 전이12개 정렬값과 구분한다. 화면 오디오는 디코딩 시 사실상 무음이어서 음성 동기화에 사용하지 않았다.

S0 해제와 S2 뒤에도 ESTOP_LATCHED·ARM 비활성이 유지되고 STM 리셋 뒤 DISARMED/BOOT·ARM 재허용, 새 ARM 뒤 재주행하는 장면을 보여준다. FAULT 중 READY/IDLE도 유지되므로 READY만으로 운전 허가를 설명하지 않는다. 영상의 S2→리셋 순서는 사용자 시연 기록이며 [표준 운용 절차](../../../../docs/handoff/CURRENT_MVP_OPERATION_RUNBOOK_ko.md)를 변경하지 않는다.

100×150cm와1m 이상 이동은 사용자 보고다. 이 영상으로 거리 정밀도·자동1m 정지·물리 정지 지연이나 전체 MVP 수용을 새로 판정하지 않는다. 원시 TEL JSON이 없고 리셋 전후 count는 합산하지 않는다. 최종 전원 분리/셀 전압은 미보고다.
