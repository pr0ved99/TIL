## 외부 입력이 개방된 상태의 첫 수신

**시험 조건.** 사용자가 수신 당시 외부 입력 배선을 모두 제거했다고 확인했다. PA4(A2)의 분압기도 분리된 상태였다. VREFINT는 MCU 내부 채널이다.

**수신 결과.** 첫 30블록 모두 7개 평균값과 `valid=1`을 포함한다. `seq`는 1부터 30까지 연속이며 보드 시각은 100 ms부터 3000 ms까지 매번 100 ms씩 증가했다. [UART 원본](first_blocks_wemd2ds1.log)

**해석.** PA4 평균 1015.44카운트는 외부에서 전압을 정해 주지 않은 입력의 ADC 결과다. 이 로그로 확인한 범위는 7개 필드 수신과 블록 주기까지다. PA4 영점과 분압 응답은 기준 입력을 연결한 별도 시험에서 확인한다.

## PA4 풀다운 연결 후

사용자는 보드 전원이 연결된 상태에서 저항을 연결했으며 사용한 저항은 12 kΩ이라고 보고했다. 시험 배선은 A2(PA4)와 NUCLEO GND 사이의 풀다운이고 3V3 쪽은 개방하는 조건이다. 재연결 때 읽은 로그는 이전 블록과 새 블록 사이에 순번 공백이 있어 평균에서 제외했다. [UART 재연결 구간](uart_reopen_mixed_seq32_3455.log)

이후 수신한 연속 30블록(seq 3678~3707)에서 보드 시각 간격은 매번 100 ms였다. PA4의 블록 평균은 2.15~3.04카운트, 전체 평균은 2.57카운트였다. VREFINT를 이용한 전압 환산은 약 2.08 mV다. [연속 30블록 원본](pa4_after_wiring_seq3678_3707.log)

같은 배선에서 사용자가 보고한 멀티미터 직류 전압은 **0.3 mV**였다(빨간 프로브 A2 쪽, 검정 프로브 GND 쪽). PA4가 0 V 근처로 내려가는 응답을 확인했다. ADC의 30블록 환산 평균은 멀티미터 표시보다 약 1.78 mV 높았다. 두 측정의 시각을 동기화하지 않았으므로 이 차이로 ADC 보정값을 정할 수는 없다.

## PA4 분압 입력

사용자가 `NUCLEO 3V3 → 9.95 kΩ → A2(PA4) → 12 kΩ → NUCLEO GND` 배선 후 두 USB를 연결하고 디버거에서 실행했다. ST-LINK 가상 시리얼 포트에서 받은 seq 636~665는 모두 7개 필드를 포함하며, 30블록의 보드 시각은 63,600~66,500 ms로 매번 100 ms 증가했다. PA4 평균은 2223.90카운트(블록별 2223.16~2224.62), VREFINT 평균은 1500.30카운트였다. [분압 입력 30블록 원본](pa4_divider_seq636_665.log)

같은 배선에서 사용자가 측정한 A2–GND 직류 전압은 **1.797 V**였다. VREFINT로 보정한 30블록 평균은 **1.80135 V**로 멀티미터 표시보다 **4.35 mV** 높았다. 7채널 스캔의 첫 번째 슬롯(PA4)이 풀다운과 약 1.8 V의 분압 입력을 구분하는 것을 확인했다.

## 분압 신호를 A3(PB0)로 옮긴 뒤

사용자가 같은 분압기의 신호 점퍼를 A2에서 A3로 옮기고 펌웨어를 실행했다. 새로 수신한 30블록(seq 473~502)은 모두 7개 필드를 포함했고 블록 간격은 보드 시각 기준 100 ms였다. 앞선 A2 시험에서 PA4 평균이 2223.90카운트였고, 이번 A3 시험에서는 PB0 평균이 2223.93카운트(2223.54~2224.31), VREFINT 보정 평균이 1.80133 V였다. 같은 분압 입력이 세 번째 슬롯(PB0)으로 옮겨간 것을 확인했다. 점퍼를 뺀 PA4의 평균 1206.12카운트는 외부 입력이 개방된 상태에서 나온 값이다. [PB0 분압 입력 30블록 원본](pb0_divider_seq473_502.log)

같은 배선에서 사용자가 측정한 A3–GND 직류 전압은 **1.797 V**였다. PB0의 30블록 환산 평균이 멀티미터 표시보다 **4.33 mV** 높았다.

## 분압 신호를 A5(PC0)로 옮긴 뒤

A5 시험부터 사용자가 ESP32를 만능기판에서 분리하고 NUCLEO의 ST-LINK USB만 연결했다. 이후 이 ADC 벤치는 같은 구성으로 진행한다. 호스트에서도 ST-LINK만 인식됐고, USART2 벤치 출력을 ST-LINK 가상 시리얼 포트에서 직접 수신했다.

같은 분압 신호를 A3에서 A5로 옮긴 뒤 연속 30블록(seq 611~640)에 7개 필드가 모두 들어왔다. 블록 간격은 보드 시각 기준 100 ms였다. 네 번째 슬롯인 PC0 평균은 **2223.82카운트**(블록별 2223.12~2224.65), VREFINT 보정 평균은 **1.80160 V**였다. 같은 배선의 A5–GND 직류 전압은 사용자 실측 **1.797 V**로, ADC 환산 평균이 **4.60 mV** 높았다. A5에 가한 시험 전압에 대한 결과이며, 실제 왼쪽 모터 전류 센서 출력은 별도 시험 항목이다. [PC0 분압 입력 30블록 원본](pc0_divider_seq611_640.log)

## 분압 신호를 A4(PC1)로 옮긴 뒤

사용자가 A4로 신호 점퍼를 옮기고 같은 배선에서 A4–GND 직류 전압을 **1.797 V**로 측정했다. ST-LINK USB에서 수신한 연속 30블록(seq 525~554)은 보드 시각 기준 100 ms 간격이었다. 다섯 번째 슬롯 PC1의 블록 평균은 2223.17~2224.38카운트, 전체 평균은 **2223.83카운트**였다. VREFINT 보정 평균은 **1.80138 V**로 멀티미터보다 **4.38 mV** 높았다. A4에서 PC1까지의 저전압 입력을 확인했으며, 실제 오른쪽 모터 전류 센서 경로는 별도 시험 항목이다. [PC1 분압 입력 30블록 원본](pc1_divider_seq525_554.log)

## 분압 신호를 CN7-35(PC2)로 옮긴 뒤

사용자가 CN7-35와 GND 사이에서 측정한 직류 전압은 **1.797 V**였다. NUCLEO ST-LINK에서 받은 30블록(seq 655~684)은 다섯 번째 슬롯에 분압 신호를 넣은 직전 시험과 같은 100 ms 간격이었다. 이번에는 여섯 번째 슬롯 PC2 평균이 **2223.89카운트**(블록별 2223.57~2224.22)였고, VREFINT 보정 전압은 **1.80157 V**로 멀티미터보다 **4.57 mV** 높았다. 이번 측정 범위는 PC2 핀에 가한 분압 입력과 UART 필드의 대응이다. [PC2 분압 입력 30블록 원본](pc2_divider_seq655_684.log)

## 분압 신호를 CN7-37(PC3)로 옮긴 뒤

사용자가 PC3–GND에서 **1.797 V**를 측정했다. seq 456~485에서 일곱 번째 슬롯 PC3의 블록 평균은 2223.38~2224.26카운트였다. VREFINT 보정 평균은 **1.80138 V**였고, PC3와 해당 UART 필드의 대응을 확인했다. 실제 오른쪽 모터의 온도 센서 측정과 채널 간 영향 평가는 별도 시험 항목이다. [PC3 분압 입력 30블록 원본](pc3_divider_seq456_485.log)

## PC2를 GND에 연결하고 PC3의 분압을 유지한 시험

사용자가 GND 점퍼의 보드 쪽 위치를 CN7-35(PC2)로 확인했다. CN7-37(PC3)은 분압 중간점에 연결했다. 30블록(seq 1214~1243) 모두 100 ms 간격이었고, 같은 블록에서 PC2와 PC3가 각각 6·7번째 필드로 수신됐다. PC2 평균은 1.66카운트(보정 후 1.34 mV), PC3 평균은 2223.95카운트(보정 후 1.80149 V)였다. PC2가 개방돼 있던 직전 PC3 시험의 평균과 비교하면 PC3 차이는 +0.11 mV였다. 이전 조건의 PC2 전압은 정해져 있지 않았으며, 앞 채널의 두 입력 전압을 정해 비교하는 시험은 남아 있다. 같은 배선에서 사용자가 측정한 PC3–GND 직류 전압은 **1.797 V**로, PC3의 ADC 환산 평균이 **4.49 mV** 높았다. [두 채널 UART 원본](pc2_gnd_pc3_divider_seq1214_1243.log)

## 상태 A · 외부 입력 다섯 곳을 GND에 연결

PA4·PB0·PC0·PC1·PC2는 공통 GND, PC3는 분압 중간점에 연결했다. NUCLEO ST-LINK로 수신한 seq 453~482의 30블록에서 순번은 1씩, 보드 시각은 100 ms씩 증가했다. VREFINT 보정 후 GND에 연결한 핀의 30블록 평균은 PA4 2.23 mV, PB0 2.24 mV, PC0 2.19 mV, PC1 2.25 mV, PC2 2.03 mV였다. PC3는 1.80133 V였다. 상태 A에서 사용자가 측정한 분압 중간점–GND 직류 전압은 **1.797 V**였다. [상태 A 원본](pc2_step_state_a_seq453_482.log)

상태 B에서는 PC2만 GND에서 PC3가 연결된 분압 중간점으로 옮겼다. A와 B의 중간점–GND 멀티미터 표시는 모두 **1.797 V**였다. 각 상태의 30블록은 모두 유효했고 구간 내 보드 시각 간격은 100 ms였다. 아래 값은 각 블록의 VREFINT 보정 전압을 평균한 결과다. 변화량은 반올림 전 평균에서 계산했다. [상태 A 원본](pc2_step_state_a_seq453_482.log) · [상태 B 원본](pc2_step_state_b_seq111_140.log)
