# 외부 전류·온도 공중 관측 — 2026-11-05

## 결과와 현재 상태

사용자가 기존 로봇의 궤도를 띄운 상태에서 모터별 전진·후진을 짧게 수행하고 UT210E와 GM1312 표시를 보고했다. 마지막 후진의 이상 없음과 **전원 분리 완료**까지 확인했다. 이 회차는 종료했다.

이는 외부 계기의 제한된 표시 관측이다. 장시간 발열·정격 부하·센서/ADC 정확도·전체 MVP 인수를 완료한 결과는 아니다. 기존 **T005A PARTIAL / T007 BLOCKED**, 온도·전류의 후속 범위 분리는 유지한다. 정식 T-LOAD-001 열적 수용 판정은 미완료다.

## 원본 근거와 관측 조건

- 근거는 이 회차 대화의 사용자 수치·정정·사진·브라우저 화면이다. 아래 표와 `observations.json`, `observations.csv`는 그 보고를 전사한 것이다. 자동 계기 로그가 아니다.
- 대화 사진/화면의 별도 원본 파일 경로는 확보하지 못했다. 이 폴더에 사진·영상·원시 TEL을 저장한 것으로 주장하지 않는다. 정확한 수행 시각도 미보고다.
- 온도계: GM1312, T1=A 모터 / T2=B 모터. 사용자 확인 폴리이미드 테이프를 아래·위에 두고 열전대 접점을 고정했다. 최종 부착은 사용자가 진행 가능하다고 확인했으며 사진만으로 금속 직접 접촉·정격 절연·부착 오차를 검증하지 않았다.
- 전류계: UT210E, 안내 범위 20A DC, 표시 분해능 0.01A. 리드를 빼고 빈 집게 ZERO 후 **M1B 또는 M2B 한 도선**을 감쌌다. B+/B− 공통 공급 입력 전류와 구분한다. A/M1은 왼쪽, B/M2는 오른쪽의 기존 대응을 따른다.
- 두 궤도 공중, 안정 지지·리드 간섭 확인을 요청하고 사용자가 진행 가능하다고 응답했다. 기존 저출력 제어를 사용하며 각 방향 입력은 **최대 1초로 안내**했다. 실제 누름 시간/출력 파형은 계측하지 않았다. 1초는 이번 절차상 제한이며 제조사 허용 운전 시간 규격이 아니다.
- 기존 설정의 전진 PWM 좌/우144/150‰, 후진−140/−150‰는 절차의 설정 문맥이다. 이번 구동 중 원시 TEL/PWM 기록으로 재확인한 실측값이 아니다.
- 새 펌웨어 빌드/플래시, ACS71240·103JT-025 연결 또는 센서 ADC 구현은 수행하지 않았다.

## 네 번의 짧은 구동 관측

전류는 모두 **영점 잔류를 별도로 보정하지 않은 계기 표시값**이다. `≤1초`는 안내한 입력 상한이고 실제 시간을 측정했다는 뜻이 아니다.

| 순서 | 측정선 / 입력 | 전류 표시 | 온도 보고 | 동작·이상 보고 |
| --- | --- | --- | --- | --- |
| 1 | M1B / 전진 | −0.18A | 정지30초 후 T1 26.7°C / T2 26.7°C | 확인 요청에 “모두 응”: 양쪽 회전→해제 정지→DISARM/IDLE·PWM/CPS0, 이상 없음 |
| 2 | M1B / 후진 | +0.18A | T1 26.6→정지 후26.7°C; T2 별도 값 미보고 | 정지 보고. 이 동작만의 DISARM/나머지 확인 항목은 명시 응답 없음 |
| 3 | M2B / 전진 | +0.20A | 정지30초 후 **T1 26.9°C / T2 27.0°C** | 양쪽 회전→해제 정지→DISARM 정상, 간섭·이상·경고음 없음 |
| 4 | M2B / 후진 | −0.23A | 정지30초 후 T1 26.9°C / T2 27.0°C | 양쪽 회전→해제 정지→DISARM 정상; 마지막 빈 이상란은 “이상 없음”으로 보완 |

정정 적용:

- 첫 M1B 보고의 “전압 −00.18A”는 단위와 계측 맥락상 전류 표시−0.18A로 기록한다.
- M1B 후진의26.6→26.7°C는 이후 사용자가 **T1만 변화**했다고 명시했다. T2에 같은 값을 대입하지 않는다.
- M2B 전진의 최초 T1 27.0/T2 26.9는 다음 “온도 서로 바뀜” 정정으로 T1 26.9/T2 27.0을 채택했다. T1=A/T2=B 연결은 유지한다.
- M2B 후진 응답의 `−00.23 A / 미포착`은 숫자와 양식 잔여 문구가 함께 왔다. −0.23A를 보고값으로 보존하고 원문 잔여 문구를 JSON에 남긴다. 연속 포착·최댓값으로 확대하지 않는다.

## 해석과 미결

1. 같은 도선에서 전진/후진 부호가 반대로 나온 것은 전류 방향 변화와 일치한다. M1/M2 사이 집게 방향은 기록하지 않았으므로 채널 간 부호만으로 배선/진행 방향 오류를 판정하지 않는다.
2. 0.18/0.20/0.23A는 서로 다른 짧은 구간의 표시다. PWM 전류 피크·RMS·안정 평균이나 모터 불균형, 고장, 센서 보정 기준으로 사용할 수 없다. −0.01A 무구동 잔류도 그대로 남긴다.
3. 이번 약26.6~27.0°C 표시는 큰 표시 상승이 보고되지 않은 범위다. 주변 온도·부착 열저항·응답 지연·측정 시간·권선 온도·긴 운전의 발열을 입증하지 않는다. 표면 온도 적합 PASS로 바꾸지 않는다.
4. UT210E 설명서(P/N110401104880X, MAY2018 REV2) PDF1쪽 VIII.3.2 DC는 영점/단일선/방향 절차, PDF2쪽 IX.6 DCA는20A 범위10mA 분해능과±(2%+3digits) 행을 제시한다. 명시된 조건의 사양이며 이번 PWM 관측의 전체 정확도 보증으로 바로 적용하지 않는다. [보유 설명서](../../../datasheets/UNI-T_UT210E_User_Manual.pdf).
5. 향후 정식 열 관측을 재개하려면 구동 시간·출력·휴지·주위 온도·부착 위치/접촉·근거 있는 중단/판정 기준을 먼저 정한다. 기존 철회40/45°C·상승10/15°C 기준을 되살리지 않는다. 오늘은 추가 통전하지 않는다.
