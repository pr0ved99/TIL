## 이름과 원본 보존

- 기존 사진과 같은 `날짜_순번_대상_시점.jpg` 형식이다. 번호는 사진을 살펴보는 순서이며 촬영 시간순은 아니다.
- 날짜는 5장 모두 EXIF `DateTimeOriginal`의 **2026-10-02**를 확인해 사용했다. 원래 촬영 시각·해상도·파일명은 [원본 대응 및 SHA-256 기록](manifest.json)에 있다.
- 원래 이름은 `KakaoTalk_20261002_164230005.jpg`와 같은 접두부의 `_01.jpg`~`_04.jpg`였다. 원본 이름과 새 이름은 manifest의 각 항목에서 대응한다.
- 이동 전후 SHA-256이 5장 모두 일치했다. 재압축·크기 변경·이미지 편집 없이 원본을 보존했고, 바탕화면에 사진 복사본을 남기지 않았다.
