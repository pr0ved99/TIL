# 전류·온도 계측과 센서 설계 사양 빠른 참조

기준:2026-10-22에 보관한 로컬 원본. 평소에는 이 요약의 해당 절을 먼저 읽고, 조건 변경·수치 판정·회로 확정 때 연결된 원본 페이지를 확인한다. PDF 페이지는 뷰어 기준이며 GM1312는 한 PDF 페이지에 인쇄6면이 들어 있다. 이미지 자료는 시각 확인으로 전사했다.

제조사 명목/한계값, 프로젝트 계산 후보, 실제 측정값은 서로 다르다. 아래 값은 새 실측·교정·시험 합격 기준이 아니다. 모터의 케이스 허용 온도와 최종 시험 중단 온도/전류는 아직 미확정이다. [외부 온도 계획](../../docs/plans/2026-10-20_External_Temperature_Test_Plan_ko.md)의40/45°C 및+10/+15°C 후보는 직접 근거가 없어 철회했다. 실행/판정 기준으로 사용하지 않는다.

## 1. UT210E — 외부 모터 전류 관측

출처: [UT210E MAY2018 REV2](UNI-T_UT210E_User_Manual.pdf), PDF2쪽 `IX. Technical index / 6. DCA measurement`; 조작은 PDF1쪽 `VIII / 3. AC/DC current measurement`와 PDF2쪽 Figure6.

| DC 전류 범위 | 표시 분해능 | 정확도 표기 |
| --- | --- | --- |
| 2.000A | 1mA | ±(읽음값2% + 8digits) |
| 20.00A | 10mA | ±(읽음값2% + 3digits) |
| 100.0A | 100mA | ±(읽음값2% + 3digits) |

- 정확도 표의 환경 조건:23±5°C, 상대습도≤75%. `digits`는 선택 범위의 최하위 표시 단위 수다. 분해능1mA를 정확도±1mA로 해석하지 않는다.
- 계산 예:1.000A를2A 범위에서 읽으면 표기 오차는±(0.020+0.008)=±0.028A다. 실제 교정 결과나 PWM 환경을 포함한 전체 오차가 아니다.
- PDF1쪽 `V`:2000counts, 표시 갱신2~3회/초, 클램프 입구17mm, 전원AAA1.5V×2. 동작 환경0~40°C와 정확도 조건23±5°C를 구분한다.
- DC 모드를 선택하고 ZERO를 수행한다. 영점 조정 때와 측정 때의 계측기 방향을 가능한 한 유지하며, **모터 한 도선만** 클램프한다. 두 도선을 함께 넣은 값을 모터 전류로 쓰지 않는다.
- AUTO OFF15분; 취소는 SELECT를 누른 채 전원 켜기(PDF2쪽 `5. Other functions`). 실물 설명서/동작과 대조한다.
- 프로젝트 기록량은 DC 표시값·관측 표시 최댓값이다. HOLD/표시 갱신을 기동 순간 피크 검출로 해석하거나 약19kHz PWM의 정확한 RMS 측정으로 주장하지 않는다. 한 대로 나눈 좌우 회차는 동시 측정이 아니다.

## 2. GM1312 — 외부 접촉 온도 관측

출처: [GM1312-EN-01 기준 스캔](BENETECH_GM1312_User_Manual.pdf), PDF1쪽의 인쇄6면 `F. Specification`, 인쇄2~3면 `B. Warning & Cautions`, 인쇄5면 `E. Operation`. [다른 스캔본](BENETECH_GM1312_User_Manual_Alternate_Scan.pdf)은 같은 판본 보존용이다.

| 항목 | 설명서 값/표기 | 적용 범위 |
| --- | --- | --- |

| 본체 K형 측정 범위 | −200~1372°C | 동봉 프로브·고정재 범위와 다름 |

- 인쇄3면: 두 열전대 사이 전위 차이가 예상되면 전기적으로 절연된 열전대를 사용하도록 안내한다. 서로 다른 전위의 노출 금속에 맨 접점을 붙이지 않는다.
- 모터 케이스·전력 소자 표면·주위 공기 온도를 구분한다. 표면 측정으로 내부 권선/접합 온도를 직접 얻었다고 쓰지 않는다.
- 본체 오차, 프로브 오차, 고정재/접촉/열지연 오차는 별개다. 짧은 구동 중 표시 변화가 작아도 내부 발열이 없다는 뜻은 아니다.
- 프로브 비교 점검은 교정이 아니다. 실제 제공 구성품과 고정재의 허용 온도/절연은 수령 후 확인한다.
