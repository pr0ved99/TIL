# Jetson Notes

## 결론

- 이 폴더는 긴 회고 문서가 아니라, `Jetson` 현장에서 바로 참고할 짧은 메모를 저장하는 공간이다.

## 구조

- `environment/`
  - `JetPack`, `L4T`, `ROS 2`, `Docker`, 장치 연결 상태 메모
- `commands/`
  - 자주 쓰는 명령 모음
- `troubleshooting/`
  - 짧은 원인-해결 메모

## 원칙

- 1개 메모는 1개 주제만 다룬다.
- 긴 분석은 `progress/`로, 일지성 기록은 `daily/`로 보낸다.
