# Jetson Handoffs

## 결론

- 이 폴더는 `Jetson`에서 이미 한 번 검증한 작업을 다른 팀원이 그대로 이어받아 실행할 수 있게 정리한 핸드오프 문서 모음이다.
- `guides/`가 복붙용 실행 순서를 담당한다면, 여기 문서는 **현재 상태 + 실행 목적 + 필요한 문서 묶음 + 다음 단계**를 한 번에 설명한다.

## 원칙

- 한 핸드오프 문서는 한 작업 단위만 다룬다.
- 이미 있는 가이드와 스크립트를 다시 복사하지 않고, 실행 순서대로 링크를 묶는다.
- 팀원이 "지금 어디까지 됐는지"와 "다음으로 무엇을 하면 되는지"를 5분 안에 파악할 수 있어야 한다.
