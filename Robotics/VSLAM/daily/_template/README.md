- 어떤 결과를 관찰했는가?

```bash

```

### HH:MM

- 어떤 작업을 했는가?
- 예상과 실제 결과가 어떻게 달랐는가?
- 다음으로 무엇을 확인했는가?

```bash
# 실행한 명령어
```

- 어떤 수정이나 설정 변경을 했는가?
- 그 변경이 왜 필요했는가?
- 변경 후 무엇이 달라졌는가?


## 오늘 관찰한 핵심 현상

- 실행했을 때 어떤 현상이 보였는가?
- 로그, 토픽, 화면에서 핵심적으로 확인한 것은 무엇인가?
- 수치로 확인한 결과는 무엇인가?
  - 예: `Hz`, `FPS`, `latency`, `CPU`, `memory`

## 원인 가설

- 처음에는 원인을 무엇이라고 생각했는가?
- 그 가설이 맞다고 생각한 이유는 무엇이었는가?
- 나중에 보니 틀렸거나 부족했던 가설은 무엇이었는가?

## 확인 방법

- 원인을 확인하기 위해 어떤 명령어를 사용했는가?
- 어떤 비교 실험을 했는가?
- 어떤 조건을 바꿔봤는가?
  - 예: 해상도, FPS, USB 포트, 실행 순서, QoS
