# D435i IMU 축 해석 정리

## 결론

- 현재 환경에서 `D435i`의 `gyro` 값은 `camera_gyro_optical_frame` 기준으로 해석하는 것이 맞다.
- 직접 관찰한 결과,
  - 오른쪽으로 회전할 때 `angular_velocity.y`가 증가했다.
  - 위로 회전할 때 `angular_velocity.x`가 증가했다.
  - `angular_velocity.z`는 카메라가 보는 정면 축을 기준으로 비틀 때 커진다.
- 즉, 지금 단계에서는 `x=상하 pitch`, `y=좌우 yaw`, `z=렌즈 축 기준 roll`로 이해하면 된다.

## 1. 먼저 알아둘 것

- `IMU`: 가속도계와 자이로를 합친 센서다.
- `gyro`: 각속도 센서다. 얼마나 빠르게 회전하는지 본다.
- `optical frame`: 카메라 영상 기준 좌표계다. 일반 로봇 `base_link` 좌표계와 다르다.
- `roll / pitch / yaw`: 각각 비틀기, 위아래 들기, 좌우 돌리기라고 생각하면 된다.

중요한 점은, 지금 보고 있는 값은 일반 로봇 좌표계가 아니라 **카메라 광학 좌표계**라는 것이다.  
그래서 축 방향이 직관과 다르게 느껴질 수 있다.

## 2. 현재 기준 좌표 해석

`camera_gyro_optical_frame`에서는 보통 아래처럼 이해하면 된다.

- `x`: 카메라 기준 오른쪽
- `y`: 카메라 기준 아래쪽
- `z`: 카메라가 보는 정면 앞쪽

즉, 일반적인 로봇 좌표계처럼 `x=앞`, `z=위`가 아니다.

## 3. 직접 관찰한 결과

현재 환경에서 `ros2 topic echo /camera/camera/gyro/sample`로 확인했을 때, 아래처럼 관찰됐다.

| 관찰한 움직임 | 주로 증가한 값 | 해석 |
| --- | --- | --- |
| 카메라를 오른쪽으로 회전 | `angular_velocity.y` | 좌우 방향 변화(`yaw`)에 대응 |
| 카메라를 위로 회전 | `angular_velocity.x` | 상하 방향 변화(`pitch`)에 대응 |
| 아직 바로 체감되지 않음 | `angular_velocity.z` | 렌즈 정면 축 기준 비틀기(`roll`)에 대응 |

즉, 현재 관찰 결과만 놓고 보면:

- `x`: 카메라를 위/아래로 드는 회전
- `y`: 카메라를 좌/우로 돌리는 회전
- `z`: 카메라를 정면 축 기준으로 비트는 회전

## 4. `z` 값을 올리려면 어떻게 움직여야 하나

`angular_velocity.z`는 카메라가 보는 방향을 중심축으로 회전할 때 커진다.

쉽게 말하면:

- 렌즈는 계속 앞을 보게 둔다.
- 카메라 몸체만 시계 방향 또는 반시계 방향으로 비튼다.

스마트폰을 정면으로 든 채로 손목만 비틀어서 화면을 기울이는 동작을 생각하면 된다.

즉:

- 그냥 오른쪽으로 돌리는 동작은 `y` 쪽
- 위로 드는 동작은 `x` 쪽
- 몸체를 비트는 동작이 `z` 쪽

## 5. 왜 이 정리가 중요한가

이 축 해석은 나중에 아래 문제를 피하는 데 중요하다.

- `IMU` 축을 잘못 해석해서 `base_link`에 잘못 연결하는 문제
- `EKF`나 `robot_localization`에서 잘못된 회전축을 넣는 문제
- `camera_link`와 `camera_gyro_optical_frame`을 같은 축이라고 착각하는 문제

즉, **지금 단계에서 축 해석을 먼저 명확히 해두는 것이 이후 센서 융합의 전제조건**이다.

## 6. 다시 확인하는 방법

### IMU만 켜기

```bash
ros2 launch realsense2_camera rs_launch.py \
  enable_color:=false \
  enable_depth:=false \
  enable_gyro:=true \
  enable_accel:=true \
  unite_imu_method:=1
```

### gyro 값 보기

```bash
ros2 topic echo /camera/camera/gyro/sample
```

### 축별 확인 동작

1. 오른쪽으로 천천히 돌린다.
2. 위로 천천히 든다.
3. 렌즈 정면 축을 기준으로 몸체를 비튼다.

이때 각각 `y`, `x`, `z`가 어떻게 변하는지 보면 된다.

## 7. 현재 단계에서의 실용적 해석

- `D435i IMU`는 회전 변화 감지는 충분히 가능하다.
- 하지만 이 값만으로 정확한 위치 odom을 만들 수 있다고 보면 안 된다.
- 지금은 **축 방향이 맞는지 확인하는 단계**로 보는 것이 맞다.

한 줄 요약:

- 오른쪽 회전 -> `y`
- 위로 회전 -> `x`
- 렌즈 축 비틀기 -> `z`
