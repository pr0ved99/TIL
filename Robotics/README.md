# Robotics

로봇 소프트웨어, 미들웨어, 시뮬레이션, 자율주행 관련 학습 기록을 정리하는 공간이다.

## Structure

- `ROS2`: ROS 2 Humble 환경, 노드/토픽/서비스/액션, launch, tf2, RViz, Gazebo 학습
- `VSLAM`: 카메라 기반 위치 추정, RTAB-Map, RealSense D435i, Jetson 실험 기록

## Study Direction

- ROS 2 기본 그래프 구조를 먼저 이해한다.
- RViz와 Gazebo를 구분해서 사용한다.
- URDF, tf2, 센서 토픽, 제어 토픽을 하나의 로봇 시스템으로 연결한다.
- 실제 하드웨어, 시뮬레이션, 로그 검증을 함께 기록한다.
