# STM32 센서 대시보드

이 프로젝트는 STM32 마이크로컨트롤러에서 수집한 센서 데이터를 웹 기반 대시보드에서 시각화하기 위해 고안된 미니 프로젝트입니다.

## 프로젝트 아키텍처

이 프로젝트는 크게 세 가지 주요 구성 요소로 나뉩니다:

- **펌웨어 (`firmware/`)**: STM32 마이크로컨트롤러에서 실행되는 코드입니다. 센서 데이터를 수집하여 백엔드로 전송하는 역할을 합니다.
- **백엔드 (`backend/`)**: 직렬 연결이나 네트워크 인터페이스를 통해 STM32로부터 데이터를 수신하고 이를 프론트엔드에 제공하는 Python 기반 서버입니다.
- **프론트엔드 (`frontend/`)**: 센서 데이터를 실시간으로 시각화하여 보여주는 웹 인터페이스입니다.

## 목표

이 대시보드의 주요 목표는 하드웨어 센서 데이터를 수집하고 이를 사용자 친화적인 웹 인터페이스에 표시하는 종단간(end-to-end) 예제를 제공하는 것입니다.
