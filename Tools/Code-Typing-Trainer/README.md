# Code Typing Trainer

Embedded C, C++, Python, ROS 2 코드를 글자 단위로 연습하는 의존성 없는 로컬 웹 앱입니다. 별도 서버나 계정 없이 실행할 수 있고, 사용자 코드와 완료 기록은 현재 브라우저의 `localStorage`에만 저장됩니다.

## Features

- Embedded C, C++, Python, ROS 2 카테고리별 기본 문제 3개 제공
- 글자별 정답·오답 판정과 현재 입력 위치 강조
- 공백, 줄바꿈, 특수문자를 포함한 오타 위치 표시
- 누적 정확도, CPM, WPM, 타이머, 오타 수, 진행률 계산
- 같은 문제 다시 시작 및 카테고리 내 다음 문제 이동
- 사용자 코드 추가·삭제 및 카테고리별 관리
- 완료 기록, 최고 정확도, 최고 WPM, 누적 연습 시간 저장
- 키보드 접근성, 작은 화면 대응, 모션 감소 설정 지원

## Run

가장 간단한 방법은 [`index.html`](./index.html)을 브라우저에서 직접 여는 것입니다.

로컬 HTTP 서버로 실행하려면 이 폴더에서 다음 명령을 사용합니다.

```bash
python -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000`에 접속합니다.

## Controls

| 입력 | 동작 |
| --- | --- |
| 일반 문자 | 현재 위치에 한 글자 입력 및 즉시 판정 |
| `Tab` | 다음 4칸 탭 위치까지 공백 입력 |
| `Enter` | 줄바꿈 입력 |
| `Backspace` | 마지막 입력 한 글자 삭제 |
| `Shift + Tab` | 이전 UI 요소로 포커스 이동 |
| `Esc` | 연습 입력 포커스 해제 |

연습 영역에서는 기록 조작을 막기 위해 붙여넣기와 드롭을 차단합니다. 사용자 코드 추가 창에서는 붙여넣기를 사용할 수 있습니다.

## Metrics

- **정확도**: `정확한 입력 시도 / 전체 입력 시도 × 100`
- **CPM**: `현재 올바른 위치의 글자 수 / 경과 시간(분)`
- **WPM**: `CPM / 5`
- **타이머**: 첫 유효 입력부터 문제 완료까지의 실제 경과 시간

오타를 지우고 다시 입력해도 최초 오타는 정확도와 오타 수에 남습니다. 문제의 모든 위치가 채워지고 전부 일치할 때만 완료 기록을 저장합니다.

## Local Data

저장 키는 `codeTypingTrainer.v1`이며 다음 데이터를 보관합니다.

- 마지막으로 선택한 카테고리
- 사용자가 추가한 코드 문제 최대 100개
- 최근 완료 기록 최대 200개

브라우저 사이트 데이터를 삭제하거나 기록 초기화 버튼을 누르면 완료 기록이 사라집니다. 기록 초기화는 사용자 코드에는 영향을 주지 않습니다.
