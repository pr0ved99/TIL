# 08-01. Protection Model

## 결론

Protection은 합법적인 사용자가 허용된 자원만 접근하게 만드는 운영체제의 경계 설정이다.

## 핵심 개념

- `Subject`: 자원에 접근하려는 주체다.
- `Object`: file, memory, device 같은 보호 대상이다.
- `Right`: read, write, execute 같은 허용 작업이다.
- `Domain`: 권한 집합이다.

## 확인 질문

1. 보호와 보안은 어떻게 다른가?
2. 최소 권한 원칙은 왜 중요한가?
3. Process마다 다른 권한을 갖게 하는 이유는 무엇인가?
