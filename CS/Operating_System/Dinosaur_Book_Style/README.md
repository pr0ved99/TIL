# Operating System Study Notes

## 결론

이 폴더는 공룡책 원문을 복제한 자료가 아니라, 공룡책식 운영체제 학습 흐름을 따르는 원본 학습 노트다.
목표는 운영체제를 `개념 -> 동작 원리 -> 확인 질문 -> 실습` 순서로 공부할 수 있게 대단원과 소단원을 나누는 것이다.

## 저작권 기준

- 원서 문장, 예제, 그림, 문제를 그대로 옮기지 않는다.
- 각 단원은 직접 작성한 설명과 실습 중심으로 확장한다.
- 특정 판의 목차를 그대로 복제하기보다 운영체제 표준 학습 흐름으로 정리한다.

## 학습 순서

먼저 [`00_LEARNING_INDEX.md`](./00_LEARNING_INDEX.md)를 본다.
그 다음 `01 -> 02 -> ... -> 10` 순서로 읽는다.

```text
01 OS 기초
02 프로세스와 스레드
03 CPU 스케줄링
04 동기화와 데드락
05 메모리 관리
06 저장장치와 파일 시스템
07 I/O 시스템
08 보호와 보안
09 가상화와 분산
10 실습과 점검
```
