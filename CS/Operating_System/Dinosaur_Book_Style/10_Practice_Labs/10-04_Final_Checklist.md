# 10-04. Final Checklist

## 결론

운영체제 학습의 1차 목표는 용어 암기가 아니라, 어떤 문제가 생겼을 때 CPU, memory, storage, I/O, security 중 어디를 봐야 하는지 판단하는 것이다.

## 핵심 질문

1. 운영체제가 제공하는 세 가지 핵심 역할은 무엇인가?
2. System call은 왜 필요한가?
3. Process와 thread는 무엇이 공유되고 무엇이 분리되는가?
4. Context switch가 많아지면 어떤 비용이 생기는가?
5. Race condition과 deadlock은 어떻게 다른가?
6. Virtual memory는 왜 필요한가?
7. Page fault는 왜 비싼가?
8. File descriptor와 inode는 어떻게 다른가?
9. Interrupt와 DMA는 I/O 성능에 어떻게 기여하는가?
10. Protection과 security는 어떻게 연결되는가?
