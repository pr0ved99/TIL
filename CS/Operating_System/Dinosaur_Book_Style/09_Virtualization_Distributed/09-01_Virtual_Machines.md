# 09-01. Virtual Machines

## 결론

가상 머신은 하나의 물리 하드웨어 위에 여러 개의 독립된 실행 환경을 제공하는 기술이다.

## 핵심 개념

- `Hypervisor`: 가상 머신을 생성하고 자원을 나누어 주는 계층이다.
- `Guest OS`: 가상 머신 안에서 실행되는 운영체제다.
- `Host`: 실제 하드웨어 또는 그 위의 기본 운영체제다.
