# 09-03. Distributed OS Basics

## 결론

분산 환경에서는 운영체제의 자원 관리 문제가 네트워크 지연, 부분 실패, 일관성 문제와 함께 확장된다.

## 핵심 개념

- `Distributed system`: 여러 컴퓨터가 네트워크로 연결되어 하나의 서비스를 제공한다.
- `Partial failure`: 일부 노드만 실패하는 상황이다.
- `Consistency`: 여러 노드가 보는 상태를 어떻게 맞출지의 문제다.
- `Replication`: 가용성과 성능을 위해 데이터를 여러 곳에 둔다.
