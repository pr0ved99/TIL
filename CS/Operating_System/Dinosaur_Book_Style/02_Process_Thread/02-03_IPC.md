# 02-03. IPC

## 결론

IPC는 서로 독립된 프로세스가 데이터를 주고받거나 작업을 조율하는 방법이다.

## 핵심 개념

- `Pipe`: 한쪽이 쓰고 한쪽이 읽는 stream 통신이다.
- `Message queue`: 메시지 단위로 데이터를 주고받는다.
- `Shared memory`: 여러 프로세스가 같은 메모리 영역을 공유한다.
- `Socket`: 같은 기계 또는 네트워크 너머 프로세스와 통신한다.

## 비교 관점

| 방식 | 장점 | 주의점 |
| --- | --- | --- |
| Message passing | 동기화가 비교적 단순 | 복사 비용 |
| Shared memory | 빠름 | 동기화 필요 |
| Socket | 네트워크 확장 가능 | 지연과 오류 처리 |
