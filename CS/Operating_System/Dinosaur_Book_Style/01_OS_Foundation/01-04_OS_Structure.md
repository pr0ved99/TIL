# 01-04. OS Structure

## 결론

운영체제 구조는 성능, 안정성, 유지보수성을 어떻게 균형 잡을지에 대한 설계 선택이다.

## 핵심 개념

- `Monolithic kernel`: 많은 기능을 커널 안에 넣어 빠르지만 결합도가 높다.
- `Microkernel`: 핵심 기능만 커널에 두고 나머지는 user space service로 분리한다.
- `Layered structure`: 기능을 계층으로 나누어 의존성을 정리한다.
- `Module`: 필요한 기능을 동적으로 추가하거나 제거할 수 있게 한다.

## 비교 관점

| 구조 | 장점 | 단점 |
| --- | --- | --- |
| Monolithic | 빠른 경로 | 오류 영향 범위 큼 |
| Microkernel | 격리와 안정성 | 메시지 전달 비용 |
| Modular | 확장성 | 모듈 경계 관리 필요 |

## 확인 질문

1. 커널 기능을 많이 넣으면 왜 빠를 수 있는가?
2. 기능을 분리하면 왜 안정성이 좋아질 수 있는가?
3. 드라이버를 모듈로 두는 이유는 무엇인가?
