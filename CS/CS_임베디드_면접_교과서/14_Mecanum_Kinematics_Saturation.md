# Mecanum Kinematics와 Saturation

## 분야

- 로봇 기구학
- 모바일 로봇 제어
- 모터 속도 명령 변환

## 관련 면접 질문

- 메카넘 휠 바퀴 속도는 어떻게 계산하는가?
- 전진, 횡이동, 회전 명령이 동시에 들어오면 어떻게 처리하는가?
- saturation은 어떻게 처리하는가?

## 선수지식

## 핵심 개념

메카넘 휠 로봇은 전후 이동, 좌우 이동, 제자리 회전이 가능합니다. 상위 제어에서는 보통 로봇 기준 속도 명령을 받습니다.

- `Vx`: 전진/후진 속도
- `Vy`: 좌우 이동 속도
- `omega`: 회전 각속도

이 세 값을 네 바퀴 속도로 변환하는 과정이 메카넘 휠 기구학입니다.

## 기본 식

좌표계와 바퀴 배치에 따라 부호는 달라질 수 있지만, 면접에서 기대하는 핵심 형태는 아래와 같습니다.

```text
front_left  = Vx - Vy - (L + W) * omega
front_right = Vx + Vy + (L + W) * omega
rear_left   = Vx + Vy - (L + W) * omega
rear_right  = Vx - Vy + (L + W) * omega
```

여기서:

- `L`: 로봇 중심에서 앞/뒤 바퀴까지의 거리
- `W`: 로봇 중심에서 좌/우 바퀴까지의 거리
- `omega`: 회전 속도

바퀴 각속도로 바꾸려면 wheel radius `r`로 나눕니다.

```text
wheel_angular_velocity = wheel_linear_velocity / r
```

## 왜 Vx, Vy, omega가 필요한가?

메카넘 휠은 각 바퀴의 롤러 방향 때문에 바퀴 회전이 로봇의 전진 성분과 횡이동 성분을 동시에 만듭니다. 따라서 단순히 "앞으로 가면 네 바퀴 전진"만 외우면 부족합니다.

면접에서는 "로봇의 body velocity를 각 wheel velocity로 변환한다"고 말하는 것이 좋습니다.

## Saturation

Saturation은 계산된 바퀴 속도가 모터가 낼 수 있는 최대 속도를 넘는 상황입니다.

예를 들어 최대 명령이 100인데 계산 결과가 아래처럼 나왔다고 가정합니다.

```text
FL = 120
FR = 80
RL = 60
RR = 100
```

이때 FL만 100으로 잘라 버리면 이동 방향이 바뀔 수 있습니다. 따라서 전체 비율을 유지하며 scale down합니다.

```text
scale = max_allowed / max_abs_command
scale = 100 / 120 = 0.833
```

모든 바퀴에 같은 비율을 곱합니다.

```text
FL = 120 * 0.833 = 100
FR = 80  * 0.833 = 66.6
RL = 60  * 0.833 = 50
RR = 100 * 0.833 = 83.3
```

이렇게 하면 로봇의 의도한 이동 방향을 유지하면서 최대 출력 안에 들어오게 됩니다.

## 면접 답변으로 연결

### 30초 답변

> 메카넘 휠은 로봇 기준 속도인 `Vx`, `Vy`, `omega`를 네 바퀴 속도로 변환해 제어합니다. 각 바퀴 속도는 전진 성분, 횡이동 성분, 회전 성분을 조합해서 계산하고, wheel radius로 나눠 각속도로 변환할 수 있습니다. 계산된 네 바퀴 명령 중 하나라도 최대값을 넘으면 한 바퀴만 자르는 것이 아니라 네 바퀴 전체를 같은 비율로 scale down해서 이동 방향을 유지합니다.

## 내 프로젝트로 연결하는 문장

> 프로젝트에서 초기에는 PWM과 direction으로 동작을 확인했지만, 면접에서는 개선 방향으로 `Vx`, `Vy`, `omega` 기반 속도 변환식과 saturation 처리를 설명하는 것이 좋습니다.
