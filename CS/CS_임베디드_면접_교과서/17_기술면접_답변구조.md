# 기술면접 답변 구조

## 분야

- 기술 면접 커뮤니케이션
- 프로젝트 설명
- 모르는 질문 대응

## 관련 면접 피드백

- "부족했습니다", "못했습니다", "공부하지 못했습니다"를 먼저 말하지 않기
- 내가 맡은 범위와 구현한 내용을 먼저 말하기
- 한계는 마지막에 짧게 말하고 개선 방향을 붙이기
- 기술 답변에는 수치와 근거를 포함하기

## 기본 답변 구조

기술 질문은 아래 순서로 답하면 안정적입니다.

1. 정의
2. 선택 기준 또는 trade-off
3. 내 프로젝트 적용 범위
4. 검증 방법
5. 한계와 개선 방향

## 예시 1: UART Frame 질문

나쁜 답변:

> 문자열로 보냈던 것 같습니다. 자세히는 잘 모르겠습니다.

좋은 답변:

> 프로젝트 초기 구현에서는 디버깅 편의성을 위해 문자열 기반 frame과 `\r\n` delimiter를 사용했습니다. 상위 시스템에서는 한 줄 단위로 수신해 parsing했습니다. 이 방식은 빠르게 확인하기 좋지만 오류 검출이 약하므로, 개선한다면 start byte, length, command, payload, CRC를 포함한 frame으로 바꾸겠습니다.

## 예시 2: 메카넘 휠 질문

나쁜 답변:

> 제가 그 부분을 많이 못 했고, 원래는 계산했어야 했습니다.

좋은 답변:

> 제가 직접 검증한 범위는 PWM과 direction 기반의 초기 동작 확인이었습니다. 다만 메카넘 휠 제어는 원칙적으로 `Vx`, `Vy`, `omega`를 조합해 네 바퀴 속도를 계산해야 합니다. 계산된 값이 모터 최대 출력을 넘으면 네 바퀴 명령 전체를 같은 비율로 줄여 방향성을 유지하는 saturation 처리가 필요합니다.

## 예시 3: 모르는 질문

나쁜 답변:

> 죄송합니다. 공부하지 못했습니다.

좋은 답변:

> 정확한 구현 경험은 제한적입니다. 다만 개념적으로는 A는 이런 역할이고, B와의 차이는 이 부분이라고 이해하고 있습니다. 제 프로젝트에서는 이 범위까지 적용했고, 이후 보완한다면 이런 방식으로 개선하겠습니다.

## 모르는 질문 대응 템플릿

```text
정확한 구현 경험은 제한적이지만, 개념적으로는 [아는 범위]까지 이해하고 있습니다.
제가 진행한 프로젝트에서는 [직접 한 범위]까지 적용했습니다.
실제 시스템에서 보완한다면 [개선 방향]을 고려하겠습니다.
```

## 방어적으로 들리는 표현 바꾸기

| 피해야 할 표현 | 바꿀 표현 |
| --- | --- |
| 못했습니다 | 제가 직접 수행한 범위는 여기까지였습니다 |
| 공부하지 못했습니다 | 해당 부분은 구현 경험은 제한적이지만 개념적으로는 이렇게 이해하고 있습니다 |
| 했어야 했는데 | 개선한다면 이 방향으로 보완하겠습니다 |
| 부족합니다 | 현재 보완 중이며, 프로젝트에서는 이 부분까지 검증했습니다 |

## 수치와 근거를 넣는 법

면접관은 "왜 그렇게 했는가"를 자주 묻습니다. 이때 아래 근거를 말하면 답변 신뢰도가 올라갑니다.

| 주제 | 말해야 하는 근거 |
| --- | --- |
| UART | baudrate, delimiter, frame 구조, checksum 여부 |
| Sensor sampling | ODR, sampling rate, latency, MCU 부하 |
| Motor control | PWM frequency, duty, encoder tick, wheel radius |
| Mecanum | `Vx`, `Vy`, `omega`, wheel radius, saturation |
| RTOS | task period, priority, semaphore/mutex 사용 이유 |

## 최종 면접 답변 원칙

1. 모르면 바로 포기하지 말고 아는 범위를 먼저 말한다.
2. 프로젝트에서 직접 한 범위를 명확히 말한다.
3. "왜 그렇게 했는지" 근거를 붙인다.
4. 한계는 인정하되 개선 방향까지 말한다.
5. 기술명 나열보다 데이터 흐름과 검증 방법을 설명한다.

## 암기 문장

> 제가 직접 수행한 범위는 이 부분까지였고, 이 구간은 이런 방식으로 구현하고 검증했습니다. 다만 실제 제품 수준으로 개선한다면 이 요소를 추가해 안정성을 높이겠습니다.
